# 俱舍论颂疏 — 学术解读

## 一、文献背景与成书

《俱舍论颂疏论本》，简称《俱舍论颂疏》，唐代圆晖法师撰，通行著录为大正藏第一八二三号，二十九卷。据语料库原档，圆晖为唐开元年间大云寺沙门，承普光之学，有感于普光《俱舍论记》卷帙浩繁、难为初学者领悟，遂节略诸家义疏、兼摄会通，撰成此疏。

其所疏对象是世亲菩萨《阿毗达磨俱舍论》之本颂（玄奘译，T1558，三十卷）。俱舍学在唐代蔚为显学：玄奘重译俱舍之后，普光作《俱舍论记》（T1821）、法宝作《俱舍论疏》（T1822），与神泰疏并称「俱舍三大疏」。圆晖此疏以本颂为纲、逐颂释义，取《光记》之精华，兼采《宝疏》之义解，见解往往调停于普光、法宝之间，删繁就简、直指要义，遂成为汉地最重要的俱舍入门典籍，被誉为「聪明论」的津梁。

## 二、文本结构与核心思想

此书以世亲本颂为经、圆晖疏文为纬，逐颂为释。原档所录数例，可见其疏体之精。

释归敬颂「诸一切种诸冥灭，拔众生出生死泥，敬礼如是如理师，对法藏论我当说」：圆晖释「一切种诸冥灭」谓灭诸境一切品冥——以诸无知能覆实义及障真见，故说为冥。此释将「冥」训为无知，点明对法（阿毗达磨）之学以慧破冥的立论起点。

释四静虑支颂「静虑初五支，寻伺喜乐定。第二有四支，内净喜乐定。第三具五支，舍念慧乐定。第四有四支，舍念中受定」：以一颂总摄四禅十八支——初静虑具寻、伺、喜、乐、等持五支；第二静虑具内等净、喜、乐、等持四支；第三静虑具行舍、正念、正慧、乐受、等持五支；第四静虑具行舍清净、念清净、非苦乐受、等持四支。颂极简而疏极明，疏不增文而义自足。

释「佛共功德」之「共」：「虽佛功德，超过一切，然依类同，故说为共。」佛德实超二乘凡夫，然以功德类别相同而非力用相等，故谓之共。此一训释于微处见圆晖辨析名相的谨严。

## 三、学术研究价值与争议

学术价值上，此疏是俱舍学入门文献中流通最广者：三大疏俱在而卷帙繁重，此疏以二十九卷摄其要，唐以后习俱舍者多由此入，其「调停光、宝」的折中立场本身即是唐代俱舍学史的重要现象。以颂带疏的体例，亦为研究汉传佛教注疏文体提供了标本。

争议方面，其一，圆晖折中普光、法宝之处，是否忠实于两家本义，抑或为求简明而模糊了关键分歧，历来评价不一；其二，俱舍学说与有部正统（《大毗婆沙论》《顺正理论》）之间的张力——世亲造颂本有「以经部义破有部」之意——在颂疏的简明框架中容易被淡化；其三，原档题「颂疏论本」之名与卷数在流传中的异同，亦需版本学的核查。

| 术语 | 释义 |
|------|------|
| 冥 | 无知、无明，能覆实义、障真见 |
| 对法 | 阿毗达磨，以慧对观诸法之论藏 |
| 生死泥 | 以泥沼喻难出之轮回 |
| 如理师 | 如实无倒教授众生之导师，指佛 |
| 静虑支 | 构成四禅之功德要素，如寻伺喜乐等持 |
| 佛共功德 | 佛与二乘凡夫类别相同之功德，如无诤愿智 |
| 俱舍三大疏 | 普光记、法宝疏、神泰疏之合称 |
