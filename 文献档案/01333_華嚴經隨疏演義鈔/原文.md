# 華嚴經隨疏演義鈔

## 一、概述

**大正藏編號**：T1736（《大正新脩大藏經》第 36 冊）

**全稱**：《大方廣佛華嚴經隨疏演義鈔》

**別稱**：《華嚴經疏演義鈔》《隨疏演義鈔》《演義鈔》《華嚴大鈔》《清涼鈔》

**撰者**：唐·澄觀（738—839），清涼國師，華嚴宗四祖，署名「清涼山大華嚴寺沙門澄觀撰述」

**卷數**：九十卷

《大方廣佛華嚴經隨疏演義鈔》是澄觀為自己所撰《大方廣佛華嚴經疏》（T1735，六十卷）再作的解釋，屬於「自疏自鈔」的體例。「鈔」是對「疏」的疏，所以此書的解釋對象不是《華嚴經》經文本身，而是澄觀自己那部疏的文句。

其成書緣由，據記載是澄觀的弟子僧睿等人請問疏中深義，澄觀遂逐句演暢疏文之義，故名「隨疏演義」。書成之後與《華嚴經疏》合刊流通，合稱《華嚴經疏鈔》，篇幅浩繁，是漢傳佛教注釋文獻中規模最大的著作之一，被視為華嚴學的百科全書。

此書體例上以「▲」標記所釋的疏文，其下逐字逐句演繹。澄觀在鈔中大量引證內外典籍——不僅遍引諸經論，還引《周易》《論語》《老子》以及僧肇、慧遠等人的著述——以會通儒釋道，這是《演義鈔》最鮮明的學術特色，也使它成為研究唐代思想交涉的重要文獻。

在義理上，《演義鈔》最大的價值在於：它把《華嚴經疏》序文中那些高度凝練的駢文命題（如「往復無際，動靜一源」）拆解為極細密的分析，並在此過程中系統展開四法界、十玄、六相等華嚴核心教義。

## 二、核心段落

### （一）總判疏文四分

**原文：**

> 將釋此疏，大分為四：一、總序名意；二、歸敬請加；三、開章釋文；四、謙讚迴向。為順經文有四分故。若順序、正、流通，則合前二為序分，開章為正宗，謙讚為流通，為疏三分。

**白話對照：**

將要解釋澄觀這部《華嚴經疏》，大體分為四個部分：第一，總述疏的名目與立意；第二，歸依敬禮三寶並祈請加被；第三，開列章門、解釋經文；第四，自謙讚歎並迴向功德。

之所以分為四分，是為了隨順經文本身也具有四分的結構。如果按照通常的序分、正宗分、流通分三分法來配，那麼前兩部分合起來算作序分，「開章釋文」是正宗分，「謙讚迴向」是流通分——這就是疏的三分。

### （二）疏序首句的細科為十

**原文：**

> 言有四者：初通序法界，為佛法大宗。二「剖裂」下，別敘此經以申旨趣。三「是以菩薩搜祕」下，慶遇由致，激物發心。四「題稱大方廣」下，略釋題目，令知綱要。
>
> 言細科為十者，為順無盡故：一、標舉宗體；二、別歎能詮；三、教主難思；四、說儀周普；五、言該本末；六、旨趣玄微；七、盛益頓超；八、結歎宏遠；九、感慶逢遇；十、略釋名題。

**白話對照：**

說疏序有四段：第一段是通論法界，以之為佛法的根本大宗；第二段從「剖裂玄微」以下，別敘這部《華嚴經》以申明其旨趣；第三段從「是以菩薩搜祕於龍宮」以下，慶幸自己得遇此經的因由，並激勵眾人發心；第四段從「題稱大方廣佛華嚴經者」以下，簡略解釋經題，使人知曉綱要。

若再細分為十科（之所以立十，是為了隨順「十」表無盡之義）：一、標舉所宗的體性；二、別別讚歎能詮的經教；三、教主境界難以思議；四、說法的儀軌周遍普備；五、言教賅攝本末；六、旨趣玄妙微密；七、獲益殊盛而能頓超；八、結歎其宏大深遠；九、感念慶幸得以逢遇；十、簡略解釋經題名目。

### （三）釋「往復無際，動靜一源」

**原文：**

> 「往復無際，動靜一源，含眾妙而有餘，超言思而迥出者，其唯法界歟」，文有五句，言意多含，略為四意：一約三大釋，二約本末釋，三明法界類別，四總彰立意。
>
> 今初，約三大釋者，意明法界具三大故。初句明用，次句明體，次句明相，次句融拂，末句結屬。

**白話對照：**

疏序首句「往復無際，動靜一源，含眾妙而有餘，超言思而迥出者，其唯法界歟」，共有五句，含義豐富，大略可從四層意思來解釋：一、約體相用三大來解釋；二、約本與末來解釋；三、闡明法界的種類差別；四、總的彰顯澄觀立此句的用意。

先說第一層，約三大解釋——用意在於顯明法界具足體、相、用三大：
- 第一句「往復無際」是明**用大**；
- 第二句「動靜一源」是明**體大**；
- 第三句「含眾妙而有餘」是明**相大**；
- 第四句「超言思而迥出」是**融拂**（融通掃蕩前三，不令執著）；
- 末句「其唯法界歟」是**結屬**（歸結所屬）。

### （四）釋「往復」三義

**原文：**

> 今初，用大即「往復無際」是也。往者，去也、起也、動也；復者，來也、滅也、靜也。無際有二：一約廣多無有際畔，此就事用；二約絕於邊際，據即事同真。
>
> 何法往復？略有三義：一、雙約迷悟說；二、唯約就妄說；三、返本還源說。
>
> 今初，謂迷法界而往六趣，去也、動也；悟法界而復一心，來也、靜也。皆法界用也。

**白話對照：**

先說用大，即「往復無際」這一句。「往」，是去、是起、是動的意思；「復」，是來、是滅、是靜的意思。「無際」有兩重含義：一是就廣大眾多而沒有邊畔來說，這是就事相上的作用而言；二是就絕待而超越一切邊際來說，這是依據事相當體即是真如而言。

什麼東西在往復呢？大略有三種解釋：

第一，同時就迷與悟兩面來說：迷失法界而流轉往生於六道，這是「往」，是去、是動；覺悟法界而返歸於一心，這是「復」，是來、是靜。這兩者都是法界的作用。

第二，唯就妄念一面來說。

第三，就返本還源來說。

（澄觀隨後引《中論》「大聖之所說，本際不可得；生死無有始，亦復無有終」以證「無際」，又引《周易》復卦「復其見天地之心乎」、泰卦「無往不復，天地際也」以明「往復」，並引《文殊師利所說不思議佛境界經》中「有往有復名修菩薩道」一段，層層演繹。）

### （五）釋「大哉真界，萬法資始」

**原文：**

> 「大哉真界，萬法資始」者，兼下句借《周易》乾卦文勢用之。彼彖辭云「大哉乾元，萬物資始，乃統天」……今此則借初二句文勢，而所宗不同：彼指乾元，此明真界；彼指萬物，不過天地之內；此言萬法，總該世出世間，故不同也。
>
> 言「大哉」者，是發語之端，仰歎之詞也。「真界」者，即真如法界。法界類雖多種，統而示之，但唯一真法界，即諸佛眾生本源清淨心也。

**白話對照：**

「大哉真界，萬法資始」這兩句，是借用《周易》乾卦的文勢而寫成的。乾卦彖辭說：「大哉乾元，萬物資始，乃統天。」

現在澄觀借用了它前兩句的句式，但所宗尚的內容並不相同：《周易》指的是「乾元」，這裡說的是「真界」；《周易》所說的「萬物」不出天地之內，這裡所說的「萬法」則總括世間與出世間一切法——所以是不同的。

「大哉」二字，是發語的開端，是仰慕讚歎的言辭。「真界」，就是真如法界。法界的種類雖有多種，但統攝起來揭示，只是「一真法界」，也就是諸佛與眾生共同的本源清淨心。

### （六）釋「教海沖深」

**原文：**

> 「夫教海沖深，法雲彌漫，智光無際，妙辯叵窮。」
>
> 「教海」總含深廣，文略語深；「法雲」「智光」略明其廣……「妙辯叵窮」者，《法華》云「諸法寂滅相，不可以言宣」，是法不可示，言辭相寂滅故，四辯八音不能談其狀也。
>
> 「以無言之言，詮言絕之理；以無變之變，應無窮之機。」
>
> 全依體上起大用故，非是無言，非在言故。然能說之妙，謂無言之言；所說之深，謂言絕之理。

**白話對照：**

疏文說：「教海沖深，法雲彌漫，智光無際，妙辯叵窮。」

「教海」總含深與廣兩義，此處文字簡略而語意側重在「深」；「法雲」「智光」則簡略顯明其「廣」。所謂「妙辯叵窮」，《法華經》說「諸法寂滅相，不可以言宣」——這種法無法指示，因為言辭之相本自寂滅，所以即使有四無礙辯、八種梵音，也無法談說它的形狀。

疏文又說：「以無言之言，詮言絕之理；以無變之變，應無窮之機。」

這是因為完全依於本體而起大用的緣故，所以既不是全然無言，也不執著在言語之中。能說法的微妙之處，在於那是「無言之言」；所說法的深邃之處，在於那是「言語道斷之理」。

## 三、名句

**其一**

> 真界者，即真如法界。法界類雖多種，統而示之，但唯一真法界，即諸佛眾生本源清淨心也。

「真界」就是真如法界。法界的種類雖多，統攝起來只是一真法界，也就是諸佛與眾生共同的本源清淨心。

這是澄觀「一心法界」思想最直截的定義。他把《華嚴》宏闊的法界宇宙論收攝到「本源清淨心」上，使客觀的法界論轉向主體的心性論。此一轉向對其弟子宗密的「華嚴禪」以及後世禪教一致的思潮影響極深——法界不在心外，故參究此心即是契入法界。

**其二**

> 以無言之言，詮言絕之理；以無變之變，應無窮之機。

用那超越言說的言說，去詮表那言語道斷的真理；用那並無變異的變現，去回應那無窮無盡的根機。

此兩句本是《華嚴經疏》原文，澄觀在《演義鈔》中詳加演繹。它精準地回答了一個根本悖論：既然真理不可言說，經教何以可能？答案是「全依體上起大用」——言說並非外在於真理，而是真理自身的顯發，所以「非是無言，非在言故」。這是華嚴宗教學觀的理論基石。

## 四、術語表

| 術語 | 說明 |
|-----|------|
| **鈔** | 註釋體裁之一。「疏」是對經的解釋，「鈔」是對疏的解釋。本書為澄觀自釋其《華嚴經疏》，故稱「隨疏演義鈔」。 |
| **隨疏演義** | 隨順疏文而演暢其義。點明本書逐句解釋自撰疏文的體例。 |
| **華嚴經疏鈔** | 《華嚴經疏》（六十卷）與《隨疏演義鈔》（九十卷）的合刊本，是華嚴學規模最大的註疏體系。 |
| **一真法界** | 統攝一切的唯一真實法界，澄觀直指其即是「諸佛眾生本源清淨心」。 |
| **四法界** | 事法界、理法界、理事無礙法界、事事無礙法界。澄觀確立的華嚴根本架構。 |
| **三大** | 體大、相大、用大。出《大乘起信論》。澄觀以此三大配釋疏序首句，顯法界具足三大。 |
| **融拂** | 融通掃蕩。在依次說明體相用之後，再以一句掃除對前三者的執著，令不落言詮。 |
| **細科** | 精細的科判。澄觀常於粗分之後再細分為十，取「十」表無盡之義。 |
| **無言之言** | 超越言說的言說。指佛陀依真如本體所起的教說之用，既不離言，亦不著言。 |
| **教海** | 譬喻佛陀言教如大海般深廣無涯。 |
| **法雲彌漫** | 譬喻佛法如雲布空，普覆一切。語出《十地經》「如來祕密藏大法明、大法照、大法雨」之意。 |
| **極位所承，凡情難挹** | 唯有十地菩薩的極位才能承受如來大法，凡夫情識難以汲取。澄觀以此結成佛法難思，隨即又依聖教許可而說明凡情仍可仰信趣入。 |

## 五、相關文獻

**直接相關**

- 澄觀《大方廣佛華嚴經疏》（T1735，六十卷）：本書所釋的對象，二書合刊為《華嚴經疏鈔》。
- 《大方廣佛華嚴經》八十卷（T279）：實叉難陀譯，疏鈔所依的經本。

**澄觀其他著作**

- 《華嚴法界玄鏡》（T1883）：註釋杜順《華嚴法界觀門》，闡明華嚴三觀與四法界的關係。
- 《華嚴經行願品疏》及《疏鈔》：疏釋《四十華嚴》普賢行願品。
- 《三聖圓融觀門》《華嚴心要法門》《五蘊觀》：闡發觀行的短篇。
- 《答順宗心要法門》：應唐順宗之問而作。

**前行淵源**

- 杜順《華嚴法界觀門》：華嚴三觀的源頭。
- 智儼《華嚴經搜玄記》（T1732）、《華嚴一乘十玄門》（T1868）。
- 法藏《華嚴經探玄記》（T1733）、《華嚴一乘教義分齊章》（T1866）：澄觀在十門體例與新十玄上直承法藏。
- 《大乘起信論》（T1666）：澄觀釋「三大」所本。

**本書所廣引的內外典籍（體現其會通特色）**

- 佛典：《法華經》《涅槃經》《十地經論》《中論》《維摩經》《文殊師利所說不思議佛境界經》等。
- 外典：《周易》（乾卦、復卦、泰卦）、《論語》（「述而不作」）、《老子》，以及僧肇《肇論》、慧遠等人的著述。

**後續**

- 宗密《注華嚴法界觀門》（T1884）、《原人論》（T1886）、《禪源諸詮集都序》（T2015）：華嚴五祖承澄觀「一心法界」而開展華嚴禪。
- 宋·淨源、明·德清等人的華嚴疏鈔整理與節本。
