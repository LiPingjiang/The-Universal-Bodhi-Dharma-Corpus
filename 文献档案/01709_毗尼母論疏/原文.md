# 毗尼母論疏·原文

## 一、概述

毗尼母论疏，指对《毗尼母经》之疏释。毗尼母经收录于大正藏第1463号，凡八卷，又名《毗尼母论》《毗尼毋经》，略称《母经》《母论》。译者为"失译人名今附秦录"，属后秦时期之译本，所属部派存在争议，通常被视为萨婆多部之论著。该论为注释律藏犍度品之典籍，属汉传律学"四律五论"中"五论"之一。"母经"者，梵云摩夷（Mātṛkā），译曰行母，是诠显行法能生行，如母之生子，故云行母，亦为论藏之别名；今为毗尼之论释，故名毗尼母经。"毗尼"意为灭——灭诸恶法，故名毗尼。该论开篇有偈颂概括其"广摄毗尼义"之特点，内容主要阐释"母经"之含义，详细解释"受具足"之多种方式与含义，并涉及僧团生活之诸多规范。

## 二、核心段落

### 段落一：毗尼母经之义

**原文：**

> 母义今当说，汝等善听之，是中文虽略，广摄毗尼义。依初事演说，智慧者当知，一切经要藏，皆总在此中。律藏外诸义，母经中可得。律义入此经，如众流入海。毗尼外诸义，如母经中得。一切诸经义，随意皆能解，律能灭疑惑，如众经定说。佛所制诸戒，皆在此经中。

**白话翻译：**

"母经"之含义现在应当解说，你们好好听。此论文中文字虽然简略，却广摄毗尼（律藏）之要义。依最初之制戒因缘来演说，有智慧的人应当知道，一切经藏之要义都总摄在此论之中。律藏以外的诸般义理，都可以在母经中获得。律藏之义理入于此经，如同众水流归于大海。毗尼以外的诸般义理，也如从母经中获得。一切诸经之义理，随意都能理解；律能灭除疑惑，如众经中所确定说。佛所制定的一切戒法，都总摄在此经之中。

### 段落二：受具足之含义

**原文：**

> 问曰：何故名受具足？智慧人受具足已不犯，所求成就故言受具。能成就义名为受具。以是义故，成就众善名为受具。复次能专心持戒，故言受具。能使成沙门义，故名受具。能使人成就意净法故，名为受具。能成就寂灭法故名受具。又成就比丘法故名受具。于此律中知见达解触证得知，名为受具。有能成就比丘五种受具，名为受具。何者五？一者善来比丘即得受具。二者三语即得受具。三者白四羯磨受戒名为受具。

**白话翻译：**

问：为什么叫做"受具足"呢？有智慧的人受具足戒之后不再违犯，所求之事都能成就，所以称为"受具"。"能成就"之义名为受具。以此义故，成就一切善法名为受具。其次，能够专心持戒，所以称为受具。能使成就沙门之义，所以称为受具。能使人成就意清净之法，所以名为受具。能成就寂灭之法所以名为受具。又因成就比丘法所以名为受具。在此律中知见通达解悟触证得知，名为受具。有能成就比丘之五种受具方式，名为受具。是哪五种呢？第一，善来比丘即可得受具足。第二，三语即可得受具足。第三，白四羯磨受戒名为受具足。

## 三、名句

1. "律义入此经，如众流入海……佛所制诸戒，皆在此经中。"——以众流归海为喻，说明毗尼母经总摄律藏要义。

2. "毗尼者，名灭。灭诸恶法，故名毗尼。"——以"灭"释毗尼，灭诸恶法为律藏之根本功能。

|------|------|
| 母经 | 梵文Mātṛkā，意译行母，诠显行法能生行，如母之生子 |
| 毗尼 | 梵文Vinaya，意译律、灭、调伏，灭诸恶法之义 |
| 受具足 | 受具足戒，比丘、比丘尼所受之圆满戒法 |
| 善来比丘 | 佛说"善来比丘"，此人须发自落、袈裟著身，即得戒体 |
| 三语 | 归依佛、法、僧三宝之三说，即得受具足戒 |
| 白四羯磨 | 僧团受具足戒之作法，一白三羯磨，为最隆重之羯磨 |
| 四律五论 | 汉传律学之基本文献，四部广律与五种律论之合称 |
| 犍度品 | 律藏中按事类编排之章品，记载僧团制度与日常规范 |
