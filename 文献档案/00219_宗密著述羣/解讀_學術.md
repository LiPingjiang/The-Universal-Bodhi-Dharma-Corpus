# 宗密著述群 — 学术解读

## 一、文献背景与成书

本档案为唐代宗密（780–841）著述的综述类条目。宗密俗姓何，名炯，果州西充（今四川西充）人，因常住终南山圭峰兰若，世称圭峰宗密；谥定慧禅师。他在佛教史上的身份是罕见的「双嗣」：既是华严宗第五代祖师（承澄观），又嗣禅宗荷泽神会一系的法脉。其所著涵盖《圆觉经大疏》（T1795）、《华严原人论》（T1886）、《禅源诸诠集都序》（T2015）、《注华严法界观门》（T1884）等，构成一个「以华严为教理骨架、以荷泽禅为心地法门」的完整体系。

时代背景须先交代：宗密生活的中晚唐，正是禅门诸宗竞立、教内义学与禅学分途的时代。宗密本人的回应是两面作战——对外会通儒道（见其判教著作《原人论》，库中另有 `01340_原人論` 专条，本条与之分工：彼论专书，本条综论著述群整体）；对内弥合禅与教，其《禅源诸诠集都序》即为此而作。《禅源诸诠集》（本书原为《禅藏》一部汇编之总序，原集已佚，赖序文传世）汇集禅宗诸家文字，序中给出「三宗配三教」的会通框架，是中国禅学史的奠基文献。宗密晚年更卷入政争（甘露之变前后），最终遇难，其生平的传奇性与著述的系统性恰成对照。

## 二、文本结构与核心思想

此著述群可以「一经、一序、一论、一注」四根支柱概观。

《圆觉经大疏》群：《圆觉经》（T842）被宗密判为一乘显性教的代表经典，他毕生用力最深者即此经的疏、钞系统（大疏、大疏释义钞、略疏、略疏钞）。其释经的立场已见于《原人论》所引：「一切有情皆有本覺真心，無始以來常住清淨，昭昭不昧，了了常知，亦名佛性，亦名如來藏。」本觉真心是贯穿全部著述的最高概念。

《禅源诸诠集都序》：此文的义理枢纽在「禅源」二字。「禪是天竺之語，具云禪那，此云思惟修，亦云靜慮，皆定慧之通稱也。源者，是一切眾生本覺真性，亦名佛性，亦名心地。悟之名慧，修之名定。定慧通名為禪。此性是禪之本源，故云禪源。」——禅不是打坐的技术，而是一切众生本觉真性的发现过程；「非離真性，別有禪體」，迷真合尘名散乱，背尘合真名禅定。由此，禅与教（经教）不是两种东西：诸宗所传之禅是「佛心」，诸师所弘之教是「佛语」，心语必不相违——这就是「禅教一致」的论证核心。

《华严原人论》：以「先破后会」的结构完成判教（详见 `01340_原人論` 专条），其〈会通本末〉篇的收摄原则与本群思想一以贯之：「真性雖為身本，生靈蓋有前後，故權設五乘之教……雖有淺深，同一所歸。猶如言家者，雖有祖孫長幼，同一宅住。」

《注华严法界观门》：注杜顺《法界观门》，将华严观法接入实践脉络。四者合观：教（华严）、禅（荷泽）、行（观门）、判（原人论）——宗密的著述群是一个自洽的、覆盖理论与方法的完整体系，其总纲即「一切有情本来是佛」。

## 三、学术研究价值与争议

研究价值方面：第一，宗密是禅宗史上第一位「有系统著作传世」的禅师，《禅源诸诠集都序》对当时禅门四家（洪州、牛头、北宗、荷泽）的判摄，是研究中唐禅宗派系史的一手材料——没有此书，中唐禅的地图无从绘制；第二，「禅教一致」的论证框架深刻影响了后世（永明延寿《宗镜录》的集大成即其余绪），是宋代以后中国佛教「教禅融合」基本格局的源头之一；第三，其对宋明理学的影响（真心说与心性论、《原人论》对儒学的批判性吸收）是思想史的重大课题；第四，裴休《唐故圭峰定慧禅师传法碑》与《遥禀清凉国师书》等附传材料，保存了珍贵生平史料。

争议与问题方面：其一，宗密所判「三宗三教」的对应框架，出于荷泽立场的安排，对洪州宗（后世临济之源）的判抑是否公允，禅学史研究长期争论；其二，《圆觉经》本身的经典地位问题——此经由《楞严》等一同被近现代文献学怀疑为「中土撰述」经典，宗密以其为一乘显性教核心的判摄，牵动其整个思想体系的经典基础；其三，「本觉真心」直接承自《起信论》，而《起信论》的作者与成书地（印度说与中土撰述说）是学界百年公案，宗密思想的「印度渊源」与「本土创造」之比例随之不定；其四，宗密著述的传本系统（宋净源重刊本等的改动问题）亦需批判性使用。本条与《原人论》专条互为表里，宜配合阅读。

## 四、术语对照表

| 术语 | 释义 |
|------|------|
| 宗密（圭峰） | 华严五祖兼荷泽禅传人，著述群之主体 |
| 禅那（dhyāna） | 梵语「禅」之全称，义为思惟修、静虑，定慧通称 |
| 禅源 | 一切众生本觉真性为禅之本源，宗密立论枢纽 |
| 本觉真心 | 众生本具的觉性真心，亦名佛性、如来藏 |
| 禅教一致 | 佛心（禅）与佛语（教）不相违背的会通立场 |
| 三宗配三教 | 《禅源诸诠集都序》将禅门三宗与经教三类相配的框架 |
| 一乘显性教 | 宗密判教的最高一级，直示真心之教 |
| 定慧 | 悟真性名慧，修真性名定，宗密对禅的操作定义 |
| 荷泽宗 | 神会所传南宗一系，宗密禅法之所承 |
| 《圆觉经》 | 宗密用力最深的经典，判为一乘显性教代表 |
