# 人天眼目 — 学术解读

## 一、文献背景与成书

《人天眼目》，六卷，南宋晦岩智昭编集，约成书于淳熙十五年（1188），收于《大正藏》第四十八册（No. 2006）。书名取"人天之眼目"之义，意为此书可为天上人间指示禅门五家宗旨之眼目。

宋代禅宗经唐末五代的发展，形成沩仰、临济、曹洞、云门、法眼五家（宋代临济下又出黄龙、杨岐二派，合称七宗）。各家宗风代代相传，纲宗名目繁多而原始文献散漫，学人往往得筌忘鱼、逐末失本。智昭有见于此，遍集五家机缘语句、纲宗图诀，分类编次，使各家宗旨一目了然。其自序明宗旨云："五家虽殊，佛祖一心无异。"

## 二、文本结构与核心思想

全书按五家分卷编次（临济、云门、曹洞、沩仰、法眼各占一卷，另有序文、宗纲杂录等），每家先列宗风概述，次录祖师机缘语句，再揭纲宗名目。如原文所录："五家宗风各有旨趣。临济宗以棒喝为宗，云门宗以一字关为旨，曹洞宗以默照为要，沩仰宗以圆相为体，法眼宗以唯心为宗。"各卷要点如下：

1. **临济**：辑三玄三要、四料简、四宾主等纲宗及临济语录要句，宗风"痛快"。
2. **云门**：辑云门三句（函盖乾坤、截断众流、随波逐浪）等，宗风"高古"。
3. **曹洞**：详录五位君臣、五位显诀、宝镜三昧等，宗风"细密"。
4. **沩仰**：辑九十七圆相等图相法门，宗风"谨严"。
5. **法眼**：辑华严六相义等，宗风"通俗"。

其核心思想可归结为"一味五调味"：五家手段不同，所证无二——名句所谓"一家一味，同契真机"。纲宗差异是应病与药的方便施设，不是真理有五套。这一"判教于禅门内部"的立场，使本书兼具纲要书与判教书的双重性质。

## 三、学术研究价值与争议

**研究价值**：本书是研究五家七宗宗风差异的枢纽文献。许多已佚或散落的纲宗资料（如沩仰九十七圆相、曹洞五位图诀）赖此保存梗概，是复原晚唐五代禅门教学方法论的一级材料。同时它反映了南宋人对"五家分灯"的历史化、体系化叙事，对研究宋代禅宗的自我理解极有价值。

**代表学者**：忽滑谷快天《中国禅学思想史》广泛利用本书论五家宗旨；柳田圣山的禅文献研究涉及其史料取舍；中文及日本学界关于五家宗风的研究（如对云门三句、曹洞五位的专题考察）多以本书为基本参照；近年西方禅学研究（如对各宗教学法差异的比较研究）亦常征引。

**争议问题**：其一，纲宗的年代学问题——书中所载诸家纲宗名目，有多少是晚唐五代原貌、多少是宋代追认整理，学界对"纲宗体系化"的时代层次多有辨析；其二，智昭的取舍与表述是否准确代表各家，例如以"默照"概曹洞之要，实为南宋曹洞（天童正觉）的时代色彩，未必尽合唐五代曹洞原意；其三，"五家一味"的调和立场与强调家派差异的宗派意识之间的张力，是解读本书叙事立场的关键。

## 四、术语对照表

| 术语 | 释义 |
|------|------|
| 五家 | 沩仰、临济、曹洞、云门、法眼五个禅宗宗派 |
| 宗风 | 一宗接机化物的独特作风与教学风格 |
| 棒喝 | 棒打与断喝，临济宗风之标志 |
| 云门三句 | 函盖乾坤、截断众流、随波逐浪 |
| 圆相 | 书圆相（○）以示旨的图相法门，沩仰宗所用 |
| 六相义 | 总别、同异、成坏，法眼宗引华严义说禅 |
