# 佛教四無畏研究_3 — 学术解读

## 一、文献背景与成书

本条目是语料库「研究」系列中的一个主题类条目，编号 06600，不属于传世大藏经中的独立典籍。其原文档仅存名目、定义与两段节引，并未收录完整经文，故不宜按单部经典的成书过程去考订，而应视为围绕「四无畏」这一佛德主题整理的专题资料。以下解读依据原文档所录内容，并就该主题在佛教文献史上的可考脉络作综述说明。

四无所畏是佛弟子描述佛陀品格的一组古老教法，散见于四部阿含、广律与阿毗达磨诸论。汉译《杂阿含经》中已有佛于大众中说法「无所畏」的表述；《大智度论》《俱舍论》等将其纳入佛德体系，与十力、十八不共法并列。值得注意的是，原文档自身保存了两套名目：概述部分作「一切智无畏、漏尽无畏、说障道无畏、说尽苦道无畏」，与《俱舍论》系统的通行四无畏名目一致；而核心段落引文则作「正等觉无畏、漏永尽无畏、说障法无畏、说出道无畏」，措辞更接近般若中观系文献的用语。两套名目并存，正是本条目以原文档为准予以著录、并加以注记的地方。

此外，引文中还录有一组菩萨四无畏——「能持无畏、不忘失无畏、无过患无畏、不失念无畏」，显示了这一名相从描述佛陀功德扩展为菩萨行位修习内容的大乘转向。

## 二、文本结构与核心思想

原文档由文献概述、核心段落选录、重要名句、术语对照表与相关文献链接五部分构成，属于「名目加节引」的主题条目体例。其核心思想可以概括为：四无畏是佛陀面对大众质询时的四种自信立场。

其一，正等觉无畏：佛自认证得圆满正觉，若有人质疑「汝非一切智」，佛能坦然作答而无惧；其二，漏永尽无畏：佛宣称烦恼已永尽无余，敢受质证；其三，说障法无畏：佛指出哪些法障碍圣道，判定明确，不因诘难而动摇；其四，说出道无畏：佛所开示的尽苦之道确实能令众生出离生死，佛对此有充分把握。引文所谓「如来在大众中作师子吼，无所畏惧」，即总说这四种面对挑战而不怯惧的气度。师子吼之喻强调的并非音量或姿态，而是陈述真相时的笃定——如同狮子一吼，群兽慑伏。

菩萨四无畏一段则把这套框架转化为修道者的功课：能持（于所受法能忆持）、不忘失、无过患、不失念，四法圆满即近佛果，体现出大乘佛教把果地德目下化为因地修持的诠释策略。

## 三、学术研究价值与争议

第一，四无畏是理解佛德体系结构的关键一环。学界通行的分析认为，十力侧重「智」的方面，四无畏侧重「决断」的方面，两者实为一事的两面：于智为力，于当众宣说、直面诘问则为无畏。本条目与库内十力、十八不共法条目对照阅读，可以完整呈现早期佛教对「佛格」的理论化过程。

第二，「一切智无畏」牵动着部派佛教一场著名争论。说一切有部主张佛是一切智者在语义上仅指「于佛法如实遍知」，而大众部则倾向于更宽泛的一切智论述；《大毗婆沙论》中保留了对佛智范围的多方辨析。四无畏中第一无畏敢于宣称正等觉，正是这场争论在名相层面的投影。

第三，菩萨四无畏的名目在大乘诸经中开合不一，本条目所录「能持、不忘失、无过患、不失念」一套，与《大智度论》等所举菩萨无所畏的表述各有出入，可为考察大乘佛格论扩展提供对照材料。原文档词条拼写如 Sāvaramāgya、Niyyānika-mārga 与通行梵巴字形略有差异，亦依原样著录，研究者引用时应核对通行梵巴语文本。

## 四、术语对照表

| 梵/巴语 | 汉语 | 英译 |
|---|---|---|
| Vaiśāradya | 无畏 | fearlessness |
| Abhisambodhi | 正等觉 | perfect enlightenment |
| Āsravakṣaya | 漏尽 | destruction of defilements |
| Sāvaramāgya | 障道 | hindrance to the path |
| Niyyānika-mārga | 尽苦道 | path leading out |
| Siṃhanāda | 师子吼 | lion's roar |

表中 Sāvaramāgya、Niyyānika-mārga 依原文档著录；其中 Niyyānika 为巴利语「导向出离」的通行形式，与「尽苦道」的意涵正相吻合。
