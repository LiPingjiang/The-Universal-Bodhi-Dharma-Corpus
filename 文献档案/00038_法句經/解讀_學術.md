# 法句经 — 学术解读

## 一、文献背景与成书

法句经（Dhammapada）为巴利经藏小部第二部，收录四二三偈，分二十六品（双品、不放逸品、心品、花品、愚人品、智者品、阿罗汉品乃至婆罗门品等），品名多以意象或人物类型为题。诸偈传为佛陀在各种情境下所说，由后人辑录成集。

汉译系统极为重要：三国吴维祇难等译《法句经》二卷（T210，约公元224年）是汉译佛典中最古老的偈颂集之一；西晋法炬、法立译《法句譬喻经》（T211）以偈配故事；宋天息灾译《法集要颂经》（T212）则出自说一切有部传本（梵语 Udānavarga，偈数近千）。巴利本四二三偈、汉译古本约五百偈、梵本近千偈的三个系统互有出入，构成偈颂文献比较研究的经典案例。

## 二、文本结构与核心思想

法句经的编集逻辑是「主题品目＋对偶偈颂」：几乎每一品都以「愚人与智者」「染污与清净」「放逸与不放逸」的两两对照展开，第一「双品」开头两偈即为全经定调——「诸法意先导，意主意造作；染污心言行，苦随如轮随辙；清净心言行，乐随如影随形」。

核心思想可归纳为三线：其一，**心为业的源头**——伦理的因果不是外在报应，而是动机→行为→习惯→命运的内在链条；其二，**不放逸（appamāda）为诸德之首**——第183偈「不作一切恶，具足一切善，自净其意，此是诸佛教」被称为「诸佛通诫偈」，是全部教法的最简表达式；其三，**自依自度**——第276偈「汝当自精勤，如来唯说示」，明确导师只能指路，行路在己。

## 三、学术研究价值与争议

**研究价值**：法句经的巴利、犍陀罗语（出土写本中亦有法句残卷）、梵语、汉译四系对勘，是重建佛教偈颂流传史的最佳标本；T210 译于3世纪初，其译语为汉译佛典语言史提供早期断代坐标；法句注（Dhammapada-aṭṭhakathā）保存的因缘故事则是叙事文献研究富矿。

**争议问题**：其一，诸本偈颂重合率不足一半，哪些偈属「共同祖本」、哪些为部派增补，需逐偈判定——学界一般认为各本共享的核心偈群即已相当古老；其二，法句类文献究竟是「修行手册」还是「布教语录集」——其格言化风格或暗示它最初面向在家人弘法的用途；其三，梵本《法集要颂》偈数远多，是「收罗更全」还是「晚期膨胀」，方向之争未息。代表性研究如学术界对巴利—犍陀罗—梵本对勘的系列成果，显示西北印度流传的偈颂传统与锡兰传统各自发展。

| 法句（Dhammapada） | 「法之偈句」，佛陀法语之偈颂选集 |

| 不放逸（Appamāda） | 警觉精进，诸善法之根本 |

| 自净其意 | 净化自心，通诫偈之第三句 |
| 双品对偶 | 愚智、染净两两对照之编偈法 |
