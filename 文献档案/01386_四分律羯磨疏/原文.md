# 四分律羯磨疏 · 原文

## 一、文獻概述

《四分律刪補隨機羯磨疏》，四卷（分作八卷），唐代道宣律師撰，收於《大正新修大藏經》第四十冊，編號T1808。此書為道宣為自輯之《四分律刪補隨機羯磨》所作之疏釋，簡稱《羯磨疏》，因羯磨梵語義為「業」，故又稱《業疏》。據《佛學大辭典》「五大部」條所載，南山所撰大部凡三：「曰刪補鈔、戒本疏及茲疏」；而「凡律之要，唯有二事，即所謂止惡與修善：戒疏詳止惡之行相，業疏詳修善之行相，事鈔兩明止惡修善之二者」。故《業疏》為南山三大部中專明「作持」——僧團一切積極法事（受戒、說戒、安居、懺悔、住房分配置物等）之理論與作法——之根本典籍，其中對受戒得戒之原理、戒體之生起、羯磨成否之條件等義理辨析尤為精密，是律宗「化教／行教（制教）」判釋中行教體系之樞紐。

注釋方面，宋代有允堪《四分律隨機羯磨疏正源記》八卷、元照《四分律羯磨疏科》四卷及《四分律羯磨疏濟緣記》（排科二十二卷），其中元照《濟緣記》為最通行之注釋，後世多與《業疏》合刊流通；明末讀體律師之《毗尼作持續釋》亦依此疏而作。近代弘一律師整理南山律典，校點《含注戒本疏》《羯磨疏》《行事鈔》等三大部，此書賴以重光。

## 二、核心段落選錄

> **原文**：「南山所撰大部凡三，曰刪補鈔、戒本疏及茲疏。」（《隨機羯磨疏正源記》卷一所引南山撰述之通敘，轉引自《佛學大辭典》）
> **白話對照**：道宣律師所著律學大部有三部：《行事鈔》（刪補鈔）、《含注戒本疏》（戒本疏），以及這部《羯磨疏》（業疏）——三部合稱南山三大部，窮盡律藏之要義。

> **原文**：「戒疏詳止惡之行相，業疏詳修善之行相，事鈔兩明止惡修善之二者。」（《佛學大辭典》「五大部」條所述南山三疏之分工）
> **白話對照**：律的內容總括只有兩件事：止惡與修善。《戒疏》（含注戒本疏）詳細說明「什麼不可做」（止持）；《業疏》（本書）詳細說明「應當怎樣做」（作持）；《行事鈔》則兩面兼明，總攝全部律行。

> **原文**：據南山律學通義，本疏於受戒門中立「能受有十二人，所受有具四緣、八障揀難」等揀別；於羯磨門中立「法、事、人、界」四種成就之軌則：法謂羯磨之作法如文，事謂所秉之事如法，人謂足數僧滿其量，界謂結界成就攝僧不亂——四種具足，羯磨方成。（據《業疏》受戒、羯磨諸篇之通行義理概括）
> **白話對照**：本疏指出：一場羯磨（僧團法事）要合法有效，必須四個條件同時具足——作法程序完全符合律文（法）、所辦的事本身如法（事）、參與僧眾人數足夠且資格無疑（人）、舉行場所之結界如法無雜（界）。缺任何一項，法事即不成立。此「法事人界」之判析是本疏對僧團制度法理之最大貢獻。

## 三、重要名句

> **名句一**：「業疏詳修善之行相」——本書之定位：南山律學中一切「應作」法事之總匯。

> **名句二**：「法、事、人、界，四種成就」——羯磨有效之四要件，僧團法事之法理判定標準。

> **名句三**：「受戒者，超凡鄙之穢流，入聖眾之寶位」——本疏受戒篇明受具之義利：由羯磨而得戒體，轉凡成聖（依《業疏》受戒緣起之通行義述）。

> **名句四**：「作持明其應作，止持明其不應作；作犯止犯，翻之即是」——止作四句之判，南山持犯理論之綱格。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 業疏 | 本書之別名；羯磨梵語為「業」，故名 |
| 作持 | 應當積極履行之善行作法，本書所明 |
| 止持 | 禁止不作之惡行防護，戒疏所明 |
| 羯磨 | 僧團法事之作法程序，本疏所釋之主體 |
| 結界 | 劃定僧團法事有效之場區範圍 |
| 足數僧 | 羯磨成立所需之最低合法人數 |
| 三壇大戒 | 沙彌、比丘、菩薩三壇次第受戒之制度，依羯磨而立 |
| 濟緣記 | 宋元照為本疏所作之注釋，最通行之本 |
