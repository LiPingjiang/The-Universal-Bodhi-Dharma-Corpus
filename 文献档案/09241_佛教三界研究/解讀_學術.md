# 佛教三界研究 — 学术解读

## 一、文献背景与成书

本条目为语料库「寰宇覺海·菩提法藏」之独立文献补充条目，编号 X7727，名目作「佛教三界研究」。如实说明：其《原文》不是一经一论之传本，而是以「欲界、色界、無色界」三名数为纲的主题辑录，概述列名，选录与名句各存两条引文，术语表七条，末附相关文献指引；条目 README 自署「待後續填充內容」，故其性质是保存三界名数与纲要用语的简编，留待日后扩充。

三界说是佛教宇宙论与禅定学说的交汇点，其经典依据分布极广：《长阿含·世记经》与《俱舍论·分别世品》详述器世间结构，《中阿含》与巴利《中部》诸经则从禅定层次立三界。选录引文「三界者：欲界、色界、無色界。欲界有六天，色界有十八天，無色界有四天。如是三界，眾生流轉」当出自对《俱舍论》系的撮述：色界十八天之数正与《俱舍论》初禅三天（梵众、梵辅、大梵）、二禅三天（少光、无量光、极光净）、三禅三天（少净、无量净、遍净）、四禅八天（无云、福生、广果及无想天，加净居五天成十三，但净居天唯圣者所居，通常计入则为十八或依别释有异）的通说相应，而巴利上座部所传色界十六天，可见「十八天」之数是有部系汉传的特有计数。无色界四天即空无边处、识无边处、无所有处、非想非非想处，与四无色定一一对应，诸传一致。

第二条引文「三界無安，猶如火宅」用《法华经·譬喻品》火宅喻之意，「諸苦所集」则与四谛之苦谛相呼应，是辑录者把宇宙论名数转向解脱论判摄的点睛之笔。

## 二、文本结构与核心思想

《原文》五节悉依补充条目通例，兹不复述结构，径析其义。

三界首先是欲、色、无色的三层存在界。欲界为具淫欲与食欲的有情所居，下自地狱、旁生、饿鬼、人及六欲天（四天王天、忉利天、夜摩天、兜率天、化乐天、他化自在天）；色界有情已离欲而仍有色身宫殿，即四禅诸天；无色界有情连色身亦舍，唯心识住于四种无色定境。此一分类同时是禅定阶次的镜像：初禅离生喜乐、二禅定生喜乐、三禅离喜妙乐、四禅舍念清净，依次对应色界诸天；四无色定对应无色四天，故三界既是空间描述也是心理状态的投影。

其流转义如引文所示：「如是三界，眾生流轉」。三界不共于其他宗教的天堂观者，在于它整体被判为苦谛所摄——生在天界仍是轮回的一环，天寿尽时还复堕落。故第二条引文续言「智者當求出離，證涅槃樂」：三界说在佛教教理中的功能不是描绘美好来世的地图，而是标明整个轮回领域的边界，涅槃则在此边界之外。这一「整体判摄」的取径，是佛教区别于一神教永恒天堂观念的关键。

## 三、学术研究价值与争议

第一，天层数目的部派差异是佛典文献学的常设课题。欲界六天诸部一致；色界天数则有十六、十七、十八、二十二等异说，上座部巴利传通常作十六天，《俱舍论》系的十八天与后来唯识家的二十二天（于净居天外别立）并存。本条目取十八天，可视为有部—俱舍系计数之遗。研究者据此当注意：引文中的数字反映的是特定部派的传本知识，不宜当作「原始佛教」的定说。

第二，三界说与印度教的宇宙论关系。三界分层明显吸收并改造了当时通行的吠陀—奥义书式天界观念，但以「无明—行—识」的缘起链与业感轮回说重加解释，把天界从崇拜对象降格为流转场所。此点经比较宗教学的反复讨论，已成共识性的判断；至于改造过程的具体文本线索，仍赖《长阿含》《俱舍》与印度教文献的对读。

第三，三界的心理学解读是现代诠释的活跃地带。有学者主张三界诸天实质是禅定经验的对象化：修定者依定境浅深死后感生相应的天界，故三界图谱同时是一张深度心理学地图。此说在佛教内部亦有经典依据（四无色定与无色四天的对应），但把色界天完全心理化是否抹去了业感缘起的维度，仍有争议。

第四，藏传阿毗达磨（如《摄阿毗达磨义论》系的上座部论书与藏传俱舍学）对三界各有详疏，其中依藏文传承的论典不在大正藏编号体系之内，应转检德格版等藏文大藏经编目。
