# 佛教創業心理學 · 原文

## 一、學科概述

創業心理學研究創業者的人格特質（風險承擔、成就動機、模糊容忍度）、認知（機會識別、過度自信）與心理資源（堅韌、樂觀）。必須如實說明：「佛教創業心理學」尚屬邊緣課題，系統研究很少，現有文獻主要沿三條路徑展開：（一）正念與創業心理資本——2010年代起，創業研究期刊開始發表正念訓練對創業者壓力、倦怠與決策的研究，顯示正念提高不確定性容忍並降低抑鬱風險；（二）佛教價值觀下的社會創業——「佛教社會企業」（如斯里蘭卡Sarvodaya運動，1958年由阿里亞拉特內創立，成為全球最大的佛教社區發展組織）為創業動機研究提供了「以利他為核心」的樣本；（三）經濟思想史層面——E.F.舒馬赫《小即是美》（1973年）中的「佛教經濟學」一章，把佛教「正命」與「簡樸」轉化為可持續創業的理論資源，影響了此後的倫理創業與「合乎正命」商業運動。

## 二、核心議題與佛教觀點

核心議題包括：（一）風險與執著——創業心理學發現「適度過度自信」是創業者的適應性偏誤，但過度則致災難；佛教「精進而不執果」提供了精確的調節配方：全力行動（因上努力）而於成敗保持捨心（果上隨緣），以防止失敗導致的抑鬱與成功導致的膨脹；（二）失敗與重啟——創業失敗率高，「失敗羞恥」是再創業的最大障礙；佛教業果觀把失敗還原為因緣組合的結果而非人格判決，配合無常觀構成心理韌性訓練；（三）機會識別與緣起——機會由市場、技術、時機等因緣聚合而生，佛教緣起思維訓練對「條件變化敏感」，與機會警覺性研究相通；（四）利他動機與可持續——社會創業研究證實利他使命提升團隊凝聚力與抗逆力，佛教菩薩道即利他創業的古典理想形態。《四十二章經》「一人與萬人戰」是本專題最切題的經典。

> **經典依據**：
> 「夫為道者，譬如一人與萬人戰……沙門學道，應當堅持其心，精進勇銳，不畏前境。」——《四十二章經》（T784）

佛陀以「一人與萬人戰」喻修道者面對煩惱大軍：或怯弱而退，或格鬥而亡，或得勝而還——創業者面對市場、資金、競爭的萬重困難，所需要者正是此「堅持其心、精進勇銳、不畏前境」的心理素質，而佛教進一步指出：勝敗之後心不失衡，方為究竟。

## 三、代表學者與實踐

阿里亞拉特內創立的Sarvodaya運動以佛教「人人覺醒」理念組織斯里蘭卡上萬村莊的自助發展，被視為佛教社會創業的世界級案例，也是經濟學與人類學的長期研究對象。舒馬赫（曾任英國國家煤炭局經濟顧問）在《小即是美》中以「佛教經濟學」提出：經濟的目的在於解脫式的富足而非消費最大化，工作本身是人格成長的手段——這一章成為倫理創業文獻引用率最高的文本之一。實證研究方面，學者對創業者正念干預的初步對照試驗（如對孵化器初創者的八周課程）顯示焦慮與倦怠下降、睡眠改善；對「佛教企業家」（如泰國佛教企業群體）的質性研究亦顯示其經營哲學中「正命」「少欲」與商業成功可並存。中國大陸與台灣學者對「佛系青年」創業觀的研究，則揭示了佛教資源在當代華人創業文化中的兩面性。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 創業韌性 | 創業者從逆境中恢復並持續前進的能力 |
| 模糊容忍度 | 對不確定情境的心理承受能力 |
| 社會創業 | 以商業手段解決社會問題的創業形態 |
| 正命 | 八正道之一，合乎倫理的謀生與經營 |
| 果上隨緣 | 佛教態度：於結果保持開放與接納 |
| 菩薩道 | 自利利他的大乘修行理想，利他創業原型 |
