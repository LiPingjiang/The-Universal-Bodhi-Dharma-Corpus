# 異部宗輪論 — 学术解读

## 一、文献背景与成书

《異部宗輪論》（Samayabhedoparacanacakra），T2031，全一卷，印度世友（Vasumitra，约公元一、二世纪顷）撰，唐玄奘于龙朔二年（662）译出，收《大正藏》第四十九册。「异部」指部派各异，「宗轮」谓各部宗旨互异、如轮转不定。本论以说一切有部教义为基础，以偈颂与长行叙述佛灭百余年后二十部派产生之经过及教义异同。异译本有真谛译《十八部论》（或疑为鸠摩罗什译）及《部執異論》各一卷；注释书有窥基《異部宗輪論述記》。本论与南传《島史》《大史》系统构成部派分裂史的两大对立叙事，是部派佛教研究的必读文献。

## 二、文本结构与核心思想

本论的叙事骨架为「根本分裂—枝末分裂」两段式。

其一，**根本分裂（大天五事）**。佛灭百余年，阿育王时代，「佛法大眾初破」——因四众（龙象众、边鄙众、多闻众、大德众）共议大天五事而分为大众、上座两部。五事偈曰：「餘所誘無知，猶豫他令入，道因聲故起，是名真佛教」——主张阿罗汉仍受魔诱、仍有无知与犹豫、须他人印证、圣道因声现起。这一「贬抑阿罗汉」的提案成为分裂的导火索。

其二，**大众部枝末分裂**。第二百年间，大众部流出一说部、说出世部、鸡胤部、多闻部、说假部；第二百年满时，另一大天（制多山大天）重议五事，又分出制多山部、西山住部、北山住部——本末合九部。

其三，**上座部枝末分裂**。上座部「一味和合」至第三百年初，分出说一切有部（亦名说因部）与雪山部；有部又流出犊子部（再分法上、贤胄、正量、密林山四部）、化地部（再出法藏部）等——本末合十一部。大众、上座二部本末合计二十部。

论首归敬颂交代了方法论自觉：「應審觀佛教，聖諦說為依，如採沙中金，擇取其真實」——以审慎拣择的态度面对分裂后的多元。

## 三、学术研究价值与争议

研究价值：本论是北传（有部立场）部派谱系的唯一系统叙述，与锡兰《島史》《大史》及《舍利弗問經》等谱系对勘，可重建部派分化史；大天五事所涉阿罗汉圣格问题，是理解大众部「佛身观抬升、阿罗汉贬抑」思想走向的枢纽；窥基《述記》保存了大量唐代注疏层信息。

争议问题：其一，本论谱系与南传谱系严重冲突——南传称根本分裂起于毗舍离十事（律制问题），本论归于大天五事（义理问题），两说是否为两次不同事件、孰先孰后，是部派史最大悬案；其二，世友的作者身份与年代（有部内另有《品類足論》之世友），是否同为一人尚有疑问；其三，本论以有部立场书写，对异部（尤其犊子部「有我」说）的转述是否公允，需以他系文献校正。Lamotte、平川彰及印顺等对此均有系统讨论。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 异部宗轮 | 部派宗旨互异如轮转之谓 |
| 大天五事 | 贬抑阿罗汉的五个命题，分裂导火索 |
| 根本／枝末分裂 | 首次二分为根本，其后诸分为枝末 |
| 说因部 | 说一切有部的别名 |
| 雪山部 | 上座部本部的转名 |
| 二十部 | 大众九部加上座十一部之总数 |
