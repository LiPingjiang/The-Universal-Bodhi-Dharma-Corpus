# 佛祖历代通载 — 学术解读

## 一、文献背景与成书

《佛祖历代通载》，二十二卷（明北藏作三十六卷），简称《佛祖通载》，元代临济宗沙门念常（1282—？）撰，成书于至正元年（1341），至正四年（1344）付梓，收于《大正藏》第四十九册（T2036）。卷首有虞集序、觉岸序及凡例目录。

念常，俗姓黄，号梅屋，华亭（今上海松江）人，为临济宗僧。本书为编年体佛教通史：卷一载过去七佛偈及元帝师八思巴《彰所知论》器世界品、情世界品等，从宇宙生成论开始展开佛教史叙事；卷二起自盘古、三皇五帝，引入中国历史脉络；卷三至卷八起自周昭王至南朝齐，兼载释尊及西天二十七祖事迹；卷九至卷二十二起自梁武帝迄元顺帝即位（元统元年，1333），广记译经、撰述、传教、佛道关系及帝王兴废佛教之事。

本书的编纂特点是：以禅宗为正统，前数卷二十八祖悉抄《景德传灯录》，自汉明帝至五代十余卷多抄祖琇《隆兴佛教编年通论》，卷十八以后宋元纪事为念常自撰，于禅宗诸师记叙尤详，并保存大量碑铭诏制。

## 二、文本结构与核心思想

全书以干支纪年为主轴，附注帝王年号，时间跨度从宇宙生成到元顺帝时期。其思想倾向可归纳为：

**禅宗正统观**。念常以临济宗僧的身份编纂佛教通史，在祖统编排上以禅宗"西天二十八祖"和"东土六祖"为正脉，与天台宗志磐《佛祖统纪》以天台宗为正统的史观形成鲜明对照。这种"禅宗中心"的佛教史叙事，是元代禅宗在佛教各宗中地位上升的反映。

**融合藏传佛教**。本书卷一收录八思巴《彰所知论》，将藏传佛教的宇宙观（器世界、情世界）纳入佛教史的框架，是汉传佛教编年史中罕见的做法。这与元代藏传佛教受皇室尊崇的时代背景密切相关。

**保存史料**。卷十八以后宋元部分的纪事，为念常自撰，保存了大量宋代禅宗史料和元代佛教碑铭、诏制、塔铭等，许多史料为他书所无，具有极高的文献价值。

## 三、学术研究价值与争议

**研究价值**：本书是研究元代佛教史、禅宗史、宋元佛教关系的重要文献。其保存的宋元时期碑铭、塔铭、诏制等，是研究元代佛教制度、僧官体系、寺院经济的珍贵资料。念常以禅宗为中心的编纂立场，与志磐以天台宗为中心的《佛祖统纪》、觉岸以编年为主的《释氏稽古略》形成互补，共同构成了元代佛教史学的多元图景。

**代表学者**：念常为作者；祖琇《隆兴佛教编年通论》为本书重要史源；道原《景德传灯录》为本书二十八祖部分的来源；陈垣《中国佛教史籍概论》卷六有专章论本书，系统指摘其纪年讹误。

**争议问题**：其一，纪年准确性——陈垣指出本书存在多处纪年错误，如将佛陀生年定在周昭王时期等，与学术共识差距较大，使用时应谨慎；其二，本书大量抄录前代文献，在史料处理上有所取舍，是否忠实于原文，需要校勘；其三，念常以禅宗为正统的立场，是否影响了对其他宗派的公正记载，值得讨论。

## 四、术语对照表

| 术语 | 释义 |
|------|------|
| 编年体 | 以时间顺序记录历史事件的史书体裁 |
| 七佛偈 | 过去七佛各自所说的偈颂，为禅宗传承之始 |
| 西天二十八祖 | 从大迦叶到菩提达摩的印度二十八位祖师 |
| 器世界／情世界 | 八思巴《彰所知论》中的宇宙分类，器世界为物质环境，情世界为众生 |
| 碑铭诏制 | 碑文、铭文、诏书、制诰等官方文书，为佛教史重要史料 |



### 拓展视域

从更广阔的思想史视野来看，此文献的意义不仅限于佛教内部。它与中国本土的儒道思想之间存在着复杂的互动关系——既有竞争、辩论，也有吸收与转化。同时，此文献的解读也需放在汉传佛教与藏传佛教、南传佛教相互参照的框架中，方能获得更全面的理解。现代学者在诠解此文时，逐渐从传统的宗派立场转向客观的学术研究，注重文献学、思想史与社会史的多维视角，为这一佛教经典注入了新的学术生命力。
