# 释量论 — 学术解读

## 一、文献背景与成书

《释量论》（Pramāṇavārttika）是印度佛教因明学最高峰的著作，作者法称（Dharmakīrti，约600-660年），约成书于7世纪。据传法称曾在那烂陀寺学习，生活于佛教哲学面临正理派、弥曼差派等婆罗门教学派激烈智识竞争的时代，《释量论》正是在这一环境中将佛教认识论武装到最高水平的产物。

书名中的 Vārttika 是一种特殊的注释体裁——不仅解释原文，更批判性地补充、修正和扩展原论，要求"说未说、正已说、重已说"。法称以陈那《集量论》为底本，但绝非亦步亦趋的逐句解释，而是一次创造性的、超越原著的哲学重构。梵文原本大部分保存，20世纪经罗睺罗·桑克里提亚延在西藏寺院发现的贝叶写本照片为基础，由宫坂宥胜、Raniero Gnoli 等学者校勘出版。完整藏译收入德格版丹珠尔（Toh.4210），是藏传佛教五部大论学习体系的核心经典；历史上无完整汉译，现代有法尊法师等从藏文转译的部分。英译有 Tom Tillemans 所译第二品部分与 John Dunne 2004年的研究性专著。

## 二、文本结构与核心思想

全论以偈颂（kārikā）形式写就，附法称自注（仅第一品存世），分四品：

1. **为自比量品**：论述获得确定知识的推理方法，阐明因三相、自性因与果性因的区分，以及"不可得因"。
2. **成量品**：论证佛陀是"量士夫"（pramāṇapuruṣa）——可靠的认知权威。法称论证佛陀的权威不来自神通或信仰，而来自其通过修行获得的无误认知能力。此品兼含伦理学、修道论与宗教哲学，是全论最具佛教宗教性的部分。
3. **现量品**：发展陈那"现量离分别"命题，详论错觉、梦境等特殊认知现象。
4. **为他比量品**：论说服他人的论式、辩论规则与谬误。

核心思想包括：

- **自相与共相的严格二分**：只有刹那生灭的独一自相才是真实存在，共相仅是概念构造；只有把握自相的认知才能引导成功行动（arthakriyā）。
- **因果效力作为实在性判准**：能产生因果效力者才是真实存在——这成为后世佛教哲学判定实在性的核心原则。
- **佛陀作为"量"的证成**：佛陀在可检验领域（如苦谛、集谛）所说被证明为真，故在不可直接检验的领域（如业果细节）也值得信赖——一种经验主义式的宗教哲学论证。
- **否定式推理**（anupalabdhi）：系统解释如何通过"没有观察到X"而获得"X不存在"的可靠知识。

## 三、学术研究价值与争议

《释量论》是国际佛学界与比较哲学界研究最密集的文献之一。维也纳学派（Ernst Steinkellner、Helmut Krasser 等）在梵文校勘和哲学分析上贡献卓著；日本学者户崎宏正等长期致力于梵藏对勘；Tillemans、Dunne、Birgit Kellner 等从分析哲学视角研究法称的论证。藏传佛教中，萨迦班智达《量理宝藏》与宗喀巴的相关著作都是本论的传统诠释。

主要争议包括：（1）法称对自证分立场的演变——早期论书（《释量论》）承认自证，后期（《成他相续论》等）有修正迹象，学界对"法称是否放弃了自证"长期论战；（2）对"除遮诠外词语如何指称个别物"的技术性争论；（3）成量品的宗教论证是否成立——法称对佛陀可靠性的归纳式论证，在现代宗教哲学中仍被反复检讨。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 量士夫（pramāṇapuruṣa） | 具有可靠认知能力者，指佛陀 |
| 自性因（svabhāvahetu） | 以本质关联成立的推理理由 |
| 果性因（kāryahetu） | 以因果关联成立的推理理由 |
| 不可得（anupalabdhi） | 通过未观察到而成立"不存在"的推理 |
| 因果效力（arthakriyā） | 判定实在性的标准：能产生实际效果者方为真实 |
| 遮诠（apoha） | 语词排除异类而表义的语义理论 |
