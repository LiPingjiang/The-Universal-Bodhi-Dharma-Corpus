# 佛教知识论 — 学术解读

## 一、文献背景与成书

佛教知识论（Buddhist Epistemology），即佛教量论（pramāṇa-vāda），是研究佛教对知识来源、结构与有效性之理论的综述性专题条目。据本库原文档的叙述，其历史脉络为：印度佛教从早期经典中现见（直接经验）与比知（推理）的区分出发，发展出成熟的量论体系——陈那（约五六世纪）著《集量论》，将量收摄为现量（直接知觉）与比量（推理）两种，并以因三相重构推理规则；法称（七世纪）著《释量论》七卷，细化量论的认知心理学与实在论基础。

汉传线索方面，玄奘汉译《因明入正理论》《正理门论》，使因明传入中土并经窥基《因明入正理论疏》发扬；二十世纪法尊法师译出《释量论》，汉藏量论交流重启。国际线索方面，维也纳学派斯坦凯尔纳主持法称文献校勘，蒂勒曼斯、邓恩《法称哲学的基础》（2004）等将量论引入分析知识论对话——原文档据此评价：佛教知识论被视为与西方认识论并立的高度精致的传统。库中另有 `04872_佛教認識論` 等同名姊妹专题，本条目专就本目录原文档立论。

## 二、文本结构与核心思想

原文档五分结构的义理部分归纳为四项议题。

其一，量的种类。佛护、月称一系坚持现比二量，而正理派等主张多量——量的数目之争背后是知识来源的哲学分歧。其二，现量的性质。陈那现量离分别原则：直接知觉不受概念建构染污，知觉与思维的功能分工构成佛教认知科学的雏形。其三，比量与因三相。遍是宗法性、同品定有性、异品遍无性三条标准，使推理成为可检验的形式规则。其四，圣言量的地位。佛教将权威经证收摄于比量框架，理性与信仰的关系由此得到独特安排——这是量论区别于一般知识论的最显著特征。

总立场方面，原文档概括为：知识为解脱服务，遍计所执的谬误知识正是苦因之一，故须以量论甄别真妄，最终由现观证真实。经典依据取陈那《因明正理门论》现量离分别一语与法尊译《释量论》释成量品意旨。

## 三、学术研究价值与争议

活态传承是本条目的一大特色：格鲁派三大寺以辩经制度活态传承量论，击掌问难的辩经至今仍是世界上最具生命力的逻辑教育实践之一——这使量论不单是文献研究对象，也是可进行教育人类学观察的现行制度。

争议有二。其一，圣言量的收摄问题：把权威经证归入比量框架，意味着经证须通过推理的检验方为知识来源，这一安排究竟是理性的胜利，还是以重新定义的方式保留了信仰的特权，学界解读分歧甚大。其二，现量离分别的哲学疑难：若直接知觉完全脱离概念，无概念的知觉如何能为概念思维提供内容，这一知觉与概念的界面问题至今是与当代心灵哲学对话的核心场域。另外，近代杨文会自日本迎回因明典籍、吕澂与熊十力复兴汉传因明研究的谱系，也为量论在现代汉语学界的重建提供了制度史案例。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 量（pramāṇa） | 认识的正确来源，即有效知识的凭借 |
| 现量 | 离分别的直接知觉 |
| 比量 | 依因三相而起的推理知识 |
| 因三相 | 宗法、同品有、异品无三条有效因的标准 |
| 自证 | 心识对自身认知活动的内在觉知 |
| 圣言量 | 以佛说为准的权威认识来源 |
