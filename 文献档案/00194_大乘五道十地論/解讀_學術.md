# 大乘五道十地论 — 学术解读

## 一、文献背景与成书

《大乘五道十地论》是一部从唯识学立场阐明大乘修道次第的论书。依本档案索引卡所记，此论题为安慧（Sthiramati，约6世纪）所造，唐地婆诃罗（Divākara）于7世纪汉译；其主题——五道与十地的配摄——则属印度大乘共通的修道论框架。安慧是唯识十大论师之一，以《唯识三十颂释》《大乘阿毗达磨杂集论》的糅释闻名；本论正是他以瑜伽行派的立场，把「从凡夫到成佛要走哪些台阶」这一修行地图系统化的尝试。

需要说明的是，本论在汉传经录中流传不广，相关译本信息历来记载简略，学界对其文本源流的讨论远不如《俱舍论》《成唯识论》充分；因此解读时以论中所呈现的修道次第义理为主要依据，作者与译者的归属则宜持审慎态度。

## 二、文本结构与核心思想

### 2.1 五道十地的配摄结构

本论开宗明义，将大乘修证次第归纳为「五道」与「十地」两个坐标系的叠合：

- **五道**：资粮道、加行道、见道、修道、无学道——这是纵贯的修行进程。
- **十地**：欢喜、离垢、发光、焰慧、难胜、现前、远行、不动、善慧、法云——这是菩萨圣位的十个阶次。

二者的配摄关系是全论的枢纽：资粮、加行二道属于「地前」（初地之前的凡夫菩萨位）；见道即初欢喜地——初次直接证见法性；修道贯通二地至十地；无学道即是佛地。论中所谓「地道相摄，修證之圖乃全」，正是说唯有把横向的道与纵向的地交叉定位，修证的全图才完整。

### 2.2 各地的名义

论中解释地名多取「证德立名」的原则：初地名欢喜，因为初次证得法性、心生大欢喜；十地名法云，因为智慧如大云普遍覆盖法界、能降法雨。中间八地——离垢（戒行清净）、发光（智慧光显）、焰慧（慧焰增盛）、难胜（难可超越世智）、现前（般若现前）、远行（已至无相功用边际）、不动（无相无功用任运不退）、善慧（具四无碍辩）——层层递进，构成一条从「初证」到「圆满」的成佛路线。

### 2.3 思想史脉络

五道框架源自部派阿毗达磨的修道论（如《俱舍论·贤圣品》的四道说），大乘将其扩展为五道；十地思想则见于《华严经·十地品》《般若经》等大乘经。本论的特色在于以唯识立场统摄二者，把「转识成智」的唯识修行论安立在传统的地道次第之上，是研究瑜伽行派修道论不可绕过的一环，也直接影响了后来藏传佛教「五道十地」的通行判摄。

## 三、学术研究价值与争议

**研究价值**：其一，本论是考察「五道十地」这一印度大乘修道论定型过程的标本，可与《现观庄严论》《俱舍论》对读，观察修道次第学说从部派到大乘、从中观到唯识的演变。其二，它体现了唯识学「境、行、果」体系中「行」与「果」部分的组织方式，与偏重「境」的诸论（如《杂集论》法相部分）互为补充。

**争议问题**：一是文本归属问题——安慧著述宏富，但本论的译者与译年记载单薄，是否存在完整汉译本、所据梵本如何，尚待经录与梵藏文献的进一步比对；二是「见道即初地」的判摄，与《成唯识论》系统一致，但与部分如来藏系文献「初住即证」的立场不同，反映了修道论内部「证入位次」的分歧。

|---|---|
| 五道（Pañcamārga） | 资粮、加行、见、修、无学五阶修行进程 |
| 十地（Daśabhūmi） | 欢喜至法云的十菩萨圣位 |
| 见道（Darśanamārga） | 初次无分别智证法性，即初欢喜地 |
| 资粮道（Saṃbhāramārga） | 积集福慧资粮的地前阶段 |
| 法云地 | 第十地，智慧如云普覆法界，将证佛果 |
| 无学道（Aśaikṣamārga） | 修学已满的究竟位，即佛地 |
