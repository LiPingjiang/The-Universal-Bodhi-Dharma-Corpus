# 佛教環境心理學 — 学术解读

## 一、文献背景与成书

本条目是档案库「佛教与心理学」系列中的综述性主题条目（库内编号04938），并非一部古代文献，而是对一个现代交叉研究领域的知识盘点。环境心理学本身研究人与物理环境的交互作用——地方依恋、环境态度、拥挤、噪声、生态行为；佛教环境心理学则追问两个问题：佛教的缘起论与依正不二思想能否为生态心理学提供世界观基础？佛教修行能否缓解生态焦虑、促进亲环境行为？

该领域的成形有一条清晰的人物线索。枢轴人物是乔安娜·梅西（1929— ）：她师承一般系统论创始人贝塔朗菲，同时长期修行佛法，兼具系统论者、佛教学者与社会活动家三重身份。1991年她出版《世界如情人，世界如自己》，把佛教无我与缘起扩展为「生态自我认同」理论；2012年与克里斯·约翰斯通合著《积极希望》，发展出「绝望与赋权工作坊」，直面气候时代人类的心理防御与行动瘫痪。与之呼应的还有一行禅师以「相即共生」为核心概念的生态伦理阐发，以及泰国自1990年代起的「林僧」为濒危树木披袈裟授戒运动。本系列相邻条目各有分工：`04940_佛教消費心理學` 处理物质欲望端，`04931_佛教社會心理學` 处理群体机制，本条目专注人与自然的关系维度。

## 二、文本结构与核心思想

作为综述条目，其原文文档按学科概述、核心议题、代表学者与术语表的体例组织，核心议题可归为四组，恰好构成一个从世界观到行动的完整链条。

第一组是世界观层：生态自我。环境心理学发现自然经验提升幸福感与亲环境态度，佛教「无我」提供了更激进的论证——既然自我本是关系性存在，自我边界本属虚构，则伤害自然即是伤害自身。梅西称之为「生态无我」，其学理根核是「依正不二」：依报即环境，正报即身心，二者不可分离，这是佛教把环境问题与心灵问题打通的本体论命题。

第二组是情绪层：生态焦虑与气候悲伤。对气候灾难的慢性恐惧与丧失感已成新兴临床议题；佛教的无常观与共修仪式（如梅西设计的「真相曼陀罗」情绪表达练习）为哀伤处理提供了仪式化容器。

第三组是动机层：物质主义批判。卡瑟的研究表明高物质主义与低幸福感、高生态足迹并存，佛教少欲知足构成替代价值坐标。

第四组是行动层：实践案例。泰国生态佛教僧人为濒危树木披袈裟阻止砍伐，被国际学界当作「规范激活」的经典田野；藏传领袖与科学家的生态对话、欧美生态佛教网络的寺院节能实践，共同构成研究与行动并进的图景。贯穿四组的总纲是《维摩诘经》（T475）名句：「隨其心淨，則佛土淨」——净土始于净心，而心的转化必须显现为国土的转化。

## 三、学术研究价值与争议

价值方面：其一，它示范了宗教资源与实证科学的中层对接——不空谈「佛教生态智慧」，而是落实到可测量的态度变量（地方依恋、生态自我认同）与可观察的行为（碳足迹、亲环境行为）。其二，梅西的「大转向」框架把生态危机定义为文明转型期，并以佛教行愿精神设计心理赋权工具，影响了整整一代气候行动者，是「宗教心理学技术化」的成功案例。其三，泰国树木授戒运动为「宗教—环境行为」研究提供了罕见的自然实验场。

争议方面：其一，「依正不二」究竟是生态伦理还是后世诠释的追认——有学者指出佛教原典的「依报」概念属于业报论语境，直接转译为现代生态学命题需要论证环节，不能一蹴而就。其二，生态焦虑的佛教式干预目前证据规模仍小，仪式化练习（真相曼陀罗等）缺乏严格对照试验，其效果陈述多出于工作坊报告。其三，佛教国家同样出现环境退化，说明教义与行为之间存在巨大的制度与社会中介，「有佛教处即有生态」的浪漫化想象需要田野证据来矫正。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 依正不二 | 佛教命题：环境（依报）与身心（正报）不可分离 |
| 生态无我 | 梅西术语：以缘起无我重构自我与自然的连续性 |
| 相即共生 | 一行禅师对缘起的现代表述，万物互即互入 |
| 地方依恋 | 人对特定地方的积极情感联结 |
| 生态焦虑 | 对环境危机的慢性忧虑，新兴临床议题 |
| 规范激活 | 亲社会（亲环境）行为被道德规范唤起的机制 |
| 无常（anicca） | 诸行迁流不住，佛教对变化的根本确认 |
