# 佛教人格心理學 · 原文

## 一、學科概述

佛教人格心理學研究佛教「無我」思想與西方人格理論——特質論（五大人格）、精神分析人格結構、人本主義自我實現——之間的緊張與對話。西方人格心理學預設存在相對穩定的「人格實體」；佛教則以五蘊（色、受、想、行、識）分解「人」為剎那生滅的過程聚合，並以「諸法無我」直接否定任何恆常不變的自我核心。這一根本分歧恰恰構成富於生產力的研究問題：如果人格是「習氣」（vāsanā）的穩定模式而非不變實體，那麼人格就是可訓練的——禪修文獻報告的特質改變（神經質下降、宜人性提升）正為此提供實證。羅伯特·克倫寧格開發的「氣質與性格量表」（TCI）將「自我超越」列為人格維度，是人格測量吸收佛教資源的標誌性嘗試。

## 二、核心議題與佛教觀點

核心議題包括：（一）無我對人格實體概念的質疑——《雜阿含經》的非我論證（若五蘊是我，則不應於色生病苦、不應「欲令如是、不令如是」）可直譯為現代語言：可被條件改變者即非自主的實體，而一切心理特質皆隨因緣變動；（二）過程人格觀——佛教視「人格」為業力與習氣的動態平衡，與米歇爾與祥田（Yuichi Shoda）的「認知情感人格系統」（CAPS）理論相通：人格是心理動力系統在情境中湧現的穩定模式，而非靜態實體；（三）人格改變的證據——縱貫研究顯示長期禪修者在大五人格的神經質維度下降、自覺性上升；正念干預的薈萃分析亦支持特質性改變；（四）理想人格模型——佛教的阿羅漢與菩薩即古典的「成熟人格」畫像：煩惱輕、慈悲廣、於境自在，可與馬斯洛自我實現者、榮格自性化者並列比較研究。

> **經典依據**：
> 「色非是我。若色是我者，不應於色病、苦生，亦不應於色欲令如是、不令如是。以色無我故，於色有病、有苦生，亦得於色欲令如是、不令如是。」——《雜阿含經》（T99）

非我論證的要義：凡不能自主、必受條件改變者，皆非「我」。人格特質正是這樣的存在——穩定卻非恆常，一致卻可轉化，故佛教把「人格」從名詞還原為動詞：一組可以被觀察、被訓練的心行過程。

## 三、代表學者與實踐

克倫寧格（華盛頓大學聖路易斯）的生物心理社會人格模型及其TCI量表，將「自我超越性」作為可測量的人格維度（與靈性體驗、整體覺知相關），為禪修者的人格研究提供了工具；其與戴維森早期的氣質神經科學研究，亦促成後者轉向情緒風格與禪修研究。實證層面，布里塔·赫爾策爾等以MBSR樣本結合量表與腦成像，追蹤八周訓練前後的特質變化；英國學者與牛津正念中心合作的多項研究亦顯示正念訓練伴隨神經質下降與自我慈悲提升。在理論層面，約翰·恩格勒與馬克·艾普斯坦將精神分析人格理論與佛教無我觀對讀，提出「健康的自我先於無我」的臨床命題，至今仍是人格心理學與佛教對話的理論基石。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 五大人格 | 神經質、外向性、開放性、宜人性、盡責性特質模型 |
| 五蘊 | 色、受、想、行、識，「人格」的佛教過程性分解 |
| 無我（anātman） | 否認恆常自主之我存在的佛教核心教義 |
| 習氣 | 行為與情緒反應的殘留傾向，近於人格的慣性面 |
| 自我超越性 | TCI中指向整體與靈性體驗的人格維度 |
| 阿羅漢 | 斷盡煩惱者，佛教的「理想人格」原型 |
