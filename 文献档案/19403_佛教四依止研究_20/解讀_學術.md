# 佛教四依止研究_20 — 学术解读

## 一、文献背景与成书

本卷为佛教典籍语料库「佛教某某研究」专题辑录系列之一，属现代汇编性专题资料，非古代单行经论。卷首概述存「依義不依語、依智不依識、依了義不依不了義、依法不依人」四目；正文所辑「佛告比丘：有四依止——依法不依人、依義不依語、依智不依識、依了義不依不了義」及「於此四法生決定解，則不為他教所轉，直入大乘正理」两段，未标注所出经论，语句属白话式重述，引证时须回查原典。

就名目而言，「四依」是印度佛教中后期至大乘阶段确立的重要判摄原则，梵语 catvāri pratisaraṇāni，直译「四种依处」。其观念先声可溯至《长部·大般涅槃经》与汉译《长阿含·游行经》的「四大教法」：判断教说真伪，不依说者是谁，而以经律为量。成型的四依则广见于大乘经论：《大般涅槃经》以专品敷演四依，逐门开为多重法义；《大智度论》屡引以释般若；《瑜伽师地论》等亦有所释。四条次第诸典不同，本卷概述以依义居首、佛告语以依法居首，两处互异，今以原文档并列两式为准而注明其序无定本。同库另有同名之卷 `19410_佛教四依止研究_20`，两卷分工：本卷侧重四依的名目成立史与经典源流，彼卷侧重依了义判摄的判教功能与现代诠释，宜对读互补；另 `19404_佛教四依法研究_20` 专释依法一门，亦当参看。

## 二、文本结构与核心思想

本卷结构是「名目—佛语总列—决解结成」的辑录三段式。四门义理可依次申之：依法不依人，以教法为检验标准，不因说法者的威望、身份、情感联结而动摇对法的独立判断；依义不依语，以求取意趣为归，不执著文句的相状，此条为经典翻译与义理诠释立了总则；依智不依识，以现观之智为准，不以分别推度的表浅认识为极则，划出了佛教知识论中智与识的等级；依了义不依不了义，以显了究竟之说为量，把不了义理解为应机权说，此条是四依中最富诠释空间的一门。

结成句「於此四法生決定解，則不為他教所轉」点出四依的功能：它是佛教内部的「认知免疫系统」，令行者在诸说并起的教环境中不为他转、自作依怙；「直入大乘正理」一语则显示本卷所承为大乘立场，四依在大乘文献中被用作由权入实的进路。

## 三、学术研究价值与争议

本卷价值有三：其一，它是讨论佛教经典权威结构的枢纽材料。四依实际上把权威的层级重排为：法高于人、义高于语、智高于识、了义高于不了义，这套层级既是诠释原则，也是判教原则，为观察佛教内部如何自我校准提供了最简明的框架。其二，四依的成立过程是研究早期佛教向大乘过渡的重要线索：从四大教法的「以经律为量」，到四依的「依法义智了义」，权威的判准由文献核对转向义理判摄，这一转变牵动整个部派至大乘的诠释史。其三，本卷概述与引文的两种次第并存，恰可印证诸典四依顺序不一的事实，为文本比较提供了样本。

争议处：其一，「智」与「识」的界划，中观与唯识两大系统标准不同，唯识且自有转识成智之学，四依第三门遂成为两派交锋的常设议题。其二，「了义」的界定即判教之争：以空性为了义、以如来藏为了义、以三性说为了义，诸宗各执，本卷未详，读者可循 `19410_佛教四依止研究_20` 展开。其三，「依法不依人」在近现代被广泛移用于佛教改革论述，与原语境「于说法者不生偏执」的窄义有距离，亦是诠释史的一部分。

## 四、术语对照表

| 梵/巴语 | 汉语 | 英译 |
|---|---|---|
| Catvāri-pratisaraṇāni | 四依止 | four reliances |
| Dharma | 法 | Dharma |
| Artha | 义 | meaning |
| Jñāna | 智 | wisdom |
| Vijñāna | 识 | consciousness |
| Nītārtha | 了义 | definitive meaning |
| Aneyārtha | 不了义 | provisional meaning |

说明：pratisaraṇa 义为「所依、归依处」，四依即四种可靠的知识依怙；Nītārtha 与 Aneyārtha 一对术语是判教理论的枢纽，nīta 义为「已引出、显了」，「不了义」一语诸传本或作 neyārtha（尚待引出者），本卷作 Aneyārtha，从原文档。
