# 觀音玄義

## 一、概述

**大正藏編號**：T1726（《大正新脩大藏經》第 34 冊）

**全稱**：《觀世音菩薩普門品玄義》

**別稱**：《觀音玄義》

**撰者**：隋·智顗（538—597）說，門人灌頂（561—632）記。智者大師俗姓陳，字德安，荊州華容（今湖北監利）人，天台宗實際創立者，被尊為「東土小釋迦」。灌頂，字法總，俗姓吳，章安人，智者大師的首席弟子，天台宗三大部的筆錄者。

**卷數**：二卷（卷上、卷下）

**所釋經品**：《妙法蓮華經》卷七〈觀世音菩薩普門品第二十五〉

《觀音玄義》是天台宗「五小部」之一，與《觀音義疏》（T1727）並稱「觀音二書」。此書並非逐句注解經文，而是在入文之前，以天台宗獨創的「五重玄義」框架，從五個層面系統闡發〈普門品〉的深層義旨。更為獨特的是，智者在「釋名」一門中又別開「十義通釋」——以人法、慈悲、福慧、真應、藥珠、冥顯、權實、本迹、緣了、智斷十個範範疇，圓融貫穿觀世音與普門兩重名號，使觀音菩薩的信仰昇華為圓教的心性哲學。

此書在「十義」中融入「六即」位次判修行階次，並在「緣了」「智斷」二義中展開「三種佛性」（正因、了因、緣因）與「三德」（法身、般若、解脫）的圓融論述，彰顯天台宗「性具」思想特色，是研究天台觀音學與性惡法門的關鍵文獻。

## 二、核心段落

### （一）開篇總敘：法界圓融

**原文（CBETA T34n1726, p.0877a07）：**

> 夫法界圓融，像無所像；真如清淨，化無所化。雖像無所像，無所而不像；化無所化，無所而不化。故無在、無不在，化應九道之身，處有不永寂，入不二之旨，是以三業致請蒙脫苦涯，四弘為誓使霑上樂，故娑婆世界受無畏之名，寶藏佛所稟觀音之目，已成種覺，號正法明，次當補處，稱為普光功德。其本迹若此，寧可測知？方便隨緣，趣舉一名耳。

**白話對照：**

法界圓融無礙，形象而無可形象；真如清淨湛然，化導而無所化導。雖說「無所形象」，卻又無所不形象；雖說「無所化導」，卻又無所不化導。因此無在而無不在——化現九道之身應機度脫，身處有為而不永滞寂滅，契入不二之旨。正因如此，眾生以身口意三業致誠祈請，便能蒙受脫離苦海之恩；菩薩以四弘誓願加持，使眾生霑沐上妙安樂。所以在娑婆世界得「施無畏」之名，在寶藏佛所禀受「觀世音」之號——其實他已成種覺，號正法明如來；次當補處，稱為普光功德山王佛。他的本迹如此深遠，豈可測度？不過是方便隨隨緣，隨舉一名罷了。

### （二）釋名：觀世音

**原文（p.0877a15）：**

> 今言觀世音者，西土正音名阿耶婆婁吉低輸，此言觀世音。能、所圓融，有、無兼暢，照窮正性，察其本末，故稱觀也。世音者，是所觀之境也。萬像流動，隔別不同，類音殊唱，俱蒙離苦，菩薩弘慈，一時普救，皆令解脫，故曰觀世音。此即境智雙舉，能所合標。

**白話對照：**

如今所說的「觀世音」，西土正音稱為阿耶婆婁吉低輸（Aryāvalokiteśvara），此土譯為「觀世音」。「觀」者，能觀所觀圓融，有無兼暢，照窮法性正體，察其本末始終，所以稱為「觀」。「世音」者，即所觀之境——萬象流動、隔別不同，各類音聲殊異唱求，俱蒙菩薩使之離苦。菩薩以弘大慈悲，一時普救，皆令解脫，所以稱為「觀世音」。這便是「境」與「智」雙舉、「能」與「所」合標。

### （三）五重玄義

**原文（p.0877a24）：**

> 大部既有五章明義，今品例為此釋。五意者：一釋名、二出體、三明宗、四辯用、五教相。

**白話對照：**

《法華》大部既然以五章明義，如今此品也以此為例來解釋。五重意旨是：第一釋名，第二出體，第三明宗，第四辯用，第五教相。

（按：天台宗「五重玄義」是智者大師獨創的解經框架——釋名解釋經題，出體辨明經之體性，明宗闡明宗旨，辯用論述功用，教相判釋教法地位。此框架見於《法華玄義》《維摩經玄疏》《金光明經玄義》《觀音玄義》等天台重要著作。）

### （四）十義通釋：列名

**原文（p.0877b05）：**

> 十義者，一人法、二慈悲、三福慧、四真應、五藥珠、六冥顯、七權實、八本迹、九緣了、十智斷。

**白話對照：**

十義是：第一人法，第二慈悲，第三福慧，第四真應，第五藥珠，第六冥顯，第七權實，第八本迹，第九緣了，第十智斷。

### （五）十義之第一：人法

**原文（p.0878c02）：**

> 人即假名所成之人也，法即五陰能成之法，此之人法通於凡聖。若色、受、想、行、識是凡鄙法，攬此法能成生死之人；戒、定、慧、解脫、解脫知見是出世法，攬此成出世聖人。故《大論》云「眾生無上者，佛是；法無上者，涅槃是。」

**白話對照：**

「人」即假名所成之人，「法」即五陰能成之法。此人法通於凡聖——若以色受想行識為凡鄙之法，攬此法便能成生死之人；若以戒定慧解脫解脫知見為出世之法，攬此法便成出世聖人。所以《大智度論》說「眾生無上者是佛，法無上者是涅槃」。

### （六）十義之第二：慈悲——圓教無緣慈悲

**原文（p.0879b13）：**

> 圓教觀法界圓融，本非違、非順，非明、非闇。無明闇故則違，違之則有苦集因果；智慧明故則順，順之則有道滅因果，緣此違順因果而起慈悲。譬如磁石不作心想，任運吸鐵，今此慈悲不作眾生及以法想，任運拔苦與樂，故名無緣慈悲也。

**白話對照：**

圓教觀法界圓融，本來非違非順、非明非闇。因為無明暗蔽所以違背，違背便有苦集的因果；因為智慧明照所以隨順，隨順便有道滅的因果。緣此違順的因果而起慈悲——譬如磁石並不作「我要吸鐵」的心想，卻任運自然地吸附鐵器；如今這種慈悲也不作「有眾生可度」「有法可修」的想法，卻任運自然地拔苦與樂，所以稱為「無緣慈悲」。

### （七）十義之第九：緣了——三種佛性

**原文（p.0880b17）：**

> 了是顯發，緣是資助，資助於了，顯發法身。了者，即是般若觀智，亦名慧行正道，智慧莊嚴。緣者，即是解脫，行行助道，福德莊嚴。《大論》云：「一人能耘，一人能種。」種喻於緣，耘喻於了，通論教教皆具緣了義，今正明圓教二種莊嚴之因，佛具二種莊嚴之果，原此因果根本即是性德緣了也，此之性德本自有之，非適今也。

**白話對照：**

「了」是顯發，「緣」是資助——資助於「了」，顯發法身。「了」即是般若觀智，也稱慧行正道、智慧莊嚴；「緣」即是解脫，行行助道、福德莊嚴。《大智度論》說「一人能耘草，一人能播種」——播種比喻緣因，耘草比喻了因。通論各教皆具緣了之義，如今正明圓教二種莊嚴之因，佛則具二種莊嚴之果。推原此因果的根本，即是性德中的緣了——這種性德本來自有，不是現在才有的。

### （八）十義之第十：智斷——三德圓融

**原文（p.0880c04）：**

> 法身滿足即是非因非果正因滿，故云「隱名如來藏，顯名法身。」雖非是因而名為正因，雖非是果而名為法身。又云「是因非果名為佛性」者，此據性德緣了，皆名為因也。又云「是果非因名佛性」者，此據修德緣了皆滿，了轉名般若，緣轉名解脫，亦名菩提果，亦名大涅槃果果，皆稱為果也。佛性通於因果，不縱不橫性德時三因，不縱不橫果滿時名三德。

**白話對照：**

法身滿足，即是非因非果的「正因」滿足，所以經云「隱藏時名為如來藏，顯現時名為法身」——雖非是因而名為正因，雖非是果而名為法身。經又說「是因非果名為佛性」，這是就性德中的緣了而言，都名為「因」；經又說「是果非因名為佛性」，這是就修德中緣了皆已滿足而言——了因轉名為般若，緣因轉名為解脫，也名為菩提果，也名為大涅槃果果，都稱為「果」。佛性通貫因果——性德之時為三因（正因、了因、緣因），不縱不橫；果滿之時為三德（法身、般若、解脫），亦不縱不橫。

## 三、名句

1. **「夫法界圓融，像無所像；真如清淨，化無所化。」**——開篇總敘，以「圓融」與「清淨」統攝全篇，揭示觀音菩薩「無相而無不相、無化而無不化」的法界境界。

2. **「譬如磁石不作心想，任運吸鐵，今此慈悲不作眾生及以法想，任運拔苦與樂，故名無緣慈悲也。」**——以磁石吸鐵為喻，闡明天台圓教「無緣慈悲」的精義：不存眾生相、不存法相，任運度生，此為天台性具思想在慈悲論上的最精練表達。

## 四、術語表

| 術語 | 釋義 |
|------|------|
| 五重玄義 | 天台宗解經框架：釋名、出體、明宗、辯用、教相，智者大師所創，見於《法華玄義》《觀音玄義》等 |
| 十義通釋 | 《觀音玄義》特有的詮釋方法，以人法、慈悲、福慧、真應、藥珠、冥顯、權實、本迹、緣了、智斷十義貫通觀世音與普門二名 |
| 無緣慈悲 | 不緣眾生相、不緣法相的慈悲，如磁石任運吸鐵，是圓教最高層次的慈悲 |
| 六即 | 天台宗判修行位次：理即、名字即、觀行即、相似即、分證即、究竟即 |
| 三種佛性 | 正因佛性（非因非果，法身）、了因佛性（般若智慧）、緣因佛性（解脫福德） |
| 三德 | 法身、般若、解脫，對應三因佛性的果滿狀態，不縱不橫 |
| 性德 | 本來具有的德性，非修習而得，天台宗「性具」思想的核心概念 |
| 普門 | 「普」是遍義，「門」是能通，以一實相開十普門，無所障閡 |
| 本迹 | 「本」為實得之法身，「迹」為應現之化身；法華本迹二門之義 |
| 真應 | 「真身」即契證實相不偽不動之法身，「應身」即稱機應現之化身 |
