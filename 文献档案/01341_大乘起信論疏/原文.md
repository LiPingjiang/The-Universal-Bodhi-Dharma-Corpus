# 大乘起信論疏

## 一、概述

**大正藏編號**：T1844（《大正新脩大藏經》第 44 冊）

**撰者**：唐·法藏（643—712），賢首大師，華嚴宗三祖

**所釋論本**：《大乘起信論》一卷，相傳馬鳴菩薩造，梁·真諦（Paramārtha）譯

### 關於書名與版本的重要說明

《大乘起信論疏》與《大乘起信論義記》（T1846）**實為法藏同一部著作的兩個題名**。據《佛學大辭典》「大乘起信論義記」條：此書「凡三卷。唐代法藏撰。又稱大乘起信論疏、起信論義記、藏疏、賢首疏」。二本開卷序文同作「夫真心寥廓，絕言象於筌蹄」，開章同為十門，內容一致。

「大乘起信論疏」一名在文獻上另有三種所指，須加辨別：

1. **法藏《義記》的異名**（即本篇所述，T1844）。
2. **宗密《大乘起信論疏》四卷**：法藏述、宗密注，係宗密摘錄法藏《義記》並增入己說而成，添削較多，歷來有「以鍮換金」之譏。
3. **新羅元曉《大乘起信論疏》二卷**（T1845）：又稱《海東疏》，與法藏《義記》、慧遠《義疏》並稱「起信論三疏」。

本篇即以法藏 T1844 本為據，側重於其**判教立場與十門懸談的架構**；至於逐段釋論的義理細節，另見 01343、01355 兩篇。

法藏此疏的獨到之處在於：他在「顯教分齊」門中**不用華嚴宗慣用的五教判，而別立四宗判**——隨相法執宗（小乘諸部）、真空無相宗（般若、中論）、唯識法相宗（深密、瑜伽）、如來緣起宗（楞伽、密嚴、寶性、起信），並將《起信論》判歸第四「如來緣起宗」。這與其《華嚴一乘教義分齊章》的五教判大異其趣，是研究法藏思想的關鍵材料。

## 二、核心段落

### （一）序文：真心寥廓

**原文：**

> 夫真心寥廓，絕言象於筌蹄；沖漠希夷，亡境智於能所。非生非滅，四相之所不遷；無去無來，三際莫之能易。

**白話對照：**

真心廣大空寂，超絕了一切言語形象——那些不過是捕魚的筌、捉兔的蹄罷了；它沖虛淡漠、無聲無形，泯除了境與智、能與所的對立。

它不生也不滅，生、住、異、滅四相無法使它遷變；它無去也無來，過去、現在、未來三際無法使它改易。

### （二）序文：不變隨緣，水波之喻

**原文：**

> 但以無住為性，隨派分岐，逐迷悟而升沈，任因緣而起滅。雖復繁興鼓躍，未始動於心源；靜謐虛凝，未嘗乖於業果。
>
> 故使不變性而緣起，染淨恆殊；不捨緣而即真，凡聖致一。其猶波無異水之動故，即水以辨於波；水無異動之濕故，即波以明於水。是則動靜交徹，真俗雙融，生死涅槃，夷齊同貫。

**白話對照：**

只因它以「無所住」為體性，於是隨著支流而分出岔道，逐著迷與悟而有升沉，任隨因緣而有起滅。雖然萬象紛繁興起、鼓盪騰躍，卻從未真正動搖過那心的本源；雖然寂靜虛凝、湛然不動，卻也未曾違背過業與果的法則。

因此，真如不改變其自性而能隨緣生起——所以染與淨恆常有別；又不捨離因緣而當體即是真如——所以凡與聖畢竟歸一。

這就好比：波浪並沒有離開水而別有其動，所以就著水便可辨明波；水也沒有離開動而別有其濕性，所以就著波便可闡明水。這樣一來，動與靜交相徹通，真諦與俗諦雙雙圓融，生死與涅槃平等齊一、貫通無二。

### （三）序文：馬鳴造論的因緣

**原文：**

> 但以如來在世，根熟易調，一稟尊言，無不懸契。大師沒後，異執紛綸，或趣邪途，或奔小徑。遂使宅中寶藏，叵濟乏於孤窮；衣內明珠，弗解貧於傭作。
>
> 爰有大士，厥號馬鳴，慨此頹綱，悼斯淪溺。將欲啟深經之妙旨，再曜昏衢；斥邪見之顛眸，令歸正趣。

**白話對照：**

只因如來在世的時候，眾生根機成熟、容易調伏，一旦稟受世尊的言教，沒有不冥然契合的。而大師滅度之後，種種異端執著紛然雜陳，有的趨向邪途，有的奔走於小乘的窄徑。於是就造成這樣的局面：宅中明明埋著寶藏，卻救不了孤苦貧窮之人的匱乏；衣裡明明繫著明珠，卻解不開傭工者的貧困。

（按：「宅中寶藏」出《涅槃經》貧女寶藏喻，「衣內明珠」出《法華經》繫珠喻，皆喻眾生本具佛性而不自知。）

於是有一位大士，名號馬鳴，感慨於這綱紀的頹敗，哀悼於眾生的沉淪。他將要開啟深經的微妙宗旨，重新照亮昏暗的歧路；斥破邪見所造成的顛倒眼目，令眾生歸向正道。

### （四）釋題「大乘起信論」

**原文：**

> 然則「大」以包含為義，「乘」以運載為功，「起」乃對境興心，「信」則於緣決定，往復折徵，故稱為論。故云《大乘起信論》。

**白話對照：**

那麼，「大」取包含一切的意義，「乘」取運載眾生的功用，「起」是說面對境界而興發此心，「信」是說對所緣之法生起決定不移的信解，而反覆往返地辯難徵詰，所以稱之為「論」。因此叫做《大乘起信論》。

### （五）開章十門

**原文：**

> 將釋此論，略開十門：一、辨教起所因；二、諸藏所攝；三、顯教分齊；四、教所被機；五、能詮教體；六、所詮宗趣；七、釋論題目；八、造論時節；九、翻譯年代；十、隨文解釋。

**白話對照：**

將要解釋這部論，大略開為十個門類：第一，辨明此教興起的原因；第二，判定它在三藏中的歸屬；第三，顯示其教法的層次分限；第四，說明此教所攝受的根機；第五，辨明能詮表的教體；第六，闡明所詮顯的宗旨趣向；第七，解釋論題名目；第八，考述造論的時節；第九，考述翻譯的年代；第十，隨順論文逐段解釋。

### （六）教起十因

**原文：**

> 初教起因者，略有十因：一、依何智；二、示何法；三、云何示；四、以何顯；五、依何本；六、藉何力；七、為何義；八、以何緣；九、由何起；十、幾何益。
>
> 初「依何智」者，謂依論主洞契心源之智、隨機巧妙之辯。
>
> 二「示何法」者，謂一心、二門、三大、四信、五行等法。此即是大乘之中起信之法，是所示也。
>
> 三「云何示」者，謂以巧便開一味大乘，作法、義二種；分一心法，復作二門；析一義理，復為三大。由此善巧而得開示。

**白話對照：**

第一門「教起因」，大略有十種因由：一、依憑什麼智慧；二、開示什麼法；三、如何開示；四、憑什麼顯明；五、依據什麼根本；六、藉助什麼力量；七、為了什麼義趣；八、憑藉什麼因緣；九、由於什麼而發起；十、有多少利益。

第一，「依何智」——是依憑論主（馬鳴）那洞徹契合心源的智慧，以及隨順根機而善巧應對的辯才。

第二，「示何法」——是開示一心、二門、三大、四信、五行等法。這就是大乘之中「起信」之法，正是所要開示的內容。

第三，「云何示」——是以善巧方便，把渾然一味的大乘開為「法」與「義」兩種；把「一心法」再分作「二門」；把「一義理」再析為「三大」。就是憑藉這樣的善巧而得以開示。

### （七）造論的十種利益

**原文：**

> 十「幾何益」者，略有六種：一、未信者令生信故；二、已信者令得聞慧故；三、已聞者令得思慧故；四、已思解者令得修慧故；五、已修行者令證入故；六、已證入者令圓滿故。

**白話對照：**

第十，「幾何益」——大略有六種利益：第一，使尚未生信的人生起信心；第二，使已經生信的人獲得聞所成慧；第三，使已經聽聞的人獲得思所成慧；第四，使已經思惟解悟的人獲得修所成慧；第五，使已經修行的人證入實際；第六，使已經證入的人達到圓滿。

### （八）四宗判與《起信論》的定位

**原文（依「顯教分齊」門要義）：**

> 東流一代諸經論，宗途有其四種：一、隨相法執宗，即小乘諸部是也；二、真空無相宗，即《般若》等經、《中觀》等論所說是也；三、唯識法相宗，即《解深密》等經、《瑜伽》等論所說是也；四、如來藏緣起宗，即《楞伽》《密嚴》等經、《起信》《寶性》等論所說是也。

**白話對照：**

傳來東土的這一代諸經論，其宗旨路徑有四種：

第一，**隨相法執宗**——就是小乘各部派所主張的，隨順事相而執有實法。

第二，**真空無相宗**——就是《般若》等經與《中論》等論所宣說的，一切法真空無相。

第三，**唯識法相宗**——就是《解深密經》等經與《瑜伽師地論》等論所宣說的，萬法唯識所現。

第四，**如來藏緣起宗**——就是《楞伽經》《密嚴經》等經與《大乘起信論》《寶性論》等論所宣說的，如來藏隨緣而起染淨諸法。

法藏將《起信論》判歸第四宗，即最高一宗。此四宗判不用五教之名，是本疏最具特色之處。

## 三、名句

**其一**

> 波無異水之動故，即水以辨於波；水無異動之濕故，即波以明於水。是則動靜交徹，真俗雙融。

波浪並非離開水而另有其動，所以就著水便能辨明波；水也並非離開動而另有其濕性，所以就著波便能闡明水。這樣，動與靜交相徹通，真諦與俗諦雙雙圓融。

水波之喻是《起信論》詮釋史上最著名的譬喻。法藏用它同時說明兩件事：一是「不變隨緣」——水不失其濕性而能起波；二是「隨緣不變」——波不離水體而宛然有相。真如與生滅、心真如門與心生滅門的關係，盡在此喻之中。後世凡論一心二門，幾乎無不援引。

**其二**

> 不變性而緣起，染淨恆殊；不捨緣而即真，凡聖致一。

不改變其自性而能隨緣生起，所以染與淨恆常有別；不捨離因緣而當體即是真如，所以凡與聖畢竟歸一。

這十六字是「真如緣起」思想最凝練的公式。前半句保住了修行的必要——若染淨無別，則修證無義；後半句保住了成佛的可能——若凡聖永隔，則解脫無門。法藏以此在「不變」與「隨緣」之間建立張力，這正是如來藏緣起宗區別於唯識法相宗與般若破相宗的關鍵所在。

## 四、術語表

| 術語 | 說明 |
|-----|------|
| **一心** | 即眾生心、如來藏心。《起信論》以此為大乘之法體，一切世間出世間法皆依此心而立。 |
| **二門** | 心真如門與心生滅門。前者就不生不滅的體性言，後者就依無明而有生滅流轉言。二門不相離而各總攝一切法。 |
| **三大** | 體大（真如平等不增減）、相大（如來藏具足無量性功德）、用大（能生一切世出世間善因果）。 |
| **四信** | 信真如根本、信佛、信法、信僧。 |
| **五行** | 施門、戒門、忍門、進門、止觀門。 |
| **真如緣起** | 亦稱如來藏緣起。真如不守自性、隨緣而成一切染淨諸法，同時又不失其不變之體。 |
| **不變／隨緣** | 真如的兩重義。「不變」謂體性恆常，「隨緣」謂能起萬法。二義相即，是本疏詮釋的核心。 |
| **四宗判** | 法藏於本疏「顯教分齊」門所立：隨相法執宗、真空無相宗、唯識法相宗、如來藏緣起宗。《起信論》屬第四宗。 |
| **十門** | 本疏懸談體例：教起所因、諸藏所攝、顯教分齊、教所被機、能詮教體、所詮宗趣、釋論題目、造論時節、翻譯年代、隨文解釋。 |
| **教起十因** | 依何智、示何法、云何示、以何顯、依何本、藉何力、為何義、以何緣、由何起、幾何益。 |
| **筌蹄** | 出《莊子》：「筌者所以在魚，得魚而忘筌；蹄者所以在兔，得兔而忘蹄。」喻言語形象只是工具，得意當忘言。 |
| **宅中寶藏／衣內明珠** | 分別出《涅槃經》貧女寶藏喻與《法華經》繫珠喻。喻眾生本具佛性而不自知，故受貧窮之苦。 |
| **阿梨耶識** | 《起信論》中依如來藏而有的生滅心識。法藏明指其即唯識家所說的阿賴耶識，並以三細（業相、能見相、境界相）配自體分、見分、相分。 |
| **本覺／始覺／不覺** | 本覺為眾生本具的清淨覺性；始覺為修行所發起的覺悟；不覺為無明所致的迷惑。三者關係是《起信論》義理的樞紐。 |

## 五、相關文獻

**所釋論本**

- 《大乘起信論》一卷（T1666）：馬鳴造，梁·真諦譯（舊譯）。本疏所釋即此本。
- 《大乘起信論》二卷（T1667）：唐·實叉難陀譯（新譯）。

**起信論三大疏**

- 隋·慧遠（淨影寺慧遠）《大乘起信論義疏》（T1843，四卷）：現存最早的《起信論》註疏之一，以地論宗立場詮釋。
- 新羅·元曉《大乘起信論疏》（T1845，二卷）：又稱《海東疏》，論旨明晰、文義暢快，法藏《義記》多所引用。
- 唐·法藏《大乘起信論義記》（T1846）：即本疏，三疏中流行最廣。

**法藏本人的相關著作**

- 《大乘起信論別記》（T1847，一卷）：法藏補充《義記》未盡之義的札記。
- 《華嚴一乘教義分齊章》（T1866）：五教十宗判教，可與本疏四宗判對照，是研究法藏判教思想演變的關鍵。
- 《華嚴經探玄記》（T1733）：法藏華嚴學的代表作。

**後世註疏**

- 唐·宗密《大乘起信論疏》（四卷）：摘錄法藏《義記》並加己說，另有傳奧《隨疏記》為之疏。
- 宋·子璿《起信論疏筆削記》（T1848，二十卷）：註釋宗密疏。
- 日本·鳳潭《起信論義記幻虎錄》（五卷）、普寂《義記要決》：考訂法藏原疏與論文的會合本，鳳潭本五卷盛行於世。
- 清·楊文會《大乘起信論義記》七卷會本：感於原書遭割裂，別求古本讎校刊行，頗受學界重視。

**相關經論**

- 《楞伽經》《密嚴經》《寶性論》：與《起信論》同屬法藏所判「如來藏緣起宗」。
- 《十地經論》：法藏釋「辯才三種」所引。
- 《瑜伽師地論》卷六十四：法藏引「欲造論者要具六因」之說。
