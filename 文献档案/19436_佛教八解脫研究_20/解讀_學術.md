# 佛教八解脱研究_20 — 学术解读

## 一、文献背景与成书

本卷为佛教典籍语料库「佛教某某研究」专题辑录系列之一，属现代汇编性专题资料，非古代单行经论。卷首概述存「內有色想觀外色解脫、內無色想觀外色解脫、淨解脫身作證具足住、空無邊處、識無邊處、無所有處、非想非非想處、滅受想定」八目；正文所辑「八解脫者：內有色想觀外色，是初解脫。內無色想觀外色，是第二解脫。淨解脫身作證具足住，是第三解脫」及「超一切色想，滅有對想，不念種種想，入空無邊處具足住。如是乃至非想非非想處、滅受想定具足住」两段，为汉巴文献通行的八解脱定型段，本卷未标所出经论，引证时须回查原典。

就名目而言，八解脱（巴 aṭṭha vimokkhā，梵 aṣṭa vimokṣāḥ）是佛教定学的老科目，成立甚早：巴利《长部》等诵经与汉译《长阿含》众集经的集法数中已见其目，说一切有部毗昙名为八背舍，联八胜处、十遍处三科铺陈；南传《清净道论》亦有详释。八目的构成分三段：前三解脱属色界定境的观色训练，中四目即四无色定，第八灭受想定为九次第定的终点。本卷八目与诸典全合，第三目「淨解脫身作證具足住」及第八目特标「身作证」的表述亦与经文相合。同系列相关卷帙：`19437_佛教八勝處研究_20`、`19435_佛教十遍處研究_20` 为其后两级科目，`19381_佛教九次第定研究_20` 与本卷第八目直接相接，宜连读。

## 二、文本结构与核心思想

本卷结构为「八目总列—前三解脱引文—后五引文」的辑录三段式。八解脱的思想结构可以从「解脱」二字切入：此处的解脱非断惑证真的解脱，而是「背舍」——于所缘背弃贪着而获得的一种自在，毗昙家即以背舍为名。三段所背舍者各有不同：初解脱内有色想观外不净色（观不净以背舍净贪）；第二解脱内无色想观外色，谓内心已伏色想而仍观外色以进阶背舍；第三净解脱观净色——值得注意的是此目由观不净翻为观净，毗昙释为考验背舍是否坚固：于净色不起贪方是真离，故特标「身作证具足住」，谓以自身触证其净。第四至第七即四无色定，其引文「超一切色想，滅有對想，不念種種想」是入空无边处的标准套语，显示此段以背舍色碍为进路；第八灭受想定灭受想二心所、令心心所止息，为八解脱之极。

合而观之，八解脱的内在逻辑是一条「逐步撤离」的路线：从不净观对治净贪（所缘上撤离净相），到观色而离色想（心理上撤离色碍），到四无色（对象上撤离物质界），到灭受想定（连受想二心所亦止息）——每一级都是对前一级所依的背舍，故其精神可概括为「离缚即脱」。

## 三、学术研究价值与争议

本卷价值有三：其一，八解脱是佛教定学中最古老科目之一，其名目贯通汉巴，是考察早期佛教禅定学如何被部派论书系统化的活标本：从经中简列到毗昙的八背舍细释，可以追踪一个禅修清单被哲学化的全过程。其二，「净解脱身作证」一目保留了重要的禅修思想史信息：从不净观进到净观、以「不起贪」为检验标准，体现了佛教禅法「对治—超越」的双层设计，与不净观、慈悲观等对治禅法的研究可以互证。其三，第八灭受想定是佛教定学最深的所依，也是唯识与部派争论「无心定有无心识」的关键文本，为心识理论史研究提供了基准问题。

争议处：其一，「内有色想观外色」之「色」诸解不同：不净色说、可憎色与净色说并传，毗昙以初二解脱同观不净、第三观净为正说，本卷引文未及此别，读者当知有异说。其二，四无色定列入八解脱的依据问题：何以无色定可称「解脱」？毗昙谓亦以背舍色碍立名，然经中亦见异说。其三，灭受想定的性质：有部谓唯圣者能入、定中无心；唯识谓入定者仍有赖耶持身；经量部异说亦存——「身作证具足住」一语如何在无心之说下解释（若无心，谁触证？），是诸家必须面对的经典难题，本卷引文存其目而未涉其辩。

| 梵/巴语 | 汉语 | 英译 |
|---|---|---|
| Vimokkha | 解脱 | liberation |
| Rūpa-saññī | 有色想 | perceiving form |
| Āpo-kasiṇa | 遍处 | kasiṇa |
| Ākāsānañcāyatana | 空无边处 | base of infinite space |
| Viññāṇañcāyatana | 识无边处 | base of infinite consciousness |
| Ākiñcaññāyatana | 无所有处 | base of nothingness |
| Nevasaññānāsaññāyatana | 非想非非想处 | base of neither-perception-nor-non-perception |

说明：文档术语表第三行以水遍（āpo-kasiṇa）对「遍处」，与八解脱第三净解脱正观净色（毗昙多释为净色观或以青黄赤白净色为所缘）可相互印证，据原文档注明；灭受想定梵 saṃjñā-vedanā-nirodha-samāpatti（想受灭等至），本卷术语表未收，特补注。
