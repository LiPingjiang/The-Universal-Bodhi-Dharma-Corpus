# 佛教十遍处研究 — 学术解读

## 一、文献背景与成书

本目录所收并非单一典籍，而是围绕「十遍处」（巴利语 kasiṇa，亦译「十一切处」「十遍入」）这一禅修体系所作的纲目式文献摘要。其原文档仅录有总纲一句与两段拟经体引文，属于主题性条目而非完整经典，故本解读以可考的传世文献为背景展开。

十遍处的完整教说，在南传系统中以觉音尊者《清净道论》第四、第五品的阐发最为系统，汉译方面则对应僧伽婆罗所译《解脱道论》的相关品目。在汉译大藏经中，《中阿含》《杂阿含》已有「一切处」的具体修习记载，《大智度论》卷二十一等处亦明列「十一切处」，说一切有部《大毗婆沙论》与《俱舍论·分别定品》则将十遍处纳入八解脱、八胜处之后，构成「三胜处」体系。此十法即地、水、火、风、青、黄、赤、白、空、识，前八者为色法遍处，后二者与四无色定中的空无边处、识无边处相通。原文档所列名目与《清净道论》一致，唯汉传论典多作「十一切处」，名目出入当以原文档为准，同时并存以资对照。

## 二、文本结构与核心思想

原文档的结构为「概述—选段—名句—术语表」四段式纲目。其概述直陈十法名目，所录核心段落为：「十遍處者：地遍一切處，水遍一切處，火遍一切處，風遍一切處。青遍一切處，黃遍一切處，赤遍一切處，白遍一切處。空遍一切處，識遍一切處。」另一段说明修法要领：「若人於地遍作意，增長廣大，周遍一切，無有間隙，是名地遍處。」

其核心思想可归纳为三点。第一，「遍」即周遍无碍，行者先取一特定所缘（如圆盘状的土、一泓清水），由「取相」「似相」的修习令心专注，再将此相无限扩大至十方一切处。第二，十遍处以八大种与四显色为所缘，实为以色法为基础而超克色法分别的禅定技术，青黄赤白四遍尤以能生色界禅那著称。第三，空、识二遍居末，显示由色界向无色界过渡的次第。原文档术语表所列 Kasiṇa、Pathavī 等巴利语汇，与《清净道论》系统相合，是其可靠处；但术语表未列空遍（Ākāsa）、识遍（Viññāṇa）二项，于十法之数略有脱漏，读时宜补足。

## 三、学术研究价值与争议

十遍处是观察印度禅定技术史的重要标本。其一，汉译「十一切处」与巴利「十遍」的名目对应、八解脱—八胜处—十遍处三层体系的部派差异，是部派佛教比较研究的经典课题，《大毗婆沙论》与《清净道论》的异文比对尤具价值。其二，青黄赤白四色遍处的所缘选择，涉及早期佛教对色彩知觉与心的关系的理解，近年引起认知科学与冥想研究者的注意。其三，空遍、识遍与四无色定的关系，南北传论典解释不一：有论师视二遍为无色定的入门加行，有论师则将其独立为定体，此一公案迄今未有定论。此外，原文档所录引文体裁为拟经式概括，并非某一经的逐字原文，引用时应注明其纲目性质，不可径称经语。

## 四、术语对照表

| 术语 | 巴利/梵语 | 说明 |
|---|---|---|
| 遍处 | Kasiṇa（巴）/ Kṛtsnāyatana（梵） | 周遍一切处的禅定所缘，汉传亦译「一切处」 |
| 地遍 | Pathavī-kasiṇa | 以地大之相为所缘 |
| 水遍 | Āpo-kasiṇa | 以水界之相为所缘 |
| 青遍 | Nīla-kasiṇa | 以青色为所缘，余黄、赤、白准此 |
| 空遍 | Ākāsa-kasiṇa | 以虚空为所缘，通空无边处定 |
| 识遍 | Viññāṇa-kasiṇa | 以识为所缘，通识无边处定 |
| 似相 | Paṭibhāga-nimitta | 遍处修习成就的内心映相 |
| 八胜处 | Abhibhāyatana | 以胜伏所缘为义，为遍处前行 |
