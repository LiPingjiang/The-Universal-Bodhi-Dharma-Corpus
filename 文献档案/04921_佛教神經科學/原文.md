# 佛教神經科學 · 原文

## 一、學科概述

佛教神經科學是以神經成像與電生理技術研究禪修對腦結構與腦功能的影響的新興領域，是「冥想科學」中最活躍的分支。其學術建制化始於2000年前後：1990年代，理查德·戴維森（Richard Davidson）在威斯康星大學麥迪遜分校建立腦成像實驗室，並與達賴喇嘛合作，說服資深藏傳佛教僧人進入實驗室接受腦掃描；2004年，戴維森與安托萬·盧茨（Antoine Lutz）等在《美國國家科學院院刊》（PNAS）發表論文，報告長期禪修者在慈悲禪修中表現出異常高振幅的伽馬波同步活動，引起全球關注。諾貝爾生理學或醫學獎得主、神經科學家埃里克·坎德爾（Eric Kandel）也公開關注並肯定這一研究方向。此後二十餘年，該領域累積了數千項研究，成為腦可塑性研究的標誌性範例。

## 二、核心議題與佛教觀點

核心議題包括：（一）長期禪修是否改變腦結構——2005年，哈佛醫學院附屬麻省總醫院的薩拉·拉扎爾（Sara Lazar）團隊發現長期冥想者前額葉與島葉皮層增厚；2011年布里塔·赫爾策爾（Britta Hölzel）等進一步發現八週正念減壓訓練即可使杏仁核密度變化。（二）禪修的腦網絡機制——耶魯大學的賈德森·布魯爾（Judson Brewer）發現禪修者靜息時「預設模式網絡」（與自我參照思維相關）活動降低，與佛教「無我」觀形成耐人尋味的對照。（三）方法學爭議——橫斷面研究難以區分天生差異與訓練效應，效應量與樣本問題持續被檢討。佛教方面，《雜阿含經》以「束蘆相依」喻名（精神現象）色（物質身體）互相依存而立，恰為心腦關係的雙向研究提供古典表述。

> **經典依據**：
> 「譬如三蘆立於空地，展轉相依，而得豎立；若去其一，二亦不立。」——《雜阿含經》（T99）

此喻出自舍利弗與摩訶拘絺羅論「識緣名色，名色緣識」之義：心理與生理、心與腦互為條件、缺一不可，既非心靈主義亦非還原論，與當代心腦互作的經驗研究立場深相契合。

## 三、代表學者與實踐

戴維森是該領域公認的旗手，其威斯康辛實驗室對僧人馬修·理查德（Matthieu Ricard）等人的腦成像研究——媒體稱理查德為「世界上最快樂的人」——已成經典案例；他後來創立「健康心智研究中心」（Center for Healthy Minds），並與丹尼爾·戈爾曼合著《改變的特質》（Altered Traits, 2017）。拉扎爾以嚴謹的縱貫設計追蹤八週正念課程前後的腦變化，確立了「短訓練亦有腦效應」的證據。中國學者唐一源（Tang Yi-Yuan）與合作者發展「身心整合訓練」（IBMT），以短時訓練改善注意與自我調節，成果發表於《美國科學院院刊》。此外，加州大學戴維斯分校克利福德·薩龍（Clifford Saron）主持的「沙瑪莎計劃」（Shamatha Project）對長期閉關者進行多維度追蹤，將禪修神經科學推向更嚴格的縱貫研究。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 神經可塑性 | 經驗與訓練引起腦結構與功能改變的特性 |
| 預設模式網絡（DMN） | 靜息時活躍的腦網絡，與自我念頭遊走相關 |
| 伽馬波同步 | 高頻腦電振盪的相位鎖定，見於深度專注與慈悲禪修 |
| 禪那（jhāna） | 深度專注的禪定狀態，神經科學研究的高階對象 |
| 名色（nāma-rūpa） | 心理現象與物質現象的總稱，佛教心身二元相依之說 |
| 慈悲禪修 | 以培養慈心與悲心為對象的禪修法，戴維森團隊重點研究對象 |
