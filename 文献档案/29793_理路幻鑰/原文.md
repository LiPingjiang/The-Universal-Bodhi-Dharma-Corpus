# 理路幻鑰（辨析量論意義集課）

## 作者簡介

普覺·強巴（藏文：ཕུར་ལྕོག་བྱམས་པ，Wylie: Phur lcog Byams pa，全名：普覺·強巴·洛桑嘉措 Phur lcog Byams pa Blo bzang rgyal mtshan），18至19世紀格魯派著名學者。普覺·強巴長期在拉薩三大寺（色拉寺、哲蚌寺、甘丹寺）從事教學與著述，其所編撰的《理路幻鑰》（རིགས་ལམ་འཕྲུལ་གྱི་ལྡེའུ་མིག，Rigs lam 'phrul gyi lde'u mig）是格魯派三大寺最通用的攝類學教材，也是整個格魯派教育體系中使用最廣、影響最深的因明入門課本。

此書全名「辨析量論意義集課」（ཚད་མའི་དོན་བསྡུས་རིགས་ལམ་འཕྲུལ་གྱི་ལྡེའུ་མིག，Tshad ma'i don bsdus rigs lam 'phrul gyi lde'u mig），其中「理路」（rigs lam）指因明邏輯推理的路徑，「幻鑰」（'phrul gyi lde'u mig）意為「神妙之鑰」，比喻此書是打開量論殿堂大門的鑰匙。

## 各章節辯題清單

以下為《理路幻鑰》各主要章節的核心辯題概覽：

### 小理路部分

**第一章：紅白顏色（dkar dmar）**

核心辯題：
1. 白色是不是顏色？（དཀར་པོ་མདོག་ཡིན་ནམ།）
2. 所有顏色是不是白色？（མདོག་ཐམས་ཅད་དཀར་པོ་ཡིན་ནམ།）
3. 非白色是不是非顏色？（དཀར་པོ་མ་ཡིན་པ་མདོག་མ་ཡིན་པ་ཡིན་ནམ།）
4. 紅色和白色是相違還是相屬？

**第二章：成事（grub pa）**

核心辯題：
1. 兔角是成事嗎？（རི་བོང་རྭ་གྲུབ་པ་ཡིན་ནམ།）
2. 成事的定義是什麼？——被量所成立（ཚད་མས་གྲུབ་པ）
3. 「所知」和「成事」是一還是異？
4. 「不存在」本身是存在的嗎？

**第三章：因果（rgyu 'bras）**

核心辯題：
1. 因和果能同時存在嗎？
2. 種子是苗的因嗎？苗是種子的果嗎？
3. 甲是乙的因，是否乙一定是甲的果？
4. 一個事物能不能既是因又是果？

**第四章：總別（spyi bye）**

核心辯題：
1. 「動物」是「牛」的總嗎？
2. 所有的總都是常法嗎？
3. 「牛」是「黃牛」的總還是別？
4. 共相和自相各是什麼？

**第五章：相違與相屬（'gal 'brel）**

核心辯題：
1. 常和無常是何種相違？——矛盾相違
2. 煙和火是何種相屬？——因果相屬（de byung 'brel）
3. 瓶子和金瓶是何種相屬？——同體相屬（bdag gcig 'brel）
4. 能否存在既不相違又不相屬的兩個事物？

### 中理路部分

**第六章：心類學（blo rig）**

核心辯題：
1. 量分幾種？——現量和比量兩種
2. 眼識是現量嗎？
3. 分別識是量嗎？
4. 猶豫識和伺察意的區別是什麼？

**第七章：量的總論（tshad ma spyi don）**

核心辯題：
1. 量的定義是什麼？——新而不欺之識（གསར་དུ་མི་བསླུ་བའི་རིག་པ）
2. 再決識是不是量？——不是，因為不「新」
3. 自證量存在嗎？——格魯派不承許自證量

### 大理路部分

**第八章：因類學（rtags rig）**

核心辯題：
1. 正因分幾種？——果因、自性因、不可得因
2. 「有煙」是推出「有火」的正因嗎？——是，屬果因
3. 似因有幾種？——不成因、不定因、相違因

## 典型立論範式原文摘錄

以下為《理路幻鑰》中一段典型的立論範式：

### 論式一：成事的定義

> རང་ལུགས། གྲུབ་པའི་མཚན་ཉིད། ཚད་མས་གྲུབ་པ་ཡིན། གྲུབ་པའི་མཚོན་བྱ་ནི། དཔེར་ན་བུམ་པ་ལྟ་བུའོ།།
> rang lugs / grub pa'i mtshan nyid / tshad mas grub pa yin / grub pa'i mtshon bya ni / dper na bum pa lta bu'o //
>
> 立自宗：成事的性相（定義），是被量所成立。成事的事例，例如瓶子。

### 論式二：相違的分類

> གཞན་ལུགས། གལ་ཏེ་འགལ་བ་ཐམས་ཅད་ཕན་ཚུན་སྤང་འགལ་ཡིན་ནོ་ཞེ་ན། རྟག་པ་དང་མི་རྟག་པ་ཕན་ཚུན་སྤང་འགལ་མ་ཡིན་ཏེ། ཕན་ཚུན་འགག་འགལ་ཡིན་པའི་ཕྱིར།
> gzhan lugs / gal te 'gal ba thams cad phan tshun spang 'gal yin no zhe na / rtag pa dang mi rtag pa phan tshun spang 'gal ma yin te / phan tshun 'gag 'gal yin pa'i phyir /
>
> 破他宗：若承許一切相違皆是互相捨棄之相違，則常與無常應非互相捨棄之相違，因其為互相阻礙之相違故。

## 版本與傳承

《理路幻鑰》自編成以來，在格魯派三大寺系統中廣泛流通，主要傳承版本包括：

1. **色拉寺木刻版**：拉薩色拉寺舊刻本，是最通行的版本。
2. **哲蚌寺抄本**：哲蚌寺各扎倉使用的手抄教學本，細節上與色拉寺版略有出入。
3. **南印度三大寺重刻版**：1959年後三大寺在南印度重建，重新刻印了《理路幻鑰》，加入了部分導讀注釋。
4. **現代排印版**：近年在印度達蘭薩拉出版的藏文排印版，附有索引和術語表。

此書目前尚無完整的漢譯本，但其核心內容已通過多部攝類學漢譯著作（如洛色林攝類學的漢譯本《因明學基礎》）間接傳入漢語學界。
