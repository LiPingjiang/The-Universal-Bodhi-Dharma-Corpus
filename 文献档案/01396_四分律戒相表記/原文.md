# 四分律戒相表記 · 原文

## 一、文獻概述

《四分律比丘戒相表記》（本檔簡稱《四分律戒相表記》），近代弘一律師（1880–1942，俗名李叔同，出家前為著名藝術家、教育家）編著。弘一1918年出家後，棄文藝而專研律學，遍考南山三大部與靈芝元照之注釋，發願重興南山律宗。本書始編於出家後數年間，歷時約十年：因《四分律》比丘二百五十戒之戒相繁雜、開遮持犯難以記誦，弘一乃依道宣《四分律含注戒本》為綱，參酌《行事鈔》《資持記》等南山諸部，將二百五十條戒文「制為表解」，逐戒列出其罪名、緣起、具緣成犯之條件、犯相輕重、境想、開緣等，以表格式條列其綱要，並親自以工楷書寫，先後石印流通二次。此書被其弟子劉質平稱為「先師佛學著作上最偉大的作品」，弘一本人亦於遺囑中囑託：「倘欲做一事業與余為紀念者，先將《四分律比丘戒相表記》印二千冊。此書可為余出家以後最大之著作。故宜流通，以為紀念也。」

本書之性質為南山律學之「便覽化」：以現代表格形式重現「具緣成犯」之判析結構，使戒律之持犯軌則一目了然，是民國以來漢傳佛教比丘學戒之通行入門典籍；其手寫字體亦具書法文獻價值。與弘一晚年所輯《南山律在家備覽略篇》並為其律學之雙璧。本書未入大藏經，屬近代刻本流通文獻；今日通行者為福建、上海等地依原印本之影印及重排本。

## 二、核心段落選錄

> **原文**：弘一《四分律比丘戒相表記·自敘》：「以戒相繁雜，記誦非易，思撮其要，列表志之。輒以私意，編錄數章；頓喜其明晰，便於初學。」（據《四分律比丘戒相表記》自敘原文）
> **白話對照**：弘一自述編書緣起：比丘戒相繁瑣龐雜，記誦很不容易，於是想撮取其要點，用表格的方式標列出來。起初以個人研究心得試編了幾章，立刻發現這樣做條理明晰，非常便於初學——於是擴而充之，成就全書。

> **原文**：劉質平記其師遺囑：「倘欲做一事業，與余為紀念者，先將《四分律比丘戒相表記》印二千冊。此書可為余出家以後最大之著作。故宜流通，以為紀念也。」（據劉質平《弘一法師的遺墨及其生活回憶》所錄遺囑原語）
> **白話對照**：弘一臨終前交代弟子：如果你們要為我做紀念的事業，就先把《四分律比丘戒相表記》印兩千冊流通——這是我出家以後最大的著作，讓它流傳於世，就是最好的紀念。一代律師以一書自署其一生，其重視可知。

> **原文**：本書解戒之體例，逐戒依「具緣成犯」判析。以「大妄語戒」為例：表列其具緣須具「（一）是眾生、（二）眾生想、（三）起欺誑心、（四）說過人法、（五）自言已證」等緣，具緣成犯，缺則不犯或犯輕；並列「境想」四句、開緣諸項。（此為南山《含注戒本疏》以降律家解戒之通行體例，本書以表格承之）
> **白話對照**：弘一解釋每一條戒，都採用南山律的「具緣成犯」分析法：一條戒要構成重犯，必須同時具足幾個條件。以「大妄語戒」（妄稱自己證得聖果神通）為例：對方是人、知道是人、有意欺騙、真的說了過人之法、說的是自己——條件全部具備才算犯重；缺一項則罪相減輕乃至不犯。這種條件式分析使模糊的「犯戒」變成可以精確判定的法條結構。

## 三、重要名句

> **名句一**：「以戒為師」——弘一終生服膺之遺訓，其律學著述之總綱（此語本自佛陀臨終垂誡）。

> **名句二**：「戒相繁雜，記誦非易；撮要列表，便於初學」——本書自敘之撰述綱領。

> **名句三**：「此書可為余出家以後最大之著作」——弘一遺囑自評，一書足傳其律學功業。

> **名句四**：「應使名詞精確，界限分明」——本書表格化解戒之效果，亦是弘一一絲不苟人格之寫照。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 戒相 | 戒法顯於外之相狀，即各戒之條文與犯相 |
| 表記 | 以表格條列綱要之編纂體裁，本書所創用 |
| 具緣成犯 | 具足若干條件方構成犯戒之分析法 |
| 境想 | 對所對境（對象）之認知正誤之四句判析 |
| 開緣 | 雖似犯戒而依法不犯之例外情形 |
| 波羅夷 | 四重禁罪，犯者失比丘體，如斷頭 |
| 南山律 | 道宣所立、以《四分律》通大乘之律學體系 |
| 含注戒本 | 道宣就《四分戒本》加注之本，本書之綱依 |
