# 佛教形而上學 — 学术解读

## 一、文献背景与成书

本目录所收《原文》为现代学科体例的专题综述，讨论佛教对实在、存在、因果、时间与自我等根本问题的立场及其与西方形而上学的比较。「形而上学」同样是外来的学科框架：佛教传统中并无此名，但阿毗达磨体系的存在范畴分析（《大毗婆沙论》五位七十五法、唯识五位百法）与中观对实体概念的解消，构成了可以被这一框架处理的丰富对象——原文以「反本体论的本体学」概括这一奇特的知识形态。

原文的学术坐标覆盖三个传统。英语学界：Mark Siderits《Buddhism as Philosophy》（2007）提出佛教「还原论」的人格观，Jay Garfield 英译《中论》并于《Engaging Buddhism》（2015）推进中观与心灵哲学的对话。日本京都学派：西田几多郎以禅的「绝对无」回应西方存在论，西谷启治《宗教是什么》以「空」重构形而上学的场域。汉语传统：牟宗三《佛性与般若》疏解天台、华严、唯识三大体系，方立天《中国佛教哲学要义》阐发中国化佛教的宇宙论与心性论。库藏方面，本档案库收有 `21240_佛教形而上學_24`、`27818_佛教形而上學_37` 等同名系列卷帙，与本卷各自独立；本卷为通论综述。本专题不对应任何大正藏编号，所引《中论》（T1564）等经论则有藏经出处。

## 二、文本结构与核心思想

原文分学科概述、核心议题与佛教观点、代表学者著作与案例、术语对照表、相关文献五节（第三节的标题与同系列其他卷的「代表学者与著作」略有差异，为原文档自身体例，本文照实说明）。第二节列出四大议题：一、空性与缘起——「空」并非虚无，而是对自性见的否定，万物「非有非无」的中道存在方式；二、二谛结构——世俗谛承认经验世界的有效性，胜义谛揭示其无自性，二者不即不离；三、无我与人格同一性——佛教否定常住自我，以五蕴相续解释人格，与洛克、帕菲特的人格理论形成对话；四、如来藏与佛性——「悉有佛性」是否违背无我，是佛教内部千年争论。

经证取《中论·观四谛品》两偈：「众因缘生法，我说即是空，亦为是假名，亦是中道义」与「诸佛依二谛，为众生说法」。原文对佛教总体立场的概括是：形而上问题应以「离二边」的中道回应，执有执无皆为戏论。值得注意的是其论证策略的双重性——一面以缘起否定实体主义，一面又以阿毗达磨的精细分类承担本体学的功能，这一「既拆又建」的结构是佛教形而上学的独特之处，也是它吸引分析哲学的原因。

## 三、学术研究价值与争议

本专题的价值在于它是佛教哲学与当代分析哲学互动最深的领域。Siderits 的人格还原论把「无人我」转写为「人格只是五蕴的方便集合」，直接对接帕菲特《理与人》的讨论；Garfield 的中观研究则使「空」成为语境主义语义学与反基础主义知识论的对话者。京都学派一线则展示了形而上学问题的另一解法：以「绝对无」和「空」场所重新安放主客关系，影响过海德格尔之后的欧陆宗教哲学。

争议集中在三处。其一，如来藏与无我的张力：佛性论是否为佛教内部的实体论回潮，从《大乘起信论》真伪之争到「批判佛教」松本史章、袴谷宪昭的论战，历时百年；这是本专题涉及的佛教学术史上最激烈的争端之一。其二，还原论读法的限度：把佛教人格观径直归约为还原主义，是否忽略了修行论与解脱论语境——Siderits 自己也承认其诠释是「哲学重构」而非教义史描述。其三，跨传统比较的对称性：西田「绝对无」与中观「空」的等同在京都学派内部即有保留意见；以西方范畴（实体、属性、共相）整理阿毗达磨法数时的错位，也是长期存在的翻译哲学问题。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 空性（śūnyatā） | 诸法无自性、缘起不实的存在本性。 |
| 二谛 | 世俗谛与胜义谛，两层真理结构。 |
| 缘起 | 诸法依因缘和合而生起的因果原理。 |
| 自性（svabhāva） | 独立自存的本质，佛教所否定的实体概念。 |
| 如来藏 | 一切众生本具佛性的成佛根据。 |
| 绝对无 | 京都学派以「无」为终极实相的哲学概念。 |
| 五位百法 | 唯识学的存在范畴分类体系。 |
