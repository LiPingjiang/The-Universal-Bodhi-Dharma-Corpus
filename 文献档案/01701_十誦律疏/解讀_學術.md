# 十诵律疏 — 学术解读

## 一、文献背景与成书

本目录题作「十诵律疏」，据语料库原文档定位，所疏对象为说一切有部（萨婆多部）所传《十诵律》，大正藏第一四三五号，凡六十一卷。其汉译过程颇费周折：后秦弘始六年（404），罽宾人弗若多罗集僧数百人诵出胡本，鸠摩罗什译为晋文，译及三分之二而多罗遘疾去世，后由昙摩流支续译，终成全帙。须如实说明：与「五分律疏」情形相近，汉地并无一部独立流传、题名为「十诵律疏」的疏书，原档所称疏释，主要体现为律文对戒条与制戒因缘的内含解释，以及《萨婆多毗尼毗婆沙》（T1440）等有部论释对十诵律的疏解。本篇即据原档所确认的这一范围撰文。

「十诵」得名，据原档所载相传之说：律文原有八十诵，自大迦叶传承至第五师优波掘多，因虑后世钝根者不能尽持，删为十诵，故称。十诵律为四部广律中最早译出者，盛行于南朝，是鸠摩罗什译经事业的重要组成部分。

## 二、文本结构与核心思想

全书将戒律分为十项叙述，结构严整：首举比丘戒法，列波罗夷法四条、僧残法十三条等共二百五十七条戒并逐一解说；次以七法、八法、杂诵二法等十七章说明僧团组织与管理；再次说明比丘尼戒三百五十五条；最后附增一法、优波离问法与比丘诵。这种「戒法—犍度—尼戒—附录」的四段式布局，成为后世观察有部律学的标准框架。

核心思想上，十诵律体现出有部律学的严密性格。原档所录初波罗夷制戒因缘可为范例：毗耶离长者子须提那出家后值饥馑，乞食难得，遂思借己出家之身劝化亲族布施作福，还归故里——此一念虽出于善意，却引出后续违缘，佛陀因而制戒。此类叙事显示有部律学的基本立场：持戒与否不仅问动机，更须观其行事之后果与对僧团整体的影响。其附篇「优波离问法」以问答体展开戒律决疑，「增一法」以数字递增编排条目，皆是后期论书体例在律藏中的雏形。

## 三、学术研究价值与争议

学术价值方面，十诵律是四部广律中最早汉译者，其译本保留了大量后秦时期的律学术语，是研究佛教译经史与汉晋佛教语汇的关键文本。作为有部广律，它与《大毗婆沙论》及唐义净译《根本说一切有部毗奈耶》构成有部律学的纵向谱系，又可与四分、五分、僧祇诸律作横向比较，以观察各部对同一戒条的宽严异同。原档所载「八十诵删为十诵」的传承说，亦为律藏编纂史研究提供了重要线索。

争议点主要有二：其一，弗若多罗未竟而卒、昙摩流支续译的成书经过，使译本内部可能存在师承不一的痕迹，学界对前后部分文气与术语一致性问题时有讨论；其二，「十诵律疏」题名易生误解，须明辨汉地无同名专疏，唐以前盛行南朝的十诵学其注疏多已散佚，今存者以《萨婆多毗尼毗婆沙》等论释为主要依托。同属本批律疏系列的「01697_四分律疏」「01699_五分律疏」「01703_摩訶僧祇律疏」「01717_菩薩戒本疏」可互参。

| 萨婆多部 | 说一切有部，主张三世实有、法体恒有 |
| 波罗夷 | 最重罪，比丘四条，犯者永摈 |
| 僧残 | 次重罪，须经僧众如法出罪方复清净 |
