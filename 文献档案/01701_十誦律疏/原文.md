# 十誦律疏·原文

## 一、概述

十诵律疏，指对萨婆多部（说一切有部）所传《十诵律》之疏释。十诵律收录于大正藏第1435号，凡六十一卷，后秦弗若多罗共鸠摩罗什译。弗若多罗罽宾人，专精十诵律部，伪秦弘始六年（404）集僧数百人诵出胡本，鸠摩罗什译为晋文，三分获二而多罗遘疾弃世。后有昙摩流支续译，终成全帙。相传律文原有八十诵，大迦叶传承以后至第五师优波掘多始删为十诵，故名"十诵"。全书将戒律分为十项叙述，首举比丘戒法波罗夷法四条、僧残法十三条等二百五十七条，并一一解说；次为七法、八法、杂诵二法等十七章，说明僧团之组织与管理；次说明比丘尼戒三百五十五条；最后附增一法、优波离问法与比丘诵。十诵律为四部广律中最早译出者，盛行于南朝。

## 二、核心段落

### 段落一：初波罗夷法之制戒因缘

**原文：**

> 明四波罗夷法之一。佛在毗耶离国，去城不远有一聚落，是中有长者子，名须提那加兰陀子，富贵多财种种成就，自归三宝为佛弟子，厌世出家剃除须发被著法服而作比丘，远离乡土到憍萨罗国一处安居。时世饥馑乞食难得，诸人民妻子尚乏饮食，何况能与诸乞求人。时须提那作是念：此大饥馑乞求难得，我等诸亲里多饶财富，当因我故布施作福，今正是时。作是念已，夏安居过三月自恣竟作衣毕，著衣持钵还毗耶离，经游诸国至本聚落。

**白话翻译：**

说明四波罗夷法中的第一条。佛陀在毗耶离国，离城不远有一个聚落，聚落中有位长者之子，名叫须提那，是迦兰陀的长者子，富贵多财，种种事业都有成就，他归依三宝成为佛弟子，厌离世俗出家，剃除须发，披上法服而作比丘，远离家乡到了憍萨罗国一处安居。当时遭遇饥馑之年，乞食十分困难，人民连自己的妻子儿女都缺少饮食，何况能给那些乞求之人。这时须提那心想：如今大饥馑，乞食难得，我等亲族多有财富，当因我的缘故布施修福，现在正是时候。这样想后，夏安居三个月期满自恣完毕、作衣结束后，著衣持钵回到毗耶离，经游诸国到达自己的故乡聚落。

### 段落二：戒律之传承

**原文：**

> 相传律文原有八十诵，大迦叶传承以后至第五师优波掘多，始删为十诵。大迦叶所传之法藏原为八十诵，至优波掘多时，因恐后世钝根者无法完全受持，遂删为十诵。

**白话翻译：**

相传律文原来有八十诵之多，从大迦叶传承以后，到第五代师优波掘多时，才删减为十诵。大迦叶所传的法藏原本是八十诵，到了优波掘多时，因为担心后世钝根的人无法完全受持，于是删减为十诵。

## 三、名句

1. "佛随物适时说一切法，后诸集法藏弟子以类撰之。"——此为萨婆多毗尼毗婆沙对佛陀说法方式之概括，律藏即由弟子分类编纂而成。

2. "佛或时为诸弟子制戒轻重有残无残，撰为律藏。"——戒律之轻重分类（有残为僧残，无残为波罗夷），为律藏之基本框架。

## 四、术语表

| 术语 | 释义 |
|------|------|
| 十诵 | 将律文分为十项叙述，故名十诵，为说一切有部之广律 |
| 萨婆多部 | 梵文Sarvāstivāda，意译说一切有部，主张三世实有、法体恒有 |
| 波罗夷 | Pārājika，最重之罪，犯者如断头不可复活，比丘有四条 |
| 僧残 | Saṅghāvaśeṣa，次重之罪，犯者须经僧众如法出罪方可复清 |
| 八十诵 | 相传律文原有八十诵之多，优波掘多删为十诵 |
| 优波掘多 | Upagupta，律藏传承之第五师，删八十诵为十诵 |
| 增一法 | 十诵律附录之一，按数字递增编排之戒法问答 |
| 优波离问法 | 十诵律附录之一，以优波离请问佛陀之形式阐释戒律 |
