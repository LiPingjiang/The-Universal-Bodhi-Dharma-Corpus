# 佛教創新心理學 · 原文

## 一、學科概述

創新心理學研究創造性思維的認知機制（發散思維、遠距聯想、孵化效應）與創造性人格。佛教與創造性的交叉研究始於2010年代：2012年，萊頓大學的洛倫扎·科爾扎托與伯恩哈德·霍姆坎普在《心理科學前沿》發表實驗，證明「開放監測」型禪修（覺察一切經驗而不聚焦）顯著提升發散思維任務（替代用途測驗）成績，而聚焦型禪修則無此效應——禪修類型對創造性的選擇性作用首次獲得實驗確證。與此呼應，禪宗「初心」（beginner's mind，日本禪師鈴木俊隆《禪者的初心》1970年在美國出版後成為矽谷創新文化的精神讀本）成為創造性研究的常用概念。最著名的實踐案例是史蒂夫·喬布斯：他長年禪修，師從曹洞宗禪師乙川弘文，公開承認直覺與專注力訓練深刻塑造了蘋果的極簡設計哲學。

## 二、核心議題與佛教觀點

核心議題包括：（一）禪修類型與發散思維——開放監測訓練認知去中心化（念頭是事件而非真相），恰是「打破功能固著」的前提；聚焦禪修收窄注意，有助深化與驗證靈感，故創新需要兩種模式的交替，與設計思維的「發散—收斂」循環同構；（二）初心與概念固著——創造性最大障礙是既有概念的先入為主，禪宗「無所求、無所知」的初心狀態即對概念固著的古典消解；（三）空性與可能性空間——佛教「空」意謂現象無固定自性，這一形上學直覺可轉譯為創造性的認知前提：事物「尚可他樣」，故可重組、可顛覆；（四）創造性動機——過度功利動機損害創造性，佛教「無所住」的遊戲三昧提供非功利的深度投入狀態，與心流理論相合。經典依據取《金剛經》名句。

> **經典依據**：
> 「應無所住而生其心。」——《金剛經》（T235）

「無住生心」是創造性心理學的古典公式：「無住」破除對既有框架的執著（去固著），「生其心」保持心的活潑起用（生成力）——心不粘滯於任何單一表象，故能自由重組、不斷出新，這正是發散思維的禪學定義。

## 三、代表學者與實踐

科爾扎托（萊頓大學認知心理學家）團隊的系列實驗確立了「禪修影響創造性認知」的實證研究線，其後續工作進一步區分了不同禪修對頓悟問題解決與遠距聯想的不同效應。喬布斯的禪修師乙川弘文（Kobun Chino Otogawa，1938-2002）在硅谷教授禪修數十年，其影響經由蘋果的設計文化輻射至整個科技業；喬布斯1996年對《連線》雜誌說「專注與簡單是我的梵咒」，並自述禪修教會他「直覺體驗先於概念思維」。谷歌陳一鳴的SIY課程把「禪修＋創造力」帶入企業研發部門；「設計思維」教育（斯坦福d.school）對正念開端的吸納亦見端倪。學術綜述方面，2010年代多篇「冥想與創造力」元分析與系統綜述（如萊頓、阿姆斯特丹團隊）總體支持「適度而類型匹配的正念提升創造性」，但也提示高強度評價性注意反而不利於發散階段。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 發散思維 | 產生多樣新穎想法的認知過程 |
| 功能固著 | 只能按慣常用途理解事物的認知定勢 |
| 開放監測禪修 | 不聚焦特定對象、開放覺知一切經驗的禪修 |
| 初心 | 禪宗語：無先入之見地面對事物的態度 |
| 空性（śūnyatā） | 諸法無自性，現象無固定不變本質的佛教核心義理 |
| 心流 | 契克森米哈賴定義的全投入最優體驗狀態 |
