# 時輪金剛續釋 — 学术解读

## 一、文献背景与成书

《时轮金刚续》，梵名 Kālacakra-tantra，全称《时轮金刚本续》（Paramādibuddha），为藏传佛教无上瑜伽部「无二续」的根本经典。Kāla（时）与 cakra（轮）合为「时间之轮」，其教法涵盖外在宇宙星象运行（外时轮）、内在气脉明点（内时轮）与秘密的生圆二次第修法（别时轮）三个层面。相传释尊于成道后约一年，在南印度达尼雅卡达卡城（Śrī Ḍhānyakaṭaka）的大佛塔中宣说此法；金刚手菩萨化身的香巴拉（Śambhala）国王月贤王（Suchandra）闻法记录为一万二千颂，回香巴拉后编成六千颂《时轮续》，其最主要注释为《无垢光》（Vimalaprabhā）。时轮法后由香巴拉传入印度，再入西藏，格鲁、噶举、萨迦各派皆有传承。宗喀巴大师从觉囊寺尊胜大师学六加行法（时轮法），从法胜大师受学《时轮金刚大疏》。西藏的历算学（饶迥纪年）即直接渊源于时轮体系，觉囊派更以时轮他空见为立宗之本。

## 二、文本结构与核心思想

本档案所选两段原文呈现时轮续的双重叙事。其一为开经叙事：佛陀「于灵鹫山依照大乘圆满的智慧法门传法，同时在达尼雅卡达卡城教授密法」，安住于「法界中的坛城」「宇宙金刚的房子」——此「一处同时说两法」的表达，是密续经典的典型序分手法，暗示显密教法不一不异。其二为内外时轮对应说：外在的日月是「人体内在气脉明点的一种投影，就像人照镜子，镜子里的人并不是真正存在」；修气脉明点达一定境界者可凭呼吸推测月相盈亏，而依外在星象变化亦可反推内在气脉状态，故于日食、月食及每月十五、三十等特殊时分精进修持，效果非同寻常。此学说将天文学、人体生理学与解脱论熔为一炉：宇宙（外时轮）与身体（内时轮）同构对应，证悟（别时轮）则是在此对应系统中的精确操作。此外，时轮续独有的香巴拉净土信仰与未来香巴拉王大军降伏浊世之战的预言，构成藏传佛教末世论的基本框架。

## 三、学术研究价值与争议

其一，科学史价值：时轮续是佛教中天文历算含量最高的经典，其置闰、日月食推算方法构成藏历的核心，世界时轮学会（1985年成立）至今仍在按其体系推算时轮历。其二，文本史价值：梵本《时轮续》及《无垢光》皆存，Vesna A. Wallace 译出续典第四章，David Reigle 等持续做文献研究，是续典研究的重点。其三，争议问题：（1）时轮续成立年代与地点，学者多主10世纪末11世纪初出现于印度，早于一般所认为的其他无上瑜伽续之后出地位与其「最晚出」传说形成张力；（2）香巴拉是历史地理实体还是纯粹宗教乌托邦，学界聚讼不休；（3）觉囊派依《无垢光》发展的「他空见」，被格鲁派宗喀巴判为不了义，构成藏传佛教史上最著名的空性论诤。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 外时轮 | 外在宇宙、星象与时间运行的规律 |
| 内时轮 | 人体气、脉、明点的内在结构 |
| 别时轮 | 依内外时轮而修的生圆二次第与灌顶 |
| 香巴拉（Śambhala） | 时轮法统所在的净土国度，月贤王之国 |
| 无垢光（Vimalaprabhā） | 时轮续根本大疏，觉囊他空见所依 |
| 明点（bindu） | 身心中能量与心识的精华凝聚处 |
