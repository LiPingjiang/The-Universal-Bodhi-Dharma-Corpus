# 佛教九地研究 — 学术解读

## 一、文献背景与成书

本条目为语料库「寰宇覺海·菩提法藏」之独立文献补充条目，编号 X8234，目录名作「佛教九地研究_1」。据实说明：其《原文》非经论传本，而是九地名数的主题辑录，概述列「欲界五趣地、離生喜樂地、定生喜樂地、離喜妙樂地、捨念清淨地、空無邊處地、識無邊處地、無所有處地、非想非非想處地」九名，选录与名句各存两条引文，术语表七条，末附相关文献指引。与姊妹条目 `09242_佛教九地研究` 所录文字全同，可知为同一底稿在语料库不同编号位的分置；条目 README 自署「待後續填充內容」，性质均为名目型简编。本条目拟专就九地与禅定修行的实践配属——即四禅四无色定的修习相状与九地的对应——作展开，与前条之名相考辨分工互补。

九地后八地即世间禅定的八个阶次，《清净道论》称为八定（加上灭尽定则称九次第定）。其经典依据：《长阿含》《中阿含》诸经广说四禅四无色，汉译《解脱道论》（僧伽婆罗译）与《清净道论》（巴利）为完备的禅法论释；本条目术语表列 Jhāna-bhūmi（禪地），即标明其禅法定位。

## 二、文本结构与核心思想

《原文》五节为补充条目通例，兹依禅定实践展开八定与九地的配属。

**初禅（離生喜樂地）**：以离欲恶不善法为前导，具寻（定向思惟）、伺（细续察照）、喜、乐、心一境性五支。喜乐由「离」生——非外来的刺激，而是放下了负担之后的轻快，故地名「離生」。得初禅者寿终生于梵众等初禅三天。

**二禅（定生喜樂地）**：寻伺止息，内净一心，喜乐由定心自生，具内净、喜、乐、一境性四支。较之初禅的「因离得乐」，此为「因定得乐」，喜乐更细更深。

**三禅（離喜妙樂地）**：舍喜心，唯受妙乐，具舍、念、正知、乐、一境性五支。喜是激动的（如跳如踴），乐是绵密的（如浸如润）；至此激动止息，世间之乐以此为极，故经称「離喜之樂，是樂第一」。

**四禅（捨念清淨地）**：出入息灭，苦乐俱舍，具舍、念清净、不苦不乐受、一境性四支。此地为诸禅通用的转向平台——六通（神足、天耳、他心、宿命、天眼、漏尽）多依此起观，以其舍受平等、观慧最利。

**空无边处地**：超出色想，缘无边虚空而住。禅者至此破「色」的限定，然仍以虚空为所缘，空相犹存。

**识无边处地**：舍空缘识，缘无边识而住。

**无所有处地**：舍识缘无所有，作意「无所有」而住。

**非想非非想处地**：极细意识，想昧劣故称非想、想非全无故称非非想。此为三界之顶，然佛判之为「圣默然之边」而非解脱——八定皆世间法，定尽还堕。

统而观之，九地配属的实践意义在于「由粗至细、由有至无」的训练序列：从五趣杂居的散心，经四禅的色界定、四无色的无色界定，最后以灭尽定（圣者所入）为出世间转折。引文「若了九地皆苦，即求出離」正显示：禅定谱系的意义不在登顶，而在登顶后看清顶亦非究竟。

## 三、学术研究价值与争议

第一，禅支分析与意识状态研究。四禅的支分（寻伺喜乐舍）是佛教对主观状态的最细粒度描述之一；当代意识研究与禅修科学已将 jhāna 状态作为「高阶意识状态」的实验对象（如对深度禅修者脑电与自陈报告的研究），四禅与无色界定提供了现成的分层假说。争议在于实验方法能否触及「心一境性」「舍受」的内省效度。

第二，「定」与「慧」的关系是九地说的义理争点。传统判摄：八定是共世间法（外道亦能得），漏尽智是佛教独有；故九地地图的功能是「知界内」，而解脱在「观智」——此即天台止观双运、南传内观（vipassanā）与奢摩他分途的义理根源。近代缅甸内观传统甚至有「纯观乘者」之说（不深依禅定而直修观），与此正相对。

第三，名相之微异。本条目概述「欲界五趣地」与引文「五趣雜居地」之异已于前条指出；又「非想非非想处」古译作「无有顶」「有顶」（bhavāgra，三有之顶）诸名，文献对读时应知互指。藏传依《俱舍》释的禅定教学与南传《清净道论》系的业处（kammaṭṭhāna）体系在所缘与次第上各有细化，藏文根本论典不在大正藏编号体系之内，应检德格版《丹珠尔》阿毗达磨类编目。
