# 薩迦班智達量理寶藏論 · 原文

## 一、文獻概述

《量理寶藏論》（藏文 *tshad ma rigs gter*，全稱《量理寶藏論及自釋》），薩迦派第四祖**薩迦班智達·貢噶堅贊**（Sa skya Paṇḍita Kun dga' rgyal mtshan，1182–1251）造，成書於十三世紀上半葉。此論是藏傳佛教因明學（量學）史上里程碑式的著作，在陳那（Dignāga）《集量論》與法稱（Dharmakīrti）《因明七論》之後，進一步系統化並藏地化了佛教認識論與邏輯體系，被譽為打開藏傳佛教知識寶庫大門的「金鑰匙」。

**作者簡介**

薩班·貢噶堅贊，1182年生於後藏薩迦昆氏家族，自幼依止三祖扎巴堅贊廣學顯密教法。二十三歲拜印度班智達迦濕彌羅·釋迦室利跋陀羅為師，精通大小五明，獲班智達學位，成為西藏歷史上第一位被尊稱為「班智達」（paṇḍita，大學者）之人，被譽為「雪域三大文殊化身」之一。其主要著作有《量理寶藏論》《三律儀差別論》《智者入門》《薩迦格言》等。1247年與蒙古闊端汗舉行涼州會談，為西藏正式納入元朝中央政府管轄奠定基礎。1251年於涼州圓寂。

**全書結構（十一品）**

| 品 | 內容 |
|---|---|
| 入論分支 | 論前禮讚與造論目的 |
| 第一品 | 觀境（所量境之建立：所取境、照了境等） |
| 第二品 | 觀識（量識之建立：現識與比度識） |
| 第三品 | 觀總與別（總相與別相之關係） |
| 第四品 | 觀能立與遣他（立宗與遮遣之理） |
| 第五品 | 觀所詮與能詮（語言與意義之關係） |
| 第六品 | 觀聯繫（同體相屬與彼生相屬） |
| 第七品 | 觀矛盾（相違之理） |
| 第八品 | 觀定與不定（性與未定性相） |
| 第九品 | 觀現量（現量之定義與分類） |
| 第十品 | 觀自利比量（為自推理） |
| 第十一品 | 觀利他比量（為他推理：立宗、因、喻） |

薩班在量論上的核心貢獻，是以**現量**（直接知覺，藏 *mngon sum*，梵 *pratyakṣa*）與**比量**（推理，藏 *rjes dpag*，梵 *anumāna*）二量為認識的全部合法途徑，凡不能歸入此二者者，皆非正量。他在第一品中即開宗明義地建立「境」的分類體系，將所量境分為所取境、照了境、執著境等，為後續各品認識活動的展開奠定了對象論基礎。在第十一品「利他比量」中，薩班系統闡述了因明論證的三支作法——立宗、因、喻，並詳細辨析了正因與似因的區別。

此論有薩班自著的《量理寶藏論自釋》（藏文 *rang 'grel*），另有薩迦派歷代學者的註疏，如果然巴·索南僧格（Go rams pa bSod nams seng ge，1429–1489）等人的釋論。漢譯方面，索達吉堪布譯講的《量理寶藏論釋》（上下冊，中國文史出版社，2014年，ISBN 9787503444241）為目前較通行的漢文版本。藏文原版收入德格版《薩迦五祖全集》及拉卜楞寺印經院木刻本。

**歷史地位**

《量理寶藏論》不僅是薩迦派僧人必讀的因明典籍，在宗喀巴大師之前，也曾是藏傳佛教各教派僧侶通用的因明學教材。它將印度陳那、法稱的量論體系加以系統整理和藏地化發展，使藏傳佛教理論研究被納入思辨論證的邏輯軌道，推動其理論走向高度理性化、精密化。藏傳佛教格魯派「五部大論」中，《因明論》使用的是法稱大師《因明七論》中的《釋量論》為法定教材，但薩班的《量理寶藏論》在量學傳統中同樣地位崇高，被稱為藏傳因明學的基礎典籍。

## 二、核心段落選錄

薩班在論首禮讚中即點明量學的根本旨趣——以正確的認識方法破除謬見、通達真實：

> **原文**（《量理寶藏論》論首禮讚與立宗，依索達吉堪布漢譯本）：
>
> 「頂禮聖尊曼殊室利！
> 成量天尊示道者，如理詮釋量理義，
> 由彼所引恭敬心，敬禮一切善逝等。
> 量學猶如大明燈，照見一切所知法，
> 欲令沉暗盡消除，是故於此略宣說。」

> **白話對照**（上段原文之今譯）：
>
> 「頂禮聖者文殊師利菩薩！
> 成為正量的天中尊（佛陀），是指示正道的導師，
> 他如理地詮釋了量理（認識論）的義理，
> 由他引生的恭敬心，我敬禮一切善逝等聖者。
> 量學如同大明的燈炬，照見一切所知的法，
> 我希望能令沉暗（無知謬見）全部消除，
> 因此在此簡要地宣說量理。」

薩班在此將量學的功用定位為「明燈」——其作用是照見所知，破除無明。這與佛教量論的根本旨趣一致：認識論並非純粹的哲學思辨，而是解脫道的方法論基礎。在第一品「觀境」中，薩班建立了境的分類體系：

> **義理摘要**（依《量理寶藏論》第一品·觀境要義）：
>
> 所量境可分為：**所取境**（外在對象）、**照了境**（識所了別的境相）、**執著境**（分別心安立的境）等。薩班辨析的核心在於：根識所緣的對象究竟是外在實有之法，還是僅為識中顯現的相分。他繼承法稱論師的經部行中觀派立場，主張所取境在世俗層面具有客觀有效性，但勝義觀察下則無自性。

> **白話對照**（上段義理之申說）：
>
> 我們認識的對象可以分為幾個層次：直接被感官所取的外在對象、意識所了別的境相、以及分別心（概念思維）所安立的對象。薩班辨析的核心問題是：我們的眼睛看到的外在事物，究竟是真實存在於心外的法，還是僅僅是意識中顯現的影像？他繼承法稱論師的立場，主張在世俗層面上，感官對象具有客觀有效性；但在勝義觀察下，一切法無自性。這一立場使量論既不墮入極端實在論，也不墮入極端唯心論。

在論證方法上，薩班強調**正因三相**（因三相，藏 *rtags kyi tshul gsum*）的完備性——因（中詞）必須具備三個條件方可成立推理：

> **原文引述**（依《量理寶藏論》第十一品·觀利他比量，釋因三相之要義）：
>
> 「宗法所立之所立，同品周遍及遣除，
> 不定相違等諸過，遮止正因三相差。」

> **白話對照**（上段原文之今譯）：
>
> 「因（理由）之正相，須具三條：一、宗法——因須在宗（主詞）上成立；二、同品周遍——因須在有法同類者中全部具備；三、異品遣除——因須在無法同類者中全部排除。不具備或不完備此三相者，即落入不定、相違等過失，不能成為正因。」

這裡所說的「因三相」即：宗法（因在主詞上成立）、同品遍（在有法同類中皆有）、異品遍無（在無法同類中皆無），是佛教邏輯中成立有效論證的基本標準。

## 三、重要名句

> **名句一**（論首禮讚，明量學之功用）：
> 「量學猶如大明燈，照見一切所知法，欲令沉暗盡消除，是故於此略宣說。」

> **名句二**（薩班量學之根本旨趣）：
> 「凡能正確引導人心趨入所量境之識，即名為量；離此二量——現量與比量——外，別無第三量可得。」
>
> 此即薩班認識論之根本立場：以現量（直接知覺）與比量（推理）二量統攝一切有效認識，凡不屬此二者者皆非正量。此一嚴格的認識論標準，成為藏傳佛教一切辯經與宗義抉擇的共同基礎。
