# 圓覺經大疏

## 一、概述

**收錄編號**：《卍新纂續藏經》第 9 冊，X0243（本書未收入《大正藏》正藏，故無 T 編號；《大正藏》所收宗密圓覺著作為《圓覺經略疏》T1795）

**全稱**：《大方廣圓覺修多羅了義經大疏》

**別稱**：《圓覺經大疏》《大疏》

**撰者**：唐·宗密（780—841），圭峰大師，諡定慧禪師，華嚴宗五祖，兼嗣荷澤禪系

**卷數**：三卷（每卷分上中下，故通行本亦作十二卷）

**成書年代**：唐穆宗長慶三年（823）夏末完成

**所釋經本**：《大方廣圓覺修多羅了義經》一卷，唐·罽賓沙門佛陀多羅譯

《圓覺經大疏》是宗密註釋《圓覺經》系列著作中最詳盡的一部，也是他畢生用力最深的著述。宗密為《圓覺經》共作七部注解，形成一個龐大的注釋群：

- 《圓覺經大疏》三卷（十二卷）
- 《圓覺經大疏釋義鈔》十三卷（二十六卷）
- 《圓覺經略疏》二卷（四卷，即 T1795）
- 《圓覺經略疏鈔》六卷（十二卷）
- 《圓覺經大疏科》三卷
- 《圓覺經道場修證儀》十八卷
- 《圓覺經禮懺略本》四卷

宗密與此經的因緣極深。他在《圓覺經大疏》序中自述其得遇此經的震撼：「禪遇南宗，教逢斯典；一言之下，心地開通；一軸之中，義天朗耀。」——在禪法上他遇到了南宗（荷澤神會一系），在教法上他遇到了《圓覺經》；一句話之下心地豁然開通，一卷經之中義理之天朗然照耀。這兩句話恰是宗密「禪教一致」思想的個人根源。

他又在《大疏鈔》卷一之下說明造疏的過程：此經兼具法性、法相、破相三宗的經論，又攝南北頓漸兩宗的禪門，並且分同於華嚴圓教，具足悟與修的門戶；因此他「研精覃思，竟無疲厭」，後來又攻讀華嚴大部與清涼廣疏，窮本究末，並遍閱藏經，凡所聽習咨詢討論披讀的，一一對照《圓覺》以求其旨趣，直到長慶三年夏末才告完成。

在宗密之前，《圓覺經》已有四家註疏：京報國寺惟愨《疏》一卷、先天寺悟實《疏》二卷、薦福寺堅志《疏》四卷、北都藏海寺道詮《疏》三卷。但《圓覺經》之所以能在唐宋教禪之間廣為流傳，實由宗密的弘揚而起；其疏鈔遂成為後世學人依憑的要籍。

## 二、核心段落

### （一）宗密自述得遇此經的因緣

**原文（《圓覺經大疏》序）：**

> 禪遇南宗，教逢斯典。一言之下，心地開通；一軸之中，義天朗耀。

**白話對照：**

在禪法上，我遇到了南宗的宗旨；在教法上，我遇到了《圓覺》這部經典。在一句話的當下，心地豁然開通；在這一卷經文之中，義理之天朗然照耀。

這四句是宗密全部思想的個人起點。「禪遇南宗」指他嗣法於荷澤神會系（遂州道圓門下），「教逢斯典」指他讀《圓覺》而契悟。禪與教在他個人的悟道經驗中原本一體，這就是他日後畢生倡導「禪教一致」的根據。

### （二）論此經的判釋地位

**原文（《圓覺經大疏鈔》卷一之下）：**

> 此經具法性、法相、破相三宗經論，南北頓漸兩宗禪門，又分同華嚴圓教，具足悟修門戶。

**白話對照：**

這部經兼具法性宗、法相宗、破相宗這三宗的經論義理，也涵攝了南宗與北宗、頓門與漸門這兩系的禪門宗旨，而且它分同於華嚴的圓教，具足了「悟」與「修」兩方面的門戶。

宗密以此為《圓覺經》定位：它是一部能夠會通教門三宗、禪門兩系的樞紐性經典，這正是他選擇以此經為畢生註釋對象的理由。

### （三）論經典真偽的判準

**原文：**

> 然入藏諸經，或失譯主，或無年代者亦多。古來諸德，皆但以所詮義宗定其真偽矣。

**白話對照：**

然而收入藏經的諸經之中，有的失去了譯主的記載，有的沒有年代可考，這種情況本來就很多。自古以來的諸位大德，都只是依據經典所詮顯的義理宗旨來判定它的真偽罷了。

這是宗密回應《圓覺經》譯出年代不明之疑時所立的判準。《開元釋教錄》卷九早已記載「此經近出，不委何年」，但同時又說「且弘道為懷，務甄詐妄；但真詮不謬，豈假具知年月耶」。宗密承此立場，主張以義理而非文獻考據定經典真偽——這一「重義理甚於重考據」的傾向，是唐宋解經學的主流觀念。（近代胡適、呂澂及日本學界則多以文獻學方法判此經為中土撰述，立場恰與之相反，此點宜並存而觀。）

### （四）所釋經文：圓覺法門的總綱

**《圓覺經》文殊章原文：**

> 善男子！無上法王有大陀羅尼門，名曰圓覺，流出一切清淨真如、菩提、涅槃及波羅蜜，教授菩薩。一切如來本起因地，皆依圓照清淨覺相，永斷無明，方成佛道。

**白話對照：**

善男子！無上的法王擁有一個大總持法門，名叫「圓覺」，從中流出一切清淨真如、菩提、涅槃以及諸波羅蜜，用來教授菩薩。

一切如來最初發起的因地修行，都是依憑圓滿照徹的清淨覺相，永遠斷除無明，才成就佛道的。

此段是《圓覺經》全經的宗趣所在，也是宗密判此經為「一乘顯性教」的根本依據。

### （五）所釋經文：無明如空華

**《圓覺經》原文：**

> 云何無明？善男子！一切眾生從無始來，種種顛倒，猶如迷人四方易處，妄認四大為自身相，六塵緣影為自心相；譬如病目，見空中華及第二月。
>
> 善男子！空實無華，病者妄執。由妄執故，非惟惑此虛空自性，亦復迷彼實華生處。由此妄有輪轉生死，故名無明。

**白話對照：**

什麼是無明呢？善男子！一切眾生從無始以來，有種種顛倒，就像迷路的人把四方的方位弄錯了一樣：虛妄地認取地水火風四大為自己的身相，認取色聲香味觸法六塵的緣影為自己的心相。這就好比眼睛有病的人，看見虛空中有花朵，又看見第二個月亮。

善男子！虛空中實在沒有花朵，是害病的人虛妄地執取罷了。由於這種虛妄執取的緣故，不僅迷惑了虛空本身的自性，同時也迷失了那真實花朵所生之處。由此便虛妄地有了生死輪轉，所以叫做「無明」。

### （六）所釋經文：無明本無自體

**《圓覺經》原文：**

> 善男子！此無明者，非實有體。如夢中人，夢時非無，及至於醒，了無所得。如眾空華，滅於虛空，不可說言有定滅處。何以故？無生處故。
>
> 一切眾生於無生中妄見生滅，是故說名輪轉生死。

**白話對照：**

善男子！這個無明並不是真實地有其自體。就像夢中的人，在做夢的時候並非沒有（那些景象），等到醒來之後，卻了無所得。又像那些空中的幻花，消滅於虛空之中，卻不能說它有一個確定的消滅之處。為什麼呢？因為它本來就沒有生起之處。

一切眾生在本無生滅之中虛妄地見有生滅，所以說是輪轉生死。

### （七）所釋經文：淨覺隨順

**《圓覺經》原文：**

> 彼知覺者，猶如虛空；知虛空者，即空華相；亦不可說無知覺性。有無俱遣，是則名為淨覺隨順。

**白話對照：**

那能知能覺的，猶如虛空一般；而那執著「我知道這是虛空」的，本身就又成了空華之相。然而也不可以說沒有這知覺之性。

把「有」與「無」兩邊一併遣除，這才叫做「淨覺隨順」（隨順清淨覺性）。

這是《圓覺經》最精微之處，也是宗密疏中著墨最深的段落之一：既不可執有覺性，亦不可撥無覺性，雙遣兩邊方為隨順。

### （八）所釋經文：知幻即離

**《圓覺經》普賢章原文：**

> 善男子！一切眾生種種幻化，皆生如來圓覺妙心，猶如空華從空而有；幻華雖滅，空性不壞。眾生幻心，還依幻滅；諸幻盡滅，覺心不動。
>
> ……知幻即離，不作方便；離幻即覺，亦無漸次。

**白話對照：**

善男子！一切眾生的種種幻化，都生自如來的圓覺妙心，就像空中幻花從虛空而顯現一樣；幻花雖然消滅了，虛空之性卻不曾毀壞。眾生的幻心，也還是依著幻法而消滅；諸幻盡滅之後，那覺心卻如如不動。

……了知是幻，當下就離；不必另作什麼方便。離了幻，當下就是覺；也沒有什麼漸次階級。

「知幻即離，不作方便；離幻即覺，亦無漸次」十六字，是《圓覺經》流傳最廣的名句，也是宗密會通禪門頓悟說的關鍵經證。

## 三、名句

**其一**

> 禪遇南宗，教逢斯典。一言之下，心地開通；一軸之中，義天朗耀。

在禪法上遇到南宗，在教法上遇到這部經；一句話之下心地豁然開通，一卷經之中義理之天朗然照耀。

這是宗密的夫子自道，也是理解他全部著述動機的鑰匙。中國佛教史上「禪教一致」的主張並非始於宗密，但唯有在宗密這裡，它不是調和折衷的策略，而是一次真實悟道經驗的理論化——禪與教在他的開悟當下本就是同一件事。此語出《圓覺經大疏》序，後世論宗密者無不徵引。

**其二**

> 古來諸德，皆但以所詮義宗定其真偽矣。

自古以來的諸位大德，都只是依據經典所詮顯的義理宗旨來判定它的真偽。

此語標示了傳統解經學的根本立場：判定一部經是否為佛說，依據的不是譯出年代與譯主的文獻記載，而是其義理是否契合佛法。這一立場在近代遭到文獻考據學的顛覆（《圓覺經》今多被視為中土撰述），但它本身作為一種詮釋學態度，仍值得注意——它所關心的是「真理」而非「真跡」。

## 四、術語表

| 術語 | 說明 |
|-----|------|
| **圓覺** | 圓滿的靈覺、圓滿覺性。為如來藏、真如、佛性、法界的別名。裴休謂「圓滿之靈覺也」。 |
| **大陀羅尼門** | 大總持法門。陀羅尼意為總持，能總攝一切法、持一切義。經中以「圓覺」為此大陀羅尼門之名。 |
| **神通大光明藏** | 經首佛所入的三昧境界，是諸佛眾生清淨寂滅、平等圓滿不二所現的淨土。 |
| **空華** | 眼病者所見的虛空之花，本無實體。喻無明妄見所現的生死輪迴之相。 |
| **第二月** | 眼病者所見的第二個月亮，喻由妄執而生的虛假影像。 |
| **淨覺隨順** | 遣除「有」「無」兩邊之執而隨順清淨覺性。 |
| **知幻即離** | 了知諸法如幻，當下即離；不須另設方便。《圓覺經》頓門的核心表述。 |
| **三種淨觀** | 奢摩他（寂止）、三摩缽提（如幻觀）、禪那（寂滅觀）。經中所說的三種修行方便。 |
| **二十五輪** | 由三種淨觀單修、齊修、前後互修所開出的二十五種清淨定輪。見〈辯音章〉。 |
| **四病** | 作病、任病、止病、滅病。求圓覺者應離的四種修行偏失。見〈普覺章〉。 |
| **四種隨順覺性** | 凡夫隨順覺性、未入地菩薩隨順覺性、已入地菩薩隨順覺性、如來隨順覺性。見〈清淨慧章〉。 |
| **法性／法相／破相三宗** | 宗密的教門判釋。法性宗顯真心，法相宗辨萬法唯識，破相宗遣一切相。他認為《圓覺》兼具三宗。 |
| **頓漸／南北兩宗** | 禪門的判別。南宗主頓、北宗主漸。宗密認為《圓覺》攝二宗禪門。 |
| **疏／鈔／科** | 註釋體裁。「疏」釋經，「鈔」釋疏，「科」為科判分章的綱目表。宗密圓覺著作三者兼備。 |
