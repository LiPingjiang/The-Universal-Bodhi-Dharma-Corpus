# 部派律典比較研究 — 学术解读

## 一、文献背景与成书

本目录为部派律藏的比较研究档案。部派佛教时期，佛陀灭度后百余年，优婆鞠多门下弟子因对戒律的理解不同，将原始律藏分为五部。据《四分律疏》卷一所载：「优婆鞠多有五弟子，各执一见，以为楷准，至传圣教不能均融齐一，于是离分，遂为五典。」

## 二、文本结构与核心思想

诸部广律皆具「经分别」（戒条及制戒因缘）与「犍度」（僧团制度）两大板块，比较研究的核心维度有四：

1. **戒条数目**：比丘戒从《四分律》的二百五十戒、《五分律》的二百五十一戒，到《僧祇律》的二百一十八条、巴利律的二百二十七戒，出入本身即是分派层位的指标。
2. **犍度组织**：《僧祇律》以「杂诵跋渠」统摄制度，巴利律以大品小品分犍度，《四分律》立二十犍度——组织方式的差异反映各部编辑史。
3. **制戒因缘的异文**：同一戒条的缘起故事诸律详略互异，为「律藏文献层」分析提供样本。
4. **亲缘谱系**：比对结果显示《五分律》与巴利律最近，《十诵律》与《根本有部律》最似，为部派谱系重建提供文献学基础。

## 三、学术研究价值与争议

1. **平川彰《律藏研究》**：以戒条与犍度的组织分析为方法，论证律藏成立与部派分化的对应关系，是比较律藏学奠基之作；其结论（如「摩诃僧祇律保留古形」之评估）后续不断被修正。
2. **印顺《原始佛教圣典之集成》**：系统比较汉巴诸律，论究原始律藏的集成过程，为汉语学界标杆。
3. **梵本残卷的价值**：中亚出土的根本说一切有部律等梵文写本（经 Schopen 等学者整理）显示，汉译律典可与原典直接对勘，修正了单纯依赖汉译的早期结论。
4. **「原始律藏」能否复原**：诸律的「最小公倍数」是否即原始形态，学界立场分歧；比较研究的成果同时也标示了方法论的限度。
