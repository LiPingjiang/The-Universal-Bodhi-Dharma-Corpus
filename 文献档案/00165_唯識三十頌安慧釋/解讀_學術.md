# 唯识三十颂安慧释 — 学术解读

## 一、文献背景与成书

《唯识三十颂》（Triṃśikā）为世亲（Vasubandhu）晚年总结其唯识思想的三十首偈颂，约成书于5世纪。世亲造颂后未及自注即去世，其后印度有十大论师（护法、德慧、安慧、亲胜、难陀、净月、火辨、胜友、胜子、智月）分别为之作释。玄奘汉译系统以护法释为主糅译成《成唯识论》（T1586，译于显庆四年前后），而安慧（Sthiramati，约6世纪）的释论在汉地未传，仅存梵本与藏译——《安慧释》（Triṃśikāvijñaptibhāṣya）的梵文写本于20世纪初经法国学者西尔万·列维（Sylvain Lévi）在尼泊尔发现并校刊出版，是十大论师注释中唯一梵本存世的一部，也是安慧学派文献研究的基石。其藏译收入丹珠尔，历代藏传佛教学者亦多有研习。

安慧生平记载零散，学界一般认为其活跃于6世纪，师承德慧一系，是"无相唯识"（或译"虚妄唯识"）路线的代表人物，与护法系的"有相唯识"形成印度唯识学后期最重要的两大阵营。

## 二、文本结构与核心思想

释论依三十颂展开，其义理骨架为：

其一，**"由假说我法，有种种相转，彼依识所变，此能变唯三：谓异熟、思量、及了别境识"**——开篇即立唯识宗旨："我"与"法"皆是假说（安慧释：我法非实有，唯是识上所现似我似法之相），能变的识只有三类：异熟识（阿赖耶识）、思量识（末那识）、了别境识（前六识）。

其二，识变理论的三性解释：一切法唯识所现，依他起性的分别心"转似"见分与相分。

其三，**安慧的"一分说"**是其标志性立场：识体转似见相二分，而见相二分同属遍计所执（非有），唯自证分（识之自体）是依他起（是有）——此为安慧异于护法"四分说"（相分、见分、自证分、证自证分均属依他起）的关键分歧。

其四，唯识性（真如）与转依：释末段依颂文阐明唯识实性及由伏断二障而证转依的行果。

## 三、学术研究价值与争议

研究价值方面，《安慧释》梵本的存世使它成为印度唯识学研究最可靠的一手材料——相较《成唯识论》的"糅译十家"（以护法为主、诸师说难以干净剥离），安慧释呈现的是单一论师的完整体系。横山纮一、长尾雅人等日本学者围绕安慧思想有系统研究；西方学界（如 Lambert Schmithausen 的阿赖耶识研究）广泛利用本释的梵文材料。护法系与安慧系的对照，构成重建印度唯识学内部谱系的主轴。

争议问题包括：（1）一分说与四分说之争的实质——见相二分是否属于依他起的争论，究竟是本体论分歧还是"言诠层面"的分歧，学界有不同判读；（2）安慧释与《唯识二十论》释及《中边释》等署名安慧文献的作者同一性问题——"一个安慧还是多个安慧"，是唯识文献学的著名公案；（3）汉地唯识（玄奘—窥基系统以护法为正义）与藏传唯识（多依安慧—律宗一系"随理行唯识"）的对立，使安慧释成为两大佛教思想传统分流的重要参照点。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 三能变 | 阿赖耶识（异熟）、末那识（思量）、前六识（了别境） |
| 一分说 | 安慧主张：唯自证分属依他起，见相二分为遍计执 |
| 自证分（svasaṃvitti） | 识自我觉知的自体 |
| 遍计所执 | 凡夫增益的虚妄相 |
| 依他起 | 依因缘而起的识之显现 |
| 转依（āśraya-parāvṛtti） | 舍染得净的根本转变 |
