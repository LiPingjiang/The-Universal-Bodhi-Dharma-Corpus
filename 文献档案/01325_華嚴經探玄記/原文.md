# 華嚴經探玄記

## 一、概述

**大正藏編號**：T1733（《大正新脩大藏經》第 35 冊）

**全稱**：《華嚴經探玄記》，又稱《華嚴探玄記》《探玄記》《華嚴經疏》

**撰者**：唐·法藏（643—712）述，署名「魏國西寺沙門法藏述」

**卷數**：二十卷

**所釋經本**：東晉佛陀跋陀羅所譯《六十華嚴》（晉譯華嚴，三十四品）

《華嚴經探玄記》是華嚴宗三祖法藏（賢首大師）註釋《六十華嚴》的代表作，體例上模仿其師智儼的《華嚴經搜玄記》而作，是華嚴宗教義體系的集大成之作。全書開為十門：一、教起所由；二、藏部所攝；三、立教差別；四、教所被機；五、能詮教體；六、所詮宗趣；七、釋經題目；八、部類傳譯；九、文義分齊；十、隨文解釋。前九門為「懸談」，總論全經綱宗；第十門則逐品逐文疏釋經義。

此書在思想史上的關鍵地位，在於其卷一所立的「新十玄」。法藏早年在《華嚴一乘教義分齊章》（五教章）中沿用智儼《一乘十玄門》的說法，學界稱為「古十玄」；至《探玄記》則加以改訂，形成「新十玄」，後為四祖澄觀全盤承用，成為華嚴宗事事無礙法界的定型表述。

歷代註疏繁多，有尊玄《探玄記鈔》、凝然《探玄記洞幽鈔》、普寂《華嚴經探玄記發揮鈔》、芳英《南紀錄》、秀存《講義》、雲溪《會錄》等，多出於日本華嚴學者之手。

## 二、核心段落

### （一）歸敬頌

**原文：**

> 歸依大智海　十身盧舍那
> 充滿諸法界　無上大慈尊
> 方廣離垢法　圓滿解脫輪
> 普賢文殊等　海會大菩薩
> 我在具縛地　悕心大法門
> 唯願見加哀　令增念智力
> 開此祕奧藏　廣益於自他
> 願令法久住　傳燈報佛恩

**白話對照：**

我皈依那如大智慧之海一般的、具足十身的盧舍那佛——他遍滿一切法界，是無上的大慈之尊。我皈依方廣無垢的正法，皈依那圓滿的解脫法輪。我皈依普賢、文殊等華嚴海會中的諸大菩薩。

我自身尚處在被煩惱繫縛的凡夫地位，卻仰慕嚮往這廣大的法門。唯願諸佛菩薩垂哀加被於我，使我的憶念力與智慧力得以增長，讓我能開顯這部經祕密深奧的寶藏，廣泛地利益自己與他人。願正法能夠久住世間，燈燈相傳，以此報答佛陀的深恩。

### （二）序文：法性難思與大教之興

**原文：**

> 夫以法性虛空，廓無涯而超視聽；智慧大海深，無極而抗思議。眇眇玄猷，名言罕尋其際；茫茫素範，相見靡究其源。但以機感萬差，奮形言而充法界；心境一味，泯能所而歸寂寥。體用無方，圓融叵測。於是無像現像，猶陽谷之升太陽；無言示言，若滄波之傾巨壑。

**白話對照：**

法性猶如虛空，空曠得沒有邊際，超越了眼見耳聞的範圍；智慧猶如大海，深邃得沒有窮盡，抗拒著思慮議論的測度。那幽遠的玄妙義理，用名相言語很難探尋到它的邊際；那浩茫的本然法則，靠形相知見無法窮究它的根源。

然而，只因眾生的根機感應千差萬別，佛便奮起形相與言教而充滿整個法界；而在心與境本是一味的層面上，則泯除能取所取的對立而歸於寂靜。法性的體與用沒有固定的方所，其圓融的境界不可測度。於是，本無形像的法性卻示現形像，就像太陽從東方暘谷升起一般；本無言說的真理卻開示言說，就像滄海之波傾注入巨大的深壑一般。

### （三）序文：華嚴經的境界

**原文：**

> 《華嚴經》者，斯乃集海會之盛談，照山王之極說。理智宏遠，盡法界而窮真源；浩汗微言，等虛空而被塵國。於是無虧大小，潛巨剎以入毫端；未易鴻纖，融極微以周法界。故以因陀羅網，參互影而重重；錠光玻瓈，照塵方而隱隱。一即多而無礙，多即一而圓通。攝九世以入剎那，舒一念而該永劫。

**白話對照：**

《華嚴經》這部經典，是匯集華嚴海會盛大法談的記錄，是如日照須彌山王般最究竟的說法。它的義理與智慧宏大深遠，窮盡整個法界而直探真如本源；它那浩瀚無際的微妙言教，廣大如同虛空而普被微塵數的國土。

因此，它不虧損大與小各自的本相，卻能把廣大的佛剎隱入一根毫毛的尖端；不改易巨大與微細各自的分限，卻能讓一粒極微塵融通遍及整個法界。所以就像帝釋天的因陀羅寶網，珠珠交參互映，重重無盡；又像明燈與玻璃寶，映照微塵世界而光影隱隱交錯。

一就是多而彼此無礙，多就是一而圓融貫通；能收攝九世時劫而納入一剎那，能舒展一念之心而涵蓋永恆長劫。

### （四）開章十門

**原文：**

> 將釋此經，略開十門：一、明教起所由；二、約藏部明所攝；三、顯立教差別；四、簡教所被機；五、辨能詮教體；六、明所詮宗趣；七、具釋經題目；八、明部類傳譯；九、辨文義分齊；十、隨文解釋。

**白話對照：**

將要解釋這部經，大略開立十個門類：第一，闡明此教興起的緣由；第二，就三藏與部類判定此經的歸屬；第三，顯示各家立教判釋的差別；第四，簡別此教所攝受的根機；第五，辨明能夠詮表教法的體性；第六，闡明所詮顯的宗旨趣向；第七，完整解釋經題的名目；第八，說明此經的部類與傳譯源流；第九，辨析文句與義理的分限；第十，隨順經文逐段解釋。

### （五）教起所由

**原文：**

> 初教起所由者，先總辨，後別顯。總者，夫大教之興，因緣無量。故《智論》之初，廣辨般若教起因緣：如須彌山，不以無事及小因緣而能令動；佛亦如是，大因緣故而有所說。《法華》亦云：如來為一大事因緣故出現於世，所謂開示悟入佛知見等。

**白話對照：**

第一門「教起所由」，先作總的辨明，後作分別的顯示。就總的方面說：大教的興起，其因緣無量無邊。所以《大智度論》開篇便廣泛辨析般若教興起的因緣，說：須彌山不會因為沒有緣故或微小的因緣而被撼動；佛也是如此，必定是有重大的因緣才有所宣說。《法華經》也說：如來是為了一件大事因緣才出現於世間的，這件大事就是為眾生開啟、指示、令其悟入佛的知見。

### （六）新十玄門

**原文：**

> 一、同時具足相應門；二、廣狹自在無礙門；三、一多相容不同門；四、諸法相即自在門；五、隱密顯了俱成門；六、微細相容安立門；七、因陀羅網法界門；八、託事顯法生解門；九、十世隔法異成門；十、主伴圓明具德門。

**白話對照：**

第一，一切諸法在同一時中具足圓滿、彼此照應；第二，廣大與狹小自在互現而不相妨礙；第三，一與多互相含容而各自的相狀仍歷然可辨；第四，一切諸法就體性而言相即自在；第五，隱蔽與顯了同時並存而俱得成就；第六，即使極微細之處也能相容一切法而各安其位；第七，如帝釋天因陀羅寶網般重重影現、無有窮盡；第八，寄託具體事相以顯示法門、令人生起悟解；第九，過去現在未來十世彼此隔別而又互相成就；第十，任舉一法為主則餘法皆為伴，主伴圓明而具足一切功德。

## 三、名句

**其一**

> 一即多而無礙，多即一而圓通。攝九世以入剎那，舒一念而該永劫。

一就是多而彼此無礙，多就是一而圓融貫通；收攝九世時劫納入一剎那之中，舒展一念之心涵蓋無盡的永恆長劫。此四句是《探玄記》序文中最精煉的華嚴法界觀表述，將空間上的「一多相即」與時間上的「延促自在」並舉，成為後世稱述華嚴圓融思想時最常引用的文句。

**其二**

> 無虧大小，潛巨剎以入毫端；未易鴻纖，融極微以周法界。

不虧損大小各自的本相，卻能讓廣大的佛國剎土隱入一根毫毛之端；不改易巨大與微細的分限，卻能讓一粒極微塵融通周遍整個法界。此句道出華嚴「事事無礙」的關鍵：相即相入並非取消差別，而是在保持差別本位的前提下互攝互融，這正是華嚴圓教區別於一般空觀的所在。

## 四、術語表

| 術語 | 說明 |
|-----|------|
| **探玄** | 探究幽玄之義。書名取意於探索《華嚴經》深奧難思的玄旨，與其師智儼《搜玄記》的「搜玄」相呼應。 |
| **十門** | 法藏疏釋經典的體例，即教起所由、藏部所攝、立教差別、教所被機、能詮教體、所詮宗趣、釋經題目、部類傳譯、文義分齊、隨文解釋。前九門為懸談，第十門為正釋。 |
| **十玄門** | 顯示事事無礙法界之相的十個法門，亦稱「十玄緣起」。有古十玄（智儼《一乘十玄門》及法藏《五教章》所立）與新十玄（法藏《探玄記》所立、澄觀承用）之別。 |
| **同時具足相應門** | 十玄之首，亦為總門。指十方三世一切諸法無有前後始終之別，同時具足圓滿、彼此照應，共成一大緣起。其餘九門皆為此門之別義。 |
| **因陀羅網** | 帝釋天宮的寶網，網上每一結繫一寶珠，珠珠互相映現、影中復現影，重重無盡。華嚴用以譬喻諸法相即相入、重重無盡的法界緣起。 |
| **十世隔法異成** | 過去、現在、未來三世各具三世成九世，九世總攝為一念成十世。十世彼此隔歷分明而又互相含攝成就。 |
| **主伴圓明具德** | 任舉一法為主，則其餘一切法皆隨之為伴，主伴互為，圓滿明現而具足一切功德。 |
| **盧舍那** | 梵語 Vairocana（毘盧遮那）在《六十華嚴》中的譯名，意為「光明遍照」，是《華嚴經》的教主，代表佛的法身與報身。 |
| **法性** | 諸法的真實體性，即真如。序文以「虛空」喻其廓然無涯、超越見聞。 |
| **文義分齊** | 十門之第九，辨析經文文句與義理的層次分限。《探玄記》即在此門中詳論十玄、六相等華嚴核心教義。 |
| **六十華嚴** | 東晉佛陀跋陀羅所譯《大方廣佛華嚴經》六十卷本，又稱晉譯華嚴，計三十四品、七處八會。《探玄記》所疏即此本。 |

## 五、相關文獻

**同為法藏所撰的華嚴著作**

- 《華嚴一乘教義分齊章》（T1866，四卷）：華嚴判教理論的系統論述，即「五教章」，其中所立為「古十玄」，可與本書「新十玄」對照。
- 《華嚴金師子章》（T1880 系列）：法藏為武則天說法所作，以殿前金獅子為喻，最簡明地闡述十玄、六相與法界緣起。
- 《華嚴經旨歸》《華嚴經義海百門》《華嚴策林》《華嚴發菩提心章》：法藏闡發華嚴義理的短篇著作。
- 《華嚴經傳記》（五卷）：法藏所集，記述《華嚴經》的部類、隱顯、傳譯與弘傳史事。
- 《大乘起信論義記》（T1846）：法藏以華嚴立場註釋《起信論》的代表作。

**本書所依與所承**

- 《大方廣佛華嚴經》六十卷（T278）：東晉佛陀跋陀羅譯，本書所疏的經本。
- 智儼《大方廣佛華嚴經搜玄分齊通智方軌》（《搜玄記》，T1732）：法藏之師所撰，本書體例所仿。
- 杜順《華嚴法界觀門》（T1880 附）：華嚴觀行的源頭。
- 世親《十地經論》：地論宗根本論典，華嚴「六相」義的出處。

**後續發展**

- 澄觀《大方廣佛華嚴經疏》（T1735，六十卷）：疏釋《八十華嚴》，全面承用《探玄記》的新十玄。
- 澄觀《大方廣佛華嚴經隨疏演義鈔》（T1736，九十卷）：澄觀自釋其疏。
- 宗密《原人論》《禪源諸詮集都序》：華嚴五祖對法藏教判的繼承與發展。
