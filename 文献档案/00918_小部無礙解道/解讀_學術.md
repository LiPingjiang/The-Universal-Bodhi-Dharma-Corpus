# 小部无碍解道 — 学术解读

## 一、文献背景与成书

《無礙解道》（巴利语 *Paṭisambhidāmagga*，音译波致参毗陀，英译 Path of Discrimination）是南传巴利三藏《小部》（Khuddaka Nikāya）的第十二部经典。传统认为此书由佛陀弟子舍利弗（Sāriputta）尊者所造，但现代学者对其作者问题普遍存疑，更倾向将其视为部派时期逐渐形成的论书。它的归属本身就是巴利文献学的一个有趣案例：巴利传统将其归入经藏的小部，部分学派则主张划归论藏，本档案原文径直称其「性質介於經藏與論藏之間」。

从文献史看，《无碍解道》被佛教研究者视为后期《论藏》中《法集论》《分别论》等阿毗达磨论书的先驱，属于「观行论」一类——即以指导止观（奢摩他-毗钵舍那）修习实践为主要内容的文献。其部分篇章以「如是我聞」开头，形式上兼具经、论两重特点，这种经体与论体的混合面貌，恰是它处于阿毗达磨形成前夜的证据。本经有摩诃那摩（Mahānāma）所造的注释书《显扬正法》（*Saddhammappakāsinī*）。

## 二、文本结构与核心思想

全书共三十章，分为三品，每品十论：大品（Mahā-vagga）、双结品（Yuganaddha-vagga）、慧品（Paññā-vagga），其中大品为全经核心。所含《智论》《见论》《入出息念论》《毗钵舍那论》《慈论》等章节，详细阐释了较古老典籍中仅约略提及的名相与教法，对道智、无常随观智、苦随观智、无我随观智、慧等概念进行系统分析，兼具修行指导与经义印证双重功能。

其核心思想可以循原文所录两段巴利语看到脉络。其一，《智论》开首列出三种智——随念过去智、随念未来智、随念现在智，并以「Yathā bhūtaṃ ñāṇaṃ ditthi visuddhiyā」（如實之智，由見清淨而得）点明全经修学纲领：智（ñāṇa）的修习是基础，由智而入见、由见而入慧，层层深入。其二，《毗钵舍那论》给出典型的观行次第：「Rūpaṃ aniccaṃ…」（色無常、受無常、想無常、行無常、識無常），继而「Evaṃ passanto sammā passati」（如是見者，名為正見）——从正见、厌离、离贪到解脱，最后「解脫已，知解脫」。「厭離故離貪，離貪故解脫」这一链条在巴利三藏中反复出现，而《无碍解道》将其扩展为精细的观智阶位体系，成为后世南传观行传统的骨架。

## 三、学术研究价值与争议

研究价值方面：（1）《无碍解道》是巴利阿毗达磨形成史上的关键环节，其系统化的随观智分类直接影响了《清净道论》的十六观智体系，是理解南传止观文献层累演进的枢纽；（2）它保存了大量早期佛教禅修术语的最早系统化解释，如入出息念十六胜行等，为禅修史研究提供基础文本；（3）其经论之间的过渡形态，是判断巴利三藏各层文献相对年代的内部标尺；（4）《慈论》等章对四无量心的分析，是南传慈心禅传统的经典依据。

争议与问题方面：（1）舍利弗作者说是传统 attribution（归属于）而非可证史实，学界对其成书年代估计从佛陀去世后一两个世纪到更晚不等；（2）藏摄归属之争——归经藏抑或归论藏——反映了上座部内部对「何为佛说」边界的不同认定，此争论至今没有定论；（3）书中部分概念（如「无碍解」四种的展开）与后期阿毗达磨定型文本之间是先驱关系还是平行发展，涉及巴利论书谱系的整体重构，尚待细部研究。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 无碍解道（Paṭisambhidāmagga） | 小部第十二部，南传观行论先驱，意为「无碍解之道」 |
| 波致参毗陀 | 《无碍解道》的音译名 |
| 智（ñāṇa） | 观智，对诸法实相的如实了知，全经修学之基础 |
| 慧（paññā） | 般若智慧，由智入见、由见入慧的更高阶层 |
| 毗钵舍那（vipassanā） | 观，对无常苦无我的如实观察 |
| 奢摩他（samatha） | 止，禅定的修习 |
| 厌离（nibbidā） | 由正见生起的对世间法的如实厌倦 |
| 离贪（virāga） | 厌离所引生的贪欲止息 |
| 解脱（vimutti） | 离贪之后的果，解脱已自知解脱 |
| 显扬正法（Saddhammappakāsinī） | 摩诃那摩造《无碍解道》注释书 |
