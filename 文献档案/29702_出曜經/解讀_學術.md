# 出曜經 — 学术解读

## 一、文献背景与成书

《出曜經》（Udānavarga），凡三十卷，姚秦竺佛念译，收《大正藏》第四册（T212）。竺佛念为凉州沙门，中国译经史上最早的本土译师之一，译风质朴直译，保留较多原文语序。经题「出曜」之含义，通行之解认为是梵语 udāna（优陀那、无问自说）的音译之变，指佛陀不待请问、有感而发的偈颂。

本经属说一切有部传承的偈颂集，与巴利文《法句經》（Dhammapada，423颂）、梵文《法集要頌經》（Udānavarga，约千颂）属同一文学传统。汉译同族文本尚有《法句經》（T210，吴维祇难等译）、《法句譬喻經》（T211）、《法集要頌經》（T213，宋天息灾译）。《出曜經》篇幅最大，凡三十三品（或作三十四品），且每颂附因缘叙事，说明佛陀于何时何地对何人宣说此颂。

## 二、文本结构与核心思想

本经结构为「偈颂＋因缘」：每品先列颂偈（gāthā），后附因缘故实，兼具「法句」与「本缘」两种文体。原文档所列品目包括：无常品、教学品、多闻品、笃信品、戒品、慎品（不放逸）、惟念品、梵志品、道品、双要品等三十余品，涵盖无常、苦、空、无我、业报、修行、智慧等主题。

核心思想可概括为「无常观」与「不放逸」的双重强调：

其一，**无常观**。无常品开宗明义：「是日已過，命則隨減，如少水魚，斯有何樂？當勤精進，如救頭燃，但念無常，慎勿放逸。」以少水之鱼、驶流之河、日出之露为喻，反复强调有为法的无常——这不是悲观主义，而是精进的动力。

其二，**生命的质量论**。教学品反复对比：「若人壽百歲，邪學志不善，不如生一日，精進受正法」——生命的价值不在长度而在质量。

其三，**戒为甘露道**。戒品云：「戒為甘露道，放逸為死徑」「持戒者最樂，心無邪惡念」——持戒不是束缚，而是内在无忧的自由。梵志品「真梵志」以心净无垢而非种姓出身为标准，体现佛教对印度种姓制度的批判。

## 三、学术研究价值与争议

研究价值：本经是汉译「法句」传统中篇幅最大、因缘叙事最丰富的译本，是研究中古汉译偈颂的关键语料；其「颂＋因缘」结构是研究佛典注释文学形成的珍贵案例；与巴利《法句經》及注、梵文 Udānavarga（Bernhard、Bechert 等校勘本）的三角对勘，是佛教文献比较研究的经典课题——同一偈颂在不同传承中归属人物、因缘不同，反映部派叙事的分化；竺佛念译文的古奥词汇对研究中古汉语佛典语言有重要价值。其「是日已過」诸颂进入后世寺院课诵，又是研究中国佛教日常修行文本的绝佳线索。

争议问题：其一，「出曜」是否即 udāna 音译，学界有异说；其二，本经因缘叙事与巴利《法句經注》的部分平行、部分独立，其传承谱系如何重建仍在讨论；其三，经中偶见的「菩萨」用例与大乘色彩的浓淡，是判断其编集层位的关键，意见不一；其四，三十三品抑或三十四品的品数异说，牵涉译出时底本的完整性问题。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 出曜（Udāna） | 感兴自说之偈颂，本经梵名 Udānavarga |
| 法句（Dharmapada） | 同一偈颂传统的巴利形态 |
| 因缘（nidāna） | 每颂所附的宣说背景叙事 |
| 不放逸（apramāda） | 精勤不懈，本经核心德目 |
| 品（varga） | 主题分章，凡三十三品 |
| 梵志 | 婆罗门之称，经中重定义为心净者 |
