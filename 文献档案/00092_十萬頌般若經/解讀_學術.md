# 十萬頌般若經 — 学术解读

## 一、文献背景与成书

### 1.1 经名与定位

《十萬頌般若經》是《大般若波羅蜜多經》（梵名 Śatasāhasrikā Prajñāpāramitā）之初会的独立称呼，全经共六百卷，分为十六会，初会四百卷七十九品，相当于梵文十万颂般若。大正藏编号 T220，唐玄奘于显庆五年至龙朔三年（660-663年）在玉华宫寺译出，次年玄奘即示寂，此经实为玄奘法师最后的译经事业。

### 1.2 译者玄奘

玄奘（602-664），洛州缑氏（今河南洛阳偃师）人，唐代四大译经家之一。贞观三年（629年）西行求法，历十七年，遍游五天竺，带回梵本六百五十七部。回国后主持译场十九年，译出经论七十五部、一千三百三十五卷。《大般若经》六百卷是其译经中卷帙最为浩大的作品，玄奘以垂暮之年毅然担此大任，译毕不久即示寂。

### 1.3 版本源流

般若经类的形成经历了从短篇到巨帙的历史过程：原始般若（如《小品般若》）约公元前1世纪成立，随后扩展为中品般若（如《大品般若》），至公元3-5世纪间最终形成十万颂巨帙。玄奘的译本汇集了当时能搜集到的所有般若类梵本，其十六会中的初会与梵本《十万颂般若》对应，第二会与《二万五千颂般若》对应，第四会与《八千颂般若》对应。此外，鸠摩罗什译《摩诃般若波罗蜜经》（T223）相当于玄奘译第二会的同本异译，罗什译《金刚般若经》（T235）相当于第九会的别译。

## 二、文本结构与核心思想

### 2.1 结构概览

全经初会四百卷，以「缘起」「欢喜」「观照」等七十九品，从佛在灵鹫山说法开始，层层展开般若空观的完整体系。经中反复以「无住生心」「无所得」「无分别」等概念，破除修行者对一切法的执著。

### 2.2 核心思想：诸法性空

《大般若经》的核心思想可以概括为「诸法性空，性空幻有」八个字。一切法（物质、精神、现象、本质）皆因缘和合而生，无有恒常独立的自性。所谓「色不异空，空不异色；色即是空，空即是色」——现象与空性并非对立，而是在同一缘起过程中同时呈现。

### 2.3 般若与方便

经中不仅强调「空」的智慧，更重视「方便」的运用。菩萨修行般若波罗蜜多，并非为了证入空寂，而是以空性智慧为眼目，以方便善巧为手足，在不舍众生、不厌生死的大悲心中圆成佛道。这种「悲智双运」的菩萨道精神，是贯穿全经的主线。

### 2.4 玄则序的精义

西明寺沙门玄则为《大般若经》初会所作序文，以精炼的笔触点明了般若宗旨：「大般若经者，乃希代之绝唱、旷劫之遐津，光被人天、括囊真俗。」又云：「我之所根者想，想妄而我不存；蕴之所系者名，名假而蕴无托。故即空之谈启、亡言之理畅。」此序抓住了般若经的核心——破除我执与法执，直显空性之理。

## 三、学术研究价值与争议

### 3.1 般若文献的层累形成问题

般若经类的形成过程，一直是国际佛教学术界关注的热点。日本学者梶山雄一、美国学者Edward Conze等对此有深入研究。Conze将般若经类的发展分为四个阶段：原型期（约前100-公元100年）、扩展期（约100-300年）、后期（约300-500年）和密教化期（约500-700年）。《十万颂般若》代表了扩展期的最高成就，其繁复的铺陈不仅是修辞需要，更有特定的修行论功能。

### 3.2 玄奘译本与梵本的对勘

玄奘译本与现存梵本《十万颂般若》之间存在一定差异，这为研究印度佛教晚期文本的演变提供了重要材料。日本学者研究《大般若经》的版本传承，发现玄奘所据梵本可能属于印度西北部的某种传本，与尼泊尔流传的梵本有所不同。此问题至今仍在讨论中。

### 3.3 与早期般若经的关系

学者们关注《十万颂般若》如何从早期短篇般若扩展而来——其间增加的不仅是篇幅，更包含了大量后来融入的密教元素、菩萨行详说和佛土庄严描述。这些增补反映了印度大乘佛教从侧重智慧到悲智双运、再到融入密教元素的演变轨迹。
