# 佛教四念處研究 · 原文

## 一、概念概述

四念處（梵 catvāraḥ smṛty-upasthānāḥ，巴 cattāro satipaṭṭhānā，又譯四念住），即身念處、受念處、心念處、法念處，是三十七道品之首要科目、佛所稱「一乘道」（ekāyana-mārga）。其根本經典為《中阿含經》卷二十四〈念處經〉（T26，對應巴利《中部》第10經〈大念處經〉Mahāsatipaṭṭhāna Sutta）及《雜阿含經》卷二十四「念處相應」。《念處經》開宗明義：「有一道淨眾生，度憂畏，滅苦惱，得真法……云何為一？謂四念處。」身念處觀身（入出息、四威儀、三十二身分、不淨觀）、受念處觀樂苦捨三受之生滅、心念處觀貪瞋痴有無等心相、法念處觀五蓋、五蘊、六處、七覺支、四諦之緣起無我。四念處之總相觀是「觀身如身、觀受如受、觀心如心、觀法如法」之「如實觀」，於五蘊身心直接現觀無常、苦、無我，破淨、樂、常、我之四顛倒。部派與大乘之發展：說一切有部以四念處攝慧學；南傳上座部以四念處為內觀（vipassanā）禪修之總綱，覺音《清淨道論》（T1659? 實為近代譯出，原典Visuddhimagga）詳述其修法；大乘《大智度論》卷十九說四念處通大小乘，《瑜伽師地論》立「四種所緣境事」以念住為遍滿所緣；近代緬甸馬哈希、葛印卡內觀體系使四念處禪法重興於世界。

## 二、核心經文選錄

> **原文**（《中阿含經》卷二十四〈念處經〉，T26）：
> 「有一道淨眾生，過度憂畏，滅苦惱，得真法，得第一利，入涅槃道。云何為一道？謂四念處：身身觀念處，受、心、法法觀念處。云何身身觀念處？比丘者，行則知行，住則知住，坐則知坐，臥則知臥……正知出入，善觀分別。」

> **白話對照**：
> 有一條唯一之道能淨化眾生、度脫憂畏苦惱、證得真法涅槃，就是四念處。以「觀身如身」而言：行住坐臥、屈伸俯仰，一切動靜中了了覺知，不加詮釋、不落回憶，只是如實觀照當下的身體。這種「正知」的訓練，即是念處禪的入手處。

> **原文**（《雜阿含經》卷二十四，T99）：
> 「當住四念處：觀身不淨，觀受是苦，觀心無常，觀法無我。……若比丘離四念處者，則離如實聖法；離如實聖法者，則離聖道。」

> **白話對照**：
> 四念處對治凡夫之四種顛倒：以身為淨、以受為樂、以心為常、以法為我。觀身不淨破淨倒，觀受是苦破樂倒，觀心無常破常倒，觀法無我破我倒——四念處即是以「無常、苦、無我」之如實觀為核心的解脫訓練。

## 三、重要名句

> 「有一道淨眾生，度憂畏，滅苦惱，得真法。」（《中阿含·念處經》）

> 「若善修四念處者，則能住於不死之門。」（《雜阿含》念處相應之精神）

> 「身身觀念處，受、心、法法觀念處，是為自洲以自依，法洲以法依，不異洲不異依。」（《長阿含·遊行經》自依止之教之具體化）

> 「四念處者，三世諸佛一趣之道。」（《大智度論》會通「一乘道」之釋）

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 念處／念住（satipaṭṭhāna） | 念安住於所緣、隨觀不捨之意 |
| 身念處 | 於行住坐臥、呼吸、身分觀身之集滅 |
| 受念處 | 於苦受、樂受、捨受隨觀其生滅無常 |
| 心念處 | 觀察心之有貪無貪、有瞋無瞋、散亂專注等相 |
| 法念處 | 觀五蓋、五蘊、六入處、七覺支、四諦 |
| 一乘道（ekāyana） | 直趣涅槃之唯一道路 |
| 四顛倒 | 常、樂、我、淨四種顛倒想，念處所破 |
| 內觀（vipassanā） | 依念處隨觀諸法無常苦無我之南傳禪法 |
