# 佛教四料揀研究 · 原文

## 一、概念概述

「四料揀」即「四料簡」之異寫（「揀」「簡」古通，均為揀擇義），為臨濟義玄禪師所立的接引學人之門庭施設，出於《臨濟錄》（T1985）。本題與`05066_佛教四料簡研究`為同一法門之兩個專題：彼篇聚焦四句本身之結構與克符問答頌之解析，本篇側重臨濟「門庭施設」之整體體系——四料簡並非孤立的口訣，而是與「四賓主」「四照用」「三玄三要」「四喝」共同構成臨濟宗風的完整勘辨系統。四料簡四句為：奪人不奪境、奪境不奪人、人境俱奪、人境俱不奪（原文及逐句頌語詳`05066`篇，互見）。置於門庭整體中看：四料簡是「簡別執障」（破什麼）的總綱；四照用是「運用手段」（怎麼破）的時序組合；四賓主是「勘驗師資」（誰明誰暗）的鑒定法；三玄三要（《臨濟錄》：「一句中具三玄，一玄中具三要」）是言句本身的層次分析；「有時一喝如金剛王寶劍，有時一喝如踞地師子」之四喝則是棒喝作用之四喻。這一整套施設使臨濟禪成為晚唐五代最峻烈、最富方法自覺的教學體系，後世稱「臨濟將軍、曹洞士民」。四料簡之思想淵源，可上溯佛教「我執法執」之二執論（《成唯識論》T1585卷一「二執」義）與四句否定之中觀論法（《中論》T1563「諸法不自生」四句）；其「奪」字訣則將唯識破執之理論轉化為禪門當機之活用。

## 二、核心經文選錄

> **原文**（《鎮州臨濟慧照禪師語錄》，T1985）：
> 「我有時奪人不奪境，有時奪境不奪人，有時人境兩俱奪，有時人境俱不奪。……我有時一喝如金剛王寶劍，有時一喝如踞地師子，有時一喝如探竿影草，有時一喝不作一喝用。」

> **白話對照**：
    同一《臨濟錄》中，四料簡與四喝相連宣示，可見其為一體之施設：料簡度量學人之執（人或境），四喝則依所料簡之機而施不同之喝。金剛王寶劍之喝斷一切知見（如人境俱奪），踞地師子之喝震懾群魔（如俱奪後之全提），探竿影草之喝試探來機（如先照後用），不作一喝用之喝即喝離喝（如人境俱不奪）。

> **原文**（《臨濟錄》「三玄三要」，T1985）：
> 「一句語須具三玄門，一玄門須具三要。有權有實，有照有用。」

> **白話對照**：
    臨濟言句教學之三玄三要，與四料簡、四照用之「權、實、照、用」互相貫通：權是施設方便（奪之運用），實是究竟指歸（俱不奪之本地風光）。門庭施設之全體，皆是「權」邊事；而施設所指向處，則是不涉安排之「實」。

## 三、重要名句

> 「臨濟門庭，料簡為本；奪人奪境，俱奪俱不奪。」（禪林對臨濟教學之概括）

> 「一句中具三玄，一玄中具三要。」（《臨濟錄》）

> 「有權有實，有照有用。」（《臨濟錄》三玄三要中與四照用相攝之句）

> 「逢佛殺佛，逢祖殺祖。」（《臨濟錄》示眾——「奪」之極致的經典表述）

|---|---|
| 料揀／料簡 | 核計度量、揀別根器（異寫同義） |
| 門庭施設 | 禪師一宗接引學人之整套教學方法 |
| 三玄三要 | 一句具三玄（體中玄、句中玄、玄中玄），一玄具三要 |
| 四喝 | 金剛王寶劍、踞地師子、探竿影草、不作一喝用 |
| 權／實 | 方便施設／究竟真實 |
| 我執法執 | 執身心為我／執諸法實有，料簡所破之二執 |
| 五位君臣 | 曹洞宗正偏五位之教學，與料簡對照 |
| 全提 | 禪師全體作用、單刀直入之提持 |
