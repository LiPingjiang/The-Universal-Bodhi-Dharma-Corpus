# 藏传佛教道次第集成 — 学术解读

## 一、文献背景与成书

本档案为藏传佛教「道次第」（Lam-rim）文献系统的综述类条目，以阿底峡尊者（Atiśa，982–1054）的《菩提道燈論》为该系统的根本文本。按原档案所记，此论造于 1042 年：阿底峡应阿里王菩提光（降曲沃）之请，在托林寺撰成，全篇仅六十八颂。需要说明的文献学位置是：阿底峡入藏时值西藏佛教「后弘期」初起，教界对修行次第、显密关系众说纷纭；阿底峡此论以极简的篇幅给出一个可操作的修学次序框架，由此形成噶当派（bKa'-gdams，意为「佛语教授」），并奠定此后整个藏传佛教教学体系的范式。藏传道次第文献以藏文传写，属藏文大藏经及藏地论疏体系，不在汉文大正藏编号之列，汉译本皆为近现代译出（如原档案所引如石法师译本）。

系统的发展线索清楚可循：宗喀巴（Tsong-kha-pa，1357–1419）依《菩提道燈論》广演《菩提道次第廣論》，复摄为《菩提道次第略論》，更造《三主要道》以三颂摄尽道次第心要；格鲁派的道次第传承即由此而来。此外噶当派的教授传承在萨迦、噶举等派中亦有各自的道次第著述，构成一个跨越数百年、覆盖诸派的大型文献谱系。本集成档案即以《菩提道燈論》偈颂为核心选录。

## 二、文本结构与核心思想

《菩提道燈論》虽短，其结构设计影响深远：全论以「三士道」为骨架，将一切修行者分为三类，各配以相应的教授。「若以何方便，唯於生死樂，但求自利益，知為下士夫」——下士唯求轮回中的现世与来生安乐，修皈依、业果；「背棄三有樂，遮止諸惡業，但求自寂滅，彼名為中士」——中士厌离轮回、唯求自度，修戒定慧与四谛；「若以自身苦，比他一切苦，欲求永盡者，彼是上士夫」——上士以自苦推及一切众生之苦，发愿尽除自他一切苦，此即菩提心所摄的大乘道。

这一框架的革命性在于：它不是以教派、经典或哲学立场划分佛教，而是以修行者自身的动机与目标划分。三种人不是三种宗教，而是修道起点不同的三类根器；道的「次第」即体现为从下士道起修、逐步升进的阶梯结构。这样，人天乘、声闻缘觉乘、菩萨乘这些原本散见于各处经论的教说，被组织为一个针对同一个修道者依次通过的完整路径。

《三主要道》将此体系再压缩为三个关键指标：出离心（认识到轮回本质是苦而决意出离）、菩提心（为度一切众生而愿成佛）、空正见（依缘起性空断除轮回根本）。宗喀巴强调：无出离心则不能息灭世间贪著，无菩提心则不能入大乘道，无清净正见则不能断除轮回根本——三者缺一即不成其为完整之道。系统内外的引证亦值得注意，《菩提道燈論》引《勇施請問經》摄颂以菩提心福德之量极言其重：「假使有色者，充滿虛空界，其福猶有餘。」

## 三、学术研究价值与争议

研究价值方面：第一，道次第文献是藏传佛教教学制度化的核心证据——次第框架支撑了格鲁派学院（扎仓）的分班课程与三大寺学制，是研究宗教教育制度的经典案例；第二，《菩提道燈論》传为藏地噶当派立派之论，其文本的梵文原典、藏译与各种注疏形成完整链路，是研究十一世纪印藏佛教交流的一手材料；第三，从思想史看，道次第是把大量异质经典组织为可执行课程的成功范例，可与汉地判教传统（依判高下而非依行设施）作深刻对比。

争议与问题方面：其一，作者与文本层次——《菩提道燈論》与阿底峡另一部《菩提道燈難處釋》（藏文传本）的关系，各本之间颂文出入的校勘，学界仍有讨论；其二，「三士道」框架并非阿底峡凭空独创，其源流可以追溯到印度佛护、莲花戒乃至更早的修道次第论传统（原档案术语表亦显示相关术语的藏文对应复杂），究竟几分来自印度、几分成于藏地，需要梵藏对勘才能判断；其三，道次第对「次第不可乱」的强调与禅宗「顿悟」立场、与密续「本尊次第」之间的张力，是藏传佛教内部长期的思想议题；其四，格鲁派对道次第的解释与宁玛「大圆满」体系之间的分际，涉及两派对显密关系的不同判摄。需要说明，本档案为综述条目，以《菩提道燈論》为核心选录，未涉及道次第各派注疏的全貌，深入的版本研究须依藏文原典。

## 四、术语对照表

| 术语 | 释义 |
|------|------|
| 道次第（Lam-rim） | 藏传佛教依修行先后次序组织全部教法的文献与教学传统 |
| 菩提道燈論（Bodhipathapradīpa） | 阿底峡造，六十八颂，道次第系统的根本论典 |
| 三士道 | 下士、中士、上士的修道框架，以动机与目标划分根器 |
| 下士夫 | 唯求生死安乐、自利者，修皈依业果 |
| 中士夫 | 厌离三有、但求自寂灭者，修四谛、戒定慧 |
| 上士夫 | 以自苦比度他苦、愿尽除自他一切苦者，修菩提心与六度 |
| 菩提心（bodhicitta） | 为利一切众生而愿成佛的愿心，大乘道的入处 |
| 出离心（nges-'byung） | 决意出离轮回的涅槃之志，《三主要道》之一 |
| 空正见 | 缘起性空的清净正见，《三主要道》之一 |
| 噶当派 | 依阿底峡教授形成的派系，「噶当」意为一切佛语皆成修行教授 |
| 托林寺 | 阿底峡造论之地，西藏阿里古格王朝的佛教中心 |
