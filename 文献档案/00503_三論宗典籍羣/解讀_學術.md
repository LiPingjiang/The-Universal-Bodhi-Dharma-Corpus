# 三論宗典籍羣 — 学术解读

## 一、文献背景与成书

三论宗是中国最早的佛教宗派之一，因依《中论》《十二门论》《百论》三部论书立宗而得名。三论均由鸠摩罗什（344–413）于后秦弘始年间译出：《中论》（T1564，青目释）、《十二门论》（T1568）、《百论》（T1569，婆薮开士释）。罗什门下僧肇（《肇论》）、僧叡等弘传龙树中观之学，其学统经「摄岭僧朗—僧诠—法朗」三代相承于摄山栖霞寺，至吉藏（549–623，住嘉祥寺，世称嘉祥大师）而集大成，撰《三论玄义》《大乘玄论》《二谛义》《中观论疏》等，正式建立三论宗。吉藏殁后此宗渐衰，但其「二谛」「八不」之学为天台、华严、禅宗所吸收，成为汉传佛教义学的底层语法。本档案原文所示「阿毗达磨者，对法也。以无漏慧观四谛境，对观对向，故名对法」，揭示了论书「分别法相、断疑生信」的文体功能，正是三论作为论典之学的总纲。

## 二、文本结构与核心思想

三论宗的义理骨架可概括为四点。其一，破邪显正：三论之学的根本方法是「破而不立」——破斥一切有所得的执见（毗昙执有、成实执空、大乘执中道为实），显示无所得的正理；吉藏称「破邪即显正，借邪以显正」。其二，八不中道：依《中论》「不生亦不灭，不常亦不断，不一亦不异，不来亦不出」八不偈，显一切法缘起无自性、离八种戏论的中道实相。其三，二谛是教：「于二谛」与「教二谛」之辨——真俗二谛是佛说法的言教方便，而非两重实在的理境；「为俗故说真，为真故说俗」，二谛以「不二」为体。其四，判教学说：吉藏判「三法轮」——根本法轮（《华严》）、枝末法轮（小乘至方等诸经）、摄末归本法轮（《法华》），以《法华》会三归一为终极。本档案所选「以论议故，断疑生信，入于正理」一语，恰可概括三论作为「论议之学」的性格：以严密的辩证破除疑惑，令信入无所得之正理。

## 三、学术研究价值与争议

其一，思想史价值：三论宗是印度中观学（Madhyamaka）在中国最忠实的一次系统移植，青目释《中论》是龙树偈颂存世的极少数早期梵藏汉对照文本之一，本档案库另有《十二门论梵藏汉对照》专档可参看。其二，学术研究脉络：日本学者如山口益、梶山雄一、安井广济对中观思想史的研究，及平川彰对《大智度论》作者问题的讨论，多以三论文献为枢纽；欧美中观研究（Robinson、Huntington 等）亦以《中论》为基点。其三，争议问题：（1）吉藏之学与摄山僧朗所传「山门义」的连续性与创发性之评估；（2）「二谛是教」说与印度中观「二谛」说的差异——汉语学界长期讨论吉藏是否「误读」了龙树；（3）三论宗衰亡的原因：会昌法难前的义学衰落、法相与天台的竞争、还是其「破而不立」性格天然缺乏制度载体，诸说并立。

| 术语 | 释义 |
|---|---|
| 三论 | 《中论》《十二门论》《百论》，宗派所依根本典籍 |
| 八不中道 | 不生不灭等八不偈所显离戏中道 |
| 二谛是教 | 真俗二谛为言教方便而非实理 |
| 破邪显正 | 破一切有所得见，即显无所得理 |
| 无所得 | 不执任何见解为实的三论宗根本立场 |
| 三法轮 | 吉藏判教：根本、枝末、摄末归本法轮 |
