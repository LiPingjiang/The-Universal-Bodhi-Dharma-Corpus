# 佛教四賓主研究 · 原文

## 一、概念概述

四賓主是臨濟義玄禪師所立的勘辨方法，與四料簡、四照用並稱臨濟門庭三大施設（另二題互見：`05066_佛教四料簡研究`、`05068_佛教四照用研究`），出於《臨濟錄》（T1985）「勘辨」部分。「賓」指參學之學人或其境界，「主」指善知識（師家）或其自受用境。師資問答往來之中，由「誰勘破誰」判別四種格局：一、賓看主（學人勘破師家）——學人拈出清淨境（真悟之語）向師家呈驗，師家不辨是境、卻作主宰亂答，師家墮野狐身，此名賓看主；二、主看賓（師家勘破學人）——師家出「境」勘驗學人，學人識破是境而不受縛，或學人執境而師家把得拋向坑裡，師家佔機鋒之勝；三、主看主——師家拈出問答，同在作用處勘辨，兩眼相照、其聲相應，賓主皆明眼人；四、賓看賓——學人披枷帶鎖（自縛於境）來見師，師家不為其解縛、更與安一重枷鎖（順其執而增其縛），雙雙不了，瞎漢對盲人。四賓主之功能不在「教學內容」而在「師資鑑定」：臨濟強調參學人「大須子細」，勿為相似禪者所誤；明眼師家則須「便與識破是境，奪卻令無路」。此法後為禪林勘驗之通用術語，曹山本寂、風穴延沼皆有引申；「賓中主、主中賓、賓中主、主中主」之石霜四位君臣亦與之相關。

## 二、核心經文選錄

> **原文**（《鎮州臨濟慧照禪師語錄》，T1985）：
> 「參學之人，大須子細。如賓主相見，便有言語往來，或應物現形，或全體作用，或把機權喜怒，或現半身，或乘師子，或乘象王。……如有真正學人，便喝，先拈出一個膠盆子。善知識不辨是境，卻作他主宰，即是流落野狐之身。」

> **白話對照**：
    臨濟告誡參學者須極為審慎：賓（學人）主（師家）相見，往來言語、現形作略皆在勘驗之中。若學人喝、設一個「膠盆子」（黏縛之境）試探，師家不識是境、卻自居主宰而答——師家便墮野狐身，此即「賓看主」：學人反成勘驗者。

> **原文**（《臨濟錄》「勘辨」段，T1985）：
> 「如學人枷鎖在身，與枷鎖在心，出來見知識；知識不為解卻枷鎖，卻與更添一重枷鎖……此名賓看賓。」

> **白話對照**：
    學人本被執著枷鎖所縛而來求解脫，師家不僅不為其解縛，反順著他的執著再添加一重枷鎖（以境接境、以解縛解）——賓主皆是瞎漢，此名「賓看賓」。四賓主中最須警惕者即是此格：相似法中互相印證，愈印愈縛。

## 三、重要名句

> 「參學之人，大須子細。」（《臨濟錄》勘辨開篇之警語）

> 「賓看主、主看賓、主看主、賓看賓。」（四賓主總目）

> 「瞎屢屢漢，死在句下。」（臨濟斥執言句而不明眼者）

> 「設有來者，我與拈卻枷鎖，令其自在。」（與「更添一重枷鎖」相對的明眼師家之作用）

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 賓／主 | 參學人（或其境）／師家（或其自受用境） |
| 賓看主 | 學人以境勘師，師不明而墮，機反在賓 |
| 主看賓 | 師家設境勘學人，奪卻其執，機在主 |
| 主看主 | 賓主皆明眼，聲色相照，殺活同時 |
| 賓看賓 | 賓主皆不明，以縛益縛，盲引盲 |
| 勘辨 | 禪門師資相互檢驗悟境之方法 |
| 機鋒 | 禪師臨機之敏捷言句動作 |
| 膠盆子 | 臨濟語，喻黏縛人之境界、言語窠臼 |
