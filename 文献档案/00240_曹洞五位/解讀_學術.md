# 曹洞五位 — 学术解读

## 一、文献背景与成书

"曹洞五位"并非一部单一著作，而是曹洞宗创始人洞山良价（807—869）所创立、其弟子曹山本寂（840—901）详加阐释的"五位"学说体系，相关文本散见于洞山《宝镜三昧歌》《五位显诀》、曹山语录及后世《人天眼目》《从容录》等文献的转述汇编之中，本档案以其义理整体为"曹洞五位"立目。

洞山良价嗣云岩昙晟，于江西洞山开创宗风；曹山本寂居抚州曹山，将乃师偏正五位敷演为"君臣五位"等图式。曹洞一名，即取曹山、洞山二字。与临济的棒喝峻烈不同，曹洞宗风"细密"——其核心正是五位学说对体用、理事关系的层层勘验。

## 二、文本结构与核心思想

五位之"位"，是心与境、体与用、理与事的五种关系格局。原文所录为通行纲目：

1. **正中偏**——"体中起用"。舍事入理、由体发用之初阶，喻如"三更初夜月明前"，暗中有明。
2. **偏中正**——"用中归体"。舍理入事、摄用归体，喻如"日出西下碧潭清"，万象之中独露一真。
3. **正中来**——"体用相即"。由体起用而即用全体，"无中有路隔尘埃"。
4. **偏中至**——"动静不二"。大用流行、内外冥合，"两刃交锋不须避"，喻应缘接物而如如不动。
5. **兼中到**——"体用双泯，理事圆融"。五位之极，超越正偏对待，"落草头"垂手接人，不可言晓。

曹山本寂复以"君臣五位"释之："君为正位，臣为偏位。君臣道合，理事相即。如此五位，尽曹洞宗旨。"君喻本体（空、理），臣喻现象（有、事），君臣道合即体用不二。此外尚有"功勋五位""王子五位"等图式，皆从不同角度勘验悟境之深浅与偏圆。

## 三、学术研究价值与争议

**研究价值**：五位学说是中国佛教中最精密的"境界类型学"之一，它把开悟的经验划分为可勘验的阶位，为研究禅宗心性论的认识论结构提供了独特样本。五位与《易经》卦象（有学者认为五位配卦）、华严四法界（理事无碍）的思想关联，是儒释交涉与宗派义理比较研究的重要课题。五位学说随道元传入日本，成为日本曹洞宗教学的骨干。

**代表学者**：忽滑谷快天《中国禅学思想史》对五位源流有系统梳理；日本驹泽大学系统的曹洞宗学研究（如伊藤秀宪等对洞山、曹山文献的考证）奠定了文本基础；柳田圣山的禅文献研究涉及五位文献的成立层次；中文学界近年对五位与易学、华严思想之关系的讨论亦持续不断。

**争议问题**：其一，五位文献的成立层次——《宝镜三昧歌》《五位显诀》等是否确为洞山亲作，抑或经曹山及后人整理敷演，需逐件辨析；其二，五位次第的诠释方向——是修证次第（由浅至深的阶梯），还是境界类型（五种平等的格局），曹洞宗内部与学界均有分歧；其三，"正偏回互"与石头的《参同契》思想之关系——回互学说是曹洞独倡还是承自石头希迁，是曹洞宗史研究的基本问题。

## 四、术语对照表

| 术语 | 释义 |
|------|------|
| 五位 | 正中偏、偏中正、正中来、偏中至、兼中到，体用关系的五种格局 |
| 正／偏 | 正位指本体、空、理；偏位指现象、有、事 |
| 君臣五位 | 以君喻正位、臣喻偏位，君臣道合喻体用理事相即 |
| 回互 | 诸法虽各住自位而彼此涉入融摄，曹洞宗思想之枢纽 |
| 宝镜三昧 | 洞山所传禅定三昧之名，喻心镜相照、光影回互 |
| 体用双泯 | 兼中到之境界，体用对待俱泯、理事圆融无碍 |
