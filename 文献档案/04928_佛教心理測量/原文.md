# 佛教心理測量 · 原文

## 一、學科概述

佛教心理測量是將心理測量學（psychometrics）的量表技術應用於正念、慈悲、無執等佛教構念（construct）的量化研究，是冥想科學得以「科學化」的方法論基石。其關鍵發展集中在二十一世紀初：2003年，羅徹斯特大學的柯克·布朗與理查德·瑞安發表「正念注意覺察量表」（MAAS），首次把正念定義為可自陳測量的特質；2004年與2006年，肯塔基大學的魯斯·貝爾先後推出「肯塔基正念技能量表」（KIMS）與「五因素正念量表」（FFMQ），把正念操作化為觀察、描述、有意行動、不判斷、不反應五個維度；同年，克里斯汀·內夫的「自我慈悲量表」（SCS）將佛教慈心對自身的運用加以測量化。這些量表已被翻譯為包括中文在內的數十種語言，累積了海量實證數據。

## 二、核心議題與佛教觀點

核心議題包括：（一）構念效度之爭——自陳的正念是否等於實際的心念品質？批評者指出「報告自己很有正念」與「真正安住當下」可能相關甚低，故近年發展出行為測量（如持續注意任務）與經驗取樣法作為補充；（二）文化等值性——西方正念定義偏重注意與接納，佛教正念（sati）則包含憶持法義與精勤抉擇，跨文化測量須防「構念漂移」；（三）佛法的可測性邊界——慈悲、輕安、無我可以部分量化，而「解脫」「涅槃」作為終極目標天然抗拒量表化，測量學者多承認量表測的只是「佛法效應的投影」。《華嚴經》「心如工畫師」之偈恰可作為測量的基本假設：量表測量的是心所描畫、可以報告的世界，而非心的本身——這提醒測量者保持謙遜。

> **經典依據**：
> 「心如工畫師，能畫諸世間，五蘊悉從生，無法而不造。」——《大方廣佛華嚴經》（T279）

心是世界的描繪者，一切經驗皆由心造——心理測量的正是這位「畫師」的筆觸（自陳報告），而畫師本身（能知之心）永遠不會完全出現在畫面（測量數據）之中，此即佛教對一切量化心靈之努力的內在限定。

## 三、代表學者與實踐

布朗與瑞安（2003年，載《人格與社會心理學通報》）的MAAS因題項簡潔而成為引用最多的正念量表，並推動「特質正念」研究範式。貝爾在肯塔基大學整合多個量表發展FFMQ，其2006年載於《評估》的方法學論文成為正念測量的標準參考；後續的「多維正念量表」與「費城正念量表」均承其脈絡。內夫（德克薩斯大學奧斯汀分校）的自我慈悲量表開闢了獨立的研究領域，證明自我慈悲對抑鬱、完美主義、進食障礙具有緩衝作用。近年，蘇珊·斯普雷徹與貝弗莉·費爾（2005年）發展的「同情之愛量表」等慈悲測量工具，以及以生理與行為指標（如幫助行為觀察）交叉驗證自陳數據的多方法取向，正在把佛教構念測量推向更高的效度標準。中文版FFMQ、MAAS與SCS亦已完成信效度檢驗，廣泛用於華人正念研究。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 構念效度 | 量表真正測到目標心理構念的程度 |
| 自陳量表 | 依被試自我報告作答的測量工具 |
| 五因素正念量表（FFMQ） | 貝爾等開發的五維度正念自陳量表 |
| 自我慈悲 | 內夫提出的構念，對自身痛苦的溫暖接納態度 |
| 特質正念 | 個體在日常生活中穩定的正念水平 |
| 正念（sati） | 佛教術語，本義為憶念、覺照，含善法抉擇之義 |
