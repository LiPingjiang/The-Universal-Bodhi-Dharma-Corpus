# 部派佛教思想史 — 学术解读

## 一、文献背景与成书

本目录为部派佛教思想史的研究性档案。部派佛教（Nikāya Buddhism）指佛陀入灭后约百年至大乘兴起之间（约公元前三世纪至公元后一、二世纪）以部派为单位展开的佛教形态；自根本分裂（上座部与大众部）至枝末分裂，形成「十八部」或「二十部」——部数与名录，北传《异部宗轮论》（T2031，玄奘译，世友造）与南传《岛史》（Dīpavaṃsa）、《大史》（Mahāvaṃsa）所记各异。

本档案的核心史料为三种部派总录及其异译：《异部宗轮论》（T2031）、《十八部论》（T2032，旧题失译）、《部执异论》（T2033，陈·真谛译），辅以《大毗婆沙论》（T1545，含大量诸部异义）、南传《论事》（Kathāvatthu，其五百余论题即部派诤议的实录）、玄奘《大唐西域记》所记七世纪部派分布等。现代研究方面，本档案以印顺法师《印度佛教思想史》《说一切有部为主的论书与论师之研究》《初期大乘佛教之起源与开展》及平川彰《印度佛教史》《律藏研究》、吕澂《印度佛学源流略讲》、E. Frauwallner、A. K. Warder、E. Lamotte 等人的著作为参照系。

## 二、文本结构与核心思想

部派思想史的基本框架可概括为四条主线：

1. **分裂史**：第二次结集（毗舍离「十事非法」之争，南传所记）与「大天五事」之争（北传所记）导致根本分裂；此后二百年间两系不断枝末分裂，形成大众、上座两大谱系的二十部。南北两系分裂叙事的差异本身即是重要研究课题。
2. **佛身与圣者观**：大众部系「诸佛世尊皆是出世」「心性本净」；上座部系（尤其说一切有部）「佛与二乘解脱无异」「罗汉不退」——两系对佛陀与圣者的定位构成思想分野的主轴。
3. **法体与时间观**：有部「三世实有、法体恒有」；经量部「过未无体」；化地部「过去未来是无、现在及无为是有」——存在论光谱至为丰富。
4. **我论**：犊子部系立「不可说之补特伽罗」，余部破之——「无我而有轮回」的难题贯穿全部部派论学。

## 三、学术研究价值与争议

1. **大乘起源问题**：部派佛教是大乘兴起的土壤。平川彰据律典研究提出大乘起源于非僧非俗的菩萨集团说，影响深远；其后学界（如欧美、日本学者）从写本、铭文、塔寺崇拜等角度提出批评与修正，至今仍是印度佛教研究的第一大公案。
2. **分裂史的重建**：南北两系史料牴牾，部数、名录、次第各说不一；现代学者（自 Mineev、Warder、Frauwallner 以来）拟构的分裂谱系均属假说，无一定谳。
3. **「部派＝堕落」叙事的检讨**：传统大乘立场视部派为「分裂的、执着的」；现代研究（尤其南传与学界）则强调部派时期是论书、注释、艺术、制度高度成就的时代——评价框架的重估本身是思想史的课题。
4. **方法论的融合**：汉译、巴利、梵语残卷、藏译、铭文与考古多源对勘，已是当代部派研究的标准配置。
