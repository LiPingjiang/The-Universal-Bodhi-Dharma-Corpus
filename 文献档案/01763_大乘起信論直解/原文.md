# 大乘起信論直解 · 原文

## 一、概述

《大乘起信論直解》二卷，明·**憨山德清**（1546–1623）述，收於《卍續藏》第四十五冊，經號 **X0766**（CBETA：X45n0766）。所依底本為梁·真諦譯《大乘起信論》一卷。

書前有作者自題〈刻起信論直解題辭〉，署「時泰昌改元歲在庚申仲冬朔／匡山逸叟憨山釋德清述」，即明泰昌元年（1620）冬，憨山時居廬山。此書由門人超逸攜稿歸廣東刊刻流通。

憨山對《起信論》用力兩次：先有《大乘起信論疏略》二卷（X0765），是刪節法藏《義記》之繁而成，已刻於雙徑；後有此《直解》，改為直接註解論文本身。二書體例不同，須分別看待。

「直解」之名，取「直注本文、貴在一貫、不假旁引枝蔓」之義——即不繞道諸家疏記，逕直解釋論文。

## 二、核心段落（原文與白話對照）

### 段落一：造《直解》的緣起——為初學而作

**原文**（〈刻起信論直解題辭〉）：

> 賢首舊疏科釋，最為精詳，加之記文浩瀚，學者望洋，杳莫可究。予嘗就本疏少刪其繁，目為疏略，業已刻雙徑，率多尊崇。頃念法門寥落，講席荒涼，初學之士，既無師匠可憑，己眼不明，非仗此論，無以入大乘，生正信，將恐久而無聞焉。山居禪悅之暇，因祖舊章，率意直注本文，貴在一貫，不假旁引枝蔓，而一心真妄迷悟之義，了然畢見，如視白黑，足有便於初學，非敢聞於大方也。

**白話對照**：賢首（法藏）的舊疏，分科解釋最為精細周詳，再加上後人的記文浩繁如海，學者面對它就像望著汪洋，深遠得無從探究。我曾就本疏稍稍刪去它的繁蕪，題為《疏略》，已經刻在雙徑山，大多受到推崇。近來感念佛門冷落、講席荒涼，初學的人既沒有師長可以依憑，自己的眼目又不明，若不憑藉這部論，就無從進入大乘、生起正信，只怕時間一久連聽都聽不到了。因此在山居參禪之餘，我依循舊有的章法，隨意直接註解論文本身，貴在前後一貫，不借助旁徵博引的枝蔓文字，而使「一心」與真、妄、迷、悟的義理清清楚楚地全部顯現，就像分辨黑白一樣，足以方便初學者，並不敢說要拿去請教大方之家。

### 段落二：判定本論的地位——大教關鑰、禪宗司南

**原文**（〈刻起信論直解題辭〉）：

> 起信論者，乃馬鳴大師為破小乘外道邪見，宗百部大乘經典所作，以為發起正信也。故立論宗法界一心，開真妄二門，徹生滅之本，窮迷悟之源，指修行之正路，示止觀之妙門，總括一萬一千餘言，理無不盡，事無不該，可謂大教之關鑰，禪宗司南也。

**白話對照**：《起信論》是馬鳴大師為了破除小乘與外道的邪見，宗依上百部大乘經典所作，用來發起大乘正信。所以立論以法界一心為宗，開出真、妄兩門，徹底揭示生滅的根本，窮盡迷悟的源頭，指出修行的正路，開示止觀的妙門。全文總共一萬一千多字，於理無所不盡，於事無所不包，可以說是通向整個大乘教法的關鍵鎖鑰，也是禪宗修行的指南針。

### 段落三：以華嚴六相統攝本論——回答「馬鳴何以為華嚴初祖」

**原文**（〈華嚴宗法界緣起綱要〉）：

> 華嚴七祖，以馬鳴為初祖，然此論中未及圓融之旨，何以稱耶？向未有知其說者，後學竟茫然莫辨，故了不加意，使古人建立宗旨，卒無以暢明於世也。故今略示其要，令知所宗。
> 華嚴圓宗，以一真法界，統四法界。依四法界，立十玄門。惟四界十玄，皆由六相而立。是則六相以成圓融無礙之宗也。此論總明六相，則包括四界十玄，理趣無遺。以六相為圓融之統，是則此論攝法界而無盡矣。故首標一心真如，為一法界大總相法門體也。

**白話對照**：華嚴宗的七位祖師，把馬鳴奉為初祖；然而這部論中並未談到圓融的宗旨，憑什麼這樣稱呼呢？一向沒有人明白其中的道理，後學於是茫然無從分辨，因此完全不加留意，使得古人所建立的宗旨最終無法在世間暢達闡明。所以現在我略示其要領，讓人知道它所宗依的是什麼。華嚴圓宗以「一真法界」統攝四種法界，依據四法界建立十玄門；而四法界與十玄門，都是由「六相」而成立的。可見是以六相來成就圓融無礙之宗。這部論總體地闡明了六相，也就包括了四法界與十玄門，義理旨趣沒有遺漏。既然以六相作為圓融的統領，那麼這部論攝取法界就無窮無盡了。所以論一開頭標舉「一心真如」，作為「一法界大總相法門體」。

### 段落四：六相配《起信論》結構

**原文**（〈華嚴宗法界緣起綱要〉）：

> 一者總相，即一心真如，為法界大總相法門體。
> 二者、別相，即：一、心，二、門，三、細，六、麤，五、意，六、染，修、斷差別也。
> 三者同相，即聖凡染淨，因果性相，同一真如，即瓦器微塵之喻也。
> 四者異相，即染淨諸法，各各差別，不一不雜，如塵器之不一也。
> 五者成相，即染淨諸法，皆由一念緣起而成也。
> 六者壞相，即染淨諸法，各住自位，各各無性，無以自立也。

**白話對照**：第一是總相，就是一心真如，作為法界大總相法門的本體。第二是別相，就是：一心、二門、三細、六麤、五意、六染，以及修行與斷惑的種種差別。第三是同相，就是凡聖、染淨、因果、性相，同歸於一個真如，也就是瓦器與微塵那個比喻所說的。第四是異相，就是染淨諸法各各差別，既不相同也不混雜，如同微塵與瓦器並非一物。第五是成相，就是染淨諸法都由一念緣起而形成。第六是壞相，就是染淨諸法各自安住在自己的位次上，各各沒有自性，無法獨立自存。

## 三、名句

1. **「可謂大教之關鑰，禪宗司南也。」**（題辭）
   ——憨山對《起信論》的總判：它既是教下的入門鎖鑰，又是宗門的方向指針。此語體現其禪教一致的立場。

2. **「率意直注本文，貴在一貫，不假旁引枝蔓。」**（題辭）
   ——「直解」二字的方法論宣言，也是憨山有別於法藏《義記》繁富疏解的自覺選擇。

## 四、術語表

| 術語 | 出處與釋義 |
|------|-----------|
| 直解 | 本書題名。直接註解論文本身，不旁引諸家疏記 |
| 疏略 | 憨山另一著作 X0765，是刪節法藏《義記》而成，與《直解》體例不同 |
| 六相 | 總、別、同、異、成、壞。憨山用以統攝《起信論》全書結構 |
| 四法界 | 理法界、事法界、理事無礙法界、事事無礙法界 |
| 十玄門 | 華嚴宗顯示事事無礙的十重玄義 |
| 一法界大總相法門體 | 《起信論》原文語，指心真如。憨山以之配六相中的總相 |
| 三細六麤 | 無明所起之三種細相與六種粗相，《起信論》生滅門的核心分析 |
| 五意六染 | 業識等五意、執相應染等六染，生滅相續的層次 |
