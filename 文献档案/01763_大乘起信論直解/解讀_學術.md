# 大乘起信論直解 — 学术解读

## 一、文献背景与成书

《大乘起信論直解》二卷，明·憨山德清（1546—1623）述，收于《卍續藏》第四十五册，经号 X0766（CBETA：X45n0766）。所依底本为梁·真谛译《大乘起信論》一卷（T1666）。书前有作者自题〈刻起信論直解題辭〉，署「時泰昌改元歲在庚申仲冬朔／匡山逸叟憨山釋德清述」，即明泰昌元年（1620）冬，憨山时居庐山，书稿由门人超逸携归广东刊刻流通。

须订正两处旧误：其一，本档旧标注此书为「T1847」，与《大正藏》实际编号不符——T1847 为唐·法藏述、宗密注《大乘起信論疏》；憨山《直解》未入大正藏，收于《卍續藏》，编号 X0766。其二，本档旧目录题此书为「明代藕益智旭所撰」，亦误；《直解》作者为憨山德清，智旭所作乃《裂網疏》（T1850）。

憨山对《起信論》用力两次，二书体例不同，须分别看待：先有《大乘起信論疏略》二卷（X0765），删节法藏《義記》之繁而成；后有此《直解》，改为直接注解论文本身。「直解」之名，取「直注本文、貴在一貫、不假旁引枝蔓」之义——不绕道诸家疏记，径直解释论文。憨山是晚明四大高僧之一，一生以禅教一致为宗，此书是其教理著作中流传最广者。

## 二、文本结构与核心思想

题辭是全书宗旨所在，其自述缘起曰：「賢首舊疏科釋，最為精詳，加之記文浩瀚，學者望洋，杳莫可究。予嘗就本疏少刪其繁，目為疏略，業已刻雙徑。頃念法門寥落，講席荒涼，初學之士，既無師匠可憑，己眼不明，非仗此論，無以入大乘，生正信，將恐久而無聞焉。山居禪悅之暇，因祖舊章，率意直注本文，貴在一貫，不假旁引枝蔓，而一心真妄迷悟之義，了然畢見，如視白黑，足有便於初學。」——法藏旧疏精详而记文浩瀚，学者望洋兴叹；憨山先删其繁作《疏略》，再为无师可凭的初学径注本文，务使一心真妄迷悟之义「如視白黑」。

其对《起信論》的总判为：「立論宗法界一心，開真妄二門，徹生滅之本，窮迷悟之源，指修行之正路，示止觀之妙門，總括一萬一千餘言，理無不盡，事無不該，可謂大教之關鑰，禪宗司南也。」——一万一千字的《起信論》，既是教下的入门锁钥，又是禅门的方向指针，此语最能见憨山禅教一致的立场。

全书最具特色者，为书前〈華嚴宗法界緣起綱要〉一文。憨山自设问答：华严七祖以马鸣为初祖，「然此論中未及圓融之旨，何以稱耶？」——马鸣既为华严初祖，而论中未见圆融之说，凭什么？他的答案是：华严圆宗以一真法界统四法界，依四法界立十玄门，而「惟四界十玄，皆由六相而立」；本论总明六相，故「包括四界十玄，理趣無遺」「攝法界而無盡矣」。随即以六相配本论结构：总相即一心真如（「一法界大總相法門體」），别相即一心、二门、三细、六麤、五意、六染诸差别，同相即圣凡染净因果性相同一真如（瓦器微尘之喻），异相即染净诸法不一不杂，成相即染净诸法皆由一念缘起而成，坏相即诸法各住自位、各各无性。以此，憨山把《起信論》整个收进华严六相圆融的架构，为其「马鸣为华严初祖」的传统定位提供了论证——这是晚明融通教义的代表性操作。

## 三、学术研究价值与争议

就研究价值言，其一，传播史价值：《直解》是明清以降《起信論》流通最广的入门注本之一，其「贵在一贯、不假旁引」的路线使这部艰深论书首次变得可读，研究《起信論》在近世的普及，《直解》是枢纽文献。其二，思想史价值：以六相统摄《起信論》全书的操作，是华严学与《起信論》学合流的一次完整示范，为研究晚明「教禅一致、性相融通」的学风提供了成熟样本。其三，文献学价值：憨山先《疏略》后《直解》的两番著述，恰好构成「删节旧疏」与「径注本文」两种注疏体例的对照实验，于注疏类型学研究别具意义。争议与限制：其一，「本论总明六相，故摄四界十玄」的论证，是对论文的创造性引申——《起信論》本身并无以六相为组织纲领的明文，憨山的配属属诠释的建构而非文本的直陈，学者引用时应区分「论中实有」与「憨山所配」；其二，「如視白黑」的简明是以舍弃法藏科判的精细与诸家异说为代价的，义理考据层面不能以《直解》为断；其三，题辭署年泰昌改元庚申，泰昌元年与万历四十八年相重叠，纪年换算须留意。

## 四、术语对照表

| 术语 | 出处与释义 |
|---|---|
| 直解 | 本书题名；直注本文、贵在一贯、不旁引诸家 |
| 疏略 | 憨山另一著作 X0765，删节法藏《義記》而成 |
| 六相 | 总、别、同、异、成、坏；憨山用以统摄本论结构 |
| 四法界 | 理、事、理事无碍、事事无碍法界 |
| 十玄门 | 华严宗显事事无碍的十重玄义 |
| 三细六麤 | 无明所起三种细相与六种粗相 |
| 五意六染 | 业识等五意、执相应染等六染 |
| 大教關鑰／禪宗司南 | 憨山对本论的总判语 |
| 一法界大總相法門體 | 《起信論》原文语，指心真如；憨山以配六相之总相 |

## 五、延伸阅读

- `01157_大乘起信論`：T1666，本书所释底本。
- `01761_大乘起信論纂注`：明·真界纂注本，同为明代注疏而走汇编路线，与「直解」路线适成对照。
- `01776_大乘起信論續疏`：明·通润续贤首疏之作，明代三注本并列。
- `01759_大乘起信論裂網疏`：T1850，明·智旭疏，与憨山并世而立场有别。
- `01773_大乘起信論會閱`：清·续法会编本，其科判正承法藏一系，与憨山「祖旧章」处可互证。
- `02384_華嚴一乘教義分齊章注`：T1866，六相十玄的完整理论出处。
