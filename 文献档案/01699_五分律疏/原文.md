# 五分律疏·原文

## 一、概述

五分律疏，指对弥沙塞部（化地部）所传《弥沙塞部和醯五分律》之疏释。该律收录于大正藏第1421号，凡三十卷，刘宋佛陀什共竺道生等译于景平元年（423）前后。弥沙塞部为上座部分出之部派，"五分"之名来自其律藏之五大部分结构：比丘戒法、比丘尼戒法、受戒犍度、说戒犍度等犍度法、附属法。此律与四分律、十诵律、摩诃僧祇律并称古来四部广律。五分律以其叙事性强、因缘故事详尽著称，但在汉传佛教中未形成独立宗派。现存疏释主要为律文本身所附之制戒因缘与戒条释义，后代对五分律之专门注疏较少流传。

## 二、核心段落

### 段落一：律藏开篇之制戒缘起

**原文：**

> 弥沙塞部和醯五分律卷第一。宋罽宾三藏佛陀什共竺道生等译。第一分初波罗夷法。佛在须赖婆国，与大比丘众五百人俱，诣毗兰若邑住林树下。其邑有婆罗门，名毗兰若，波斯匿王以此邑封之。闻佛释种出家学道，成如来应供等正觉明行足善逝世间解无上调御士天人师佛世尊，普知世间一切心念，为说正法初中后善善义善味，具足清白梵行之相，与诸弟子来游此邑，叹言善哉，我愿见佛。即与五百眷属前后围绕出诣佛所，遥见世尊在林树下，诸根寂定光明殊特，欢喜踊跃下车步进，住立问讯却坐一面。尔时世尊，为说妙法示教利喜，闻法欢悦即白佛言：愿佛及僧，受我安居三月供养。

**白话翻译：**

弥沙塞部和醯五分律第一卷。刘宋罽宾三藏佛陀什与竺道生等翻译。第一分之最初波罗夷法。佛陀在须赖婆国，与五百位大比丘众在一起，来到毗兰若邑住在树林之下。该邑有一位婆罗门，名叫毗兰若，波斯匿王将此邑封赐给他。他听说佛陀是释迦族人出家学道，成就了如来应供等正觉明行足善逝世间解无上调御士天人师佛世尊，普知世间一切众生的心念，为众生宣说正法，初善、中善、后善，义善、味善，具足清净白净的梵行之相，与诸弟子游化来到此邑。他赞叹道：太好了，我愿意见佛。于是带领五百眷属前后围绕，出城前往佛的住处。远远看见世尊在树林下，诸根寂静安定，光明殊胜特异，欢喜踊跃地下车步行而进，站立问讯后坐在一面。那时世尊为他说妙法，开示教导、利益欢喜，他听法后欢悦地说：愿佛及僧团接受我安居三个月的供养。

### 段落二：制戒之因缘

**原文：**

> 时魔波旬作是念：今婆罗门请佛及僧安居三月，我当厌蛊迷乱其意。念已即来厌之。彼婆罗门为魔所厌，即入后宫受五欲乐，敕守门者：我今游宴三月在内，外事好恶一不得白。都不复忆请佛及僧。尔时彼国信向邪道，邑里未有精舍讲堂，城北有山林流清净，佛与大众即而安居。时世饥馑乞求难得，入里分卫都无所获。时波利国，有贩马师，驱五百匹马，夏初来至，热时已到。

**白话翻译：**

这时魔波旬心中想道：现在这位婆罗门请佛及僧团安居三个月，我应当用厌蛊之术迷乱他的心意。这样想后即刻前来施厌蛊之术。那位婆罗门被魔所迷惑，便进入后宫享受五欲之乐，并命令守门人说：我现在在宫中游乐宴乐三个月，外面的事情好坏一律不得禀报。他完全不再记得请佛及僧团之事。那时该国的信仰趋向邪道，邑里还没有精舍讲堂，城北有山林流水清净之处，佛与大众就在那里安居。当时遭遇饥馑之年，乞食十分困难，入城中乞化一无所获。当时波利国有一位贩马师，驱赶五百匹马，夏初来到此地，天气已经炎热。

## 三、名句

1. "普知世间一切心念，为说正法初中后善善义善味，具足清白梵行之相。"——描述佛陀之德，以正法化导众生，律藏之弘传即以此为本。

2. "时魔波旬作是念：今婆罗门请佛及僧安居三月，我当厌蛊迷乱其意。"——制戒因缘中常有魔扰，说明修行之路并非平坦，僧团须以戒律自持。

## 四、术语表

| 术语 | 释义 |
|------|------|
| 弥沙塞部 | 梵文Mahīśāsaka，意译化地部，上座部之分派，五分律之传承部派 |
| 五分 | 指五分律之五大部分：比丘戒、比丘尼戒、犍度法、附属法等 |
| 波罗夷 | Pārājika，最重之罪，犯者如断头不可复活，永弃僧团 |
| 安居 | 每年雨季三个月，僧众聚于一处修道，五分律以四月十六日入安居 |
| 分卫 | 梵语Piṇḍapāta，意译乞食，比丘入城乞化食物之修行方式 |
| 波旬 | Māra-pāpimant，恶魔，常扰乱修行者 |
| 犍度 | Khandhaka，律藏中按事类编排之章品，记载僧团制度与日常规范 |
| 波斯匿王 | Prasenajit，拘萨罗国国王，佛陀之护法居士 |
