# 地藏菩萨灵验记 — 学术解读

## 一、文献背景与成书

《地藏菩萨像灵验记》，一卷，宋代传教沙门常谨集，收于《卍新纂续藏经》第八十七册（X1638）。书成于北宋端拱二年（989年）前后。常谨于序中自称因归信地藏菩萨，乃"寻访先迹、咨问口实"，收集感应事迹百余条，择取三十余条编成此记。

从书名可知，本书记录的是"造像、画像"地藏菩萨所显现的灵验故事。全书上起梁代，下迄宋代，凡三十二则，如"梁朝善寂寺画地藏放光之记""唐抚州祖氏家金色地藏救亲记"等。这些感应故事的共同主题是：以诚敬之心造地藏像（或画像、刻石、铸像），地藏菩萨即于危难中现身救护。

本书的文献价值在于：其一，它是地藏信仰在中土流布的重要史料，记录了地藏信仰由"经典文本"走向"民间实践"的轨迹；其二，书中地藏"冥间救度""救亲报恩"的事迹，与《地藏菩萨本愿经》"地狱不空，誓不成佛"的大愿相呼应，反映了中国民间对地藏"幽冥教主"形象的理解。

## 二、文本结构与核心思想

全书共收录感应故事三十二则，核心主题可归纳为：

**造像显灵**。本书记录了大量"造地藏像而得感应"的事迹——有人因重病在床，忏悔发愿造地藏像，病即痊愈；有人于梦中见地藏，指示其造像自利利他；有人造金地藏像，夜见放光。造像在此不仅是一种功德，更是一种"与菩萨结缘"的修行方式。

**救生脱难**。诸多故事记载地藏现形救脱危难——或于火灾中护佑、或于病难中痊愈、或于瘟疫中幸免、或于刀兵劫中保全。这些故事与观音的"寻声救苦"有相似之处，体现了地藏菩萨在民间的"救护者"形象。

**度亡报恩**。书中大量记载地藏菩萨度脱亡者、超荐亲人的事迹。如"唐抚州祖氏家金色地藏救亲记"，记祖氏因虔诚供奉金色地藏像，其已故的亲人得地藏救护而免于恶道。这类故事将地藏信仰与中国的孝道传统紧密相连——为亡亲造像诵经，是最典型的报恩方式。

**地狱救度**。受《地藏经》影响，地藏在本书中亦以"幽冥教主"的形象出现，接引地狱中的罪苦众生。《序》文借佛陀在忉利天宫"殷勤付嘱"地藏、令娑婆世界众生"悉使解脱，永离诸苦"，确立了地藏作为"佛陀灭度后、弥勒出世前的救度本尊"的地位。

## 三、学术研究价值与争议

**研究价值**：本书为宋代地藏信仰的专书文献，与辽代非浊《三宝感应要略录》等同类感应录共同构成了中国地藏感应文献的系列。通过本书，可以考察地藏信仰在唐代至宋代（地藏信仰的成熟期）如何通过"造像感应"深入民间，并分析地藏信仰中"冥间救度"与"孝道报恩"两大主题的交织。

**代表学者**：常谨为编者；中国近代以来对地藏信仰的研究，有学者从"地藏与目连"的关系、地藏与"冥界"民俗等角度展开；相关的感应文献还有《地藏菩萨本愿经》《大乘大集地藏十轮经》等根本经典；日本学界对地藏信仰（如"地藏盆"等民俗活动）有较多研究。

**争议问题**：其一，感应故事的历史真实性——此类感应文多为"劝信"目的而作，史实与虚构交织，需谨慎使用；其二，"造像感应"与佛教"依法不依人"的义理如何统一——造像究竟是一种有效的修行方便，还是一种外求的执着，教理上存在讨论；其三，本书中地藏的"幽冥教主"形象，是源于印度经典还是中国本土（与道教的冥界观念结合）的产物，学界对此争论不已。

## 四、术语对照表

| 术语 | 释义 |
|------|------|
| 地藏菩萨 | 中文音译，意"大地之藏"，誓度一切众生、尤其恶道众生的大菩萨 |
| 感应 | 众生之心"感"与佛菩萨之"应"，感是因，应是以至于冥冥中护佑 |
| 忉利天 | 三十三天，佛在忉利天为母说法并付嘱地藏之处 |
| 本愿 | 地藏菩萨因地发下的根本誓愿，如"地狱不空，誓不成佛" |
| 造像| 造作佛像、菩萨像，被视为功德与结缘的修行方式 |
