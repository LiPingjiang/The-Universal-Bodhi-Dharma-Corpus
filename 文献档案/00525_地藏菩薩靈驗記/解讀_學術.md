# 地藏菩萨灵验记 — 学术解读

## 一、文献背景与成书

《地藏菩薩像靈驗記》，一卷，北宋传教沙门常谨集，收于《卍新纂續藏經》第八十七册，编号 X1638。书成于北宋端拱二年（989年）。需要说明的是，本档案目录题作「地藏菩萨灵验记」，而按原书序题，全名当作《地藏菩薩像靈驗記》——「像」字点出了全书限定于造像、画像显灵这一特定感应类型，通行简称与本档案名均属省称。

据常谨自序，他因归信地藏菩萨，乃「寻访先迹、咨问口实」，共收集感应事迹百余条，择取三十余条编成此记。全书上起梁代，下迄宋代，凡三十二则，名目如「梁朝善寂寺画地藏放光之记」「唐抚州祖氏家金色地藏救亲记」等。从编纂方式看，此书属于中国佛教「感应录」传统：编者并不虚构情节，而是以见闻、传闻与口述为素材，择其可征信者笔录成书。这类文献在唐宋之际大量涌现，与净土信仰、菩萨信仰向民间纵深传播的进程同步。《地藏菩薩本願經》（通行本题唐实叉难陀译）在唐末五代广泛流通，为地藏信仰提供了经典依据；常谨此书则从实践层面记录了这一信仰如何在造像、救亲、度亡等具体场景中展开。

## 二、文本结构与核心思想

全书以一篇序文统摄三十二则故事。序文借释迦牟尼佛在忉利天宫付嘱之语立论：「汝當憶念，吾在忉利天宮，慇懃付屬，令娑婆世界已來眾生，悉使解脫，永離諸苦。」这一付嘱确立了地藏在佛陀灭度之后、弥勒下生之前这段「无佛时代」代理救度的特殊地位，是全书神学结构的总纲。

三十二则故事可以归纳为四个母题。其一为造像显灵：因重病、困厄而发愿造地藏像，像成而感应随之，或放光、或入梦。其二为救生脱难：地藏于火灾、刀兵、疫病中现形救护，与观音「寻声救苦」的功能型信仰颇为接近。其三为度亡报恩：亡亲因生者造像供养之力得免恶道，此类故事将地藏信仰与中国孝道传统紧密结合。其四为幽冥救度：地藏以幽冥教主身份接引罪苦众生，直接呼应《地藏经》「地狱不空，誓不成佛」的大愿。

序中「但於佛法中所為善事，一毛一渧、一沙一塵，或毫髮許，我漸度脫，使獲大利」一句，为全书的救赎逻辑提供了经证：救度不由资格门槛决定，而由哪怕极微小的善缘启动。这解释了为何「造像」这一门槛极低的实践，能够成为民间信仰动员的核心手段。

## 三、学术研究价值与争议

研究价值方面：第一，此书是地藏信仰在中土流布的重要专书史料，可以与敦煌愿文、石窟造像题记相互印证，重建地藏信仰由经典文本走向民间实践的轨迹；第二，书中保存的寺院名、地名、人物身份，为唐宋基层佛教社会史提供了细节；第三，它与辽代非浊《三寶感應要略錄》、宋代的《觀音慈林集》等构成一个感应文献序列，是比较菩萨信仰形态（观音与地藏的分工与重叠）的现成样本。

争议问题主要有三。其一，史料性质问题：感应录以劝信为目的，史实与传说交织，哪些细节可作信史使用，需要外部证据约束，学界一般只将其视为信仰心态史与观念史的史料，而非事件史的史料。其二，「造像感应」的教理定位：从「依法不依人」的立场看，外求造像是否偏离智慧之道，佛教内部即有讨论；研究者亦需区分义理层面的批判与信仰实践层面的事实。其三，地藏「幽冥教主」形象的来源问题：其地狱救度职能究竟是印度经典（如《地藏菩萨本愿经》的地狱场景）自身的展开，还是与中土冥界观念、泰山信仰融合的产物，学界至今聚讼未定。此书作为这一形象流变过程中的早期实证材料，恰是争论双方都要引用的关键文本。

## 四、术语对照表

| 术语 | 释义 |
|------|------|
| 地藏（Kṣitigarbha） | 意译「大地之藏」，以大地含藏万物喻其含藏救度一切众生的悲愿，汉传以「大愿地藏」著称 |
| 灵验（感应） | 众生之「感」与菩萨之「应」相契合而显现的事效，感应录文体的核心概念 |
| 造像 | 塑造、绘制、刻镂佛菩萨形像，被视为功德与结缘的修行方式 |
| 忉利天（Trāyastriṃśa） | 三十三天，佛为母说法并于其间付嘱地藏之处，全书序文的场景 |
| 化身／分身（Nirmāṇa-kāya） | 菩萨随类应现的多个身形，序文言地藏分身「遍满百千万亿恒河沙世界」 |
| 本愿 | 菩萨于因地所发的根本誓愿，地藏以「地狱不空，誓不成佛」为其标志 |
| 恒河沙（Gaṅgā-nadī-vālukā） | 以恒河沙数喻不可计数，汉译佛典表示极大数量的套语 |
| 阿僧祇（Asaṃkhya） | 「无数」的音译，佛典计劫、计世界常用的数量单位 |
| 那由他（Nayuta） | 古印度大数单位，经中每与「百千万亿」连用极言其多 |

## 五、延伸阅读

- `00084_地藏經` — 地藏信仰的根本经典，本记序文付嘱情节的出处
- `00524_觀音慈林集` — 同类菩萨感应录，可比照观音与地藏信仰形态之异同
- `00521_太平廣記佛教類` — 宋代志怪总集，其中释门感应故事可作旁证材料
- `00520_法苑珠林` — 唐代佛教类书，其感应篇为早期感应资料之渊薮
- `00522_神僧傳` — 僧人神异传记，与灵验记文体互为补充
- `02695_佛教感應錄` — 感应录文体的综汇条目，可总览此一文类的源流
