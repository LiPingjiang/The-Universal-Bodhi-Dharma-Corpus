# 人施設论注 — 学术解读

## 一、文献背景与成书

《人施設論注》（巴利语 Puggalapaññatti-aṭṭhakathā），是巴利论藏第四部《人施設論》（Puggalapaññatti）的注释书，传统题为五世纪上座部论师觉音（Buddhaghosa）所造，与《分別論注》《界論注》《雙論注》《發趣論注》（按传统次第为论藏五部之外沿排列）等同收于《五論註》（Pañcappakaraṇa-aṭṭhakathā）之中。需要首先说明的是版本学位置：此注属南传上座部大寺派传承的藏外文献，没有古代汉译本；汉译《南传大藏经》（元亨寺版）仅译出论本《人施設論》（编号 N50n0027），本注的巴利原文可依第六次结集版（Chattha Saṅgāyana）abh03a.att3 以下读取。也就是说，此书在汉文大藏经传统中并无对应位置，研究者必须直接面对巴利文献。

觉音的造注工作有一个统一的历史背景：五世纪时锡兰大寺派所传的论释原以古僧伽罗语保存，觉音自印度渡海至阿努拉达普拉的大寺，依据僧伽罗语旧注整理、翻译、改写为巴利语，遂成传世诸注。本注的序偈自陈造论次第：佛先在天界宣说阐明「界之差别」的《界論》，「緊接其後」又宣说阐明「施設差別」的《人施設論》，如今注释的时机已到，故「我將解說此論，願諸位攝心專注而聽聞」——这一叙事既把论典归源于佛说，也为注释行为的合法性提供了传统论证。

## 二、文本结构与核心思想

《人施設論》本论以「施設」（paññatti，概念安立、假名施设）为主题，采用类似《增支部》的增一法体例，从「一法人」逐类递增至「十法人」，分类罗列并定义各类型的补特伽罗（puggala）：时解脱者与非时解脱者、俱分解脱者与慧解脱者、随信行者与随法行者等。它关心的不是抽象法相，而是「修行者可以分成哪几种人、各自特征何在」——一部佛教的「人格类型学」。

注释书对应本论分为两大部分：「本母释」（mātikā-vaṇṇanā）先解释论母，说明「施設」一语的六种分类；「广释」（niddesa-vaṇṇanā）再逐条解释各类型人的定义与差别。这一双层结构与觉音其他注释的体例一致：先立纲目，后敷细义。注释的实际内容涉及大量名相辨析——例如「随信行者」与「随法行者」在证悟路径上的差异、「俱分解脱」与「慧解脱」在定慧配比上的分际——这些辨析后来成为上座部修道论（如《清淨道論》相关章节展开的行人分类）的文献基础。

在思想史上，此注的价值还在于「施設」概念的枢纽位置：以「施設」而非「实体」来安立「人」，正是上座部佛教处理「无我」教义与「人」之实用概念之间张力的经典方案——「人」只是假名安立的分类，而非实体性存在。注释忠实地维护了这一立场，使本注成为研究早期部派「补特伽罗」讨论的重要参照。

## 三、学术研究价值与争议

研究价值方面：第一，此注是《人施設論》唯一的古典全注，不读注几乎无法通读论本中高度压缩的定义与类型；第二，它保存了《增支部》增一体例在论书中的移植方式，对研究「经—论」文体关系很有价值；第三，其中的人格类型学直接关系到上座部修道论中「行人根器」的分析传统，可与《清淨道論》《攝阿毗達磨義論》的行人分类互相校核。

争议问题方面：其一，作者问题——觉音名下的注释书是否皆为其亲手所撰，学界长期存疑，部分学者认为其中掺有其学派后人的增补，本注的成书层次亦在此讨论范围之内；其二，注释所依据的僧伽罗语旧注已佚，觉音的工作是「翻译」还是「改写」，关系到注释内容的史料价值定位；其三，「施設」六种分类的具体所指，巴利注释传统内部与近代学者之间存在不同的解读；其四，论本与注释对「补特伽罗」的处理，涉及上座部对「犊子部补特伽罗实体说」的论战背景，如何在本注中辨识这一论战痕迹，尚待深入研究。需要再次强调，此书属巴利藏外注疏文献，不入汉文大藏经编号体系，引证时应以巴利原典及近代校勘本为准。

## 四、术语对照表

| 术语 | 释义 |
|------|------|
| 人施設論（Puggalapaññatti） | 巴利论藏第四部，以「人」之分类施設为主题的论书 |
| 施設（paññatti） | 概念、假名之安立；以名相安立而非实体存在的方式成立「人」 |
| 补特伽罗（puggala） | 人、个体；佛教讨论「人格」「众生」问题的中心概念 |
| 注释书（aṭṭhakathā） | 巴利三藏各部的古典义疏，觉音据僧伽罗语旧注改译巴利语而成 |
| 本母释（mātikā-vaṇṇanā） | 注释书先解释论母、总目纲要的部分 |
| 广释（niddesa-vaṇṇanā） | 注释书逐条敷演论本细义的部分 |
| 俱分解脱（ubhatobhāgavimutta） | 依禅定与智慧两分而得解脱者 |
| 随信行者（saddhānusārī） | 依信心趣入圣道的根器类型，与「随法行者」对说 |
| 觉音（Buddhaghosa） | 五世纪上座部注释传统集大成者，《清淨道論》作者 |
