# 清晰思辯練習本——白話解讀

## 這本練習冊怎麼刷題？

《清晰思辯練習本》是目前唯一正式出版的辯經專項習題冊。它不教新知識——它假設你已經在學（或者學過）攝類學的課本了，然後給你一大堆題目練手。

這本書分三個板塊：

### 第一板塊：基礎題

基礎題主要練四種題型：

**1. 概念定義填空**

> 問：「成事」的定義是什麼？
> 答：被量所成立。

就是考你有沒有記住那些最基本的定義。這一步看起來簡單，但如果定義記不牢，後面的辯題就沒法做。

**2. 兩類事物關係判斷**

> 問：「無常」和「所作性」是什麼關係？
> A. 同義  B. 三種可能  C. 四種可能  D. 相違

答案是A——凡是無常的東西必然是被製造出來的（所作性），凡是所作性的東西也必然是無常的。兩個概念完全重合。

這種題型訓練的是你對概念之間邏輯關係的判斷能力。兩個概念之間的關係通常有幾種：

- **同義**：範圍完全一樣。A就是B，B就是A。
- **三種可能**：A包含B（或B包含A），存在「是A但不是B」的情況，不存在「是B但不是A」的情況。
- **四種可能**：A和B有交叉，存在「是A且是B的」「是A但不是B的」「是B但不是A的」「既不是A也不是B的」四種情況。
- **相違**：A和B不能同時成立，是矛盾的。

**3. 立論仿寫**

給你一個辯題模板，讓你照著格式換一組概念仿寫。比如：

> 模板：「有法——聲音，應是無常，因為是所作性故。」
> 仿寫：「有法——瓶子，應是無常，因為是所作性故。」

這一步是為了讓你練熟應成辯式的句型。

**4. 反例反駁**

給你一個錯誤的主張，讓你舉反例來打倒它。比如：

> 錯誤主張：「凡是存在的都是無常的。」
> 反駁：虛空是存在的但不是無常的（虛空是常法），所以這個主張錯了。

### 第二板塊：拔高題

拔高題比基礎題難很多，主要練三種能力：

1. **心識分類**：給你一個具體的場景，讓你判斷裡面涉及的認知屬於七種心識中的哪一種。
2. **因的判定**：給你一個推理，讓你判斷裡面的理由是好理由（正因）還是壞理由（似因）。
3. **連鎖辯題續寫**：給你一段辯經對話的開頭，讓你接著往下寫。

### 第三板塊：錯題復盤

這個板塊收集了辯經場上最常見的錯誤，一道一道分析給你看。每道錯題都包含：
- 錯誤場景（學生實際犯的錯）
- 錯誤分析（錯在哪裡、為什麼會犯這個錯）
- 正確答案（應該怎麼回答）

## 四句範式怎麼用？

辯經中守方只能用四種標準回答。怎麼判斷該用哪一種？下面給你一個簡單的決策流程：

### 第一步：看結論對不對

攻方說「某某事物應是某某」——這個結論你同不同意？

- 如果結論正確，而且攻方給出了理由 → 回答「**承許**」
- 如果結論正確，但攻方沒給理由 → 回答「**何以故？**」（讓他補充理由）

### 第二步：如果結論不對，看理由對不對

攻方給的理由（因）成不成立？

- 如果理由本身就不成立 → 回答「**因不成**」
  - 例如攻方說「虛空應是無常的，因為虛空是所作性的」——虛空根本不是所作性的，理由就不成立。

### 第三步：如果理由成立但結論不對

那就是理由和結論之間沒有必然的推理關係 → 回答「**不遍**」
- 例如攻方說「虛空應是無常的，因為虛空是成事」——虛空確實是成事，但「是成事」推不出「是無常」（因為成事裡面既有常法也有無常法）。

用流程圖表示：

```
攻方提出應成辯式
    ↓
結論正確嗎？
    ├── 正確 → 有理由嗎？
    │       ├── 有 → 「承許」
    │       └── 沒有 → 「何以故？」
    └── 不正確 → 理由成立嗎？
            ├── 不成立 → 「因不成」
            └── 成立 → 「不遍」
```

## 怎麼判斷自己答對答錯？

《清晰思辯練習本》的每道題都附有標準答案。判斷自己答對答錯的方法很直接——對照答案看：

1. **填空題**：你填的定義和標準答案一模一樣（或語意完全相同）就算對。
2. **關係判斷題**：你選的關係類型和標準答案一致就算對。但注意，光選對關係類型還不夠——你還需要能說出理由（比如舉出或排除反例）。
3. **仿寫題**：你仿寫的辯題格式正確、概念使用恰當、推理有效就算對。
4. **反駁題**：你舉的反例確實能推翻原主張就算對。
5. **錯題復盤**：你能準確識別錯誤所在、並給出正確答案就算掌握了。

### 常見的「答錯」模式

根據書裡的錯題復盤板塊，初學者最容易犯的錯有這幾種：

**模式一：概念記混了**

最典型的就是把「成事」（存在）和「物質」搞混。虛空不是物質，但虛空是成事。不是物質不等於不存在。

**模式二：亂用「不遍」**

很多人拿不準的時候就下意識地說「不遍」，好像能拖延時間。但如果周遍關係其實是成立的（比如「凡所作性必無常」），你說了「不遍」就等於犯了一個明確的錯誤——攻方接下來只要證明周遍成立，你就輸了。

**模式三：只記結論不記理由**

有些題目你「感覺」答案是對的，但說不出理由。在辯經裡，光知道結論不行——你必須能用因明學的語言解釋為什麼。

## 刷題的建議節奏

如果你是自學者，建議這樣安排：

1. **先讀一章課本內容**（比如《賽倉攝類學》的某一章）。
2. **再做練習本裡對應章節的基礎題**。做完對答案，錯了的題重新看課本相關部分。
3. **基礎題全對之後再做拔高題**。拔高題如果做不出來，先放著，等後面學了更多內容再回來做。
4. **最後看錯題復盤板塊**。不管你自己有沒有犯那些錯，都建議認真讀一遍——別人踩過的坑你早知道了，以後就能避開。

一句話：**基礎題全過→拔高題挑戰→錯題復盤鞏固**，這是最有效的刷題順序。

## 能不能完全靠這本書自學辯經？

老實說，不能。

這本書能教你辯經的「語法」（格式、規則、標準答案），但辯經的核心體驗——在壓力下快速思考、面對真人對手的意外提問、在幾秒鐘內判斷該用哪句回應——這些只能在真實的面對面辯論中獲得。

打個比方：你可以靠做題學會國際象棋的所有規則和常見棋路，但下棋的水平只有在和真人對弈中才能提高。

所以，這本練習冊最好的用法是：**作為課本學習的補充和鞏固工具**。如果你有機會參加辯經學習班或找到一起學習的夥伴，那就用這本書做課後練習。如果你是一個人學，那就把它當作自我測驗的工具——做題、對答案、找到自己的薄弱點，然後回到課本上重點鑽研。
