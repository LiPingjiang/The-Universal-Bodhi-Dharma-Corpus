# 論軌 — 学术解读

## 一、文献背景与成书

《論軌》（Vādanyāya，又译《诤论正理》）为法称（Dharmakīrti，约600—660）所造，约成于七世纪，是其因明著作群中专论论辩规则的短篇。梵本大半存世，完整藏译收入丹珠尔；汉地古代无译本，故不在大正藏编号体系之内，现代研究多据梵本与藏译对勘。本目录原文档所收为本论核心义理的提要（破斥二十二负处、收摄为二负处）及术语表，未收全文译文，兹据实撰文。

书名 Vādanyāya 由 vāda（论议）与 nyāya（正理、轨则）合成，直译为「论议之正理」，汉译「论轨」精确传达了「辩论的轨道规则」之义。在法称著作序列中，本论地位特殊：《释量论》等解决「何为正确认知」，本论则解决「何为如法论辩、何为论败」——是佛教认识论向论辩伦理与实践规则的延伸。

## 二、文本结构与核心思想

本论专论论议之轨则与负处（nigrahasthāna，判定落败的情形），其核心贡献是对负处说的大幅简化与重构。

其一，**破正理派的二十二负处**。正理派（Naiyāyika）经典立二十二种负处，涵盖言辞迟钝、重复、声量不当、失念等辩论现场的各种失误。法称逐一检讨，斥其繁琐——原文档所录名句即言：以言辞迟钝、重复、声量等判负，皆非正理。

其二，**收摄为二**。真正的负处唯二：所立不成（自宗有过——己方论题或论证本身立不住）与不能答难（无法回应对方的责难）。除此二者，余皆非真负处。这一化约把胜负判准从仪态、口才等表演性因素中解放出来，只保留与论证有效性直接相关的两项。

其三，**论辩的目的论**。法称为论辩划定基调：论辩的目的在于明真理，不在胜人；若以诡辞取胜而理不明，虽胜犹负。这把「赢」从修辞层面拉回到认识论层面——判定胜负的唯有论证与应答的质量。

## 三、学术研究价值与争议

研究价值：本论是研究印度论辩学（vāda-vidyā）谱系的关键文本——佛教因明从陈那到法称对正理派论辩规则的批判性接收，本论提供了最集中的样本；二十二负处到二负处的化约，被视为一次规则的「科学化」；藏传注疏传统（如萨迦班智达《量理宝藏论》的论辩章）对负处说的进一步讨论即以本论为参照；维也纳学派与日本学界的梵藏对勘研究均以本论为基本文献。

争议问题：其一，二负处的判准边界——「所立不成」是否已涵盖论证的全部实质过失，「不能答难」与「问题本身预设错误时的沉默权」如何区分，注释家有分歧；其二，法称对正理派负处表的批判是否公允——二十二负处自有其论辩现场管理的背景，学界有「是否误读对手」的讨论；其三，本论与《释量论》第四品论辩理论的分工与重复关系。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 负处（nigrahasthāna） | 辩论中判定落败的情形 |
| 所立不成 | 己方论题或论证不能成立，真负处之一 |
| 不能答难 | 无法回应对方责难，真负处之二 |
| 论议（vāda） | 以求真为目的的如法辩论 |
| 能破（dūṣaṇa） | 对敌方论证的驳斥 |
| 正理派 | 印度六派哲学之一，传统论辩学的代表 |
