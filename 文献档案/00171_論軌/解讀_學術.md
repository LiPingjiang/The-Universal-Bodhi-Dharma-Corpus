# 论轨 — 学术解读

## 一、文献背景与成书

《论轨》（Vādanyāya，全名或译《论轨论》《诤论正理》）为法称（Dharmakīrti，约600-660年）所造，约成书于7世纪，是法称"七论"中专论论辩规则的著作，篇幅短小而立场鲜明。梵本大半存世（部分依赖藏译补全），完整藏译收入丹珠尔；汉地无古代译本，现代有据藏译的研究性译本。本论在法称著作序列中地位特殊：如果说《释量论》等解决"何为正确认知"，《论轨》则解决"何为如法论辩、何为论败"——是佛教认识论向论辩伦理与实践规则的延伸。

书名梵语 Vādanyāya：vāda（论议、辩论）+ nyāya（正理、轨则），直译"论议之正理"，汉译"论轨"精确传达"辩论的轨道/规则"之义。

## 二、文本结构与核心思想

本论专论论议之轨则与负处（判输的情形）。其核心贡献是对"负处"（nigrahasthāna，判定落败的节点）的大幅简化与重构：

**其一，破正理派的二十二负处说**：正理派经典（如《正理经》及其注释传统）立二十二种负处，包括言辞迟钝、重复、声量不当、失念等辩论现场的各种失误。法称逐一检讨，斥其繁琐——以言辞迟钝、重复、声量等判负，皆非正理。

**其二，收摄为二**：真正的负处唯二——**所立不成**（自宗有过：你所立的论题/论证本身立不住）与**不能答难**（不能通他难：无法回应对方的责难）。除此二者，余皆非真负处。

**其三，论辩之的在明真理**：法称为论辩划定的目的论基调——论辩的目的在于明真理，不在胜人。若以诡辞取胜而理不明，虽胜犹负。这一立场把"赢"从修辞层面拉回到认识论层面：判定胜负的唯有论证与应答的质量。

## 三、学术研究价值与争议

研究价值方面，本论是研究印度论辩学（vāda-vidyā）谱系的关键文本：佛教因明从陈那到法称对正理派论辩规则的批判性接收，本论提供了最集中的样本。二十二战处到二负处的化约，被视为一次"规则的科学化"——把胜负判准从仪态、口才等表演性因素中解放出来，只保留与论证有效性直接相关的两项。藏传注疏传统（萨迦班智达《量理宝藏论》的论辩章等）对负处说的进一步讨论即以本论为参照。国际学界对《论轨》的研究以维也纳学派及日本学者的梵藏对勘工作为代表。

争议问题包括：（1）二负处的判准边界——"所立不成"是否已涵盖论证的全部实质过失，"不能答难"与"沉默的正当性"（如对方提问本身预设立场）如何区分，注释家有分歧；（2）法称对正理派负处表的批判是否公允——正理派立二十二负处自有其论辩现场管理的背景，学界有"是否误读对手"的讨论；（3）本论与法称其他著作中论辩理论（如《释量论》第四品）的分工与重复关系。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 负处（nigrahasthāna） | 辩论中判定落败的节点 |
| 所立不成 | 自方论题或论证不能成立 |
| 不能答难 | 无法回应对方的责难 |
| 论议（vāda） | 以求真为目的的辩论 |
| 能破（dūṣaṇa） | 对敌方论证的驳斥 |
| 正理派（naiyāyika） | 印度六派哲学之一，论辩学的正统 |
