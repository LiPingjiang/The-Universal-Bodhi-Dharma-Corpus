# 佛教三身研究 — 学术解读

## 一、文献背景与成书

本条目为语料库「寰宇覺海·菩提法藏」之独立文献补充条目，编号 X8211，目录名作「佛教三身研究_1」。据实说明：其《原文》非经论传本，而是三身名数的主题辑录，概述列「法身、報身、化身」三名，选录与名句各存两条引文，术语表七条，末附相关文献指引。与姊妹条目 `09219_佛教三身研究` 所录文字全同，可知为同一底稿在语料库不同编号位的分置；条目 README 自署「待後續填充內容」，性质均为名目型简编。本条目拟专就三身概念的历史演化与诸宗异说作纵向梳理，与前条之结构分析（体相用框架）分工互补。

三身概念的历史演化可分四期。第一期，原始佛教与部派的二身阶段：以释尊之生身为生身，以佛所具戒定慧解脱功德为法身，此说见于《长阿含·游行经》等；此期「法身」是德性的集合义，尚无宇宙实相之义。第二期，般若与法华的扩展阶段：《金刚般若经》以「若見諸相非相，即見如來」遮止以身见佛，《法华经·寿量品》开显佛寿久远——「我成佛已來，甚大久遠」，为「报身久远」说埋下伏笔。第三期，瑜伽行派的定型阶段：《摄大乘论》果智分立受用身与化身而合自性身为三，《佛地经论》以自性身、受用身、变化身为佛地三事，名相与分判从此定型。第四期，汉土诸宗的再诠释阶段：此为下节详述之重点。

## 二、文本结构与核心思想

《原文》五节为补充条目通例，其于诸宗诠释中的异说可梳理为四系。

其一，华严系的三身十佛说。法藏《华严经探玄记》判佛身，于三身外别开解境十佛（众生身、国土身、业报身乃至虚空身等皆佛身）与行境十佛，其旨在于以「无碍」破三身之分段——佛身即法界，故一一行境皆具三身。本条目引文「隨類現身」四字在十佛义下被极度扩充：不但人天是化身，山河草木无非佛身。

其二，天台的三身相即说。天台家以法报化三身为一心三观的果上显现：法身中道、报身空观、化身假观，三身即一佛身之德用，立「三身相即」义；并配合法华开显，谓报化用歇而法身不灭。三身从「三种存在」转为「一心的三种显现」，是心性化诠释的典型。

其三，禅宗的自性三身佛。《六祖坛经·忏悔品》以自性三身释三身：清净法身佛谓自性本自清净，圆满报身佛谓一念善心生起即圆报，千百亿化身佛谓心行慈悲即化身——三身全收于当下一念，经典佛身论被彻底内化：「若離本性，別說三身，即名有身無智」。此系对后世汉地佛教的佛身观影响至巨。

其四，净土宗的报身判摄。善导系判阿弥陀佛为报佛、极乐为报土，以《大经》四十八愿修行所感为据，回应了「凡夫何以得生报土」之问，其「凡入报土」义是三身说在净土教门的特色开展。密教的四身说（法身、报身、化身加自性身或大乐身）则为藏传金刚乘的框架，视传承而定，多不在大正藏编号体系之内。

## 三、学术研究价值与争议

第一，三身演化的思想史意义是「佛陀观的神学化」程度的标尺。从历史上的人间导师，到具足相好的报身，到遍一切处的法身，佛的「存在规模」逐级放大；学界对此演化的动因有「佛灭后思念说」（信众对佛陀怀念推动理想化）、「经典神圣化需要说」等 competing 解释，为中观—净土—如来藏研究共享的基础课题。本条目名数简编虽不涉此层，却是全部争论所环绕的公分母。

第二，法身的两种义涵之辨。「法身」在经论中或指以佛法为身（戒定慧等道谛功德，近于早期义），或指以法界真如为体（宇宙实相义），两义在汉译文献中同用一词，极易相混；玄奘系以「自性身」专指后者而与「法身」的宽泛用法有所区分。辨析此两义，是读通一切三身文献的前提。

第三，三身与如来藏思想的交涉。《楞伽经》以法身为如来藏之果位名（如来藏为因位名），法藏《大乘起信论义记》以本觉释法身，使法身义从静态理体向动态本觉转化——此一「法身活化为觉性」的路线，是东亚佛教（华严、禅）区别于印度唯识原义的显著特征，也是近现代批判佛教（袴谷宪昭、松本史朗）论争的焦点之一。

第四，比较研究维度：三身与基督教三位一体、印度教化身说（avatāra）的结构比较，须警惕名词表层的相似；化身说与 avatāra 同属神力的世间显现，但化身在佛教中不承担救赎盟约的独一性，法身亦非位格神。又藏传各派佛身论另有四身五身之别说，其根本典籍不在大正藏编号体系之内，应检德格版《甘珠尔》《丹珠尔》。
