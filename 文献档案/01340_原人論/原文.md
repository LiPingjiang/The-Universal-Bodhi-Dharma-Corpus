# 原人論

## 一、概述

**大正藏編號**：T1886（《大正新脩大藏經》第 45 冊）

**全稱**：《原人論》，通行亦題《華嚴原人論》

**撰者**：唐·宗密（780—841），圭峰大師，諡定慧禪師，華嚴宗五祖，兼嗣荷澤禪系

**卷數**：一卷

《原人論》是宗密晚年的代表作，也是中國佛教思想史上最著名的判教與三教論衡文獻之一。書名中的「原」是動詞，取「窮本究原」之義（如《漢書》顏師古注「原，謂尋其本也」）；「原人」即推究人之所以為人的終極本源。

全書結構分為序與四篇：

- **序**
- **斥迷執第一**（習儒道者）——破斥儒家、道家的元氣論、自然論、天命論
- **斥偏淺第二**（習佛不了義教者）——破斥佛教內部人天教、小乘教、大乘法相教、大乘破相教四種「不了義」之說
- **直顯真源第三**（佛了義實教）——正面顯示一乘顯性教的本覺真心
- **會通本末第四**（會前所斥，同歸一源）——回過頭來把前面所破斥的各家，重新統攝於真心一源之中

宗密在此建立了一個含攝儒道在內的五重判教序列：**儒道教 → 人天教 → 小乘教 → 大乘法相教 → 大乘破相教 → 一乘顯性教**。

此書方法論上最有特色之處在於「先破後會」：前兩篇層層破斥，第三篇正顯真源，第四篇則不棄前說，反而將被破斥的各家一一安置於真心緣起的次第之中——所謂「會通本末」。這種既批判又包容的姿態，使《原人論》成為中國「三教合一」思潮的重要理論文本。宗密另有《禪源諸詮集都序》主張「禪教合一」，與此書構成其融合論的兩翼。

## 二、核心段落

### （一）序：萬物皆有本源

**原文：**

> 萬靈蠢蠢，皆有其本；萬物芸芸，各歸其根。未有無根本而有枝末者也。況三才中之最靈，而無本源乎？

**白話對照：**

芸芸眾生蠢蠢而動，都各有其根本；萬事萬物紛紜繁盛，最終都要回歸其根柢。從來沒有哪樣東西是沒有根本卻能生出枝葉末梢的。

何況人是天、地、人三才之中最有靈性的存在，難道反而會沒有本源嗎？

（按：「萬物芸芸，各歸其根」化用《老子》「夫物芸芸，各復歸其根」，「三才」出《周易》。宗密開篇即以儒道語彙立論，正見其會通姿態。）

### （二）斥迷執第一：儒道二教之說

**原文：**

> 儒道二教說：人畜等類，皆是虛無大道生成養育。謂道法自然，生於元氣；元氣生天地，天地生萬物。故愚智貴賤貧富苦樂，皆稟於天，由於時命；故死後卻歸天地，復其虛無。
>
> 然外教宗旨，但在乎依身立行，不在究竟身之元由。所說萬物，不論象外；雖指大道為本，而不備明順逆起滅、染淨因緣。故習者不知是權，執之為了。今略舉而詰之。

**白話對照：**

儒、道兩家說：人與禽獸等一切生類，都是由虛無大道所生成養育的。他們認為「道」以自然為法，從自然中生出元氣；元氣生出天地，天地再生出萬物。所以愚笨與聰慧、尊貴與卑賤、貧窮與富有、痛苦與安樂，都是稟受於上天、取決於時運命數；因此死後又復歸於天地，回到那虛無之中。

然而這些外教的宗旨，只在於依託此身而確立行為規範，並不在於追究此身的終極來由。他們所談論的萬物，不涉及形象之外的層面；雖然指認「大道」為根本，卻沒有完備地闡明順逆、起滅、染淨的因緣道理。所以學習的人不知道那只是權宜之說，反而執著它為究竟了義。現在略舉幾點來詰問。

### （三）詰難之一：以大道為本的困難

**原文：**

> 所言萬物皆從虛無大道而生者，大道即是生死賢愚之本，吉凶禍福之基。基本既其常存，則禍亂凶愚不可除也，福慶賢善不可益也，何用老莊之教耶？
>
> 又道育虎狼、胎桀紂、夭顏冉、禍夷齊，何名尊乎？

**白話對照：**

你們說萬物都是從虛無大道而生，那麼大道就成了生死、賢愚的根本，也成了吉凶、禍福的基礎。既然這個根基是恆常存在的，那麼禍亂凶愚就無法去除，福慶賢善也無法增益——那還要老子、莊子的教化做什麼呢？

再者，若說大道生育一切：它養育了虎狼這樣的猛獸，孕育了桀、紂這樣的暴君，卻讓顏回、冉耕這樣的賢者早夭，讓伯夷、叔齊這樣的義士遭禍——這樣的「道」，憑什麼稱得上尊貴呢？

### （四）詰難之二：自然生化說的困難

**原文：**

> 又言萬物皆是自然生化，非因緣者，則一切無因緣處悉應生化。謂石應生草，草或生人，人生畜等。又應生無前後，起無早晚；神仙不藉丹藥，太平不藉賢良，仁義不藉教習——老莊周孔何用立教為軌則乎？

**白話對照：**

又說萬物都是自然而然地生化，並非依因緣而有。那麼一切沒有因緣的地方都應該能夠生化才對：石頭應該能生出草，草或許能生出人，人又能生出禽獸，如此等等。

而且生成應該沒有先後之別，發起應該沒有早晚之分；那麼神仙就不必憑藉丹藥，太平之世就不必依靠賢良之臣，仁義也不必經由教導修習而成——既然如此，老子、莊子、周公、孔子又何必建立教化來作為準則呢？

### （五）詰難之三：元氣說與天命說的困難

**原文：**

> 又言皆從元氣而生成者，則歘生之神未曾習慮，豈得嬰孩便能愛惡驕恣焉？
>
> 且天地之氣本無知也，人稟無知之氣，安得歘起而有知乎？草木亦皆稟氣，何不知乎？
>
> 又言貧富貴賤、賢愚善惡、吉凶禍福皆由天命者，則天之賦命，奚有貧多富少、賤多貴少，乃至禍多福少？苟多少之分在天，天何不平乎？
>
> 況有無行而貴、守行而賤，無德而富、有德而貧，逆吉義凶、仁夭暴壽，乃至有道者喪、無道者興。既皆由天，天乃興不道而喪道，何有福善益謙之賞、禍淫害盈之罰焉？

**白話對照：**

又說人都是從元氣生成的。那麼那忽然生出的精神從未經過學習思慮，嬰孩怎麼一出生就懂得愛憎、懂得驕縱任性呢？

況且天地之氣本身是沒有知覺的，人稟受了無知覺的氣，怎麼會忽然生起而有了知覺呢？草木同樣稟受了氣，為什麼卻沒有知覺呢？

又說貧富貴賤、賢愚善惡、吉凶禍福都由天命決定。那麼上天賦予命運，為何貧的多而富的少、賤的多而貴的少，乃至禍多而福少？如果這多寡之分都在於天，那天豈不是太不公平了嗎？

更何況現實中有品行不端卻顯貴的、恪守德行卻卑賤的，無德的富有、有德的貧困，悖逆者吉利、仗義者凶險，仁厚者早夭、暴虐者長壽，乃至有道之人敗亡、無道之人興盛。既然都由天定，那就是上天在扶助無道而毀棄有道了——那還談什麼「福善」「益謙」的獎賞、「禍淫」「害盈」的懲罰呢？

### （六）斥迷執的結論

**原文：**

> 又既禍亂反逆皆由天命，則聖人設教，責人不責天，罪物不罪命，是不當也。然則《詩》刺亂政，《書》讚王道，《禮》稱安上，《樂》號移風，豈是奉上天之意、順造化之心乎？
>
> 是知專此教者，未能原人。

**白話對照：**

再者，既然禍亂與叛逆都出於天命，那麼聖人設立教化時，責備的是人而不是天，歸罪於行事者而不歸罪於命運，這就講不通了。既然如此，《詩經》譏刺亂政、《尚書》讚揚王道、《禮記》稱說安定君上、《樂經》主張移風易俗——這些難道是在奉行上天的意旨、順從造化的心意嗎？

由此可知：**專守這一套教說的人，還不能真正推究出人的本源。**

### （七）斥偏淺第二：佛教內部的五重淺深

**原文：**

> 佛教自淺之深，略有五等：一、人天教；二、小乘教；三、大乘法相教；四、大乘破相教（上四在此篇中）；五、一乘顯性教（此一在第三篇中）。

**白話對照：**

佛的教法由淺入深，大略有五個等級：第一，人天教；第二，小乘教；第三，大乘法相教；第四，大乘破相教（以上四種在本篇中破斥）；第五，一乘顯性教（這一種放在第三篇「直顯真源」中正面闡明）。

### （八）人天教的內容

**原文：**

> 一、佛為初心人，且說三世業報、善惡因果。謂造上品十惡，死墮地獄；中品餓鬼；下品畜生。故佛且類世五常之教，令持五戒——不殺是仁，不盜是義，不邪淫是禮，不妄語是信，不飲啖酒肉、神氣清潔益於智也——得免三途，生人道中。修上品十善及施戒等，生六欲天。

**白話對照：**

第一，佛陀為初發心的人，姑且宣說三世的業報與善惡因果。就是說：造作上品的十種惡業，死後墮入地獄；中品的墮為餓鬼；下品的墮為畜生。

所以佛陀姑且比照世間五常的教化，令人受持五戒——不殺生相當於「仁」，不偷盜相當於「義」，不邪淫相當於「禮」，不妄語相當於「信」，不飲酒食肉則使神氣清潔而有益於「智」——如此便能免墮三惡道，得生於人道之中。若修上品十善以及布施持戒等，則能生於六欲天。

（按：以五戒配五常，是宗密會通儒佛最著名的具體操作，對後世三教合一影響極大。）

## 三、名句

**其一**

> 萬靈蠢蠢，皆有其本；萬物芸芸，各歸其根。未有無根本而有枝末者也。況三才中之最靈，而無本源乎？

芸芸眾生都各有根本，萬物紛紜都要歸於根柢。從來沒有無根本而有枝末的事。何況人身為三才中最具靈性者，豈能沒有本源？

這是《原人論》的開卷第一句，也是全書的問題意識所在。宗密刻意採用《老子》「夫物芸芸，各復歸其根」與《周易》「三才」的語彙來提出佛教的終極追問——這一姿態本身就宣告了：他要在儒道共享的語境中，論證只有佛教能夠回答「人從何來」。此句因其氣象宏闊、辭旨警策，成為漢傳佛教論著中傳誦最廣的開篇之一。

**其二**

> 是知專此教者，未能原人。

由此可知，專守這一套教說的人，還不能真正推究出人的本源。

這是《原人論》全書反覆出現的判語句式。宗密在破斥每一層教說（儒道、人天、小乘、法相、破相）之後，都以類似的斷語作結，如同層層剝筍。此句的力量不在於否定，而在於它預設了一個更高的立足點——被否定的並非「錯」，而是「未盡」。這正是宗密判教的基本精神，也為第四篇「會通本末」的回收埋下伏筆。

## 四、術語表

| 術語 | 說明 |
|-----|------|
| **原人** | 「原」為動詞，窮本究原之義；「原人」即推究人之所以為人的終極本源。書名點題。 |
| **斥迷執** | 第一篇篇名。破斥儒道二教在人之本源問題上的迷惑執著。 |
| **斥偏淺** | 第二篇篇名。破斥佛教內部人天、小乘、法相、破相四種不了義教的偏頗淺薄。 |
| **直顯真源** | 第三篇篇名。正面顯示一乘顯性教所說的本覺真心，即人的究竟本源。 |
| **會通本末** | 第四篇篇名。回過頭來把前面所破斥的諸家，會通統攝於真心一源之中，各安其位。 |
| **五等判教** | 人天教、小乘教、大乘法相教、大乘破相教、一乘顯性教。若加上儒道教，則成六重序列。 |
| **一乘顯性教** | 宗密判教的最高一級，指直接顯示本覺真心（如來藏）的教法，如《華嚴》《圓覺》《起信論》。 |
| **大乘破相教** | 指般若中觀一系，破斥一切相而顯空義。宗密判其為「破相」而未能顯性，故仍屬不了義。 |
| **大乘法相教** | 指唯識瑜伽一系，析辨萬法唯識所現。 |
| **本覺真心** | 眾生本自具足的覺性真心，即如來藏。宗密以此為「人之本源」的最終答案。 |
| **元氣** | 道家與漢代宇宙論的核心概念，指構成天地萬物的原初之氣。宗密以「無知之氣不能生有知」破之。 |
| **虛無大道** | 道家所立的終極本體。宗密以「基本常存則凶愚不可除」破之。 |
| **天命** | 儒家所說決定人生際遇的天所賦予之命。宗密以現實中「逆吉義凶、仁夭暴壽」的不公破之。 |
| **五戒配五常** | 宗密的著名會通：不殺配仁、不盜配義、不邪淫配禮、不妄語配信、不飲酒配智。 |
| **三才** | 天、地、人。出《周易·說卦》。宗密借此指出人為最靈，必有本源。 |
| **權／了** | 權，權宜方便之說；了，究竟了義之說。宗密批評儒道學者「不知是權，執之為了」。 |

## 五、相關文獻

**宗密本人的相關著作**

- 《禪源諸詮集都序》（T2015，四卷）：主張「禪教合一」，以三宗三教相配。與《原人論》的「三教合一」構成宗密融合論的兩翼。
- 《圓覺經大疏》《圓覺經大疏釋義鈔》《圓覺經略疏》（T1795）《圓覺經略疏鈔》：宗密畢生用力最深的一組著作。
- 《注華嚴法界觀門》（T1884）：註釋杜順《法界觀門》。
- 《中華傳心地禪門師資承襲圖》：論述禪門各家宗旨與傳承。
- 《遙稟清涼國師書》：宗密致澄觀的書信，附於《圓覺經略疏》之後，含其生平自述。

**思想淵源**

- 澄觀《大方廣佛華嚴經疏》（T1735）、《隨疏演義鈔》（T1736）：宗密之師，「一真法界即諸佛眾生本源清淨心」為《原人論》真心說所本。
- 法藏《華嚴一乘教義分齊章》（T1866）：五教判的原型，宗密的五等判教由此改造而來。
- 《大乘起信論》（T1666）：本覺真心、一心二門之說的根本論典。
- 《大方廣圓覺修多羅了義經》（T842）：宗密判為一乘顯性教的代表經典。

**所破斥的外典**

- 《老子》：「道法自然」「夫物芸芸，各復歸其根」。
- 《周易》：三才、造化之說。
- 《詩》《書》《禮》《樂》：宗密以聖人設教「責人不責天」反詰天命論。

**後續影響**

- 宋·淨源《原人論發微錄》（三卷）：最早的《原人論》註釋。
- 元·圓覺《原人論解》（三卷）。
- 明·楊嘉祚《原人論合解》。
- 裴休《唐故圭峰定慧禪師傳法碑並序》：宗密生平最重要的傳記材料，柳公權篆額。
