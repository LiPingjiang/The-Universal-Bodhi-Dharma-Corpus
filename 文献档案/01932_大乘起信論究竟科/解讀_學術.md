# 大乘起信论究竟科 · 学术解读

## 一、文献背景与成书

先说明本档性质：题名中的「大乘起信論究竟科」一名，是文献整理过程中机生成的注疏变体名，并不对应历史上实际存在过的独立注疏著作，该目录所存的原文档亦仅为说明性的名目档，未收具体经文或疏文。但这一名目把两个真实存在的东西联系了起来：一是《大乘起信論》这部大乘论书，二是"科"——即科判、科文——这一汉传佛教注疏传统中最具特色的文献体裁。

《大乘起信論》相传为马鸣菩萨造、梁代真谛三藏译（大正藏 No.1666，一卷），唐代实叉难陀另有重译本（No.1667，二卷）。全书以"一心二门三大"组织大乘义理，篇幅短小而纲领宏大，历代注疏极多，隋净影慧远《大乘起信論義疏》、唐法藏《大乘起信論義記》、新罗元晓《大乘起信論疏》、宗密注疏、宋子璇《大乘起信論疏筆削記》、明憨山德清《大乘起信論直解》、智旭《大乘起信論裂網疏》等前后相望。这些注疏无一例外都带有细密的科判：把短短一卷论划分为若干大段、中段、小段，逐层标举段落大意，形成一张"义理地图"。古人因此又专门抽出单行的科文，如语料库中著录的《大乘起信論科文》。至于"究竟"二字，本是判位用语：科判不仅要切分文字段落，还要给每一段定位次——是劝初信，还是判至佛果；"究竟"即指科分中判至果位穷极处而言。

## 二、文本结构与核心思想

从科判的视角看，《大乘起信論》正文被通行为五分：因缘分、立义分、解释分、修行信心分、劝修利益分。

因缘分述马鸣造论的八种因缘，相当于全论的序言，说明为何要"起信"；立义分提出总纲，即以"众生心"为所依之法，开一心为真如、生灭二门，标举体、相、用三大；解释分为全论重心，先"显示正义"（一心二门、觉与不觉、三细六粗、熏习之义），次"对治邪执"（破人我见、法我见等五种执），后"分别发趣道相"（信成就发心、解行发心、证发心）；修行信心分立四种信心（信根本真如及佛法僧）与五行（布施、持戒、忍辱、精进、止观），是全论的实践出口；劝修利益分则总结闻持功德，劝导流通。科判传统把这一结构读成一条从初发心到究竟觉的路线：立义是目标，解释是道理，修行是道路，劝修是推动。注家科分宽严不同——慧远疏与法藏义记在段落判属上即有出入——但"以科判把短论读成完整的修行地图"这一意图，正是汉地疏钞之学的共同品格。本名目以"究竟"冠于"科"前，提示的正是科判将论义判至佛果究竟的向度，可与本系列中侧重义理总摄的「大乘起信論圓滿科」条目互参。

## 三、学术研究价值与争议

科判是研究中国佛教诠释学的绝佳标本。其一，它显示了汉地注家如何为一部义理密集的短论设定"阅读程序"：读者依科而入，先见其纲，后寻其目，义不紊乱。其二，不同注家的科分差异本身就是思想差异的痕迹：把某一段判属"显示正义"还是"对治邪执"，牵动对论义的总体理解，比较慧远、法藏、元晓三家科判，可以重建各自的诠释立场。其三，科判还关乎文献的物理形态——禅林讲经时科文单行，讲者执科以临文，敦煌写本中亦有科判节略之体，这是书籍史与讲经制度史的素材。争议方面：现代学界对《大乘起信論》的作者（马鸣）与译者（真谛）均有系统质疑，相关公案详见「大乘起信論了義探」条目；一旦论之成立时代后移，则围绕它生长千年的科判传统便呈现出"传统为经典加冕"的再生产过程，其研究价值不减反增——它说明一部文本的经典性，很大程度上是被注疏与科判逐层塑造出来的。

## 四、术语对照表

| 术语 | 简释 |
|---|---|
| 科判／科文 | 将经论分段标目、显示结构的注疏体裁，科文为抽出的单行大纲 |
| 五分 | 起信论正文的因缘分、立义分、解释分、修行信心分、劝修利益分 |
| 一心二门 | 一心开真如门与生灭门，二门各总摄一切法 |
| 三大 | 体大、相大、用大，众生心所显示的摩诃衍义 |
| 八因缘 | 因缘分所列造论缘由，"为欲令众生离苦得解脱故"等 |
| 显示正义 | 解释分第一段，正面成立一心二门之义 |
| 对治邪执 | 解释分第二段，破斥人我见、法我见等执著 |
| 究竟觉 | 觉行圆满之位，科判用语中"究竟"多指判至此位 |
| 疏钞之学 | 疏解经论、再作钞记的中国佛教注疏传统 |
