# 中論頌與佛護釋 — 学术解读

## 一、文献背景与成书

《中论佛护释》（Buddhapālita-mūlamadhyamaka-vṛtti）是印度论师佛护（约五至六世纪）为龙树《中论颂》所作的逐品注释。佛护生平资料稀少，一般认为他活动于南印度，年代早于清辨而晚于青目。此释在古代没有汉译，因此无《大正藏》T号；完整文本主要由藏译保存，近代又发现梵文贝叶经残片。2021年出版的叶少勇《〈中论佛护释〉译注》即以藏译本和梵文残片为依据，首次将全书系统译为现代汉语。故本目录所谓"佛护释"绝不能误指T1564：T1564是鸠摩罗什所译青目释，二者在载体、年代和解释方法上均不相同。

佛护所处时代，印度佛教论辩与因明方法正走向精密化。他不满足于早期释本的随文解义，而常把龙树简短偈颂补写成完整的辩论过程。稍后的清辨在《般若灯论》中批评佛护未自行提出规范的独立论证；七世纪月称则在《明句论》中为佛护辩护并反批清辨。佛护因而成为后来中观方法论分歧的枢纽。

现存藏译收入丹珠尔中观部，梵文残片则只覆盖部分章节，不能取代完整藏本。现代汉译需要在藏译句法、残片读法和《中论》颂本之间反复校勘。因此，引用佛护时应说明所据现代译本，尤其不能把罗什汉译偈句直接说成佛护释的汉文原句；二者可能表达同一颂义，却属于不同传承层次。

## 二、文本结构与核心思想

佛护释依《中论》二十七品次第展开，核心仍是缘起无自性，但诠释重点落在"如何破执"。其典型办法是暂且接受对手的概念与前提，推出对手自己不能承认的荒谬后果。例如，对方若主张事物从自身产生，便要解释一个已经存在的东西为何还需再次产生；若主张从全然不同的他者产生，则黑暗也应能从火焰生出。论证的力量来自对方前提内部，而不是中观师先安立一个同类实体理论。

后世把这种办法称为prasaṅga，常译"应成"或"归谬"。它不是拒绝一切语言与理性，而是认为胜义观察中若先设一个自性成立的共同对象，再用独立三支比量证明其空，会把待破的自性偷偷带回论证。佛护由此突出中观的治疗性：指出执著结构的矛盾，使错误见解自行松脱。世俗层面仍可依约定谈人、瓶、因果和修道；被否定的是这些事物不依条件而成立的自性。

## 三、学术研究价值与争议

佛护释的价值首先在于展示五至六世纪中观由简明释义转向系统论证的过程；其丰富的敌论重构，也是研究当时部派佛教、数论等思想的重要资料。其次，清辨批评、月称辩护所形成的三方文本链，使学者能够具体研究印度逻辑学进入中观之后的冲突与改造。再次，梵文残片与藏译对勘，可校订《中论》颂文，并观察藏译术语如何重构梵语论证。

争议集中于"应成派"的历史定位。藏传后期常把佛护视为应成派先驱，把清辨归入自续派；但这些宗派名称并非佛护自称，将成熟的西藏分宗直接投射到六世纪印度，容易造成时代错置。现代研究还争论佛护究竟是完全"只破不立"，还是仍隐含积极的认识论承诺。近年叶少勇等从早期中观与后期中观的差异出发，强调佛护不能简单等同月称；也有研究继续从月称—宗喀巴传统解释佛护。无论采取哪种立场，都应把佛护释视为独立文本，而非月称体系的预告片。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 佛护释 | 佛护对《中论颂》的逐品注释，古代完整本主要存于藏译 |
| 应成 | 依据对手承认的前提，推出其不能接受的结论 |
| 归谬 | 通过显示某主张导致矛盾或荒谬后果来破斥它 |
| 自续比量 | 论者以双方共同承认的宗、因、喻主动成立命题的方法 |
| 无自性 | 事物不以独立、恒定、不待缘的方式存在 |
| 他比量 | 主要依据对方自许前提而构成的论证形式 |
