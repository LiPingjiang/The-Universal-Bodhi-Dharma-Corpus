# 十二門論註疏 — 学术解读

## 一、文献背景与成书

《十二门论》一卷，收《大正藏》第三十册，编号T1568，传统题龙树造、后秦鸠摩罗什译，一般系于弘始十一年（409）前后。全论以二十余首偈颂及长行解释组成，按十二种观察方法阐明诸法无生。梵文原本与藏译均未传，现存汉译因而具有孤本性质。其若干偈颂与《中论》《七十空性论》等相同或近似，作品究竟是龙树亲撰的独立论书、对龙树材料的纲要汇编，还是经汉译场整理成形，现代研究仍须从文本层次审慎判断。

《十二门论》与《中论》《百论》合称"三论"，是中国三论宗立宗依据。重要注疏有隋代吉藏《十二门论疏》六卷，收《大正藏》第四十二册T1825；唐代华严宗法藏《十二门论宗致义记》二卷，收同册T1826。前者以三论宗"破邪显正"、二谛中道阐释，后者则从华严圆融立场重读空有关系，显示同一论典在不同宗派中的再诠释。

由于只有汉译本，历代刻藏、敦煌残卷及注疏引文对校勘格外重要。吉藏疏所见句读未必与现代标点本相同，法藏义记又会依华严宗旨重新分科。讨论原论时须先剥离后世科判，但也不能忽略注疏保存的早期异文和解释线索；孤本研究正依赖这种双重处理。

## 二、文本结构与核心思想

十二门依次为：观因缘、观有果无果、观缘、观相、观有相无相、观一异、观有无、观性、观因果、观作者、观三时、观生。所谓"门"，是进入空观的十二个入口，而不是十二条互不相关的教义。前几门从因缘与结果入手：若果在因中已存在，便无须再生；若完全不存在，因又如何生果；若四缘本身被当作实有，也会与待缘而成相矛盾。中段检查生、住、灭等相与有无、一异、自性，后段再分析因果、作者、过去现在未来以及"生"本身，层层消除对固定实体的执取。

首门偈"众缘所生法，是即无自性；若无自性者，云何有是法"是全论纲领。它不是否认日常出现的瓶、芽和身心活动，而是在众缘的一一部分、和合整体及众缘之外，都找不到一个独立果体。长行列举泥团、陶师和轮绳合成瓶，种子、土水与时节促成芽，说明"有"只是依缘安立。由有为法无自性，进一步观察我与涅槃，也不可另立固定实体。

## 三、学术研究价值与争议

《十二门论》的价值首先在于以短篇幅浓缩中观论证，适合研究汉译中观的概念结构。其次，因无梵藏对本，它能突出罗什译场在术语选择、偈颂编排与长行说明上的创造作用。再次，吉藏与法藏注疏形成三论宗、华严宗两套解释史：吉藏重在破除一切有所得见，法藏则强调真空与幻有相即，由此可考察中国宗派如何吸收印度论书。

主要争议是作者与成书层次。传统坚持龙树造；现代学者则注意到大量偈颂与《中论》重合、汉译之外无直接见证，因而提出汇编或译场编整的可能，但尚不足以简单否定传统题署。第二，"一切法空"究竟是本体论否定、语言分析还是修行性的去执，各家侧重不同。第三，后代以华严圆融解释本论，是否忠于早期中观，还是中国思想的新创造，也值得区分。研究时应把原论、吉藏疏、法藏义记分别定位，不以某一后期注解代替原文。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 十二门 | 从因缘至生的十二种观察路径，皆通向无自性 |
| 无生 | 否定具自性的真实生起，不否认世俗缘起现象 |
| 四缘 | 因缘、次第缘、缘缘、增上缘四类条件 |
| 三论 | 《中论》《百论》《十二门论》的合称 |
| 破邪显正 | 通过破除有、无等执著，使中道实相显现 |
| 境智 | 所观实相之境与能观般若之智，吉藏释论的重要范畴 |
