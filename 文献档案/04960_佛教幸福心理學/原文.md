# 佛教幸福心理學 · 原文

## 一、學科概述

幸福心理學（hedonic/eudaimonic psychology）研究幸福的本質、測量與來源，區分享樂主義幸福（hedonia，愉悅與滿足）與實現論幸福（eudaimonia，意義與繁盛），主觀幸福感（SWB，含生活滿意度、積極情緒、消極情緒）是其標準測量框架。佛教與此的交匯是「佛教×心理學」研究中最經典的板塊。標誌性事實有三：其一，馬修·理卡德——法國分子生物學家出身、後出家為藏傳佛教僧侶——在戴維森實驗室的腦成像研究中表現出顯著的左前額葉激活（與積極情緒相關）與對驚嚇刺激的快速恢復，被媒體稱為「世界上最快樂的人」，他本人則以此推廣「幸福是可訓練技能」的命題；其二，享樂適應研究（布里克曼與坎貝爾1971年提出「享樂跑步機」概念，中彩票者與截癱者的幸福感研究）為佛教「樂受皆苦」的古老判斷提供了實驗對照；其三，世界幸福報告與各國幸福政策的興起，使「幸福的可訓練性」成為公共政策議題，正念與慈悲訓練被多國納入福祉教育。

## 二、核心議題與佛教觀點

核心議題包括：（一）享樂適應與「壞苦」——人對得失榮辱的心理適應速度快得驚人，享樂跑步機使人終生追逐而幸福不增；佛教把依緣而生的樂受判為「壞苦」，診斷在兩千五百年後獲得實驗證實，其對策不是更快的跑步機而是「下跑步機」——離渴求的平靜；（二）比較幸福學——幸福大半是比較的產物（社會比較理論），佛教「隨喜」（對他人之樂的欣悅）是唯一使比較心理增益幸福的古典技術；（三）收入與幸福的悖論——伊斯特林悖論（收入增長與幸福感長期不同步）與佛教「少欲知足」的經濟倫理互證；（四）幸福的三種層次——現代框架的享樂幸福、實現幸福之外，佛教提出第三層：寂靜之樂（santi sukha）——離煩惱本身的安樂，這是無法被跑步機稀釋的幸福；（五）利他與幸福——大量研究顯示助人與捐贈提升施予者幸福（「helper's high」），與佛教布施、慈悲訓練的實證研究（弗雷德里克森的慈心禪研究）匯流。經典依據取《法句經》「無病最利，涅槃最樂」。

> **經典依據**：
> 「無病最利，知足最富，誠信為親，涅槃最樂。」——《法句經》（T210）

此偈是佛教幸福觀的四極坐標：最大利益是無病（健康優先於財富）、最大富足是知足（主觀幸福感獨立於客觀條件）、最親者是誠信（關係品質為幸福之本）、至樂是涅槃（幸福的終極形態是煩惱的止息）——每一條都與當代幸福研究的核心發現對位，可謂古典的幸福心理學提要。

## 三、代表學者與實踐

理卡德著有《快樂學》（Happiness, 2003年），系統闡述「幸福作為技能」的修行—科學論證，並與父親（哲學家讓-弗朗索瓦·何維）的對談錄《僧侶與哲學家》（1997年）成為西方佛教普及的經典。戴維森（威斯康辛大學）的長期禪修者系列研究確立了禪修改變情緒風格的證據；其與理卡德合著《大腦的情緒生活》把研究公共化。心理學家索尼婭·柳博米爾斯基（Sonja Lyubomirsky，《幸福的方法》作者）的「幸福定點理論」與干預研究（感恩、善意行動等「幸福的怎樣做」）與佛教修行清單有大量重合；理查德·戴維森、理卡德等共同創立的「心智與生命研究所」對話持續推動「幸福科學與 contemplative 科學」的制度性合作。不丹的「國民幸福總值」（GNH）政策框架亦以佛教價值為底色，成為幸福經濟學的重要案例。

| 術語 | 釋義 |
|---|---|
| 主觀幸福感 | 個體對生活滿意度與情緒平衡的總體評價 |
| 享樂適應 | 對積極或消極事件的心理回歸基線傾向 |
| 壞苦 | 依緣而生的樂受，必然變異衰變 |
| 隨喜 | 對他人成就與善樂的真誠欣悅 |
| 寂靜之樂 | 離煩惱的安樂，佛教幸福的至高形態 |
| 國民幸福總值（GNH） | 不丹提出以幸福為本的發展指標體系 |
