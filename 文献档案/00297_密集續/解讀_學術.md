# 密集续（Guhyasamāja-tantra）— 学术解读

## 一、文献背景与成书

《密集续》（Guhyasamāja-tantra，"秘密集会续"）是印度佛教无上瑜伽部（Anuttarayoga-tantra）最重要、最古老的续典之一，学界一般断代于公元7–8世纪。本档案编号 V30，原始语言为梵语，后经译师藏译，收入藏文《甘珠尔》秘密部，格鲁派将其与时轮续、胜乐续并列为三大无上瑜伽续，并有"续王"（rgyud kyi rgyal po）之称。

作者问题依传统归诸"密集金刚"佛之宣说，实际编纂者已不可考。续文本身或经层累而成，学界一般认为其先有核心章节、后续附增益。8世纪以后，龙树系论师（藏传称"龙树阿阇黎"及"圣者龙树"二系）为此续造释，其中月称（Candrakīrti）的《明灯释》（Pradīpoddyotana）成为藏地最权威的注释传统。本续约于后弘期由仁钦桑布等大译师译藏，此后布敦、宗喀巴等均撰有多部密集释论，宗喀巴的《集密五次第明灯论》等著作即以此续为依。

梵文本方面，本续及《明灯释》梵文写本至今仍存，20世纪日本学者松长有庆（Matsunaga Yūkei）等曾对《密集续》梵本及各种藏译进行系统校勘研究，是密教文献学的经典课题。

## 二、文本结构与核心思想

《密集续》通行本分为十七（或十八）品，以金刚萨埵请问、密集金刚宣说为框架。其核心思想，原文所选段落有最凝练的表达——**"五蕴即五佛"**：

> "以五蕴修法转五蕴为五方佛——色蕴为大日如来，受蕴为宝生佛，想蕴为无量寿佛，行蕴为不空成就佛，识蕴为阿閦佛。如是五蕴即五佛体，离五蕴外更无佛可求。"

这一"转依"（āśraya-parāvṛtti）结构是密集体系的心髓：烦恼与清净不是两个世界，构成"我"的五蕴本身就是五方佛——问题不在五蕴，而在认识。修行不是抛弃身心另觅佛土，而是换一套眼光重看当下身心。

在修法架构上，本续属**父续（Pitṛ-tantra）**：名句所谓"密集续为父续之根本，以幻身为道"。其圆满次第特重"幻身"（māyākāya）与"光明"（prabhāsvara）双运：先由气脉修持引生极细风心所成的"幻身"，继而于心之"光明"中证空，二者双运即成佛之色身与法身之因——"证法身与色身无二"。生起次第则如传统所传"五蕴即五佛，五大即五佛母。如是观修，自身即为本尊，世间即为坛城"，将整个经验世界在本尊瑜伽中重新编码。

## 三、学术研究价值与争议

**研究价值**：其一，《密集续》是无上瑜伽部最早成形的续典，被视为"一切无上续之母体"，其术语（幻身、光明、四喜、三摩地细分）构成后世续典共享的概念框架，研究印度密教的源流必须由此入手；其二，幻身-光明学说经萨迦、格鲁两派精细化，成为藏传佛教"即身成佛"理论的哲学核心；其三，本续梵本尚存，与藏译对照可为密教翻译史提供精确样本。

**代表学者**：日本学界松长有庆对密集文献的整理研究是奠基之作；山口英一、酒井真典等续有专论；西方方面，Benoytosh Bhattacharyya 早年曾英译研究本续，Daniel Cozort 的《无上瑜伽坦特罗》（*Highest Yoga Tantra*）以格鲁派密集传统为纲，兼涉宗喀巴密集五次第学说；David Germano、Ronald Davidson 关于印度密教史的通论性著作亦以本续为重要个案。

**争议问题**：其一，本续与湿婆派怛特罗的关系——"佛教改造湿婆派材料"还是"平行发展"，自 Shahi Tattva 研究以来争论不休；其二，"龙树造密集释"的龙树是否即中观之龙树，藏传二系传承与学界考证出入较大；其三，十七品与十八品诸本（如摄略本 Ārya 系与 Jñānapāda 系注释传统）的关系，涉及密续"层累成书"的通例问题。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 密集（Guhyasamāja） | "秘密集会"，谓诸佛集会共说之甚深密续 |
| 五蕴即五佛 | 色受想行识五蕴当体即五方佛，密集体系之核心见地 |
| 父续（Pitṛ-tantra） | 无上瑜伽续之一类，以幻身与方便为道 |
| 幻身（Māyākāya） | 由极细气所成、如幻之清净色身，成佛色身之近取因 |
| 生起次第（Utpatti-krama） | 观自身为本尊、转五蕴五大为佛父佛母之方便 |
| 圆满次第（Saṃpanna-krama） | 修气脉明点、证幻身光明双运之智慧修法 |
