# 佛教方法論 · 原文

## 一、學科概述

佛教方法論（Buddhist Methodology）研究佛教傳統中研習、詮釋與傳承佛法的系統方法，以及現代佛學研究的方法自覺。傳統佛教內部形成了豐富的方法體系：一是判教，如劉宋慧觀立「五時教」、隋智顗立天台「五時八教」、法藏立華嚴「五教判」，對佛陀一代言教作體系化分類；二是科判，將經論逐段剖析，藏傳格魯派講經尤重科判傳統；三是注疏，天台三大部、窺基《成唯識論述記》等構成層累的詮釋鏈；四是因明論辯，陳那、法稱建立量論邏輯，使義理商榷有公共規則。近代以來，隨著敦煌文書（1900年藏經洞發現）與梵巴寫本的出土，佛學研究進入文獻考據時代：湯用彤《漢魏兩晉南北朝佛教史》（1938）以史料考證見長，呂澂《中國佛學源流略講》以義理梳理著稱，日本宇井伯壽、高楠順次郎等亦以文獻學方法重塑佛學研究範式。當代佛學更轉向「數字人文」方法，2023年中國佛教協會「人間佛教思想建設研討會」即以「人間佛教視域中的佛教典籍數字化」為主題，清華大學鍾周等學者探討數字人文與佛教研究的方法論結合。

## 二、核心議題與佛教觀點

核心議題包括：判教與科判作為「詮釋學的結構化方法」如何組織浩瀚經藏；注疏傳統中「我注六經」與「六經注我」的張力；文獻考據與義理詮釋、信仰立場之間的平衡——王國維「二重證據法」在佛教文獻研究中的運用；以及數字時代的遠讀（distant reading）、文本挖掘與傳統細讀的互補。佛教立場認為，方法應服務於「智慧與慈悲」的證成：判教是為應機施教的方便，考據是為辨明法義源流，所謂「依義不依語，依了義不依不了義」，方法論最終須歸於四依四不依的原則。

> **經典依據**：
> 「依義不依語，依智不依識，依了義經不依不了義經，依法不依人。」——《大般涅槃經》（T374）

## 三、代表學者、著作與案例

湯用彤（1893–1964）《漢魏兩晉南北朝佛教史》是近代佛教史學方法典範；呂澂（1896–1989）與支那內學院開創以梵藏文獻對勘漢譯佛典的「批判佛學」方法。陳寅恪以文史考據治佛教史，其《支愍度學說考》示範了小問題見大問題的方法。當代案例方面，中華電子佛典協會（CBETA，1998年成立）以《大正藏》《卍新纂續藏經》為底本建立全文數據庫並施以XML標記，使詞頻統計、版本比對成為新的研究方法；杭州靈隱寺則研發「基於人工智能的古籍OCR引擎」與「古籍數字化生產平台」，推進《徑山藏》《永樂北藏》《思溪藏》的數字化整理。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 判教 | 對佛陀教法依深淺、次第作體系分類的方法 |
| 科判 | 將經論分章析段的結構分析方法 |
| 注疏 | 依傍原典逐句詮釋的著作體裁 |
| 因明 | 佛教邏輯與認識論體系，陳那、法稱集大成 |
| 二重證據法 | 傳世文獻與出土文獻互證的考據方法 |
| 數字人文 | 以計算方法輔助人文研究的交叉學科 |
