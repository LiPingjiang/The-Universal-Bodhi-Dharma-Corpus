# 法藏部律典 — 学术解读

## 一、文献背景与成书

本目录文献为法藏部（Dharmaguptaka，又称昙无德部）所传广律《四分律》（T1428），全称《曇無德部四分律》，六十卷，姚秦弘始十年至十二年（408—410）由佛陀耶舍、竺佛念于长安译出。

法藏部属上座部系：据《异部宗轮论》，佛灭三百年间从化地部分出。传统另有「优婆鞠多五弟子分律为五部」之说，昙无德（Dharmagupta）所传即其一。因全律分四次诵出，故名「四分」。此部特重塔寺供养，其律对佛塔制度的规定在诸部律中最为详备，被视为法藏部佛陀崇拜传统的制度表征。

## 二、文本结构与核心思想

《四分律》四部分：（一）比丘戒法，含波罗夷、僧残等二百五十戒；（二）比丘尼戒法，含三百四十八戒；（三）犍度法，规定僧团修行仪式与日常礼仪，含受戒、布萨、安居等二十犍度；（四）附随事项，含五百集法、七百集法等结集史料。

其律典思想承上座系统：制戒必具缘起，犯相轻重以「开遮持犯」判分；二十犍度中「房舍犍度」「杂犍度」等对佛塔、供养的重视，显示此部「佛不与僧同体、施佛功德胜于施僧」的宗义取向。

《四分律》的历史地位系于道宣（596—667）：唐初道宣以《四分律》为宗，居终南山，创南山律宗，撰《四分律删繁补阙行事钞》《四分律含注戒本疏》《四分律随机羯磨疏》（合称「南山三大部」），立「戒法、戒体、戒行、戒相」四科，以阿赖耶识善种子为戒体，会通声闻戒与大乘菩萨戒，使《四分律》成为汉传僧团的根本律典，沿用至今。同时期法砺创相部宗、怀素创东塔宗，合称「律宗三家」，而南山一宗独传后世。

## 三、学术研究价值与争议

1. **汉传佛教的「活律」**：中国、韩国、日本僧团受戒制度皆以《四分律》为底本，其注疏群（南山三大部及历代记钞）构成东亚律学的主体文献。
2. **部派归属与地理**：法藏部广行于西北印度与中亚，犍陀罗出土写本中有法藏部文献；有学者认为早期汉译般若经的传入亦与该部有关，此说尚在讨论中。
3. **戒体论的哲学争论**：南山宗以「阿赖耶识种子」释戒体，天台学者及后世律家（如蕅益智旭）另有「无作戒体」诸解，是汉传佛教义理史的内部课题。
4. **四分律与巴利律的层位比较**：二者虽同出上座系统，结构歧异明显，为部派律藏分流提供了与《五分律》不同的对照样本。
