# 摄阿毗达磨义论 — 学术解读

## 一、文献背景与成书

《攝阿毗達磨義論》（巴利语 *Abhidhammatthasaṅgaha*，英译 Compendium of Abhidhamma），锡兰学者阿耨楼陀（Anuruddha）所造，推定约成书于公元 1100 年左右，被誉为巴利佛教教理纲要之最优秀作品。汉译由近代僧人法舫译出。本论是上座部佛教文献体系的产物，流传于南传巴利语传统，不在《大正藏》编号体系之内。

其文献学位置在于「集大成」：本论承继觉音（Buddhaghosa）与佛授（Buddhadatta）的《入阿毗达磨论》一系纲要书传统，同时重新组织材料、补充以前论书未及言及的部分，成为初学者最好的阿毗达磨纲要书。它是后世南传阿毗达磨教育的实际入口——缅甸、泰国、斯里兰卡的寺院教育至今以本论及其注释为教材，其注释书（如 Chandago 的疏钞）形成了延续至今的活传统。

## 二、文本结构与核心思想

全书九品构成严整的教理总纲。原文档的品目为：一摄心分别、二摄心所分别、三摄杂分别、四摄路分别、五摄离路分别、六摄色分别、七摄集分别、八摄缘分别、九摄业处分别。前五品讲心法与心所法，第六品讲色法与涅槃法，第七品讲种种法相，第八品说缘起论（二十四缘），第九品说修定修慧之禅修业处——从心理、物质、关系（缘）到修行实践，恰好是一张完整的教理地图。

其核心义理可循档案所录三段看到。其一，摄心分别：心略说有四——欲界心、色界心、无色界心、出世间心；欲界心五十四、色界心十五、无色界心十二、出世间心八，合计八十九心，若依禅那与道果分则为一百二十一心。这套心识分类是上座部心理学的总纲。其二，摄心所分别：五十二心所，分十三通一切心所（七遍行加六别境）、十四不善心所、二十五善心所；名句「五十二心所，與心相應，同生同滅，同一所緣，同一依處」给出「相应」的严格定义——心与心所四同一齐：同时生、同时灭、认识同一对象、依托同一依处。其三，摄缘分别：列因缘、所缘缘、增上缘、无间缘、等无间缘、俱生缘、相互缘、依止缘、亲依止缘、前生缘、后生缘、重复缘、业缘、异熟缘、食缘、根缘、禅那缘、道缘、相应缘、不相应缘、有缘、无有缘、离去缘、不离去缘——二十四缘穷尽诸法之间一切缘力关系，此为《发趣论》（Paṭṭhāna）庞大体系的纲要化。

## 三、学术研究价值与争议

研究价值方面：（1）本论是南传阿毗达磨的「活教材」，九百年间持续用于寺院教育，是研究上座部教理传承连续性的最佳标本；（2）八十九心（或一百二十一心）与五十二心所的分类体系，是佛教心理学最精细的模型之一，为比较心理学与认知科学提供了古老而系统的参照系；（3）二十四缘的纲要化，把《发趣论》数以千计的缘力关系压缩为可教学的结构，是研究佛教因果理论形态的一级材料；（4）「四同一齐」的心心所相应定义，是分析心识活动的基本单元模型，具有严格的概念构造意识。

争议与问题方面：（1）阿耨楼陀其人年代有十至十二世纪之间多种估计，本论确切成书年代与地点（锡兰或缅甸）尚无定论；（2）原文档所列九品品名中「摄路分别」与「摄离路分别」标注同一巴利名 Vīthimuttavibhāga，当系档案转录之误，二者实应分别为 Vīthimutta 之路分与离路分，读者宜核对通行本；（3）五十二心所的分类与觉音《清净道论》所传略有出入，不同注释传统在若干心所的归类上互有分歧，本论所代表的是主流计数；（4）八十九心与一百二十一心的两套计数并存，涉及禅那展开方式的判定，历来注家有细部讨论。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 摄阿毗达磨义论 | 阿毗达摩诸法概要之手册，阿耨楼陀造纲要书 |
| 心（citta） | 认识的主体，八十九心（或百二十一心） |
| 心所（cetasika） | 五十二种与心相应的心理因素 |
| 欲界/色界/无色界 | 心的三层世间所属，出世间心之外的三类 |
| 出世间（lokuttara） | 超越世间的道果之心，八种 |
| 遍行心所 | 与一切心相应之七种：触、受、想、思、一境性、命根、作意 |
| 不善心所 | 痴、贪、瞋等十四种烦恼性因素 |
| 相应（sampayutta） | 心心所同生同灭、同一所缘、同一依处 |
| 二十四缘 | 《发趣论》一切缘力关系的总集，本论第八品所摄 |
| 业处（kammaṭṭhāna） | 禅修用功之所缘，第九品主题 |
| 速行（javana） | 心路过程中起造作作用之识，业之所在 |
