# 圓覺經略疏

## 一、概述

**大正藏編號**：T1795（《大正新脩大藏經》第 39 冊）

**全稱**：《大方廣圓覺修多羅了義經略疏》

**別稱**：《圓覺經略疏》《略疏》

**撰者**：唐·宗密（780—841），圭峰大師，華嚴宗五祖

**卷數**：二卷（每卷又分為二，故實作四卷）

**所釋經本**：《大方廣圓覺修多羅了義經》一卷，唐·罽賓沙門佛陀多羅譯

《圓覺經略疏》是宗密在《圓覺經大疏》之後所作的節略本。據書首裴休序所述，宗密疏解《圓覺經》「凡大疏三卷、大鈔十三卷、略疏兩卷、小鈔六卷、道場修證義十八卷，並行於世」——本書即其中的「略疏兩卷」。

《大疏》與《略疏》的關係：《大疏》詳博，廣引經論、備列異說，適於專門研究；《略疏》則刪繁就簡、提綱挈領，便於講習誦讀。二者在義理判釋上一貫，而《略疏》因文字精要，流通反而更廣，並被收入《大正藏》正藏（《大疏》則入《卍續藏》）。此書亦見載於宋《毗盧藏》、明《永樂南藏》、清《龍藏》等歷代藏經。

**本疏的十門架構**（與《大疏》體例略有調整，是《略疏》最具辨識度的部分）：

一、別起因緣；二、藏乘分攝；三、權實對辨；四、分齊幽深；五、所被機宜；六、能詮體性；七、宗趣通別；八、修證階差；九、通釋名題；十、別解文義。

在「別解文義」門中，又依序、正說、流通三分科判經文。其中正宗分的十一番問答再分為二：最初一番問答旨在「令信解真正，成本起因」；其後十番問答旨在「令依解修行，隨根證入」。這一科判精確地把握住了《圓覺經》「先信解、後修證」的結構。

疏後附錄《圭峰定慧禪師遙稟清涼國師書》一文，是宗密致其師澄觀的書信，含有重要的生平自述與師承材料。

## 二、核心段落

### （一）略疏十門

**原文：**

> 一、別起因緣；二、藏乘分攝；三、權實對辨；四、分齊幽深；五、所被機宜；六、能詮體性；七、宗趣通別；八、修證階差；九、通釋名題；十、別解文義。

**白話對照：**

第一，「別起因緣」——闡明這部經別別興起的因緣。
第二，「藏乘分攝」——判定此經在三藏與諸乘中的歸屬。
第三，「權實對辨」——對比辨析權宜之教與真實之教，以定此經地位。
第四，「分齊幽深」——辨明此經義理分限的幽微深邃。
第五，「所被機宜」——說明此教所攝受的根機。
第六，「能詮體性」——辨明能夠詮表此教的體性。
第七，「宗趣通別」——闡明宗旨趣向的通義與別義。
第八，「修證階差」——說明修行證入的階位次第。
第九，「通釋名題」——總的解釋經題名目。
第十，「別解文義」——逐段別別解釋經文義理。

### （二）正宗分的二重科判

**原文（依本疏科判要義）：**

> 正宗分中十一問答分二：初一問答，令信解真正，成本起因；後十問答，令依解修行，隨根證入。

**白話對照：**

正宗分中的十一番問答分為兩大部分：

最初的一番問答（文殊章），是要使人生起真正的信解，成就本起因地的正因；

其後的十番問答，是要使人依憑所解而起修行，隨順各自根機而證悟契入。

這一科判是《略疏》的骨幹。宗密以此指出：《圓覺經》的結構不是十二章平列，而是「一解十行」——文殊章確立見地，其餘各章開示行門。

### （三）所釋經文：圓覺法門總標

**《圓覺經》文殊章原文：**

> 善男子！無上法王有大陀羅尼門，名曰圓覺，流出一切清淨真如、菩提、涅槃及波羅蜜，教授菩薩。一切如來本起因地，皆依圓照清淨覺相，永斷無明，方成佛道。

**白話對照：**

善男子！無上的法王有一大總持法門，名叫「圓覺」，從中流出一切清淨真如、菩提、涅槃以及諸波羅蜜，用以教授菩薩。

一切如來最初發起的因地修行，都是依憑圓滿照徹的清淨覺相，永斷無明，才成就佛道的。

此即「令信解真正，成本起因」之所指——先確立「本起因地」的見地，一切修行方有依憑。

### （四）所釋經文：三種淨觀

**《圓覺經》威德自在章原文：**

> 善男子！若諸菩薩悟淨圓覺，以淨覺心取靜為行，由澄諸念，覺識煩動，靜慧發生，身心客塵從此永滅，便能內發寂靜輕安……此方便者，名奢摩他。
>
> 善男子！若諸菩薩悟淨圓覺，以淨覺心知覺心性及與根塵皆因幻化，即起諸幻以除幻者……此方便者，名三摩缽提。
>
> 善男子！若諸菩薩悟淨圓覺，以淨覺心不取幻化及諸靜相，了知身心皆為罣礙，無知覺明不依諸礙……此方便者，名為禪那。

**白話對照：**

善男子！如果諸位菩薩悟入了清淨圓覺，以清淨覺心取「靜」作為修行：由於澄清了種種念頭，覺察到識心的煩擾躁動，寂靜的智慧便得以發生，身心的客塵煩惱從此永遠止息，於是能夠從內在生發寂靜輕安……這種方便，名為「奢摩他」（寂止觀）。

善男子！如果諸位菩薩悟入了清淨圓覺，以清淨覺心了知能覺的心性以及六根六塵都是幻化，於是興起種種如幻的方便來除去幻妄……這種方便，名為「三摩缽提」（如幻觀）。

善男子！如果諸位菩薩悟入了清淨圓覺，以清淨覺心既不取如幻之化、也不取寂靜之相，明了身與心都成為障礙，而那無知之覺明並不依待於諸般障礙……這種方便，名為「禪那」（寂滅觀）。

三種淨觀是《圓覺經》修行論的核心，本疏「修證階差」門即以此為綱。由三觀單修、齊修、前後互修，開出〈辯音章〉的二十五輪清淨定輪。

### （五）所釋經文：四種隨順覺性

**《圓覺經》清淨慧章原文：**

> 善男子！一切眾生從無始來，妄想執有我、人、眾生及與壽命，認四顛倒為實我體，由此便生憎愛二境，於虛妄體重執虛妄。二妄相依，生妄業道；有妄業故，妄見流轉；厭流轉者，妄見涅槃。由此不能入清淨覺。

**白話對照：**

善男子！一切眾生從無始以來，虛妄地想像執取有「我」、有「人」、有「眾生」、有「壽命」，把這四種顛倒認作真實的我體；由此便生出憎與愛這兩種境界，在虛妄的體上又重重執取虛妄。

兩重虛妄互相依待，生出虛妄的業道；因為有虛妄之業，所以虛妄地見有生死流轉；而厭離流轉的人，又虛妄地見有涅槃可得。由於這樣的緣故，便不能契入清淨覺性。

宗密於此指出：連「厭生死、欣涅槃」也仍在妄見之中，這正是《圓覺》高於一般權教之處。

### （六）所釋經文：離四病

**《圓覺經》普覺章原文：**

> 善男子！彼善知識所證妙法，應離四病。云何四病？
> 一者作病。若復有人作如是言：我於本心作種種行，欲求圓覺。彼圓覺性非作得故，說名為病。
> 二者任病。若復有人作如是言：我等今者不斷生死、不求涅槃，涅槃生死無起滅念，任彼一切隨諸法性，欲求圓覺。彼圓覺性非任有故，說名為病。
> 三者止病。若復有人作如是言：我今自心永息諸念，得一切性寂然平等，欲求圓覺。彼圓覺性非止合故，說名為病。
> 四者滅病。若復有人作如是言：我今永斷一切煩惱，身心畢竟空無所有，何況根塵虛妄境界，一切永寂，欲求圓覺。彼圓覺性非寂相故，說名為病。
>
> 離四病者，則知清淨。作是觀者，名為正觀；若他觀者，名為邪觀。

**白話對照：**

善男子！那善知識所證的微妙之法，應當遠離四種病。哪四種病呢？

第一是「作病」。如果有人這樣說：我要在本心上造作種種修行，以求得圓覺。——但那圓覺之性並非造作可得，所以說這是病。

第二是「任病」。如果有人這樣說：我如今既不斷生死、也不求涅槃，對涅槃與生死都不起生滅之念，一任那一切隨順諸法本性，以求得圓覺。——但那圓覺之性並非放任可有，所以說這是病。

第三是「止病」。如果有人這樣說：我如今讓自心永遠止息一切念頭，得到一切法性寂然平等，以求得圓覺。——但那圓覺之性並非止息所能契合，所以說這是病。

第四是「滅病」。如果有人這樣說：我如今永斷一切煩惱，身心畢竟空無所有，何況根塵那些虛妄境界，一切永歸寂滅，以求得圓覺。——但那圓覺之性並非寂滅之相，所以說這是病。

遠離了這四種病，才算是知曉清淨。作這樣觀察的，名為正觀；若作其他觀察的，名為邪觀。

「作、止、任、滅」四病，是《圓覺經》對修行歧路最著名的診斷，直接影響了後世禪門的用功指示。

### （七）所釋經文：修證的最終發心

**《圓覺經》普覺章原文：**

> 善男子！末世眾生欲求圓覺，應當發心作如是言：盡於虛空一切眾生，我皆令入究竟圓覺；於圓覺中無取覺者，除彼我人一切諸相。如是發心，不墮邪見。

**白話對照：**

善男子！末世的眾生想要求得圓覺，應當發心作這樣的誓言：窮盡虛空界的一切眾生，我都要使他們契入究竟圓覺；然而在圓覺之中，並沒有一個取證圓覺的人，要除去那「我相」「人相」等一切諸相。

這樣發心，才不會墮入邪見。

## 三、名句

**其一**

> 離四病者，則知清淨。作是觀者，名為正觀；若他觀者，名為邪觀。

遠離作、止、任、滅四病，才算知曉清淨。作這樣觀察的名為正觀，作其他觀察的名為邪觀。

「四病」之說是《圓覺經》對修行實踐最犀利的批判：造作是病，放任是病，止息是病，斷滅也是病——四種看似正當的用功方式，一一被判為病。其鋒芒所指，是修行者對「能修之我」與「所求之覺」的隱微執取。宗密於《略疏》中特為標舉，此說遂成為唐宋禪門勘驗學人的常用尺度。

**其二**

> 於圓覺中無取覺者，除彼我人一切諸相。

在圓覺之中，並沒有一個取證圓覺的人；要除去我相、人相等一切諸相。

這是《圓覺經》發心說的究竟處，與《金剛經》「滅度無量眾生，實無眾生得滅度者」同一機杼。它為前文的「離四病」提供了根據：四病之所以是病，根源都在於預設了一個「能求圓覺的我」。唯有連這個能證之我一併遣除，發心才不墮邪見。

## 四、術語表

| 術語 | 說明 |
|-----|------|
| **略疏** | 相對於《大疏》而言的節略本。刪繁就簡、提綱挈領，便於講習。 |
| **十門** | 本疏懸談體例：別起因緣、藏乘分攝、權實對辨、分齊幽深、所被機宜、能詮體性、宗趣通別、修證階差、通釋名題、別解文義。 |
| **權實對辨** | 十門之三。對比辨析權宜方便之教與真實究竟之教，以確定《圓覺經》的判釋地位。 |
| **修證階差** | 十門之八。說明修行證入的階位次第，是《圓覺經》觀行論的總攝。 |
| **本起因** | 「本起因地」的略稱。指如來最初發心修行時所依的因地正見，即圓照清淨覺相。 |
| **奢摩他** | 梵語 śamatha，寂止觀。三種淨觀之一，以取靜澄念為行。 |
| **三摩缽提** | 梵語 samāpatti，如幻觀。三種淨觀之一，以起幻除幻為行。 |
| **禪那** | 梵語 dhyāna，寂滅觀。三種淨觀之一，不取幻化亦不取靜相。 |
| **二十五輪** | 由三種淨觀單修、齊修、前後互修所開出的二十五種清淨定輪。見〈辯音章〉。 |
| **四病** | 作病、任病、止病、滅病。求圓覺者應離的四種修行偏失。 |
| **四相** | 我相、人相、眾生相、壽命相（壽者相）。《圓覺經》〈淨諸業障章〉別有細釋，與《金剛經》四相同名而所詮更細。 |
| **四種隨順覺性** | 凡夫、未入地菩薩、已入地菩薩、如來四類隨順覺性的差別。見〈清淨慧章〉。 |
| **序／正宗／流通三分** | 傳統科判經文的通例。本疏於「別解文義」門中依此三分判釋全經。 |
| **十一問答** | 正宗分中十一番問答。初一番（文殊章）令信解真正，後十番令依解修行。 |
