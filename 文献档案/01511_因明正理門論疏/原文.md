# 因明正理門論疏 · 原文

## 一、文獻概述

《因明正理門論疏》，通稱《因明正理門論述記》（下稱《述記》），唐沙門神泰撰，是對陳那《因明正理門論》（玄奘貞觀二十三年〔649〕譯，T1622）的注疏，今通行本為三卷（亦有作一卷、上下二卷者，因傳本殘缺而異）。

神泰，唐代法相宗學僧，曾住蒲州（今山西永濟）普救寺，以律學、因明著稱，奉詔參與玄奘譯場，任證義之職，與靖邁、靈潤等同列奘門高足。玄奘門下因明著述極盛，據載當時注解《理門論》《入論》者有神泰、靖邁、明覺、文備、文軌、璧公、靈俊、玄應、玄範、順憬等十餘家，世稱「唐疏」；然唐末會昌法難及五代兵燹之後，諸疏在中土相繼散佚，惟賴日本入唐求法僧攜歸之抄本，部分得存於東瀛。《述記》即其中之一，近人於1923年據日本傳本由金陵刻經處、支那內學院先後刊印流通，遂重歸中土學界。今收入《萬續藏》（新纂續藏經）。

《述記》是現存唐代《理門論》注疏中唯一較完整傳世的一種，其價值在於：其一，保存了玄奘譯場對新因明術語的理解口徑，是研究陳那學說初傳漢地面貌的第一手材料；其二，其釋文常與窺基《因明入正理論疏》（大疏）互證，可見奘門師弟因明學說之異同；其三，凡《入論》所略而《理門論》獨有之義（如九句因、宗過、似破等），賴此疏得窺唐人解釋。今本有殘缺，卷首釋論主歸敬等文已佚，現存部分起於釋本文「宗等多言說能立」段。

## 二、核心段落選錄

### （一）總判論旨——三分科文

> **原文**：
> 依《理門論》本文：「宗等多言說能立，是中唯隨自意樂，為所成立說名宗，非彼相違義能遣。」神泰科判全論大旨，謂此論三分：一者敘論之發起（歸敬與造論所为），二者辨釋正宗（能立、似立、現比二量、能破、似破），三者所為契真（明造論利益）。

> **白話對照**：
> 這是《理門論》開篇的著名本頌，也是《述記》逐句解釋的第一段。頌文說：由「宗」等若干言詞構成的整體，稱為「能立」；其中「宗」是立論者隨自己的意樂所樹立、有待成立的主張，且不得被相違的義理（現量、比量、世間共許等）所遮遣。
> 神泰按照當時講經的科判慣例，把全論分為三分：先是說明造論緣起，中間是正式辨釋能立、能破等正宗義理，最後說明造論所為（利益眾生、住持正法）。這一「三分科文」為後世研讀《理門論》提供了綱領。

### （二）釋「能立」之總成

> **原文**：
> 《理門論》云：「宗等多言說能立者，由宗、因、喻多言辯說他未了義故。此多言於論式等說名能立。又以一言說能立者，為顯總成一能立性。由此應知，隨有所闕名能立過。」《述記》釋云：能立以「生他解」為義，三支闕一，即不成生解之用，故為過失。

> **白話對照**：
> 經文解釋為何宗、因、喻「多言」合稱能立：因為要藉三支的配合，才能為對方辯說他尚未明了的義理；而以「一言」（單數）稱能立，是顯示三支總成一個完整的能立性。
> 神泰的解釋特別點出「生他解」三字——能立的功能在於令敵論者生起正解，這是認識論意義的功能；正因如此，三支之中隨缺一支，生解之用不成，即名「能立過」。此釋下啟窺基大疏「生因、了因」之說。

### （三）釋九句因

> **原文**：
> 《理門論》本頌：「宗法於同品，謂有、非有、俱；於異品各三，有、非有及二。」《述記》隨文逐句解釋「有」「非有」「俱」三種分布，並判定九句之中唯第二句（同品有、異品非有）與第八句（同品俱、異品非有）為正因，餘皆不定或相違。

> **白話對照**：
> 九句因是陳那邏輯的核心：考察因在「同品」（與宗所立同類的事物）中的分布——遍有、全無、部分有三種；再於「異品」中考察，同樣三種，共成九句。
> 神泰一一疏解各句，指明唯「同品有、異品非有」與「同品俱、異品非有」二句是真正的因（正因），其餘七句或屬不定（不能決定宗之成立）、或屬相違（反而證成反面）。《入正理論》略九句因而直標因三相，故《述記》此段所存唐人舊解，正是《入論》系統所無的珍貴材料。

### （四）釋「證了因」非「生因」

> **原文**：
> 《理門論》云：「今此唯依證了因故，但由智力了所說義，非如生因由能起用。」《述記》申之：比量但取敵者智了，故名了因；言說之體，非是生因。

> **白話對照**：
> 這一段區分「證了因」與「生因」：因明所依的是使人「了知」的因，靠智慧之力通達所說的義理；不是像生成萬物的因那樣實際起用造作。神泰進一步申說：比量（推理）所取的在於令敵論者的智慧了解宗義，故稱「了因」；言說本身只是媒介，不是親生的因。這一辨析，後經窺基《大疏》發展為著名的「言生因、智了因」六因之說，而《述記》實為其先聲。

## 三、重要名句

> **名句一**：
> 「宗法於同品，謂有、非有、俱；於異品各三，有、非有及二。」——《理門論》九句因總綱。神泰於此逐句疏解，是漢傳文獻中對九句因最早的系統解釋。以窮舉法列盡因與同異品的全部九種關係，並判出唯二正因，被視為新因明區別於古因明的分水嶺。

> **名句二**：
> 「今此唯依證了因故，但由智力了所說義。」——區分「證了因」與「生因」，明確因明處理的是「如何使人認識」的問題，而非「事物如何產生」的問題。神泰以「生他解」概括能立之義，最得此旨，後世「言生因／智了因」之分析皆由此出。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 能立 | 以宗、因、喻三支完整成立自宗的論證 |
| 能破 | 揭破對方論證過失的批駁 |
| 宗 | 立論者所欲成立的主張 |
| 因 | 支持宗的理由（宗法） |
| 喻 | 例證，分同喻、異喻 |
| 同品 | 與宗後陳同類的事物 |
| 異品 | 與宗後陳異類的事物 |
| 九句因 | 因於同異品九種分布的窮舉分類 |
| 因三相 | 正因的三個條件（遍是宗法性、同品定有性、異品遍無性） |
| 證了因 | 令人了知義理的因，屬認識論意義 |
| 生因 | 實際生起作用之因，屬存在論意義 |
| 不成因 | 因本身不能成立的過失 |
| 不定因 | 不能決定證成宗之過失 |
| 相違因 | 反證成相反宗之過失 |
| 現量 | 直接知覺 |
| 比量 | 推理認知 |
| 科判 | 分段判釋經論結構的綱目 |
| 證義 | 譯場職位之一，審核譯文義理 |
