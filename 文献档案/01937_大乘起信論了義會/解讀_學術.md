# 大乘起信论了义会 · 学术解读

## 一、文献背景与成书

本档性质须首先如实说明：题名「大乘起信論了義會」为文献整理中机生成的注疏变体名，不对应历史上实际存在的独立著作，目录所存原文档仅是说明性名目，未收经文疏文。但这个合成名目的两个成分——"了义"与"会"——都各自牵出一段真实而重要的思想史，可以借题发挥。

"了义"是佛教诠释学的核心判词，源自"四种意趣""四种秘密"一类经典分类法：佛说法有随宜的权说（不了义），也有把究竟道理和盘托出的实说（了义）。中国各宗继承并发展了这一判分标准，天台以圆教为了义，华严以圆宗为了义。"会"则指"会通"或"会解"之学：当经论彼此文义参差时，注家不采取"一是一、二是二"的档案式处理，而是判定何者为方便施设、何者为究竟了义，从而把分歧的文本融合成一个层秩分明的整体。敦煌与藏外文献中有《大乘起信論會解》《大乘起信論會閱》一类题名，正是这一体裁的实存样本。而《大乘起信論》本身——相传马鸣造、真谛译（大正藏 No.1666），实叉难陀重译（No.1667）——在"了义与否"的问题上恰好是中国佛教史上最著名的是非之地：它被判为了义的如来藏系标准文献，又被近世唯识学者指控为不了义乃至伪作。以"了义会"为名目，正好从诠释学的角度重新检讨这场争论。

## 二、文本结构与核心思想

以"了义"为纲来会读《大乘起信論》，关键在于看它如何一面立"了义之体"，一面施"方便之用"。

全论五分之中，立义分标举众生心、一心二门、体相用三大，是把"究竟了义"和盘托出：所依的法不是别的，就是众生当下这一心；真如门说心之"不变"，生灭门说心之"随缘"，二门不即不离，全无所遮。解释分则展开"依了义不依不了义"的教学法：先显示正义，把真如门、生灭门、觉与不觉、熏习还灭的义理铺陈完备，这是称性而谈；继而对治邪执，特破五种执著，其中对治"法我见"诸条，实际上是把听法者容易堕入的知见窠臼逐层标记出来——凡有可执之相，皆非了义；末后分别发趣道相，立信成就、解行、证三种发心，为不同根器的人开出阶梯，则是随他意语、方便施设。可见全论自身即是"了义体上开方便门"的范本：了义不废阶梯，阶梯终归了义。修行信心分立四信五行，劝修利益分结劝流通，也无一处不从"众生心本来是佛、但须起信修行"这一了义立场流出。这一读法与同系列「大乘起信論究竟會」条目（侧重与唯识学会通）、「大乘起信論圓滿會」条目（侧重与如来藏经典群会通）分工并观。

## 三、学术研究价值与争议

围绕《大乘起信論》的"了义"资格，形成佛教诠释学史上罕见的百年辩题。会通派以法藏、宗密为代表，判起信论为如来藏缘起宗之了义，认为其"真如随缘"正是大乘极致之谈；日本镰仓时代以来，凝然、凤潭等讲习家亦大体循此路数。批判派则从唯识立场发难：真如为无为法，"凝然不作诸法"，岂能"依如来藏故有生灭心"？民国年间王恩洋《大乘起信論料簡》径斥其伪，欧阳竟无一系起而应之，太虚则撰《大乘起信論唯識釋》为起信论回护，印顺后作《起信論平議》，主张论中思想属印度后期如来藏与唯识融会之学，不必以唯识义例绳之——这场论战的实质，正是"谁有权判定何为了义"的诠释权之争。学术研究的价值因此有三：其一，它是观察"判教如何运作"的活体样本；其二，它涉及"依了义经不依不了义"这一四依原则在何种制度、权力结构中执行的社会史问题；其三，比较其与藏传佛教"辨了不了义"传统（如宗喀巴依《解深密经》判摄）的异同，可以呈现东亚佛教诠释学的两种进路。相关真伪考辨的细节，另详「大乘起信論了義探」条目。

## 四、术语对照表

| 术语 | 简释 |
|---|---|
| 了义／不了义 | 究竟如实之说了义，随宜方便之说为不了义 |
| 四依 | 依法不依人、依义不依语、依了义经不依不了义经等 |
| 会通／会解 | 判定权实、融合经论异义的诠释体裁 |
| 随他意语／随自意语 | 顺听者根机之方便言说与称实而谈的自证之说 |
| 一心二门 | 众生心开真如、生灭二门，起信论的立义总纲 |
| 显示正义 | 解释分正明一心二门之义，全论了义所在 |
| 对治邪执 | 破人我见、法我见等五执，标记不了义之可执处 |
| 三种发心 | 信成就发心、解行发心、证发心 |
| 真如随缘 | 真如不变而随缘现起诸法，会通派的核心命题 |
