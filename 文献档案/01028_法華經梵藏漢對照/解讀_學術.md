# 法華經梵藏漢對照 — 学术解读

## 一、文献背景与成书

《法華經梵藏漢對照》是本库「梵藏漢對照」系列条目之一（同系列尚有 `01026_心經梵藏漢對照` 至 `01075_陀羅尼集經梵藏漢對照` 等数十档），标示以《妙法蓮華經》为对象的三语对勘研究。据本库原文档，所涉文本为：梵本《妙法蓮華經》（Saddharmapuṇḍarīka Sūtra，尼泊尔系写本及中亚出土残本两大系统）；汉译以姚秦鸠摩罗什弘始八年（406年）所译七卷二十八品本（《大正藏》第九册 T262）为主，另有竺法护《正法華經》（T263）、隋阇那崛多与达摩笈多《添品妙法蓮華經》（T264）二译可参；藏译由印度论师日帝觉（Jinamitra）、施戒（Dānaśīla）与吐蕃译师智军（Ye shes sde）等译出，收入甘珠尔大乘经部（德格版 Toh 113）。须注明：藏译属藏传大藏经系统，不在《大正藏》编号体系之内。

本经为大乘一乘思想的根本圣典，素有「經中之王」之誉。其「開權顯實」「會三歸一」的宗旨——三乘皆为方便、究竟唯一佛乘——经由罗什译本的优美文体，主导了整个东亚佛教的自我理解。

## 二、文本结构与核心思想

对照研究的价值首先显现在文本结构上。罗什本二十八品中，通行学术观点认为原始层位为第一至二十品（含偈颂不全的形态），二十一品以后（如来寿量等）为晚期增补；中亚出土的梵本残卷止于较早的品数，与藏译的品次编排亦各有出入——三语对读正是判定经文成长史的利器。罗什本独有而梵本所无的《觀世音菩薩普門品》偈颂等细节，更是对照研究的经典案例。

义理层面，本库原文档录三语对照之核心段落，即〈方便品〉「一乘」偈：梵文「ekaṃ hi yānaṃ dvitīyaṃ na vidyate tṛtīyam api naivāsti kadāci loke」（十方佛土中唯有一乘，无二亦无三），与藏译「ཐེག་པ་གཅིག་སྟེ་གཉིས་པ་ཡོད་མིན་ཞིང་།」（theg pa gcig…）及罗什译文逐句对应。其思想结构为：其一，会三归一——声闻、缘觉、菩萨三乘是如来「以假名字引導於眾生」的方便施設；其二，一大事因缘——「諸佛世尊唯以一大事因緣故出現於世……欲令眾生開示悟入佛之知見」；其三，一切众生皆当成佛，为经中授记思想的根据。梵本的 「upāyā」（方便）一词，经什译点化为「方便說」，成为东亚佛教最核心的概念之一。

## 三、学术研究价值与争议

其一，文本批判价值：法华经梵本存世量在大乘经中首屈一指（尼泊尔系、克什米尔系、中亚系），与三译对读可逐品判定成立年代，是佛教经典形成史研究的示范田；著名的「添品」即隋代译者据梵本对什本重编的产物，其增删本身成为经文流动的标本。其二，翻译学价值：什译为意译极则，文采斐然而时有增饰；藏译逐字忠实。二本对勘可以精确分离「经文原义」与「罗什文体」，如「世尊」对译 bhagavat 之取舍诸例。其三，争议点：一者，〈药王菩萨本事品〉等品梵本与汉译的对应残缺，结尾诸品的形成顺序聚讼未决；二者，藏译所据梵本与尼泊尔系写本的亲缘关系尚待写本研究深入；三者，「一乘」与「佛性」概念在梵本中的措辞差异，牵动对整部经思想定位（成佛论还是涅槃存在论）的讨论。
