# 四分律拾毗尼義鈔 · 原文

## 一、文獻概述

《四分律拾毗尼義鈔》（又作《拾毗尼義鈔》，通稱《義鈔》），唐道宣律師（596–667）撰於貞觀元年（627）。原書三卷，今作六卷；現存上、中四卷，下篇二卷至宋代已散佚不傳。此書為道宣南山律學「五大部」之第四部：道宣以《行事鈔》總攝綱領，以《含注戒本疏》《刪補隨機羯磨疏》別明戒與業之二軌，而《義鈔》與《比丘尼鈔》則為拾遺補闕之作——「拾」者，拾三大部之遺義也。自卷上至卷中，共有毗尼大綱、起戒差別等十四段，多為辨析律學中疑難未決之義，以問答體裁申明律意，性質近於「義理之鈔」，與《行事鈔》之「事相之鈔」相為表裏。此書提出戒法、戒體、戒行、戒相四層理論體系，將戒律分為止持與作持，並以阿賴耶識種子為核心建立戒體論，思辨深度在五大部中最為突出。

《義鈔》之考據辨難，學術性極強，在五大部中最為難讀；唐五代戰亂後注疏散佚，下篇二卷至宋代竟不獲存。今本收於《卍續藏》第七十一冊，卷首有宋元照所撰之序，敘述撰述緣由、古注異議及校本差誤等；宋代允堪著有《四分律拾毗尼義鈔輔要記》六卷為其疏釋，元照又撰《四分律拾毗尼義鈔科》一卷。今人整理本有宗教文化出版社2015年《四分律拾毗尼義鈔校釋》（「南山律典校釋系列」之一）。其僅存之部分，仍是研究道宣律學思想深層義理之珍貴文獻。

## 二、核心段落選錄

> **原文**：據百度百科「四分律拾毘尼義鈔」條記載：「《四分律拾毗尼義鈔》，凡六卷，唐代道宣撰於貞觀元年（公元627年）。本書又被稱為拾毗尼要義鈔、拾毗尼義鈔、集義鈔、要義鈔。乃補充解釋《四分律行事鈔》的著作，現存上、中四卷，下篇二卷至宋代已散佚不傳。自卷上至卷中，共有毘尼大綱、起戒差別等十四段。卷首有元照的序，敘述撰述的來由及古注異議校本的差誤等。」
> **白話對照**：本書共六卷，是唐代道宣律師在貞觀元年（627）撰寫的，又名《拾毗尼要義鈔》《集義鈔》《要義鈔》。它的作用是補充解釋道宣自己的《四分律行事鈔》：現在保存下來的是上、中四卷，下篇兩卷到宋代已經失傳。從卷上到卷中，共有「毗尼大綱」「起戒差別」等十四段內容。卷首附有宋代元照寫的序，說明這本書撰寫的緣由、古代注解的分歧意見，以及校對底本時發現的錯誤。

> **原文**：據律宗史傳記載，道宣律師於終南山豐德寺撰述律部，一生著述「南山五大部」：《四分律刪繁補闕行事鈔》十二卷、《四分律含注戒本疏》八卷、《四分律刪補隨機羯磨疏》八卷、《四分律拾毗尼義鈔》六卷、《四分律比丘尼鈔》六卷，為千年來漢傳律學之根本典據。（此五大部書名卷數為律宗通說）
> **白話對照**：道宣律師在終南山豐德寺專心撰述律學著作，一生完成了南山宗的五部根本大書：《行事鈔》《含注戒本疏》《刪補隨機羯磨疏》《拾毗尼義鈔》《比丘尼鈔》。這五部書（俗稱「南山五大部」）確立了漢傳佛教律學的基本格局，一千多年來一直是出家人學戒的根據。其中《義鈔》的角色，是把前三大部裏來不及詳細討論的疑難義理，用問答方式再深入辨析一遍。

> **原文**：據百度百科條目所述：「書中將戒律分為止持戒與作持戒，並以阿賴耶識種子為核心建立戒體論體系。宋代允堪著有《四分律拾毗尼義鈔輔要記》六卷，元照著有《四分律拾毗尼義鈔科》一卷。」（此為本書義理結構之概說）
> **白話對照**：本書把戒律分成兩大類：「止持」——禁止去做的戒；「作持」——必須去做的戒（如說戒、安居等僧團法事）。又以唯識學的「阿賴耶識種子」學說來解釋「戒體」——受戒時在內心種下的防非止惡之功能，這是道宣會通大小乘、以唯識義建立戒體論的著名主張。宋代允堪為此書寫了六卷《輔要記》，元照編了一卷《科》，可見後世律家對它的重視。

## 三、重要名句

> **名句一**：「事義兩鈔，表裏相資」——元照對《行事鈔》與《拾毗尼義鈔》關係之概括：事相與義理如內外表裏，互相資成。

> **名句二**：「拾毗尼遺義，決持犯疑難」——本書性質之寫照：拾取律藏遺義，決斷持犯之疑難。

> **名句三**：「南山五大部」之總名——道宣律學體系之通稱，本書為其中第四部，足見其於律宗地位。

> **名句四**：「以問答辨析，申明律意」——本書體裁之特點：不鋪陳事相，而以問難往覆闡明深義。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 毗尼 | 梵語 vinaya 之音譯，即律藏、調伏之義 |
| 義鈔 | 拾遺辨義之鈔記，與明事相之「事鈔」相對 |
| 五大部 | 道宣五大律書之總稱：事鈔、戒疏、業疏、義鈔、尼鈔 |
| 止持作持 | 止持即禁惡之戒，作持即應作之善法，本書之分類綱領 |
| 戒體 | 受戒所發防非止惡之體，道宣以阿賴耶識種子釋之 |
| 持犯 | 持戒與犯戒之判析，律學核心問題 |
| 通塞 | 律文適用之通例與限制，義鈔辨析之重點 |
| 二部僧 | 比丘僧與比丘尼僧，尼眾受戒須二部僧中作法 |
| 豐德寺 | 道宣撰述五大部之根本道場，在終南山 |
| 卍續藏 | 《卍字續藏經》第七十一冊，本書今存本所依之藏經 |
