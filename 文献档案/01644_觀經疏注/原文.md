# 观经疏注·原文

## 一、概述

观经疏注，涉及《观无量寿经》的两部重要注疏：

**《观无量寿佛经疏》** 一卷（T1750），隋·智顗说，门人灌顶记，收于《大正藏》第三十七册。此疏以天台五重玄义（释名、出体、明宗、辨用、教相）解析《观经》，以一心三观释"观"字，以一体三身解"佛"字，以诸法实相为经正体，以修心妙观显四净土为宗，以能除五逆即生九品为用，以方等大乘圆顿为教相。宋·知礼撰《观无量寿佛经疏妙宗钞》六卷（T1751）为此疏作注，倡导即心念佛、约心观佛之义。

**《观无量寿经疏》** 四卷（T1753），又称《观经四帖疏》《四帖疏》，唐·善导集记，收于《大正藏》第三十七册。全书由玄义分、序分义、定善义、散善义四部分组成，旨在"楷定古今"——评判裁定前人（净影慧远、嘉祥吉藏、天台智顗等）注解以为后世楷模。核心主张为"本愿称名，凡夫入报"，确立称名念佛为"正定之业"，将修行分判为正行与杂行，主张凡夫可仗阿弥陀佛愿力带业往生报身报土。

## 二、核心段落

### 原文

> 一心专念，弥陀名号，行住坐卧，不问时节久近；念念不舍，是名正定之业，顺彼佛愿故。

> 一者决定深信：自身现是罪恶生死凡夫，旷劫以来常没常流转，无有出离之缘。二者决定深信：彼阿弥陀佛四十八愿，摄受众生，无疑无虑，乘彼愿力，定得往生。

> 譬如有人，欲向西行，百千之里。忽然中路，见有二河，一是火河在南，二是水河在北。二河各阔百步，各深无底，南北无边。正水火中间，有一白道，可阔四五寸许。此道从东岸至西岸，亦长百步。……作此念时，东岸忽闻人劝声："仁者！但决定寻此道行，必无死难，若住即死。"又西岸上有人唤言："汝一心正念直来，我能护汝，总不畏堕于水火之难。"此人既闻此遣彼唤，即自正当身心，决定寻道直进，不生疑怯退心。……须臾即到西岸，永离诸难，善友相见，庆乐无已。

### 白话翻译

> 一心专念阿弥陀佛的名号，不论行住坐卧，不拘时间的长短，念念相续而不舍离，这就叫作"正定之业"——因为随顺阿弥陀佛的本愿的缘故。

> 第一，决定深信：自己现今是罪恶生死的凡夫，无始劫以来常常沉没于生死之中、流转不息，没有出离的因缘。第二，决定深信：彼阿弥陀佛的四十八愿，摄受一切众生，不用怀疑也不必忧虑，乘着佛的愿力，一定能够往生。

> 譬如有一个人，想要向西方行走百千里路。忽然在中途见到有两条河，一条是火河在南边，一条是水河在北边。两条河各宽百步，深不见底，南北无有边际。在水火二河正中间，有一条白道，大约四五寸宽。这条道从东岸到西岸，也有百步之长。……正这样想的时候，东岸忽然传来劝勉的声音："仁者！你只管决定沿着这条道走，一定不会有死的灾难，如果停下来就会死。"西岸上也有人呼唤道："你一心正念直接过来，我能保护你，完全不必害怕堕入水火的灾难。"这人听到东岸的遣发和西岸的呼唤，就端正身心，决定沿着白道一直前进，不生疑怯退却之心。……不一会儿就到了西岸，永远脱离一切苦难，与善友相见，欢喜无比。

## 三、名句

1. **"汝一心正念直来，我能护汝，总不畏堕于水火之难。"** ——出自善导《四帖疏》二河白道喻，阿弥陀佛的呼唤，是净土宗他力本愿思想的经典表达，体现了佛力护念、摄取不舍的核心教义。

2. **"一心专念弥陀名号，行住坐卧不问时节久近，念念不舍，是名正定之业，顺彼佛愿故。"** ——善导确立称名念佛为正定之业的根本依据，"顺彼佛愿"四字是净土宗称名念佛得以成立的教理核心。

## 四、术语表

| 术语 | 释义 |
|------|------|
| 四帖疏 | 善导《观无量寿经疏》四卷之总称，即玄义分、序分义、定善义、散善义 |
| 楷定古今 | 善导撰疏之意趣，评判前人注解是非，为后世确立楷模 |
| 正定之业 | 善导所立五正行中的称名念佛，以"顺彼佛愿"故为正定往生之行业 |
| 正行与杂行 | 正行即依净土经典修行的五种行（读诵、观察、礼拜、称名、赞叹供养）；杂行为净土经典以外诸善万行 |
| 三心 | 往生须发三心：至诚心（真实心）、深心（深信心）、回向发愿心 |
| 二河白道 | 善导所设譬喻，水火二河喻贪嗔烦恼，白道喻清净愿生心，东岸遣喻释迦，西岸唤喻弥陀 |
| 凡夫入报 | 凡夫仗佛愿力可直接往生阿弥陀佛报身报土，不需断惑 |
| 妙宗钞 | 宋·知礼《观无量寿佛经疏妙宗钞》，释智顗观经疏，倡即心念佛、约心观佛 |
| 一心三观 | 天台宗观法，一念心中同时观空、假、中三谛，知礼用以统摄十六观 |
| 定善与散善 | 善导分十六观：前十三观为定善（韦提希请），后三观为散善（佛陀自说），即三福九品 |
