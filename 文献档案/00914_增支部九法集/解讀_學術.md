# 增支部九法集 · 学术解读

## 一、背景部类

《九法集》（Navakanipāta，巴利文）是南传巴利三藏《增支部》（Aṅguttara-nikāya）的第九集，是收束于"九"这一法数的经典总集。增支部按法数由少到多编排经典的次序，从一法集逐渐递进到十一法集，九法集即处在这一递增体系的靠后位置，收录以九为纲目的经典约一百一十余经，内容涵盖九次第定、九众生居、九慢、九恼法与九想等多类法门。

在部类归属上，《九法集》属于"经藏"（Sutta-piṭaka）中的《增支部》，并非独立成书，而是整个增支部结构里的有机一环。它与第一至第八法集、第十、第十一法集共同构成增支部的完整体系。后世流传的汉译对应典籍是《增壹阿含经》（T125），藏汉对照研究中，可看到增一阿含中分散收录的"九法"类教说，并无与巴利九法集逐一对应的独立品名，多数内容零散分布于各卷。

本集的教理枢纽位置甚为关键：它以"九"为结构序数，上承八正道等八法门教学，下启十善十恶等十法教义，是从别相法门到总相法门的过渡桥梁。特别是"九众生居"与"九次第定"，分别从存在论与禅定修学两个面向，完整概括了三界众生的安居形态与止观次第的纲领，历来为禅修传统与教学体系所重。

## 二、结构与核心思想

《九法集》的核心内容可从三个维度加以把握。

其一为"九众生居"（sattāvāsa）。所谓众生居，即以九种众生所能安居的状态为名，逐一列举欲界人天、色界诸天、乃至无色界的空无边处、识无边处、无所有处、非想非非想处等，合为九种"生居"或"住处"。这一分类用于说明有情在三界的种种生存形态，并区分"既有存在而又安住"与"存在而不住止"的差别，属于南传宇宙论的基本框架。

其二为"九次第定"（anupubbavihāra），即由四禅（初禅、二禅、三禅、四禅）与四无色定（空无边处、识无边处、无所有处、非想非非想处）再加之"想受灭定"（saññāvedayitanirodha），共九种定境，构成由浅入深、层层递进的正定次第。这种对定境的整体编排在九法集中被固定为"九级阶梯"，成为后世佛教禅定次序理论的直接源头，也被《清净道论》所继承发扬。

其三为"九想""九慢""九恼"等对治修行与烦恼分类。九想是从观照身体坏散的九种不净观想，用于对治贪染；九慢是收束于自慢与他慢的九种比较之心；九恼则指缘于九种对象所生起的恼害。这些法数把贪、慢、瞋等烦恼分门别类，明确"何者当断、以何法对治"的修行科目，体现了佛陀因材施教的教学特色。

九法集的思想旨趣在于"以除法数归类教学，契应不同根机"。它既提供认识存在的宏观框架（九众生居），也提供止观归一的具体阶梯（九次第定），还提供烦恼对治的自省工具（九想、九慢、九恼）。全卷反复强调"如实知、如实见"，以慧为导而修习，最终达成烦恼灭尽而得解脱。

## 三、价值与汉译对应

《九法集》的学术价值有三。其一，它是研究巴利"法数"教学法与经部按数目分类的重要史料；其二，"九次第定"是后世禅定次序理论的直接源头，对南传《清净道论》的定学体系具有奠基作用；其三，"九众生居"提供了三界众生观的标准表述，是理解南传宇宙论的关键节点。

汉译对应上，《增壹阿含经》中散见多处涉及"九法"的内容，属同源而不同编排。自东晋僧人译出《增一阿含》以来，其中已含九众生居的次第说法，与巴利九法集相印证。《中阿含》中关于定次第的教说，也与九次第定一脉相承。现代学术界常用南传巴利与汉译《增壹阿含》对勘，借以探讨部派律则与教义之间的异同。

其中"九想"与汉地不净观修法相通，"九众生居"与汉译论书对三界众生分布的描述甚为一致。这些提示我们，以九为数的教法在部派时代即已广泛通行，可说跨越传承差异、作为共同法理而被反复采用，是探讨原始佛教统一面貌的重要依据。

## 四、术语

| 术语（巴利/梵语） | 汉译名 | 释义 |
|---|---|---|
| Navakanipāta | 九法集 | 以九为法数的经典结集 |
| Aṅguttara-nikāya | 增支部 | 按法数递增排列的经藏部类 |
| Anupubbavihāra | 九次第定 | 四禅、四无色定、想受灭共九种定境 |
| Saññāvedayitanirodha | 想受灭定 | 尽灭感官知与受的第九定 |
| Sattāvāsa | 九众生居 | 众生在三界的九种安居之处 |
| Nava-saññā | 九想 | 对身体的九种不净观想 |
| Nava-māna | 九慢 | 依身等所生的九种慢 |
| Nava-kodha | 九恼 | 缘于九种对象所生的恼害 |
| Kāma-guṇa | 欲功德（五欲） | 五欲绳，诸境所得欲乐 |
| Āsava | 漏 | 烦恼漏失，令流转生死 |

以上术语表明，九法集既有宏观的存在结构论（九众生居），又有具体定境次第（九次第定）与烦恼对治法门（九想、九慢、九恼），是全面把握巴利增支部九法教义的关键节点。
