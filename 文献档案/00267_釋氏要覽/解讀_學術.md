# 釋氏要覽 — 学术解读

## 一、文献背景与成书

《釋氏要覽》为北宋道诚法师所集的佛教名相类书，三卷，今收于《大正藏》第五十四册（事汇部）。道诚初为京师讲经论义学僧，后退居钱塘（杭州）昭庆寺，专事撰述。据书前自序，他因见初学者面对佛教繁多名相术语茫然无绪，于是检阅经论、采集众书，约于天禧年间至天圣初（11世纪20年代）编纂成书，取「便于初学检阅」之意。

本书的性质是一部「佛教百科小辞典」，体例上承类书传统，分二十七篇（三宝、住持、出家、剃发、法衣、戒法、斋粥、礼数、道具、寺院等），每篇之下条列名相，注明出典。所据文献包括经律论三藏及《高僧传》《续高僧传》《大唐西域记》《南海寄归内法传》《开元释教录》等史传杂书百余种，许多条文还保存了今日已佚或稀见文献的引文。

## 二、文本结构与核心思想

《释氏要览》虽为工具书，却有其贯穿性的理解框架。本档案所录「僧宝」条最能体现：

其一，**以和合释僧**。「僧者，梵語僧伽，此云眾和合。」书中进一步引申「理和」（同证择灭无为）与「事和」（六和敬：身和同住、口和無諍、意和同事、戒和同修、見和同解、利和同均）。这一条目完整呈现了佛教僧团的组织理想——「和」不是一团和气，而是以共同的证悟目标（理和）统摄日常生活的六个协作维度（事和）。

其二，**三宝的解读**。「佛者覺也，法者正也，僧者和也。」以觉、正、和三字概括三宝的精神内核，沿袭了南北朝以来「三宝为一体三义」的诠释传统，是宋代民间佛教知识普及的标准表述。

其三，**以戒为师、以法为药、以心为道的纲要**。「受持戒法，修習止觀，度諸眾生，名為僧寶」——将持戒（律）、止观（禅）、度生（悲）并举，勾勒出北宋佛教对出家身份的完整定义。

全书二十七篇的排序亦有深意：从三宝、住持（教团史）讲起，经出家的制度与生活细节（剃发、法衣、戒法、斋粥），终于礼数与称谓——实际构成一部「宋代出家生活指南」。

## 三、学术研究价值与争议

研究价值方面：（1）本书是研究北宋佛教知识社会史的独特材料：它记录了11世纪普通僧人与居士实际使用的佛教词汇、称谓与礼俗，与义学高深著述形成互补；（2）书中大量征引的唐五代文献（如段成式《酉阳杂俎》释氏条、《备急单方药方》之类）可作辑佚之资；（3）它是了解宋代「民间佛教」如何标准化的重要证据——名相解释的取舍背后，是当时通行的佛教常识底图。

争议问题方面：（1）道诚的训释有时沿用俗说而非严格经据，如对若干梵语名词的对音解释带有民间词源学色彩，引用时须与《翻译名义集》（南宋法云编，性质相近而更严谨）对勘；（2）本书与《翻译名义集》《一切经音义》等同类书的资料重合与先后关系，尚未有全面的源流研究；（3）书中所反映的僧制（如挂单、斋粥）与唐宋实际寺院运作是否一致，需结合禅宗清规类文献与敦煌文书互证。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 僧伽（Saṅgha） | 意译「众和合」，四人以上如法生活的出家团体 |
| 六和敬 | 身、口、意、戒、见、利六个维度的僧团和合原则 |
| 三宝（Triratna） | 佛（觉）、法（正）、僧（和），佛教归依对象 |
| 择灭无为 | 以智慧简择而证得的寂灭真理，「理和」之所同证 |
| 止观（Śamatha-Vipaśyanā） | 定慧二学的修行方法，僧宝行持的核心 |
| 类书 | 分门别类辑录知识以便检阅的工具书体例 |
