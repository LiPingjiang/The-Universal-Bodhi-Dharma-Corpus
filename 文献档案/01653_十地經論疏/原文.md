# 十地经论疏·原文

## 一、概述

《十地经论》十二卷（T1522），天亲（世亲）菩萨造，后魏·北印度三藏菩提流支、勒那摩提译（508-511年），佛陀扇多传语，收于《大正藏》第二十六册。本论是对《华严经·十地品》（即《十地经》）的注释论书，系统阐释菩萨修行成佛所经历的十个阶位（十地），并阐述"三界唯心""六相圆融"等重要思想。

世亲原为小乘学者，后因听闻《十地经》而改宗大乘。此论于北朝被专门研习，形成地论学派（地论宗），分南道、北道二派。其思想后来为华严宗所吸收，六相义成为华严宗法界缘起的理论基础之一。后世注疏有净影慧远《十地经论义记》、法上《十地论义疏》、灵裕《十地论疏》等，多已散佚或残存。

十地者：一欢喜地、二离垢地、三发光地、四焰慧地、五难胜地、六现前地、七远行地、八不动地、九善慧地、十法云地。

## 二、核心段落

### 原文

> 论曰：菩萨如是已证正位，依出世间道，因清净戒，说第二菩萨离垢地。此清净戒有二种净：一发起净，二自体净。发起净者，说十种直心。何等为十？一直心、二柔软心、三调柔心、四善心、五寂灭心、六真心、七不杂心、八不悕望心、九胜心、十大心。菩萨生是十心，得入第二菩萨离垢地。
> ——论·离垢地第二

> 论中举出六相以释经文中各种十法之义。六相者：一总相、二别相、三同相、四异相、五成相、六坏相。总相者，根本入故；别相者，余差别入故；同相者，入法故；异相者，入相差别故；成相者，说事说于名故；坏相者，如来说诸地故。
> ——论·初地（六相义）

> 三界唯心。如来在此分别演说十二因缘皆依一心。
> ——论·六地（三界唯心义）

### 白话翻译

> 论中说：菩萨这样已经证得正位，依出世间道，以清净戒为因，宣说第二地——菩萨离垢地。此清净戒有两种清净：一是发起净，二是自体净。发起净，是说十种直心。哪十种？一直心、二柔软心、三调柔心、四善心、五寂灭心、六真心、七不杂心、八不悕望心、九胜心、十大心。菩萨生起这十种心，便能进入第二地——菩萨离垢地。
> ——离垢地白话

> 论中举出六相来解释经文中各种"十法"的意义。六相是：一总相（总体）、二别相（部分差别）、三同相（共同性）、四异相（差异性）、五成相（成立相）、六坏相（坏灭相）。总相，是就根本总体而入；别相，是就其余差别部分而入；同相，是就共同法体而入；异相，是就各入相差别而入；成相，是说事相建立名称；坏相，是如来说明诸地次第不同。
> ——六相义白话

> 三界唯是心所造。如来在此分别演说十二因缘，皆依一心而建立。
> ——三界唯心义白话

## 三、名句

1. **"三界唯心。如来在此分别演说十二因缘皆依一心。"** ——世亲释《十地经》第六地，提出"三界唯心"的核心命题，将十二缘起归于一心，为瑜伽行派唯识思想的重要源头，影响深远。

2. **"六相者：一总相、二别相、三同相、四异相、五成相、六坏相。"** ——世亲从初地菩萨愿文中提炼六相义，后经华严宗法藏、澄观等发扬为"六相圆融"，成为华严宗法界缘起论的理论基石。

## 四、术语表

| 术语 | 释义 |
|------|------|
| 十地 | 菩萨修行十阶位：欢喜、离垢、发光、焰慧、难胜、现前、远行、不动、善慧、法云 |
| 六相 | 世亲所立：总相、别相、同相、异相、成相、坏相，后为华严宗六相圆融义所本 |
| 三界唯心 | 世亲释六地时提出，谓三界万法皆依一心而建立 |
| 离垢地 | 第二地，以清净戒为体，远离一切垢染 |
| 十种直心 | 入离垢地所发十心：直、柔软、调柔、善、寂灭、真、不杂、不悕望、胜、大 |
| 三种戒净 | 离戒净（十善业道）、摄善法戒净、利益众生戒净 |
| 地论宗 | 北朝研习《十地经论》的学派，分南道（慧光系）与北道（道宠系）二派 |
| 十二有支 | 无明至老死十二缘起支，论中释为皆依一心 |
| 法云地 | 第十地，菩萨如大云含受法雨，普润众生 |
