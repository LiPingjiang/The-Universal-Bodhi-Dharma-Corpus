# 佛教美學 · 原文

## 一、學科概述

佛教美學（Buddhist Aesthetics）研究佛教義理與佛教藝術中的審美經驗、審美範疇及其對東亞審美傳統的塑造。佛教雖以「離欲」為教，卻在兩千餘年的實踐中孕育了極豐富的美的世界：經變畫的莊嚴、造像的圓滿相好、伽藍的空間秩序、禪僧書畫的枯淡，皆為「以相表法」的美學載體。中國方面，宗炳《畫山水序》提出「澄懷味象」，把山水審美與觀照佛理打通；王維以「詩佛」開闢空靈詩境；禪宗更以「青青翠竹，盡是法身」消解宗教與審美的界限。日本方面，鎌倉以降茶道、俳句、能樂將禪的直觀發展為「侘寂」（wabi-sabi）美學——欣賞無常、不完美與質樸——美學家大西克禮（1888–1959）以西方哲學方法對「侘」「寂」「物哀」作現代闡釋，其《日本侘寂》經王向遠譯介影響中文學界；京都學派久松真一《禪與美術》則提出「無相的美」的禪美學綱領。當代漢語學界，皮朝綱等以《禪宗美學史稿》等著作建構中國禪宗美學史，而「禪意設計」「侘寂風」已成為全球室內設計與產品美學的流行範式。

## 二、核心議題與佛教觀點

核心議題有四：一、佛教對「美」的基本態度——美色為五欲之一，耽著則障道；但佛教並不否定美的宗教功能，以「相好莊嚴」攝受眾生，佛像量度（如《造像量度經》）本身就是審美法則；二、審美範疇的形成——空、靜、寂、淡、圓融等義學範疇如何沉澱為審美範疇，禪的「不立文字」催生了以少勝多的表達美學；三、無常與美——侘寂以凋殘、時間痕跡為美，正是「諸行無常」的審美化；四、審美與解脫的關係——審美觀照可否成為「觀照般若」的方便，即「美育代宗教」式的現代命題。佛教的總立場是：美非目的，而是入道之門，故金身與空庭、華麗與枯淡皆可為法之符號。

> **經典依據**：
> 「心如工畫師，能畫諸世間，五蘊悉從生，無法而不造。」——《華嚴經·夜摩宮中偈讚品》（T279）
>
> 「觀色如聚沫，觀受如水泡。」——《雜阿含經》（T99）所示之觀照，正是對美色執著的消解

## 三、代表學者、著作與案例

大西克禮《幽玄與物哀》《日本侘寂》確立了日本佛教系美學的學理表述；久松真一（1889–1980）《禪與美術》以「無相的自我」詮釋禪藝術。鈴木大拙《禪與日本文化》向西方介紹禪的審美精神，深刻影響了約翰·凱奇等現代藝術家。中國方面，皮朝綱《禪宗美學史稿》系統梳理了從達摩到明清的禪宗審美意識；田青《禪與樂》闡發禪與音樂的關係。藝術實例方面，敦煌莫高窟壁畫以經變畫實現「凈土意象」的視覺化，千利休的草庵茶室「待庵」則以二疊空間將侘寂美學推向極致，二者分別代表佛教美學的「莊嚴」與「空寂」兩極。

| 術語 | 釋義 |
|---|---|
| 侘寂 | 源於禪的日本美學，欣賞不完美、無常與質樸 |
| 澄懷味象 | 宗炳語，以虛靜胸懷品味物象、觀照道體 |
| 相好 | 佛身三十二相八十種好的莊嚴形象 |
| 經變 | 將經文義理轉為圖像的敘事藝術 |
| 空寂 | 以空、靜為基調的禪美學範疇 |
| 莊嚴 | 以美好事物嚴飾佛土與佛像的宗教美學實踐 |
