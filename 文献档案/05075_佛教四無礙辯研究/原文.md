# 佛教四無礙辯研究 · 原文

## 一、概念概述

四無礙辯是四無礙解（catasraḥ pratisaṃvidāḥ）就「說法運用」一面的譯名（「辯」與「解」異譯同體：解約內證之智，辯約外用之才）。本題側重其作為說法者之辯才功德；義理總述與名目解析詳`05074_佛教四無礙解研究`、通名概述詳`05084_佛教四無礙研究`，三題互見。四無礙辯之名目：一、法無礙辯——於教法名相差別（蘊處界、諦緣度等一切法相）說之無盡；二、義無礙辯——於法之義理（空、真如、實際等別相之義）說之無盡；三、辭無礙辯——於三世一切眾生之語言音聲、方域差別，隨類而說無礙；四、樂說無礙辯（辯說無礙）——隨一切眾生之所應機，樂說不倦，於一義中說無量義、於無量義中說一義，辯才無盡。此「四辯」作為說法功德之經證：《法華經·五百弟子受記品》稱「得四無礙辯」為菩薩記別之德；《維摩詰經》（T475）以維摩詰「深入緣起，斷諸邪見，有無二邊，無復餘習；演法無畏，猶師子吼」顯無礙辯才；《華嚴經》以九地菩薩「四無礙辯」為大法師之德；《大智度論》卷二十五、《瑜伽師地論》卷四十五、《成唯識論》卷九皆有論列。就「辯」之立場：四辯之運用在「不滯」——說法者以法辯立教、以義辯顯理、以辭辭達機、以樂辯不倦；佛教史中鳩摩羅什譯場、玄奘譯場之「辯才無礙」，以及《法華經》「為大法師」之理想，皆以此為最高修養。天台立「化他說法」之教學次第，亦以四辯為極則。

## 二、核心經文選錄

> **原文**（《妙法蓮華經》卷四〈五百弟子受記品〉，T262）：
> 「爾時佛告諸比丘：……是人於無量阿僧祇劫，具菩薩道，當得作佛……其佛以三乘教化眾生，得四無礙辯。」

> **白話對照**：
    菩薩修行圓滿之德中，佛特為授記者點出「得四無礙辯」：能以三乘隨機教化，於法、義、辭、樂說四者皆無滯礙。四辯是佛與大菩薩「應機說法」之能力保證，故受記文屢屢標舉之。

> **原文**（《維摩詰所說經》卷上〈佛國品〉，T475）：
> 「深入緣起，斷諸邪見，有無二邊，無復餘習；演法無畏，猶師子吼，其所講說，乃如雷震。」

> **白話對照**：
    維摩詰長者之辯才：於緣起深法通達無疑（義無礙），於一切見執斷之無餘（法無礙），演法無所畏懼如師子吼（樂說無礙），言音如雷震十方（辭無礙）。大乘經以「師子吼」為四無礙辯之象徵——於九十六種外道眾中說法而無所怖畏。

## 三、重要名句

> 「得四無礙辯，為大法師。」（《法華經》受記之通文義）

> 「以一音演說法，眾生隨類各得解。」（《維摩詰經·佛國品》——辭無礙辯之極致）

> 「辯才無礙，樂說不倦。」（大乘經歎菩薩之常語）

> 「樂說無礙者，於一法中說無量義，於無量義中說一法。」（《大智度論》卷二十五之義概）

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 四無礙辯 | 法、義、辭、樂說四種說法無滯之辯才 |
| 法無礙辯 | 於一切法相差別說之無盡 |
| 義無礙辯 | 於諸法義理說之無盡 |
| 辭無礙辯 | 於一切眾生音聲語言隨類而說 |
| 樂說無礙辯 | 應機樂說、辯才不竭 |
| 師子吼 | 說法無畏之象徵 |
| 一音說法 | 佛以一音而眾生各得其解，辭辯之極致 |
| 大法師 | 具四無礙辯、能持大乘法藏之說法者 |
