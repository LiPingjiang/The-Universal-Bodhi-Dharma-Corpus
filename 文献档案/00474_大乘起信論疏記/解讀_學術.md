# 大乘起信论疏记 — 学术解读

## 一、文献背景与成书

《大乘起信论》题为马鸣菩萨造、梁真谛译（T1666），另有唐实叉难陀重译本（T1667），但自20世纪初日本学者望月信亨提出"中国撰述说"以来，其作者与译者的真伪成为佛教文献学第一悬案，迄今未有定论（详见本档案库`00103_大乘起信論`专档）。无论真伪，此论以"一心二门"统摄如来藏与阿赖耶识的框架，深刻塑造了整个东亚佛教。

本文献所题"起信论疏记"，指《起信论》的"疏—记"注疏谱系，即历代注疏及其再注释的层累传统，其中骨干为：

1. **隋慧远《大乘起信论义疏》**：现存最早注疏，以地论师立场释之；
2. **新罗元晓《大乘起信论疏》二卷**（世称"海东疏"，收于《大正藏》第四十四册）：判教精当、文义畅快，为"起信三疏"之一，远传日本，影响深远；
3. **唐法藏《大乘起信论义记》**（另有专档收录）与**宗密《大乘起信论疏》四卷**（法藏述、宗密注）：宗密摘录《义记》兼加己意，成为后世最通行的本子；
4. **"记"的层累**：宗密疏出，后有传奥《随疏记》、宋子璿《笔削记》等"记"体再注，构成"疏下加记"的立体注释传统；明代德清《起信论直解》、智旭《裂网疏》（另档收录）复开新风。

## 二、文本结构与核心思想

"疏记"传统围绕《起信论》的本有结构展开：

1. **依"因缘—立义—解释—修行信心—劝修利益"五分**科判全书；
2. **疏解"一心二门"**：一心开真如、生灭二门——元晓以"动静一对"释二门不一不异；宗密承法藏，以"不变随缘、随缘不变"释真如与无明的交彻；
3. **诠释"本觉—始觉—不觉"**：本觉是心体本明，不觉是一念无明，始觉是修行回归——疏家由此阐明"觉悟非新得，只是复本"；
4. **会通禅教**：宗密疏的最大特色，是以《起信论》"本觉"义为枢纽，会通华严与禅宗，主张"一心"为禅教共同的宗源，其疏成为禅教一致论的经典文本。

核心思想可概括为三点：

- **注释即诠释史**：从元晓到子璿，各代疏记对"一心二门"的不同科判，实际是如来藏思想在东亚被反复重构的历史——研究注疏比研究孤立的《起信论》文本更能呈现思想史的实际进程；
- **"疏不破经，记不破疏"的注经规范**：疏解经、记解疏的层级注释体，使义理传承既有稳定性又可层层推进，是东亚儒佛共享的学术制度；
- **本觉论的枢纽地位**：疏记传统把"心性本觉"确立为东亚佛教心性论的标准表述，对禅宗"明心见性"、华严"性起"说均有直接滋养。

## 三、学术研究价值与争议

**研究价值**：（1）起信论注疏群（含本档及`00728_大乘起信論註疏`所收历代诸疏）是考察中国、新罗、日本佛教思想互动的最佳标本——元晓疏、法藏疏、宗密疏与日本凤潭等的再批判，构成一条跨国思想链；（2）宗密疏是研究唐代禅教一致论的核心文本；（3）"疏—记"层级注释的体例本身，是东亚文献学与学术史研究的独特对象。

**代表学者与争议**：（1）望月信亨《大乘讲信论之研究》立伪托说后，宇井伯寿、平川彰等相继讨论，注疏传统中对"真谛译"的记载遂皆需重审；（2）宗密疏对法藏《义记》的"添削窜改"问题，日本凤潭《起信论义记幻虎录》早有严苛批评，成为文献批判的著名公案；（3）现代研究中，高崎直道的如来藏研究与"批判佛教"（松本史朗、袴谷宪昭）对"本觉"思想的批判，使疏记传统的义理价值需要重新定位。
