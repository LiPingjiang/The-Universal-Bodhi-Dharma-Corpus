# 佛教中庸思想 — 学术解读

## 一、文献背景与成书

本条目为语料库「寰宇覺海·菩提法藏」之独立文献补充条目，编号 X8080，目录名作「佛教中庸思想_1」。需先作名目辨正：佛教义理中与本条目相应的规范术语是「中道」（Madhyamā-pratipad），「中庸」一词借自《礼记·中庸》与宋明儒学，编目者以之译写「无过无不及而行于中」之义，属语料库编纂时的用词选择；本条目《原文》概述一节所标「離於二邊，行於中道」实为中道义之正文，故以下以「中道」论之，而于标题仍存「中庸」原名并加辨析。

据实说明：《原文》非经论传本，而是中道义理的纲要辑录——概述一句，选录与名句各存两条引文，术语表七条，末附相关文献指引；条目 README 自署「待後續填充內容」，性质为保存中道纲要断语的名目型简编。

选录引文「佛說中道者，離於二邊——不著常，不著斷；不著苦，不著樂；不著有，不著無。如是離二邊，行中道」糅合了两处经典义：一为《杂阿含经》与巴利《相应部》所传缘起中道之义——「离于二边而说法，所谓此有故彼有……」；一为龙树《中论·观因缘品》归敬颂「不生亦不灭，不常亦不断，不一亦不异，不来亦不出」的八不中道。引文以常断、苦乐、有无三对二边作说，其中「不著苦，不著樂」近于早期佛教既斥纵欲乐行亦斥自苦行之中道、《转法轮经》所示之理；「不著常，不著斷」「不著無」则是缘起正观破二边的展开。第二条引文「中道者，即十二因緣。無明滅即行滅，乃至老死滅。此是中道正觀」直指缘起还灭门为中道体，与《中论》「因緣所生法，我說即是空」之归趣一贯。

## 二、文本结构与核心思想

《原文》五节为补充条目通例，其义理可分三层。

其一，中道的方法论义。佛教的中道首先是认知方法而非折中主义：凡夫与外道于一切法计执两边——或执常（灵魂永存）或执断（死后断灭）、或执乐（纵欲无害）或执苦（自苦得脱）、或执有（实有）或执无（断无）；中道即以缘起正观双破两边。引文三个「不著」的排比正是此操作：不是取两边的中间值，而是揭示两边各自的不可立足。

其二，中道的缘起义。第二条引文点明中道即十二因缘：缘起故非常（有生灭故），非断（相续故），非有非无（待缘故）。「無明滅即行滅」的还灭门更显示中道不止于理论平衡，而是通向解脱的因果操作——顺观知苦集，逆观证灭道。

其三，与儒家中庸之辨。儒家中庸是德性实践上的「执两用中」「无过不及」，落在人伦分寸上；佛教中道是实相观照上的「离边不住中」，落在缘起性空的证悟上。二者名近而实异：前者之「中」是可执持的度，后者明言「中」亦不可立——若立中为中，则中复成边。天台家「但中」「圆中」之辨、明末蕅益智旭以佛理会通《中庸》而作《四书蕅益解》，是两系交涉的显例。

## 三、学术研究价值与争议

第一，中道概念的语义史。从原始经教的实践性中道（苦乐之间的八正道），到部派阿毗达磨的谛理中道，再到中观学派的八不中道与天台圆中，中道义经历了由修行方针到实相哲学的深化；横山纮一、梶山雄一等学者对此谱系均有专著。本条目引文混合早期与中观两层表述，恰可作语义史教学的一枚标本。

第二，「中道非折中」的诠释争议。世俗理解常把中道等同于调和折中（各打五十大板），此误读已遭佛教内部一致否定；但「不著有无」在何种意义上仍是一种「立场」，中观后学（如寂护《中观庄严论》）与汉传三论宗（吉藏《中观论疏》）对「中」之可说性有不同的安立，构成中观诠释史的主线之一。

第三，佛儒会通的学术评估。以「中庸」译写中道、以中道解释《中庸》，是宋明以来三教会通的常见路径；现代学界（如牟宗三对佛教「圆教」与儒家圆教的分判、荒木见悟关于阳明学与佛教的系列研究）对此持严格分辨的态度，强调两家在「本体」与「工夫」上的根本差异。本条目以「中庸」为名的跨体系表述，当在此张力中理解。另藏传中观学（自续、应成二派）对中道的中论式论证有庞大的注疏传统，其根本论典不在大正藏编号体系之内，应转检德格版《丹珠尔》编目。
