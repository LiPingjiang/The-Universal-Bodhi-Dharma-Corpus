# 阿毗达磨俱舍释论 — 学术解读

## 一、文献背景与成书

《阿毘達磨俱舍釋論》二十二卷，梵名 *Abhidharmakośa-bhāṣya*，是世亲（Vasubandhu）《俱舍论》长行释文的真谛译本，世称「旧俱舍」，今收于《大正藏》第二十九册（编号 T1559）。译者为陈·真谛（Paramārtha，499—569），西印度优禅尼国人，梁武帝时来华，陈天嘉四年（563）于广州制旨寺译出此论。真谛是南朝最重要的译经家，另译有《摄大乘论》《摄大乘论释》等，是摄论学派与旧译唯识学的奠基者。

「旧俱舍」之名是相对的：唐永徽二年（651）玄奘另译三十卷本（T1558），世称「新俱舍」。两本同出一梵本而译语、卷帙不同——真谛译本用语古朴，多存南朝译场的旧译名相（称「陰、入、界」而非玄奘的「蘊、處、界」）；奘译词义精严，后为法相宗基本教本，流通最广。旧俱舍在汉地流通虽不及奘译，但因保存了不同的译语与若干异读，在校勘梵本、考察世亲原意以及研究真谛一系思想上具有不可替代的文献价值。

## 二、文本结构与核心思想

本论内容与奘译本相同，依界、根、世间、业、惑（随眠）、圣道（贤圣）、智、定八品组织，末附〈破我品〉（通行称〈破说品〉一系名称与本档「破說我品」记录略有出入，兹依原文档），合为九品。全书以说一切有部教义为框架，而以「理长为宗」的批判态度广引经量部之说加以评破。

开篇归敬偈点出全论的立足点：顶礼那「于一切种灭诸冥闇、拔济众生出生死泥」的大师，然后方说阿毘达磨俱舍论。论名二字的解释见于卷一：无漏净慧及其随行名为「对法」（阿毘達磨），能得此净慧的诸慧论亦名对法；本论「摄彼胜义依彼故」，故立名「对法俱舍」——「俱舍」（kośa）即「藏」，谓摄藏对法胜义之库藏。

其思想性格的最好标本，是〈分别随眠品〉中世亲对有部「三世实有」说的处理：反复诘难之后，终以「法性甚深」四字作结——既已穷尽论难，仍不遽然断定旧说必不可立。这种「不拘成说、但凭理长」的批判理性，使《俱舍》成为部派佛教教理的集大成与批判性总结的双重纪念碑。

## 三、学术研究价值与争议

研究价值方面：（1）新旧二译并立为佛教翻译史上罕见的完整平行文本，真谛本所存旧译名相与异读，是校勘《俱舍》梵本、复原世亲原文的重要参照；（2）真谛译语受其摄论学立场浸润，将旧俱舍与《摄大乘论》系统对读，可观察旧译唯识学与说一切有部教理在译语层面的互动；（3）《俱舍》本身以有部框架收纳经量部批判，是研究四至五世纪部派佛教思想论争的第一线文本，旧译提供了与奘译不同的观察角度；（4）本档案原文的文献处理态度严谨——对真谛本开篇归敬偈的具体译词，明言因未获可靠原文影本待复核 CBETA 原文，以奘译对应颂文标义而不作臆造，这一如实注记本身就是文献学的示范。

争议与问题方面：（1）新译通行后旧译相对沉寂，历代注疏多依奘本，真谛本的底本是否与奘译所据梵本完全一致，学界有不同意见——印、日学者曾据称友梵疏与两种汉译对勘，发现若干真谛本存古、奘译改动的实例；（2）「法性甚深」一语显示世亲在有部立场与经量部批判之间的暧昧位置，其《俱舍》时期思想归属（有部异端抑或经量先驱）是长期争点；（3）真谛译文增补解释性文字的现象（所谓「译语带释」）如何影响文本原貌，涉及对陈代译场工作方式的整体评估。

| 旧俱舍 | 真谛译二十二卷本《阿毗达磨俱舍释论》的通称 |
| 新俱舍 | 玄奘译三十卷本《阿毗达磨俱舍论》的通称 |

| 说一切有部 | 以三世实有为宗的部派，本论的框架所在 |

- `00384_阿毗達磨俱舍論` — 同名系列条目，从奘译系统角度展开，与本篇旧译视角分工互注
- `00184_阿毗達磨順正理論` — 众贤造、有部对《俱舍》的反驳书，观察《俱舍》论争效力的后续

- `00208_真諦譯經羣` — 真谛译经总目，考察旧译者整体译语风格的语境
- `00142_攝大乘論` — 真谛另一核心译作，摄论学派所依，可比观其译经倾向
