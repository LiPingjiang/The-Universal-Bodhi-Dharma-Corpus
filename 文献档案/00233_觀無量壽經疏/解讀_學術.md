# 观无量寿经疏 — 学术解读

## 一、文献背景与成书

《观无量寿经疏》，全称《观无量寿佛经疏》，又称《观经四帖疏》，四卷，唐代善导（613—681）著，收于《大正藏》第三十七册（No. 1753）。善导早年诵习《法华》《维摩》，后见西方净土变相图而发心往生，又读《观无量寿经》大受触动，遂专修十六观。后入长安光明寺、实际寺弘传净土，抄《阿弥陀经》数万卷，画净土变相图三百余壁，被尊为中国净土宗的实际创立者。

据善导自序，本书是"楷定古今"之作——他在梦中感得圣教指授后写下此疏，意在纠正当时种种"错解"《观经》的注说。因每卷各立别名（玄义分、序分义、定善义、散善义），故俗称"四帖疏"。其风格上引经证、下斥异说，态度极为笃定，是净土宗文献中罕见地兼具注释体例与宗派宣言性质的著作。

## 二、文本结构与核心思想

四帖结构极有特色：第一"玄义分"先以七门料简总摄一经大义，再以著名的"三重六义"解释九品往生者皆是凡夫；第二"序分义"释证信序与发起序（韦提希被囚请法）；第三"定善义"释十六观中佛答的前十三观；第四"散善义"释三福九品。核心思想有三：

1. **十六观的体系化**。如原文所录："十六观者：日想、水想、地想、树想、池想、总观、华座、像观、佛真身观、观音观、势至观、普观、杂观、上辈生、中辈生、下辈生。如是十六，摄尽净土依正。"前十三观观依正庄严（定善），后三观明九品往生（散善），把"观想念佛"与"称名念佛"统一于一经之内。

2. **三心为往生正因**。原文所示"上品上生者，若有众生愿生彼国，发三种心——至诚心、深心、回向发愿心。具三心者，必生彼国"。至诚心是真实无伪，深心是深信机法（深信自身是罪恶生死凡夫、深信弥陀愿力不虚），回向发愿心是以一切功德回愿往生。三心说后被日本净土真宗发展为"信心正因"的理论核心。

3. **凡夫入报与弥陀本愿**。善导主张弥陀净土是报土，而"凡夫"凭佛愿力亦可往生报土——这正面推翻了当时诸师"凡夫只能生化土"之说；又将《无量寿经》第十八愿的"十念"明确为"下至十声口称名号"，确立称名为往生正行。

## 三、学术研究价值与争议

**研究价值**：本书是净土宗教学的原点，善导"五部九卷"（《观经疏》《法事赞》《观念法门》《往生礼赞》《般舟赞》）中地位最高者。其"九品皆凡"说、"凡夫入报土"论，是研究中国净土宗信仰主义（piétisme）特质的第一手文献，也深刻影响日本净土宗法然、净土真宗亲鸾的整个思想体系。

**代表学者**：塚本善隆《唐中期之净土教》对善导的教学与唐代净土教史有经典研究；望月信亨《中国净土教理史》梳理其教义源流；陈扬炯《中国净土宗通史》论述其在宗派创立中的地位；日本净土宗学界（如稻城选『善導大師の净土思想』等系列研究）更是以本书为宗义根据展开。

**争议问题**：其一，真伪问题——本书一度在中土失传，宋代以后由日本回流，故中土文献著录与文本流传的关系需仔细辨析；其二，"楷定古今"所针对的诸师（如净影慧远、吉藏、智顗的同经疏解）与善导的差异，涉及净土"报土／化土"之争的教理史重构；其三，善导强调"称名"与《观经》本身以"观想"为主的结构之间的张力——善导如何从一部观经读出称名易行，是学术研究的持续热点。

## 四、术语对照表

| 术语 | 释义 |
|------|------|
| 十六观 | 《观经》所说十六种观法：前十三观观净土依正庄严，后三观明九品往生 |
| 三心 | 至诚心、深心、回向发愿心，往生之正因 |
| 九品 | 上中下三辈各分三品，共九等往生者 |
| 报土 | 佛酬报因位愿行所感之净土，相对"化土"而言 |
| 定善／散善 | 入定修观为定善；散心修三福、称名为散善 |
| 楷定古今 | 善导自谓依圣僧指授判定古今诸师注解之是非 |
