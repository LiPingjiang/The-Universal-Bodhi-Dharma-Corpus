# 佛教工業心理學 · 原文

## 一、學科概述

工業心理學（industrial psychology）研究工作環境中的人類行為：人因工程、職業倦怠、工作動機、選拔與訓練。「佛教工業心理學」作為建制領域尚不存在，但作為研究方向已有清晰輪廓：一是職場正念干預的實證研究——2000年代起，學者將MBSR簡化為工作場所版本並檢驗其對倦怠、情緒耗竭與注意表現的效果；2011年，明尼蘇達大學的特蕾莎·格龍布與同事發表題為「工作場所的正念」的系統評述，整合人因、組織行為與神經科學證據，提出正念影響工作結果（績效、關係、幸福感）的心理機制模型，成為該方向的奠基文獻。二是佛教勞動觀的理論研究：八正道中的「正命」（恰當的謀生方式）為職業選擇與工作倫理提供了古典規範，而「工作即修行」的禪宗傳統（如百丈懷海「一日不作、一日不食」）則構成東亞職業倫理的重要源頭。

## 二、核心議題與佛教觀點

核心議題包括：（一）職業倦怠——長期情緒勞動導致的耗竭、去人格化與低成就感的流行病；對照研究顯示正念訓練降低倦怠量表得分，機制在於「去人格化」環節——把服務對象重新「如實看作人」；（二）人因與差錯——高風險行業（航空、醫療、核電）的安全績效取決於注意與情境覺察，正念訓練被引入醫療差錯防範研究（如麻醉師與外科團隊的正念研究）；（三）工作動機——自決理論區分內在與外在動機，佛教以「少欲」與「願力」（發心）區分匱乏驅動與意義驅動的工作狀態，與「使命召喚」研究相通；（四）工作時間與注意碎片化——「多任務」損害績效與幸福，佛教「一次一事」的修行原則即古典的單任務管理。《雜阿含經》對「正命」的定義是本領域最重要的經典依據。

> **經典依據**：
> 「何等為正命？謂如法求衣服、飲食、臥具、湯藥，非不如法。」——《雜阿含經》（T99）

正命即以正當、不傷害的方式謀取生活資具——這是佛教對「職業倫理」的綱領性定義：工作不僅是謀生，其方式本身即構成道德與心理後果，為現代「體面勞動」「倫理消費鏈」概念提供了古典原型。

## 三、代表學者與實踐

格龍布（明尼蘇達大學卡爾森管理學院）2011年的評述開闢了職場正念的學術議程，其後續現場實驗顯示工作中的正念片刻（如會議前的三分鐘呼吸空間）降低情緒耗竭與無禮行為。企業實踐方面，2012年《紐約時報》對通用磨坊公司正念項目的報導、健康保險巨頭安泰（Aetna）首席執行官馬克·貝托利尼在經歷重大車禍康復後引入正念與瑜伽課程並報告壓力指標下降與生產率提升，是常被引用的案例（記者戴維·格勒斯2015年《正念工作》一書系統記錄）。醫療系統內，梅奧診所等機構為醫護人員提供正念版「復原力」訓練以對抗倦怠；台灣部分醫院與科技公司亦引入禪修減壓課程。佛教內部，法鼓山「心五四」等職場心法則代表漢傳佛教對現代工作倫理的主動回應。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 職業倦怠 | 情緒耗竭、去人格化、低成就感的三維職業綜合征 |
| 人因工程 | 研究人—機—環境匹配以提升安全與效率的學科 |
| 正命 | 八正道之一，如法而不傷害的謀生方式 |
| 情緒勞動 | 工作要求下的情緒表達管理，倦怠的重要來源 |
| 單任務化 | 一次專注一事的工作組織原則 |
| 一日不作、一日不食 | 百丈清規，禪宗勞動即修道的制度表達 |
