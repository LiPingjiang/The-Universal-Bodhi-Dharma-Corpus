# 佛教信息學 · 原文

## 一、學科概述

佛教信息學（Buddhist Informatics）研究佛教文獻與知識的信息組織、編碼、檢索與管理，是圖書館學、信息科學與佛教研究交叉的領域。其核心對象包括：一、書目控制——從梁僧祐《出三藏記集》（中國最早的佛教目錄）、隋費長房《歷代三寶紀》到唐智昇《開元釋教錄》，古代經錄本身就是精密的信息組織系統，入藏標準、譯經真偽判別、卷帙編次構成傳統「佛教信息科學」；二、當代數據庫建設——中華電子佛典協會CBETA的全文檢索系統、法鼓山中華佛學研究所的「佛學規範資料庫」（收錄古今佛教人名、地名、年代規範檔案）、日本「國際佛教學大學院大學」的梵文寫本數據庫等；三、文本標記與元數據——CBETA以XML標記經文段落、校注與版本信息，與國際TEI標準對接，使佛典成為機器可讀、可分析的結構化信息。學界稱CBETA是「目前流通最廣、使用最多、貢獻最大的佛教典籍全文數據庫」，其文本分類、信息標注方式本身即為信息學研究對象（如王茜、辛睿龍以《廣弘明集》為例的XML標記研究）。

## 二、核心議題與佛教觀點

核心議題包括：一、經錄傳統與現代書目的對接——《開元釋教錄》的分類法（經律論、大小乘、一譯重譯）如何轉換為現代主題詞表與分類體系；二、規範控制——同一名相的異譯（「般若」/「智慧」、玄奘新譯與鳩摩羅什舊譯）、同一人物的名號（諡號、字號、俗名）需要權威檔案規範，法鼓「佛學術語知識庫」即為此設；三、全文檢索與知識檢索的差距——從字串匹配到概念檢索，需引入本體（ontology）與知識圖譜技術；四、信息組織的佛教觀——古代經錄以「判教」為分類的內在邏輯，信息架構本身承載世界觀，這提示當代佛教信息系統設計者：分類即詮釋。佛教立場認為，信息組織是「法藏」的護持方式，入藏與否、如何編次，古德皆極審慎，今日亦當以「慧命所繫」的態度對待數據質量。

> **經典依據**：
> 「此經此名，彼經彼名……名字品類，皆悉了知。」之意旨，參《大智度論》（T1509）釋「法無礙解」
>
> 「菩薩摩訶薩……於一句中通達無量義。」——《法華經》（T262）所示名句文身的信息結構觀

## 三、代表學者、著作與案例

僧祐《出三藏記集》（T2145）與智昇《開元釋教錄》（T2154）是佛教信息組織的古典巔峰，其「總經序」「譯經師傳記」實為最早的佛教文獻信息數據庫。當代方面，CBETA技術團隊（首任總幹事杜正民等）建立從掃描、錄入、校對到標記、發布的完整信息生產流程；法鼓文理學院圖書資訊館的「佛學數位資源整合」系統是佛教專業信息檢索的代表。北京大學楊浩（數字人文研究）、上海師範大學定源法師（佛教文獻與數據庫建設）在2023年中佛協研討會上分享古籍整理與數據庫案例。國際方面，美國「佛教數字資源中心」（BDRC，前身TBRC，由金·史密斯創立）收藏並數字化海量藏文文獻，是藏傳佛教信息學的樞紐機構。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 經錄 | 記載佛典譯撰、卷帙、真偽的佛教目錄 |
| 規範檔案 | 對人名地名等作唯一標識的權威數據 |
| XML標記 | 以結構化標籤編碼文本信息的語言 |
| 元數據 | 描述數據屬性的數據，如版本、譯者信息 |
| 入藏 | 佛典經審定編入大藏經的傳統程序 |
| BDRC | 佛教數字資源中心，藏文文獻數字樞紐 |
