# 唯识论 — 学术解读

## 一、文献背景与成书

《唯识论》（即世亲《唯识二十论》，Viṃśatikā）为世亲（Vasubandhu）所造，约成书于5世纪，是世亲唯识学的两大论颂之一（另一为《唯识三十颂》）。本目的汉译史颇为特殊：《唯识二十论》有两个古代汉译——菩提流支译本，题作《大乘楞伽经唯识论》（一名《破色心论》）；玄奘另译《唯识二十论》（T1590）。本档案所收即菩提流支译系统的《唯识论》（T1589），与《楞伽经》"三界唯心"的教证直接挂钩。此外真谛亦译有《大乘唯识论》。三部古译加上奘译，使本论成为汉地"唯识新旧译对照"的经典案例。

世亲造此论的目的，是为"唯识无境"这一核心命题进行辩护性论证——不正面铺陈唯识体系（那是《三十颂》的任务），而是集中回应"如果没有外境，常识经验如何解释"的诘难。

## 二、文本结构与核心思想

本论宗旨在立"唯识无境"：三界所有，唯是心识所现，无有外境——"三界唯心"，所现似外之境实是识之所变，离识无有少法可得。

论的主体采取**自设四难、自作四答**的结构。论主预想论敌的诘难：若无外境，以下四事不应成立——（1）**处定**（为何所见物有确定的空间位置）；（2）**时定**（为何大家同一时间都能见到）；（3）**相续不定**（为何众人所见彼此一致）；（4）**作用不成**（若无实境，为何实物有实际作用，如梦中物不能充饥）。世亲逐一作答：**梦中亦有处定、时定，而无实境**——由此可知处时决定不足以证外境实有；众人共见的境界可如"地狱"喻——狱卒等共相所见之境，是诸有情共业所感、各识所变，非心外实有；作用之别则由"境"与"实"的差异解释。四答之后，更引《十地经》"三界唯心"等圣教量为证。

## 三、学术研究价值与争议

研究价值方面：（1）本论是印度哲学"实在论vs观念论"之争的佛教经典文本，其"梦喻"论证（梦中有处时决定而无实境）与现代哲学中关于幻觉、虚拟经验的讨论直接可通，故被比较哲学界频繁征引；（2）"四难四答"的问答体保留了古代印度论辩的实战样貌，是研究论辩术与哲学论证互动的样本；（3）菩提流支译、真谛译、玄奘译三个系统的异文，为翻译史与唯识学新旧译差异研究（如真谛系统的"阿摩罗识"因素、译语系统的演变）提供材料。西藏另有日慧等注释传统的传承。

争议问题包括：（1）"共相所见"的解释力——共业所感之说是否构成对"相续不定"难点的充分回答，历来有讨论；（2）新旧译本的义理差异——菩提流支译掺入地论学派的术语背景，与奘译的严格唯识今学表述之间，何者更接近世亲原义，学界以梵本与藏译为参照持续研究；（3）本论"识"的实在性承诺——唯识无境是否意味着"识是唯一实在"，与本论姊妹篇《三十颂》的诠释（尤其安慧与护法的分歧）相关联。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 唯识无境 | 境相由识变现、离心无境的核心命题 |
| 三界唯心 | 《十地经》等所出的唯识圣教量 |
| 处定/时定 | 境界空间/时间上的确定性 |
| 相续不定 | 众多心识各自变现的难题 |
| 梦喻（svapna） | 以梦证成"有相无境"的关键比喻 |
| 地狱喻 | 共业所感、共见非实的经典例子 |
