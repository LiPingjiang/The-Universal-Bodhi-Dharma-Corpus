# 掌中论 — 学术解读

## 一、文献背景与成书

《掌中论》（Hastavālaprakaraṇa）为陈那（Dignāga，约480-540年）所造，约成书于5世纪，是陈那唯识论证系列中最简洁的代表作。汉译本为义净于7世纪（约景龙年间赴印归来后）译出，收于大正藏（T1620），一卷，附有陈那自注性质的简释。藏译亦有传本。书名梵语 Hastavāla（或作 hastavālaprakaraṇa），意为"如掌中之物"——一掌可握、一览无遗，宣示其"极简"的自负：把"诸法无自性、唯假施设"的大道理压缩到掌心大小的篇幅中。

本论与《观所缘缘论》同属陈那唯识阶段的论证著作，但风格不同：《观所缘缘论》以认识论标准破外境实有，《掌中论》则以"绳蛇之喻"层层解析的方式遣除"实有"之执，更接近中观的分析风格。

## 二、文本结构与核心思想

本论主旨在破"实有"之执，论证采取层层遣除的三段结构：

**第一层，遣遍计所执**：以绳蛇之喻明能遍计所执之无体——黄昏见绳谓蛇，蛇本无有，唯是妄计。此喻中，蛇喻遍计所执（纯虚的增益），绳喻依他起（真实存在的因缘现象）。

**第二层，遣依他起之实执**：复析绳为麻缕，则"绳"相亦泯——绳子本身也不过是麻缕的假合，"绳"这个相状同样不可得。以此类推，一切名相层层分析，皆无实体可得。

**第三层，能所俱遣**：层析至无可析处，则知所谓"实体"者不过名言施设；名言既遣，自性亦不可得——一切法无自性、唯假施设。

**绳蛇喻的三层对应**：蛇喻遍计所执、绳喻依他起、麻缕喻析之则相泯——喻显一切名相皆假立。这一比喻后来成为唯识与中观共同沿用的经典意象，其"层层剥析"的方法则被视为把龙树式分析（如《中论》析五蕴、析因果）移植到唯识三性框架的尝试。

## 三、学术研究价值与争议

研究价值方面，本论是考察陈那思想中唯识与因明两个面向如何互动的便利文本：绳蛇喻的三性对应显示陈那深受《辨中边论》等弥勒学文献影响，而其分析手法又承龙树。义净在译本附记中对本论的推崇，使其成为汉传因明知识谱系的一环。现代研究多将本论与《观所缘缘论》《取因假设论》等陈那短论合并讨论，以重建陈那"唯识论证时期"的思想面貌（参照 Frauwallner 对陈那著作的三期划分说）。

争议问题包括：（1）本论立场归属——它究竟是唯识论书（以三性解空）还是已具中观化倾向（"名言既遣、自性不可得"的表述亦可作中观读解），学界有不同判读，藏传文献中本论亦被量论传统与中观传统分别征引；（2）绳蛇喻中"麻"的终极地位——麻是否最终也被遣除（"麻亦复如蛇"的无限回溯问题），涉及本论是否主张彻底的"一切假立"；（3）作者问题——除陈那造的主流记载外，个别文献对论主有异说，文本流传中的注释归属亦有讨论。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 绳蛇喻（rajju-sarpa） | 误绳为蛇的经典比喻，三性分析的核心意象 |
| 遍计所执（parikalpita） | 虚妄增益的执著之相（蛇） |
| 依他起（paratantra） | 依因缘而现的现象（绳） |
| 假施设（prajñapti） | 名言安立，非实体存在 |
| 无自性（niḥsvabhāva） | 无独立不变的自体 |
| 能所俱遣 | 主客二元的框架一并放下 |
