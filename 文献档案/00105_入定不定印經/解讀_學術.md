## 一、文献背景与成书

《入定不定印经》（梵 *Anunayana-niyāma-avatāra-mudrā* 之意译，直译「顺决定印」），大正藏编号 T646，一卷，唐三藏义净于久视元年（700）奉制译出，译场为洛阳大福先寺翻译院。武则天为此经亲撰《大周新翻三藏圣教序》，冠于经首，并概述其要义为「此明退不退之心，前二后三，虽有迟速，如来设教，同趣菩提」——皇帝御制经序在本经传译史上是极罕见的殊荣，也使本经成为武周官方佛教的直接见证。

本经另有隋代阇那崛多所译《入定不定印经》前身（《发觉净心经》，T827）为异译，属同一梵本的先后两译。经文成立约在公元 5-7 世纪的印度，主题为菩萨修行的「退转与不退转」（vaivartya / avaivartikatā）判定问题。

## 二、文本结构与核心思想

### 2.1 问题意识：哪些菩萨会退转？

经首，妙吉祥菩萨（文殊师利）白佛言：「云何二不定菩萨为求无上正等正觉，于无上智道而有退转？云何三决定菩萨为求无上正等正觉，于无上智道而不退转？」——将发心菩萨分为「二不定」（有退）与「三决定」（不退）两类，此即经题「定印／不定印」之所在：修行者尚未获得「决定」（niyāma）之印可前，皆在可退之数。

### 2.2 五种行：退与不退的分型学

佛以五种「行」（修行方式）回答：一羊车行、二象车行、三日月神力行、四声闻神力行、五如来神力行。前二种「有退，名不定」，后三种「不退，名决定」。其喻极为形象：欲过五佛刹微尘数世界的远行者，若乘羊车，「行百由旬，忽为大风所吹退八十由旬」——以羊车之缓弱，欲渡无边刹土，「若能过者，无有是处」。象车稍胜而仍可退；日月神力、声闻神力、如来神力三行则疾进不退。

### 2.3 退转的原因：退大向小

经文明示退转的典型因缘：或有菩萨先发大菩提心已，后于大乘法中「不持不诵」，反而于声闻法中「爱乐修习同其称赞，受持读诵解释其义，复令他人持习解了」，由是因缘「智慧钝劣」。即：退转并非戏剧性的信仰崩塌，而是注意力的悄然移转——大心已发，日常的熏习却渐渐转向小果自了之法。这一诊断对菩萨道「发心—长养—不退」的修行心理学有精准的刻画，武则天序所谓「退不退之心」正指此。

### 2.4 「同趣菩提」的会通

御制序点出本经的归结：「前二后三，虽有迟速，如来设教，同趣菩提。」——五乘迟速有别，而如来设教终归一致，与《法华》会三归一的立场遥相呼应，也框定了本经「判而不废」的开放结构。

## 三、学术研究价值与争议

**翻译史价值**：本经是义净译经（侧重律部）中少数的义理类经典，且附武则天御序，是研究武周政教关系、官方译场制度（大福先寺翻译院）运作的一手材料。义净译语（如「薄伽梵」「苾刍」等新译规范）在此经中亦有体现，可与其《南海寄归内法传》所载翻译理念互证。

**菩萨道思想史价值**：「不退转」（avaivartika）是般若经系以来的核心范畴，本经以「五车喻」将抽象的位次判定转化为修行方式的分型，是研究大乘修行位阶学说（退/不退、决定/不定）流变的专门文献；其「退大向小」的病理分析，也为理解中国佛教史上大乘小乘之争的实际心理机制提供了经证。

**文本对勘**：本经与阇那崛多旧译《发觉净心经》（T827）的对照，是隋唐两代译语变迁研究的合适样本。

|---|---|
| 定印／决定（niyāma） | 已入不退之位、决定成就的印证 |
| 不定印（aniyāma） | 修行未决定、仍有退转之虞的位次 |
| 五种行 | 羊车、象车、日月神力、声闻神力、如来神力，前二有退后三不退 |
| 不退转（avaivartika） | 于无上菩提不再退失 |
| 退大向小 | 发大乘心后熏习转趋小乘而致退转 |
| 义净 | 唐译经三藏，与罗什、真谛、玄奘并称四大译经家 |
