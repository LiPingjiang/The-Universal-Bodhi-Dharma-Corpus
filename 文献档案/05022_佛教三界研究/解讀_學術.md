# 佛教三界研究 — 学术解读

## 一、文献背景与成书

需先如实说明：本目录的原文档为简目式材料，仅列「欲界、色界、无色界」三目及两段概括性引文（含「三界无安，犹如火宅」的综述句，其意象本于《法华经·譬喻品》火宅喻），未标注经卷出处。本篇按综述性条目体例，就可考的学术背景撰文。

三界（梵语 triloka / traidhātuka）说是佛教宇宙论的骨架，于阿含经中已成定型，《长阿含·世记经》（T1）等有系统叙述；论典以《俱舍论·分别世间品》（T1558）所述最详，《大智度论》（T1509）、《瑜伽师地论》（T1579）各有阐发。三界的内容：欲界含地狱、饿鬼、畜生、人、阿修罗及六欲天；色界含初禅至四禅诸天（汉传通计十八天）；无色界含空无边处、识无边处、无所有处、非想非非想处四天。此体系与婆罗门教宇宙论（如《奥义书》的三界说）有交涉又有改造，佛教特以「业感缘起」说明三界的成因——三界不是神的创造，而是众生共业所感的果报居所。

## 二、文本结构与核心思想

三界的结构可从纵横两面看。纵的层级：欲界以饮食男女之欲为特征，色界离欲而尚有净妙色身（依禅定层级分四禅天），无色界离色而唯余四蕴（受想行识）的心识住著，依四空定而分。横的成因：众生依欲惑居欲界，依四禅居色界，依四空定居无色界——禅定境界与投生处所一一对应，宇宙结构即是心理状态的投射图，这是三界说最具特色的「心物同构」原理。

核心思想有三：其一，「三界无安，犹如火宅」——三界虽有苦乐层级之别，其性皆苦、皆无常，生天非究竟，故佛教以「出三界」为解脱的同义语；其二，「三界唯心」——《华严经》「若人欲了知，三世一切佛，应观法界性，一切唯心造」将三界收归一心，为如来藏与唯识学的共同纲领；其三，三界说的伦理功能——六欲天、四禅天的安立使「天」纳入业果法则之内，天亦有死、亦须出离，破除了以生天为终极的印度宗教通见。

## 三、学术研究价值与争议

三界研究的学术价值：第一，它是比较宗教学的重要题材——佛教三界与婆罗门教、耆那教宇宙论的异同，可据以考察印度宗教史的竞争与互动；第二，「禅定层级—天界层级」的对应关系是研究印度禅学史的独特材料，四禅八定如何被宇宙论化，线索俱在；第三，汉传佛教对三界的本土化诠释（如道教三十三天与佛教三界说的交涉）是宗教交流史的个案。

争议点：三界诸天名数各经所列不一（色界天或作十六、十七、十八），部派间有净居天是否别立等诤论；「中有」是否三界所摄之有部与大众部之争；以及近代以来佛教宇宙论与科学宇宙观的调适问题（印顺、太虚等均有论列）。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 三界（triloka） | 欲界、色界、无色界之总称 |
| 欲界（kāmadhātu） | 具饮食淫欲之众生居所，含六欲天 |
| 色界（rūpadhātu） | 离欲而具净色身之四禅天 |
| 无色界（ārūpyadhātu） | 离色唯心识之四空处天 |
| 六欲天 | 四天王天至他化自在天之六天 |
| 四禅 | 色界四层级之根本禅定 |
| 三界唯心 | 《华严经》三界不离一心之纲领 |
| 火宅喻 | 《法华经》喻三界危苦之著名譬喻 |
