# 噶舉派創古仁波切文集 · 原文

## 一、文獻概述

本檔彙集噶瑪噶舉傳承主要上師——堪千創古仁波切（Khenchen Thrangu Rinpoche，1933–2023）之著作與講授文集。創古仁波切出生於西藏康區，由第十六世大寶法王讓炯日佩多傑認證為創古寺第九世創古祖古，於西藏圓滿佛學教育後流亡印度、尼泊爾，曾任第十六世大寶法王駐錫之錫金隆德寺那爛陀高級佛學院院長，為噶舉傳授堪布學位之重要師長；並先後擔任第十七世大寶法王鄔金欽列多傑之親教師，是噶瑪噶舉公認的「學者型上師」代表。仁波切在尼泊爾重建南無布達（Namo Buddha）創古寺，設立佛學院、閉關中心與创古文化（Thrangu Dharmakara）出版機構，弘法足跡遍佈亞洲、歐美各地，並在世界多地從事慈善教育事業。據噶舉傳承之訃告，仁波切於2023年6月4日（藏曆氏宿月十五，薩嘎月佛陀誕生、成道、涅槃日）示寂於尼泊爾南無布達創古寺。

其著作特點，如傳承訃告所評：「以一種非常溫和又便於理解的方式，闡述了複雜的佛法主題，無論是對於佛學初學者，還是最資深的行者，都因之受益。」其文集漢譯多由創古文化等機構出版，代表著作如下表：

| 代表著作 | 內容要點 |
|---|---|
| 《轉心四思維》（四共加行講解） | 人身難得、死亡無常、輪迴過患、業果不虛之基礎前行教授 |
| 《佛性》 | 依彌勒菩薩《究竟一乘論》（《寶性論》）闡釋一切眾生皆具佛性 |
| 《止觀禪修》 | 依傳統次第講授奢摩他（止）與毗婆舍那（觀）之修法 |
| 《直指法身》等大手印系列 | 噶瑪噶舉不共之大手印引導教授 |
| 《月燈》等經典講記 | 對《月燈三昧經》等經之現代講授 |
| 中觀、唯識教義講錄 | 融通噶瑪噶舉他空／中觀見之教理著述 |

## 二、核心段落選錄

> **原文**：創古仁波切《轉心四思維》所闡之前行綱領，即噶舉派四共加行：「（思維）暇滿人身難得、死亡無常、輪迴過患、業果不虛。」此四者為一切修行之基礎，岡波巴大師「四法」云：「願心趨法，願法循道，願道斷惑，願惑顯智。」（四法頌為噶舉共同傳承之教授，依通行漢譯）
> **白話對照**：修行之先，必須反覆思維四件事：獲得具足修行條件的人身極為難得；死亡隨時可能到來；輪迴本性是苦；善惡業果真實不虛。由此轉心向法。岡波巴四法之意則是：願心轉向佛法，願佛法趨入正道，願正道斷除迷惑，願迷惑轉為智慧——正是「轉心四思維」所要達成的結果。

> **原文**：據《究竟一乘寶性論》所傳、創古仁波切《佛性》一書所闡之根本義：一切眾生皆有如來藏（佛性），如貧家地底伏藏，本自具足，客塵煩惱所覆而不能見；修道即是顯發本具，非新得。
> **白話對照**：每一個眾生心中本來就具足佛的功德，就像貧窮人家的地底下埋著寶藏，只是被泥土（煩惱）覆蓋看不見。修行不是從外面獲得什麼新東西，而是把覆蓋的煩惱清除，讓本來具足的佛性顯露出來。

> **原文**：據噶舉傳承訃告所記，仁波切一生之弘法風格：「以一種完整、真實又絕對慈悲的方式，全面地開示了噶瑪噶舉的見地。」（2023年噶瑪噶舉傳承訃文）
> **白話對照**：創古仁波切以完整的學統、真實的修證與無條件的慈悲，把噶瑪噶舉傳承的見地毫無保留地傳授給各地弟子。

## 三、重要名句

> **名句一**：「人身難得，佛法難聞」——四共加行之首，仁波切所有前行教授之起點。

> **名句二**：岡波巴四法「願心趨法，願法循道，願道斷惑，願惑顯智」——噶舉傳承之總綱，仁波切於諸講錄中反覆闡釋。

> **名句三**：「佛性本具，修道為顯」——依《寶性論》所闡：覺悟是本有之功德的顯發，而非製造。

> **名句四**：「止為基礎，觀為慧照」——仁波切禪修教授一貫強調：先以奢摩他成就穩定，再以毗婆舍那生起觀慧。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 噶瑪噶舉 | 噶舉四大八小傳承之首，以噶瑪巴（大寶法王）為依怙 |
| 堪千 | 「大堪布」之尊稱，指佛學院最高學位之師長 |
| 四共加行 | 暇滿難得、死亡無常、輪迴過患、業果不虛之共通行持基礎 |
| 大手印 | 噶舉不共之心性法門，直指心之本性 |
| 奢摩他／毗婆舍那 | 止／觀；禪定之穩定與觀照之智慧 |
| 佛性（如來藏） | 一切眾生本具之成佛因性 |
| 祖古 | 轉世修行者之藏語稱謂，漢地俗稱「活佛」 |
| 前行 | 正行之前之基礎修法，含四共加行與四不共加行 |
