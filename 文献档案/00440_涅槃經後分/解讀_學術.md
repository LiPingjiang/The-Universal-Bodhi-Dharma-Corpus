# 涅槃經後分 — 学术解读

## 一、文献背景与成书

《大般涅槃经后分》收于《大正新修大藏经》T377，二卷。传统经录题为南海波陵国（亦作诃陵）沙门若那跋陀罗，唐僧会宁参与译出。麟德年间（664—665），会宁西行求法途经波陵，与若那跋陀罗合作翻译；经本经交州在仪凤年间传至长安。它又称《大般涅槃经荼毗分》或《阇维分》，题名中的“后分”指其被视为大本《大般涅槃经》的后续叙事，而不是大本自然保存下来的最后两卷。

T377分为“憍陈如品余”“遗教品”“应尽还源品”“机感荼毗品”“圣躯廓润品”四品半，叙述须跋陀罗最后得度、佛陀遗教、入灭、荼毗和舍利事。它传入后既可单行，又常被接在昙无谶译《大般涅槃经》之后，编作第四十一、四十二卷，所以在寺院读诵与后世经目中经常被当作“大本”的结尾。敦煌写本与汉地刻藏保存了这种合部、单行并存的流传形态；藏文大藏经亦将其附于涅槃经末，但该藏译与汉译传承密切相关。

版本判断还须注意，所谓“北本四十卷加后分二卷”与慧严、慧观等整理的南本三十六卷属于不同编藏系统。后分题作“憍陈如品余”，恰好为其接续大本提供形式依据，却不能单凭品名证明印度原本本来相连。历代藏经的卷次、品题和序跋因此既保存资料，也参与塑造了“完整涅槃经”的观念。

## 二、文本结构与核心思想

首段以须跋陀罗闻法、舍邪归正并证阿罗汉果开场，形成“最后得度者”的叙事高潮。随后的遗教并非抽象论述佛性，而是将佛将入灭所触发的悲恸、嘱累和修行秩序放在具体人际情境中。经中又以“应尽还源”提示佛陀示现入灭的意义：对弟子而言，重要的不是无限延长对师长肉身的依赖，而是使教法和修行成为可承继的依止。

后两品集中描写拘尸城民众、天人与弟子如何为佛荼毗、供养和分布舍利。荼毗不是单纯的丧葬手续：一方面，金棺、香花、佛塔等叙事塑造了佛教供养与圣迹崇敬的仪式语言；另一方面，经文不断呈现哀痛与无常，使舍利崇敬不应脱离对法义的记忆。与以佛性、常乐我净为重点的昙无谶大本相比，T377的重心更接近佛传末尾和遗体处置的叙事传统。

## 三、学术研究价值与争议

此经对研究佛灭叙事如何在南海、交州与长安之间传播尤具价值。若那跋陀罗与会宁的合作说明，唐初汉译佛典的形成不只发生在中原大型译场，也经过海上航线和跨区域僧侣网络。它与《长阿含经·游行经》等佛陀入灭叙事可相互比较，能帮助辨认早期佛传母题在大乘语境中的改写。

其身份问题长期有争论。义净曾认为它与阿含系统的涅槃叙事相近，和昙无谶本大乘《涅槃经》“颇不相涉”；《开元释教录》则依据“憍陈如品余”题名及常乐我净等语，认为其与大本义理、文势相接。又有研究注意到它与《居士请僧经》等疑伪材料的篇章对应，因此对梵本来源、汉地增饰及归入大本的过程持审慎态度。现有证据不足以简单断为伪经或完整原典；更合适的做法是区分其唐代译传的历史事实、文本内容的多重来源，以及后世合部造成的阅读效果。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 后分 | 被接续在大本《大般涅槃经》之后流通的两卷文本。 |
| 荼毗 | 梵语音译，意为焚烧遗体、火化，亦写作阇维。 |
| 舍利 | 佛陀或圣者遗骨、遗身；在本经中与供养、建塔相连。 |
| 须跋陀罗 | 经中佛陀临入灭前最后受度并出家的外道老人。 |
| 应尽还源 | 以示现入灭说明应尽之化缘已毕、归于本源的表达。 |
