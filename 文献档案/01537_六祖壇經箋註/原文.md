# 六祖壇經箋註 · 原文

## 一、文獻概述

《六祖壇經箋注》，民國丁福保（1874–1952，字仲祜，號疇隱）撰，為近代《壇經》注釋之集大成之作。丁福保為著名佛教居士、藏書家，學通經史，兼擅算學、醫學、日文，中歸心佛教後以十年之功編成中國第一部新式大型佛學辭典《佛學大辭典》。他有感於佛典文字艱澀、古人注疏多重判科談玄、初學難以領會，遂選擇卷帙較少之要典，仿漢儒訓詁之法逐字逐句解釋，詳略適中，名之曰「箋注」，《六祖壇經箋注》即其代表。

所箋之《六祖大師法寶壇經》，禪宗六祖惠能（638–713）說、弟子法海集錄，為中國僧人著述中唯一被尊稱為「經」者，中心思想為「見性成佛」。丁氏箋注以通行宗寶本為底本，依行由、般若、疑問、定慧、坐禪、懺悔、機緣、頓漸、護法、付囑十品展開，「字字考其來歷，句句求其證據」，廣採古今注釋與經典文獻為證；卷首有自序、後序及「箋經雜記」十四則，卷末附王維、柳宗元、劉禹錫所撰六祖碑銘及歷朝崇奉事跡。1928年黃茂林即依此箋注本開始將《壇經》譯為英文，1930年出版，是《壇經》走向世界之重要媒介。當代學者陳兵評此書為《壇經》注本中「內容最為豐富、徵引最為廣泛、解說相當全面、理解較為可靠的一種」。今有齊魯書社（2012）等簡體整理本。

## 二、核心段落選錄

> **原文**：丁氏箋注自序云：「夫所謂禪宗者，非六度中第五度之坐禪，乃第六度之般若波羅蜜也。六祖示不識文字相，故平生無著作。惟法海紀述其說法之語，名曰《法寶壇經》。」（《六祖壇經箋注》序）
> **白話對照**：丁福保指出：禪宗之「禪」，並非六度中第五度的禪定坐禪，而是第六度的般若波羅蜜（究竟智慧）。六祖示現不執著文字之相，所以平生沒有親筆著作，只有弟子法海記述他說法的語錄，名為《法寶壇經》。

> **原文**：《壇經·行由品》：「何期自性，本自清淨；何期自性，本不生滅；何期自性，本自具足；何期自性，本無動搖；何期自性，能生萬法。」（丁氏逐句箋注，考「自性」即佛性、真如之異名）
> **白話對照**：惠能大徹大悟時感歎：想不到自性本來就是清淨的；本來就不生不滅；本來就圓滿具足一切；本來就沒有動搖變壞；而且能夠生起宇宙萬法。丁福保於箋注中以《易·繫辭》「寂然不動」、《中庸》「天命之謂性」等儒典與之會通，認為壇經與孔孟莊氏之書多有相通。

> **原文**：《壇經·定慧品》：「我此法門，從上以來，先立無念為宗，無相為體，無住為本。」
> **白話對照**：我這個法門，從歷代祖師以來，首先確立：以「無念」為宗旨，以「無相」為本體，以「無住」為根本。即不為外境所牽而起妄念、不執著於一切相、心念念念不住著於任何一處——此即禪門著名的「三無」法門。

## 三、重要名句

> **名句一**：「字字考其來歷，句句求其證據」——丁氏箋注之治學標準，使其注成為近代佛教訓詁式箋注之典範。

> **名句二**：「中國佛教著作被尊稱為『經』的，僅此一部」——此為壇經在中國佛教史上的獨特地位，丁氏於雜記中亦詳論「稱經者，後人尊其法耳」。

> **名句三**：「見性成佛」——《壇經》中心思想，與《涅槃經》「一切眾生悉有佛性」一脈相承。

> **名句四**：「定慧一體，不是二」——定與慧如燈與光，體用不二，為丁氏箋注重點闡發之南宗禪要義。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 箋注 | 仿漢儒訓詁之注釋體，逐字逐句考證解釋，不用繁瑣科文 |
| 自性 | 眾生本具之佛性、真如；壇經中「佛性、實性、本心、本來面目」皆其異名 |
| 無念 | 於念而不念，心不染著於境，非百物不思 |
| 頓悟 | 不假漸次階位，直下明心見性；南宗宗旨 |
| 一行三昧 | 於一切處行住坐臥常行直心之三昧 |
| 般若波羅蜜 | 六度之第六「究竟智慧」，丁氏界定禪宗之核心 |
| 箋經雜記 | 丁氏箋注卷首所附考證雜記十四則 |
| 宗寶本 | 元代宗寶改編之《壇經》流通本，分十品 |
