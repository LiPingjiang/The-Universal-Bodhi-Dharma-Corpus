# 發趣論 — 学术解读

## 一、文献背景与成书

《發趣論》（Paṭṭhāna-ppakaraṇa），巴利原名「发趣大论」（Paṭṭhāna-mahāpakaraṇa），为巴利论藏七论中最后、最庞大者，素有「论王」之称。属巴利语论藏文献，不在大正藏编号体系之内；现存巴利原文，日译收入《南传大藏经》第五十至五十六卷，本目录原文档所录段落标注为玛欣德尊者的现代汉译。

本论详述「论本母」（mātikā）一百二十二门与二十四缘（paccaya）之间的条件关系，构成南传上座部缘起理论的核心框架。七论之中发趣论成立最晚，学界一般视为阿毗达磨发展的顶点：由《法集论》的分类、《分别论》的分别，到本论的「关系网」。相传佛陀思惟此论时身放光明——传说的夸张正反映其地位：二十四缘可从各种角度穷尽分析一切法的种种可能性。

## 二、文本结构与核心思想

全论分论母设置分与缘分别分两大部分，核心为二十四缘与二十四发趣。

**二十四缘**（原文档所录）：因缘、所缘缘、增上缘、无间缘、等无间缘、俱生缘、相互缘、依止缘、亲依止缘、前生缘、后生缘、重复缘、业缘、异熟缘、食缘、根缘、禅那缘、道缘、相应缘、不相应缘、有缘、无有缘、离去缘、不离去缘。前数缘大致可与北传说一切有部的四缘、六因体系对读，而后面的缘目为南传独有的精细展开。

**二十四发趣的组织法**：顺发趣、逆发趣、顺逆发趣、逆顺发趣四种——即正面、反面、正反合、反正合四个推理方向；每种再开展三法发趣、二法发趣、二法三法发趣、三法二法发趣、三法三法发趣、二法二法发趣六种，合为二十四发趣。论本母一百二十二门与二十四缘被逐一枚举配对。

**缘广释示例**：如所缘缘——「色處對眼識界及其相應諸法以所緣緣為緣……一切諸法對意識界及其相應諸法以所緣緣為緣」；增上缘分欲、精进、心、观四类。这种「A对B以C缘为缘」的三元句式，构成一部庞大的条件关系数据库。

## 三、学术研究价值与争议

研究价值：本论是人类思想史上罕见的「关系本体论」文本——它不问「有什么东西」，而问「东西之间有多少种联结方式」；二十四缘与《舍利弗阿毗曇論》的北传十缘说对勘，可重构部派分流前缘起解释的演化路线；缅甸传统以精通发趣为通达佛法的标志，其背诵与论议实践至今存活，是活的学术传统。

争议问题：其一，二十四缘的分类学依据——有学者认为离去缘与不离去缘等存在定义上的冗余，其完备性存疑；其二，如此机械的穷举是禅修经验的记录还是经院演算的产物，南传内部与学界均有讨论；其三，本论与《攝阿毗達磨義論》缘分别品的关系（后者为其纲要化），显示文本的层累加工。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 发趣（Paṭṭhāna） | 诸法缘力关系的建立与穷尽分析 |
| 缘（paccaya） | 使他法得以生起、存续的条件 |
| 因缘／所缘缘 | 根本条件／对象条件 |
| 无间缘／等无间缘 | 前心灭无间隔地令后心生起的条件 |
| 俱生缘／相互缘 | 同时生起互为条件／互相支持为条件 |
| 论本母（mātikā） | 一百二十二门法数纲目 |
