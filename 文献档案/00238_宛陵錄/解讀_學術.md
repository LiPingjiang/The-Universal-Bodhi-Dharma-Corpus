# 宛陵录 — 学术解读

## 一、文献背景与成书

《宛陵录》，一卷，唐代黄檗希运禅师语录，裴休集录，与《传心法要》同帙流传，收于《大正藏》第四十八册（No. 2012）。二录的区别在于结集地点：裴休任洪州刺史时于钟陵（南昌）所录为《传心法要》；其后裴休移镇宛陵（今安徽宣城），延请黄檗至开元寺说法，所录即《宛陵录》。因地名宛陵，故有此题。

就性质而言，二录同源而各有侧重：《传心法要》篇幅精简，多示法要义；《宛陵录》篇幅稍长，多出机锋问答与修持细节，尤其集中讨论"无心功夫"如何在日常中操作的问题，如原文所录："无心功夫者，但于日用中，行住坐卧，一切时中，不生分别。心如虚空，不存一物。"

## 二、文本结构与核心思想

《宛陵录》同为语录体，其义理可归纳为三点：

1. **无心功夫的日用化**。黄檗反复申明：无心不在蒲团上，而在"行住坐卧一切时中"。这是洪州禅"平常心是道"传统在黄檗处的深化——修行不是另设一个特殊时段，而是日常用心方式的彻底转变。"若有取舍，即非无心"，连"我要修无心"这一念本身也是取舍。

2. **心境双忘的层次论**。名句所云："凡夫取境，道人取心。心境双忘，乃是真法。忘境犹易，忘心至难。人不敢忘心，恐落空亡。不知心本空，不须忘也。"这是全录最精密的分析：凡夫被外境牵着走（取境），修行人初步学会收心（取心），但执著"能观之心"仍是病；真正的目标是心境俱遣。而最后一步最险——人们怕"忘心"落入空无，黄檗点破：心本来就是空的，"不须忘也"，无可忘者，才是真忘。

3. **无求无着的成佛观**。"学道人若欲得成佛，一切佛法总不用学，唯学无求无着。无求即心不生，无着即心不灭。不生不灭，即是佛。"把浩瀚佛法归结为"无求（不生）＋无着（不灭）"两门功夫，与《传心法要》"唯传一心"之说首尾呼应，而更加可操作化。

## 三、学术研究价值与争议

**研究价值**：《宛陵录》与《传心法要》共同构成黄檗禅的完整文献，而本录的特殊价值在于保存了大量关于修行次第与心理细节的讨论（如"忘境易、忘心难"的层次分析），是研究唐代禅法"功夫论"（修行技术层面）的珍贵材料。其"心本空，不须忘"的辨析，触及禅宗心性论与般若空观衔接处的核心问题，历来为义学僧侣与学者所重。

**代表学者**：铃木大拙的英译《The Zen Teaching of Huang-Po》将本录与《传心法要》一并介绍给西方，其中"忘心"一段是其解说重点；忽滑谷快天《中国禅学思想史》以本录论黄檗"无心"之旨；印顺《中国禅宗史》则将其置于洪州禅"触类是道"的谱系中理解；日本入矢义高主持的唐代语录译注系列对本录的白话训读，是文本精细研究的代表。

**争议问题**：其一，二录的边界与重出——传本中《传心法要》与《宛陵录》部分内容互有出入，何为裴休两次集录的原貌，需写本层面的比勘；其二，"忘心"与后世禅宗"无事""休歇"等功夫语的谱系关系——黄檗是否为宋代"默照"类型禅法的远源之一，学界有讨论；其三，黄檗语录中"心如虚空"之类的表述与如来藏系文献的关系，是"本有真心"还是"缘起性空"义，诠释立场不同结论亦异。

## 四、术语对照表

| 术语 | 释义 |
|------|------|
| 无心 | 于日用一切时中不生分别取舍的心行状态 |
| 取境／取心 | 执著外境／执著能观之心，前者凡夫之病，后者修道之病 |
| 心境双忘 | 能缘之心与所缘之境俱遣，黄檗所示之究竟处 |
| 空亡 | 落于断灭顽空，忘心者所惧之歧路 |
| 无求无着 | 无求则心不生、无着则心不灭，成佛之两门功夫 |
| 平常日用 | 行住坐卧之日常生活，无心功夫之现场 |
