# 摩訶僧祇律 — 学术解读

## 一、文献背景与成书

《摩訶僧祇律》（Mahāsāṃgha-vinaya），T1425，凡四十卷，收《大正藏》第二十二册，东晋佛陀跋陀罗与法显共译（416—418年）。本律为印度大众部（Mahāsāṃghika）所传广律。法显于隆安三年（399）西行，在中印度抄得本律梵本，义熙十四年（418）与佛陀跋陀罗于建康译出——是法显求法事业的直接成果，也是汉译诸律中唯一的大众部广律。

全书结构：卷一至卷三十五为比丘戒法，列比丘戒二百一十八条，另有杂诵跋渠法一百一十三条、威仪法五十条（相当于他律之犍度品）；卷三十六至卷四十为比丘尼戒法，列比丘尼戒二百七十七条及杂跋渠法。戒条总数为现存诸广律中最少者，与巴利律（227条）、四分律（250条）形成对照。

## 二、文本结构与核心思想

本律有三大特色：

其一，**制戒编年意识**。四波罗夷的制定被推定为佛成道后第五至第六年，律文自带年代坐标，为佛传年代研究提供内部材料。

其二，**七百结集的异说**。本律所记毗舍离七百结集不举「十事非法」，而提及「五净法」。巴利律藏系统的叙事以「十事」判定引发上座、大众分裂；本律的版本则显示大众部对同一事件的自我立场——承认某些开许之「净」的合法性。这是部派分裂史关键争议的「另一方证词」。

其三，**本生故事的密集引用**。释戒中引《本生经》五十三处、二十余种本生故事，为诸律之最，显示大众部律与叙事传统的深度绑定。

思想层面，戒序明示立法的目的论：「諸佛世尊，無量方便，為眾生故，說種種法，為斷貪欲、瞋恚、愚癡故」——一切戒条指向贪嗔痴的断除。对波罗夷的解释用三义：退没（道果无分）、不共住（不入僧数）、堕落（堕阿鼻地狱），宗教后果的表述较他律为重。

## 三、学术研究价值与争议

研究价值：本律是大众部立场的唯一完整广律，「五净法」叙事为部派分裂研究提供不可替代的对立材料；其组织以「跋渠」而不以「犍度」为单元，保留了更接近早期口诵形态的结构，被部分学者视为诸律中最古的形态之一；本生引用群是研究戒律与叙事互动的富矿。平川彰《律藏之研究》以诸律对勘重建犍度起源，本律为其关键参照。

争议问题：其一，本律是否真代表「原始僧团多数派」的传承，戒条偏少究竟是古拙还是删并，两说并立；其二，「五净法」与「十事非法」何者更近第二次结集的史实，是佛教史悬案；其三，大众部常被视作大乘思想的温床，但本律本身几乎不含大乘因素，「温床说」需谨慎评估。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 大众部（摩诃僧祇） | 本律所属部派，佛灭后根本分裂中的多数派 |
| 跋渠 | 本律的段落单元，相当于他律之犍度 |
| 五净法 | 本律版七百结集所举之开许事项 |
| 波罗夷三义 | 退没、不共住、堕落 |
| 杂诵跋渠 | 制度规程的主体部分 |
| 威仪法 | 五十条行仪细规 |
