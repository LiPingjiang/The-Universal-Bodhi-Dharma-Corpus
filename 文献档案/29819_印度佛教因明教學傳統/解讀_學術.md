# 印度佛教因明教学传统 — 学术解读

## 一、文献背景与成书

本档案题为「印度佛教因明教学传统」，属于学科教育综述类条目：它不对应某一部单独的典籍，而是对印度佛教逻辑学与知识论（因明，梵 hetuvidyā；量论，pramāṇa）从创立到融入寺院教育全过程的系统综述。据档案文献信息卡，其叙述年代跨度约自公元5世纪（陈那）至12世纪（那烂陀、超戒寺等学府衰亡），文献依据包括陈那《集量论》与法称《释量论》《正理滴论》《量决定论》，及汉藏译本与相关研究。需要说明的是：藏传一系因明文献依甘珠尔、丹珠尔（德格版《丹珠尔》量论部）编次，不在大正藏编号体系之内；汉传因明文献则见于玄奘译《因明正理门论》《因明入正理论》等，收入大正藏。

作为综述条目，本档案与前述诸档的分工是：`29812_漢傳因明教學傳統` 档侧重汉地一脉（玄奘传入、慈恩宗弘传），`00532_藏傳佛教因明典籍` 与 `29805_藏傳因明應成論式詳解` 侧重藏地一脉（摄类学、应成论式），本档则立足印度本土，追索这一学科从论辩术到寺院必修课的源流。

## 二、文本结构与核心思想

档案分六节展开，可归纳为「一源、两祖、一制度、两结合、一检验场」。

**一源：正理派的论辩土壤。**因明是印度「五明」之一，其源头并非佛教独有。正理派（Nyāya）依《正理经》建立五支论式——宗、因、喻、合、结；早期佛教在与外道的论辩实践中吸收改造此法，世亲著有《论轨》《论式》等论辩之作。档案特别指出五支论式的结构冗余：「合、結實為宗、因的重複」——这一批判正是陈那改革的起点。

**两祖：陈那的革命与法称的集成。**陈那（约480–540）晚年总结之作《集量论》有三项革命：确立「二量」说（现量离分别、比量依正因，将认识来源压缩为二）；简化五支为三支作法（宗、因、喻）；建立因三相（遍是宗法性、同品定有性、异品遍无性）与九句因，并创遮诠（apoha）理论——概念「并非指向某個實在的共相，而是通過『排除非牛』來界定」。法称（约600–660）则以三部论典构成教学核心：《释量论》四品（成量、现量、自义比量、为他比量）为哲学巅峰；《正理滴论》为纲要式入门教材，「最便於初學與教學」；《量决定论》居中量之作。其补足陈那的关键在「因三种」说——自性因、果因、不可得因——并主张论证有效性奠基于「自性關聯」，即因与所立法间须有同一性或因果性的实在关联。

**一制度：寺院必修课。**因明在那烂陀、超戒寺等学府中是基础必修，其教学有三个特点：通用工具课地位（「無論學中觀還是唯識，都須先具備因明訓練」）；由略入广的教材次第（《正理滴论》→《量决定论》→《释量论》→《集量论》）；与辩经实践互为表里。

**两结合：因明与义理教学的融合。**与唯识：陈那出身世亲一系，其现量理论强调「自證分」，玄奘曲女城无遮大会所立「真唯识量」即以三支论证唯识宗义。与中观：清辨自续派主张以正面自立论式成立空性，月称应成派则只以归谬式（应成论式）揭露对方矛盾——档案指出这场「自續 vs 應成」之争「本質上正是關於『因明工具如何運用於空性論證』的教學論爭」。

**一检验场：公开辩论。**印度宗教哲学高下由公开论辩裁定，常由国王主持，败者或须改宗、或须事胜者为师，甚至以身家性命为赌。因明由此成为「佛教在印度思想競技場上賴以自立、破斥異說、護持正法的鋒利武器」。

## 三、学术研究价值与争议

**印度哲学史的关键一环。**陈那被档案称为「中世紀印度邏輯學之父」，其二量说、九句因与法称的因三种说，构成世界逻辑史上与亚里士多德三段论、中国名辩学并立的独立传统。陈那对「合、结冗余」的诊断与三支化简，是论证形式化进程中的里程碑；遮诠理论（排除性定义）则被视为可与现代语言哲学意义理论对话的先驱。

**教育史与学科制度的活标本。**本档案最有特色之处，是它不把因明写成书斋逻辑，而写成一套完整的教学制度：教材次第（由略入广）、课程定位（工具课）、实践环节（辩经）、终极检验（公开辩论）。这为研究古代印度的知识传授模式提供了佛教一侧的样本，也是理解藏传格鲁派学制（摄类学—辩经—中观课程）的直接前提——瑟曼等学者所称藏传「心识科学」，其课程骨架正源于此。

**争议所在。**其一，陈那、法称生卒年问题：学界对其年代（如陈那约480–540、法称约600–660）均有十余年至数十年幅度的不同推算，本档案取通行一说，引用时宜注明异说。其二，因明的「派系属性」：陈那是否应视为唯识学者、其量论与唯识的关系，藏传内部与西方学界长期争论；档案采「陈那出身世亲一系」之说，属格鲁派式叙述，宁玛派学者（如如意宝幢对法称的批判）另有立场。其三，汉传因明的「中断」叙事：玄奘传入的因明在汉地数百年后渐衰，传统解释归咎于社会环境，学界则更关注其与慈恩宗衰落的同步关系，本档案未展开此节，读者可参 `29812_漢傳因明教學傳統`。其四，档案为综述编译性质，所引梵文术语与论式表述宜核对原典译本。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| hetuvidyā（因明） | 「关于理由的学问」，五明之一，逻辑学与知识论 |
| pramāṇa（量） | 正确认识的来源，陈那立现、比二量 |
| 现量／比量 | 直接知觉／依正因之推理 |
| 三支作法 | 宗、因、喻的论证式，陈那由五支简化而来 |
| 因三相 | 正因三条件：遍是宗法性、同品定有性、异品遍无性 |
| 九句因 | 因与同品、异品九种组合的穷尽分析 |
| apoha（遮诠） | 以「排除他者」界定概念的语义理论 |
| 自性因／果因／不可得因 | 法称「因三种」：同一性／因果性／未缘得之因 |
