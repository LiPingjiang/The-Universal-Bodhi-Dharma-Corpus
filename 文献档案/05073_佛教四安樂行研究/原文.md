# 佛教四安樂行研究 · 原文

## 一、概念概述

四安樂行出自《妙法蓮華經》（T262）卷五〈安樂行品〉第十四，是佛囑累菩薩於佛滅後惡世中弘揚《法華經》應安住的四種修行軌則：一、身安樂行——安住菩薩行處（住忍辱地、柔和善順而不猝暴，心無所畏）與親近處（不親近國王、外道、兇險戲者、四眾之欲因緣，於一切眾生平等說法）；二、口安樂行——不樂說人及經典過失，不輕慢他乘，不彰他好惡長短，不說聲聞緣覺之短，於四眾不說其過惡，常歎法之善、不嫌恨；三、意安樂行——無嫉諂之心，不惱亂他人，不戲論諸法，於一切眾生起大悲想、於如來起慈父想、於諸菩薩起大師想、於十方諸大菩薩常應深心恭敬禮拜；四、誓願安樂行——於後末世法欲滅時，受持讀誦是經者，發大誓願：願得不退轉心、得如來智慧，願諸眾生皆聞《法華》而得無上道。佛於偈頌中以髻珠喻（轉輪聖王解髻中明珠與功臣）喻《法華》為諸經中王，能持四安樂行者，成就種種微妙功德：「若能如是，是人於後惡世，無諸障難」。此品為歷代法華信仰之實踐綱領：南嶽慧思依之立「安樂行」之誓（終身行頭陀、誦法華），智者大師《法華文句》（T1718）詳釋四行之相，天台更以四安樂行配對治五濁之義；日蓮宗「折伏」「攝受」之修行論亦自本品「於濁世說法華」之難展開。

## 二、核心經文選錄

> **原文**（《妙法蓮華經》卷五〈安樂行品〉，T262）：
> 「若有菩薩摩訶薩，於後惡世，欲說是經者，應安住四法：一者、安住菩薩行處、親近處，能為眾生演說是經。」

> **白話對照**：
    在佛滅後濁惡之世弘揚《法華經》的菩薩，應安住於四種法。第一是身安樂行：「行處」是內在的安住——住於忍辱之地，心柔和善順而不暴戾；「親近處」是外在的防護——遠離諸過緣，於一切眾生起平等心而說法。身行清淨故，說法無難，身心安樂。

> **原文**（《妙法蓮華經》卷五〈安樂行品〉偈頌，T262）：
> 「又文殊師利，菩薩摩訶薩，於後末世，法欲滅時，受持讀誦斯經典者，無懷嫉妒諂誑之心，亦勿輕罵學佛道者……常應如來想。是則我大事，一切世間，皆應信順。……是人於後世，所說無所畏，諸天常守護。」

> **白話對照**：
    偈頌總攝口、意、誓願三行：口行則不說他過、不輕慢他人所學；意行則無嫉諂、於眾生起大悲、於如來起慈父想；誓願行則於末世受持是經，發願令一切眾生皆得佛慧。住此四行者，說法無所畏懼，諸天守護——「安樂」即是於濁世弘經而不遭濁世之惱。

## 三、重要名句

> 「於後惡世，欲說是經者，應安住四法。」（《法華經·安樂行品》）

> 「住忍辱地，柔和善順，而不卒暴，心亦不驚。」（身安樂行「行處」之文）

> 「不樂說人及經典過……於一切眾生，平等說法。」（口安樂行之要）

> 「以佛滅度後，能持是經故，諸佛皆歡喜。」（持經功德之偈）

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 安樂行 | 令身心遠離惱害、安隱說法之四種修行法 |
| 行處／親近處 | 內心安忍之地／外境防護之緣 |
| 惡世／五濁惡世 | 劫濁、見濁、煩惱濁、眾生濁、命濁之世 |
| 髻珠喻 | 轉輪聖王解髻中明珠賜功臣，喻《法華》為諸經之王 |
| 法華經王 | 《法華經》於諸經中最上之尊稱 |
| 行處（cirābhilāsa?） | 修行安住之境，忍辱柔和 |
| 折伏／攝受 | 日蓮宗自此品開出之兩種化導法 |
| 誓願安樂行 | 發大誓願受持弘傳《法華》之第四行 |
