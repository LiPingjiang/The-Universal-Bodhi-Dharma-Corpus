# 佛教南傳歷史 · 原文

## 一、文獻概述

南傳佛教史記述上座部（Theravāda）自印度傳入斯里蘭卡（錫蘭），再擴布至東南亞的過程。其史料主體是巴利文編年史：**《島史》**（Dīpavaṃsa）、**《大史》**（Mahāvaṃsa）與**《小史》**（Cūḷavaṃsa）。

**《大史》**（亦名《大王統史》）為早期巴利文的斯里蘭卡王朝與佛教編年史，約成書於**六世紀左右，大名長老（Mahānāma）著**。該書以《島史》與宮廷文件為主要資料，敘述佛教的產生、傳入斯里蘭卡，直到大軍王統治時期（325–352）的過程，內容主要涵蓋四個方面：佛教的產生與發展、佛陀至斯里蘭卡弘法的傳說、佛教傳入後的變化發展、護教國王杜多伽摩尼（Duṭṭhagāmaṇī）的業績。作者採史詩體裁，文筆優美，敘述生動，兼具文學與史料價值。

《大史》有三種修訂本，目前流行的編訂本共 **37 章**，由德國學者威廉·蓋格（Wilhelm Geiger）編纂，倫敦巴利聖典學會（PTS）出版。《小史》為《大史》續篇，記述 4–8 世紀王朝盛衰、典章沿革與佛教發展，以至歐洲殖民者的入侵。僧伽羅學者原將二書合編統稱《大史》，蓋格始將其分立。

### 史事年表（依編年史與考古研究）

| 年代 | 事件 |
|---|---|
| 約前 483 年 | 據《大史》，維舍耶（Vijaya）率眾自北印度抵島，島史記載之始 |
| 前 377 年 | 阿努拉德普勒（Anurādhapura）建城，成為主要聚落 |
| 前 3 世紀（約前 250 年） | **摩哂陀**（Mahinda，阿育王之子）將佛教傳入斯里蘭卡 |
| 前 161 年 | 杜多伽摩尼王擊退南印度朱羅勢力，重掌阿努拉德普勒 |
| 前 1 世紀 | 巴利三藏在斯里蘭卡首次**書寫成文**（此前純賴口傳） |
| 5 世紀 | 覺音（Buddhaghosa）於大寺（Mahāvihāra）系統整理註疏，著《清淨道論》 |
| 993–1077 年 | 全島短暫統一於朱羅（Chola）統治下 |
| 1597–1658 年 | 島上大部分地區處於葡萄牙統治；後荷蘭、英國相繼入主 |
| 1815 年 | 康提戰爭後全島統一於英國統治 |
| 19 世紀末 | 內觀禪修於緬甸復興，並回傳斯里蘭卡、泰國、寮國 |
| 1948 年 | 斯里蘭卡獨立 |

自阿努拉德普勒至康提時期，斯里蘭卡共歷 181 位君主。佛教雖在印度本土影響漸衰，卻在僧伽羅文化中逐步紮根，成為其核心。

## 二、核心段落選錄

> **原文**（《大史》書名與體例，巴利語）：
> 「Mahāvaṃsa」——直譯「大系譜」「大王統史」。
>
> `mahā` 為大，`vaṃsa` 為世系、傳承、系譜。同系書名尚有 `Dīpavaṃsa`（島史，`dīpa` 為島）與 `Cūḷavaṃsa`（小史，`cūḷa` 為小）。

> **白話對照**（說明上段）：
> 「大史」即「偉大的傳承之書」。以 `vaṃsa`（系譜）名書，反映南傳史學的核心觀念——佛法的正統性繫於**師師相承的傳燈系譜**：從佛陀、迦葉、優波離，經歷次結集，到摩哂陀渡海入島，再到大寺（Mahāvihāra）諸師。王統與法統在此類編年史中被編織為同一條線索，故護法之王（如杜多伽摩尼）的功業被大書特書。

## 三、重要名句

> **名句一**（南傳三大編年史並稱）：
> 「Dīpavaṃsa、Mahāvaṃsa、Cūḷavaṃsa」——《島史》《大史》《小史》。
>
> 斯里蘭卡的原史時期大致自公元 3 世紀開始，即以此三部編年史為據。它們記錄了僧伽羅人自北印度遷入後的歷史，涵蓋公元前 6 世紀檀巴潘尼（Tambapaṇṇī）王國建立以來的時期。島上最早的定居文獻紀錄，即見於這些編年史。

> **名句二**（三藏書寫之始）：
> 「南傳上座部的巴利語佛典，直到公元前一世紀才在斯里蘭卡（錫蘭）被書寫下來。」
>
> 原始結集的佛典與部派初期傳承的佛典，都是依靠**集體背誦與口傳**的方式保存。此一書寫事件是南傳佛教史的關鍵轉折——三藏由「合誦」轉為「貝葉」，文本自此定型。斯里蘭卡貝葉寫本傳統延續甚久，今存者多為 17–19 世紀所抄。
