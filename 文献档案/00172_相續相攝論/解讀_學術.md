# 相续相摄论 — 学术解读

## 一、文献背景与成书

《相续相摄论》（Saṃtānāntarasiddhi，或译《成他相续论》《证他心存在论》）为法称（Dharmakīrti，约600-660年）所造（一说"天主"，即作者归属另有传承异说），约成书于7世纪，是法称"七论"中唯一专论"他心问题"（the problem of other minds）的哲学专论。梵本状况：全本未完整存世（或仅存部分），主要依赖藏译流传；汉地无古代译本。本论在近代西方哲学"他心问题"研究的参照系中被频繁援引，是佛教哲学对这一经典知识论难题最系统的正面回应。

书名梵语 Saṃtānāntarasiddhi：saṃtāna（相续，心识之流）+ antara（他、异）+ siddhi（成立），直译"他相续之成立"——即论证"他人之心识流"的存在。

## 二、文本结构与核心思想

本论的问题意识来自唯识学的一个内在张力：**既然唯识无外境，如何避免"独我论"（solipsism）？**——若一切皆我识所变，他人之心岂不也只是我心变现的影像？

论主的论证核心是一个类比推理（比量）：**他身之语言、动作等，并非随我之意欲而发起**——别人的言行不服从我的意志，其发动之因只能归于他自己的心识（意愿），故"他相续"（他人的心识流）得以成立。换句话说：我无法解释他人行为的原因序列，除非承认在那一端有一个独立的心理因果系统在运作。

与之配套的是概念澄清：**唯识所遮者是"离识之外境"，非遮"他人之心"**——他人心识虽然不直接呈现于我的经验（它不是我现量的对象），但可以作为比量的对象（由其果——言行——推其因——他心）。由此，唯识不堕独我论：外境被否定，他心被证成，"遮外不遮他"的义理边界由此划定。

## 三、学术研究价值与争议

研究价值方面，本论是印度哲学"类比论证"（ātopa/anumāna via behavior）传统的代表作：法称以"行为的最佳解释推理"证他心，与当代心灵哲学中对他心问题的"类比论证""最佳解释推理"方案结构相通，因而被比较哲学界广泛讨论（如西尔万·列维以来的印度学传统与当代分析心灵哲学的对读）。本论也是研究法称因果理论与意向性理论交汇点的关键文本：他心作为"不可直接经验但可由果推知"的存在，恰处在自相（真实）与"仅由比量所成"的边界上，注释家为此发展了精细的讨论。

争议问题包括：（1）作者归属——法称造为主流，但"天主造"的异说使部分文献史的归属仍有讨论；（2）论证的强度——类比推理能否证成他心的存在（而非仅仅其"功能等价物"），在哲学上始终有"行为主义读法"与"实在论读法"的分歧；（3）他心的认知地位——他心究竟是比量的"所量"还是仅是"推知的对象"，牵涉法称体系中共相/自相二分的边界难题，藏传注疏传统对此有绵长的辩论。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 相续（saṃtāna） | 个体的心识之流 |
| 他相续（saṃtānāntara） | 他人的心识流 |
| 独我论（solipsism） | 认为唯有自心存在的立场 |
| 他心（paracitta） | 他人心识，本论的论证对象 |
| 意欲（cetanā） | 发动身语行为的意志 |
| 唯识（vijñaptimātra） | 遮外境而不遮他心的唯识学 |
