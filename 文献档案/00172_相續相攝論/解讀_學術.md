# 相續相攝論 — 学术解读

## 一、文献背景与成书

《相續相攝論》（Saṃtānāntarasiddhi，又译《成他相续论》）为印度论师法称（Dharmakīrti，约600—660）所造，一说系「天主」所传，作者归属存异说，兹依本目录原文档所记「法稱造（一說天主）」并注明。本论是法称因明—认识论著作群中唯一专论「他心问题」的短篇专论，约成于七世纪。梵本未完整存世，主要依靠藏译本（收入丹珠尔）流传；汉地古代无译本，故不在大正藏编号体系之内，现代研究多据藏译及梵文残存引文展开。

本目录原文档所收内容较为简略，仅录本论的核心论式、两条名句及术语表，未收完整译文。下文即据原文档所存条目，就可考的论旨背景撰文。

书名 Saṃtānāntarasiddhi 由 saṃtāna（相续，心识之流）、antara（他）、siddhi（成立）三词合成，直译为「他相续之成立」——论证他人心识流的真实存在。

## 二、文本结构与核心思想

本论的问题意识源于唯识学的内在张力：既然主张「唯识无境」，如何避免滑向独我论——若一切皆我识所变，他人之心岂非也只是我心变现的影像？

论主的论证核心是类比推理（比量）：原文档所录论式为「他身之語動作等，非我意所欲而起，其因唯應歸於他之心識，故他相續得成」——他人的语言、动作不服从我的意欲而发起，其发动之因不能归于我识，只能归于他自己的心识流。由此「他相续」得以成立。

与之配套的概念澄清是：唯识所遮遣的是「离识之外境」，而非他人之心——原文档名句二即言「唯識所遮者是離識之外境，非遮他人之心。故唯識不墮獨我，理在於此」。他心虽非我现量所缘，却可由果（言行）推因（他心），成为比量的合法对象。遮外境而不遮他心，唯识学与独我论的边界由此划定。

## 三、学术研究价值与争议

研究价值：其一，本论是印度哲学传统对「他心问题」最系统的正面回应，与当代分析心灵哲学中的类比论证、最佳解释推理方案在结构上高度相通，是比较哲学的标准个案；其二，本论处在法称因果理论与意向性理论的交汇点——他心作为「不可现量经验而可由果推知」的存在，恰在自相与比量所成的边界上，藏传注疏传统对此有绵密的后续辩论；其三，它展示了唯识学自我辩护的机制，是理解世亲—陈那—法称一系义理演化的关键环节。

争议问题：其一，作者归属——「法称造」为主流传承，「天主造」的异说使文献史定位仍有讨论空间，本目录原文档两说并存，兹如实注明；其二，类比推理能否证成他心的「存在」而不仅是「功能等价」，历来有行为主义读法与实在论读法之争；其三，本目录原文档仅存核心论式与名目，完整文本须依赖藏译本研究，档案层面的阙如应如实说明，不做虚构补充。

| 独我论 | 唯有自心存在的立场，本论所要避免的结论 |
| 意欲（cetanā） | 发动身语行为的意志因素 |
| 唯识（vijñaptimātra） | 遮外境而不遮他心的立场 |
| 比量 | 由果推因的推理认知，他心认知的合法途径 |
