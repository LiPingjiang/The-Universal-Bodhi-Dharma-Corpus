# 金剛經六譯本合集 — 学术解读

## 一、文献背景与成书

《金剛般若波羅蜜經》（Vajracchedikā Prajñāpāramitā Sūtra）为大乘般若部核心经典，以佛陀与须菩提的问答展开，阐发缘起性空、破除我人等四相之理。本目录所收为该经汉译六本的合集：鸠摩罗什译（T235，后秦弘始四年，402）、菩提流支译（T236，北魏永平二年，509）、真谛译（T237，陈天嘉年间）、笈多译（T238，隋开皇十年，590）、玄奘译（T220第九会，唐贞观二十二年，648）、义净译（T271，唐景云二年，703）。六译均收入《大正新脩大藏經》。

般若类经典在印度的编集经历了数百年层累过程，《金剛經》属其中篇幅适中、流传最广的一支。其传入中国后屡经重译，本身就是译经史上的罕见现象——同一梵本系统在三百年间被六位顶级译师反复传译，为观察汉译佛典翻译思想的演变提供了独一无二的纵剖面。1900年敦煌莫高窟出土的唐咸通九年（868）刻本《金剛經》（罗什本），是现存有明确纪年的最早雕版印刷品；近年龙门石窟亦发现唐代石刻罗什译本，可见此经在唐宋社会的渗透深度。

## 二、文本结构与核心思想

全经以须菩提「云何应住，云何降伏其心」之问为纲，佛陀答以「应无所住而生其心」，展开三轮破执：破我法二执（「凡所有相，皆是虛妄」）、破布施相（「菩薩於法應無所住行於布施」）、破佛法相（「如來所說法，皆不可取、不可說」）。结尾「一切有為法，如夢幻泡影，如露亦如電，應作如是觀」之六如偈，为全经总收。

六译本的差异构成本合集的核心研究对象：其一，经题不同——前三译作「金剛般若波羅蜜」，笈多本增「能斷」二字，玄奘、义净本则作「能斷金剛」，反映对 vajracchedikā 一词「金刚之断」抑或「能断（烦恼）之金刚」的不同解读；其二，偈颂差异——罗什本六喻（梦、幻、泡、影、露、电），玄奘本扩为九喻（星、翳、灯、幻、露、泡、梦、电、云），更近现存梵本；其三，语言风格——罗什意译流畅，笈多直译存梵文语序，玄奘精密雅正；其四，分科不同——罗什本三十二分相传为梁昭明太子所加，梵本与其他译本并无此分章。

## 三、学术研究价值与争议

研究价值方面：六译对勘是重建梵本原貌的经典案例，可与现存梵本（吉尔吉特出土等）及藏译本互校，考察印度文本自身的流变；六祖慧能因闻「應無所住而生其心」而悟的传说，使此经成为禅宗史研究的枢纽文献；敦煌刻本则使此经稳居世界印刷史起点位置。德国学者马克斯·缪勒、孔睿（Conze）等均校刊过梵本，日本学界对六译词汇的比较研究积累深厚。

争议问题：其一，昭明太子三十二分的分科是否合乎经义，历代注家褒贬不一；其二，玄奘、义净两译为何在罗什本已极流行的情况下仍要重译，反映译场对旧译准确性的何种判断，学界有「订讹说」与「求备说」之争；其三，六译中某些段落（如「一合相」段）的译语分歧，牵涉梵本是否有不同传本的文本史问题。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 般若（Prajñā） | 超越世俗认识的智慧，「到彼岸」之智 |
| 波罗蜜（Pāramitā） | 到彼岸，六度之行法 |
| 四相 | 我相、人相、众生相、寿者相，所破之执 |
| 六如偈 | 「如夢幻泡影，如露亦如電」之结经偈，玄奘本为九喻 |
| 无住 | 心不执著于任何对象而安住 |
| 三十二分 | 罗什本相传由昭明太子所分的章节结构 |
