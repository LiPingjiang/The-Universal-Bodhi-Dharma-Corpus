# 大乘起信論科文 · 原文

## 一、概述

**檢索結果說明（重要）**：經查 CBETA 電子佛典（《大正藏》《卍續藏》全文與書名檢索），**並無獨立成書、題名為《大乘起信論科文》的文獻**。以「起信論科文」為關鍵詞的全文檢索結果為零。丁福保《佛學大辭典》「大乘起信論」條所列歷代註疏二十種，亦無此名目。因此本條目所指，不能作為一部有確定作者與藏經編號的單行典籍看待。

「科文」並非書名，而是中國佛教特有的一種**文獻體裁**——又稱「科判」「分科」，指把經論內容按層次結構分科排列，標明各部分的宗旨與邏輯關係。歷代《起信論》註疏幾乎都自帶科判，但多附於疏記之中，少有單行。

現存文獻中，與「起信論科文」最直接對應的實物，是清·**續法**《起信論疏記會閱》卷首（**X0767**，CBETA：X45n0767）中所編的「科判」一項。續法在〈凡例〉中明確交代了他如何處理舊有的科文單行本，這段文字是討論「起信論科文」問題時可據的第一手材料。以下所錄，即出於此。

---

## 二、核心段落（原文與白話對照）

### 段落一：續法論舊有科文一卷的處置

**原文**（《起信論疏記會閱》卷首〈凡例〉，X0767）：

> 舊有科文一卷，論科之後附贅疏科，殊覺障眼。今別本科中單編論科，疏科仍存記中，此則不唯省煩瑣，且與圭山註本極為相應。

**白話對照**：舊時另有科文一卷，在論的科判之後又附綴上疏的科判，很覺得礙眼。如今在另編的科本之中，只單獨編排論的科判，疏的科判仍舊保留在記文之內。這樣做不僅省去了煩瑣，而且與圭峰（宗密）的註本極為相應。

此條可證：續法之前確有《起信論》科文的單行一卷本流通，但其體例是論科與疏科混編；續法認為此體例不佳，故將二者拆分重編。舊本今已不存。

### 段落二：科判的編次原則——依賢首舊科，不另立異

**原文**（同上〈凡例〉）：

> 論中分文章段，原依賢首大師科判，並無異立。論前序疏段落，例此可知。
> 科門層疊，源委難明。交光大師科，楞嚴經創以干支，今稟承之以標其科，則曾玄生起有序，而前後脉絡亦貫通也。

**白話對照**：論中劃分文句章段，原本就依照賢首（法藏）大師的科判，並沒有另立不同的說法。論前序文與疏文的段落劃分，比照這個辦法就可以明白。科判的門類層層疊疊，來龍去脈難以理清。交光（真鑑）大師為《楞嚴經》作科判，首創用天干地支來標示；如今我承襲這個辦法來標示科目，這樣一來，從曾祖到玄孫般的層級生起就有了次序，前後脈絡也能夠貫通了。

### 段落三：科判所依的全論五分結構

《起信論》科判的最上層架構，本論自身即已明示。實叉難陀新譯本作（T1667）：

> 此中作因有八……此論分為五分。一作因、二立義、三解釋、四修信、五利益。

梁·真諦舊譯本作（T1666）：

> 說有五分。云何為五。一者因緣分。二者立義分。三者解釋分。四者修行信心分。五者勸修利益分。

**白話對照**：這部論分為五個部分：第一是說明造論因緣的「因緣分」，第二是標舉全論義理綱要的「立義分」，第三是展開詳細解釋的「解釋分」，第四是說明如何修習信心的「修行信心分」，第五是勸勉修行、顯示利益的「勸修利益分」。

一切《起信論》科文，無論繁簡，都以這五分為第一層綱目；其下再分「解釋分」為顯示實義、對治邪執、分別修行正道相三科，如此層層細分。

## 三、名句

1. **「舊有科文一卷，論科之後附贅疏科，殊覺障眼。」**（續法《會閱》卷首凡例）
   ——這是現存文獻中，關於「起信論科文」曾以單行一卷本存在的直接記載，也是續法改編其體例的理由。

2. **「科門層疊，源委難明……今稟承之以標其科，則曾玄生起有序。」**（同上）
   ——道出科判之學的根本困難（層級太深則脈絡不清）與續法的解決方案（借交光真鑑的干支標號法）。

## 四、術語表

| 術語 | 出處與釋義 |
|------|-----------|
| 科文／科判／分科 | 中國佛教文獻體裁，將經論按層次分科排列以顯結構 |
| 論科／疏科 | 分別指為論本文所作的科判、為疏文所作的科判 |
| 五分 | 《起信論》最上層結構：因緣、立義、解釋、修行信心、勸修利益 |
| 曾玄 | 曾祖與玄孫，喻科判層級的上下輩分關係 |
| 干支標科 | 以甲乙丙丁、子丑寅卯標示科判層級，明·交光真鑑首創於《楞嚴》 |
| 圭山／圭峰 | 唐·宗密，續法會本所對應的註本作者 |
| 賢首 | 唐·法藏，《起信論》科判的標準確立者 |

## 六、文獻說明

本篇原文段落引自 CBETA 電子佛典《卍續藏》第四十五冊 X0767《起信論疏記會閱》卷首〈凡例〉，以及《大正藏》T1666、T1667《大乘起信論》兩譯本的五分標目，白話對照為逐段今譯。

**如實說明**：
1. 經檢索 CBETA 全文與書名，未發現題為《大乘起信論科文》的獨立典籍，亦無可靠的作者與藏經編號可考。本目錄 README 舊稱其為「唐代僧人所作、作者不詳、可能為法藏弟子或同時代學僧」，此說未見文獻依據，屬推測之詞，不宜作為定論。
2. 據續法〈凡例〉可知，明清之際確曾有《起信論》科文單行一卷本流通，但其書今已不存，內容僅能由續法的描述反推。
3. 本篇因此改採「以現存可靠材料說明科文問題」的處理方式，所引皆為實有出處之文，未作虛擬補綴。
