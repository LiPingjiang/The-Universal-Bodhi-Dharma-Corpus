# 金剛頂經疏 · 原文

## 一、概述

本條所據的可核實注疏為《金剛頂經大瑜伽秘密心地法門義訣》一卷（《中華大藏經》續編漢傳注疏部，編號0689）。舊錄稱原三卷，今僅存卷上。其著者與記錄者異說並存：早期《兩部大法師資相承記》作一行造，後世亦有題為金剛智口說、智藏（不空）記，或逕署不空撰者；因此不宜將作者斷定為一人。此書解說金剛智所傳《金剛頂略出念誦經》，以普賢、毗盧遮那、金剛薩埵與一切有情的關係，闡明瑜伽、戒、三昧耶及成佛之義。

## 二、核心段落

> **原文**（《金剛頂經大瑜伽秘密心地法門義訣》現存卷上）：
>
> 「謂大日如來普賢身心三摩地輪遍空塵界。其中有情即與如來智光明相和合一味。故《梵網》云：『一切眾生皆有佛性，一切諸意識色心，是情是心皆入佛性戒中。』如是有情亦名為佛亦不名佛，功德智慧未明顯故；亦名普賢亦非普賢，隨分行願未淳醲故；名為有情亦非有情，如來藏性生缺減故。」

> **白話翻譯**：
>
> 大日如來的普賢身心三昧之輪遍滿如虛空與微塵般無量的世界；其中的有情與如來智慧光明相應，成為一味。依《梵網經》所說，一切眾生皆有佛性，意識與色心等皆攝入佛性戒中。眾生可說名為佛，又不可說已是佛，因其功德與智慧尚未顯明；可說名為普賢，又不可說已是普賢，因其行願尚未純熟；可說名為有情，又不可執為固定的有情，因如來藏性本無生滅增減。

## 三、名句

1. 「其中有情即與如來智光明相和合一味。」
2. 「此普賢菩薩現住佛心者有二意：一表知普賢即是毗盧遮那，二令諸有情覺知自身不離佛心。」

## 四、術語表

| 術語 | 說明 |
|---|---|
| 金剛頂 | 密教金剛界系統之經典與法門總稱。 |
| 瑜伽 | 相應、相合；此處指身語意與佛智相應的修行。 |
| 普賢 | 此疏中與大日如來、金剛薩埵密切相連的菩薩名號與德相。 |
| 三摩地 | 等持、三昧，心專一安住之境。 |
| 三昧耶 | 密教中約誓、平等與加持相應之義。 |
| 如來藏 | 眾生所具成佛可能性或覺性之語彙。 |

## 五、相關文獻

- 《金剛頂略出念誦經》：金剛智譯，為《義訣》所解之經本系統。
- 《金剛頂瑜伽中發阿耨多羅三藐三菩提心論》：不空譯，論行願、勝義、三摩地三種菩提心行相。
- 《金剛頂瑜伽金剛薩埵五秘密修行念誦儀軌》：不空譯，提供金剛頂瑜伽儀軌材料。
- 《梵網經》：本疏核心段落引為說明佛性戒的經證。

> **校記**：檢索未能證實本條可直接對應「T1797」；T1797實為不可思議《大毗盧遮那經供養次第法疏》。故本條不沿用原有T1797標注，並保留《義訣》作者歸屬的學術疑義。
