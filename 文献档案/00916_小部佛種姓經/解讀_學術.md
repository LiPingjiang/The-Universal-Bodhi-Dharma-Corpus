# 小部·佛种姓经 · 学术解读

## 一、背景部类

《佛种姓经》（Buddhavaṃsa，意为"佛之谱系史"）属巴利《小部》（Khuddaka-nikāya）第十四经，是偈颂体的古文献，共二十九品。其内容由佛陀应舍利弗之请，自述从燃灯佛以来诸佛的世系与史传，为读者呈现"过去诸佛"的完整谱系。经中所记诸佛从燃灯佛直到迦叶佛及释迦牟尼佛本人，合计二十五佛，当为南传上座部佛教菩萨思想的重要根据。

在部类上，它属经藏中的小部。小部是汇集偈颂、本生等经文的合集，《佛种姓经》在其中占有一席，既以偈颂述史，又承载菩萨波罗蜜的教理使命。它在斯里兰卡、缅甸等上座部地区拥有极崇高的地位，常与《所行藏》配套研习，被视为"佛传圣谱"的源点。

本经成立的时代约属后期。其立场突出"成佛度生"的菩萨愿行与波罗蜜累积，既非纯历史性的传记，也非纯哲理性的论书，而是以信仰性的谱系叙事来承载教理。就经义而言，本经把"成佛"的境界转化为可借愿行渐至的目标：诸佛历世相续出现，正说明菩提并非遥不可及，而是以誓愿为因、以十种波罗蜜为缘、经历无尽劫数渐趋圆满。于上座部中兼具信仰与修习意义。

## 二、结构与核心思想

全经以"诸佛谱系"为主线，依次展开三层内容。

其一为"开场与请缘"。经初设立一地点，佛陀住于此处，舍利弗以恭敬心祈请佛陀讲述过去世成佛的根源与菩萨道，于是佛陀开演本经，构成全经"应机说法"的缘起架构。

其二为"历代诸佛谱系"，是全经主体。依序叙述燃灯佛（Dīpaṅkara）等二十五佛，每尊佛均列其族姓、家世、亲属、菩提树、上首弟子、侍者、寿量、成道之处等细目，形成极为整饬的"佛谱"。其中尤以善慧（Sumedha）隐士于燃灯佛前发大誓愿、得受成佛授记一段最为著名，被视为"菩萨道起始"的典范。

其三为"十波罗蜜的誓愿与践行"。善慧在燃灯佛前发誓，要在未来无数劫中圆满布施、持戒、出离、智慧、精进、忍辱、真实、决意、慈、舍十种波罗蜜。由此，"菩萨"才正式成为以实现正觉为志、长劫修行的誓愿者，为后世"菩提道"思想奠定经典根基。

## 三、价值与汉译对应

《佛种姓经》的学术价值，其一在于它是南传"菩萨道"与"十波罗蜜"思想的根本经典，是研究"成佛理念"形成的珍贵资料；其二，它为"诸佛名号与谱系"提供了完整的佛传；其三，它与《所行藏》《本生》等共同构成南传"佛传与本生"文献群。

汉译方面，小部整体未得完整结构汉译入藏，本经亦无独立的汉译对照本。但燃灯佛施善慧授记的脉络，与汉传《过去现在因果经》《佛本行集经》的相关记载一脉相通；"十波罗蜜"也与汉译大乘十地等思想相映类似，可为学者比照探讨"菩萨愿行"的源流与差异。

## 四、术语

| 术语（巴利/梵语） | 汉译 | 含义 |
|---|---|---|
| Buddhavaṃsa | 佛种姓 | 记叙诸佛世系的经典 |
| Dīpaṅkara | 燃灯佛 | 诸佛之一，最初的过去佛 |
| Sumedha | 善慧 | 燃灯佛前发誓的菩萨 |
| Bodhisatta | 菩萨 | 立志成佛的行者 |
| Pāramī | 波罗蜜 | 成佛所要圆满的十种德目 |
| Vyākaraṇa | 授记 | 佛对成佛的预示 |
| Kappa | 劫 | 极长的世间周期 |
| Dhammacakkavattana | 转法轮 | 最初开演正法 |

以上术语说明，《佛种姓经》以传承诸佛的常系叙述，以十波罗蜜为纲，承载了南传菩萨道与"成佛因缘"的信仰，是研读南传菩萨思想的重要经典。
