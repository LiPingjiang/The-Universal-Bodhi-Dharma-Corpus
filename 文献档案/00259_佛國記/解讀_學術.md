# 佛国记 — 学术解读

## 一、文献背景与成书

《佛国记》，又称《高僧法显传》《历游天竺记传》，一卷，东晋法显（约337—约422）著，收于《大正藏》第五十一册（No. 2085）。法显俗姓龚，平阳人，三岁出家，慨于汉地律藏残缺，以六十余岁高龄于隆安三年（399）自长安西行求法，穿流沙、越葱岭，遍历北、西、中、东天竺，学梵语、写经像，后泛海经师子国（斯里兰卡）、耶婆提，漂泊数年，义熙八年（412）前后归抵青州，"前后十五年，备经艰险"——名句所记即其总述。归国后与佛驮跋陀罗于建康道场寺共译经律，并撰此游记。

法显是中国佛教史上第一位抵达印度本土并留下完整行纪的求法僧，其陆去海还的环形路线，比玄奘早二百三十余年，是西行求法运动的真正开端。

## 二、文本结构与核心思想

全书依行程编次：长安出发—乾归、耆檀—度流沙（沙河）—鄯善、焉夷—越葱岭—北天竺（陀历、乌苌、犍陀卫等）—西天竺（弗楼沙、那竭）—中天竺（摩头罗、僧伽施、拘萨罗、迦维罗卫、拘夷那竭、巴连弗邑、王舍城、伽耶、鹿野苑）—东天竺多摩梨帝国写经—泛海师子国—耶婆提—归国。核心内容可归为三点：

1. **中天竺佛教盛况的实录**。原文所录："中天竺所谓中国，气候和暖，人民殷盛。佛法最盛，僧众万数。国王长者竭力供养。塔寺幢幡严饰华丽。自佛在世至今，相承不绝。"法显以"中国"称中天竺，是当时以佛生之地为文明中心的独特视角，也保存了5世纪印度佛教（大众部盛行、大乘与上座并存）的第一手图景。

2. **社会与法律的记录**。名句所云："中天竺所谓中国，寒暑调和，无霜雪。人民殷乐，无户籍官法。唯耕王地者乃输地利。"——不设户籍、不立刑狱、耕王地者纳租——此类观察是研究5世纪印度社会史的珍贵材料。

3. **圣迹巡礼与虔敬叙事**。法显每到佛迹（诞生、成道、初转法轮、涅槃处）必详记其供养仪式、行像盛会（如于阗国行像的壮观记录），其文字朴素而感情深挚，是巡礼文学的典范。

## 三、学术研究价值与争议

**研究价值**：本书与《大唐西域记》《南海寄归内法传》并称中国求法僧三大行纪。其价值：（一）5世纪印度（笈多时代）佛教与社会史的独特记录——印度本土此期史料同样稀缺；（二）师子国部分记录了当时斯里兰卡佛教（无畏山寺等），是斯里兰卡佛教史的重要外部史料；（三）海上航路（从多摩梨至师子国、耶婆提至长广郡）的记录，是研究5世纪南海交通与航海史的第一手材料（其中关于耶婆提方位的讨论曾是中外交通史学的著名课题）。

**代表学者**：章巽《法显传校注》为集大成整理本；岑仲勉、足立喜六等对路线地名多有考订；英国学者比尔（S. Beal）、翟理斯（L. Giles）之英译及20世纪以来各国学者关于"耶婆提是否美洲"之讨论（主流学界已否定，但可见本书引发想象之能量）均显示其国际影响；日本学者对5世纪印度佛教的重建亦以此为基。

**争议问题**：其一，法显的年龄与生年——史料记载互歧，"六十余岁西行"若确，其坚韧更形惊人，但生年推算至今无定论；其二，归国登陆地（牢山/青州）与后期事迹的细节考订；其三，文本的流传与异文——现存各本文字有出入，章巽校注已作系统清理，个别地名的比定（如西北印度诸国）学界仍在讨论。

## 四、术语对照表

|------|------|
| 天竺 | 印度之古称，分东南西北中五部 |
| 中国（中天竺） | 法显称中天竺为"中国"，佛生之文明中心地 |
| 行像 | 以宝车载佛像巡行的盛大法会 |
| 师子国 | 今斯里兰卡，古佛教重镇 |
| 耶婆提 | 法显归程所经之地，一般认为在爪哇或苏门答腊 |
| 求法 | 西行印度寻求经律之壮举 |
