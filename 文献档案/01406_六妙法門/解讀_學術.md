# 六妙法门 — 学术解读

## 一、文献背景与成书

《六妙法门》一卷，隋·智顗（智者大师，538–597）述，收于《大正新脩大藏经》第四十六册，编号 T1916。又称《修禅六妙门》《六妙门禅法》，略称《六妙门》。相传为智顗应尚书令毛喜之请，于金陵瓦官寺讲说，属于天台三种止观（渐次、不定、圆顿）中"不定止观"的代表著作。在天台止观著作序列中，它与《次第禅门》（渐次止观）、《小止观》《摩诃止观》（圆顿止观）并列；本库另设 `01401_天台止觀` 总条综论这一体系，本条专论本书文本，二篇互注。需注意：据本库原文档，书名释义为"六"是约数法立名，"妙"指灭谛涅槃，"门"谓六法能通向涅槃——六妙门即"以六个法门通达涅槃"。

## 二、文本结构与核心思想

全书开为十章：历别对诸禅六妙门、次第相生六妙门、随便宜六妙门、随对治六妙门、相摄六妙门、通别六妙门、旋转六妙门、观心六妙门、圆观六妙门、证相六妙门。前数章把六门当作次第进修之阶梯，后数章则转为圆顿观法，一章一义，层层旋转——这正是"不定止观"的特征：六门不是单行道，而是随人随病互相触发、互通互摄。

六门为：一数（摄心在息，从一至十）、二随（舍数，心依息之出入）、三止（息诸缘虑，凝寂其心）、四观（于定心中观照身息心法）、五还（返照能观之心，境智双亡）、六净（心无所依，妄垢自净）。每门又各有"修"与"证"两阶，合为十二法。其进阶逻辑是"以粗换细"：修数至心住息缘、反患数为粗，即舍数修随；随既细已，又厌随修止——如同剥笋，层层向内。

全书开篇即以此法门上溯释尊：「釋迦初詣道樹，跏趺坐草，內思安般：一數、二隨、三止、四觀、五還、六淨。因此萬行開發，降魔成道。」第六章以下又将六门摄入圆观：依数为妙门则出生四禅、四无量心、四无色定，且能于非非想处觉知其非涅槃而破析之；依随为妙门则出生十六特胜（知息入、知息出、知息长短乃至观弃舍）——显示天台以圆教见地重估早期禅法的方法。

## 三、学术研究价值与争议

价值有四。第一，它是汉传呼吸禅法最系统的文本之一，与早期传入的《安般守意经》一系对勘，可见印度数息法如何被天台改造为兼具次第与圆顿双轨的体系。第二，"修—证"两阶、"以粗换细"的进阶设计，是一份珍贵的古代禅修现象学记录，对今日禅修教学仍有参考价值。第三，十六章中"旋转六妙门""观心六妙门""圆观六妙门"诸章，是从"不定"通向"圆顿"的关键，为研究三种止观之间的关系提供直接证据。第四，"妙者即是灭谛涅槃""门虽有六，会妙不殊"的判摄，是天台"方便有多门，归元无二路"精神的具体展开。

争议方面：一、成书语境，"瓦官寺应毛喜之请"出自传记系统，讲说场合的细节诸传所记不一；二、此书与《禅门口诀》《禅波罗蜜》等天台禅籍在内容上互有出入，成立先后与文本层次尚有讨论余地；三、"不定止观"的独立性——有学者认为三种止观的划分本身即天台后学的判教安排，本书恰是检验这一判摄的样本；四、十六特胜与六门相配的义理依据，教内与学界解释不尽相同。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 六妙门 | 数、随、止、观、还、净六法，通向涅槃之门 |
| 数息 | 出入息计数摄心之法，六门之首 |
| 随息 | 舍数而心依息之出入 |
| 安般 | 梵语 ānāpāna（入息出息）音译，即呼吸禅 |
| 十六特胜 | 由随息出生之十六种观法，自知息入至观弃舍 |
| 四禅／四无色定 | 色界、无色界诸定，依数息所出生 |
| 不定止观 | 三种止观之一：六门互发、不定次第 |
| 一心三观 | 一念心中即空即假即中，圆观章之所归 |
| 修／证 | 每门皆分修相与证相两阶 |
| 灭谛涅槃 | "妙"之正意，四行中之灭、止、妙、离 |
