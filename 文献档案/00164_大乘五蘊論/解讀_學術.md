# 大乘五蕴论 — 学术解读

## 一、文献背景与成书

《大乘五蕴论》（Pañcaskandhaka，梵名一般作 Pañcaskandhaprakaraṇa）为世亲（Vasubandhu）所造，约成书于公元4-5世纪，是世亲从大乘唯识立场撰写的五蕴法相简明手册。汉译本为玄奘于7世纪（贞观年间）译出，收于大正藏 T1613，一卷。另有唐代释义净系传出的相关论书可资对照。本论篇幅极短，却在东亚唯识学教育中长期充任"启蒙教材"——法相宗的教学次第中，学人多以本论与《百法明门论》为入门二书。

需要说明的是，世亲另有说一切有部立场的《五蕴论》性质著作（《俱舍论》之〈分别根品〉等亦广论五蕴），本论之为"大乘"，在于其以唯识意趣重新界定五蕴的每一项内容，并在行文中预摄大乘法相体系。

## 二、文本结构与核心思想

本论采取"定义式"（lakṣaṇa）文体，开篇即总标：

> 如世尊言：略有五蕴——一者色蕴、二者受蕴、三者想蕴、四者行蕴、五者识蕴。

随后逐蕴定义：**色蕴**者，"谓四大种及四大种所造诸色"——以能造之地水火风四大与所造色合说，是界定色法的定式；**受蕴**为领纳（苦、乐、不苦不乐）；**想蕴**为取像（认知表象的构造）；**行蕴**为造作（以思心所为主的意志与心理活动，除色受想识之外的诸行皆摄于此）；**识蕴**为了别（眼耳鼻舌身意六识，及阿赖耶识等大乘八识义）。四大种之定义为"地界、水界、火界、风界"，并在色蕴细目中开出五根、五境、无表色等。

本论以五蕴统摄百法、开世亲自作《百法明门论》之先河：蕴为粗分，法为细析，粗细相摄而唯识之法相体系立。相较《俱舍论》的五蕴说，本论的显著大乘特征是：将识蕴扩至八识系统，并在行蕴中容纳大乘心所分类的雏形——法相的"零件表"被从部派框架升级为唯识框架。

## 三、学术研究价值与争议

研究价值方面，本论是研究世亲思想从说一切有部转向大乘唯识的关键样本之一：同一作者、同一主题（五蕴）、两套立场（部派《俱舍》系与大乘唯识系）的文本对照，为"世亲转向"这一思想史公案提供了直接证据。同时，本论作为玄奘译籍中最短的唯识论书之一，是考察玄奘译场翻译策略（定义句式的统一、术语的定名）的便利材料。历代汉地注疏以民国以来法相学复兴时期的讲记（如杨文会系统以来的教学）为主流。

争议问题包括：（1）成书先后——本论与《百法明门论》孰先孰后、是否同为世亲晚年作品，学界有讨论；（2）本论的阿赖耶识表述较为简略，它究竟预设了完整的八识体系还是仅有六识加种子说的过渡形态，涉及唯识学文献分期；（3）汉译本与藏译本（若对应传本）在个别法数上的出入，是文本校勘的课题。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 五蕴（pañca-skandha） | 色受想行识，佛教分析"人"与"经验"的五大类 |
| 四大种（mahābhūta） | 地水火风，构成色法的四种基本属性 |
| 所造色（upādāya-rūpa） | 依四大而生的色法（五根、五境等） |
| 受（vedanā） | 领纳，苦乐等感受 |
| 想（saṃjñā） | 取像，表象与概念的形成 |
| 行（saṃskāra） | 造作，意志与心理活动 |
