# 南传律疏·原文

## 一、概述

南传律疏，指南传上座部（Theravāda）所传巴利律藏的注释文献体系，其核心代表作为五世纪锡兰觉音尊者（Buddhaghosa）所撰《一切善见律注》（Samantapāsādikā）。该注为巴利律藏（Vinaya Piṭaka）之全注，依锡兰僧团所传之僧伽罗语古注编译而成，系统阐释经分别（Suttavibhaṅga）与犍度（Khandhaka）之戒律义理。其汉译节译本为《善见律毗婆沙》（大正藏第1462号），系萧齐永明七年（489）僧伽跋陀罗于广州竹林寺译出。巴利原典之罗马字校订本由巴利圣典协会（Pali Text Society）出版。觉音尊者在注中广明制戒因缘、戒条分类、僧团羯磨、安居自恣等律藏要义，为南传佛教律学研究之根本典籍。

## 二、核心段落

### 段落一：归敬偈与结集缘起

**原文：**

> 若人百亿劫，不可思议时，为一切众生，往至疲倦处，正为世间故，南无大慈悲。由法难知故，从生生世间，稽首头顶礼，甚深微妙法。破裂坏消尽无明烦恼网，若戒定智慧解脱具足行，勤修功德者，众僧良福田。我今一心归，头面稽首礼，归命三宝竟，至演毗尼义，令正法久住，利益饶众生。

**白话翻译：**

即使有人在百亿劫那样不可思议的漫长岁月里，为了利益一切众生，走到疲惫不堪的地方，也正是因为世间的缘故，向大慈悲者致敬。由于佛法难以了知的缘故，从生生世世的世间中，以头顶礼拜甚深微妙的佛法。要破除消尽无明烦恼之网，对于具足戒定智慧、解脱行持、勤修功德者，僧团是众生的良福田。如今一心归命，头面顶礼，归依三宝之后，便要演说毗尼（律）的义理，使正法久住世间，利益饶益众生。

### 段落二：律藏结集之记述

**原文：**

> 说曰：律本初说，尔时佛在毗兰若，优波离为说之首，时集五百大比丘众。何以故？如来初成道于鹿野苑转四谛法轮，最后说法度须跋陀罗，所应作者已讖，于拘尸那末罗王林娑罗双树间二月十五日平旦时入无余涅槃。七日后，迦叶从叶波国来，与五百比丘僧往拘尸那国问讯世尊，路逢一道士，迦叶问曰：见我师不？道士答曰：汝师瞿昙沙门命过已经七日，瞿昙涅槃诸人天供养，我从彼得此天曼陀罗华。迦叶与大比丘闻佛已涅槃宛转啼哭闷绝擗地。时有比丘名须跋陀罗摩诃罗言：止止何足啼哭，大沙门在时是净是不净是应作是不应作，今适我等意欲作而作不作而止。时迦叶默然而忆此语，便自思惟：恶法未兴宜集法藏，若正法住世利益众生。

**白话翻译：**

论中说：律藏的开篇记载，那时佛陀住在毗兰若，优波离是诵出律藏的第一人，当时集合了五百位大比丘。为什么如此呢？如来最初在鹿野苑成就佛道，转四谛法轮，最后说法度化须跋陀罗，所应做的事已经完毕，于拘尸那末罗王林娑罗双树之间，二月十五日平旦时分入无余涅槃。七日之后，大迦叶从叶波国来，带领五百比丘僧前往拘尸那国问候世尊，路上遇到一位外道行人，迦叶问他：你见到我的老师了吗？道士回答：你的老师瞿昙沙门命终已经七日了，瞿昙涅槃后诸人天都在供养，我从那里得到这些天上的曼陀罗花。迦叶与诸大比丘听到佛已涅槃，悲痛地辗转啼哭、昏闷倒地。当时有一位名叫须跋陀罗的年老比丘说：好了好了，何必哭泣！大沙门在世时，规定什么是清净、什么是不清净，什么是应作、什么是不应作；现在我们可以随自己的心意，想作的就作，不作的就不作了。这时迦叶沉默地记住了这番话，心中暗自思惟：恶法尚未兴起，应当赶快结集法藏，使正法住世，利益众生。

## 三、名句

1. "令正法久住，利益饶众生。"——归命三宝之后，以演说毗尼义令正法久住，为律藏之根本目的。

2. "恶法未兴宜集法藏，若正法住世利益众生。"——迦叶尊者见佛灭后有比丘放逸，遂起结集律藏之心，此为律藏结集之直接缘起。

## 四、术语表

| 术语 | 释义 |
|------|------|
| 毗尼（Vinaya） | 梵语，意译为律、调伏，指佛所制定之戒律，为三藏之一 |
| 波罗夷（Pārājika） | 戒律中最重之罪，犯者永弃僧团，如人断头不可复活 |
| 犍度（Khandhaka） | 律藏中按事类编排之章品，记载僧团制度与仪轨 |
| 羯磨（Kamma） | 僧团中处理事务之方法，意为"办事"，有单白、白二、白四三种 |
| 安居（Vassa） | 每年雨季三个月间，僧众聚于一处修道，不得游行 |
| 自恣（Pavāraṇā） | 安居期满，僧众集会各自省察有无违犯，请他举过，互相忏悔 |
| 布萨（Uposatha） | 半月一次之诵戒集会，僧众齐聚诵波罗提木叉戒本 |
| 波罗提木叉（Pāṭimokkha） | 戒本，比丘半月一次诵念之戒条总集 |
