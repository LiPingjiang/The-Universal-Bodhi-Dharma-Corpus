# 佛教運動心理學 · 原文

## 一、學科概述

運動心理學研究心理因素與運動表現、運動動機及運動員心理健康的關係；佛教運動心理學則研究禪修訓練在其中的應用。該領域已有清晰的學術軌跡：2009年，費爾菲爾德大學的基思·考夫曼、卡羅爾·格拉斯（Carol Glass）與唐納德·阿恩科夫出版《正念運動表現提升》（Mindful Sport Performance Enhancement, MSPE）手冊，把源自佛教的禪修標準化為運動員訓練模組，開此領域之先河；其後的對照研究顯示MSPE提高大學運動員的流暢狀態、信心與覺察能力。更富傳奇色彩的是喬治·芒福德（George Mumford）：這位曾在毒品與慢性疼痛中掙扎、因禪修獲新生的禪修教師，受籃球名帥菲爾·傑克遜之邀，於1990年代為芝加哥公牛隊（含喬丹、皮蓬）及隨後的洛杉磯湖人隊講授正念，2015年出版《正念運動員》（The Mindful Athlete），成為「禪修進入職業體育」的標誌性人物。

## 二、核心議題與佛教觀點

核心議題包括：（一）表現焦慮與「放手」——運動心理學的經典悖論是「越想打好越打不好」：自我意識的過度監控干擾自動化技能；佛教「無執」與「平常心」恰為對治，正念訓練讓運動員觀察壓力反應而不被捲入；（二）流暢狀態（flow）——契克森米哈賴定義的全神貫注、忘我與行動—覺知合一的最優體驗，與禪定的「心一境性」高度同構，MSPE研究報告訓練後流暢量表得分上升；（三）傷病康復與職業轉換——運動員身份認同的喪失、傷後復出的恐懼，正念接納訓練有助於心理康復；（四）瑜伽與身心訓練——印度傳統瑜伽（與佛教禪定同源）作為運動輔助的證據積累已久。佛教方面，《佛遺教經》「若勤精進，則事無難者」確立佛教對世間技藝成就的基本態度：恰當的努力配合禪定訓練，世法與道法互資。

> **經典依據**：
> 「汝等比丘，若勤精進，則事無難者，是故汝等當勤精進，譬如小水常流，則能穿石。」——《佛遺教經》（T384）

精進（vīrya）是佛教六度之一，但佛教的精進是「不放逸亦不強求」的持續努力——運動心理學的證據同樣表明：穩定的訓練節律與賽前的情緒接納勝過臨場的意志硬頂，此即「小水穿石」的運動版本。

## 三、代表學者與實踐

芒福德的故事始於波士頓：他在麻省大學醫療中心接受卡巴金MBSR課程而走出成癮與疼痛，後隨禪師修行，1993年起在菲爾·傑克遜執教的公牛隊開設靜坐課程，助球隊在王朝時期維持心理穩定；傑克遜自著《神奇的心靈朝聖》多次提及這段合作。考夫曼與同事的MSPE項目則走學術路線，以大學擊劍、足球、長跑運動員為對象發表系列研究，並與「覺察訓練」（如職業棒球小聯盟項目）推廣結合。近十年，職業體育界引入正念漸成風氣：NBA、英超、NFL多家球隊聘請正念教練，德國足球國家隊與英國自行車隊亦有報導；奧運心理學會議自2010年代起專設正念專題。學界亦在檢驗機制：腦電與心率變異研究表明，正念訓練降低賽前皮質醇、改善壓力下的運動決策。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 流暢狀態（flow） | 全身心投入、忘我與高度勝任感的最優體驗 |
| 表現焦慮 | 對評價與失敗的恐懼引發的表現受損 |
| MSPE | 正念運動表現提升訓練，考夫曼等開發 |
| 平常心 | 禪宗語，於勝負得失保持不動的心態 |
| 精進（vīrya） | 佛教六度之一，持續而不過度耗竭的努力 |
| 心一境性 | 禪定的定義：心安住於一對象的統一狀態 |
