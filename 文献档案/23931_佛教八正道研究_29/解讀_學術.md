# 佛教八正道研究_29 — 学术解读

## 一、文献背景与成书

本条目为「寰宇覺海·菩提法藏」语料库独立文献补充条目，编号 X22417，属第二十九批补充条目。同目录 README 记其状态为「待後續填充內容」，故此份《原文》为名目式纲要：概述一句，枚举八正道名目——正见、正思惟、正语、正业、正命、正精进、正念、正定；正文存两段引文与一张七词项术语表，所录文字与同批 `23921_佛教八正道研究_29`、`23924_佛教八正道研究_29` 两条目全同，当系同批编纂的名目复份。须如实说明：该条目非一部有传译史的独立典籍，而是八正道名目的纲要保存。依同名条目分工原则，`23921_佛教八正道研究_29` 篇从道谛总纲与中道义立论，`23924_佛教八正道研究_29` 篇从戒定慧三学统摄立论，本篇专论八正道的世间与出世间两重结构，即有漏八正道与无漏八正道之判分，三篇互注并观。

两重八正道的判分见于阿毗达磨文献：《大毗婆沙論》与《俱舍論》明判八正道体通有漏无漏，世间八正道是凡夫所修、为有漏取所系，出世间八正道唯圣者无漏心中所摄；南传《清淨道論》亦有「世间道」「出世间道」二重之说。条目第二段引文「此正道者，諸古仙人之所行道，從此得至涅槃」所示「得至涅槃」的指向，在此判分下有了精确的分层含义：世间八正道是趋向涅槃之道，出世间八正道是证得涅槃之道。

## 二、文本结构与核心思想

两重八正道之分，其判准在「体性」而不在「名目」：凡夫依八正道之相而修，持正语、修正业、习正定，此八支为善有漏法，能引生人天善果及定慧资粮，然与取烦恼相杂，故名世间；行者至见道位，无漏智起，八支同一剎那俱起，以无漏慧为体，正见即谛智、正思惟即无漏思惟，乃至正定即无漏心一境性，此为出世间八正道，即四圣谛中道谛的本体。故论书说：道谛唯指无漏八支，而世间八支是能生无漏之因行。

此判分的义理价值有二。其一，回答了「凡夫修行算不算走在道上」的问题：算，但要分清是助道分行还是道体正行——世间八正道如登楼之梯，出世间八正道如已入之室，梯不可废亦不可即执为室。其二，为「正」字的含义立了双重标准：世间之正是相对的正（较邪为正），出世间之正是绝对的正（无漏为正）；引文古仙人道之「古」，于两层各有其义：世间正道亘古而为凡圣所共行，出世间正道亘古而为一切解脱者所同证。术语表七支平列不判两层，正见纲要保存名目之体；两重之义则须待论书而后明。

## 三、学术研究价值与争议

其一，两重判分是有部与经部、南传论书之间的重要议题：有部以八正道体通漏无漏、圣者八支剎那并起之说为特色，经部及譬喻师系统更重次第修相，南传于出世间道的剎那心路（道心一念顿具八支）自有细密解说，三系对勘是部派修道论比较研究的核心段落。其二，「正命」在无漏位如何安立是诸家辩难之一：圣者已离恶命，无漏正命以何为体，论书有「离表无表」诸释，牵动对戒体论的整个讨论。其三，两重结构与修行次第的配置（世间八支圆满后方转无漏，抑或闻思位已具其萌芽）关涉加行位理论，瑜伽唯识系统的三乘修道次第即以此为基架展开，其菩萨地中的八正道释义与阿毗达磨传统详略互见。其四，本条目与 `23921_佛教八正道研究_29`、`23924_佛教八正道研究_29` 两条目名目全同，三篇分别自总纲义、三学义、两重义立论，恰可示范纲要条目「一文多解」的解读空间，亦见编纂者置三条目于同批而未加区分的原始形态。
