# 華嚴一乘教義分齊章

## 一、概述

**大正藏編號**：T1866（《大正新脩大藏經》第 45 冊）

**全稱**：《華嚴一乘教義分齊章》

**別稱**：《華嚴一乘教分記》《華嚴教分記》《華嚴五教章》《五教章》《教義分齊章》

**撰者**：唐·法藏（643—712），賢首大師，華嚴宗三祖，署名「京大薦福寺沙門法藏述」

**卷數**：四卷

《華嚴一乘教義分齊章》是華嚴宗判教理論最重要的奠基文獻，通稱《五教章》。全書以「開釋如來海印三昧一乘教義」為總綱，開為十門：建立一乘第一、教義攝益第二、古今立教第三、分教開宗第四、乘教開合第五、起教前後第六、決擇其意第七、施設異相第八、所詮差別第九、義理分齊第十。

此書的核心貢獻有三：

其一，確立**別教一乘／同教一乘**的區分，論證《華嚴》為超出三乘之外的「別教一乘」，以《法華》火宅喻中「界外露地所授大白牛車」為據。

其二，建立**五教十宗**判教體系。五教為：小乘教、大乘始教、大乘終教、頓教、圓教；十宗為：我法俱有宗、法有我無宗、法無去來宗、現通假實宗、俗妄真實宗、諸法但名宗、三性空有宗（一切皆空宗）、真空絕相宗、空有無礙宗（真德不空宗）、圓明具德宗。

其三，於卷四「義理分齊」門中，從**異體、同體**兩方面論證「一即一切，一切即一」，並詳述十玄門（即「古十玄」）與六相圓融（總、別、同、異、成、壞）。

《五教章》所立十玄與法藏後期《華嚴經探玄記》所立「新十玄」略有出入，學界因此以本書為「古十玄」的代表。

此書註疏極盛，宋代有道亭《義苑疏》、觀復《折薪記》、師會《復古記》、希迪《集成記》，合稱「宋代四大家」；日本則有凝然、鳳潭、普寂等人的大量講錄。

## 二、核心段落

### （一）開章十門

**原文：**

> 今將開釋如來海印三昧一乘教義，略作十門：
> 建立一乘第一　教義攝益第二　古今立教第三　分教開宗第四　乘教開合第五　起教前後第六　決擇其意第七　施設異相第八　所詮差別第九　義理分齊第十

**白話對照：**

現在將要開演解釋如來在海印三昧中所宣說的一乘教義，大略分作十個門類：

第一，建立一乘——確立華嚴一乘教的地位；第二，教義攝益——辨明教與義如何攝受利益眾生；第三，古今立教——梳理古今各家判教之說；第四，分教開宗——分判五教、開列十宗；第五，乘教開合——論述「乘」與「教」的開合關係；第六，起教前後——說明諸教興起的先後次第；第七，決擇其意——抉擇判教的用意；第八，施設異相——列舉一乘不同於三乘的種種異相；第九，所詮差別——辨析各教所詮法義的差別；第十，義理分齊——闡明華嚴義理的究竟分限。

### （二）別教與同教、性海果分與緣起因分

**原文：**

> 初明建立一乘者。然此一乘教義分齊，開為二門：一別教，二同教。
> 初中二：一、性海果分，是不可說義。何以故？不與教相應故，則十佛自境界也。故《地論》云「因分可說，果分不可說」者是也。二、緣起因分，則普賢境界也。此二無二，全體遍收，其猶波水，思之可見。

**白話對照：**

第一門「建立一乘」。這一乘教義的分限，開為兩個門類：一是別教，二是同教。

先說別教，其中又有兩重：

第一是「性海果分」，這是不可言說的境界。為什麼呢？因為它不與言教相應，那是十身佛自證的境界。所以《十地經論》說「因分可以言說，果分不可言說」，指的正是這個。

第二是「緣起因分」，這是普賢菩薩的境界。

這兩者其實並非二物，全體互相遍攝收盡，就像水與波的關係一樣——思量一下便能明白。

### （三）分相門：別教一乘別於三乘（法華三車喻）

**原文：**

> 就普賢門，復作二門：一分相門，二該攝門。
> 分相門者，此則別教一乘別於三乘。如《法華》中，宅內所指門外三車，誘引諸子令得出者，是三乘教也；界外露地所授牛車，是一乘教也。

**白話對照：**

就普賢境界這一門，又分作兩個門類：一是分相門，二是該攝門。

所謂「分相門」，是說別教一乘有別於三乘。就像《法華經》火宅喻中所講的：長者在宅內指著門外的羊車、鹿車、牛車三車，誘引諸子出離火宅，這三車比喻的是三乘教法；而諸子出到界外空曠露地之後，長者另外賜與的大白牛車，比喻的才是一乘教法。

### （四）權實差別

**原文：**

> 然此一乘三乘差別，諸聖教中略有十說。一權實差別。以三中牛車亦同羊鹿，權引諸子，務令得出，是故臨門三車，俱是開方便門；四衢道中別授大白牛車，方為示真實相。

**白話對照：**

這一乘與三乘的差別，在諸聖教中大略有十種說法。第一是「權實差別」。

三車之中的牛車（菩薩乘），其實與羊車（聲聞乘）、鹿車（緣覺乘）一樣，都只是權巧方便，用來引誘諸子，務求讓他們出離火宅。所以說，停在門口的那三輛車，全都屬於「開方便門」；只有到了四衢道中另外授與的那輛大白牛車，才是「示真實相」。

（按：這正是法藏判《法華》「會三歸一」之一乘為「同教一乘」，而《華嚴》直顯本法之一乘為「別教一乘」的理據所在。）

### （五）一乘十異中的「所依異」與「時異」

**原文（依卷一十異之義）：**

> 一、時異，謂此一乘教義在初時二七日中宣說，猶如日出先照高山，又於此初時攝一切時，無前際後際之隔。
> 二、處異，謂此一乘教義在蓮華藏世界海中眾寶莊嚴之菩提樹下宣說，攝七處八會及其餘不可說不可說諸世界海於此中，即以一處攝一切處。
> 五、所依異，謂此一乘教起，依佛之海印三昧中出，不同於三乘教等依佛之後得智出。

**白話對照：**

第一，「時異」——這一乘教義是在佛成道後最初的二七日（十四日）中宣說的，好比太陽初升時先照亮高山之巔；而且在這最初之時中便攝盡了一切時，沒有前際後際的隔閡。

第二，「處異」——這一乘教義是在蓮華藏世界海中眾寶莊嚴的菩提樹下宣說的，這一處便攝盡了七處八會以及其餘不可說不可說的一切世界海，也就是以一處攝一切處。

第五，「所依異」——這一乘教法的興起，是從佛的海印三昧中流出的；不同於三乘等教法，那是依佛的後得智而流出的。

### （六）六相圓融

**原文（卷四義理分齊門）：**

> 六相者，謂總相、別相、同相、異相、成相、壞相。
> 總相者，一含多德故。別相者，多德非一故，別依止總，滿彼總故。
> 同相者，多義不相違，同成一總故。異相者，多義相望，各各異故。
> 成相者，由此諸緣起成故。壞相者，諸義各住自法，不移動故。

**白話對照：**

所謂「六相」，就是總相、別相、同相、異相、成相、壞相。

**總相**——一個整體含攝眾多功德。（如一間房舍統攝椽、瓦、樑、柱。）

**別相**——眾多功德各自不同，並非渾然一體；各別的部分依止於總體，又正是它們成滿了那個總體。（如椽不是瓦，瓦不是柱，而房舍正由這些構件成就。）

**同相**——眾多義項彼此不相違背，共同成就一個整體。（如椽瓦樑柱同為造舍之緣。）

**異相**——眾多義項互相對望，各各差異分明。（如椽有椽相，瓦有瓦相。）

**成相**——由這些眾緣和合而使整體得以成立。（有椽瓦等，房舍方成。）

**壞相**——各個義項各自安住於自己的法位，並不移動改變。（椽仍是椽，並不因成舍而失其椽相。）

此六相三對，總別、同異、成壞，一一圓融無礙，是華嚴用以說明整體與部分、普遍與特殊關係的根本範疇。

## 三、名句

**其一**

> 性海果分，是不可說義……緣起因分，則普賢境界也。此二無二，全體遍收，其猶波水。

佛自證的性海果分是不可言說的境界，普賢菩薩所行的緣起因分是可以言說的境界；然而這兩者並非二物，全體互相遍攝收盡，就像水與波一樣。

此語出《五教章》開篇「建立一乘」門，是理解華嚴宗全部教義結構的鑰匙。法藏在此劃出「可說／不可說」的界限，同時又以波水之喻取消這一界限的實體性——正因果分不可說，故須藉因分而說；正因因分即果分，故所說者不外果海。這一「不可說而說」的張力，貫穿華嚴宗全部判教與觀行。

**其二**

> 臨門三車，俱是開方便門；四衢道中別授大白牛車，方為示真實相。

停在門口的羊、鹿、牛三車，全都屬於「開方便門」；直到四衢道中另外賜與的那輛大白牛車，才是「示真實相」。

法藏借《法華》火宅喻重新詮釋一乘與三乘的關係，關鍵在於他把三車中的「牛車」（菩薩乘）也判為權教，從而為《華嚴》「界外別授」的別教一乘騰出位置。這一解讀直接針對天台宗「會三歸一」的《法華》一乘說，是華嚴與天台判教之爭的核心文獻依據。

## 四、術語表

| 術語 | 說明 |
|-----|------|
| **教義分齊** | 「教」指能詮的言教，「義」指所詮的義理，「分齊」指層次分限。書名意即：辨明華嚴一乘教法與義理的究竟分限。 |
| **海印三昧** | 佛的根本定。如大海風平浪靜時能同時印現一切物象，佛在此定中同時朗現一切法。《五教章》以此為華嚴一乘教法流出的本源。 |
| **別教一乘** | 有別於三乘、不共三乘的一乘教法，特指《華嚴》。直顯本法，十十法門迥異諸宗。 |
| **同教一乘** | 與三乘相通、該收諸教的一乘教法，如《法華》的會三歸一。同頓同實，攝前四教為方便。 |
| **性海果分** | 佛自證的果地境界，即十佛自境界，不與言教相應，故「不可說」。 |
| **緣起因分** | 普賢菩薩所行的因地境界，可藉言教顯示，故「可說」。 |
| **五教** | 法藏判教體系：小乘教、大乘始教、大乘終教、頓教、圓教。《華嚴》屬圓教中的別教一乘。 |
| **十宗** | 依所詮義理由淺至深分為十宗：我法俱有宗、法有我無宗、法無去來宗、現通假實宗、俗妄真實宗、諸法但名宗、一切皆空宗、真德不空宗、相想俱絕宗、圓明具德宗。 |
| **六相** | 總相、別相、同相、異相、成相、壞相。三對六義，說明整體與部分圓融無礙。源出世親《十地經論》，由智儼、法藏發揚為華嚴核心教義。 |
| **十玄門** | 顯示法界重重無盡的十個法門。《五教章》所立為「古十玄」，法藏《探玄記》所立為「新十玄」，二者在門名與次第上有出入。 |
| **異體／同體** | 卷四論證「一即一切」的兩種進路。異體門就緣與緣互望而論相即相入，同體門就一緣自具多義而論相即相入。 |
| **三車／大白牛車** | 出《法華經》火宅喻。羊車喻聲聞乘，鹿車喻緣覺乘，牛車喻菩薩乘，界外露地所授大白牛車喻一乘。法藏據此判三車俱權、大白牛車為實。 |

## 五、相關文獻

**法藏本人的相關著作**

- 《華嚴經探玄記》（T1733，二十卷）：疏釋《六十華嚴》，其中所立為「新十玄」，可與本書「古十玄」對照。
- 《華嚴金師子章》（一卷）：法藏為武則天說法所作，以金獅子為喻，最簡明地演示十玄、六相與五教，是《五教章》義理的濃縮普及本。
- 《華嚴經旨歸》《華嚴經義海百門》《華嚴策林》《華嚴發菩提心章》《華嚴經關脈義記》：闡發華嚴義理的短篇。
- 《大乘起信論義記》（T1846）：以華嚴立場詮釋《起信論》，其中所立「四宗判」與本書五教判有別，是研究法藏思想演變的重要材料。

**前行淵源**

- 杜順《華嚴法界觀門》：華嚴三觀，一宗之濫觴。
- 智儼《華嚴一乘十玄門》（T1868）：古十玄的直接來源。
- 智儼《華嚴經搜玄記》（T1732）、《華嚴五十要問答》《華嚴經內章門等雜孔目章》：法藏教義的師承所自。
- 世親《十地經論》：六相義的出處。
- 《妙法蓮華經》〈譬喻品〉：火宅三車喻的原典。

**後續註疏與發展**

- 澄觀《大方廣佛華嚴經疏》（T1735）、《隨疏演義鈔》（T1736）：華嚴四祖對法藏教判的繼承與調整。
- 宗密《原人論》（T1886）、《禪源諸詮集都序》（T2015）：華嚴五祖將五教判擴展為含攝儒道的判教體系。
- 宋代四大家註疏：道亭《義苑疏》、觀復《折薪記》、師會《復古記》、希迪《集成記》。
- 日本：凝然、鳳潭、普寂等華嚴學者的大量講錄。
