# 經量部論典 — 学术解读

## 一、文献背景与成书

经量部（Sautrāntika，亦名说经部、经部）约于佛灭后四百年顷（约公元二世纪）从说一切有部分出，是上座部系中最后兴起的大部派。其部名宣示立场：以「经」（佛说）为量（权威），反对有部以《发智论》等论书为「一身」的立场——凡论书与经抵触者，舍论从经。

需如实说明：经量部没有独立完整的论书文库传世，其思想主要保存在三部「他者文献」中：世亲《阿毗达磨俱舍论》（T1558）破有部而屡采经部之说；众贤《阿毗达磨顺正理论》（T1562）为护有部而系统转述并批驳经部义（尤其是对上座室利逻多）；诃梨跋摩《成实论》（T1646，后秦鸠摩罗什译）被视为深受经量部思想影响的独立论书。经部祖师相传为迦多衍尼子之后的鸠摩罗逻多（童受，Kumāralāta），主论师为室利逻多（Śrīlāta，胜受）；法胜《阿毗昙心论》、法救《杂阿毗昙心论》之间的譬喻师传统，被视为经部的思想前身。

## 二、文本结构与核心思想

经量部宗义散见《俱舍论》《顺正理论》等，其荦荦大者：

1. **过未无体**：过去、未来法无实体，唯现在刹那实有——针对有部「三世实有」的根本否定。
2. **种子说（bīja）**：业力以「种子」形态熏习于心（或心相续），待缘感果。种子六义（刹那灭、果俱有、恒随转等雏形）后为唯识学直接继承，是佛教业力理论的关键跃进。
3. **色心论**：不立「无表色」为实色，业属思心所；色法心法皆刹那灭，以「相续」解释记忆与轮回。
4. **细意识与一味蕴**：经部或立细意识为结生相续之依，上承说转部「一味蕴」之说，下开大乘唯识「阿赖耶识」之先河。

## 三、学术研究价值与争议

1. **思想史的枢纽**：经部处于部派与大乘的交接点——其种子说、细意识说被学界（如印顺《说一切有部为主的论书与论师之研究》、上田义文等）视为唯识学最直接的部派渊源。
2. **《成实论》归属之争**：《成实论》属经部抑或另成一系（有学者联系于说假部、多闻部等），自吉藏以来聚讼千年，是汉传佛学史的经典公案。
3. **「上座」身份之谜**：《顺正理论》所破的「上座室利逻多」，其所著《经部毗婆沙》全佚，仅能从驳文中钩沉，其学说的完整性至今无法复原。
4. **譬喻师与经部的关系**：从《大毗婆沙论》所载譬喻师（如大德法救）到经部的演变链条，是部派思想史研究的重要课题。
