# 佛教四依止研究_19 — 学术解读（认识论与修行实践角度）

## 一、文献背景与成书

本目录原文档为综述性条目，以「四依止」（梵 catvāri pratisaraṇāni）为纲，录四名及文句二段，附术语对照，属专题式汇编而非一经之完整录文。档案库中另有同名条目 `18953_佛教四依止研究_19`（诠释学与判教角度）及近名条目 `18954_佛教四依法研究_19`（名相与翻译流变角度），三目互注；本条则聚焦四依止的认识论内涵与其在修行实践中的操作层面。

汉译文献中四依止的阐明，以《大般涅槃經》系与《大智度論》卷九为著。原文档概述所列名次（依義居首）与正文引文（依法居首）存在参差，今以原文档为准并如实注明。从修行论看，四依止不是抽象原则，而是佛弟子在「佛灭度后依何而住」这一根本问题上的回答——佛陀入灭，权威缺位，僧团与个人皆须一套不依人而自立的修道判准，四依止正是此判准的经典表述。

## 二、文本结构与核心思想

原文档五节式编排：概述列四名，选录与名句二段，末附术语表。核心段落「佛告比丘：有四依止——依法不依人、依義不依語、依智不依識、依了義不依不了義」为标准表述；「於此四法生決定解，則不為他教所轉，直入大乘正理」则标出修证目标：决定解（不动信）的成就。

从认识论角度解析，四依止中最富理论张力的一对是「依智不依识」。识（vijñāna）是了别之心，依根尘而生、带名言分别，是有漏认知的基本形态；智（jñāna）则指离妄显真的如实知。唯识学以「转识成智」为修道总纲——转八识成四智，正是「依智不依识」在宗派理论中的极致展开。「依法不依人」在修行实践中的落点则是师承问题：师为指月之指，非月本身，善知识可贵而不可执，执人则门户生、依法则大道公。「依义不依语」于持诵讲经中化为「得意忘言」的功夫，「依了义不依不了义」则使行者于次第法门中不迷权实。四者皆可在日常修行中一一操作，非徒玄谈。

## 三、学术研究价值与争议

研究价值方面：其一，「智／识」之辨是佛教认识论的核心议题，四依止为其最古老的表述之一，上可接阿毗达磨心心所分析，下可通唯识转依理论与如来藏系的「智如合一」说，线索绵长。其二，「依法不依人」为研究佛教权威理论提供经典依据——与「以戒为师」「自依止、法依止」诸说合观，可见佛教在领袖缺位后维持正统的独特机制，宗教社会学界屡有称引。其三，四依止在禅门中的实际运用（如「依经解义，三世佛怨；离经一字，即同魔说」式的张力表述）是考察中国禅宗经典态度的好材料。

争议问题主要有二：一是「依智不依识」的「智」由谁认证——未证言证的修行人如何避免以识冒智，此在修证伦理上是真实的困难，传统以善知识印可为对治，而印可本身又涉「依人」之嫌，构成微妙的循环；二是佛灭后「依法不依人」与僧团制度权威之间的历史张力，部派分裂的教训表明，四依止可为止诤之具，亦可为各执之资。

沿用原文档所附对照，酌加注记：

| 梵/巴语 | 汉语 | 英译 |
|---|---|---|
| Catvāri-pratisaraṇāni | 四依止 | four reliances |
| Dharma | 法 | Dharma |
| Artha | 义 | meaning |
| Jñāna | 智 | wisdom |
| Vijñāna | 识 | consciousness |
| Nītārtha | 了义 | definitive meaning |
| Aneyārtha | 不了义 | provisional meaning |

按：智（jñāna）与识（vijñāna）同根异词，识为一般了别，智为证真之知；「依智不依识」后成为唯识与如来藏系诠释「转依」的经典依据之一，理论负载极重。
