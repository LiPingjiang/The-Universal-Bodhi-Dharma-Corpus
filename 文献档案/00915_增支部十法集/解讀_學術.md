# 增支部十法集 · 学术解读

## 一、背景部类

《十法集》（Dasakanipāta，巴利文）是南传巴利三藏《增支部》（Aṅguttara-nikāya）的第十集，处于增支部按法数递增体系的靠后位置，收录以"十"为法数的经典二百余经。《十法集》的教学地位重要，举凡十不善道与十善道、十波罗蜜、十圣居法、十遍处、十随念等，都以十为纲目加以系统组织。

在部类归属上，《十法集》属"经藏"中的《增支部》。它与第一至第九法集共同构成增支部以法数立教的完整结构，处于从九法集转至十一法集的过渡环节，把修行所涵盖的善恶业道与种种德目品阶详细铺陈。其对应的汉译内容，仍集中见于《增壹阿含经》（T125）中涉及"十"法的经卷，此外在《中阿含》等相关经典里也能找到相应教说。

本集的教理地位，在于它把"业道"观念落实为明确的十善十恶体系，这是南传上座部伦理教义的重要根基，也反映了原始佛教对"身口意三业"善恶落实的分类教学。纯陀铁匠子经于此破斥外道仪式的"净化"，直指内心的十善十恶，正是本集精神的典型表达。

## 二、结构与核心思想

《十法集》的核心内容可从三大主题来提纲领。

其一为"十随念"（dasa anussatiyā），即对十种对象的偏引导的忆念：念佛、念法、念僧、念戒、念施、念天、念出入息、念身、念死亡、念寂静（涅槃）。这十种随念构成修行者"置心一处"的常用方便，尤其"念出入息"（ānāpāna）与"念身"为后世禅修传统所重，亦为修止观入门的方便，被广泛采取。

其二为"十不善道与十善道"（dasa akusala-kammapathā，dasa kusala-kammapathā）。其中十不善道指身三（杀生、偷盗、邪淫）、口四（妄语、两舌、恶口、绮语）、意三（贪欲、瞋恚、邪见）；十善道则是远离这些恶行、奉行相应善法的正面德目。这是道德实践与因果业报理论的纲要，是《十法集》训诫的核心。

其三为"十波罗蜜"等具足修德的体系，包括布施、持戒、出离、智慧、精进、忍辱、真实、依止（净意）、慈心、舍心等十种波罗蜜，另有十圣居法、十遍处等。特别是十波罗蜜，将菩萨道的修德德目化为具体完整的十级品阶，把修行者的道德与实践功夫一一落到可行的纲要之上。

《十法集》的总体旨趣，在于"以十为纲目，分摄身口意三业与一切善法"。它既从反面厘清当断的十不善道，又从正面建立当修的十善道与十波罗蜜；既提供随念、念处的方便入观，又相机落入业报功德的殊胜。把一个修行人的道德与心念修养，安放于具体而可执行的法数骨架之内。

## 三、价值与汉译对应

《十法集》的学术价值，首在它是研究"十善十恶""十波罗蜜"等核心概念原始出处的第一手文献。其次，"十随念"对后世念处与普遍禅修传统具有纲领意义；"十不善道"更是南传律与伦理教义的枢纽。

汉译对应上，《增壹阿含经》保留部分涉及"十善十恶"与"十随念"的内容，可对补。《佛说十善业道理》（T600）等汉译经典以十善业道为题展开，与《十法集》纯陀铁匠子经开示的精神相通。现代学术常以巴利《十法集》与汉译十善经典互证，考察十业道在各部派与其他佛教传统中的讲述差异。

《十法集》中"十随念"传至后世，化为汉地"十念往生""十想观"等不同展开；"十波罗蜜"则与汉传菩萨道大乘十地、十度互有分别与交涉，显示"十"法教义在佛教史上既同源又多向开展的图景。

## 四、术语

| 术语（巴利/梵语） | 汉译名 | 释义 |
|---|---|---|
| Dasakanipāta | 十法集 | 以十为法数的经典结集 |
| Dasavatthu | 十遍处 | 十种遍满观的对象（十一切处） |
| Pāramī | 波罗蜜 | 十种究竟圆满的德目 |
| Kusala-kammapatha | 十善道 | 十种善的业道 |
| Akusala-kammapatha | 十不善道 | 十种不善业道 |
| Anussati / Anusati | 十随念 | 对念佛等十对象的忆念 |
| Kāyika-vācika-mano-kamma | 身口意三业 | 身口意三方面的活动 |
| Musāvāda | 妄语 | 说虚妄（口四之一） |
| Micchādiṭṭhi | 邪见 | 不正见的看待 |
| Satipaṭṭhāna | 念处 | 观者之正念所住处 |

以上术语显示，《十法集》兼具业道规范（十善十恶）、随观修持（十随念）与品德圆满（十波罗蜜）三层内容，是贯通身口意伦理、静观功夫与成佛德目的枢要文献。
