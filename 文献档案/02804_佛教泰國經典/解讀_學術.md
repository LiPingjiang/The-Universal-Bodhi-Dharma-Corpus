# 佛教泰国经典 — 学术解读

## 一、文献背景与成书

本条目是语料库"各国佛教经典"系列中的泰国部分，为综述性条目。它概括的对象并非某一部单独的经，而是泰国的巴利三藏传承史：泰国是当今上座部佛教人口最多、僧团组织最完备的国家，其经典主体即巴利三藏，以泰文字母转写巴利语——与缅甸情形相同，这不是另一部经，而是同一部巴利圣典的泰文转写定本。

条目依泰国史自身的分期框架叙述：素可泰时代（1238–1351）、阿瑜陀耶时代（1351–1767）、吞武里时代（1767–1782）、曼谷（拉达那哥欣）时代（1782 至今）。并指出在泰人政权建立之前，这片土地上已有孟人的堕罗钵底与高棉人的佛教文化，对后世泰国的佛教艺术与义理影响甚深。

条目所记的两个关键事实均可征信。其一，皇室护持是泰国经典传承的核心特征：曼谷王朝自拉玛一世起即以护法为王权合法性的根本，国都"拉达那哥欣"意即"玉佛所在之地"，玉佛供奉于大皇宫玉佛寺，是王权与佛法结合的最高象征——按佛教教义，转轮王礼敬佛法僧、统一四洲，摩尼宝珠正是转轮王七宝之一。其二，近代刊本方面：拉玛四世（蒙固王）出家为僧期间创立法宗派，推动回归巴利原典、严持戒律的改革，他 1833 年在素可泰发现的《坤·兰甘亨碑》是泰文与泰国佛教史的第一手石刻史料；拉玛五世（朱拉隆功）在位期间以现代铅字印刷刊行泰文巴利三藏，并以王室名义赠送给各国图书馆与学术机构，其改革档案已列入联合国教科文组织《世界记忆名录》。

## 二、文本结构与核心思想

条目原文由文献概述、核心段落选录、重要名句、术语对照与相关文献构成。选录的三段经文极有代表性：礼敬世尊文（南传一切佛事的开场句）、三皈依（泰国男子传统上一生至少短期出家一次，受戒即从此三句起）、佛随念（Buddhānussati，赞叹佛陀九种德号）。

佛随念一段尤其重要。它引"Itipi so Bhagavā Arahaṃ Sammāsambuddho, Vijjācaraṇasampanno, Sugato, Lokavidū, Anuttaro purisadammasārathi, Satthā devamanussānaṃ, Buddho, Bhagavā"，即汉传所称"如来十号"的巴利原型：应供、正等正觉、明行足、善逝、世间解、无上士调御丈夫、天人师、佛、世尊。泰国寺院早晚课诵此段，等于每天把"佛是什么"重新定义一遍。这些文句的巴利文字在泰、缅、斯里兰卡、柬、老诸国基本一致，仅发音随各国语音略异——这正是条目想说明的要点：南传世界共享同一部圣典与同一套仪轨定型文句，国别差异主要在文字转写与僧制组织，而非经文本身。

僧制层面，条目指出泰国僧团今分法宗派与大宗派两系，设僧王统领，此"两派僧王制度"为东南亚上座部国家的共同体制。这是理解泰国经典校勘与僧伽教育的制度背景。

## 三、学术研究价值与争议

价值方面：泰国提供了巴利三藏由贝叶写本进入现代印刷时代的完整案例——王室刊印本将一部藏经从寺院藏经阁变为可流通的出版物，是佛教文献史"媒介革命"的典型样本；法宗派的改革则是十九世纪上座部"原典主义"运动的先声，可与同期斯里兰卡的僧团改革相互参照。

争议方面有三。其一，玉佛与王权的解释框架：学界对"摩尼宝珠即转轮王七宝"与玉佛崇拜之间的教理关联，是后世附会的意识形态建构还是当时有意的教义设计，仍有讨论。其二，法宗派叙事：传统史观以法宗派为"纯净改革"、大宗派为"积弊旧制"，近年研究指出这一对立叙事部分源于法宗派自身的文献，需要批判性使用。其三，泰文转写本身造成的文本问题：泰文字母系统与巴利语音并非一一对应，转写本在实际诵读与教学中产生了独特的"泰式巴利语"，这是巴利文献学一个持续的研究课题。
