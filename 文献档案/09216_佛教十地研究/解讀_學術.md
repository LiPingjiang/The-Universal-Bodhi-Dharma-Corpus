# 佛教十地研究 — 学术解读

## 一、文献背景与成书

本条目为语料库「寰宇覺海·菩提法藏」之独立文献补充条目，编号 X7702，通行名目作「佛教十地研究」。需如实说明的是：其《原文》并非一部完整经本或古佚文献的传抄本，而是一份名目式辑录，由十地名目（歡喜地乃至法雲地）、两条选录引文及一份八条目的梵汉术语表构成，属于主题汇编性质的摘要文本；条目 README 自署「待後續填充內容」，可判知编纂者原意是以此保存十地名数与代表文句，留待日后扩充。

十地思想的可考经典依据是《华严经·十地品》。该品在汉译史上长期以单品别行经《十地经》的形态流通，今可考的译本至少有四种：西晋竺法护译《渐备一切智德经》五卷、后秦鸠摩罗什与佛陀耶舍共译《十住经》四卷、元魏佛陀扇多译《十地经》九卷，以及唐代尸罗达摩重译之《十地经》。本条目选录引文「菩薩始入歡喜地，出生大願，以十盡句不可盡故，發大悲心，觀察一切眾生」与《十地品》欢喜地初住之文的意脉相应，「十盡句」正 是欢喜地十大愿所依的十种无尽句（众生界无尽、世界无尽、虚空界无尽等），可视为辑录者对《十地品》系统的知识摘要。

又，元魏天亲造、勒那摩提与菩提流支合译的《十地经论》十二卷为此一品作论释，直接催生了中国北朝的地论学派，并成为后来华严宗判教与观法的重要源头。本条目虽未标明具体所据经本，但其术语表以 Daśabhūmi（十地）领衔、下配诸地梵名，显示编纂所据的是通行的梵汉对音知识，而非某一种特定刻本。

另有一处录文细节当指出：「受佛职位」一句中「职」为简体字混入繁体文本，属写录层面的小疵，于文义无伤，但提示本辑录当出于今人过录，而非旧钞影拓。

## 二、文本结构与核心思想

《原文》的结构是本语料库补充条目的通例，凡五节：一为文献概述，实即十地名目之罗列；二为核心段落选录，含一条原典式引文与一条白话对照；三为重要名句，将上述两条引文复出；四为术语对照表；五为相关文献指引。就体量而言是「以名数摄义」的类书式简目。

其核心思想可以从名目与引文两层读出。名目层面，十地是菩萨修行的十个阶位：初欢喜地（Pramuditā）为初证真如、见平等法界之位，故生大欢喜；第二离垢地持戒清净、远离微犯；第三发光地得闻持陀罗尼而慧光发焰；第四焰慧地修三十七觉分烧烦恼薪；第五极难胜地真俗二智合观、难可制胜；第六现前地般若智现前、入缘起理；第七远行地功用至极、过二乘行；第八不动地无相无功用任运而转；第九善慧地具四无碍辩、说法自在；第十法云地大法智云含众德水、受佛灌顶职位。引文层面，「十盡句不可盡故，發大悲心，觀察一切眾生」点出十地行门以无尽大愿与大悲为体；「於一一地中，修行萬行，漸次增進」则强调阶位的渐次性，即万行修集有次第、有品级，不可躐等。

## 三、学术研究价值与争议

第一，十地思想的来源问题至今聚讼。一说十地阶位滥觞于部派所说的菩萨行位（如说一切有部传出的十地说），大乘经典将其改造充实；一说十地体系本为大乘菩萨行的独立创造，《十地经》先别行成立、后被编入《华严经》成为会中之品。现代学者如吕澂、印顺及比利时学者拉莫特（É. Lamotte）均就此有专门讨论，本条目所存名数与「十盡句」文句，正可为这一文本史问题提供最简明的基础材料。

第二，地论学派与华严宗的诠释分歧。南北朝地论师分南道北道两系，就佛性当现、地体真妄聚讼不休；唐法藏《华严经探玄记》、澄观《华严经疏钞》以六相圆融释十地，把修行阶位转化为法界缘起的展现。本条目引文只取「渐次增进」一义，恰与华严家「行布不碍圆融」之说可相发明，也隐去了顿渐之争的面向，读者当知其为撮要之选。

第三，十地说在藏传传统中与五道（资粮、加行、见、修、无学道）合流为「五道十地」的道次第框架，与汉传华严十地的诠释取径不同。需说明的是，藏传相关的根本论典如《入中论》等传自梵藏传承，不在大正藏编号体系之内，研究者使用时应转检德格版《丹珠尔》等藏文大藏经编目。
