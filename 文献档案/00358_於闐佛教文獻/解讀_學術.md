# 于阗佛教文献 — 学术解读

## 一、文献背景与成书

本档案是地域文献综述类条目，所收为古代于阗国（Gostana，今新疆和田一带）的佛教文献遗存。需要先说明定名与范围：本档案目录题作「於闐佛教文獻」，正文材料亦使用「于闐塞语」的表述；按现代文献学的通行用法，此语言多称「于阗语」（Khotanese），属印欧语系伊朗语支的塞语（Saka）东南方言，档案表中列出的原语名称即 hvatanai，故「塞语」与「于阗语」实指同一文献语言。这些文献不属于汉文、巴利或藏文三藏体系，也不在大正藏编号之列——它们是一批「死而复生」的出土文献，直到十九世纪末二十世纪初才随着敦煌、和田一带写本的流散被发现与解读，其语言本身也是由现代学者重新破译的。

于阗是古代丝绸之路南道的大乘重镇。据玄奘《大唐西域记》所记，于阗崇奉大乘佛法；其佛教文化从魏晋延续至约十一世纪，最后在伊斯兰化进程中湮没。出土的于阗语写本大多为此期产物，大致可分为几类：本土编译的佛教著作、从梵语或汉语译入的经论、以及密教与佛顶尊胜类陀罗尼文献。原档案举出的代表文献包括《贊巴斯塔書》、《于闐语金光明最胜王经》、《于闐國授記》、《僧伽吒經于闐语本》等。

## 二、文本结构与核心思想

档案选录的核心文本是《贊巴斯塔書》（Book of Zambasta）。这是现存篇幅最大的于阗语佛教诗体著作，以供养人 Zambasta 得名，以大乘义理为主，阐释菩萨行、空性与佛身观。档案所录偈颂极好地浓缩了其思想纲领：「凡有生者皆無常，是故當求彼正覺；善行乃是最上道，寂滅即是涅槃。」四句完成了大乘佛教的完整闭环：以无常观破除对现象的执取（凡有生者皆无常），由此引出求觉的动机（当求彼正觉），以善行为修道的主体（善行乃是最上道），以寂灭为归宿（寂灭即是涅槃）。这首偈的特点在于义理浓缩而语言素朴，与同属西北印度语言圈的犍陀罗语《法句经》残本气质相通。

从文献系统看，于阗语佛典呈现出鲜明的「转译枢纽」特征：《金光明最胜王经》《首楞严三昧经》《僧伽吒经》等经的存在，说明于阗既从梵语接受原典，又与汉译传统保有平行对照；而《于闐國授記》一类文献则是于阗本土的信仰历史叙事（于阗建国的佛教传说），已带有强烈的在地化色彩。档案术语表中保留的原语词汇也颇可注意：balysa（佛）等词形显示伊朗语吸收佛教术语的独特路径。

## 三、学术研究价值与争议

研究价值方面：第一，于阗语文献填补了佛教从印度向中国传播链条上缺失的一环——汉译佛经中不少译名与概念经由西域语言的过滤，于阗语材料使这条转译路径部分可见；第二，《贊巴斯塔書》是一部几乎「无原典可对」的本土著作，为研究大乘思想如何在一门印欧语言中被独立表述提供了独一无二的语言学材料；第三，于阗作为法显、玄奘取经路上的大乘中心，其文献与汉文行纪（《大唐西域记》所记于阗条）互证，可重建西域佛教史的地理断面；第四，于阗语晚期塞语文献中与佛教混杂的世俗文书，对研究中亚语言接触与丝路社会极具价值。

争议与问题方面：其一，语言归属与释读——于阗语文献残损严重，释读工作至今仍在推进，不少段落词义未定，档案所录偈颂的汉译亦属意译，细部措辞与原文的对合需要存留余地；其二，写本年代与层累——多数写本为内容互异的抄本残片，一部「书」（如赞巴斯塔书）实际上是学者对散佚残片的重新拼合，各部分的成文先后仍有讨论；其三，于阗佛教的宗派面貌——大乘为主之外，于阗与密教、与毗沙门天王信仰（于阗守护神）的关系，学界重构尚有分歧；其四，于阗佛教衰亡的过程与十一世纪前后写本埋藏（藏经洞式窖藏）的性质，涉及伊斯兰化进程的具体细节，仍依赖考古新发现。本档案为综述条目，所举文献均为存目性质，深入研究须依各写本的专门校勘与刊布。

## 四、术语对照表

| 术语 | 释义 |
|------|------|
| 于阗语（hvatanai） | 印欧语系伊朗语族塞语的于阗方言，古代于阗的书面语言 |
| 贊巴斯塔書（Book of Zambasta） | 现存最大的于阗语佛教诗体著作，以供养人命名 |
| balysa | 于阗语「佛」的词形，伊朗语系统吸收佛教术语之例 |
| 于闐國授記 | 于阗本土的建国与佛教传说文献，授记体叙事 |
| Gostana | 于阗国的自称，见于出土文献的本地拼写 |
| 转译枢纽 | 于阗在梵语—汉语佛典传播链中的中介角色 |
| 寂灭（nirvāṇä） | 于阗语偈颂中直接借用的佛教术语，即涅槃 |
| 供养人 | 出资抄经或造像者，其名常存于写本题记 |
