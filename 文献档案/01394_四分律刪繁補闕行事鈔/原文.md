# 四分律刪繁補闕行事鈔 · 原文

## 一、文獻概述

《四分律刪繁補闕行事鈔》，簡稱《行事鈔》，三卷（依大正藏本分作十二卷，即上、中、下三卷每卷又各分四卷），唐代南山律宗開祖道宣（596–667）律師撰，收於《大正新修大藏經》第四十冊，編號T1804。本書於唐武德九年（626）撰成，貞觀四年（630）再校定。所謂「刪繁」，謂一事之下諸師說法不一、紛紜複出者，一律刪略、只存文證；所謂「補闕」，謂舊說舊義不合時宜者，糾偏補缺——書中收入的梁武帝《出要律儀》、靈裕《寺誥》等，均因賴其收載而得以保存。內容分三十篇，「以方軌行事」為核心，就《四分律》廣律刪繁補闕，並參酌諸律諸家之說、廣引大小乘經論，詳述僧團律行之故實制規，其中「盜戒」之解釋最為詳盡。

本書與《四分律含注戒本疏》（戒疏）、《四分律刪補隨機羯磨疏》（業疏）合稱「南山三大部」，為南山律宗之正依、中國僧團制度之基本典範，一千三百餘年來對漢傳佛教僧伽行儀之確立影響極大，《續修四庫全書提要》譽之為「肥終南揚律藏，刪繁補闕異群宗」。歷代注釋極盛，見於《行事鈔諸家記標目》者六十二家，今存重要者有：唐大覺《四分律鈔批》十四卷、唐志鴻《四分律行事鈔搜玄錄》、後唐景霄《簡正記》、宋元照《行事鈔科》與《資持記》十六卷（或作十二卷）等，其中以元照《資持記》最為精到、流傳最廣；1686年日本僧慈光、瑞芳更將《資持記》編於《行事鈔》文下、元照《科》文繫於其上，題名《三籍合觀》，今有天津刻經處刻本。

## 二、核心段落選錄

> **原文**：「上卷則攝於眾務，成用有儀。中卷則遵於戒體，持犯立懺。下卷則隨機要行，托事而起。」（《行事鈔》序，《大正藏》T1804，卷一）
> **白話對照**：本書上卷統攝僧團大眾之事務，確立行事之儀則；中卷闡明戒體之義，詳述持犯與懺悔之法；下卷則隨機記述日常要行，依具體事項而立篇。此序文為全書三卷之總綱。

> **原文**：據《行事鈔》通行解題所概括其撰述旨趣：「所謂刪繁，是指一事之下，諸師說法不一，紛紜複呈，則一律刪略，只存文證；所謂補闕，是指舊說舊義不合時宜，糾偏補缺。」（據本書解題資料所述）
> **白話對照**：「刪繁」，就是同一件事上各家說法混亂重複時，刪去蕪雜、只留經律明文作證；「補闕」，就是發現舊說過時或不合律意時，加以糾正補足。道宣以「刪繁補闕」自明其非私意造律，而是整理律藏以切於實用。

> **原文**：據南山律學通義所傳，本書於戒體一義「遵《成實論》而論戒體，依大乘教而立終極」：以非色非心之法體釋戒體，復會歸大乘，攝戒歸於心識，為南山宗「分通大乘」之特色。（據《行事鈔》「標宗顯德」等篇義理及律宗史之通行論述）
> **白話對照**：在「什麼是戒體」這一核心問題上，道宣依《成實論》以「非色非心」解釋戒體，同時又以大乘教義作為最終歸趣——這使得源自聲聞律的《四分律》得以會通大乘，成為中國大乘佛教僧團通行的戒律基礎。

## 三、重要名句

> **名句一**：「刪繁補闕，隨機行事」——書名本身即是方法論：刪律藏之繁蕪，補時機之闕失，令律制切實可行。

> **名句二**：「戒是一切善法之基，三學之首」——本書標宗之義，道宣以持戒為定慧之本。

> **名句三**：「盜戒一科，解釋最詳」——中卷釋戒相篇於盜戒不與取之境想、開緣辨析極細，為歷代律師持犯判定之重要依據。

> **名句四**：《續修四庫全書提要》讚語「肥終南揚律藏，刪繁補闕異群宗」——後世對本書地位之定評。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 刪繁補闕 | 刪除律說之繁複、補足行事之缺漏，本書撰述方法 |
| 行事鈔 | 「僧人日常行為之操作手冊」，今謂僧團制度之實務大典 |
| 戒體 | 受戒時領納於心中之防非止惡功能，律宗理論核心 |
| 三大部 | 行事鈔、戒疏（含注戒本疏）、業疏（刪補隨機羯磨疏） |
| 持犯 | 持戒與犯戒之相狀判定 |
| 犍度 | 律藏中有關僧團制度儀軌之篇章 |
| 資持記 | 宋元照為本書所作之注，最通行之釋 |
| 四分律 | 曇無德部廣律，佛陀耶舍、竺佛念共譯六十卷 |
