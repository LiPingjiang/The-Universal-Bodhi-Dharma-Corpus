# 陈垣佛教史籍著作 — 学术解读

## 一、文献背景与成书

本条目所收不是古代译典，而是现代学者陈垣（1880—1971，字援庵，广东新会人）的佛教史学著作群，主要包括《中国佛教史籍概论》六卷（约十余万言）、佛教史专题论文与史学工具书。据原文档，其主要撰作年代在 1920 年代至 1960 年代，即民国至中华人民共和国时期。这批著作自然不在大正藏编号体系之内——它们是二十世纪中国新式佛教史学（所谓「教外学者治佛教史」一路）的奠基之作。

陈垣以史学名家，自学成才，长于目录、年代、校勘、避讳之学，曾任辅仁大学校长、北京师范大学校长。他的佛教研究有两个鲜明取向：一是把佛教史籍当作中国史学整体的组成部分来清理，而非局限于宗教内部叙事；二是以考据方法取代信仰叙事。《中国佛教史籍概论》六卷逐部检讨从梁僧祐《出三藏记集》、慧皎《高僧传》直至元觉岸《释氏稽古略》等佛教史籍的版本源流、内容要旨、史料价值与考订得失，实为一部「佛教史籍的账本」。专题论文中，《明季滇黔佛教考》考证明末清初西南地区的佛教流布，《清初僧诤记》考明末清初东南僧团内部的纷争，《释氏疑年录》以工具书体例考订历代僧人生卒年，皆以坚实史料纠正旧说。工具书《二十史朔闰表》《中西回史日历》则为处理中西回三种历法的换算提供了通用基准，至今仍是文史研究的基本配备。

## 二、文本结构与核心思想

据原文档所列，《中国佛教史籍概论》的卷次安排按史籍时代为序：卷一论《出三藏记集》《高僧传》等六朝史籍，卷二论《历代三宝记》《广弘明集》等隋唐史籍，卷三论《续高僧传》《法苑珠林》，卷四论《宋高僧传》《佛祖统纪》，卷五论《五灯会元》《释氏稽古略》，卷六收其余。这一安排本身就是一部中国佛教史学史的骨架。

其方法论的集中表述，见于原文档所录两段论述。其一论史料价值：「佛教史籍，不独为佛教之史料，亦为中国史学之重要组成部分。其中所载，或涉及政治，或涉及社会，或涉及文化，或涉及中外交通，其价值远不限于一端。」这一立场把佛教文献从「宗教资料」升格为「通史材料」，直接决定了此后数十年中国大陆学界处理佛教文献的基本态度。其二论治学门径：「读佛教史籍，当以目录学为入门，以年代学为基础，以校勘学为工具，以考据学为归宿。四者相辅而行，方能得其真际。」这四句是其一生治学的自我总结，也可视作对清代考据学传统的佛门应用。

对具体史籍的评价亦见其眼力。论《高僧传》曰「体例谨严，文笔雅洁，为中国佛教史传之典范」，肯定其分科立传（译经、义解、神异、习禅、明律、亡身、诵经、兴福、经师、唱导）「条理井然，后之续作者，皆不能出其范围」，同时提醒「其中亦杂有传说附会之处，读者当以批判眼光审慎取之」——典范与批判并举，正是其史学的底色。

## 三、学术研究价值与争议

第一，开「教外考据」一路的先河。陈垣之前，佛教史叙述基本由教内学者承担；他以纯史学家身份系统整理佛教史籍，示范了信仰立场之外的研究可能，深刻影响了后来汤用彤、吕澂等人的工作格局（此为学术史共识，非原文档所载）。

第二，《中国佛教史籍概论》至今仍是佛教目录学的实用导引：它把一部部史籍的成书、卷数、版本、讹误讲得可操作，初学者按图索骥即可入门。其「论一书而带出一代文献」的写法，本身即是体裁创新。

第三，其研究亦有时代局限须予指出：论文写作于民族危机与政治变动的年代，《明季滇黔佛教考》等著作中的选题寄托（借明末遗民僧事寓当世之感），后人多有讨论；其考订结论的个别条目，随着新文献（如敦煌写本、域外所藏）的刊布也有修正余地。但这些属学术推进之常轨，不掩其奠基之功。

第四，须如实说明：本条目原文档为提纲式汇录，所录「重要观点与论述原文摘录」数段，其文字风格与陈垣传世文体一致，惟原文档未标具体出处卷页，引用时宜与中华书局点校本《中国佛教史籍概论》及《明季滇黔佛教考》等通行本核对。本条依原文档所记为准，特此注明。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 史籍概论 | 对史书逐部评介其源流、要旨、价值的著述体裁 |
| 目录学 | 考订书籍名目、卷数、存佚、真伪的学问，陈垣治学之门径 |
| 年代学 | 排比推算历史年代之学，其工具为朔闰表、历日对照诸书 |
| 校勘学 | 比对版本异文、订正讹误之学 |
| 考据学 | 以证据辑事实、下判断的清代朴学传统方法 |
| 疑年录 | 考订历史人物生卒年的著述体裁，如《释氏疑年录》 |
| 纂集体 | 《法苑珠林》等按类目汇编文献的史籍类型 |
