# 佛教四禪八定研究 · 原文

## 一、概念概述

「四禪八定」為色界四禪（初禪、二禪、三禪、四禪）與無色界四定（空無邊處、識無邊處、無所有處、非想非非想處）之合稱，是佛教承襲並重整古印度禪定傳統而形成的完整世間禪定階位系統。其結構以「支分遞捨」為綱：初禪具尋（覺）伺（觀）喜樂一心五支，離欲界欲惡不善法；二禪捨尋伺，內信澄淨，「定生喜樂」；三禪捨喜，「離喜妙樂」，其樂為三界之最；四禪捨樂入「捨念清淨」，不苦不樂——由粗至細、由染至淨，四禪成已，復次第超色想入四無色定，故四禪八定實為一條「漸次遺捨」的階梯：尋伺→喜→樂→色想→空→識→無所有，最後至非想非非想之細想。此系統通於世間與出世間：佛說「四禪是沙門果」（四雙八輩之果位多依禪立），三果不還、四果應供與滅盡定皆以禪定為依；無漏觀慧多依第四禪發，以其捨念清淨、不昧不動故。經文出處見《長阿含經》（T1）卷四遊行經、《雜阿含經》四禪相應諸經；論典以《俱舍論》卷廿八、《清淨道論》分別為南北傳之集大成。本檔案已就色界禪（`05087`、`05090_佛教四禪定研究`）、無色定（`05088_佛教四空定研究`、`05089_佛教四無色定研究`）分篇專述，本篇側重八定合系之階位結構與修行總綱。

## 二、核心經文選錄

> **原文**（《長阿含經》卷四〈遊行經〉，T1）：
> 「時王即升法殿，入金樓觀，坐銀御床，思惟貪淫欲惡不善，有覺有觀，離生喜樂，得第一禪。除滅覺觀，內信歡悅，斂心專一，無覺無觀，定生喜樂，得第二禪。捨喜守護，專念不亂，自知身樂，賢聖所求，護念樂行，得第三禪。捨滅苦樂，先除憂喜，不苦不樂，護念清淨，得第四禪。」

> **白話對照**：
    四禪之定義於此古經一氣呵成：初禪——思惟欲惡之過而離之，具足覺（尋）觀（伺），「離生喜樂」；二禪——覺觀除滅，內心信順澄淨，「定生喜樂」；三禪——捨去喜之踴動，住於正念，唯餘「離喜之樂」，賢聖所求；四禪——苦樂俱捨、憂喜先除，「不苦不樂，捨念清淨」。每一禪的成立，都以捨棄前一禪的支分為門。

> **原文**（《大毗婆沙論》卷八十四所引契經，T1545）：
> 「云何識無邊處？如契經說：超一切空無邊處，入無邊識，識無邊處具足住。是名識無邊處。」

> **白話對照**：
    四禪之上，經文以「超一切……」之公式次第標列無色四定：超一切色想入空無邊處；超一切空無邊處入識無邊處；超一切識無邊處入無所有處；超一切無所有處入非想非非想處。「具足住」即圓滿安住其地——每一階位皆以超越前一階位為入門，八定由此連成一條完整的世間禪定階梯；再加滅受想定（滅盡定），即成九次第定。

## 三、重要名句

> 「有覺有觀，離生喜樂，得第一禪。」（《長阿含經·遊行經》）

> 「不苦不樂，護念清淨，得第四禪。」（《長阿含經·遊行經》）

> 「超一切空無邊處，入無邊識，識無邊處具足住。」（《大毗婆沙論》卷八十四引契經）

> 「於四禪中，第四最勝：捨念清淨，能發無漏。」（論家通說四禪利觀之要義）

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 四禪八定 | 色界四禪與無色界四定之合稱 |
| 尋／伺（覺／觀） | 心之粗推度／細伺察，初禪所具 |
| 離生喜樂 | 初禪之樂，由離欲而 生 |
| 定生喜樂 | 二禪之樂，由定心內淨而生 |
| 離喜妙樂 | 三禪之樂，捨喜猶餘身樂 |
| 捨念清淨 | 四禪之相，苦樂雙亡、正念平等 |
| 具足住 | 圓滿成就而安住其定 |
| 九次第定 | 八定加滅盡定，次第而入之定 |
