# 大乘起信論疏（元曉《海東疏》）

## 一、概述

**大正藏編號**：T1845（《大正新脩大藏經》第 44 冊）

**全稱**：《大乘起信論疏》

**別稱**：《海東疏》《元曉疏》《曉公疏》

**撰者**：新羅·元曉（원효，617—686），海東法師

**卷數**：二卷

**所釋論本**：《大乘起信論》一卷，馬鳴造，梁·真諦譯

### 關於本檔的定位說明

「大乘起信論疏」一名在文獻上至少有三種所指，須加辨別：

1. **法藏《大乘起信論義記》的異名**（T1844／T1846）——見本檔案 01341、01343、01355 諸篇。
2. **宗密《大乘起信論疏》四卷**——法藏述、宗密注，係宗密摘錄法藏《義記》並增入己說而成。因添削過多、每每自加臆斷，歷來有「以鍮換金」之譏。其註疏本有傳奧《起信論隨疏記》、子璿《起信論筆削記》、續法《起信論會閱》等。
3. **新羅元曉《大乘起信論疏》二卷**（T1845）——即《海東疏》。

前兩者的內容已見於本檔案其他各篇。為避免重複、並如實呈現「大乘起信論疏」這一書名下的不同文獻，**本篇專述元曉《海東疏》**。

元曉此疏與隋·慧遠《義疏》、唐·法藏《義記》並稱「起信論三大疏」。其特點是**論旨明晰、文義暢快**，故為後世廣泛引用——法藏《義記》、太賢《內義略探記》、見登《同異略集》、宗密《注疏》等，均大量援引此疏。可以說，法藏《義記》在相當程度上是踵繼元曉而作的。

**本疏的三門架構**（極簡潔，與法藏十門的繁複體例形成鮮明對照）：

- 一、**標宗體**——標舉此論的宗旨體要，謂《大乘起信論》乃大小乘一切眾典之精髓。
- 二、**釋題名**——援引《虛空藏經》《阿毗達磨雜集論》等文，闡述「大乘」諸義。
- 三、**依文顯義**——逐文註解論文，以彰顯論中深旨。

元曉另撰有《大乘起信論別記》一卷（T1845 附），與本疏相輔。後世常將二書合刊，稱《起信論疏記》。

## 二、核心段落

### （一）標宗體：《起信論》的定位

**元曉疏文要義：**

元曉在第一門「標宗體」中，標舉《大乘起信論》為「諸論之祖宗、群諍之評主」——它既是大乘各家論書的根本源頭，又是平息各種諍論的裁決者。

他指出此論的殊勝在於：**開則無量無邊之義為宗，合則二門一心之法為要**。展開來說，它含攝無量無邊的義理；收攝起來，不過是「二門一心」四字。既能開又能合，既博大又簡要，立而無所得、破而無所失，這是《起信論》體大思精之處。

### （二）所釋論文：立義分——法與義

**《起信論》原文：**

> 摩訶衍者，總說有二種。云何為二？一者法，二者義。所言法者，謂眾生心。是心則攝一切世間法、出世間法，依於此心顯示摩訶衍義。

**白話對照：**

所謂摩訶衍（大乘），總的說有兩種。哪兩種呢？一是「法」，二是「義」。

所說的「法」，指的是眾生心。這個心就統攝了一切世間法與出世間法；依託於這個心，便能顯示大乘的義理。

**元曉釋義要點：**

元曉特別著意於為何立「眾生心」而非「佛心」為大乘之法體。他指出：此心在凡不減、在聖不增，眾生心即是如來藏，一切世出世法皆不出此心。立眾生心為法體，正是要指明大乘不在心外別求。

### （三）所釋論文：一心二門

**《起信論》原文：**

> 顯示正義者，依一心法有二種門。云何為二？一者心真如門，二者心生滅門。是二種門皆各總攝一切法。此義云何？以是二門不相離故。

**白話對照：**

所謂顯示正義：依於這一心之法，開出兩種門。哪兩種呢？一是心真如門，二是心生滅門。這兩種門各自都能總攝一切法。

為什麼這樣說呢？因為這兩門並不彼此分離的緣故。

**元曉釋義要點：**

元曉對「皆各總攝一切法」一句的疏解尤為著名。他辨明：若說二門各攝一切法，會有「重複」之疑；然而二門所攝雖同是一切法，而攝法的方式不同——真如門是就「不生不滅」之義總攝，生滅門是就「生滅」之義總攝。同一諸法，隨義門不同而分屬二門，故不相濫、亦不相離。

### （四）所釋論文：心真如門

**《起信論》原文：**

> 心真如者，即是一法界大總相法門體。所謂心性不生不滅，一切諸法唯依妄念而有差別；若離妄念，則無一切境界之相。是故一切法從本已來，離言說相，離名字相，離心緣相，畢竟平等，無有變異，不可破壞，唯是一心，故名真如。

**白話對照：**

所謂心真如，就是那唯一法界的、統攝一切總相的法門本體。也就是說：心的體性本自不生不滅，一切諸法只是依託妄念才顯現出種種差別；如果離開妄念，那就沒有任何境界之相可得。

因此一切法從本以來，就遠離言說之相，遠離名字之相，遠離心所攀緣之相，畢竟平等一如，沒有變異，不可破壞，唯是這一心而已——所以名為「真如」。

### （五）所釋論文：離言真如與依言真如

**《起信論》原文：**

> 言真如者，亦無有相。謂言說之極，因言遣言。此真如體無有可遣，以一切法悉皆真故；亦無可立，以一切法皆同如故。當知一切法不可說、不可念，故名為真如。

**白話對照：**

說「真如」的時候，其實也沒有一個相可得。這只是言說的極致，是藉著言語來遣除言語罷了。

這真如之體並沒有什麼可以遣除的，因為一切法悉皆真實的緣故；也沒有什麼可以建立的，因為一切法都同一真如的緣故。

應當知道：一切法不可言說、不可思念，所以名為「真如」。

**元曉釋義要點：**

元曉以「離言真如」與「依言真如」二分疏釋此段：真如本身超絕名言（離言），但為引導眾生不得不藉言而說（依言）；而所謂依言之說，其功用恰恰在於「因言遣言」——用言語來取消言語。這一詮釋為後來法藏所承。

### （六）所釋論文：本覺與始覺

**《起信論》原文：**

> 所言覺義者，謂心體離念。離念相者，等虛空界，無所不遍，法界一相，即是如來平等法身。依此法身說名本覺。何以故？本覺義者，對始覺義說，以始覺者即同本覺。

**白話對照：**

所說的「覺」的意義，是指心體遠離妄念。那離念之相，等同於虛空界，無處不遍；整個法界唯是一相，這就是如來平等的法身。依於這法身，便稱之為「本覺」。

為什麼呢？因為「本覺」這一概念是相對於「始覺」而安立的；而所謂「始覺」，其實就等同於本覺。

### （七）所釋論文：生滅門與和合識

**《起信論》原文：**

> 心生滅者，依如來藏故有生滅心。所謂不生不滅與生滅和合，非一非異，名為阿梨耶識。

**白話對照：**

所謂心生滅，是說依於如來藏所以有生滅心。也就是：那不生不滅的（真）與生滅的（妄）和合在一起，既不是同一、也不是相異，這就名為「阿梨耶識」。

**元曉釋義要點：**

「非一非異」是元曉疏中反覆致意之處。他強調：若說真妄為一，則真隨妄滅；若說真妄為異，則妄無所依。唯有「非一非異」，方能既說明眾生流轉的機制，又保住還滅成佛的可能。這一「和合識」的詮釋，是《起信論》區別於唯識學阿賴耶識說的關鍵。

### （八）所釋論文：真如熏習

**《起信論》原文：**

> 熏習義者，如世間衣服實無於香，若人以香而熏習故，則有香氣。此亦如是。真如淨法實無於染，但以無明而熏習故則有染相；無明染法實無淨業，但以真如而熏習故則有淨用。

**白話對照：**

所謂「熏習」的意思，好比世間的衣服本身實在沒有香氣，如果有人用香去熏它，它就帶上了香氣。這裡的道理也是這樣。

真如這清淨之法本來實在沒有染污，只因無明的熏習，所以才顯現出染污之相；無明這染污之法本來實在沒有清淨的作用，只因真如的熏習，所以才生起清淨的功用。

## 三、名句

**其一**

> 開則無量無邊之義為宗，合則二門一心之法為要。

展開來說，它以無量無邊的義理為宗旨；收攝起來，它以「二門一心」之法為要領。

這是元曉《海東疏》總論《起信論》最著名的判語，也是中國佛教文獻中概括一部論典最為精警的表述之一。「開」與「合」的辯證，既讚歎《起信論》的博大，又點明其簡要——而真正的用意在於：博大與簡要並非兩事，無量義即是一心，一心即開無量義。元曉的思想風格（後世稱其為「和諍」）在此已見端倪。

**其二**

> 言說之極，因言遣言。

這是言說的極致——藉著言語來遣除言語。

《起信論》此語經元曉疏解而廣為流傳。它回答了一個所有佛教義學都必須面對的難題：既然真如「離言說相、離名字相、離心緣相」，何以還要造論立言？答案是：言說在此不是描述工具，而是自我取消的裝置——它的功能恰恰在於把使用者引到言說止息之處。這與杜順《法界觀門》「泯絕無寄」的三重否定，可謂異曲同工。

## 四、術語表

| 術語 | 說明 |
|-----|------|
| **海東疏** | 元曉《大乘起信論疏》的通稱。「海東」指新羅（朝鮮半島），因元曉為新羅人而得名。 |
| **三門** | 本疏的架構：標宗體、釋題名、依文顯義。較法藏十門遠為簡潔。 |
| **標宗體** | 三門之一。標舉論的宗旨體要，元曉判《起信論》為「諸論之祖宗、群諍之評主」。 |
| **和諍** | 元曉思想的總體風格。主張各家異說各有所見，可會通而不必偏執，與其《十門和諍論》一脈相承。 |
| **一心** | 即眾生心、如來藏心。《起信論》的法體。 |
| **二門** | 心真如門與心生滅門。各總攝一切法而不相離。 |
| **離言真如／依言真如** | 元曉疏解真如的一對範疇。真如本身超絕名言為「離言」，為導眾生而藉言施設為「依言」。 |
| **因言遣言** | 藉著言語來遣除言語。說明依言真如的功用不在建立，而在取消執著。 |
| **阿梨耶識** | 不生不滅與生滅和合、非一非異之識。元曉強調「非一非異」為其樞紐。 |
| **非一非異** | 真如與生滅、如來藏與阿梨耶識的關係。既非同一，亦非相異。 |
| **本覺／始覺／不覺** | 本覺為本具清淨覺性，始覺為修行所發之覺，不覺為無明迷惑。始覺究竟即同本覺。 |
| **真如熏習** | 真如能熏無明而起淨用。《起信論》特有之說，與唯識家「真如凝然」相異，是眾生能成佛的內在根據。 |
| **起信論三大疏** | 慧遠《義疏》、元曉《海東疏》、法藏《義記》。 |
