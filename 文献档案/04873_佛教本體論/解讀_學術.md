# 佛教本体论 — 学术解读

## 一、文献背景与成书

佛教本体论是以现代哲学术语概括佛教对存在、实在、因果、时间、人格与意识之讨论的综述性专题条目。据本库原文档的界定，佛教未必以追问一个最高实体为目标，反而通常从苦、无常、无我与缘起出发，批判把现象认作自性常住的倾向。因此本体论在佛教中必须与解脱论相连：对何者存在的分析，意在解除执取，而非建立另一个永恒本原。

原文档同样强调方法论前提：古典佛典并非依现代学科分类撰成，学科名称首先是研究视角而非古代自称；本条目是问题地图式的综述。库中另有多个同名专题目录（如 `13140_佛教本體論_8`），各自独立撰写，本条目专就本目录原文档立论。

## 二、文本结构与核心思想

原文档五分结构中的义理部分，可概括为两大板块。

第一板块是传统模型的谱系。说一切有部以法的分析与三世实有说处理因果连续；经量部对此提出批判；瑜伽行派以阿赖耶识、三性与唯识论说明经验世界；中观则以空性、缘起和二谛批判任何法具有独立自性。原文档特别警告：这些学说不能被粗略排成实在论—唯心论—虚无论三种标签，因为它们都在回应认识、语言、业果和解脱的复合问题。

第二板块是核心命题的展开。其一，缘起为起点：事物依因缘、部分、命名与认识条件而呈现，故没有不待他物、永恒不变的自性。其二，空性不是什么都没有，而是说一切法不以固定本质自立；正因无自性，生灭、因果、伦理和修行才可能——若万物自性固定，改变与解脱反而无从成立。其三，二谛防止两种偏差：世俗谛中人、疾病、责任依约定与因果有效运作，胜义谛则显示它们不可被究竟分析为自性实体。其四，无我否定的是主宰、常一的我，不否定五蕴相续与道德责任；佛性、如来藏等教义也需依具体经论传统辨析，不宜径自等同形而上学的实体灵魂。经典依据取《中论》观四谛品著名一颂：众因缘生法，我说即是空；亦为是假名，亦是中道义。

## 三、学术研究价值与争议

代表研究方面，原文档举龙树《中论》、世亲《俱舍论》、玄奘译《成唯识论》为三大根本文本；现代研究举韦斯特霍夫《龙树的中观》澄清中观的否定并非虚无论，卡卢帕哈纳从因果与中道解释龙树，汉语学界则推方立天《佛教哲学》与吕澂《印度佛学源流略讲》。这些研究的共同结论是：佛教存在论不能脱离经论和修行目的来读。

争议集中于两处。其一，空性与虚无论的界线问题：这是中观研究中最持久的争论，原文档立场鲜明——空性恰是变化与解脱之所以可能的条件，而非取消世界的断灭；但批评者一直追问：若无自性，因果效力的承载者是什么，此问题贯穿部派至中观的全部论史。其二，跨传统比较的风险：以西方本体论框架整理佛教思想，容易把如来藏读成实体灵魂、把空性读成否定存在，原文档明确要求避免以相似词汇断定思想同一，并主张分层处理经典规范性说法、注疏诠释与研究者理论语言——这一立场与当前佛教哲学研究的方法论共识一致。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 法 | 可被分析与认识的现象、要素或规范，随学派而有不同界定 |
| 缘起 | 诸法依条件而生灭，没有孤立自性 |
| 无自性 | 任何法都不具不依条件而自立的固定本质 |
| 空性 | 诸法无自性的性质，非断灭或虚无 |
| 二谛 | 世俗谛与胜义谛，说明有效安立与究竟分析的差别 |
| 阿赖耶识 | 瑜伽行派解释业种与经验相续的重要概念 |
