# 噶舉派司徒仁波切文集 · 原文

## 一、文獻概述

本檔彙集噶瑪噶舉傳承「大司徒」（Tai Situpa，又譯泰錫度仁波切、廣定大司徒巴）傳承之著作與法教文獻，以當代第十二世大司徒仁波切貝瑪東由寧杰（Pema Tönyö Nyinje，1954– ）為中心。據《第十二世大司徒仁波切簡傳》等資料：大司徒轉世譜系可上溯千年以上，依傳統被尊為彌勒菩薩之化身，其前身包括大成就者多必巴、蓮師二十五弟子之一的登瑪·策夢、譯師瑪爾巴、以及第一世噶瑪巴杜松欽巴弟子卓貢·雷千等；自元代受封「大司徒」名號以來，此傳承成為康區宗教與學術之柱石。噶瑪巴與大司徒歷代互為師徒：由噶瑪巴認證大司徒並為其上師，復由大司徒認證下一世噶瑪巴，此慣例延續至今。

歷代大司徒中，第八世丘吉炯涅（Chökyi Jungne，1700–1774）貢獻最鉅：1727年在德格土司贊助下創建八蚌聖教法輪寺（Palpung），成為噶瑪噶舉與香巴噶舉兩傳承之中心；他也是著名譯師與大藏經學者，在其推動下德格土司興建德格印經院，並主持校刊《甘珠爾》（德格版），為藏文大藏經最佳版本之一。當代第十二世出生於東藏德格白玉農家，由第十六世大寶法王認證，一歲半於八蚌寺坐床；1959年流亡，在不丹、錫金追隨十六世法王完成教育；1975年在印度創建智慧林（Sherab Ling）寺院。1992年，正是第十二世司徒仁波切依十六世法王遺囑認證了第十七世大寶法王鄔金欽列多傑。其著作多為藏文撰述及英文法教輯錄，漢譯流通者如《喚醒沉睡的佛》（Awakening the Sleeping Buddha）等；近年並圓滿給予《甘珠爾》大藏經完整口傳，延續第八世以降之譯經護法傳統。

## 二、核心段落選錄

> **原文**：據《第十二世大司徒仁波切簡傳》所載其傳承源流：「依據傳統，大司徒是彌勒菩薩（未來佛）的化身，從釋尊的年代開始，他曾多次以印度與西藏瑜珈士的外像化現。」
> **白話對照**：在大司徒傳承的自我敘述中，這一轉世系統被視為未來佛彌勒菩薩的化現：從佛陀時代以來，曾多次以印度、西藏大成就者和瑜伽士的形象出現於世，護持佛法。

> **原文**：噶舉傳承之綱領——岡波巴大師四法：「願心趨法，願法循道，願道斷惑，願惑顯智。」此為司徒傳承諸大師講授噶舉法教時共同依止之總綱。（依噶舉派通行傳承之漢譯）
> **白話對照**：願我的心轉向佛法，願佛法趨入正道，願在道上斷除迷惑，願迷惑本身轉化為智慧。這四願概括了從凡夫到成佛的全部過程，是噶舉各支傳承共同的核心教授。

> **原文**：據藏傳佛教史籍與八蚌寺史料所記第八世大司徒之護法偉業：「公元1727年，28歲的第八世廣定大司徒巴丘吉炯涅在德格土司的大力贊助下開始創建八蚌聖教法輪寺」；德格印經院亦在其勸進下興建，後成德格版《甘珠爾》之刊刻因緣。
> **白話對照**：1727年，年僅28歲的第八世大司徒在德格土司支持下創建八蚌寺；其後德格土司又在大司徒的鼓勵下興建印經院、刊刻大藏經——今天舉世公認最佳的藏文《甘珠爾》版本即由此因緣而成。

## 三、重要名句

> **名句一**：「噶瑪巴與大司徒，互為師徒」——噶瑪噶舉傳承延續數百年的認證與傳法慣例，象徵師徒法脈之環環相扣。

> **名句二**：「不要忘記你在廁所裡找到的寶貝！」——傳為第八世大司徒勸德格土司興建印經院之機語，喻指宿願與法寶不可忘失。

> **名句三**：「八蚌」義為「財富集中、人傑地靈之地」——寺名本身即預示其成為康區佛教文化寶庫。

> **名句四**：岡波巴四法（願心趨法、願法循道、願道斷惑、願惑顯智）——司徒傳承與噶舉各支共依之心要。

| 術語 | 釋義 |
|---|---|
| 大司徒（Tai Situpa） | 元明以來朝廷所封轉世尊號，噶瑪噶舉重要活佛傳承之一 |
| 八蚌寺（Palpung） | 第八世大司徒所建，康區噶舉傳承總寺 |
| 德格版《甘珠爾》 | 第八世大司徒主持校刊之藏文大藏經佛說部，公認最佳版本之一 |
| 智慧林（Sherab Ling） | 第十二世大司徒在印度創建之根本道場 |
| 彌勒化身 | 大司徒傳承之傳統認定：為未來佛彌勒菩薩之化現 |
| 祖古認證 | 由傳承上師依授記、遺囑等認定轉世者之制度 |
| 口傳（加持） | 藏傳佛教將完整教典口耳相傳之傳承方式 |
| 康區（Kham） | 東藏文化地理區域，八蚌寺與德格印經院所在地 |
