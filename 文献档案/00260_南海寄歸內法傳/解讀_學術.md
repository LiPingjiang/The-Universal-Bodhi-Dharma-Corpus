# 南海寄归内法传 — 学术解读

## 一、文献背景与成书

《南海寄归内法传》，四卷，唐代义净（635—713）撰，收于《大正藏》第五十四册（No. 2125）。义净字文明，俗姓张，齐州人，仰慕法显、玄奘之高风，于咸亨二年（671）自广州取道南海（室利佛逝，今苏门答腊）赴印，遍学于那烂陀等地，前后二十余年；武周证圣元年（695）赍梵本经论四百部归国。本书约于天授二年（691）撰于室利佛逝，托人附舶寄回国内，故名"寄归"——是中国著述史上少见的"海外寄稿"。

"内法"指佛教（内学）戒律仪轨。义净西行的核心动机与法显一脉相承：痛感汉地戒律实践紊乱，"传受讹谬，违律失科"，故亲赴印度、南海实地考察僧团生活，将"如法"的僧制逐条记录寄回，供中土僧团矫正之用。

## 二、文本结构与核心思想

全书四卷四十章（另有番数等），以僧团生活的时间与制度为序：从出家受戒的仪式（破夏、受戒轨则）、日常行持（食坐小床、餐分净触）、病药的料理、穿衣的规制、洗浴的仪则，到布萨、安居、自恣、随意（功德回向）等律制节日，乃至"进用门徒""衣食须省"等僧团管理细则，逐章比较印度、南海与中国之异同。核心思想可归为三点：

1. **以根本说一切有部律为正宗**。原文所示："其要在明四部律之轨则，辨根本说一切有部之传承。"义净遍考四部律（十诵、四分、僧祇、五分）流行区域后，判定根本说一切有部律为当时印度最盛、最可依循之传承，故归国后尽译此部律典（与《金光明经》等同为武周时期译业大宗）。

2. **"虽途不同，戒体是一"的会通观**。名句所云："四部律者……虽途不同，戒体是一。凡布萨安居，各有仪轨。"义净的立场是考据的而非宗派的：细辨诸部轨则之异，同时承认戒体无别——这为汉地（行四分律）与印度律统之间的关系留出了弹性。

3. **戒为菩提之本**。"凡是出家，先受沙弥十戒，次受具足戒。戒为无上菩提本，应当一心持净戒"——全书的根本关怀：修行的大厦建立在律仪的地基上，地基不清，上层建筑终必倾颓。

## 三、学术研究价值与争议

**研究价值**：本书是7世纪印度与东南亚佛教僧团生活最详尽的第一手记录：（一）研究印度佛教寺院经济、僧人日常生活（饮食、医药、衣着、卫生——如齿木刷牙、沐浴制度）的资料宝库，也是中外物质文化交流史（牙刷传入中国的最早记录之一即在此）的名典；（二）室利佛逝等南海古国的史料极为稀缺，本书与义净《大唐西域求法高僧传》是研究7世纪海上丝绸之路与东南亚佛教的两根支柱；（三）对四部律流布区域的记录，是印度佛教部派史地理重建的基本材料。

**代表学者**：王邦维《南海寄归内法传校注》（1995）为集大成整理本；日本学者高楠顺次郎早年英译（1896，伦敦）使本书进入西方学界，是近代西方了解印度佛教僧制的经典文献；法国学者沙畹、伯希和一系对义净文献中南海史地的考订亦多。

**争议问题**：其一，义净对根本说一切有部律的推崇与汉地已行四分律的落差——其"矫正如法"的药方并未被中土僧团整体采纳（汉地律宗终以四分立宗），何以如此，是律学史的重要问题；其二，本书所述是否即全印通行的标准实践——印度各地部派互异，义净所见主要是那烂陀一带的规范，其代表性需限定；其三，若干名物（如"立地"糖、药品名）的比定，涉及中外交流史的细部考证，学界讨论尚多。

## 四、术语对照表

| 术语 | 释义 |
|------|------|
| 内法 | 佛教（内学）之律仪制度，与"外道"相对 |
| 四部律 | 十诵律、四分律、摩诃僧祇律、五分律 |
| 根本说一切有部律 | 义净所尊印度当时最盛之律统 |
| 布萨 | 半月集众说戒忏悔之法 |
| 安居 | 雨季三月定居修学之制 |
| 自恣 | 安居竟日，众僧互举过失、自恣受谏之法 |
