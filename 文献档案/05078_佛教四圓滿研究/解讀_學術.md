# 佛教四圆满研究 — 学术解读

## 一、文献背景与成书

本条目为语料库「佛教专题研究」系列的主题类综述条目。四圆满（梵 catvāraḥ saṃpadāḥ）在佛教文献中名目多出，原文档如实交代了这一多义现象并作出取舍：以《瑜伽师地论》（T1579）卷五十〈菩萨地·菩提品〉所立如来「无上无等四种圆满」为主轴；其次则《瑜伽师地论》〈声闻地〉卷二十别说的「生圆满」十种（依内五、依外五，修定之前提），卷二十二的邪命与净命之辨；又《大宝积经》等所说增上生之圆满（财位、眷属等人天果报），属人天教法一层。本条以如来四圆满（戒、见、轨则、净命）为核心，理由依原文档：其理论结构最严整，且与 `05077_佛教四清淨研究` 之唯识四清净（性、修、果、教）互为表里。

原文档又引卷五十语境：如来菩提有七种最胜，「圆满最胜」即四圆满——「由诸如来，无上无等四种圆满，谓戒圆满、见圆满、轨则圆满、净命圆满，皆悉成就，故名圆满最胜」。四圆满是增上戒学的圆满相，标示佛为戒学之究竟成就者。

## 二、文本结构与核心思想

四圆满之名目与义涵依《瑜伽师地论》如下。一、戒圆满（śīla-saṃpat）：净戒具足，于性罪遮罪皆无毁犯。二、见圆满（darśana-）：正见具足，离于萨迦耶见（我见）等一切恶见取执。三、轨则圆满（ācāra-）：于威仪路、所作事、修善品等一切轨则皆悉成就，于世间无讥嫌。四、净命圆满（ājīva-）：远离矫诈现相、占相吉凶、说得供养等邪命，一切资生如法而得。〈声闻地〉释邪命与净命之对说：「谓为利养恭敬故，矫现异相、诈现威仪、自说功德、占相吉凶、说得供养，如是等类，名为邪命。与此相违，如法乞求、法施所感而自活命，名为净命。」

四者的结构极可注意：戒摄身口之律，见摄心地之眼，轨则摄公共之威仪，净命摄资生之来源——一人之宗教生命，由「行为—见解—做派—生计」四根柱子撑起，四柱皆圆满，方名「圆满最胜」。原文档谓其「以戒摄身口、以见摄心地、以轨则摄威仪、以净命摄资生，成佛之人格基础于是完备」，正是此意。此四圆满之为「戒学」总持：戒律是消极的遮止，四圆满则是遮止之上积极成就的人格相——佛不是「没犯戒的人」，而是四轨皆净、世无可讥的究竟者。

## 三、学术研究价值与争议

四圆满的研究价值，首先在佛格论层面：佛教描述佛果多以神通、相好、智慧立言，如来四圆满却把「人格的无可指摘」置于佛果七种最胜之一，包含生活来源之净（净命）与公共形象之无讥嫌（轨则）——宗教圣者的成德标准被落实到如此日常的层面，是佛教伦理精神极鲜明的表达，为「佛格的人格维度」研究提供了核心文本。其次，「净命圆满」所破之邪命清单（诈现威仪、自说功德、占相吉凶、示异相以博利养）实质是一份针对宗教敛财骗术的古典诊断书，对研究宗教社会学的「神圣性市场化」现象极有对照价值。

争议方面：其一，「四种圆满」名目在阿含与论书层累中含义不一（人天果报之圆满、修行处所之生圆满、如来戒学之圆满），原文档的取舍以《菩萨地》为主轴，是依「结构最严整」之标准，研究者引用时须标明层次，不可混同。其二，「生圆满」十种中依外五事（大师住世、正法流布等）以他力条件为「圆满」，与四圆满之以自德为圆满，两种「圆满」的语义结构不同，如何在一框架内安放，论书本身未尝明言。其三，戒圆满之「性罪遮罪皆无毁犯」与菩萨戒中开遮权变（为利他可开某些戒）之关系，是瑜伽行派戒论中长期讨论的技术问题。

| 戒圆满 | 性罪遮罪一切净戒具足无毁 |
| 见圆满 | 离萨迦耶见等一切恶见之正见成就 |
| 轨则圆满 | 威仪路、所作事、修善品一切轨则成就 |
| 净命圆满 | 远离邪命、如法资身 |
| 邪命 | 矫诈现相等五种不如法之活命 |
| 生圆满 | 声闻地所说修行处所内外十种圆满 |
| 七种最胜 | 佛菩提之七种殊胜（所依、正行、圆满、智、威力、断、住） |
