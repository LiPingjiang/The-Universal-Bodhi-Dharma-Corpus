# 佛教四圓滿研究 · 原文

## 一、概念概述

四圓滿（梵 catvāraḥ saṃpadāḥ）在佛教文獻中有數說，本題以《瑜伽師地論》（T1579）〈菩薩地·菩提品〉所立如來「無上無等四種圓滿」為主軸：《瑜伽師地論》卷五十謂諸佛由「圓滿最勝」故顯無上菩提，即「由諸如來，無上無等四種圓滿，謂戒圓滿、見圓滿、軌則圓滿、淨命圓滿，皆悉成就」。名目：一、戒圓滿（śīla-saṃpat）——淨戒具足，於遮罪性罪皆無毀犯；二、見圓滿（darśana-）——正見具足，離於一切薩迦耶見等惡見取執；三、軌則圓滿（ācāra-）——於威儀、所作、修作等一切軌則皆悉成就，於世間無譏嫌；四、淨命圓滿（ājīva-）——遠離矯詐、現相、激磨、以利求利等邪命，一切資生如法而得。此四圓滿是戒學之圓滿相，因攝戒、見、行、命四軌，故為「增上戒學」之總持標準，佛為究竟成就者。其次，《瑜伽師地論》卷二十〈聲聞地〉別說「生圓滿」十種（依內五：眾同分、處所、依止、無業障、無信解障；依外五：大師、世俗正法施設、勝義正法隨轉、正行不滅、隨順資緣），是修定之前提之圓滿；卷四十九〈菩薩地〉又說波羅蜜多異熟果之「五自體圓滿」。「四種圓滿」亦見於《大寶積經》等所說增上生之圓滿（世間財位、眷屬等報果），屬人天果報之說。本題以如來四圓滿（戒、見、軌則、淨命）為核心，因其理論結構最嚴整：以身口之律（戒、軌則）、正智之眼（見）、資生之淨（淨命）合成佛格之基礎德目，與`05077_佛教四清淨研究`之唯識四清淨（性、果、道、境）互為表裡。

## 二、核心經文選錄

> **原文**（《瑜伽師地論》卷五十〈菩薩地·菩提品〉，T1579）：
> 「由諸如來，以三十二大丈夫相等莊嚴其身，故名所依最勝。……由諸如來，無上無等四種圓滿，謂戒圓滿、見圓滿、軌則圓滿、淨命圓滿，皆悉成就，故名圓滿最勝。」

> **白話對照**：
    佛之無上菩提具七種最勝，其中「圓滿最勝」即四種圓滿：戒圓滿——戒律清淨無缺；見圓滿——正見成就，離我見邊見；軌則圓滿——行住威儀皆如法如律，無可譏嫌；淨命圓滿——以清淨如法之方式活命，遠離五種邪命。此四者以「戒」攝身口、以「見」攝心地、以「軌則」攝威儀、以「淨命」攝資生，成佛之人格基礎於是完備。

> **原文**（《瑜伽師地論》卷二十二〈聲聞地〉釋邪命與淨命之義，T1579）：
> 「云何邪命？謂為利養恭敬故，矯現異相、詐現威儀、自說功德、占相吉凶、說得供養，如是等類，名為邪命。與此相違，如法乞求、法施所感而自活命，名為淨命。」

> **白話對照**：
    「淨命」之反面是邪命：為求名聞利養而詐現奇特之相、自誇功德、占相吉凶、暗示他人布施等。佛之淨命圓滿，即是一切飲食衣服醫藥臥具皆由如法乞求、法施感得，絲毫無矯詐心——修行人資生之淨，與持戒之淨同為增上戒學之兩翼。

## 三、重要名句

> 「戒圓滿、見圓滿、軌則圓滿、淨命圓滿，皆悉成就，故名圓滿最勝。」（《瑜伽師地論》卷五十）

> 「生圓滿者，依內有五，依外有五，總依內外合有十種。」（《瑜伽師地論》卷二十——修處所之圓滿）

> 「戒如大明燈，能照生死暗。」（律藏通偈，戒圓滿之喻）

> 「少欲知足，淨命自活。」（《佛遺教經》之淨命精神）

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 四種圓滿 | 戒、見、軌則、淨命四種圓滿成就 |
| 戒圓滿 | 性罪遮罪一切淨戒具足無毀 |
| 見圓滿 | 離薩迦耶見等一切惡見之正見成就 |
| 軌則圓滿 | 威儀路、所作事、修善品一切軌則成就 |
| 淨命圓滿 | 遠離邪命、如法資身 |
| 邪命 | 矯詐現相等五種不如法之活命 |
| 生圓滿 | 《聲聞地》所說修行處所內外十種圓滿 |
| 七種最勝 | 佛菩提之七種殊勝（所依、正行、圓滿、智、威力、斷、住） |
