# 佛教十遍处研究_28 — 学术解读

## 一、文献背景与成书

本条目为「寰宇覺海·菩提法藏」语料库独立文献补充条目，编号 X22025，属第二十八批补充条目。同目录 README 记其状态为「待後續填充內容」，故其所收《原文》为一篇名目式纲要：概述仅一句，标出地、水、火、风、青、黄、赤、白、空、识十种遍处；正文存两段经体引文及一张九词项的术语对照表。须如实说明：该条目并非一部有译者、有卷次的独立典籍，而是对佛教「十遍处」（十一切处）这一禅观名目所做的纲要式保存。

十遍处之说见于汉译《阿含》及阿毗达磨系统。《中阿含》与《大智度論》等均以「十一切处」之名枚举十种遍处定；说一切有部《大毗婆沙論》与《俱舍論》将其判为八色遍处加空、识二无色遍处，并主张后二遍处唯依无色界定而起；南传上座部则以十业处（十遍处 kasiṇa）之名，将其列为四十业处中的十个，是《清淨道論》定学部分的重镇。本条目所录「十遍處者：地遍一切處……識遍一切處」一段，句式与汉译论书中的通枚举文相合；第二段「若人於地遍作意，增長廣大，周遍一切，無有間隙」则与《清淨道論》所传取相、扩展遍作相的修法叙述相应。另按：本库尚有同题条目 `23542_佛教十遍處研究_28`，二条目正文文字相同而解读分工不同，读者宜互相参照。

## 二、文本结构与核心思想

条目结构为概述、引文两段、名句、术语表与相关文献五部分。其核心思想在于「以一摄万」的所缘革命：修行者拣取地、水、火、风四大种，或青、黄、赤、白四显色，作为专注对象，先取一有限之相（如一块圆土、一片白色曼陀罗），经由反复作意，令此相「增長廣大，周遍一切，無有間隙」，终至心所缘境满世间而无一物可见。八色遍处如是成就之后，转观空间本身周遍，则为空遍处；转观能缘之心周遍，则为识遍处，由此衔接四无色定。

十遍处的位次在传统定学中列于八解脱、八胜处之后，被认为是不净观炼净色之后的进阶功夫：不净观破贪，胜处于色得自在，遍处则令所缘无限扩展。青黄赤白四遍处尤为南北传共许的净色业处，与慈心修法互通；地水火风四遍处则被认为依之易发神通，经典中多见以地遍为基础而现种种神变的记载。条目术语表列 Pathavī、Āpo、Tejo、Vāyo、Nīla、Pīta、Lohita、Odāta 等词，正是南传业处文献的标准拼写，可证编纂时兼采巴利系统材料。

## 三、学术研究价值与争议

其一，十遍处是检验南北传禅法异同的绝佳标本：汉译阿毗达磨以「遍处」摄入解脱、胜处、遍处的三级炼心序列，重在法数与判摄；南传《清淨道論》则给出从「取相」到「似相」再到扩展的完整操作细节，重在教学可执行性。两者对空、识二遍处的界定亦不尽一致，是部派定学比较研究的常设议题。其二，青黄赤白四色遍处与不净观的关系值得注意：有部文献谓遍处须于净色起，故多在不净观转净之后修习，南传则以白遍为四护卫禅之一，取相即可直接入手，安排不同，效果定位亦异。其三，现代学界与禅修界关心 kasiṇa 修法的可复原性：以光点、圆盘为所缘的修法在缅甸、泰国仍有传承，其经验描述与《清淨道論》文本的契合程度，屡有实证报告与研究讨论。其四，「遍处」一词的翻译史（一切处、遍处、周遍处）本身亦为汉语佛教术语史提供了材料。
