# 佛教十遍处研究_28 — 学术解读

## 一、文献背景与成书

本条目为「寰宇覺海·菩提法藏」语料库独立文献补充条目，编号 X22028，属第二十八批补充条目。同目录 README 记其状态为「待後續填充內容」，故此份《原文》为名目式纲要：概述一句标出地、水、火、风、青、黄、赤、白、空、识十种遍处；正文存两段经体引文与一张九词项术语表。须如实说明：该条目非独立成书的原典，而是对十遍处禅观名目的纲要保存。本库另藏同题条目 `23539_佛教十遍處研究_28`，两者《原文》文字全同，编号相承（X22025、X22028），当系同批编纂的名目复份；依同名条目分工原则，彼篇从业处修法与取相次第立论，本篇则从神通所依与所缘转换的角度另作解读，读者宜两篇对读。

十遍处作为名目，汉译《阿含》作「十一切处」；《大智度論》屡引以释禅定神通，谓于八色遍得自在者能现种种变化；南传《清淨道論》明言神变（十八神变）与十遍处修法相通，谓「虚空遍」等的扩展作意是神变之近因。条目所录「十遍處者：地遍一切處……識遍一切處」与「若人於地遍作意，增長廣大，周遍一切，無有間隙」两段，正与上述经论的叙述范式相应。

## 二、文本结构与核心思想

就本篇所取的角度而言，十遍处文本的价值在于揭示「所缘转换」这一禅定技术枢纽。原文「周遍一切，無有間隙」八字，点出遍处所缘的根本特征：所缘被扩展至无有限量、无有中断，心的作意由「择一而系」转为「周遍而持」。这一转换在传统教理中有三层效应。其一为引发神变：经典谓依地遍、水遍等能现多身、穿壁、飞行、身中出火出水等十八神变，其原理即是所缘既遍，心物之间的固定对应被松动。其二为四无量心之近依：慈、悲、喜、舍以一切有情为所缘，所缘本身即是「无量」，故修遍处的扩展功夫与四无量心的放大训练结构同构，青黄赤白四净色遍处尤与慈心光明相通。其三为转入无色定之门：空遍处与识遍处两名目，本身就是空无边处定与识无边处定的所缘描述，十遍处的后半直接嵌在四无色定的阶梯里。

条目术语表所列九词中，地水火风四大与青黄赤白四显色构成「八色遍处」，加上空识二遍即满十数；原表未列空识二项而概述已备其名，此亦纲要体详略互见之一例。

## 三、学术研究价值与争议

从神通角度研究十遍处，首先要处理文献学问题：神变叙述与遍处修法在《阿含》中常相伴出现，学者对二者的教理关联有不同估计，或谓神变是遍处修习的副产品，或谓是依遍处所依禅力别加引发，毗婆沙师与南传论师的解释路径不一。其次，十八神变的名目与十遍处的配合，在《大智度論》与《清淨道論》中各有铺陈，汉传所传较详于喻说，南传所传较详于作意次第，适成对照。第三，空识二遍处的归属争议：有部以为空识二遍处即无色定本身，另有论师以为于无色定心缘「遍」之义更立遍处，两说牵动十遍处与九次第定的关系图。第四，比较宗教学的视野下，以单一色相扩展至宇宙的修法，在其他印度禅定传统中亦有平行现象，佛教文本对之的改造与判摄，是研究佛教与印度宗教交涉史的材料。本条目虽仅存名目，然其以「無有間隙」四字保存了遍处技术最核心的规定性，弥足珍贵。
