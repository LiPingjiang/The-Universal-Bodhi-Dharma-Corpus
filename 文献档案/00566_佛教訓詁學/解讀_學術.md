# 佛教训诂学 — 学术解读

## 一、文献背景与成书

本档案是学科综述类条目，所整理的不是一部单一的佛教典籍，而是一门学科的文献基础与研究方法。佛教训诂学，又称佛教汉语研究或佛经语言学，研究对象是汉译佛经的语言现象。按原档案所述，这一领域的根本命题是：「佛教漢語是漢語歷史文獻語言的非自然變體，是經由佛經翻譯所導致的間接語言接觸的產物」，其中不但有文言文与大量口语、俗语的混合，更有汉语与梵语、巴利语等原典语言的混合。

这一学科的形成背景，是佛经翻译在中国文化史上的独特地位。佛经翻译是中国历史上首次大规模、长时段吸收域外文化的举措——自东汉安世高、支娄迦谶开其端，历鸠摩罗什、真谛、玄奘、不空等译经大家的译业，绵延逾千年，涉及二十余种东方语言。这场旷日持久的语言接触，直接导致汉语词汇的大爆炸：「菩萨」「比丘」「涅槃」等佛教专词、「缘起」「无我」等哲学用语，乃至「世界」「方便」「圆满」这类日用而不自知的语汇，都是这场接触的沉淀物。与此同时，中国佛教解经文献以义疏、文句、集解等形式发展出一整套注疏传统，与儒家传统的章句训诂既有渊源又有区别。现代学术意义上的佛教训诂学，即是在梵汉对勘、汉语史、文献学诸方法的交汇处，对这些现象作系统研究。

## 二、文本结构与核心思想

作为一个学科类条目，其「文本结构」实为研究材料的三个层次。第一层是翻译文本本身：从东汉到北宋的汉译佛典语料，其中混杂的口语成分、俗语成分与原典语言成分，是观察语言接触的天然实验室。第二层是注疏文献：佛家的义（佛学通论）、论（佛典总论）、疏（经文注疏）三类解经文献中，疏类与中国传统章句训诂最为接近，但其解经不取儒家「述而不作」的姿态，而主张「辨体明宗」，具有鲜明的哲学论证特点——训释文本的同时即在进行哲学建构。第三层是工具文献：如《翻譯名義集》一类梵语名相的汉语汇编，是古代佛教训诂的专门成果。

其核心方法论是梵汉对勘：将汉译佛经的语言与原典语言逐段对比分析，发现其中与中土文献有异的语言现象，再综合运用汉语史的各种方法加以考察，借以明确语言接触对汉语演变的影响。研究者据此指出，经由佛经翻译所导致的语言接触大体分为三个阶段：译名探索期、系统对译期与完全归化期。按原档案所引陈明教授之说，佛经翻译研究不应局限于汉文化圈，也不应局限于中古时期，而应在东方文化的宏观视域下观察——跨文化、跨语言是这门学科的基本视野。

## 三、学术研究价值与争议

研究价值方面：第一，佛教汉语是汉语史研究不可绕过的语料——中古汉语的许多口语现象正是靠佛典语料得以保存，佛经白话成分对近代汉语研究尤其关键；第二，梵汉对勘可以为经典文本批评提供语言学证据，同一经典的异译、重译对照是考察翻译规范演变与文本流变的直接材料；第三，这门学科为「佛教中国化」提供了最具体的切面：一个宗教在多大程度上被接受，可以从它留下的词汇与句式中精确测量。

争议与难点方面：其一，佛教汉语的「非自然变体」性质带来了归类的困难——它是文言、是口语，还是一种独立的翻译体语言？各家界定不一，直接影响语料的取舍与结论；其二，梵汉对勘的前提是获得可靠的原典，但大量汉译佛典的梵文原本已佚，对勘只能依靠平行译本间接推断，方法上有其限度；其三，注疏传统与训诂传统的关系：佛教义疏究竟是仿自儒家经师讲经，还是另有印度「邬波第铄」解经传统的来源，学界尚有讨论；其四，数字人文方法的引入（语料库统计、机器辅助对勘）正在改变研究范式，但标注标准与文本校勘的基础工作仍显薄弱。此外应当说明，本档案定位为学科综述，所引多为现代学者论断，与具体典籍类条目性质不同，使用时应注意区分方法论叙述与文献考证结论。

## 四、术语对照表

| 术语 | 释义 |
|------|------|
| 佛教汉语 | 经由佛经翻译形成的汉语非自然变体，混合文言、口语与原典语言成分 |
| 语言接触 | 不同语言因翻译、移民、贸易等接触而产生的相互影响，佛经翻译属「间接接触」 |
| 梵汉对勘 | 将汉译佛经与梵语原典逐段对照，以发现译经语言特殊性的研究方法 |
| 义疏 | 中国佛教解经文献的主要形式，随经逐段敷演其义，兼含训释与义理建构 |
| 辨体明宗 | 佛教解经的基本立场：先辨明经体、再标举宗旨，与儒家「述而不作」相对 |
| 佛教专词 | 因翻译而进入汉语的佛教概念词，如「菩萨」「涅槃」「缘起」等 |
| 翻译名相 | 梵语术语的汉语对应系统，古代以《翻譯名義集》一类工具书汇总之 |
| 重译／异译 | 同一原典的不同译本，对勘研究的基本材料 |
