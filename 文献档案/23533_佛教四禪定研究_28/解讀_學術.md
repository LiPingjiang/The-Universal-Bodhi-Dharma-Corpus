# 佛教四禅定研究_28 — 学术解读

## 一、文献背景与成书

本条目为「寰宇覺海·菩提法藏」语料库独立文献补充条目，编号 X22019，属第二十八批补充条目（目录名后缀 _28）。据同目录 README 所记，其状态为「待後續填充內容」，即尚未形成独立成书的典籍；其《原文》为一篇名目式纲要：文献概述仅一句，罗列四禅别名——初禅离生喜乐地、二禅定生喜乐地、三禅离喜妙乐地、四禅舍念清净地；正文部分仅存两段经体引文与一张术语对照表。因此，本条目的性质是主题纲目，而非一部有传译历史的原典，解读时须如实区分条目所存文字与其所指向的可考教义背景。

条目所录两段引文，与汉译《阿含经》及南传《清淨道論》中反复出现的四禅定型句高度吻合：「離欲離諸惡不善法，有尋有伺，離生喜樂，初禪具足住」云云，是佛教经藏中最稳定的禅定叙述范式之一。四禅学说本身源流极为久远：定型句见于四部《阿含》与巴利《尼柯耶》，禅支的精细分析则由说一切有部阿毗达磨（《發智論》《大毗婆沙論》《俱舍論》）完成，南传分别说部由觉音《清淨道論》集其大成，汉地天台系统又以「离生喜乐地」等命名见《法界次第初門》一系文献。本条目概述所用的四地之名，即沿天台旧目，说明编纂者取材于汉传禅学谱系。

## 二、文本结构与核心思想

条目结构为四段式：概述、核心段落选录（附白话对照栏）、重要名句、术语表与相关文献链接。值得注意的是，置于「白話對照」栏下的第二段文字仍是文言经体（「尋伺息故，內等淨故……」），并非白话；此处依原条目编排如实照录，不代为改动，此点亦提示该条目属草创纲要，体例尚未划一。

其核心思想可概括为「以离为进」的定学阶梯。四禅的每一进阶都以放下前一层的粗相为标志：初禅离欲界之欲与诸恶不善法，具寻、伺、喜、乐、心一境性五支；二禅寻伺息灭，依内等净与心一趣而生定生喜乐；三禅离喜，于乐中住，故称离喜妙乐；四禅并乐亦舍，入不苦不乐、舍念清净之地。引文中「離生喜樂」与「定生喜樂」的对举尤可玩味：前者谓喜乐由离欲而生，后者谓喜乐由定体而发，一外一内，构成禅定深化的内在逻辑。四禅在佛教定学中是世间定的顶点，向上接四无色定，横向则为神通、四无量心与观慧所依，故条目虽小，所指实为整个佛教禅定体系的骨架。

## 三、学术研究价值与争议

就条目本身而言，其价值在于以极简形式保存了四禅的汉传命名系统与禅支术语，可与语料库所藏经论互证。就四禅学说而言，学界长期关注的议题包括：其一，巴利系统与说一切有部系统对禅支的不同安立，如有部于初二禅之间别立「中间定」（无寻唯伺），南传《清淨道論》则以安止心路过程解释禅支生起，两系的五支四目不尽可一一对应；其二，「禅那」一词的汉译史，由 dhyāna 音译为禅那，再省称为禅，其间经历了怎样的格义与定型，是汉语佛教词汇史的公案；其三，四禅是否必须严格次第而入，毗婆沙师有「超定」（超越定）之说，主张利根者可跃入深禅，近现代禅修传承（如缅甸、泰国诸系统）对四禅是否可证、如何印证亦有争论。本条目以「离生喜乐地」等四地统摄四禅，未涉禅支细目，反映的是汉传纲目书一路的讲法，其取舍本身即是一种文献学材料。
