# 摩訶僧祇律疏·原文

## 一、概述

摩诃僧祇律疏，指对大众部所传《摩诃僧祇律》之疏释。摩诃僧祇律收录于大正藏第1425号，凡四十卷，东晋佛陀跋陀罗与法显共译于义熙十四年（418）。梵名Mahāsāṅgha-vinaya，略称僧祇律，意译大众律，为部派佛教大众部所传之广律。法显于隆安三年（399）西行求律，因北天竺诸国戒律皆为师师口传无本可写，故远涉至中天竺，于摩竭提国巴连弗邑阿育王塔南天王精舍抄得梵本，携归中土后与佛陀跋陀罗共同译出。全书分为比丘戒法（卷一至卷三十五）与比丘尼戒法（卷三十六至卷四十）两大部分。比丘戒法详列二百一十八戒，并举杂诵跋渠法一百一十三条与威仪法五十条；比丘尼戒法列举二百七十七戒及杂跋渠法三十四条。此律多处含有大乘经意，在解释中有五十三处引用《本生经》，为其显著特色。

## 二、核心段落

### 段落一：律藏传承之记载

**原文：**

> 据本书卷三十二"五百比丘集法藏"条载，本书系优波离受摩诃迦叶之命所诵出者，其次并记有陀娑婆罗、树提陀娑、耆哆等二十七人之相承，是乃本律传承之记录。

**白话翻译：**

据本书卷三十二"五百比丘集法藏"条记载，本书是优波离受大迦叶之命所诵出的，其次还记载了陀娑婆罗、树提陀娑、耆哆等二十七人的代代传承，这就是本律传承之记录。

### 段落二：波罗夷制定之时间

**原文：**

> 四波罗夷制定之年份，被推定为自佛成道后第五年冬分第五半月至第六年冬分第四半月期间。于所记七百结集律藏中，不举十事非法，却提及制限净等之五净法。内中并载有四十余种本生谭，援引二十余种之本生经。

**白话翻译：**

四条波罗夷法制定的年份，被推定为从佛陀成道后第五年冬分第五半月至第六年冬分第四月半期间。在所记载的七百结集中，不像其他律典那样举出"十事非法"，反而提及制限净等"五净法"。内容中还载有四十余种本生故事（本生谭），援引二十余种本生经。

## 三、名句

1. "佛灭度后，所说法戒，即是汝大师。"——佛陀临终之教诲，以戒法为师，为律藏住世之根本依据。

2. "此律为大众部所奉持，其中多处含有大乘经意，为大乘说法之萌芽。"——指出摩诃僧祇律之特色，对大乘义理有所含摄。

## 四、术语表

| 术语 | 释义 |
|------|------|
| 摩诃僧祇 | 梵文Mahāsāṅgha，意译大众，指大众部 |
| 跋渠 | 梵文Vagga，意译品、聚，律藏中按事类编排之章品 |
| 本生谭 | Jātaka，佛陀前世修行之故事，僧祇律中大量引用 |
| 五净法 | 七百结集中所提及之五项净法，与十诵律所载之十事非法不同 |
| 七百结集 | 佛灭后百年于毗舍离举行之第二次结集，主要处理戒律之争 |
| 杂诵跋渠 | 僧祇律中相当于犍度品之部分，记载僧团行事仪式与日常规范 |
| 威仪法 | 律藏中关于僧尼日常行住坐卧等威仪之规范 |
| 陀娑婆罗 | 律藏传承之第二十七师，为僧祇律传承记录之重要人物 |
