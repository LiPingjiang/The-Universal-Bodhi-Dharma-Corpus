# 菩薩戒本疏·原文

## 一、概述

菩萨戒本疏，指对菩萨戒本之疏释。菩萨戒本有多种传本，主要分为两大系统：一为梵网戒本系统，即鸠摩罗什所译《梵网经》卷下之十重四十八轻戒文，为释尊所说，道俗兼摄之顿立戒；二为瑜伽戒本系统，即唐玄奘所译《菩萨戒本》一卷（大正藏第1501号），出自《瑜伽师地论》本地分菩萨地初持瑜伽处戒品（卷四十及四十一），为弥勒菩萨所说，以三聚净戒、四种他胜处法为基准，通权达变，有开有遮。瑜伽戒本说有四条重戒（摄律仪戒）与四十三条轻戒（摄善法戒与摄众生戒），译于贞观二十三年（649）。古代注疏有元晓之《菩萨戒本持犯要记》一卷、睿尊之《应理宗戒图释文钞》二卷等。瑜伽戒本为地持戒本之同本异译，内容大同小异，然无归敬偈，共举四十三轻戒。

## 二、核心段落

### 段落一：瑜伽戒本之受持要义

**原文：**

> 若诸菩萨，已受菩萨所受净戒，应自数数专谛思惟：此是菩萨正所应作、此非菩萨正所应作。既思惟已，然后为成正所作业，当勤修学。又应专励听闻菩萨素呾缆藏及以菩萨摩呾理迦，随其所闻，当勤修学。

**白话翻译：**

如果诸菩萨已经受了菩萨所受之清净戒律，应当自己一次又一次地专心审慎思惟：这是菩萨正应当作的、这不是菩萨正应当作的。这样思惟之后，然后为了成就正所应作之业，应当精勤修学。又应当专心努力听闻菩萨素呾缆藏（经藏）及菩萨摩呾理迦（论藏），随其所闻之法，精勤修学。

### 段落二：梵网与瑜伽二系之区别

**原文（概述）：**

> 梵网戒本为释尊所说，具明十重四十八轻，为道俗兼摄之顿立戒；瑜伽戒本则以三聚净戒、四种他胜处法为基准，虽亦通摄道俗，然必先受小乘七众戒而久已成就无犯者，方能受持，故为一种渐立戒。梵网戒本较为严格繁琐，受者应绝对依教奉行；瑜伽戒本则较方便善巧，通权达变，是染非犯，有开有遮。

**白话翻译：**

梵网戒本是释迦牟尼佛所说，详细说明十重戒和四十八轻戒，是出家在家皆可受持的顿立戒；瑜伽戒本则以三聚净戒和四种他胜处法为基准，虽然也通摄出家与在家，但必须先受小乘七众戒并且久已成就无犯之人，方能受持，所以是一种渐立戒。梵网戒本较为严格繁琐，受持者应当绝对依教奉行；瑜伽戒本则较为方便善巧，通权达变，虽有染污而非犯戒，有开许也有遮止。

## 三、名句

1. "应自数数专谛思惟：此是菩萨正所应作、此非菩萨正所应作。"——受菩萨戒后须时时自省，思惟何为正行、何为非行，为持戒之关键。

2. "梵网戒有遮无开……瑜伽戒有完整的组织，有开遮的条文。"——概括两大菩萨戒系统之根本差异，梵网重遮止，瑜伽重开遮。

## 四、术语表

| 术语 | 释义 |
|------|------|
| 菩萨戒本 | 菩萨所受持之戒条集录，有梵网与瑜伽两大系统 |
| 瑜伽戒本 | 出自《瑜伽师地论》之菩萨戒本，玄奘译，四重四十三轻 |
| 三聚净戒 | 摄律仪戒、摄善法戒、饶益有情戒 |
| 他胜处法 | 梵文Pārājika之意译，菩萨戒中最重之罪，同波罗夷 |
| 顿立戒 | 不须先受小乘戒即可直接受持之戒法，如梵网戒 |
| 渐立戒 | 须先受小乘戒成就无犯后方可受持之戒法，如瑜伽戒 |
| 素呾缆藏 | 梵文Sūtrapiṭaka，即经藏，三藏之一 |
| 摩呾理迦 | 梵文Mātṛkā，即论藏或本母，三藏之一 |
| 开遮 | 戒律之开许与遮止，瑜伽戒本有开有遮，梵网戒有遮无开 |
