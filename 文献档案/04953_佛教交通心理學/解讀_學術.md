# 佛教交通心理学 — 学术解读

## 一、文献背景与成书

定位需要先讲清楚：「佛教交通心理学」不是古代文献，不在大正藏编号体系之内，「04953」是语料库自编的序列号。它所指称的是一个概念契合度很高、但系统研究仍然零散的现代交叉领域。交通心理学研究人在交通系统中的心理与行为：驾驶认知、驾驶愤怒（road rage）与攻击性驾驶、分心驾驶、疲劳驾驶、行人与骑行者决策，以及自动驾驶时代的人机交互；其旗舰期刊《交通心理学与行为》（Transportation Research Part F）自1998年创刊以来积累了丰富文献。佛教与此的交汇点明确而具体：其一，已有实证研究考察自报告正念与驾驶愤怒、攻击性驾驶的关联；其二，手机时代的「心不在焉」使交通事故成为全球主要死因之一，而佛教「念」的训练直接对治注意力失守；其三，被抢道、被鸣笛瞬间升起的路怒，是佛教瞋恚心理学最日常的观察窗口。原文对自身的判断是审慎的：这是一个佛教概念与交通心理学问题天然贴合、但研究缺口同样大的领域。

## 二、文本结构与核心思想

原文采用学科概述、核心议题、代表学者与实践、术语对照表、相关文献的五节结构，以《法句经》「心為法本」偈为纲领：「中心念惡，即言即行，罪苦自追，如車轢於轍」。汉译《法句经》此颂恰以「车」为喻：恶念如车辙，罪苦随行碾压——在一门以车为研究对象的心理学看来，这是绝妙的古典注脚：交通事故的心理根源在「中心念恶」（瞋怒、急躁、自负），改善交通行为的枢钮在心不在路。五个核心议题：（一）驾驶愤怒——车厢是一个「去个体化」的封闭空间，匿名性降低自我监控，使路怒的频率与强度远超日常冲突；佛教把瞋恚列为三毒之一，其分析是愤怒源于「我」与「我所」（我的路权、我的时间）受侵犯的认知评估，正念训练在愤怒的第一秒插入「观察间隙」，与愤怒管理的「暂停—重评」技术同构；（二）分心与多任务——驾驶中使用手机是典型的「身在此心在彼」，「繫念面前」直指其病灶；（三）风险知觉偏差——年轻男性驾驶者的高估技术、低估风险（「乐观偏差」）与佛教「我慢」「愚癡」的诊断相合；（四）疲劳与单调驾驶的警觉衰退是禅修文献「惛沉」的路面版本，其对治（策举其心）与佛教对治昏沉的方法可资比较；（五）自动驾驶接管中的人因，是「念住」研究的新应用场景。

## 三、学术研究价值与争议

本条目最具价值之处在于三点。第一，它为「瞋恚心理学」找到了最日常的实证场域：路怒每天在千万条马路上发生，是观察「我—我所受侵犯→愤怒」这一经典佛教链条的最佳天然实验室。第二，「念与分心」的对位干净利落：交通心理学对分心驾驶的操作化测量（脱靶反应、视线偏离）可以为「念」的训练效果提供客观指标，这比问卷式正念测量更硬。第三，原文如实记录了制度层面的借用：印度、泰国等佛教文化国家长期以佛教伦理语汇（如泰国以五戒之不害劝导安全驾驶）进行道路安全教育；一些保险与车队管理公司已把正念模块纳入职业驾驶员培训。争议与局限：其一，现有的正念—驾驶愤怒研究多为相关设计，因果方向未定——是正念降低了路怒，还是不易愤怒者自报正念更高？其二，同行评审证据仍待积累，行业培训中的正念模块多缺对照评估；其三，把「策举其心」这类古典技术转译为防疲劳手段，须警惕时序错置——古代禅修对治昏沉的对象是静坐，不是方向盘，迁移应用需要重新验证。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 驾驶愤怒 | 驾驶情境中被他人行为激起的愤怒情绪 |
| 攻击性驾驶 | 以报复或威吓为动机的危险驾驶行为 |
| 分心驾驶 | 注意偏离驾驶任务的状态 |
| 乐观偏差 | 高估自身能力、低估风险的认知倾向 |
| 繫念面前 | 觉知安住于眼前当下的佛教训练 |
| 惛沉 | 禅修障碍之一，警觉低沉的状态 |
| 防御性驾驶 | 预判他人错误以规避事故的驾驶技术体系 |
