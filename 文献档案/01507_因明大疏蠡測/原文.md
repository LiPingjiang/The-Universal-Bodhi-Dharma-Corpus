# 因明大疏蠡測 · 原文

## 一、文獻概述

《因明大疏蠡測》，陳大齊（1886–1983，字百年，浙江海鹽人；曾留學日本、德國研習邏輯學與心理學，中國現代心理學之開創者，曾任北京大學代理校長）著，是首次運用現代方法研究因明學之代表作。本書以唐代窺基《因明入正理論疏》（世稱《因明大疏》）為研究對象：窺基承玄奘口授，歷時十餘年撰《大疏》，未竟之稿由弟子慧沼續補，代表唐代因明研究之最高成就；其書宋元後在中土散佚，1895年楊仁山從日本取回八卷本，1896年由金陵刻經處刻印流通，近代因明研習由此重興。陳大齊自研讀《大疏》至寫成本書，耗時八九年，1938年完成全稿，凡十二餘萬字、分四十二章，以論文集之形式逐題梳理、解釋《大疏》；初稿於1945年8月在重慶鉛印出版，2006年由中華書局列入「真如·因明學叢書」再版。

本書與呂澂之研究並為「五四」以後三十年現代因明研究之雙璧。其特色在於：以西方邏輯學為工具，將因明三支作法（宗、因、喻）與邏輯三段論作系統比較，認為「因明邏輯，二本同理，趨向有別」——二者形式相同，而因明於演繹中兼寓歸納，立量軌式「果先而因後」；又分析因明三支之宗、因及同喻體俱屬全稱肯定判斷，相當於邏輯之AAA式。書中對「體義」作四種分析（各分兩有、兩無、自有、他有），以闡明宗因喻之關係；並辨析同品異品、有體無體、表詮遮詮、全分一分等核心術語，糾正《大疏》關於宗定義之疏失。本書用文言文寫成，多以四字為句，文字極簡練，為初學者帶來不便，然其精審程度至今無出其右者。1952年陳大齊又在此書基礎上撰《印度理則學》敘述因明全貌，1970年八十三歲時出版《因明入正理論悟他門淺釋》，終身以使因明成為易讀之書為志。本書為近代著作，未入大藏經。

## 二、核心段落選錄

> **原文**：陳大齊《因明大疏蠡測·序》：「《大疏》精審，堪為楷式，間有缺陷，亦不容諱。名言分別，界限不清。先後闡述，不相符順。義本連貫，散見不聚。理有多端，掛一漏餘。」（據《因明大疏蠡測》自序）
> **白話對照**：陳大齊對《大疏》的評價是：精深審慎，足以作為楷模；但也有缺陷，不能諱言。哪些缺陷呢？一是概念術語的分辨，界限不夠清楚；二是前後的闡述，彼此不一致；三是本來連貫的義理，散見各處而不聚集；四是道理有很多方面，往往只講了一點而漏掉其餘。這段話既是對《大疏》的持平之論，也列出了《蠡測》一書要解決的全部問題清單。

> **原文**：陳大齊自述其研究方法：「紊者理之，似者正之，晦者顯之，缺者足之，散者合之，違者通之。」並「參證其他疏記，間亦旁證邏輯，以期獲得正解」。（據《因明大疏蠡測》自序及全書體例）
> **白話對照**：這十八個字是《蠡測》的方法論綱領：混亂的使之有條理，似是而非的加以糾正，隱晦的使之明白，缺漏的給以補足，散見的加以會聚，互相違忤的予以會通。具體做法是：拿唐代其他因明注疏來互相參證，必要時再借助西方邏輯學作旁證，以求得正確的理解。以現代學術方法整理中古注疏，而態度又如此謹嚴，故此書成為百年來因明研究繞不開的文獻。

> **原文**：《因明入正理論》開篇之頌（本書所研《大疏》所釋之綱領）：「能立與能破，及似唯悟他；現量與比量，及似唯自悟。」（商羯羅主造，玄奘譯；窺基《大疏》與陳大齊《蠡測》皆依此「八門二益」框架展開）
> **白話對照**：這首頌概括了因明的全部內容：能立（正確的論證）、能破（正確的反駁），以及各自的「似」（錯誤形態），這四門的作用都在「悟他」——使他人開悟；現量（直接的知覺認識）、比量（推理的認識），以及各自的「似」，這四門的作用都在「自悟」——使自己獲得正確的認識。八門二益，即因明之全體大用；《蠡測》四十二章即環繞這一框架，重點在立破悟他一面的宗、因、喻三支論式。

## 三、重要名句

> **名句一**：「內容富贍，為諸疏冠」——陳大齊序中對《大疏》之總評，也是他選擇《大疏》為研究對象之理由。

> **名句二**：「紊者理之，似者正之，晦者顯之，缺者足之，散者合之，違者通之」——本書方法論之十八字綱領。

> **名句三**：「因明邏輯，二本同理，趨向有別」——陳大齊論因明與西方邏輯之關係：根本原理相同，發展取向各異。

> **名句四**：「能立與能破，及似唯悟他；現量與比量，及似唯自悟」——因明八門二益之總綱，《大疏》與《蠡測》共同之義理骨架。

> **名句五**：「果先而因後」——陳大齊對因明立量軌式之概括：論式中先出結論（宗）後出理由（因），與三段論之序相反。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 因明 | 梵語 hetu-vidyā 之意譯，印度邏輯與論辯之學 |
| 大疏 | 窺基《因明入正理論疏》之尊稱，唐代因明集大成之作 |
| 蠡測 | 「以蠡測海」之謙辭，喻淺學者之測度，本書自謙之名 |
| 宗 | 論題、結論，三支之首，相當於三段論之結論 |
| 因 | 證成宗之理由，三支之樞紐，須遍是宗法性等三相 |
| 喻 | 例證，同喻異喻，相當於三段論之大前提 |
| 因三相 | 因須具足之三條規則：遍是宗法性、同品定有性、異品遍無性 |
| 同品異品 | 與宗所立同類、異類之事例，《大疏》主張「同異品除宗有法」 |
| 表詮遮詮 | 表詮直陳其是，遮詮遮遣其非，兩種判斷方式 |
| 全分一分 | 相當於邏輯之全稱與特稱，本書辨析之要題 |
