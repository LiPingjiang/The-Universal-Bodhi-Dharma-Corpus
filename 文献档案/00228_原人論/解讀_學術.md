# 原人论 — 学术解读

## 一、文献背景与成书

《原人论》，全称《华严原人论》，一卷，唐代华严宗五祖宗密（780—841）撰，收于《大正藏》第四十五册（T1886）。宗密，俗姓何，果州西充人，早年习儒，后出家为禅宗荷泽宗道圆之弟子，又受华严宗四祖澄观之教，致力于禅教一致的会通，是唐代佛教思想史上一位会通性的大师。

本书以"推原人之本源"为主旨，针对儒道二教及佛教内部各派对人性和生命起源的种种说法，层层辨析，最终归宗于一乘显性教。宗密写作此书，有其深刻的思想背景：唐代中后期，儒释道三教论争激烈，佛教内部各宗派亦各执己见。宗密欲以华严宗"一乘显性教"为最高标准，统摄一切教法，建立了"五教判人"的体系。此书可视为宗密"禅教一致"思想的延伸——不仅在教法上会通禅教，更在人性论层面会通三教。

## 二、文本结构与核心思想

全书大致分为序言及正文两部分。序言阐明"万灵蠢蠢，皆有其本；万物芸芸，各归其根"的立论宗旨，正文则依次破斥儒道二教、佛教内部小乘、大乘法相教、大乘破相教，最终建立一乘显性教为究竟。

宗密提出"五教"判释人的本源：

1. **人天教**（儒道二教）。认为人由大道、元气、自然等生成。宗密批评此说"未辨本源"，因为元气等本身也是物质性的，属于"所造"而非"能造"，不能解释生命意识的来源。

2. **小乘教**。说人由色受想行识五蕴和合而成，无有实我。宗密认为此说虽破除了"我执"，但未说明五蕴从何而来，根源仍不彻底。

3. **大乘法相教**（唯识宗）。说一切法皆由阿赖耶识种子所生，众生与佛的差别在于种子的染净不同。宗密认为此说虽触及了"心识"的层面，但将心的本体与现象割裂，尚未达究竟。

4. **大乘破相教**（中观宗）。说一切法皆空，破除对一切相的执着。宗密认为此说虽破除了"法执"，但"破相"本身也成为一种执着，且未正面说明"真性"是什么。

5. **一乘显性教**（华严宗）。说一切众生皆有本觉真心，真如佛性为无明所覆而流转生死，若能破除无明，则本觉真心自然显现。宗密认为这才是"原人"的究竟所在——人的本源不是物质、不是意识、不是空，而是"本觉真心"。

## 三、学术研究价值与争议

**研究价值**：本书是中国佛教思想史上唯一一部以"人的本源"为专题的哲学论著，在儒释道三教关系史、佛教心性论、华严宗发展史等研究领域都有重要地位。宗密以"五教"判释人性论，将佛教内部各派及儒道二教纳入一个高低有序的体系，体现了唐代佛教"判教"思想在人性论上的深化。

**代表学者**：宗密为作者；澄观《华严经疏钞》为华严理论之基础；日本学者镰田茂雄《宗密教学的思想史研究》对宗密思想有系统分析；冉云华《宗密》为英文世界的重要研究；董群《融合的佛教——宗密的佛学思想》在中文世界有代表性。

**争议问题**：其一，宗密将儒道归入"人天教"是否公允——儒道二教是否完全等同于佛教中追求人天福报的"人天乘"，学界一直有争议；其二，宗密对唯识与中观的批评是否准确——部分学者认为宗密以华严宗立场理解唯识与中观，存在一定程度的误读；其三，本书的"会通"之功过——宗密广大会通三教，但"会通"是否意味着"消解"各宗的独特性，值得讨论。

## 四、术语对照表

| 术语 | 释义 |
|------|------|
| 原人 | 推究人的本源，探究生命与心识的终极来源 |
| 五教（原人论） | 人天教、小乘教、大乘法相教、大乘破相教、一乘显性教 |

| 无明 | 根本无知，遮蔽本觉真心的虚妄境界 |
| 一乘显性教 | 华严一乘教法，直显众生本具之真如佛性 |



### 拓展视域

从更广阔的思想史视野来看，此文献的意义不仅限于佛教内部。它与中国本土的儒道思想之间存在着复杂的互动关系——既有竞争、辩论，也有吸收与转化。同时，此文献的解读也需放在汉传佛教与藏传佛教、南传佛教相互参照的框架中，方能获得更全面的理解。现代学者在诠解此文时，逐渐从传统的宗派立场转向客观的学术研究，注重文献学、思想史与社会史的多维视角，为这一佛教经典注入了新的学术生命力。
