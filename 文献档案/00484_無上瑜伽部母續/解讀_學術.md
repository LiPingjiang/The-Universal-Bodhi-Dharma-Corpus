# 無上瑜伽部母續 — 学术解读

## 一、文献背景与成书

无上瑜伽部（Anuttarayoga Tantra）母续，以《胜乐金刚续》（Cakrasaṃvara Tantra，又称 Śrīherukābhidhāna、Laghusaṃvara）与《喜金刚续》（Hevajra Tantra）为根本经典。胜乐金刚梵名 Cakrasaṃvara，藏语称「阔洛登巧」，意为「总摄轮」——总摄一切如来本尊坛城与空行勇父，故得此名。胜乐续约成立于印度八世纪末或九世纪初，现存梵本及藏译本；汉译大藏经未收全本，相关内容可见于法护译《大悲空智金刚大教王仪轨经》（喜金刚本续，T1191，北宋译出，五卷二十品）。主要传承有卢伊巴、噶那巴（黑行者）、智布巴三派；噶举派金刚亥母、萨迦派金刚瑜伽母修法皆出自胜乐续。十九世纪自尼泊尔发现喜金刚梵文写本，1959年 D. L. Snellgrove 以之与藏译对照英译，David B. Gray 后又完成胜乐续梵文校刊与英译，使母续研究成为国际佛学界显学。

## 二、文本结构与核心思想

母续之「母」，指其以「智慧」（prajñā）为主导，与以「方便」（upāya）为主导的父续相对。其核心教义可析为三层。其一，本尊论：胜乐金刚为四面十二臂之赫鲁嘎（Heruka）身，拥抱金刚亥母（Vajravārāhī），面半寂半怒，足踏大自在天及乌摩天女，于尸林转法轮——这是「以贪治贪、以染净染」的转烦恼为道用思想的艺术化表达。其二，身心论：母续特重圆满次第，以气、脉、明点为核心，本档案所选原文明言「外在日月运行是内在气脉明点变化之外现」，故于日月食及每月十五、三十等特殊时分行持，效果非同寻常——此即著名的「外时轮与内时轮对应」学说。其三，果位论：「俱生大乐」（sahaja-mahāsukha）与空性和合不二，胜乐金刚与金刚亥母「虽为二尊，实是乐空和合之一体」；「俱生」（sahaja）意为本来具足、自然本有，指最微细的原始心（俱生光明心）凡圣本具，修行只是令其显现。

## 三、学术研究价值与争议

其一，文献价值：母续是印度晚期佛教（波罗王朝时期）的主流教法，胜乐、喜金刚二续及胜乐六十成就者传承，是研究8至12世纪印度金刚乘的关键样本。其二，宗教人类学价值：尸林、天葬场、空行母等意象，牵涉印度沙克蒂（Śakti）女神传统与佛教的交涉，是性别研究与宗教对话的热点。其三，争议问题：母续双身图像与双运教义的现代诠释之争——传统上格鲁派强调其唯指「以俱生大乐心证空性」的内在观修，绝非世俗男女之事；学界则围绕其与印度教怛特罗的渊源、那洛巴与帝洛巴传记的史实性多有论辩。 Snellgrove、Gray、David Germano 等学者的译注与宗义研究，是进入此领域的基干文献。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 母续 | 无上瑜伽中以智慧为主导、重圆满次第与大乐的一类续典 |
| 胜乐金刚／总摄轮 | Cakrasaṃvara，母续本尊，总摄一切如来坛城 |
| 俱生（sahaja） | 本来具足、自然本有，指俱生光明心与大乐 |
| 乐空不二 | 大乐体验与空性证悟和合无二，母续核心果位观 |
| 气脉明点 | 脉（nāḍī）、气（prāṇa）、明点（bindu），圆满次第的身心基础 |
| 空行母（ḍākinī） | 密教女性圣众，密法传承的护持者 |
