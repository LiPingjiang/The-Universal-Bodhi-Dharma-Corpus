# 佛教組織心理學 · 原文

## 一、學科概述

組織心理學研究組織中的個體與群體心理：組織承諾、組織文化、領導、團隊動力與組織變革。佛教組織心理學的交叉點主要有三：其一，「組織正念」概念——2001年，密歇根大學的卡爾·維克與凱瑟琳·薩特克利夫出版《管理意外》（Managing the Unexpected），從高可靠性組織（HRO，如航空母艦、核電站）提煉出「集體正念」（organizational mindfulness）五原則：對失敗的先入為主的警惕、不願簡化、對運營的敏感、韌性承諾與專業遷就——這是佛教正念概念進入組織理論的里程碑；其二，佛教組織本身的社會科學研究——僧團（saṅgha）是人類歷史最悠久的自願組織之一，「六和敬」羯磨會議等制度是古典組織設計的活化石；其三，現代企業的佛教式干預（正念課程、禪修室）對組織氛圍的影響評估。

## 二、核心議題與佛教觀點

核心議題包括：（一）集體正念與安全——HRO研究證明組織層面的覺察文化（歡迎壞消息、尊重一線專業判斷）能防範災難性失誤，與佛教「正知現前」的修行原理在組織尺度上同構；（二）組織文化與價值觀——佛教寺院以戒律與共修塑造文化，其「以法攝眾」對應現代的使命驅動型組織；六和敬（身和同住、口和無諍、意和同悅、戒和同修、見和同解、利和同均）實為古典的團隊規範體系，其中「利和同均」尤可與分配公平研究對讀；（三）組織變革與無常——組織發展理論以變革為常態，佛教無常觀為變革管理提供了價值論基礎：執著於現狀（組織惰性）正是痛苦與失敗之源；（四）佛教經濟組織實驗——泰國「功德信仰與合作社」、台灣慈濟基金會的巨型志願組織運作，是組織心理學的獨特田野。《六祖壇經》「佛法在世間」為佛教資源進入世俗組織提供了綱領性依據。

> **經典依據**：
> 「佛法在世間，不離世間覺；離世覓菩提，恰如求兔角。」——《六祖壇經》（T2008）

惠能指出覺悟不離世間事——組織、工作、管理本身即是修行的道場。這一命題把佛教從寺院推向一切人類協作系統，構成佛教組織心理學的總綱：組織不僅是效率機器，更是成員心智轉化的環境。

## 三、代表學者與實踐

維克與薩特克利夫的「集體正念」是學術界最著名的佛教概念移植（儘管二人更多借用其「覺察」義而非佛教義理），其HRO研究深刻影響了醫療安全管理（如退伍軍人醫療系統的安全文化改革）。組織行為學者威廉·卡恩與之呼應提出工作場所的「臨在」概念。實踐方面：通用磨坊公司自2000年代中期由副總法律顧問賈尼斯·馬圖拉諾引入高管靜修，孵化出全球首個企業級正念領導力項目；谷歌工程師陳一鳴2007年創立的「探索內在的自我」（Search Inside Yourself）課程從企業內訓發展為獨立的領導力研究院，已培訓數萬名企業員工。佛教組織研究方面，社會學者對僧團決策制度（羯磨）與現代合議制的比較研究，以及對慈濟、佛光山等現代佛教組織的管理研究（台灣學界成果尤豐），構成了漢語世界的主要貢獻。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 組織正念 | 維克提出的組織層面持續覺察與警覺文化 |
| 高可靠性組織（HRO） | 在高風險環境中長期保持安全的組織類型 |
| 六和敬 | 僧團和合共住的六項原則，古典團隊規範 |
| 羯磨（karma） | 僧團依程序集體決策的制度 |
| 組織承諾 | 成員對組織的認同與投入 |
| 和合（saṃgha） | 僧伽本義「和合眾」，共同體心理的古典原型 |
