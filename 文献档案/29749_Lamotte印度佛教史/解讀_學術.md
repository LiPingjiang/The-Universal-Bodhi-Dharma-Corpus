# Lamotte《印度佛教史》 — 学术解读

## 一、文献背景与成书

本档案的传主是比利时佛教学家 Étienne Lamotte（1903—1983），其代表作为 1958 年出版的《印度佛教史：从起源到塞迦时代》（*Histoire du bouddhisme indien, des origines à l'ère Śaka*）。这不是一部佛教典籍，而是一部现代学术著作，条目因此按人物与著作综述体撰写。Lamotte 是 20 世纪欧洲最杰出的佛教学者之一，在鲁汶天主教大学接受古典学与东方语言训练，学术底色是法国、比利时古典文献学传统与德国印度学方法的结合。本档案原文以其著作清单与代表性观点摘录为主，所录法语引文均附中译，是本条目论述的依据。

除《印度佛教史》外，他的主要著作包括：历时近四十年（1944—1980）完成的《大智度论》五卷法译——《该书》迄今最完整的西方语言译本；以及《解深密经》（1935）、《维摩诘经》（1962）、《首楞严三昧经》（1965）等一系列汉语、藏语文献的法译，和多篇关于说一切有部与部派佛教的论文。

## 二、文本结构与核心思想

《印度佛教史》的时间跨度从佛陀时代到塞迦时代（约公元初），以严谨的文献学方法建构佛教在印度的历史演变。其结构上的显著特点是：以现存多语种文献（梵、巴、汉、藏）为骨架，把教团史、教义史、王权史编织为一体，全书对部派分化、阿育王时代、大乘兴起等关键节点均设专门讨论。

本档案摘录的三条代表性观点，可以概括其学术思想的三个支点。观点一，为部派佛教正名：「部派佛教並非原始佛教的墮落，而是其教義與制度發展中必要的一個階段。」Lamotte 反对把部派佛教仅仅视为大乘佛教的次要前奏，主张给予部派独立的学术地位。观点二，佛教必须在印度语境中理解：「佛教從來不是一種與其印度環境隔絕的宗教；它持續與婆羅門傳統及其時代的哲學流派對話。」这一立场反对把佛教抽离为孤立现象来研究。观点三，《大智度论》的复合文献性质：「《論》是一部複合性著作，其最古老的部分可能可追溯到龍樹，但在數世紀中經歷了擴充與重組。」他一边翻译一边分析文献层次，揭示了这部巨著复杂的形成过程。

## 三、学术研究价值与争议

研究价值方面：（1）《印度佛教史》是西方第一部全面、系统的印度佛教通史，为整个学科设定了分期框架与问题域，是此后数十年佛教史研究的绕不开的参照；（2）《大智度论》法译附详尽注释与研究，成为龙树研究及汉译佛典文献学研究的核心参考；（3）对说一切有部等部派佛教的研究纠正了以往重轻视部派的偏向；（4）他精通梵、巴、藏、汉、日多种语言，示范了多语文献比较研究的强大力量，深刻影响了后来的欧洲佛教学术传统。

争议与问题方面：（1）《大智度论》「复合形成说」是二十世纪佛教学最著名的公案之一：Lamotte 据文证推断此论非龙树一人一时之作，这一结论在日本学界引发长期论战，干潟龙祥等提出不同方案，至今未有完全的定论；（2）《印度佛教史》以公元初的塞迦时代为下限，大乘经典成立与后期佛教史着墨有限，这一「断代在前」的选择本身反映了他对佛教史重心的判断，后人（如平川彰等）的通史在框架上已有调整；（3）其部派佛教「必要阶段」论的表述，带有对批判「退化叙事」的矫枉，部派教义在多大程度上是创造性发展而非解释性固守，学界评价仍有分歧。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 印度佛教史（Histoire du bouddhisme indien） | Lamotte 1958 年代表作，西方首部系统的印度佛教通史 |
| 塞迦时代（ère Śaka） | 全书叙事下限，约当公元初的印度历史纪年体系 |
| 部派佛教 | 佛陀去世后数百年间分裂形成的各个部派，Lamotte 主张给予独立重视 |
| 说一切有部（Sarvāstivāda） | Lamotte 深入研究的部派之一，主张三世实有 |
| 大智度论 | 鸠摩罗什译龙树系巨论，Lamotte 断为复合性著作 |
| 复合著作（ouvrage composite） | 指经数世纪扩充与重组、非一人一时写定的文献 |
| 多语文献比较研究 | 以梵、巴、汉、藏等多种语言文献互证的方法，Lamotte 学术标志 |
| 鲁汶天主教大学 | Lamotte 学习与任教之地，其学术生涯所在 |
