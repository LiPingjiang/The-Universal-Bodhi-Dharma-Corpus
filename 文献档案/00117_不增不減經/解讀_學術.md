# 不增不减经 — 学术解读

## 一、文献背景与成书

《不增不减经》（梵 Anūnatvāpūrṇatva-nirdeśa，即「不增不减说」），大正藏编号 T668，一卷，元魏菩提流支译（约6世纪初），收于《大正藏》第十六册。本经篇幅极短，却是如来藏系经典中论理密度最高的一部，与《如来藏经》《胜鬘经》并列为如来藏三部根本经典。据本目录档案所记，其梵名与题名「不增不减」为全称直译；经以舍利弗为对告者，通篇围绕「众生界不增不减」一义反复抉择。藏传大藏经中亦存本经译本，其偈颂与《宝性论》所引高度重合，显示本经与《宝性论》所依经典群的密切关系。

需要说明的是经题的隶属关系：本经传统上被视为《胜鬘经》的姊妹篇（同属如来藏系根本经典），也有经录将其与《胜鬘经》视为同会别出；学界一般认定其成书于公元三至四世纪的印度。菩提流支译经群（见本语料库 `00207_菩提流支譯經羣`）是北朝瑜伽行系文献入华的主通道，本经即其中篇幅最短、命题最纯的一部。

## 二、文本结构与核心思想

据本目录档案所录经文，本经的核心论证是一组环环相扣的等同句：「甚深義者，即是第一義諦。第一義諦者，即是眾生界。眾生界者，即是如來藏。如來藏者，即是法身。」第一义谛＝众生界＝如来藏＝法身，四名一实。这一等同连锁的教理功能有二：其一，把「众生」从经验层面的杂染存在直指为第一义谛的当体——众生的实相即是法身；其二，为「不增不减」的本体论奠基。

「不增不减」是针对两种边见的对治：谓「众生界减」（有修行者证涅槃而究竟灭度、众生界因之减少——落于断灭见）与谓「众生界增」（有新众生生起、众生界因之增多——落于增益见）。经言：「眾生界不增不減。何以故？眾生界即是法身，法身即是眾生界。」法身周遍常住、非造作法，则于此周遍界中，「众生灭后法身减损」与「新众生增益法身」俱不可得。本目录档案所录名句总括此义：「不增不減者，謂眾生界、法界、如來藏，三名一義。離於增減，常恆不變。」

由此，本经对迷悟位次的处理是「体无变异」的三重结构：众生位为染净和合（如来藏为烦恼所覆），菩萨位为净显，佛位为圆满——位次有迷悟，法身体性无增无减。这一「不变随缘、随缘不变」的雏形表述，是如来藏思想「迷悟不二」论的最早形态之一。

## 三、学术研究价值与争议

**如来藏三部经的枢纽**。本经与《如来藏经》（九喻的譬喻性宣说）、《胜鬘经》（系统化论证）构成三部曲；学界（高崎直道等）注意到本经的特殊角色：它以最精简的逻辑形态给出如来藏思想的「本体论骨架」，其等同句式直接被《宝性论》继承为论证框架。本语料库同名的其他《不增不减经》相关档目均以此为共同文本。

**与「空」的关系之辩**。本经「法身即是众生界」的表述，在「批判佛教」（松本史朗、袴谷宪昭）看来是「基体（dhātu）一元论」最露骨的形态——单一实体作为万法根基；反方（高崎直道及为如来藏辩护的学者）则指出经中法身「离于造作、不可说有不可说无」的表述与中观空义并不违逆。本经因文本短小、命题赤裸，是这场论争中被引用频率最高的经典之一。

**争议所在**。其一，「三名一义」的融贯问题：「众生界＝如来藏＝法身」的等同若取严格一义，则与「如来藏在缠」的位差别义如何协调（同经后文又说染净位次的差别），经文自身的张力即是注疏史争论的起点。其二，「不增不减」与般若语汇的关系：本经题名与《心经》「不增不减」同为般若系语汇，其「众生界不减」论亦与《金刚经》「实无众生得灭度者」义脉相通——如来藏思想对般若空观的继承与转化（空性「实体化」为佛性）如何发生，本经提供了中间形态的观察样本，学界对这一「继承—转化」的定性至今有不同评估。其三，本经与《胜鬘经》的关系（别译单行抑或同会别出）及菩提流支译本与藏译的差异，也仍有考订余地。

| 术语 | 释义 |
|---|---|
| 众生界（sattva-dhātu） | 一切有情之界，本经等同于法身 |
| 法身（dharma-kāya） | 诸法实相之身，与众生界不二 |
| 如来藏（tathāgata-garbha） | 众生位中本具的佛性 |
| 第一义谛 | 终极真理，即胜义谛 |
| 众生界减 | 断灭见：证涅槃者令众生界减少 |
| 众生界增 | 增益见：新众生生起令众生界增多 |
| 三名一义 | 众生界、法界、如来藏，体一名异 |
| 不增不减 | 超越增减两边的法身本际 |
