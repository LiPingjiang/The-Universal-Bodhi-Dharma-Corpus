# 佛教四法印研究 — 学术解读

## 一、文献背景与成书

本条目为语料库「佛教专题研究」系列的主题类综述条目，所整理的四法印（梵 catvāraḥ dharma-mudrāḥ）是判别佛法真伪的四条根本印章：「诸行无常、诸漏皆苦（有漏皆苦／一切行苦）、诸法无我、涅槃寂静」。法印（dharma-mudrā）之意象取自王印勘验：凡合此理者即佛说，违者即非佛法。原文档为综述型条目，对名目、两系汉译经证、三法印之开合与义理结构均有系统交代，并明确其义理与四圣谛互为表里（互见 `05027_佛教四聖諦研究`）。

汉译经证依原文档有二系。其一，《增一阿含经》（T125）卷十八〈四意断品〉之「四法本末」：「一切諸行無常……一切諸行苦……一切诸行无我……涅槃为灭尽」，此为最古之四法印形式。其二，《瑜伽师地论》（T1579）卷四十六立「四种法嗢柁南」（udāna）：「諸行無常、諸行是苦、諸法無我、涅槃寂靜」，《菩萨地持经》（T1581）卷八译为「四忧檀那法」。又通途之三法印（诸行无常、诸法无我、涅槃寂静）见《大智度论》卷二十二之说；增列「有漏皆苦」即成四法印，故三法印与四法印并非两种教理，而是开合之别。

## 二、文本结构与核心思想

四印之义理结构依原文档可析为三。第一，能所的完整覆盖：前二印观有为法——诸行无常（一切造作迁流之法念念生灭），有漏皆苦（无常故非安稳，含苦苦、坏苦、行苦三重）；第三印遍观一切法无我（有为无为皆无常一主宰之实我）；第四印示无为涅槃（烦恼永灭、生死止息）。前二摄流转，后二摄还灭；三印观所知，第四印示所证。第二，与四谛互为表里：苦谛即有漏皆苦，集谛说明诸行之缘起，道谛趣向无我之观慧，灭谛即涅槃寂静——法印是横说，四谛是竖说，纲目相成。第三，勘验功能：四印作为「印」，其价值不在增加知识而在鉴别——《瑜伽师地论》谓于此四种嗢柁南不如实知者「不能超出一切恶趣」，正见其为入道之门而非学院之学。

部派与宗派之开合亦须注意：南传巴利系多依三法印（sabbe saṅkhārā aniccā…），而《法句经》偈颂实具四句之内容；大乘天台则别立「一实相印」，《法华玄义》（T1716）以诸法实相统摄三法印，将印之义收归一实相——三印、四印、一印之递收，正见各宗判摄之不同趣向。

## 三、学术研究价值与争议

四法印的研究价值，首先在于它是佛教的「自我定义装置」：一个自称佛法的学说是否成立，检验标准不在传承、不在人数、不在神迹，而在是否符合无常、苦、无我、涅槃之理——这在宗教史上是罕见的内在批判结构，为佛教的理性品格提供了纲领性证明。其次，「法印」一词的存在本身即是佛教文献层累与正伪之争的产物：正因佛典在流传中真伪杂陈，才需要印之勘验，四法印是佛教最早的「经典鉴别学」，与现代佛典文献学的对话空间极大。

争议方面：其一，三法印、四法印孰为原始？学界多以「诸行无常、诸行苦、诸法无我」之形式更古，「涅槃寂静」与「有漏皆苦」的入印反映不同部派的教理整合，四印与三印的系统化次序至今聚讼。其二，「诸法无我」印与如来藏系经典「我」之用语表面相违，是佛教内部诠释的老问题（如来藏以「无我之我」疏解），涉及判教立场。其三，一实相印与四法印的收摄关系：天台以一摄三，中观家则谓实相即是三印所表之空理、无须别立，二者之辨实为方法论之争。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 法印（dharma-mudrā） | 勘验佛法真伪之根本标准 |
| 诸行无常 | 一切有为法迁流不住，念念生灭 |
| 有漏皆苦 | 一切杂染之法其性是苦，含苦苦、坏苦、行苦 |
| 诸法无我 | 一切有为无为法皆无常一主宰之实我 |
| 涅槃寂静 | 烦恼永灭、生死止息之寂静界 |
| 法嗢柁南（udāna） | 《瑜伽师地论》对法印之称，法之总集偈 |
| 三法印 | 四法印去「有漏皆苦」之开合形态 |
| 一实相印 | 天台宗以诸法实相统摄法印之究竟说 |
