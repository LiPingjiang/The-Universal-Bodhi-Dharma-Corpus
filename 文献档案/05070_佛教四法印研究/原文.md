# 佛教四法印研究 · 原文

## 一、概念概述

四法印（梵 catvāraḥ dharma-mudrāḥ）是判別佛法真偽的四條根本印章：「諸行無常、諸漏皆苦（有漏皆苦／一切行苦）、諸法無我、涅槃寂靜」。法印（dharma-mudrā）意謂如王印之勘驗真偽：凡合此四理者即佛說，違者即非佛法。四法印之漢譯經證有二系：其一，《增一阿含經》（T125）卷十八〈四意斷品〉所說「四法本末」：「一切諸行無常、一切諸行苦、一切諸行無我、涅槃為滅盡」，此為最古之四法印形式；其二，《瑜伽師地論》（T1579）卷四十六立「四種法嗢柁南」（udāna）：「諸行無常、諸行是苦、諸法無我、涅槃寂靜」，《菩薩地持經》（T1581）卷八譯為「四憂檀那法」。四法印與三法印之關係：通途所謂三法印（諸行無常、諸法無我、涅槃寂靜）見《大智度論》卷二十二「三法印」說，係就「印」之功能簡別；增列「有漏皆苦」即成四法印，故四法印與三法印並非兩種教理，而是開合之別——三法印重在勝義空理之勘驗，四法印更圓滿標出佛教對「苦」之本質的立場。部派之異：南傳巴利系多依三法印（sabbe saṅkhārā aniccā…）而《法句經》偈亦具四句之實；大乘則別立「一實相印」（《法華玄義》T1716以諸法實相攝三法印）為究竟。四法印之義理結構：前二印觀有為法（無常故苦），第三印觀一切法無我，第四印示無為涅槃，恰攝「有為／無為、流轉／還滅」之全體，與四聖諦（苦集滅道）互為表裡（詳`05027_佛教四聖諦研究`，互見）。

## 二、核心經文選錄

> **原文**（《增一阿含經》卷十八，T125）：
> 「今有四法本末，我之所說。云何為四？一切諸行無常，是謂初法本末；一切諸行苦，是謂第二法本末；一切諸行無我，是謂第三法本末；涅槃為滅盡，是謂第四法本末。」

> **白話對照**：
    佛說四條根本之理：一切造作遷流的法皆無常（無常故非安穩）；一切有漏造作皆苦（行苦）；一切造作之法皆無獨立自主之我（無我）；熄滅煩惱則是寂靜（涅槃）。此四理涵蓋佛教世界觀與解脫觀的全部綱領。

> **原文**（《瑜伽師地論》卷四十六，T1579）：
> 「復有四種法嗢柁南：諸行無常、諸行是苦、諸法無我、涅槃寂靜。……若有說言：於此四種法嗢柁南不如實知，而能超出一切惡趣，無有是處。」

> **白話對照**：
    瑜伽行系承認四法嗢柁南為佛法之總綱：不如實了知此四理者，不能出離惡趣、不能趣入正道。大乘論書同樣以此四印勘定佛說與非佛說，其地位為大小乘所共許。

## 三、重要名句

> 「諸行無常，諸漏皆苦，諸法無我，涅槃寂靜。」（四法印之通行定型句）

> 「諸行皆是壞滅之法，應自奮勵，念念不忘。」（《長阿含·遊行經》佛最後之教，無常印之極致）

> 「諸法從本來，常自寂滅相。」（《法華經·方便品》，一實相印對四印之會歸）

> 「若無常、苦、空、非我者，是生滅法；寂滅為樂。」（《大般涅槃經》，會通無常印與涅槃印）

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 法印（dharma-mudrā） | 勘驗佛法真偽之根本標準 |
| 諸行無常 | 一切有為法遷流不住，念念生滅 |
| 有漏皆苦 | 一切雜染之法其性是苦，含苦苦、壞苦、行苦 |
| 諸法無我 | 一切有為無為法皆無常一主宰之實我 |
| 涅槃寂靜 | 煩惱永滅、生死止息之寂靜界 |
| 法嗢柁南（udāna） | 《瑜伽師地論》對法印之稱，義為「法之總集偈」 |
| 三法印 | 四法印去「有漏皆苦」之開合形態 |
| 一實相印 | 天台宗以諸法實相統攝法印之究竟說 |
