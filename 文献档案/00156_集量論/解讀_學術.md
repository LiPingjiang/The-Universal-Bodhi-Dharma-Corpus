# 集量论 — 学术解读

## 一、文献背景与成书

《集量论》（Pramāṇasamuccaya）是印度佛教因明学大师陈那（Dignāga，约480-540年）晚年的总结性著作，约成书于6世纪上半叶。原以梵语写成，全书六品，附陈那自撰的散文注释（Vṛtti）。汉译方面，义净于唐景龙四年（710年）译出，题为《集量论》，但存本残缺不全，收于大正藏 T1632；完整的传承依赖藏译本，保存于德格版丹珠尔（Toh.4203），附有陈那自注，是今日研究本论最重要的底本。梵文原本大部分已佚，仅存残片与后世引文，20世纪罗睺罗·桑克里提亚延（Rāhula Sāṅkṛtyāyana）在西藏寺院拍摄的梵文贝叶写本照片为文本复原提供了关键材料。

书名梵语 Pramāṇasamuccaya 直译为"量之集成"：pramāṇa（量，正确认知的手段）+ samuccaya（汇集）。这一命名宣示了陈那的雄心——将佛教关于正确认知的理论全面系统地集成于一书。

## 二、文本结构与核心思想

全书六品：（1）现量品，论述直接知觉，提出著名命题"现量离分别"——直接知觉不含概念构造；（2）为自比量品，阐明因三相、九句因等推理有效性的形式条件；（3）为他比量品，论三支论式（宗、因、喻）的正确构成；（4）喻与似喻品，论实例的正确运用及其过失；（5）遮诠品，提出"遮诠论"（apoha）；（6）过类品，分析辩论中的伪反驳。

核心思想可归纳为四项：

- **二量说**：正确认知的手段唯有现量与比量两种，与正理派的四量说（现量、比量、圣言量、譬喻量）形成鲜明对比，极大简化了认识论结构。
- **自证分**（svasaṃvedana）：心识具有自我觉知的功能，不需要另一个认知来认知自身，否则会陷入无穷倒退。
- **所量唯二**：认知对象只有自相（svalakṣaṇa，个别相）与共相（sāmānyalakṣaṇa，概念化的一般相）；现量取自相，比量取共相。
- **遮诠论**：语词的意义不在于指向实在的"共相"，而在于排除非所指对象——这是佛教唯名论语义学的核心理论。

思想史脉络上，《集量论》标志着佛教哲学从宗教论辩工具转向具有独立学术价值的认识论与逻辑学体系。此后法称（Dharmakīrti）正是以注释和发展本论为起点，将佛教量论推向最高峰。

## 三、学术研究价值与争议

《集量论》是国际佛学界与印度哲学界研究最密集的论典之一。服部正明（Masaaki Hattori）1968年出版的第一品英译与研究《Dignāga, On Perception》开创了现代研究的范式；桂绍隆（Shoryu Katsura）对第二品的研究、Ole Pind 对整部论的重构工作，以及 Ernst Steinkellner 主持的维也纳学派对佛教量论的系统性研究，皆是里程碑式贡献。中国学界方面，吕澂、法尊法师等对汉藏译本进行了比较研究。

争议问题主要包括：（1）现量是否"纯然无分别"——陈那主张直接知觉完全不含概念，这一强主张在西方分析哲学语境中引发长期讨论，有学者认为其接近"所予神话"（myth of the given）的批评，也有学者为之作知识论辩护；（2）遮诠论是否陷于无穷倒退——若"排除非牛"仍需借助"非牛"概念，语词意义如何可能，这在藏传佛教宗义文献中是绵延数百年的争论；（3）自证分的地位——陈那以自证分作为记忆与认知确定性的根据，法称后期学说对此有所修正，学界对二人立场的差异论述甚多。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 现量（pratyakṣa） | 直接知觉，离分别的可靠认知手段 |
| 比量（anumāna） | 推理，由已知推未知的知识来源 |
| 自相（svalakṣaṇa） | 独一无二的个别相，现量的对象 |
| 共相（sāmānyalakṣaṇa） | 概念化的一般相，比量的对象 |
| 遮诠（apoha） | 语词以"排除异类"方式表义的理论 |
| 自证分（svasaṃvedana） | 心识自我觉知的功能 |
