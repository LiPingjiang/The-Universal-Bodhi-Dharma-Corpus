# 佛教认识论 — 学术解读

## 一、文献背景与成书

佛教认识论是现代学术视野下的综述性专题条目，研究何谓可靠认识、认识如何产生、错误如何形成，以及知识如何服务于离苦。据本库原文档的明确交代，它并非一套单一理论，而是横跨佛教思想史的复合传统：早期佛教重如实知苦集灭道与经验验证；阿毘达磨细分心、心所与认识对象；瑜伽行派分析识的结构与遍计所执；陈那、法称的量论则以现量、比量、概念与语言为中心。其共同问题是：如何避免由无明、执取和错误分别所导致的认知偏差。

原文档特别强调方法论自觉：古典佛典并非依现代学科分类撰成，学科名称首先是一种研究视角，而非可直接回溯的古代自称。因此本条目性质是问题地图，而非单一文献的考释。本库尚有多个同名专题目录（如 `18705_佛教認識論_19`），各自独立撰写，本条目专就本目录原文档立论。

## 二、文本结构与核心思想

原文档以学科概述、核心议题、代表学者与著作、术语对照、相关文献五分展开，其义理骨架可归为三层。

第一层是量的理论。量是能导向新而不欺诳之知的认识手段。陈那《集量论》将正确认识主要归为现量与比量：现量不是日常所说的一切感官经验，而是离分别、直接呈现个别相的认识；比量则依可成立的理由推知未直接呈现者。法称《释量论》深化知觉、推论、语义和圣教权威的论证。原文档所引《因明入正理论》现量者谓离分别一句，正是这一传统的经典定义。

第二层是概念与语言的分析。概念和语言在世俗生活与教学中不可或缺，但若把概念的分类误认为对象自身固定不变的本质，便会生起我执法执。法称的排除他义（apoha）理论说明：一般概念不是直接抓住实在的普遍体，而是藉排除非彼来运作。

第三层是认识论的修行意义。瑜伽行派三性说区分遍计所执、依他与圆成实：错误不在于经验全然不存在，而在于把依条件显现的经验执作二取实体。认识的正确性因此与转化烦恼相连；经典、师承与证言可作引导，但其权威仍须与理证、现证和不害的实践相互检验。

## 三、学术研究价值与争议

代表研究方面，原文档列举谢尔巴茨基《佛教逻辑》的早期系统介绍，邓恩《法称哲学的基础》、蒂勒曼斯《经典、逻辑与语言》与当代分析哲学的对话，以及桂绍隆、郑伟宏等汉语学界成果。

争议有二。其一，佛教认识论不应被化约为形式逻辑：原文档明确指出它与因明密切相连，却是服务于解脱的知识论，其现量定义、apoha 理论都不能脱离修行脉络来理解；把量论当作纯逻辑学处理，会错失其认知—伦理一体的品格。其二，跨传统比较的陷阱：以相似词汇断定思想同一，是原文档点名的常见错误；现量对应直觉、比量对应推理这类方便说法，在严格比较研究中必须让差异与反例保留在分析之内。原文档要求区分经文、论书、戒律、碑刻等材料的证据力并交代推理范围，这一分层次处理证据的立场，正是当前佛教哲学研究的方法论共识。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 量 | 能导向新且不欺诳认识的有效认识手段 |
| 现量 | 离概念分别、直接呈现个别相的认识 |
| 比量 | 依理由与遍充关系推得未现前对象的认识 |
| 分别 | 将经验概念化、命名与分类的心识活动 |
| 排除他义 | 以排除非彼的方式说明概念意义的理论 |
| 三性 | 遍计所执、依他起、圆成实三种分析层次 |
