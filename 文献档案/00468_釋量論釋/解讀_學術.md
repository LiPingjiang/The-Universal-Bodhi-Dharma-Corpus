# 释量论释 — 学术解读

## 一、文献背景与成书

《释量论》（Pramāṇavārttika，直译"量理广注"），法称（Dharmakīrti，约600-660）造，是对陈那《集量论》的重新注疏与创造性发展。法称出身南印度，师从护法系学者，于迦湿弥罗一带著书立说，其"七部量论"（"因明七论"）将佛教逻辑与知识论推向印度思想史的顶峰，而《释量论》篇幅最大、地位最高，凡二千余颂，与作者自注并行。

本论无古代汉译。近代法尊法师于20世纪中据藏译译出《释量论》，并译出僧成（一世达赖喇嘛根敦珠巴）的释论提要，其译本于80年代出版，是汉地研究本论的基础文本。藏传方面，《释量论》为格鲁派"五部大论"之一，历代注释浩繁，贾曹杰《显扬量论广疏》等为其代表；寺院辩经制度即以此论与《集量论》的体系为骨架。

## 二、文本结构与核心思想

《释量论》四品的次第为：

1. **为自比量品**：阐发推理规则与因三相，将陈那逻辑精细化，系统论述"三种因"（自性因、果性因、不可得因）的推理类型学；
2. **成量品**：全论思想的高峰。由归敬颂"敬礼定量欲利生，大师善逝救护者"展开，以两千余颂论证佛陀是"量"（究竟可靠的认知者）——将宗教信仰的辩护转化为认识论的论证：佛的资质（意乐圆满的慈悲与加行圆满的智慧）可由"果溯因"的推理逐步建立，四谛教法可由其实效得到验证；
3. **现量品**：深化陈那的知觉理论，精密处理错觉、刹那灭、瑜伽现量等问题；
4. **为他比量品**：论语言论证及其过失。

核心思想可概括为三点：

- **信仰的知识论化**：成量品不诉诸神迹与权威，而以推理证明"佛为量"——这是世界宗教史上罕见的把信仰根基完全交给理性论证的尝试，故本论被称为"佛教的理性神学"（此为学界通行的概括性说法）；
- **刹那灭与因果的有效性**：现量品以"刹那灭"论证经验世界的无常结构，为因果推理提供形而上学基础；
- **推理类型学**：三因说的建立使佛教逻辑从论辩术升华为关于一切经验推理的普遍理论，直接支配了此后印度与西藏的逻辑思辨。

## 三、学术研究价值与争议

**研究价值**：（1）《释量论》是印度哲学最后六百年间影响最大的著作之一，正理派、耆那教的逻辑发展皆以其为论敌或参照，是新古典印度哲学研究的轴心文本；（2）藏传佛教的辩经教育以本论为纲，研究藏传寺院学术制度（摄类学、辩经程式）必须由之入手；（3）成量品为佛教"信仰与理性"问题提供了最系统的一份答卷。

**代表学者与争议**：（1）俄国舍尔巴茨基《佛教逻辑》（Buddhist Logic, 1930-32）译出为自比量品与成量品的核心内容，其"佛教逻辑乃印度式康德哲学"式的解读影响深远也争议巨大；（2）乔治·德雷福斯（Georges Dreyfus）《认清实在》（*Recognizing Reality*, 1997）据其亲历的藏传学制完整重构《释量论》的义理与教育语境，为当代研究的标志之作；（3）汤姆·蒂勒曼斯（Tom Tillemans）对为他比量品与语言哲学的系列研究、维也纳学派对法称著作的持续校勘，构成当前研究的主力；（4）争议焦点包括：法称对陈那的修改是否"背叛"、成量品论证的逻辑有效性、以及法称不可知论倾向与佛教解脱论之间的张力。
