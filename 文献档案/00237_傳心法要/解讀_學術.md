# 传心法要 — 学术解读

## 一、文献背景与成书

《传心法要》，全称《黄檗山断际禅师传心法要》，一卷，唐代黄檗希运禅师（活动于9世纪中叶，卒年约855年前后）示法语录，宰相裴休于大中年间（847—860）任洪州刺史、宛陵刺史时结集并作序，与《宛陵录》同收于《大正藏》第四十八册（No. 2012）。

黄檗希运住洪州黄檗山（今江西宜丰），嗣百丈怀海，是南岳—马祖洪州禅系的第三代重要人物。他的两大"作品"影响了整个后世禅宗：一是弟子临济义玄开创了临济宗，二是这部由在家弟子裴休记录的语录，成为唐末"唯传一心"禅风最纯粹的文献之一。原文所示"黄檗希运禅师云：诸佛与一切众生，唯是一心，更无别法"，正是全书开宗明义之句。

## 二、文本结构与核心思想

本书为语录体，不立科判，依说法因缘汇集，但义理线索极为清晰，可概括为三点：

1. **唯有一心，别无别法**。心是万法之源、诸佛之体，"无始以来，不曾生不曾灭，不青不黄，无形无相"。黄檗将《楞伽》《起信》以来"一心"的传统推到极处：不但众生与佛同此一心，连"成佛"也只是识得此心，"本来是佛，更无一法可得"。

2. **即心是佛，无心是道**。"即心是佛"指心体外更无佛可求；"无心是道"指此心不生分别、不着取舍即是道之现前。两者一体两面：前者破"向外求佛"，后者破"向内执法"。如名句所云："即心是佛，无心是道。但无心于万物，何妨万物常围绕。"修行不是消灭世界，而是心不随万物攀缘。

3. **无法可传之传**。"达摩西来，唯传一心，更无别法。"黄檗把达摩禅重新解释为"传心"——所传的不是文字、不是仪式，甚至不是任何"法"，因为"有所得者皆是虚妄"。这为临济义玄"无位真人""无一法与人"的激越宗风提供了直接的思想母体。

## 三、学术研究价值与争议

**研究价值**：本书是研究洪州禅向临济宗过渡的关键文本。黄檗上承马祖"即心即佛"的洪州传统，下启临济"人"的思想（无位真人），在禅思想史上处于枢纽位置。语录语言雄浑斩截，是唐代白话禅语的典范文献，对汉语史研究亦有价值。

**代表学者**：铃木大拙将本书与《宛陵录》英译为《The Zen Teaching of Huang-Po》（1958），使黄檗思想进入西方视野；忽滑谷快天《中国禅学思想史》论其"无心"宗旨；印顺《中国禅宗史》将其置于洪州禅的发展脉络中考察；日本学界对语录的文献形成（裴休集录的性质、与《临济录》的语言关联）亦有系列研究。

**争议问题**：其一，文本的成立问题——裴休集录的可靠性及后世增补的可能性，唐代语录多经宋人重编，需与《祖堂集》《景德传灯录》相关记载对勘；其二，黄檗"一心"说与《起信论》如来藏思想的关系——是如来藏禅的延续，还是已转向更彻底的"无心"立场，学者评价不一；其三，黄檗与临济思想的分际——"唯传一心"与"无位真人""逢佛杀佛"之间的连续与断裂，是理解临济宗起源的核心论题。

|------|------|
| 一心 | 诸佛与众生同具的心体，不生不灭、无形无相 |
| 即心是佛 | 心外无佛，佛即是当下之心体 |
| 无心 | 心不攀缘、不生分别取舍之状态，非断灭顽空 |
| 传心 | 达摩以来以心印心之传，不立文字、无一法可得 |
| 歇即菩提 | 妄念止歇处即是觉悟，不须别求菩提 |
| 分别 | 心于境起是非取舍之攀缘，为生死根本 |
