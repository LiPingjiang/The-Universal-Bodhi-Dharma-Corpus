# 佛教三界研究 — 学术解读

## 一、文献背景与成书

本条目为语料库「寰宇覺海·菩提法藏」之独立文献补充条目，编号 X8233，目录名作「佛教三界研究_1」。据实说明：其《原文》非经论传本，而是三界名数的主题辑录，概述列「欲界、色界、無色界」三名，选录与名句各存两条引文，术语表七条，末附相关文献指引。与姊妹条目 `09241_佛教三界研究` 所录文字全同，可知为同一底稿在语料库不同编号位的分置；条目 README 自署「待後續填充內容」，性质均为名目型简编。本条目拟专就三界诸天的谱系细目与部派计数异说作展开，与前条之三界总体结构及流转义分工互补。

三界诸天的完整谱系，汉传所传以《长阿含·世记经》《大楼炭经》《起世经》等世界观经典及《俱舍论·分别世品》为两大系统。选录引文「欲界有六天，色界有十八天，無色界有四天」属《俱舍》系计数，兹依此铺陈。

## 二、文本结构与核心思想

《原文》五节为补充条目通例，兹展开诸天谱系。

**欲界六天**：一四天王天（须弥山腰，四大天王领八部鬼神）、二忉利天（须弥山顶，帝释居善见城，即三十三天）、三夜摩天（须弥空中，依空而住，时分随时受乐）、四兜率天（知足天，一生补处菩萨未成佛前所居，弥勒今居其内院）、五化乐天（自化五尘而受欲乐）、六他化自在天（夺他所化而自受用；其上别有魔宫，魔天或摄于此天或别立，经论有异）。六天皆有男女饮食之事，唯愈上愈微。

**色界十八天**（依《俱舍》系）：初禅三天——梵众天、梵辅天、大梵天；二禅三天——少光天、无量光天、极光净天；三禅三天——少净天、无量净天、遍净天；四禅九天——无云天、福生天、广果天、无想天，及净居五天（无烦、无热、善见、善现、色究竟天，唯证果圣者所居，不还圣者于此般涅槃）。他系异说：上座部巴利传承通常作十六天（无无想天，净居作五）、别传有十七、二十二天之说；唯识系于色究竟上另立一门（密教以此天为大日如来说法处）。

**无色界四天**：空无边处、识无边处、无所有处、非想非非想处——有名无形，唯以识缘虚无之境而住，寿量递增，非想非非想天寿八万大劫，为三界之顶。

**寿量与量器**：《俱舍论》备载诸天寿数（四天王五百岁、忉利一千岁，其一昼夜当人间数十年；色界以劫计），及器世间成坏（三灾所及：火灾至初禅、水灾至二禅、风灾至三禅，四禅无灾而不动）——引文「三界無安，猶如火宅」于《俱舍》体系中更有三灾坏灭的实义支撑：不仅众生苦，世界本身亦在周期性毁灭中。

## 三、学术研究价值与争议

第一，诸天谱系是佛教吸收改造印度流行神话的总账簿。帝释（Śakra/Indra）即吠陀雷神因陀罗之转化，梵天（Brahmā）即创世神之降格录用——但一律改造成护法角色与轮回成员，居于业感缘起的因果链内，「天人不耐久、福尽还堕」的判摄消解了其神圣性。研究佛教对婆罗门教神谱的批判性继承，三界诸天表是第一手材料。

第二，计数异说的文献学意义。色界天数的十六、十七、十八、二十二诸说，与净居天的归属、无想天的摄属直接相关，其分歧可上溯至部派时代的阿毗达磨传本差异；本条目取「十八」一数，属说一切有部至《俱舍》系的汉传主流计数。处理这类数字时，语料内部自洽即可，不可执一非余。

第三，「世界成坏」与现代宇宙学的对话。成住坏空的周期性宇宙观（劫波思想）与热寂说、循环宇宙论常被并提；学界一般立场是：二者问题意识不同（佛教旨在对治常执，非旨在物理预测），比附须有分寸。又藏传与时轮系统（kālacakra）另有独特的宇宙度量说（须弥结构与劫量另成体系），其根本典籍不在大正藏编号体系之内，应检德格版《甘珠尔》相关续部编目。

第四，兜率天与净居天在信仰史上的特殊地位：前者因弥勒信仰而成为求生净土之一系（道安相传发愿兜率，无著、世亲亦传上生之说），后者作为圣者专属之地为禅定成就提供目标设定——谱系中的两处「特区」，显示三界图并非均质的空间，而有价值梯度的设计。
