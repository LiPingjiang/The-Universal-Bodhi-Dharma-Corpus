# 品类足论 — 学术解读

## 一、文献背景与成书

《阿毗达磨品类足论》（Abhidharma-prakaraṇa-pāda），T1542，十八卷，尊者世友（Vasumitra）造，唐玄奘译。为说一切有部六足论之一，亦为根本七论之一。异译本有刘宋求那跋陀罗与菩提耶舍合译《众事分阿毗昙论》十二卷。学术界一般认为此论并非出自一人之手，而是多种作品的汇集——「品类」之名即来自其按品类组织法义的方法。

世友另造《异部宗轮论》，是有部最重要的理论家之一（婆沙结集之上座）；但「世友」之名在文献中可能指向不同人物，本论的成书实为有部成熟期（约公元前一至公元一世纪）的层累产物。

## 二、文本结构与核心思想

全书八品，构成有部法相体系的总纲：

- **辩五事品**：提出「五位」总分类——一色（四大种及所造）、二心（六识身及七识界）、三心所（与心相应之受、想、思、触、作意、欲、胜解、念、定、慧等）、四不相应行（得、非得、无想定、灭尽定、命根、众同分、生老住无常等）、五无为（虚空、择灭、非择灭）。这一「五事摄一切法，尽无遗余」的分类框架，成为此后《俱舍论》乃至唯识学百法体系的骨架。
- **辩七事品**：以七识界（眼耳鼻舌身五识界＋意界＋意识界）摄尽一切心法。
- **辩随眠品**：建立「九十八随眠」的烦恼系统——三界各依见苦、见集、见灭、见道、修道五所断配分，欲界三十六（如见苦所断之萨迦耶见、边执见、邪见、见取、戒禁取、疑、贪、瞋、慢、无明十种），色无色界亦各三十六，合九十八。这一烦恼分类学把「心理病理解剖」推进到前所未有的精度。
- **辩千问品**：以二十门各五十问答，共千问决择诸法自相共相——方法论的极致展演。

本论标志着佛教系统心理学的确立：心所（mental factors）作为独立范畴与心并立，为后世一切佛教心理学奠定分类基础。

## 三、学术研究价值与争议

**研究价值**：五位七十五法（由五事发展而来）与九十八随眠是有部教理的两大支柱，《大毗婆沙论》广泛引用本论为典据；「不相应行」这一独类目（得、命根、生住异灭等非心非色之法）是佛教形而上学中最具原创性的范畴之一，可与现代「抽象实体」问题对话；辩千问品的问答矩阵是古代辩证逻辑的样本。

**争议问题**：其一，五事分类是经验性的还是实体化的——「不相应行」诸法（尤其「得」）是否实有，成为经部日后批判有部的首要靶子；其二，九十八随眠的系统化程度远超经藏描述，其「三界五断」的配分是教理推演还是禅修经验的归纳，学界有分歧；其三，求那跋陀罗异译本与玄奘本的出入显示文本流变，两本所据梵本或不同层。本论与巴利《法集论》本母的平行性，是南北论藏共同祖本说的关键证据之一。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 五事（五位） | 色心心所不相应行无为总分类 |
| 心所 | 与心相应俱起之心理因素 |
| 不相应行 | 非心非色之抽象法（得、命根等） |
| 九十八随眠 | 三界五断配分之烦恼总数 |
| 萨迦耶见 | 身见，执五蕴为我之根本见 |
| 择灭／非择灭 | 由慧拣择得灭／不由择力之无为 |
