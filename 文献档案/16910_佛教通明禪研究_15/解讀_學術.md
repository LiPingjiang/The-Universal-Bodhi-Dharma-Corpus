# 佛教通明禅研究_15 — 学术解读

## 一、文献背景与成书

本条目是文献库编号 16910 的补充性条目（目录 README 标注编号 X15396），属于「佛教某某研究」丛编中带「_15」后缀的一期重编卷，同卷尚有「佛教四禅八定研究_15」「佛教十六特胜研究_15」「佛教不净观研究_15」等数十种禅学专题条目。就性质而言，它不是一部古代典籍的原典全文，而是一条名目式的研究纲要：全文仅四十余行，由一句话的文献概述、两条核心引文、一张术语表和相关文献链接构成，属于待充实的骨架条目，其可考的实质内容是汉传禅学体系中的一个特定法门——通明禅。

通明禅的教理渊源可以考实。它是汉地禅数之学中的一门，在南朝流传的禅经体系与天台智顗（538—597）的判摄中获得系统论述：《释禅波罗蜜次第法门》《法界次第初门》等书将通明禅列为四禅八定、六妙门等之外别立的一门，条目引文所谓「不同於四禪八定，別为一門」，正与智顗一系的分判相合。需要说明的是，引文「別为一門」的「为」字作简体字形，与全篇繁体不谐，可见条目在辑录时经过现代文本处理，并非迻录古书版刻，引用时应加甄别。

## 二、文本结构与核心思想

条目结构极为简明：概述语「觀息、色、心三事無礙，通明無障」十二字总摄全宗；两条引文一释立名（「通明禪者，觀息、色、心三事和合……故名通明禪」），一释果用（「此禪能發六通三明，故名通明」）；术语表列念息、色、心、通、明、禅、三界七目。其核心思想可析为三层：

其一，三事和合同观。通明禅不以息、色、心任何一事为单独所缘，而是于出入息、身色、心识三者同时起观，息依色、色依心，展转相依，一时照了。这种「三事俱观」的结构，与数息门专缘于息、不净门专取于色者迥异，是本门在所缘安立上的独特之处。

其二，依果立名。「通」指六通，「明」指三明，引文以「能發六通三明」解释通明之名，即以禅定所发之果用回注法门之名，这与天台文献以「从因得名」释数息、以「体用为名」释通明的思路一致。

其三，别立一门。通明禅超出根本四禅八定的通途次第之外，自成一路，故条目特别强调「別为一門」，提示读者不可将其简单归并入世间禅定的常规阶梯。

## 三、学术研究价值与争议

本条目的价值首先在于保存了通明禅这一冷门禅法的名目与基本定义，为研究者提供检索线索。通明禅是汉传禅学史上的专门题目：智顗称此门特胜能发三明六通、疾断结漏，后世禅宗兴起后此门传授渐衰，宋代以下几成绝学，故任何系统的汉地禅法史叙述都需为其留出位置。其次，条目术语表把通、明分列并配以梵语 Abhijñā、Vidyā，客观上触及六通（abhijñā）与三明（vidyā）在名词层面的对应问题，可供名数研究参考。

争议与疑点亦有可述者。第一，通明禅的经典出处问题：智顗所传禅法多源自罽宾、西域系统禅师东传之禅经，通明禅与《大集经》等所传禅法的关系，学界迄今没有定论，本条目对此全无交代，是明显的局限。第二，条目两条引文体例可疑：第二条径标「白話對照」，与「原文」对举，实为条目编者的改写撮述而非经本文字，作史料引用时须回核原典。第三，术语表英译「clarknowledge」显系排印之误，当读作 clear knowledge（清净之明），兹照录原档并加订正说明。
