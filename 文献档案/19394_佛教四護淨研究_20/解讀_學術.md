# 佛教四护净研究_20 — 学术解读

## 一、文献背景与成书

本卷属于佛教典籍语料库「佛教某某研究」专题辑录系列，由名目概述、核心段落选录、重要名句、术语对照表与相关文献链接五部分构成，并非古代单行流传的一部经论。卷首概述仅存「護命、護根、護心、護正念」八字名目；所辑「四護淨者：護命清淨、護根清淨、護心清淨、護正念清淨。如是四法，令梵行清淨」及「護命者，不殺生；護根者，守根門；護心者，令心不散；護正念者，常修正念」两段文字，语句平易、未标注所出经论，学术上应视为汇编式的白话重述，而非逐字引自某部经典的原文，引用时须回查原典。

就名目本身而言，「护」是佛教修行论中最基本的动词之一：戒、定、慧三学的入门功夫几乎都以「守护」来定义。汉译经论中未见与「四护净」完全相同的定名组合，但四支分项各有清晰可考的教义源头：护命对应不杀生戒与正命的守护；护根即经律反复申说的「根律仪」，守护六根门头使烦恼不于对境生起；护心通于念防护与心澄清；护正念则直指念根、念力与念觉支。把「净」字总括于四护之后，构成了「守护即清净、防护本身即是修行」的表述，与《清净道论》以「戒清净」为修定之基的进路可以互读。

## 二、文本结构与核心思想

本卷文本结构呈典型的专题辑录形态：第一部分以八字并列给出全部名目；第二部分先以「清净」贯穿四法作总释，再以「不杀生、守根门、令心不散、常修正念」逐项配以白话定义；第三部分重复征引，以示重点。其立意可以概括为三层。

第一，由外而内、由粗而细的防护次第：护命重在身行不害，是戒门；护根在于对境之际收摄六门，是律仪门；护心在于使心不随境流散，是定门前方便；护正念则要求正念恒常现前，贯摄前三种守护。第二，「护」与「净」同体：本卷不把清净安置在防护之外，而认为四护成就之时梵行即净，故末句归结为「令梵行清净」。第三，正念为总钥匙：四法以正念殿后而非居首，暗示前三种守护若无正念维系终必退失，这与《法句》「诸法心为前导」、念为一切善法前导的传统立场一致。

## 三、学术研究价值与争议

本卷的研究价值首先在名目考订：它是「以数字归纳法门」这一佛教文献编纂习惯的当代样本，研究者可借之观察现代辑录者如何从散见诸典的「护」字法门中提炼出一种组合，以及这种组合与原始经典中根律仪、正念、正命诸段落的对应与落差。其次，四护净把戒学（护命）、律仪（护根）与心学（护心、护正念）压入同一框架，为讨论早期佛教修行论中「戒、念、定」的过渡关系提供了一个简明切口。

争议点亦有可述：其一，「护命」应解为不杀生戒，还是兼含「正命」（生计清净），本卷白话对照取前一解，而若与「四清净」类的名目（正语、正业、正命）合观，后解亦通，整理者当注明两可。其二，本卷术语表所给「Āṇāipaṭipā」等巴利转写，字形可疑，与学界通行的转写规范不合，疑为辗转抄录致讹，读者使用时宜以通行转写及原典复核。其三，「四护净」与南传「四护」类名目的对应关系尚待专门考察，本卷未给出文献出处，据实说明，只能存疑备考。

| Catasso-rakkhā | 四护 | four protections |
| Āṇāipaṭipā（文档原转写，疑有讹误） | 护命 | protecting livelihood |
| Indriya-rakkhā | 护根 | guarding faculties |
| Citta-rakkhā | 护心 | protecting the mind |
| Sati-rakkhā | 护正念 | protecting mindfulness |
| Brahmacariya | 梵行 | holy life |
| Visuddhi | 清净 | purity |

说明：表中「四护」总名对应巴利 rakkhā（守护）一系的用法；「护根」与通行名相 indriya-saṃvara（根律仪）相当，「护正念」与 sati（念）相当；文档所给第一行转写存疑，已如上文注明。
