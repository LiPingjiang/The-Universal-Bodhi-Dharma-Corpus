# 六十如理论注 — 学术解读

## 一、文献背景与成书

《六十如理论注》（Yuktiṣaṣṭikāvṛtti）为月称（Candrakīrti，约600-650年）所造——所注之本为龙树《六十如理论》（Yuktiṣaṣṭikā，六十颂论缘起正理），约成书于7世纪。龙树《六十如理论》与《中论》《七十空性论》《回诤论》等同属其论颂群，篇幅适中、主题集中；月称为之作注，是其注释工程（《中论》注为《明句论》，《入中论》有自注）的一部分。本注梵本大半存世（20世纪经发现校勘），完整藏译收入丹珠尔；汉地无古代译本，现代有据梵藏的译注与研究。

月称的注释将龙树六十颂的义理从应成派立场加以系统化，是连接龙树原典与后期应成诠释的关键中继文本。

## 二、文本结构与核心思想

龙树颂本以六十偈阐明**缘起正理**（yukti），月称注释的义理骨架为：

**其一，缘起与无自性的同一**：由缘起故知无自性，由无自性故离有无二边——这是《中论》"众因缘生法，我说即是空"的展开：缘起本身就是无自性的别名，不是"缘起之外另有一个无自性"。

**其二，缘起的双遮功能**：月称注释中最具特色的发挥——**缘起有二用：遮自性有，兼遮断灭无**。执有者（实在论者）见缘起而知其无自性（条件所生，故无独立实体）；执无者（虚无论者）见缘起而知其非断灭（条件相续，故非空无所有）。故缘起一义，双治二病——中观之所以称"中"，正在于此：一个概念同时治两种相反的病。

**其三，缘起非徒理论，实为证入之门**：注释引"见缘起即见法，见法即见佛"之义——缘起不是书斋里的哲学命题，而是观修与证悟的对象；如实见缘起的当下，即是见实相、见佛。

**其四，对轮回与涅槃的如幻诠释**：颂与注中对"缚与脱""有为与无为"等成对概念作如幻的抉择——轮回如幻，故可出离；涅槃亦非实有之物，唯是惑业的止息。

## 三、学术研究价值与争议

研究价值方面：（1）本注是研究月称对龙树"论颂群"（除《中论》外的短论）系统诠释的代表作，与《明句论》对读可见其诠释方法的一致性；（2）"缘起双遮"的表述是应成派对"中道"最凝练的概括，在藏传格鲁派教学中（宗喀巴《中论广释》等对此论的引用）被定为标准教理；（3）注释中与正理派、唯识师的交涉段落，是7世纪印度哲学论战的资料。本注的梵文校勘与研究由Christina Scherrer-Schaub 等学者完成，是国际中观研究的重点文本之一。

争议问题包括：（1）《六十如理论》颂文的传承与文本分层——月称所据底本与其他传本（藏译另有异本）的出入；（2）"见缘起即见佛"的诠释幅度——此语在经中的原义与月称（及后世格鲁派）"观修缘起即是观佛"的义理化引申之间的关系；（3）月称对颂中若干偈的应成式解读是否为龙树本怀——"以注代论"的诠释史问题（历代有"月称是否过度系统化龙树"的讨论）。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 缘起（pratītyasamutpāda） | 依因缘而起，与无自性同义 |
| 双遮 | 缘起同时遮"自性有"与"断灭无" |
| 断灭（uccheda） | 否定因果相续的虚无论 |
| 如理（yukti） | 符合实相的正理 |
| 见缘起即见法 | 缘起为证入实相之门的经义 |
| 应成（prāsaṅga） | 月称所承的归谬论法 |
