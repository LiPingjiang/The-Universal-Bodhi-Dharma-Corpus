# 大乘起信論裂網疏

## 一、概述

**大正藏編號**：T1850（《大正新脩大藏經》第 44 冊）

**全稱**：《大乘起信論裂網疏》

**別稱**：《起信論裂網疏》《裂網疏》

**撰者**：明·智旭（1599—1655），靈峰蕅益沙門，明末四大師之一（蓮池、紫柏、憨山、蕅益）。俗姓鍾，名際明，字蕅益，江蘇吳縣人。早年以儒學闢佛，後讀蓮池大師《自知錄》而改信佛法，二十四歲依憨山大師門人雪嶺剃度。博通諸宗，融攝天台、唯識、淨土、律宗，著作極富，後人輯為《蕅益大師全集》。

**卷數**：六卷

**所釋論本**：《大乘起信論》二卷，唐·實叉難陀（Śikṣānanda）新譯本（T1667）

《大乘起信論裂網疏》是智旭對實叉難陀新譯《起信論》的系統注疏。書名「裂網」，意為破除法相宗與法性宗二宗差別見解之網。智旭認為，歷代注疏者或執法相、或執法性，各立門戶，如蛛網纏縛，遮蔽了《起信論》的圓融本旨。他以天台「藏、通、別、圓」四教中之圓教配釋「一心」，會通二宗，彰顯一心三寶之圓頓義趣。

此書與法藏《起信論義記》（T1846）、元曉《起信論疏》（T1845）等並為《起信論》重要注疏，但立場獨特——法藏以華嚴宗立場作疏，元曉以新羅法相通宗作疏，而智旭以天台圓教為宗，以「一心三寶」貫穿全論，自成一家之說。書中對真諦舊譯與實叉難陀新譯二本對照參對照參閱，稱「二譯對閱，唐本更為文顯義順」，足見其治學之嚴謹。

注疏本有清代觀竺《講錄》六卷。

## 二、核心段落

### （一）開篇總序：佛祖之道以心傳心

**原文（CBETA T44n1850, p.0877a）：**

> 佛祖之道，以心傳心。菩薩造論通經，亦唯此一大事。故云：十方諦求，更無餘乘。縱令曲為群機，循循善誘，從實施權，說種種道。譬如三草二木，受潤不同，而能潤之雨，原只一味。故云：如食石蜜，中邊皆甜。

**白話對照：**

佛祖之道，是以心傳心。菩薩造論通經，也唯有這一大事因緣。所以經中說：十方諦實推求，更無其餘乘教。縱然曲隨各類根機，循循善誘，從實智施設權宜，說種種道法——譬如三草二木，承受雨水滋潤各有不同，然而能滋潤的雨，原本只有一味。所以經中說：如食石蜜，中間和邊緣都是甜的。

### （二）論「裂網」之義：破二宗之執

**原文（T44n1850 續）：**

> 此論以藏、通、別、圓四教中之圓教，配以一心之眾生心，而舉出圓教觀境之妄心。

**白話對照：**

此論以藏、通、別、圓四教中的圓教，配釋「一心」的眾生心，從而舉出圓教觀照境界的妄心。

（按：「裂網」之名，意在破除法相宗與法性宗的對立見解。法相宗執有，法性宗執空，各成一網。智旭以天台圓教「即空即假即中」的一心三觀貫通二者，使《起信論》「一心二門」的圓融本旨得以顯發。）

### （三）釋「一心三寶」

**原文（CBETA T44n1850 卷第六，修信分釋）：**

> 信根本者，真如即是一切三寶根本。謂我現前介爾心性，離虛妄相，平等平等，即真如體大，名為法寶。雖復覓之了不可得，而性自神解，靈明不昧，即真如相大，名為佛寶。一切色心依正，十方虛空，千如百法，並此介爾心中所現之影，與能現心無是非是，不可分離剖析，即真如用大，名為僧寶。究竟說此一心三寶，名之為佛。所以具足無邊功德，必應頂禮恭敬供養，聽聞所說正法，如法修行，迴向一切智也。

**白話對照：**

所謂「信根本」，真如即是一切三寶的根本。就是說：我現前這一念微小的心性，遠離虛妄之相，平等平等——這就是真如的「體大」，名為法寶。雖然尋覓它了不可得，但它的本性自然神解、靈明不昧——這就是真如的「相大」，名為佛寶。一切色心依正、十方虛空、千如百法，都是這一念微心中所顯現的影像，與能現之心既非「是」也非「非是」，不可分離剖析——這就是真如的「用大」，名為僧寶。究竟而言，這「一心三寶」就名為佛。所以佛具足無邊功德，必須頂禮恭敬供養，聽聞所說正法，如法修行，迴向一切智。

### （四）釋「五門行」——止觀合門之義

**原文（CBETA T44n1850 卷第六續）：**

> 修五門行，能成此信。所謂施門、戒門、忍門、精進門、止觀門。此即六波羅蜜，從初即是隨順真如之行。而作五門說者，若至信成就後，則一一皆到彼岸，無有不智之禪，無有不禪之智，故不妨說六。今為未入正定聚人，倘以止觀分二門，無由契會真如性故，所以合為一也。當知前四門是助行，止觀門是正行。正助合行，以成福德智慧二種莊嚴，顯發真如也。

**白話對照：**

修習五門行，能成就此信。所謂施門、戒門、忍門、精進門、止觀門。這就是六波羅蜜，從初發心即是隨順真如的修行。之所以說為五門而非六門，是因為若到了信成就之後，則一一都到彼岸，沒有不具智慧的禪定，沒有不具禪定的智慧，所以不妨說為六度。如今是為未入正定聚的人說——如果將止觀分為二門，便無從契會真如性的緣故，所以合為一門。應當知道：前四門是助行，止觀門是正行。正行與助行合修，以此成就福德、智慧二種莊嚴，顯發真如。

### （五）釋「四種信心」

**原文（CBETA T44n1850 卷第六續）：**

> 信有四種：一信根本，謂樂念真如法故。二信佛具足無邊功德，謂常樂頂禮恭敬供養，聽聞正法，如法修行，迴向一切智故。三信法有大利益，謂常樂修行諸波羅蜜故。四信正行僧，謂常供養諸菩薩眾，正修自利利他行故。

**白話對照：**

信心有四種：第一，信根本——即樂於憶念真如之法。第二，信佛具足無邊功德——即常常樂於頂禮恭敬供養，聽聞正法，如法修行，迴向一切智。第三，信法有大利益——即常常樂於修行諸波羅蜜。第四，信正行僧——即常常供養諸菩薩眾，正修自利利他之行。

### （六）論二譯對照

**原文（T44n1850，據 CBETA 校錄）：**

> 裂網疏稱二譯對閱，唐本更為文顯義順。

**白話對照：**

《裂網疏》中稱：將二種譯本對照閱讀，唐代實叉難陀的新譯本更為文句顯明、義理順暢。

（按：《大乘起信論》有二譯：一為梁·真諦舊譯一卷（T1666），二為唐·實叉難陀新譯二卷（T1667）。智旭此疏以新譯為本，同時參照舊譯，擇善而從。法藏《義記》所釋為真諦舊譯，智旭選擇新譯，別開生面。）

## 三、名句

1. **「佛祖之道，以心傳心。菩薩造論通經，亦唯此一大事。」**——全書開篇第一句，將《起信論》定位為「以心傳心」的教外別傳，彰顯智旭會通禪教的思想特色。

2. **「我現前介爾心性，離虛妄相，平等平等，即真如體大，名為法寶。雖復覓之了不可得，而性自神解，靈明不昧，即真如相大，名為佛寶。」**——智旭以「一心三寶」配釋「體相用三大」，將《起信論》的三大理論與三寶信仰圓融會通，是其詮釋中最具原創性的段落。

## 四、術語表

| 術語 | 釋義 |
|------|------|
| 裂網 | 破除法相宗與法性宗二宗對立見解之網，會通二宗以顯《起信論》圓融本旨 |
| 一心三寶 | 智旭的創見：以真如體大為法寶、相大為佛寶、用大為僧寶，一心即具三寶 |
| 藏通別圓 | 天台化法四教：藏教（小乘）、通教（通大小乘）、別教（大乘別教）、圓教（圓融無礙） |
| 五門行 | 施門、戒門、忍門、精進門、止觀門，即六波羅蜜以止觀合為一門而成五門 |
| 二譯對閱 | 將真諦舊譯與實叉難陀新譯對照參閱，智旭以新譯為主 |
| 一心二門 | 《起信論》核心架構：心真如門（清淨本性）與心生滅門（現象世界），同出一心 |
| 體相用三大 | 《起信論》所立真如的三種屬性：體大（平等不增不減）、相大（具足功德）、用大（能生善因果） |
| 四種信心 | 信根本（真如）、信佛、信法、信僧，為修行信心分的核心內容 |
| 正定聚 | 已入正定、決定不退的修行位次，與之相對為「未入正定聚」的初機眾生 |
| 助行與正行 | 前四門（施戒忍進）為助行，止觀門為正行，正助合行以顯真如 |
