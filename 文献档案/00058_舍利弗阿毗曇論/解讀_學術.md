# 舍利弗阿毗昙论 — 学术解读

## 一、文献背景与成书

《舍利弗阿毗昙论》（Śāriputrābhidharma-śāstra），姚秦罽宾三藏昙摩耶舍共昙摩崛多于弘始九年（407年）译出，三十卷，收于《大正藏》第二十八册。本论相传为佛弟子舍利弗所造，学界一般判属法藏部（或谓雪山部）之论书，代表早期阿毗达磨之形态——与有部七论、巴利七论鼎足而三，是三大阿毗达磨系统中唯一完整汉译的非有部论藏。

论序称：「阿毗昙，秦言无比法，出自八音，亚圣所述。作之虽简，成命曲备。」并述其体例「四分」：问分、非问分、摄相应分、绪分（序分）。

## 二、文本结构与核心思想

全书四分三十三品：

- **问分**（十品）：以「问曰／答曰」的界定体逐门定义十二入、十八界、五阴、四圣谛、根、七觉支等基本法相。如问分入品：「问曰：几入？答曰：十二……内六入、外六入」，并对每一入给出多重定义（眼入即眼根、即眼界、即四大所造净色），显示定义递进的注释技术。
- **非问分**（十一品）：不求定义而铺陈诸法内容——界、业、人、智、缘、四念处、四正勤、四神足、四禅、道、烦恼等。禅定品记「共明想定」：取火光、日月星光、摩尼珠光为所缘而修定，成后得「天眼清净过人」，见众生生死、善道恶道；非问分又记「无间定」：思惟无常、苦、空、无我、涅槃寂静而得定心，得「初圣五根」（信进念定慧），正向决定、离凡夫地，「若中命终，无有是处」——趋向须陀洹果的决定性禅定。
- **摄相应分**（摄、相应二品）：处理诸法之互摄与心心所相应关系，与巴利《法集论》的心所分析平行。
- **绪分**（十品）：遍品、因品、名色、假结、行、十八触、假心、十不善业道、十善业道、定等，收束全论。

思想特色：以「无比法」为名，强调对法的精密分别；「人」与「假」（假名施设）独立成品，显示此系对人格连续性问题的独特处理。

## 三、学术研究价值与争议

**研究价值**：本论与巴利七论（尤其《分别论》《人施设论》）结构深度相通，为「阿毗达磨共同祖本」假说提供核心证据——法藏部与锡兰上座部同出分别说系，二系论书的平行使学者得以重构部派分化前的论藏雏形；其译语古朴（407年译出，早于玄奘系论书二百余年），是汉语阿毗达磨术语史的上游样本。

**争议问题**：其一，部派归属——法藏部说为主流，但「雪山部」说亦有依据（论中不见法藏部特有主张），至今未决；其二，「舍利弗造」的托名性质明显，实际成书当在佛灭二至三百年间；其三，此论无注释传统存世（与有部、巴利两系皆有大量注疏对照），文本的细部理解困难较多；其四，其「问分／非问分」的二分体例是否代表早期论书的原始形态，抑或地方性编排，学界仍在讨论。日本学者桧材智岳、伊藤秀宪等曾以本论与巴利论藏作系统比较。

| 无比法 | 阿毗昙之意译，殊胜无对之法义分析 |
| 问分／非问分 | 以问答界定／直接铺陈之两种体例 |
| 入（Āyatana） | 处，认识生起之根境十二处 |
| 共明想定 | 以光明相为所缘之禅定 |
| 无间定 | 无间趋向圣果之决定性定 |
| 初圣五根 | 信进念定慧五根之初得 |
