# 佛教業力研究 — 学术解读

## 一、文献背景与成书

本条目为语料库中的综述性专题文献，以「业」（梵 karma，巴利 kamma，义为「造作」）与业力为主题，汇辑阿含圣典、大乘经及部派、大乘论典中的业力学说，属于教义学资料汇编而非单一古籍。业说的思想史背景是：佛陀明确以「思即是业」（《增支部》六之六三，汉译阿含同义）重新定义 karma，把业的重心从婆罗门教祭祀的外在仪式行为转移到内在动机，这是印度宗教史上的范式转换。条目所据文本各有源流：《中阿含經》（T26）的鹽喻诸经说明业报可被修行稀释；《雜阿含經》（T99）说「随所作业则受其报」；《大寶積經》（T310）提供「如影恒逐形」的教证。论典方面，《成實論》（T1646，鸠摩罗什译）论无表业；世亲《成業論》（T1616，玄奘译）专破诸部业体说而立思愿熏种之义，是业力理论的根本论书；唯识学以第八阿赖耶识持业种，回应「造业已久，其谁记忆、谁受果报」的诘难。部派中正量部立「不失法」、经量部立「种子熏习」，皆是业力相续问题的理论尝试。条目以「業力」定名，通行学界多称「业」或「业报」说，此处从原文档题名。

## 二、文本结构与核心思想

条目正文分概念概述、核心经文选录、重要名句、术语对照表、相关文献五节。核心思想可归纳为四点：第一，业的本质是「思」（cetanā）——发动身口意三业的意志心所，故业的轻重在动机而不在外相，「意为前导，意造诸业」，三业之中意业为主。第二，业的分类体系周密：以载体分身、口、意三业；以道德性分善、恶、无记；以感果功能分引业（招感六道总报，决定生于何道）与满业（招感别报，决定一道之内的贫富寿夭）；以受报时间分现报、生报、后报；另有定业与不定业之别。第三，业力不失——「假使百千劫，所作业不亡；因缘会遇时，果报还自受」，业的潜在力量超越一期生死而相续，其保存机制在部派间引发无表色、不失法、种子等诸说竞争，最终由唯识种子熏习说集大成。第四，业可转变：鹽喻经以一把盐入杯水则咸、入恒河则淡为喻，说明心量广大、修行深厚者能令重业轻受，忏悔与修善可以转业——这使佛教业说区别于机械宿命论。条目总结佛教业说的三大特点：自作自受而非神判、业可转化而非定命、缘起无作者而业果宛然，即「不思议业力」的中道。

## 三、学术研究价值与争议

本条目的学术价值在于完整呈现了业力学说从经教到论典、从部派到大乘的理论深化链条，尤以《成業論》与唯识种子说的理论线索最为珍贵。主要争议有四：其一，业体之争——说一切有部的无表色、正量部的不失法、经量部的种子、唯识的阿赖耶识持种，是印度佛教哲学最激烈的论域之一；其二，业力与自由意志的关系：业若决定果报，当下的选择是否自由？学界多以「业决定境遇而不决定回应」作调和性解读；其三，定业能否转、转业的界限何在，经论间有不同表述，密教更有「灭定业」的陀罗尼说，引发教判层面的讨论；其四，现代诠释将业力读作道德因果的心理学模型或叙事伦理，与基因、环境决定论的对话成为比较哲学前沿。本库另有同名系列目录如 `05484_佛教業力研究_1`、`05990_佛教業力研究_2` 等，各自独立成篇；本篇侧重业的定义、分类与相续机制，与 `04976_佛教因果研究`（因果结构）、`04979_佛教果報研究`（果报分类）分工互参。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 业（karma） | 身口意的造作及其潜在力量 |
| 思（cetanā） | 业之自体，造作的意志心所 |
| 三业 | 身业、口业、意业，以意业为主 |
| 引业／满业 | 招感总报与别报的两种业 |
| 定业／不定业 | 果报决定与否之业 |
| 现报／生报／后报 | 今生、次生、多生之后受报的业 |
| 不失法／业种子 | 正量部与经量部、唯识对业力保存的说明 |
| 共业／别业 | 感得共同环境与个别境遇之业 |
