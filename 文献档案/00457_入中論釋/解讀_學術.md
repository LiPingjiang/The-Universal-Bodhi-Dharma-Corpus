# 入中论释 — 学术解读

## 一、文献背景与成书

《入中论》（Madhyamakāvatāra）是印度中观应成派（Prāsaṅgika）代表论师月称（Candrakīrti，约公元600-650年）所造，与月称自著的《入中论自释》（Madhyamakāvatārabhāṣya）并行，是中晚期印度中观学的巅峰之作。月称出身南印度萨曼多婆罗门种姓，长期住持那烂陀寺，其思想经译传入藏后成为藏传佛教格鲁派中观学的正统。

本论无古代汉译，直至20世纪三四十年代，法尊法师依藏译本译为汉文，并译出月称《入中论自释》要点，汉地学界始得窥其全貌。梵本至今未发现完整写本，研究主要依据藏译及梵文断片。藏传方面，宗喀巴著有《入中论善显密意疏》，为格鲁派权威注解。

## 二、文本结构与核心思想

《入中论》共十一章，巧妙地以菩萨"十地"为骨架展开，每章对应一地，末章赞叹般若波罗蜜：

1. **第一至第五章**（欢喜地至难胜地）：依龙树《中论》义，逐地阐述布施、持戒、忍辱、精进、禅定诸波罗蜜，兼破各层面的实执。
2. **第六章（现前地）**：全书核心，篇幅几近半部，以般若波罗蜜统摄空性正见。此章依次：出离二乘而赞叹菩提心；以"七相推求"（如以车轮等七相观察而不可得"车"，喻人我与法我皆不可得）抉择无我；广破唯识宗"自证分"与依他起实有；阐明二谛——世俗谛唯是缘起假名的安立，胜义谛离一切戏论。
3. **第七至第十章**（远行地至法云地）：明方便度、愿度、力度、智度，显示空性与大悲双运的菩萨行。
4. **第十一章**：结叹般若，归趣佛果。

其核心思想可归纳为：

- **缘起性空的应成派诠释**：本档案原文所录"众因缘生法，我说即是空，亦为是假名，亦是中道义"，本是《中论》第24品偈颂，月称以之为全论纲领，论证"正因空性，缘起方成"——正因为事物没有自性，因果、运动、变化才可能成立。
- **不立自宗，唯破他执**：应成派不许立"自续"的比量式，只以对方不得不承许的例子引出矛盾，是《中论》破而不立方法的极致化。
- **二谛的分工**："若无世俗，胜义不入；若无胜义，不得涅槃"——名言中因果、修行、证果宛然而有，胜义中一切不可得，二者不相妨碍。

## 三、学术研究价值与争议

**研究价值**：《入中论》是理解月称思想、应成自续两派分野的最主要文献，也是藏传格鲁派"五部大论"课程之一，研究藏传佛教义学教育体系必读。第六章对唯识"自证"的批驳，是中观与唯识论诤史上的标志性文本。

**代表学者与观点**：20世纪上半叶，柔克义以前的研究多经藏译；1967年舍尔巴茨基等人的俄系佛教学已有涉及；英文世界最重要的译注是C.W. Huntington Jr.与格西旺秋合作的《空之空性》（*The Emptiness of Emptiness*, 1989），译出第六章并引发关于应成派"是否否定一切理性论证"的长期论战（Huntington倾向诠释学式解读，与以格鲁派"正理"传统理解月称的学者针锋相对）。杰弗里·霍普金斯及其学派则系统译介月称与格鲁派注释。

**争议问题**：（1）应成派是否彻底否定比量，学界解读分歧极大；（2）月称对唯识的批判是否"公平"，现代唯识学者多有再检讨。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 月称（Candrakīrti） | 应成中观派集大成论师，《入中论》作者 |
| 应成派/自续派 | 中观两支：应成派不许自立因量，自续派许之 |
| 七相推求 | 以七种方式寻觅"车"而不可得，抉择无我 |
| 二谛 | 世俗谛（假名安立）与胜义谛（离戏论） |
| 十地 | 菩萨修行的十个阶位，《入中论》的结构骨架 |
| 萨迦耶见 | 执五蕴为"我"的身见，烦恼之根源 |
