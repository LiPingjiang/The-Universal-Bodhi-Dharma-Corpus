# 佛教四禅定研究_18 — 学术解读

## 一、文献背景与成书

本条目是语料库中的综述性研究条目，不是一部古籍。原文档由一句概述（「初禪離生喜樂地、二禪定生喜樂地、三禪離喜妙樂地、四禪捨念清淨地」）、两则引文与一张术语表构成，属名目式编目。同库另有一条同名「佛教四禪定研究_18」（编号 18470），两条名目相同而各自独立；依分工原则，彼条以禅支分析与四禅公式为纲，本条以禅定思想史的谱系比较为纲——把四禅放回佛教禅定学与古印度禅定传统、汉传与南传分流的大脉络中观察，两相对读。以下以原文档名目为准撰述。

从思想史看，四禅的位置极为特殊。其一，它处于佛陀成道叙事的中心：佛依四禅发三明证觉，四禅由是「佛法之定」的标志，与外道共通的四个无色定（空无边处至非想非非想处）相区别——经律中佛屡言「第四禅」为如实智见的升起之地。其二，它是南北传定学的共同骨架：巴利《清淨道論》的定篇以四禅为三十八业处所通的核心安止，汉译《俱舍論》《瑜伽師地論》以四禅为根本定地，摄一切世间定。其三，汉地「禅」字本身即「禅那」（dhyāna）之略——后汉以来译语定型，至唐代禅宗兴起，「禅」的语义重心由定学转向见性，四禅八定在汉地反而让位于祖师禅的顿悟传统，此一语义漂移是禅定史上最大的分水岭。

## 二、文本结构与核心思想

原文档所示义理可综述为三重。

其一，「四地」名号的体系化。概述所列四地名（离生喜乐地等）是阿毗达磨对经文公式的提炼：每地以「所得之受」与「所舍之支」复合命名——离（所离）生喜乐（所得）、定生喜乐、离喜（所离）妙乐（所得）、舍念清净（所得）。命名本身就是一张修行地图。

其二，四禅与无色定的分界。四禅属「色界定」，尚有微妙身受与喜乐之受；无色定（含于八定的后四）超越色想，唯余识与舍。佛教把四禅划为发慧正地，无色定因想心过分微昧反非观慧所依——此判摄是佛教定学区别于外道禅定的理论枢纽。

其三，引文的叙事层位。核心引文「離欲離諸惡不善法……入初禪具足住」为经本公式，白话对照「尋伺息故……入二禪具足住」为其递进句——两条引文所保存的，正是经文中禅定次第叙述的标准句式。

## 三、学术研究价值与争议

本条目的价值在于为四禅的思想史定位保存了名目与经典句式。学术争议有三：一是「依四禅发慧」的历史真实性——成道叙事中四禅与三明的组合，学界或视为古法的实录、或视为教理的追认（四禅作为「佛法不共定」可能晚于早期禅定实践），与《尼柯耶》中多处禅定叙述的层位分析相关；二是四禅五支与无色定的对比研究——《清淨道論》以「禅支」唯属色界定、无色定无支可说，此结构性差异是南北传一致的阿毗达磨共识，而其心理学解释（为何超越色想的心境不可分析为支）仍在讨论；三是汉地语义漂移的影响评估——禅宗「不立文字、直指人心」把「禅」从技术性定学转为见性之学，太虚以降的教界学者与铃木大拙以来学界对「禅那之禅」与「禅宗之禅」的辨析，至今是禅学研究的基本课题，其评价从「中国佛教对定学的创造性转化」到「定慧分离的历史代价」不一而足。
