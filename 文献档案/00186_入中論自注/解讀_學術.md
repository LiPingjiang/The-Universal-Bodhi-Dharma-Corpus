# 入中论自注 — 学术解读

## 一、文献背景与成书

《入中论自注》（Madhyamakāvatārabhāṣya）为月称（Candrakīrti，约600-650年）所造——月称先造《入中论》（Madhyamakāvatāra）颂本，继而自作长行注释，颂与自注合为完整的思想文献，约成书于7世纪。月称是那烂陀寺后期住持，佛护（Buddhapālita）再传（经月称的发扬，佛护所代表的归谬路线被确立为"应成派"正统），其《明句论》《入中论》及自注构成应成中观的经典三件套。本论梵本大半存世，完整藏译收入丹珠尔；汉地无古代译本，现代有法尊法师《入中论》译本（颂释俱译）流传，影响甚广。

《入中论》的体裁特色是以"十波罗蜜多"配菩萨"十地"——每地配一度，从初地布施到十地智度，第六〈现前地〉配般若波罗蜜，是全论的重心所在，篇幅独大。

## 二、文本结构与核心思想

颂本以十地十度为骨架，其中第六〈现前地〉广破"四句生"：

**其一，四句破生**：非自生、非他生、非共生（自他共）、非无因生——四门俱闭，则"自性生"不可得。这一框架继承并扩充《中论》第一品（观因缘品）的归谬论证，把龙树对"生"的遮遣发展为完备的论战系统。

**其二，自注破"他生"尤详——直指唯识**：第六地注释中最大篇幅用于驳斥唯识师所立"依他起自相有"。月称的核心论证极为锋利：**"若依他起有自相，则不待他而成，何名依他？"**——依他起的定义就是"依待他缘而起"；若它有自相（独立的自体），它就不需要依待任何东西，那它就不是"依他起"了。定义与立场自相矛盾。此外还系统驳斥了唯识"自证分"说，认为识自我证明的设定同样落入自性执。

**其三，二谛安立**：月称在破生之后安立二谛——世俗谛中因果宛然（缘起的假立有效），胜义谛中生不可得。其特色是"世俗如幻"的彻底化：连世俗层面的法也只如幻事般假立而有，无毫许自性。

## 三、学术研究价值与争议

研究价值方面：（1）本注是理解月称思想最权威的文献——自注的意义在于作者本人对颂文的"官方解释"，避免了后世注释的分歧；（2）第六地对唯识的批评，是中观与唯识论战的最高潮文本，玄奘所传的汉地唯识学恰好缺少这一"对方视角"，故本注成为汉地学界反思唯识立场的必读参照；（3）"若依他起有自相，何名依他"的论证被视为中观批评史上最著名的归谬之一，在现代中观研究（如 Jeffrey Hopkins、Geshe Lhundub Sopa 对空性的英文讲授体系）中被反复剖析。

争议问题包括：（1）月称对唯识的批评是否击中要害——唯识家可回应"自相有"义另有分寸（护法的四分说并非月称所破的粗相），这场论战在藏传"宗义学"教材中至今作为教学案例被逐句重演；（2）应成派"自无所立"的彻底程度——连二谛的安立也只是"他许"（随顺世间与教典）？学界对月称是否持"彻底的语用论"立场有不同判读；（3）法尊译本的风格与术语问题，使汉语学界对若干关键颂段的理解仍有讨论。

## 四、术语对照表

|---|---|
| 四句生 | 自生、他生、共生、无因生四种生论 |
| 依他起 | 唯识所立依他缘而起的法性 |
| 自相（svalakṣaṇa） | 独立自体，月称所遮的核心 |
| 现前地 | 十地之第六，配般若波罗蜜 |
| 二谛 | 世俗如幻有、胜义无生 |
| 应成（prāsaṅga） | 唯以归谬破他的论证方式 |
