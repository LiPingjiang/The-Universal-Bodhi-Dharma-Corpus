# 四分律疏·原文

## 一、概述

四分律疏，指唐代道宣律师（596-667）所撰《四分律删繁补阙行事钞》，略称《行事钞》，收录于大正藏第1804号。道宣为律宗南山宗之创始人，十六岁从智顗出家，二十岁从智首受具足戒，后于终南山丰德寺撰成此书初稿，武德九年（626）撰成，贞观四年（630）重加修定。全书分为三卷（古本作三卷，共三十篇），以"删繁补阙"为编纂宗旨，对四分广律加以删繁、补阙，叙述四分律之要义，并参酌诸律诸家之说，详述律行之故实制规。其序文概括全书结构为"上卷则摄于众务，成用有仪；中卷则遵于戒体，持犯立忏；下卷则随机要行，托事而起"。此书与道宣所撰《四分律含注戒本疏》《四分律删补随机羯磨疏》并称南山三大部，为律宗之权威著作。

## 二、核心段落

### 段落一：序文总纲

**原文：**

> 夫戒德难思，冠超众象，为五乘之轨导，实三宝之舟航。依教建修，定慧之功莫等，住持佛法，群籍於兹息唱。自大师在世，偏宏斯典，爰及四依，遗风无替。逮於像季，时转浇讹，争锋唇舌之间，鼓论不形之事。

**白话翻译：**

戒律的功德难以思议，超越一切万法之上，是五乘佛法的轨范导师，确实是三宝的舟航。依照教法建立修行，禅定与智慧的功效都不能与之相等；住持佛法的重任，在众多典籍中也以此最为要紧。自从佛陀在世时，就特别弘传这部律典，乃至传到四依之人，遗风未曾中断。到了像法与末法时代，时风逐渐浇薄讹误，人们只在唇舌之间争锋，鼓吹一些不合形相的空论。

### 段落二：编纂宗旨与方法

**原文：**

> 余因听采之暇，顾盼群篇，通非属意，俱怀优劣。斐然作命，直笔具舒，包异部诚文，括众经随说，及西土贤圣所遗，此方先德文纪。搜括同异，并皆穷尽。长见必录，以辅博知；滥述必翦，用成通意。或系文以显事用，或略指以类相从，或文断而以义连，或徵辞而假来问。如是始终交映，隐显互出，并见行羯磨，诸务是非，导俗正仪，出家杂法，并皆揽为此宗之一见，用济新学之费功焉。

**白话翻译：**

我在听闻采录律藏的空闲之时，审阅各种律学篇章，发现它们虽然都不算特别用心，却都各有优劣。于是发心撰写，秉笔直书，收录各部派律典的诚谛文字，统括众经中随缘所说之戒法，以及西土贤圣所遗留的论述、中土先德的文献记录。搜罗同异之说，并皆穷究其源。正确的见解必定记录，以辅助广博之知见；浮滥的叙述必定删剪，以成就通达之义理。有时系属经文以显明事相之用，有时略作指引以类相从，有时文字虽断而以义理相连，有时徵引文辞而假借设问。如此始终交相映照，隐显互出，将现行羯磨法、各项事务之是非、引导俗众之正仪、出家之杂法，都揽收为此宗之统一见解，用以济助新学之人免于徒费功夫。

## 三、名句

1. "夫戒德难思，冠超众象，为五乘之轨导，实三宝之舟航。"——道宣以戒德为修行之本，五乘之导，三宝之舟航，开宗明义。

2. "包异部诚文，括众经随说，及西土贤圣所遗，此方先德文纪。"——此为行事钞"删繁补阙"之编纂原则，广引诸部，择善而从。

## 四、术语表

| 术语 | 释义 |
|------|------|
| 行事钞 | 《四分律删繁补阙行事钞》之略称，道宣律师撰 |
| 删繁补阙 | 删除繁冗之说，补正缺失之义，为行事钞之编纂宗旨 |
| 戒体 | 受戒时于身心上所发之防非止恶之功能，为戒法之根本 |
| 止持作持 | 止持为止恶之门，作持为作善之门，二者合为完整之戒行 |
| 开遮持犯 | 戒律之四维度：开（开许例外）、遮（禁止）、持（遵守）、犯（违犯） |
| 三聚净戒 | 摄律仪戒、摄善法戒、饶益有情戒，为大乘菩萨戒之总纲 |
| 南山三大部 | 行事钞、含注戒本疏、删补随机羯磨疏三者之合称 |
| 羯磨 | 僧团中处理事务之方法，有单白、白二、白四三种 |
