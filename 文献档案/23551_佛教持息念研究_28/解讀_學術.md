# 佛教持息念研究_28 — 学术解读

## 一、文献背景与成书

本条目为「寰宇覺海·菩提法藏」语料库独立文献补充条目，编号 X22037，属第二十八批补充条目。同目录 README 记其状态为「待後續填充內容」，故此份《原文》为名目式纲要：概述一句，谓持息念「攝持出入息，令心專注」；正文存两段引文与一张八词项术语表。须如实说明：该条目是对持息念（安般念之又一译名）名目的纲要保存，非一部有传译史的独立典籍。

「持息念」即念安般、数息观的异译，其六门组织出于天台文献：隋智顗《六妙法門》（本库藏 `01406_六妙法門`）以数、随、止、观、还、净六门统摄持息修法，谓三乘行人共用此门而果位有别；其思想前源可溯至《大智度論》所引释，及汉魏以来《安般守意經》一路的禅经叙述。条目第一段引文「持息念者，謂數、隨、止、觀、轉、淨，如是六因妙門，從持息念中流出」所列六目中第五目作「轉」，与天台通行本之「還」字有异，此处依原文档为准照录并注明通行作「還」（还净之还）；「六因妙門」的表述亦与通行「六妙门」微异，一并照录。第二段「以持息念為根本，能生四禪四空定，及六妙門、十六特勝」点出持息念的果德谱系，十六特胜之名目见于《成實論》及天台诸书，谓胜于四禅八定之十六步观慧。

## 二、文本结构与核心思想

六妙门的结构是「三止三观」的阶梯。依原文所列六目：数（数息摄心）、随（不数而随息）、止（心止一处）、观（观息无常及身受心法）、转（通行本作还，转心还源、回观能观）、净（垢尽明生，净心显现）。前三是定门，后三是慧门；由数至净，正是由粗至细、由止至观、由凡入圣的完整路线。原文谓此六门「從持息念中流出」，其义有二：一是六门皆以出入息为所缘，不离一息；二是六门之果皆从摄持出入息这一根本功夫中生出，故概述言「攝持出入息，令心專注」。

术语表列 Gaṇanā（数）、Anugama（随）、Sthāpana（止）、Upalakṣaṇā（观）、Vivarta（转）、Pariśuddhi（净）六词，与引文六目一一对应，词形采梵语转写，当系编纂者据义构拟之对应；观其以 Vivarta 对「转」、以 Pariśuddhi 对「净」，正与原条目用「轉」字的取径一致。第二段引文所示果德谱系尤可注意：持息念一门能生四禅四空定（世间定）、六妙门（止慧双运）、十六特胜（观慧胜进），是汉传禅学「一门摄万流」思想的典型表述。

## 三、学术研究价值与争议

其一，「持息念」诸译名的流变是译经史材料：念安般、数息、持息念、安那般那诸名并行，各有时代与宗派印记，本条目取「持息念」为名而六目用「轉」字，与天台通行本对勘可见异文，其异文或存另一传承之旧，或为转录之变，姑存疑备考。其二，六妙门与十六特胜的关系是天台禅学研究的专题：智顗诸书于十六特胜的分配（对四禅八定各配观慧）与《成實論》所说不尽同，学者据以讨论天台对成实禅法的吸收与改造。其三，六妙门「止观并运」的结构对后代禅法影响深远：其后禅宗之「随息」、净土之「念佛数息」、近代居士佛教之呼吸法门，多见此结构的变体。其四，与南传系统的对读显示：巴利《清淨道論》安般念十六步骤（四念处各四）与汉传六妙门、十六特胜三分鼎立，同源异构，是禅法跨传统比较最现成的对照组。本库同批 `23549_佛教數息觀研究_28` 已就数息入门立论，本条目专论六门全体与果德谱系，两篇互注。
