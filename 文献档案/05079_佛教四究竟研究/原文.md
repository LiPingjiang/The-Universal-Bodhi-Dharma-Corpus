# 佛教四究竟研究 · 原文

## 一、概念概述

「四究竟」（梵 catvāraḥ paramārtha-dharmāḥ，巴 cattāri paramattha-dhammā，直譯「四勝義法」）指南傳上座部阿毗達磨所立的四種究竟法/勝義法：一、心（citta，識知所緣之心識）；二、心所（cetasika，與心相應之受想思等心理素質）；三、色（rūpa，物質現象）；四、涅槃（nibbāna，無為之寂滅）。其根本典據為覺音論師（Buddhaghosa，五世紀）《清淨道論》（Visuddhimagga，葉均譯本通行）第十四〈說蘊品〉之分析：一切有為法可析為心、心所、色三究竟法，涅槃是第四種無為究竟法；除此四者，一切概念（paññatti，施設、假名）皆是世俗諦而非究竟真實。《清淨道論》引《法集論》注（Atthasālinī）之傳統：「慧地諸法」以四究竟法、五蘊、十二處、十八界等次第鋪陳，而四究竟法是其總綱——「於此，心、心所、色三種是有為，涅槃是無為」。此說之義理特點：一、以「可經驗之元素」為真實，將人格、山河、自我等一律判為概念施設（如「我」「人」「眾生」是施設有而非究竟有），與佛教無我義直接相應；二、四法中涅槃是唯一無為法，是離繫之「諦義境」，前三為緣生之「時節、心、食、業」四因所生；三、與北傳阿毗達磨之對照：說一切有部立「三世實有、法體恆有」之七十五法，《俱舍論》（T1558）於五位七十五法外別立擇滅非擇滅三無為；唯識立五位百法、六種無為——其「分析法之究竟」的思路同源，而南傳唯此四種最簡。漢譯文獻中「究竟」亦常用指涅槃果位（「究竟涅槃」，《心經》），及《瑜伽師地論》「四究竟」之別說（煩惱究竟斷、苦究竟滅之義），本題以四究竟法（心、心所、色、涅槃）為主軸。

## 二、核心經文選錄

> **原文**（《清淨道論》第十四〈說蘊品〉，覺音造，葉均譯本通行）：
> 「此中，慧地諸法之分析，於經中世尊說蘊、處、界；於論（阿毗達磨）則說四種究竟法：心、心所、色、涅槃。除此四種究竟法之外，無別究竟法。」

> **白話對照**：
    經典的說法（五蘊、十二處、十八界）是應機的分類；阿毗達磨則將一切法歸納為四種究竟法：心——認知的主體；心所——伴隨心而起的心理作用（受、想、思等五十二心所）；色——二十八種色法；涅槃——無為寂滅。此外一切，如「人」「我」「有情」「世間」，皆只是概念施設。

> **原文**（《清淨道論》續釋，義同《法集論》之旨）：
> 「此四法中，心、心所、色是有為，是應修、應遍知、應斷、應證之境；涅槃是無為，乃貪瞋痴之究竟滅盡，是應證之果。」

> **白話對照**：
    四究竟法的修學結構：前三（心、心所、色）屬有為緣起，是內觀之所緣——於其上觀無常、苦、無我；第四（涅槃）是無為果——煩惱之「究竟滅」。凡夫於前三法起常樂我淨之顛倒，聖者如實觀之而證第四——四究竟法即攝盡「所觀之境」與「所證之果」。

## 三、重要名句

> 「除心、心所、色、涅槃四種究竟法外，無別究竟法。」（《清淨道論》）

> 「『我』『人』『眾生』唯是施設有，究竟真實唯此四法。」（南傳阿毗達磨之綱領性概括）

> 「涅槃者，貪瞋痴之究竟不生。」（《清淨道論》釋涅槃之通義）

> 「以無我故，無人於輪迴中流轉，亦無人於涅槃中寂滅，唯諸法之流轉與止息。」（南傳「無我而輪迴」之著名難題及其解答精神）

| 術語 | 釋義 |
|---|---|
| 四究竟法（paramattha-dhamma） | 心、心所、色、涅槃四種勝義真實 |
| 心（citta） | 識知所緣之識，八十九（或一百二十一）種心 |
| 心所（cetasika） | 與心相應俱生之心理素質，五十二種 |
| 色（rūpa） | 二十八類物質元素，四大所造 |
| 涅槃（nibbāna） | 貪瞋痴永盡之無為界，唯一無為究竟法 |
| 設施／概念（paññatti） | 「人」「我」等假立之名，世俗諦有 |
| 有為／無為 | 緣生造作／不生不滅 |
| 五十二心所 | 觸、受、想、思乃至慧等心所總數 |
