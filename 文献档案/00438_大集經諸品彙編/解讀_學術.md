# 大集經諸品彙編 — 学术解读

## 一、文献背景与成书

《大方等大集经》（简称《大集经》）是大乘佛教重要的“合集型”经典，现行汉文本六十卷，收录于《大正藏》第十三册，编号 T397。其形成并非一人一时一次翻译：北凉昙无谶约于五世纪初在姑臧译出前二十九卷（传统称三十卷），包括《璎珞品》《陀罗尼自在王菩萨品》《宝女品》《无尽意菩萨品》等；北齐那连提耶舍译《日藏经》《月藏经》等后起部分；隋代僧就据昙无谶本，加入《大乘大方等日藏经》《大方等大集月藏经》《大乘大集须弥藏经》及《十方菩萨品》等，合成六十卷的通行本。因此，“诸品汇编”并非现代随意节录，而是在形式上忠实呈现此经本来即由多部单经、多次法会、多种译本拼合而成的性质。

现行文本的编次与卷数在各藏本间略有出入，一些“分”又曾以独立经名流通；梵文仅存《宝幢陀罗尼经》等吉尔吉特残片及若干零篇，藏译亦保存部分对应文本。经中混合印度、中亚乃至汉地的天文、星宿与国土地理知识，使其成为研究大乘经典跨区域编纂的珍贵文献。

## 二、文本结构与核心思想

全经虽庞杂，仍可按思想重心分为三层。第一层是早期昙无谶译诸分，以“大集”为场景：佛成道十六年，于王舍城大塔与十方菩萨、天龙鬼神大会，宣说菩萨戒、三昧、智慧、陀罗尼与大悲行。《陀罗尼自在王菩萨品》系统列举戒、定、慧、陀罗尼四璎珞；《无尽意菩萨品》以八十“无尽”法门展示布施、持戒、忍辱乃至慈悲皆随众生界而无尽，其中“众生无尽故，菩萨修慈亦不可尽”最能代表其精神。

第二层是《日藏》《月藏》《须弥藏》等后附部分，以护法、陀罗尼、星宿和国土付嘱为中心。佛将佛法与阎浮提诸国交付诸天、龙王、夜叉守护，又描述正法、像法、末法的衰变过程。《月藏分》的“五个五百年”说对中国末法思想、三阶教与净土宗影响尤大。

第三层是贯穿各品的政治与社会伦理：国王护持正法、僧团清净、众生行十善与社会安宁被编织为共同因果结构。其“护国”不是单纯求诸神降福，而是把戒德、布施、忏悔与天龙护佑并列为国土安稳的条件。由此，经中早期菩萨行与后期密教化的咒术护国形成一个多层体系。

## 三、学术研究价值与争议

研究价值首先在文献史。《大集经》像一座跨越数百年的文本地层：昙无谶译本、北齐增译本与隋代合编本可供逐层分析，显示大乘经典如何从单经汇成“大部”。其次，末法思想的传播史离不开《月藏分》；第三，星宿、五行、震旦、于阗等内容为佛教与中亚、汉地知识交流提供资料；第四，《无尽意菩萨品》中的无尽法门又影响《法华经·普门品》对无尽意菩萨的形象接受。

争议问题主要有三。第一，各分成立地点与年代差距很大，不能以“《大集经》成书于某年”一言概括；《日藏经·护塔品》可能形成于喀什噶尔，《月藏分》亦混有于阗与汉地知识，具体来源仍在研究。第二，隋代僧就合编是否保持了各单经原貌：异本编次、卷数与译者题署不完全一致，部分段落或经整理改写。第三，末法“五五百年”是否是印度原始观念还是中亚东传中的强化结果，学界无定说。阅读此经应把它当作“文献群”而非风格统一的一部著作。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 大集 | 十方佛菩萨、声闻、诸天龙神共同集会说法的宏大会场 |
| 分与品 | “分”多为相对独立的单经，“品”是分内章节，后合编为一部 |
| 无尽意 | 意乐与菩萨行无有穷尽；亦为本经重要菩萨名 |
| 月藏分 | 那连提耶舍译的十卷经典，含末法、护国、星宿等内容 |
| 五五百年 | 佛灭后五个五百年法运递变的末法时间模式 |
| 护法诸天 | 受佛付嘱守护国土、僧团与正法的天龙八部 |

## 五、延伸阅读

- `00439_寶積經諸品彙編`：另一部由多会单经集成的大乘经集，可比较编纂方式。
- `00431_法華經觀世音菩薩普門品`：无尽意菩萨在《法华经》中启问观音法门。
- `00441_金光明經諸品`：护国、忏悔与诸天护法思想的另一核心经典。
- `00447_大乘經典集成`：从更广范围理解大乘合集型经典与现代汇编。
