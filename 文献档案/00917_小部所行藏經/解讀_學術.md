# 小部·所行藏经 · 学术解读

## 一、背景部类

《所行藏》（Cariyāpiṭaka）亦译"若用藏"，是巴利三藏小部（Khuddaka-nikāya）中的一部经文，叙述释迦牟尼佛过去世行菩萨道的本生事迹。全经以"七波罗蜜"为结构轴线，收录三十五则本生故事，依次阐明菩萨于无数前世中如何以布施、持戒、出离、决意、真实、慈心、平等舍心等德目，济济众生而成度众之行。其注释为达磨波罗所造《真谛灯》（Paramattha-dīpanī）。

在部类上，它属于经藏里的小部，与《本生》《佛种姓经》等共同构成南传"佛传与本生"文献群。与后来巴利传统所传"十波罗蜜"相比，本经并未为智慧、精进、忍辱单设专章，而是以七波罗蜜为主导纲目，显示出菩萨行编纂早期尚未固定为十德的痕迹，因而在波罗道思想史上占有独特的早期意义。

"所行"（Cariyā）一词即"菩萨历世之行"，本经正是以一位修行者的全部前世行为为材料，把抽象的行善原则落实为一则则具体的"我曾这样做"的本生实例。

## 二、结构与核心思想

《所行藏》以波罗蜜来分类本生故事，可把握为三个主题层面。

其一为"施与戒"。开卷以大善见王、大典尊、尼罗王等故事立施波罗蜜的示范，说明菩萨如何把自己的一切（财产、王位乃至生命）施舍与众生；继之以摩监伽等故事立戒波罗蜜，显示持戒清净、不踰不毁的威仪。

其二为"出离、决意与真实"。菩萨经世以舍离为志，坚定地以不达目的不罢休的决心为准绳；又以言必有信、如实不虚的"真实"为基本，使每一德皆扎根于诚实之上。

其三为"慈与舍"。以诸慈悲本生示慈波罗蜜，教人对一切众生普发慈心；以舍波罗蜜示菩萨于苦乐之中能维持平等、心无系著。全经立教之要，在于"以事证理、以行立德"——把波罗蜜的宏大理念化为菩萨在轮回中的一个个具体事迹，从而守护后人"德存于行"的修行信念。

## 三、价值与汉译对应

《所行藏》的价值有二。其一，它保存了早期"波罗蜜"尚未扩至十数时的七波罗蜜结构，是研究菩萨德目演变的重要资料；其二，它把波罗蜜与本生结合，为后世本生、佛传确立"菩萨行之门径"，并对后世《清净道论》所讲波罗蜜的取材与界定有直接影响。

汉译方面，本经并无独立的全译本，相关菩萨行波罗蜜的思想散见于汉译经典。汉传《佛本行集经》《大智度论》所谈布施等波罗蜜，虽多循大乘十波罗蜜体系，但追本溯源，与《所行藏》的菩萨行精神相通，可以对照研究。

## 四、术语

| 术语（巴利/梵语） | 汉译 | 含义 |
|---|---|---|
| Cariyā | 所行 / 行持 | 此菩萨历世之行 |
| Piṭaka | 藏 | 佛教典籍的结集 |
| Dāna | 布施（舍） | 自己所拥之物施与众生 |
| Sīla | 戒 | 远离恶行、清净的正戒 |
| Nekkhamma | 出离 | 舍离欲染 |
| Adhiṭṭhāna | 决意 | 坚定不摇的誓愿 |
| Sacca | 真实 | 如实不虚、名实相副 |
| Mettā | 慈 | 对众生广发慈悲 |
| Upekkhā | 舍 | 平等观照、心不系执 |
| Pāramī | 波罗蜜 | 菩萨所要究竟的十（七）种德 | 

以上术语显示，本经系以七波罗蜜为纲、以三十五本生为目，为南传菩萨行道提供了具体范本，也让后人一探"波罗蜜"结构演进的早期样态。
