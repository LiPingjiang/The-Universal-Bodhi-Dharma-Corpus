# 佛教心理物理學 · 原文

## 一、學科概述

心理物理學（psychophysics）由費希納（Gustav Fechner）於1860年創立，研究物理刺激強度與心理感覺之間的定量關係，韋伯定律、感覺閾限與訊號偵測論皆屬其範疇。「佛教心理物理學」並非建制學科，而是近二十年冥想研究中一個小而精的交叉方向：借用心理物理學的嚴格測量方法，考察禪修訓練對知覺閾限、知覺穩定性、時間知覺與痛覺敏感度的影響。其理論意義在於：佛教傳統聲稱禪修能改變感官經驗的品質（所謂「心轉則境轉」），而心理物理學恰能以可重複的行為測量檢驗這一主張，使二者的對話由玄談轉為實證。

## 二、核心議題與佛教觀點

核心議題包括：（一）知覺競爭（binocular rivalry）——2005年，約翰·卡特（Oliver Carter）等人在《當代生物學》（Current Biology）發表研究，發現參加三個月止禪閉關（由佛教學者艾倫·華萊士指導）的行者，其雙眼知覺競爭的交替速率顯著改變，提示注意訓練可直接作用於初級知覺過程。（二）痛覺知覺——喬舒亞·格蘭特（Joshua Grant）等與扎伊丹（Fadel Zeidan）等的研究顯示，禪修者與短時正念訓練者對同等熱刺激的主觀痛感降低，腦成像顯示初級體感皮層活動重分配，即「痛覺不減而痛苦減」。（三）時間知覺與剎那生滅——佛教以「剎那」（kṣaṇa）為身心現象生滅的最小時間單位，冥想者的時間知覺研究為此提供了操作化入口。佛教方面，《雜阿含經》著名的「聚沫水泡喻」正是對感官經驗流動性、無實體性的古典知覺分析。

> **經典依據**：
> 「觀色如聚沫，受如水上泡，想如春時燄，諸行如芭蕉，諸識法如幻。」——《雜阿含經》（T99）

佛陀以聚沫、水泡、陽燄、芭蕉、幻事喻五蘊：感官經驗看似堅實連續，實則如泡沫般剎那生滅、層層相依而無核心——這與心理物理學揭示的知覺的建構性、離散性與閾限性深相呼應。

## 三、代表學者與實踐

卡特等人的知覺競爭研究是本方向的標誌性成果，其被試來自華萊士指導的閉關，是「第一人稱訓練＋嚴格心理物理測量」模式的典範。格蘭特與皮埃爾·雷恩維爾（Pierre Rainville）在蒙特利爾大學的研究組以禪修者為對象，證明長期禪修改變痛覺的分維加工，論文發表於《疼痛》等期刊。北卡羅來納大學的扎伊丹則證明僅四天、每天二十分鐘的正念訓練即可降低痛覺強度與不愉悅度，大幅降低了應用門檻。此外，威斯康辛團隊關於禪修者注意閃爍（attentional blink）的研究（2007年，斯萊蓋特與戴維森等）顯示三個月密集禪修縮小了注意瞬脫，說明注意資源分配本身可被訓練——這些工作共同構成「禪修改變知覺」的證據鏈。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 感覺閾限 | 能引起感覺體驗的最小刺激強度 |
| 知覺競爭 | 兩眼接受不相容圖像時知覺交替切換的現象 |
| 注意瞬脫 | 快速連續刺激中第二個目標易被漏報的注意瓶頸 |
| 剎那（kṣaṇa） | 佛教時間觀中現象生滅的最小單位 |
| 五蘊 | 色、受、想、行、識，身心經驗的五類聚合 |
| 止禪（samatha） | 以專注一境培養定力的禪修，心理物理研究常用訓練 |
