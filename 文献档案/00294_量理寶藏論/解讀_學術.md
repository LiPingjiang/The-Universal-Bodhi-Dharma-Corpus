# 量理寶藏論 — 学术解读

## 一、文献背景与成书

《量理宝藏论》（藏 *Tshad ma rigs gter*，常译《正理藏论》《量理宝藏论》）为萨迦班智达·贡噶坚赞（Sa skya Paṇḍita Kun dga' rgyal mtshan，1182—1251）所造，是西藏佛教因明（量论）史上最具影响力的独立论书之一。萨班通晓印度因明陈那、法称传统，且曾在克什米尔班智达座前受学；本论以法称《释量论》（Pramāṇavārttika）为理论根基，吸收陈那量论与藏地既有辩论传统，建立适合西藏经院教育的量论纲要。

成书年代通常置于十三世纪上半叶。全书七品（不同版本题名略异），一般围绕现量、自利比量、他利比量、观诠释、遮遣与宗教认识论等问题展开；后世格鲁、萨迦、宁玛诸派均有注释，成为藏传佛教辩经课程的基本教材之一。文集与单行刻本流传甚广，本档案所录「现量」定义即其开篇或核心论题的典型表达。

## 二、文本结构与核心思想

其一，**二量论**。本论主张正量（pramāṇa）主要有二：现量（pratyakṣa）与比量（anumāna）。原文说：「現量者，謂離分別，無有錯亂，新起而不欺誑之識。」四个限定分别排除：概念分别（离分别）、错觉（无错乱）、重复记忆或推演（新起）、不能导向有效行动的虚假认知（不欺诳）。这是法称系量论中极为严格的「直接知觉」定义。

其二，**自相与共相**。现量所知为自相（svalakṣaṇa）——刹那、具体、不可由概念完整替代的个别事物；比量所知为共相（sāmānyalakṣaṇa）——由语言、概念、推理把握的普遍形式。原文「离名言共相之分别」「于所量自相不生余相」正是在划定二者边界。这一界分将认识论、语言哲学与修行中的无分别智关联起来。

其三，**因三相与比量**。档案中概括「比量者，依因三相而推断也」——有效理由须具遍是宗法性、同品定有性、异品遍无性。萨班虽以藏文论述，却将印度因明的严格推理规则转化为西藏辩经的可操作语言。

其四，**现量为根本的知识秩序**。本档案名句称「现量为一切量之根本。离现量则比量无以立，离比量则教量无以成。」这一层级观显示：直接经验提供材料，推理组织材料，经典权威的理解也需以经验与推理作检验——它并非盲目的权威主义。

## 三、学术研究价值与争议

研究价值方面：（1）《量理宝藏论》是研究法称量论如何在西藏本土化的核心文献，与汉传窥基《因明入正理疏》相对照，可见两大因明传统的不同发展；（2）它长期构成藏传经院辩经的逻辑教材，保存了术语、论式和教学方法的系统化形态；（3）现量、概念、语言与有效行动之间的分析，可与现代认识论、认知科学和语言哲学展开富有成效的比较。

争议问题方面：（1）萨班对法称的诠释究竟是忠实继承还是创造性重构，学界对其与早期藏传因明家（如恰巴·确吉僧格）立场的差异持续研究；（2）「离分别的现量」能否被现代哲学严格定义、以及它是否可被经验科学验证，是跨文化哲学讨论的难点；（3）不同宗派对自相、共相、佛智与量的解释并不一致，后世注释传统的分歧提醒读者不可将本论视作唯一的「藏传因明答案」。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 量（Pramāṇa） | 能如实且有效地认识对象的正知或认识手段 |
| 现量（Pratyakṣa） | 离分别、无错乱、新起、不欺诳的直接认知 |
| 比量（Anumāna） | 依可靠理由进行的推论认识 |
| 自相（Svalakṣaṇa） | 现量所缘的具体、个别、刹那性对象 |
| 分别（Kalpanā） | 依名言共相而起的概念建构 |
| 因三相 | 有效推理理由的三个条件 |
