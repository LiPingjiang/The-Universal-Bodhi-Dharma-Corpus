# 佛教四无畏研究_29 — 学术解读

## 一、文献背景与成书

本条目为「寰宇覺海·菩提法藏」语料库独立文献补充条目，编号 X22384，属第二十九批补充条目（目录名后缀 _29）。同目录 README 记其状态为「待後續填充內容」，故此份《原文》为名目式纲要：概述一句，枚举四无畏名目——一切智无畏、漏尽无畏、说障道无畏、说尽苦道无畏；正文存两段引文与一张六词项术语表。须如实说明：该条目是对佛果功德名目的纲要保存，非一部有传译史的独立典籍。

四无所畏之名目见于经律两藏：汉译《阿含》与巴利经典均有如来于大众中作师子吼、于四事无所畏之文；《大智度論》《俱舍論》《瑜伽師地論》等论书详释其相。条目第一段引文「如來四無所畏者——正等覺無畏、漏永盡無畏、說障法無畏、說出道無畏。如來在大眾中作師子吼，無所畏懼」即此名目的论书式叙述。第二段引文转为菩萨行门：「菩薩亦修四無畏——能持無畏、不忘失無畏、無過患無畏、不失念無畏」，此与《大智度論》所传大乘论书中的菩萨四无畏同源，唯用字与通行本略有出入，此处依原文档为准照录并注明。术语表中 Sāvaramārga（障道）、Niyyānika-mārga（尽苦道）等词形为原表所构拟之对应，一并照录。

## 二、文本结构与核心思想

如来四无畏的结构是「自证与说法」的两两对应：前二无畏属自证边——正等觉无畏，谓佛自证一切智，于「我已正觉」更无怖畏；漏永尽无畏，谓佛自证诸漏永尽，于「我已漏尽」更无疑惧。后二无畏属说法边——说障法无畏，谓佛说贪嗔痴等能障圣道，此说决定无谬，无人能难；说出道无畏，谓佛所说能尽苦之道决定出离，无人能破。自证与说法合观，四无畏实为「佛在公开场合为自身教法作担保」的四种资格，故经典以「師子吼」喻之：狮子一吼，百兽脑裂；如来法音一出，异论自摧。

菩萨四无畏则移此结构于因地：能持无畏，于所闻法总持不忘；不忘失无畏，于说法定无忘误；无过患无畏，于自身行无缺漏可指；不失念无畏，于正念恒无退失。原文谓「如是四法圓滿，即近佛果」，点明菩萨四无畏是如来四无畏的因位对应——因中能持不忘，果上一切智；因中无过无失，果上漏尽无碍。两段合观，恰好构成一组从因到果的功德谱系。

## 三、学术研究价值与争议

其一，四无畏与十力、十八不共法的配属是佛功德论的经典课题：三组功德互相交涉，诸论于「四无畏即十力之用」的判释不一，学者据以观察佛身观在各部派与大乘论书中的演化。其二，「无畏」的心理描述颇有义理深度：佛教把「无所畏惧」不诉诸勇气，而诉诸证知的确定性——因为直接见到，所以无须自壮声势；这一界定与凡俗「克服恐惧」的模式截然不同，为比较宗教研究中的信心论提供了独特样本。其三，菩萨四无畏的成立背景值得注意：大乘论师以佛果功德移于因地，重释为菩萨可修之法，此一「果德因地化」的操作在大乘文献中反复出现，是研究大乘菩萨行理论构作机制的好例。其四，师子吼之喻的修辞史：由经藏譬喻到论书的论证术语，再到禅门「狮吼」的转用，一线贯穿。本条目以两段引文分别保存如来与菩萨两套名目，于佛功德纲要中算得上眉目清楚。
