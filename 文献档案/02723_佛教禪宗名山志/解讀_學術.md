# 佛教禅宗名山志 — 学术解读

## 一、文献背景与成书

"名山志"是专门记述佛教名山之得名由来、地理封域、古今胜迹、高僧行止与感通灵异的著述体裁，在汉传佛教文献中自成谱系。其开山之作是唐代慧祥所撰《古清凉传》二卷，书成于高宗永隆元年（680）至弘道元年（683）之间，记文殊菩萨道场五台山（清凉山），收于《大正新修大藏经》第五十一册史传部，经号 T2098。因为它是五台山山志中最古老的一部，故冠以"古"字。此后宋代延一《广清凉传》三卷（T2099）、宋代张商英《续清凉传》二卷（T2100）相继问世，形成"清凉系山志三书"的层累序列；明代镇澄《清凉山志》虽未入大藏正藏，却是五台山志的集大成者。

需要特别辨明的是题名与内容的出入：本目录原档题为"佛教禅宗名山志"，但据原文档自述，真正收入大藏经的名山志以清凉（五台）系三传为主，而五台山是文殊道场，并非禅宗祖庭；禅宗一系的名山专志，如《径山志》《天童寺志》《少林寺志》，多为明清所修，未入大藏正藏。禅宗名山的核心是南宋宁宗时代确立的"五山十刹"制度——径山兴圣万寿寺、灵隐寺、净慈寺、天童景德寺、阿育王广利寺五山，加上嵩山少林（达摩面壁）、曹溪南华、百丈山、沩山、仰山、杨岐山、云门山、云居山等祖庭。本篇依照原文档的处理：以入藏的清凉系山志为文献主体，同时概述禅宗名山系统，并明确指出二者的界限。

## 二、文本结构与核心思想

以《古清凉传》为例，全书五节构成一种可称为"圣地志"的标准体例：卷上第一节"立名标化"，说明五台山、清凉山名称的由来及奉此山为圣地的理由；第二节"封域里数"，交代地理位置与山界；第三节"古今胜迹"，记录山中寺院、石窟等建筑；卷下第四节"游礼感通"，记巡礼者的灵感事迹；第五节"支流杂述"，收在家居士灵异事四则。这一结构兼有地理志、僧传与感应录三重性质，成为后世山志的通用范式。

名山志的核心思想是"圣地的经典建构"。五台山被奉为文殊道场，其根本经证是《大方广佛华严经·菩萨住处品》："东北方有菩萨住处，名清凉山。过去诸菩萨常于中住。彼现有菩萨，名文殊师利，有一万菩萨眷属，常为说法。"（晋译六十卷本 T278，唐译八十卷本 T279 亦有对应篇章）。慧祥正是以这段经文为纲领，把一座华北山地论证为经典所记的圣域。华严宗四祖澄观国师释山名说"岁积坚冰，夏仍飞雪，曾无炎暑，故曰清凉"，则将地理实录与佛法象征合一——外境之清凉，正表烦恼热恼之息灭。汉传"四大名山"（五台文殊、普陀观音、峨眉普贤、九华地藏）加雪窦山（弥勒）称"五大名山"，共同构成汉地佛教的圣地地理。

## 三、学术研究价值与争议

其一，圣地研究（sacred geography）的样本价值。名山志展示了"经证—地名—灵验"三位一体的圣地建构逻辑：先由经典提供依据，再以山名、物候、形胜作印证，最后以巡礼感应叙事巩固信仰。五台山信仰从隋唐全盛期到近代的完整层累过程，可以从三传的文字增衍中逐层剥离。

其二，巡礼史料的互证价值。圆仁《入唐求法巡礼行记》所记五台巡礼，与《广清凉传》所收灵应记可对读；山志中的封域、里数、寺院条目又可与《洛阳伽蓝记》（T2092）的寺院志笔法、《大唐西域记》（T2087）的天竺圣迹记录比较，呈现"从都城寺志到圣山志到域外圣迹志"的文献谱系。

其三，争议主要集中在感应叙事的史料性质上。"游礼感通"类内容以神异叙事为主体，宗教史学者视之为研究信仰心态的一手材料，实证史学则须审慎区分其中的实录与传说；明代镇澄删并前代材料重修《清凉山志》时已有去取，今人利用时更须逐层核对。另外，禅宗五山十刹的等级制度本是宫廷敕定的寺院位次，与"祖庭"崇拜并不重合，研究中容易混为一谈，原文档对这一区分的提示值得重视。

## 四、术语对照表

| 原词 | 释义 |
|---|---|
| 名山志 | 记名山得名、封域、胜迹、行止、灵异的专门著述 |
| 清凉山 | 五台山别名，出自《华严经·菩萨住处品》 |
| 文殊道场 | 文殊菩萨说法应化之地，五台山信仰的核心 |
| 五山十刹 | 南宋宁宗时敕定的禅院等级制度 |
| 立名标化 | 《古清凉传》首节，论证山名与圣化依据 |
| 感通（灵感） | 巡礼者与圣境之间的灵验感应叙事 |
| 封域里数 | 山志记述山界四至与里程的体例 |
| 朝台（大朝台） | 信众巡礼五座台顶的朝圣实践 |
