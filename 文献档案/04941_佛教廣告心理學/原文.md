# 佛教廣告心理學 · 原文

## 一、學科概述

廣告心理學研究說服的信息機制：注意捕獲、情感條件化、聯想學習、品牌人格與購買意圖的喚起。必須如實指出：目前並不存在建制化的「佛教廣告心理學」，此專題的實質內容由三部分構成：（一）對廣告工業的心理學批判——廣告系統性地訓練「貪」，其技術（情感喚起、稀缺暗示、社會比較）在佛教看來皆是激活隨眠煩惱的外緣；（二）「守護根門」的消費者防禦研究——注意力經濟時代的媒介素養與正念訓練能否提高對說服信息的免疫力，已有初步實證：正念水平較高的消費者對廣告的情感操縱更敏感、更少衝動消費；（三）佛教自身的傳播實踐——佛教教義的傳播（如「marketing dharma」）與寺院品牌形象研究，屬宗教傳播心理學的邊緣課題。

## 二、核心議題與佛教觀點

核心議題包括：（一）慾望喚起的機制——廣告心理學的經典原理（巴甫洛夫條件化、阿倫森的說服理論、卡尼曼的雙系統）被用於把產品與快樂、地位、性魅力聯結；佛教則指出「欲樂」的適應性結構使這種承諾結構性落空，故廣告依賴的不是滿足而是「匱乏—暫緩」的循環；（二）注意力作為戰場——經濟學家赫伯特·西蒙1971年斷言信息過剩時代「注意力成為稀缺資源」，今天的平台經濟正是對注意力的工業化收割；佛教「守護根門」（indriya-saṃvara）即古典的注意力倫理：主動選擇感官輸入，不令心為境轉；（三）正念防禦假說——實驗顯示正念誘導下被試對「情感訴求」廣告的購買衝動降低，對「資訊訴求」的加工不受損，提示正念選擇性削弱操縱性說服；（四）廣告中的東方主義——禪意美學被用作品牌光環（「禪風」設計、冥想App營銷），其與佛法實質的張力本身即是研究對象。《四十二章經》的刀刃之蜜喻是本專題的古典核心文本。

> **經典依據**：
> 「財色於人，人之不捨，譬如刀刃有蜜，不足一餐之美，小兒舐之，則有割舌之患。」——《四十二章經》（T784）

刀刃之蜜是對誘惑結構最精練的佛教分析：短期微小甜頭（廣告承諾的快樂）與隱藏的重大代價（債務、匱乏循環、環境負擔）——這正是廣告心理學「即時獎勵偏置」與「延遲後果折扣」的古典表述。

## 三、代表學者與實踐

在批判理論方面，社會評論家與心理學者對「注意力經濟」的分析（如傳播學者對廣告刺激匱乏感的經典研究）常援引佛教術語，埃里希·弗洛姆《占有還是存在》（1976年）對「占有型」人格與消費社會的剖析雖非佛教研究，卻是此領域最常被對讀的文本。實證方面，前述卡瑟的物質主義研究為「廣告—幸福感」鏈條提供了縱貫證據：青少年時期廣告暴露與成年後物質主義的追蹤研究顯示廣告文化的心理後果。正念消費研究則以實驗法檢驗佛教式覺察對說服的緩衝（如台灣與香港學者對正念與衝動購買、廣告態度的系列研究）。實踐層面，緬甸與泰國的「佛教經濟」倡議、一行禪師社群的「正念消費」承諾，以及歐美「道德廣告」運動對佛教倫理的引用，構成了廣告工業之外的自覺替代路徑。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 情感訴求 | 以情緒喚起而非資訊為主的廣告說服策略 |
| 條件化聯結 | 將產品與愉悅刺激反覆配對的學習機制 |
| 守護根門 | 佛教對感官輸入的主動節制與選擇 |
| 隨眠（anuśaya） | 潛伏的煩惱傾向，可被廣告等外緣激活 |
| 注意力經濟 | 以爭奪人類注意力為核心的商業模式 |
| 匱乏營銷 | 系統性製造「不足感」以驅動消費的策略 |
