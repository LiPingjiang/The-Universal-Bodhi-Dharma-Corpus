# 佛教廣告心理學 — 学术解读

## 一、文献背景与成书

本条目是「佛教与心理学」系列的综述性主题条目（库内编号04941）。先作如实的定性说明，这也是其原文文档开宗明义的自陈：目前并不存在建制化的「佛教广告心理学」，没有学会、没有专门期刊、没有教科书；此专题的实质内容由三部分拼合而成——（一）对广告工业的心理学批判；（二）以佛教「守护根门」为框架的消费者防御研究；（三）佛教自身传播实践（所谓「营销佛法」）的边缘研究。因此，把它读作一个「问题域」而非一门「学科」，更符合实际。

其时代背景是注意力经济的兴起：经济学家赫伯特·西蒙1971年断言，信息过剩的时代，注意力将成为稀缺资源——今天的平台经济正是对注意力的工业化收割，广告是其中的主力机具。广告心理学研究说服的信息机制：注意捕获、情感条件化、联想学习、品牌人格与购买意图的唤起；佛教以「贪」的诊断与「守护根门」的修行介入这一场域。理论近邻方面：埃里希·弗洛姆《占有还是存在》（1976年）对占有型人格与消费社会的剖析虽非佛教研究，却是此领域最常被对读的文本。与相邻条目的分工：`04940_佛教消費心理學` 研究欲望在个体内的运转（下游），本条目研究欲望如何被工业制造（上游）；`04945_佛教決策心理學` 提供说服抵抗的认知机制。

## 二、文本结构与核心思想

综述条目按学科概述、核心议题、代表学者与术语表组织，核心议题可归纳为四组，构成一条「广告如何工作—佛教如何看—如何防御—反身观察」的完整链条。

第一组：欲望唤起的机制。广告心理学的经典原理——巴甫洛夫条件化（把产品与愉悦刺激反复配对）、阿伦森的说服理论、卡尼曼的双系统——被用于把产品与快乐、地位、魅力联结。佛教则指出「欲乐」的适应性结构使这种承诺结构性落空：广告真正依赖的不是满足，而是「匱乏—暂缓」的循环——先制造不足感，再许诺补足，而补足之日即新的不足感生成之时。

第二组：注意力作为战场。佛教「守护根门」（indriya-saṃvara）即古典的注意力伦理：主动选择感官输入，不令心为境转。这在刷屏时代获得了字面意义的现实性——每一次解锁屏幕，都是一次「开门」或「守门」的选择。

第三组：正念防御假说。实验显示，正念诱导下的被试对「情感诉求」广告的购买冲动降低，而对「信息诉求」的加工不受损——提示正念是选择性削弱操纵性说服，而非全面钝化感知。这是本专题目前最结实的实证发现。

第四组：广告中的东方主义。「禅风」设计、冥想应用的营销，把禅意美学用作品牌光环，其与佛法实质的张力本身即是研究对象——佛教符号被广告化的过程，正是观察宗教商品化的活体标本。

古典核心文本出自《四十二章经》（T784）的刀刃之蜜喻：「財色於人，人之不捨，譬如刀刃有蜜，不足一餐之美，小兒舐之，則有割舌之患。」短期微小甜头与隐藏重大代价的结构，正是广告心理学「即时奖励偏置」与「延迟后果折扣」的古典表述。

## 三、学术研究价值与争议

价值方面：其一，本专题把佛教「随眠」理论转化为可检验命题——潜伏烦恼被外缘（广告）激活，激活强度可用注意偏向、购买冲动等指标测量，是宗教心理学操作化的有趣案例。其二，卡瑟的纵贯研究为「广告—幸福感」链条提供了长期证据：青少年时期广告暴露与成年后物质主义水平的追踪关联。其三，正念防御实验（含台湾与香港学者对正念与冲动购买、广告态度的系列研究）为媒介素养教育提供了新工具——防御不靠回避信息，而靠觉察信息对自己的作用。

争议方面：其一，「守护根门」的现实践行边界在哪——完全不接触商业信息在现代社会近乎不可能，防御策略的现实版本只能是「选择性守门」，但选择标准本身需要伦理讨论。其二，正念防御的证据规模仍小，多为止于实验室的短期诱导，长期正念训练者对广告的真实免疫力数据不足。其三，佛学界内部的批评：把正念仅用作「消费防御技术」，剥离了佛教对贪的系统批判（少欲、布施、正命），是「用佛法的一部分去修补另一部分被破坏的世界」——此批评与本系列各条目共通的「去语境化」争论同构，而在广告场域中最为尖锐，因为这里佛教技术所对抗的，正是资本对同一批心理机制的工业化利用。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 情感诉求 | 以情绪唤起而非信息为主的广告说服策略 |
| 条件化联结 | 将产品与愉悦刺激反复配对的学习机制 |
| 守护根门 | 佛教对感官输入的主动节制与选择 |
| 随眠（anuśaya） | 潜伏的烦恼倾向，可被广告等外缘激活 |
| 注意力经济 | 以争夺人类注意力为核心的商业模式 |
| 匱乏营销 | 系统性制造「不足感」以驱动消费的策略 |
| 即时奖励偏置 | 高估近处小利、低估远处代价的决策倾向 |
