# 回諍論頌與注 — 学术解读

## 一、文献背景与成书

《回诤论》（Vigrahavyāvartanī）传统归于龙树，是中观学派专门回应认识论与语言哲学质疑的重要论书。汉译本一卷收《大正藏》第三十二册，编号T1631，题后魏毗目智仙与瞿昙流支共译，昙林笔受。译序明确记载：兴和三年（541）在邺城金华寺译出，历时二十余日。现存文本由偈颂与逐颂解释组成，汉本分"偈初分、偈上分、释初分、释上分"四段；梵文本和藏译本亦存，为跨语种校勘提供了难得条件。

本论的自释传统上也归于龙树，但现代文献学对作者层次仍有讨论，宜表述为"颂与传统所传自释"，不把全部释文的同一作者性视作绝对定论。不同版本对颂数统计略有差异，常见说法为七十余颂；与其执定数字，不如注意全书清楚的两段式结构：先完整陈述论敌对空性的攻击，再逐项回答。

梵本在近代重新发现后，学界得以把汉译、藏译和梵文三线对勘。三本的分段、颂序及术语并非处处一致，汉译“量”“所量”等词也须结合印度认识论语境解释。T1631的译序还保存译场地点、参与者和用时，是判断北朝佛典翻译流程的少见一手材料，不应只把它当作哲学正文的附属。

## 二、文本结构与核心思想

论敌的首要诘难是：若一切法都无自性，那么"一切法无自性"这句话也无自性，既然言语为空，怎能破斥别人的实有主张？若这句话反而有自性，又会推翻"一切皆空"。进一步，论敌援用现量、比量、譬喻、圣教量，主张认识工具可以证明对象的自性。

回答的关键，是区分"无自性"与"无作用"。言语同样依咽喉、唇舌、概念和听者等因缘发生，虽无独立本质，却能在世俗层面发挥纠错作用，正如幻人可以制止幻人。空性论述并不站在空性之外，也不需要成为唯一例外。对量与所量，本论指出二者相待而立：若量需另一量证明，会导致无穷后退；若量自证，则所量也可不待量而自成；若量与所量互证，又近于"父生子、子生父"的循环。

"若我宗有者，我则是有过；我宗无物故，如是不得过"不是拒绝一切表达，而是否认中观另立一个自性实有的形而上学命题。世俗言说照常运作，胜义观察则不把任何宗、量、对象实体化。故全论最终回到缘起：有自性者不待因缘，凡待因缘者即无自性。

## 三、学术研究价值与争议

《回诤论》补足《中论》较少集中处理的知识论问题，是研究早期中观如何面对印度正理学传统的核心文本。其量论部分涉及现量、比量、譬喻、阿含等认识方式，保存了正理思想发展史的重要切片；"空的语言能否有效"则与现代自指悖论、怀疑论和元语言问题形成富有启发性的比较。Jan Westerhoff等现代学者把它视为理解龙树哲学的理想伴读本。

争议有三：一是论敌究竟代表成熟正理派，还是若干实在论立场的综合，学界并无绝对一致意见。二是"我宗无物"应理解为彻底无命题立场、治疗性哲学，还是仍可承认缘起等世俗主张，不同解释会导向不同的中观认识论。三是量与所量的批评究竟否定知识工具本身，还是仅否定它们自性成立，亦有争论。较稳妥的理解是：本论并未取消日常求知，而是拒绝为求知活动寻找一个不依条件、永不受审查的终极地基。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 回诤 | 回应、消解针对空性学说的诘难 |
| 自性 | 不依因缘、固定独立而成立的本质 |
| 量 | 获得或证明知识的手段，如现量、比量等 |
| 所量 | 被认识、被证明的对象 |
| 无穷后退 | 每个证明又需另一证明，永远无法完成奠基 |
| 世谛 | 日常语言、因果和认识活动得以运作的约定层面 |
