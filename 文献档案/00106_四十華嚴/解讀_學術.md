# 四十华严 — 学术解读

## 一、文献背景与成书

《大方广佛华严经入不思议解脱境界普贤行愿品》，通称《四十华严》或《普贤行愿品》，四十卷，唐罽宾三藏般若奉诏译，收入《大正新修大藏经》第十册，编号 T293。汉译《华严经》有三大本：东晋佛驮跋陀罗译六十卷本（T278，旧译），唐实叉难陀译八十卷本（T279，新译），以及此四十卷本。三本关系需要说明：四十卷本并非全经的重译，而是《八十华严·入法界品》的别译，篇幅大大扩充，末卷《普贤行愿品》为前两本所无，其地位独特。通行所称的「三本华严」中，只有此本的经题直接标出「普贤行愿」，可见其重心所在。

另需注意一个通行的说法：后世澄观将此本最后一卷别行流通，遂有单行本《普贤行愿品》，并被附加为八十《华严经》的别行卷流通至今；汉传佛教日常课诵、忏仪中所用的「十大愿王」，均出此卷。净土宗更将此卷列入「净土五经」，则是因为经文明言以愿王「导归极乐」。

## 二、文本结构与核心思想

全经由两大板块构成。主体是善财童子五十三参的圆满收束：善财历参善知识之后，最后谒见普贤菩萨，普贤为其称叹如来功德，并开示成就此功德门的下手处——「应修十种广大行愿」：礼敬诸佛、称赞如来、广修供养、忏悔业障、随喜功德、请转法轮、请佛住世、常随佛学、恒顺众生、普皆回向。这十愿构成一个从个体礼拜（礼敬、称赞）到破障净心（忏悔、随喜）到护持教法（请转法轮、请佛住世）到效学佛陀（常随佛学）到面向众生（恒顺众生）再到总摄回向的完整次第。

十愿的表述自有其深义。每一愿都以法界为量：礼敬诸佛，是「尽法界、虚空界，十方三世一切佛剎极微尘数诸佛世尊」，且于一一佛所「皆现不可说不可说佛剎极微尘数身」；每一愿又都以无尽为限：「虛空界盡，我禮乃盡；以虛空界不可盡故，我此禮敬無有窮盡。」空间上遍及法界，时间上穷尽未来——行愿被设计成没有边界的结构。这是《华严经》「一即一切、一切即一」的圆融观在修行论上的落实：任何一个善行，只要以普贤行愿力为「放大器」，即遍满法界。

偈颂部分则将十愿转为可诵持的韵文，其中忏悔偈「我昔所造诸恶业，皆由无始贪瞋癡；从身语意之所生，一切我今皆忏悔」成为汉传佛教一切忏仪的通用文句，其影响早已溢出华严一宗的范围。

## 三、学术研究价值与争议

研究价值方面：第一，四十卷本《入法界品》对勘价值极高——将它与六十、八十两本的〈入法界品〉对读，可以研究《华严经》这一品在印度不同时期的层累扩充，学界普遍认为善财求法故事的规模随传本时代推移而增大；第二，末卷《普贤行愿品》的十大愿体系，是研究大乘佛教修行观从「六度」向「愿—行」结构演变的材料，其仪轨化程度（可直接作为课诵文本）也是佛教实践史的重要现象；第三，「导归极乐」的结尾为华严与净土两系的合流提供了经典接口，是研究中国佛教诸宗融合的关键文本；第四，般若译本保存的罽宾地区华严传承信息，对研究此经在西北印度的流传亦有意义。

争议与问题方面：其一，《四十华严》与《八十华严·入法界品》的梵文原典残存情况不同，各本之间的梵文依据如何，尚在研究之中；其二，「十大愿王导归极乐」与华严「毗卢遮那圆满法界」的义理关系——十大愿的归结处为何是西方净土而非华藏世界，教理史上长期存在解释分歧；其三，此卷被列入「净土五经」的历程属净土宗近代以来的追认，不能倒推为经文本义；其四，善财五十三参所涉善知识的身份（含外道、婆罗门、女性等），其中社会学内涵的解读各家不一。使用时应注意区分：此经末卷的流通形态（单行、课诵本）与全四十卷的经本形态，在文献学上是两回事。

## 四、术语对照表

| 普贤行愿品 | 此经末卷，十大愿王的出处，别行流通的单行本即此 |
| 普贤（Samantabhadra） | 十大愿王的宣说者，与文殊并称华严二圣，表行愿之德 |
| 十大愿王 | 礼敬诸佛至普皆回向的十种广大行愿，此经的核心贡献 |
| 行愿（praṇidhāna） | 愿与行的合称：发愿定向，依愿起行 |
| 善财童子 | 五十三参的主角，历访善知识求菩萨道的典范行者 |
| 五十三参 | 善财遍访五十三位善知识的求法历程 |
| 回向（pariṇāmanā） | 将功德转施一切众生的实践，十愿之总归 |
| 法界（dharma-dhātu） | 十愿所缘的穷尽范围，「尽法界虚空界」 |

| 随喜功德（puṇyānumodanā） | 对自他善行生欢喜心，十愿之一 |
