# 华严经疏 — 学术解读

## 一、文献背景与成书

"华严经疏"一名在大藏经中并非专指一书：智俨《搜玄记》曾称《华严经疏》，法藏《探玄记》亦有《华严经疏》之别称；本档原文明确本档所涉为唐代澄观（738—839，清凉国师，华严宗四祖）所撰《大方廣佛華嚴經疏》，又称《华严经大疏》《清凉疏》，收于《大正新脩大藏經》第三十五册，经号 T1735，全书六十卷。澄观后又自撰《大方廣佛華嚴經隨疏演義鈔》九十卷（T1736）以解此疏，二者合称《华严经疏钞》，是华严宗义学巅峰期的集大成巨著。本档与语料库中 `01326_華嚴經疏`、`01329_華嚴經疏`、`01979_華嚴經疏` 等同名档各自独立、分工互注：本档以 T1735 的思想文本（尤其疏序骈文）为重心，`01326_華嚴經疏` 档侧重十门释经体例与四法界判摄，`01329_華嚴經疏` 档为空模板性质，`01979_華嚴經疏` 档归入注疏谱系，读者检索时应知同名异实，勿相混淆。

本疏所释为唐代于阗三藏实叉难陀所译八十卷本《大方广佛华严经》（八十华严，T279）。澄观于唐德宗兴元元年（784）至贞元三年（787）在五台山大华严寺历时三载（一说四年）撰成。其撰述因缘据本档原文：澄观有感旧有注疏"文繁义约"，遂发心重疏。书成后于五台山开讲，后又应河东节度使之邀在太原宣讲，影响极大。全书以"十门开启"解经：教起因缘、藏教所摄、义理分齐、教所被机、教体浅深、宗趣通局、部类品会、传译感通、总释名题、随文解释——十门释经体例上承法藏《探玄记》而略作调整，后成汉传佛教注疏的典范体例。

## 二、文本结构与核心思想

本档所录核心文本为澄观卷一自撰《华严经疏序》骈文，历来被誉为中国佛教骈文的冠冕。序文开卷总纲曰：

> 「往復無際，動靜一源，含眾妙而有餘，超言思而逈出者，其唯法界歟！」

以"法界"为最高本体统摄全经。继而总标经德："剖裂玄微，昭廓心境，窮理盡性，徹果該因……其唯大方廣佛華嚴經焉！"继说佛身："十身初滿，正覺始成……湛智海之澄波，虛含萬象；皎性空之滿月，頓落百川。"

序文第二段发挥事事无碍玄旨，是全疏义理的预演：

> 「冥真體於萬化之域，顯德相於重玄之門……理隨事變，則一多緣起之無邊；事得理融，則千差涉入而無礙。故得十身歷然而相作，六位不亂以更收。廣大即入於無間，塵毛包納而無外。」

其纲要名句有三：「往復無際，動靜一源」标举一真法界；「真妄交徹，即凡心而見佛心；事理雙修，依本智而求佛智」点出修证宗要；「一多無礙，等虛室之千燈；隱顯俱成，似秋空之片月。重重交映，若帝網之垂珠；念念圓融，類夕夢之經世」铺陈事事无碍的四重譬喻——室内千灯光光相映（一多无碍）、秋空片月隐显同时（隐显俱成）、帝释宝网珠珠互摄（重重交映）、一梦经世（念念圆融）。

思想史定位上，澄观在法藏（贤首）思想基础上作两大推进：其一，把"法界"直接诠释为"一心""心体"，使华严本体论与禅宗心性论接榫——为他后来会通禅与华严、乃至影响圭峰宗密铺路；其二，系统确立"四法界"（事法界、理法界、理事无碍法界、事事无碍法界）的完备架构，成为后世理解华严哲学最通行的纲领。序文所谓"超言思而逈出"，正是四法界观在语言层面的自我声明：华严义理超于言诠，而骈文繁喻，恰是"以言遣言"的极致表演。

## 三、学术研究价值与争议

研究价值有四。其一，注疏体例的价值：十门释经的结构，是研究中国佛教注疏学从"文句式"（如《法华文句》）走向"体系化"（先悬谈纲领、再随文释义）的样板。其二，思想史价值：澄观身处中唐教下诸宗（天台、禅、律）鼎立之世，其融摄天台教观与禅宗心法的努力，标志着华严学从"宗派自足"转向"综合判教"，为研究唐代佛教思想的合流大势提供标本。其三，文学价值：疏序骈文气象汪洋、文质兼备，是佛教汉语文体研究的顶级语料。其四，义理价值：四法界、十玄门、六相圆融在澄观处的最终定型，为一切后世的华严诠释（包括日本华严、朝鲜圆测系统之外的义学）提供了标准框架。

争议问题有三。第一，与法藏的异同问题：澄观改法藏"新十玄"诸细节（如"唯心回转善成门"改为"主伴圆明具德门"之类调整），学界对这种"修正"是发展还是偏离有不同判断；镰田茂雄等澄观研究的详密考订，揭示其释义与法藏多有一致处，但判摄方式确有独立面目。第二，"一心"与"法界"的诠释张力：澄观以一心释法界，是回应禅宗的理论策略，还是内在义理的必然展开——这涉及华严心识论立场的再评价。第三，本档的文本性质问题：本档所录以疏序为主（序文而非法疏正文），六十卷疏的"随文解释"部分未入档，研究者须明此局限，勿以序文概全疏。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| Dharmadhātu（法界） | 一真法界，华严宗的最高本体范畴 |
| 四法界 | 事、理、理事无碍、事事无碍，澄观定型的判摄架构 |
| 十玄门 | 十种圆融无碍的观门（澄观承法藏新十玄而小有调整） |
| 六相圆融 | 总别、同异、成坏六相，相即互摄的原理 |
| 帝网（因陀罗网） | 帝释天宫宝网，喻重重无尽、珠珠互映 |
| 十身 | 澄观所立的十种佛身说（众生身、国土身等摄入佛身） |
| 五周因果 | 澄观对八十华严全经因果结构的五分判 |
| 随疏演义钞 | 澄观自撰的解释此疏的钞文（T1736，九十卷） |
