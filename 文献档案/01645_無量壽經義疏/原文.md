# 无量寿经义疏·原文

## 一、概述

《无量寿经义疏》涉及两部同名的佛典注疏，均收于《大正藏》第三十七册（T1745/T1746）：

**《无量寿经义疏》** 二卷（T1745），隋·净影寺慧远（523-592）撰，又称《净影疏》《大经义疏》。慧远为地论宗南道派代表，住隋长安净影寺，世称净影慧远。本疏为《无量寿经》现存最早注疏，旨在宣说无量寿佛之"所行、所成及所摄化"：所行者，彼佛本所起愿、本所修行；所成者，今所成法身、净土二种之果；所摄化者，普摄十方有缘众生同往彼国。释经时将经文分为序分、正宗分、流通分三分。此疏判阿弥陀佛净土为应身应土，后遭善导《观经四帖疏》批驳。此疏不见于国内诸藏，现存于日本《卍续藏》及《大正藏》。

**《无量寿经义疏》** 一卷（T1746），隋·吉藏（549-623）撰，又称《嘉祥疏》《大经义》。吉藏为三论宗创始人，本书依三论宗立场解释《无量寿经》。内容分两部分：先略述经文大意及释解经题，后释解经文文句。释经时分为序分、正说分、流通分三分。其判经宗致有二例：一者法藏修因感净土果，二者劝物修因往生彼土。吉藏认为此经之说相，先示妙果，后劝往生，系为使五浊众生舍离秽土而取净土。此疏国内不传，现存于日本《卍续藏》及《大正藏》。

## 二、核心段落

### 原文

> 此经宗要，宣说无量寿佛所行、所成、所摄。所行者，彼佛本所起愿、本所修行。所成者，今所成法身、净土二种之果。所摄化者，普摄十方有缘众生，同往彼国，修道证灭。故曰所摄。以此三义，为经宗致。
> ——慧远疏·卷一

> 此经宗致凡有二例。一者，弥陀修因，感净土果。二者，劝物修因，往生彼土。
> ——吉藏疏

> 愿佛为我广宣经法。我当修行，摄取佛国，清净庄严，无量妙土，令我于世，速成正觉，拔诸生死勤苦之本。
> ——（经文）法藏比丘白佛所言，慧远疏释为："所为有三：一是所行，二是所成，三是所摄。我当修行，是其初门，修行法身净土之因。摄取已下，是第二门，明己所成。"

### 白话翻译

> 这部经的宗要，是宣说无量寿佛的所行、所成、所摄化三个方面。所行，是指阿弥陀佛在因地所发之本愿和所修之行持。所成，是指如今已成就的法身与净土两种果报。所摄化，是指普摄十方有缘众生，共同往生彼国，修持道业，证得寂灭。所以称为"所摄"。以这三义，作为本经的宗要。
> ——慧远疏卷一文

> 这部经的宗致有两方面：第一，阿弥陀佛修因行而感得净土的果报；第二，劝导众生修习因行，往生彼佛国土。
> ——吉藏疏文

> 法藏比丘向佛请求："愿佛为我广说经法。我应当修行，摄取佛国清净庄严的无量妙土，使我在世间速成正觉，拔除一切众生生死勤苦的根本。"慧远疏释为：法藏所求有三方面——所行（修行法身净土之因）、所成（成就佛身与净土）、所摄（摄取佛国清净庄严等）。

## 三、名句

1. **"所行者彼佛本所起愿、本所修行；所成者今所成法身、净土二种之果；所摄化者普摄十方有缘众生同往彼国。"** ——慧远以"所行、所成、所摄"三义概括《无量寿经》全部宗要，将阿弥陀佛因地修行、果地成就、度化众生三个层面统摄无遗，成为后世理解此经的根本框架。

2. **"此经宗致凡有二例：一者弥陀修因感净土果，二者劝物修因往生彼土。"** ——吉藏以三论宗立场，将经旨归纳为弥陀修因感果与劝众生修因往生两大纲领，揭示净土法门因果相应之理。

## 四、术语表

| 术语 | 释义 |
|------|------|
| 净影疏 | 慧远撰《无量寿经义疏》之别称，因慧远住净影寺而得名 |
| 嘉祥疏 | 吉藏撰《无量寿经义疏》之别称，因吉藏住嘉祥寺而得名 |
| 所行所成所摄 | 慧远立《无量寿经》三义宗要：所行（因地愿行）、所成（果地法身净土）、所摄（度生往生） |
| 应身应土 | 慧远判定阿弥陀佛为应身佛、极乐净土为应化土，与善导"报身报土"说对立 |
| 四十八愿 | 法藏比丘所发大愿，慧远疏中逐一标题（如"国无恶道愿"等），以便醒目 |
| 三辈往生 | 《无量寿经》所说上辈、中辈、下辈三种往生，各以发菩提心、一向专念为根本条件 |
| 法藏比丘 | 阿弥陀佛之因地，于世自在王佛所发菩提心，摄取二百一十亿佛刹，发四十八愿 |
