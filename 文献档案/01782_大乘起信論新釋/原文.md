# 大乘起信論新釋 · 原文

## 一、概述

《大乘起信論新釋》，日本佛教學者**湯次了榮**（ゆずり りょうえい）著，**豐子愷**譯。

**譯本源流**：豐子愷於 1966 年譯成此書。因當時處境特殊，譯者未具真名，署為「中國一佛教徒無名氏譯」。此譯本後在台灣流通，1990 年 8 月由世樺印刷企業有限公司出版（212 頁，ISBN 9789577220240）；2015 年由浙江人民美術出版社再版（234 頁，ISBN 978-7-5340-4576-9，列「藝文類聚」叢編）。

**所依底本**：以梁·真諦譯本與唐·實叉難陀譯本兩種漢譯為基礎。

**詮釋立場**：據該書內容提要，本書「專以賢首大師的《義記》為準則，並從旁參考諸家的疏注，揭示其要旨；但注意於緣起及實用的兩面觀」。即以法藏《大乘起信論義記》（T1846）為主要依據，兼採他家，並特別著眼於「緣起」（義理）與「實用」（修行）兩個面向。

**版權說明**：本書著者湯次了榮為近代日本學者，譯者豐子愷（1898–1975）之譯文亦在著作權保護期內，且現行版本為正式授權出版物。因此本篇**不迻錄原文段落**，僅作體例說明、結構提要與特點述評，並註明版本以便讀者查考原書。此與本檔案庫中唐宋明清古籍條目（已入公有領域、可全文引用並作白話對照）的處理方式不同。

## 二、本書體例

本書最顯著的特色，是為《起信論》每一段論文設立**四段解析**的固定格式：

| 段目 | 功能 |
|------|------|
| **和譯** | 將漢文論句譯為現代語（原為日語口語譯，中譯本轉為現代漢語） |
| **字義** | 逐字逐詞解釋名相 |
| **要義** | 提示該段的核心旨趣 |
| **詳義** | 展開詳細的義理疏解，並引諸家異說 |

這一體例把傳統疏家「隨文解義」的單線方式，改造為由淺入深的四層階梯——先通文字，次通名相，再握綱要，終入深義。對於文義艱澀的《起信論》而言，這種分層處理正是「新釋」之「新」的所在，也是本書長期作為入門讀本的原因。

## 四、內容特點述評

### （一）覺義分析的細密化

由上列節目可見，本書對「覺與不覺」一組概念的處理極為細密：把《起信論》原本連貫的一段文字，拆解為「覺不覺」總說 → 「本覺始覺」對舉 → 「始覺的四位」次第 → 「隨染本覺」「性淨本覺」二重本覺 → 「根本不覺」「枝末不覺」二重不覺 → 「覺不覺的同異」會通，共七節。這種析理方式承自法藏《義記》而更為條理化，是近代學術性佛典註釋的典型作法。

### （二）熏習說的獨立處理

「熏習的四法」「染法熏習」「淨法熏習」三節，把《起信論》真如與無明互熏的機制單獨提出詳論。真如受熏問題正是《起信論》與唯識學爭議的焦點（參 01759 條蕅益智旭《裂網疏》自序中對此的辨析），本書以三節篇幅處理，可見其重視程度。

### （三）兼顧緣起與實用

書中提要自陳「注意於緣起及實用的兩面觀」——「緣起」指真如緣起的理論體系，「實用」指修行實踐的可操作性。第八章「修行信心分」的處理，即體現後一面向。

### （四）考證與義理並重

本書亦涉及傳譯歷史的考證與相關研究成果的梳理，兼具義學疏解與文獻研究的雙重性格。這與同屬近現代的印順《大乘起信論講記》（見 01778 條）在懸論中大篇幅處理真偽公案，屬於同一時代學風的產物，但二者立場不同：湯次了榮以法藏《義記》為準則，基本承續華嚴宗傳統詮釋；印順則以「真常唯心系」為之定位，帶有明確的思想史批判意識。
