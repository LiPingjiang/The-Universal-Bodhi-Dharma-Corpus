# 《大乘阿毗達磨經》 — 学术解读

## 一、文献背景与成书

《大乘阿毗達磨經》（梵 *Mahāyānābhidharma-sūtra*）是瑜伽行派传说中最重要的根本经典之一，却也是一部"佚经"——梵本、汉译本今皆不存，其内容只能通过无著《攝大乘論》、以及《瑜伽師地論·攝決擇分》等论书中的引文窥见一斑。本档案原文档即如实标注了这一点：所录经文皆转引自《攝大乘論》（玄奘译，T1593）。

此经在印度佛教史上的地位，可由无著论书的援引方式推知。《攝大乘論》开卷即引"阿毗達磨大乘經中薄伽梵前，已能善入大乘菩薩，為顯大乘體大故說"，并引其偈颂（如"無始時來界，一切法等依"）作为阿赖耶识说的经典依据；安慧、无性、世亲诸家释《攝論》，亦皆视此经为唯识学说的圣言量。换言之，瑜伽行派以"论"传世的全部核心教义——阿赖耶识、三性、唯识无境——都被溯源到此"经"的权威之下。至于此经是否真有完整的梵本流传、抑或部分出于学派的"圣言建构"，正是近代以来学界聚讼的问题。

## 二、文本结构与核心思想

现存可考的经文要点，集中在《攝大乘論》所引"十种殊胜"纲领：一者所知依殊胜（阿赖耶识为一切法的所依），二者所知相殊胜（依他起、遍计所执、圆成实三自性），三者入所知相殊胜（唯识观行的悟入），四者彼入因果殊胜（六波罗蜜多），五者彼因果修差别殊胜（菩萨十地），六者增上戒殊胜，七者增上心殊胜，八者增上慧殊胜（菩萨三学），九者彼果断殊胜（无住涅槃），十者彼果智殊胜（法身等三身）。无著明言：此十处于声闻乘"曾不见说"，唯大乘处处说之——这是大乘自证其殊胜合法性的经典论证。

其思想的枢纽有二。一是"界"（dhātu）为一切法等依的种子说：经中"无始时来界，一切法等依，由此有诸趣，及涅槃证得"一偈，被唯识家解释为阿赖耶识摄持一切种子的经典出处，亦是"赖耶缘起"的总纲。二是三性说：遍计所执性是凡夫妄执的实我实法，依他起性是依缘而起的唯识相，圆成实性是离执所显的真如——迷悟、染净、真妄，皆在此三相结构中定位。由此，十殊胜层层展开为一部完整的大乘修道论。

## 三、学术研究价值与争议

研究价值方面，此经虽是佚书，却是重建早期瑜伽行派形成史的关键坐标：将《攝論》引文与《瑜伽師地論》《大乘阿毗達磨集論》及藏传所传无著、弥勒诸论比对，可勾勒"大乘阿毗达磨"从经到论的演变轨迹。日本学界（如勝又俊教、上田義文）曾系统辑佚此经佚文，近年学者又将其与犍陀罗语写本、中亚出土文献对勘，试图判断其成立的年代与地域。

争议主要有三。其一，此经的实在性问题：有学者（如舟桥尚载等）怀疑它并非一部独立流传的完整经典，而是瑜伽行派将学派义理"经化"的结晶，类似《解深密經》的形成过程；亦有学者据引文体例主张其确有梵本。其二，与《解深密經》的关系：两经同为唯识圣言依据，何者在前、是否存在共同的母本，尚无定论。其三，汉藏传本的差异：藏传传统对此经的征引路径与汉传不同，反映两系对"大乘阿毗达磨"理解的分流。

## 四、术语对照表

| 梵语 | 汉译 | 说明 |
|------|------|------|
| abhidharma | 阿毗达磨、对法 | 对教法的系统论究；此经以"大乘对法"为名 |
| ālaya-vijñāna | 阿赖耶识 | 所知依，摄持种子的根本识 |
| dhātu | 界 | "无始时来界"之界，种子义 |
| trisvabhāva | 三自性 | 遍计所执、依他起、圆成实 |
| parikalpita-svabhāva | 遍计所执性 | 妄情所执的实我实法 |
| paratantra-svabhāva | 依他起性 | 依托众缘而生之法 |
| pariniṣpanna-svabhāva | 圆成实性 | 依他起上离遍计执所显真如 |
| apratiṣṭhita-nirvāṇa | 无住涅槃 | 不断生死不住涅槃的佛果 |
