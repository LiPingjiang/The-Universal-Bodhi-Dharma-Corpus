# 噶舉派蔣貢仁波切文集 · 原文

## 一、文獻概述

本檔彙集蔣貢康楚羅卓泰耶（Jamgon Kongtrul Lodrö Thaye，1813–1899，一說示寂於1901；又稱工珠·雲丹嘉措）之著作文集。第一世蔣貢康楚為十九世紀藏傳佛教最偉大的學者、詩人與實修者之一：他不僅精通經藏與密續，對苯教教義亦有深刻認識，一生著作多達一百餘部；與其根本上師蔣揚欽哲旺波（1820–1892）、大伏藏師秋吉林巴共同發起「利美」（Rimé，不分教派）運動，打破宗派藩籬，廣蒐八大實修傳承之教法，使眾多面臨失傳的法脈得以保全。他是第十五世大寶法王卡恰多傑最主要的上師，也是噶瑪噶舉蔣貢康楚轉世傳承之第一世；其駐錫與康區八蚌寺系統（第九世大司徒貝瑪寧杰與其分建八蚌上、下閉關中心）關係密切，故其文集屬噶舉派傳承之核心寶藏。

其最著名的著作為總稱「五寶藏」（或云五大藏）之巨著，依通行記載包含：《大寶伏藏》（Rinchen Terdzö，彙集當時寧瑪派主要伏藏及灌頂實修之釋文）、《教授藏》（口訣藏，彙集各傳承實修口訣）、《所知藏》（知識藏，十明學問之總彙）、《噶舉密咒藏》（彙集噶舉傳承密法）及《根本教法藏》等。其中《大寶伏藏》最為豐富：為收編此藏，蔣揚欽哲旺波曾赴藏地中東部行腳十三年，從幾近失傳之傳承處請受教法。此外，蔣貢康楚尚著有《了義炬》（四加行之經典指導，漢譯本通行）、《自傳》等重要作品。

## 二、核心段落選錄

> **原文**：據其傳記所載利美運動之旨：蔣貢康楚與蔣揚欽哲旺波「共同收集來自藏傳佛教八大實修傳承的教法……利美運動並非和事佬，也不是把不同的法門攪混在一起，而是真的尊重並保全各自法脈傳承的完整性，弘揚釋迦牟尼佛所傳下的每一種佛法」。（據藏傳佛教史料之通行表述）
> **白話對照**：不分教派運動並不是無原則的調和，更不是把不同法門混成一鍋粥；它的真精神是尊重每一條法脈、完整地保存每一種傳承，使佛陀傳下的所有教法都能延續弘揚——這正是蔣貢康楚編纂五寶藏的動機。

> **原文**：蔣貢康楚《了義炬》為四不共加行之根本指導，其綱領為：皈依大禮拜、金剛薩埵百字明、獻曼達、上師相應（上師瑜伽）四法，依序淨除罪障、積聚資糧、領受加持，為大手印正行之階梯。（據《了義炬》通行漢譯本之教授次第）
> **白話對照**：進入密乘正行之前，要先完成四種基礎修行：以身口意皈依而行十萬大禮拜，拜除我慢、淨化罪障；持誦金剛薩埵百字明，清除業垢；以曼達供養累積福慧資糧；最後修上師相應法，使心與傳承上師的證悟合一——這是進入大手印的階梯。

> **原文**：據五寶藏編纂史料所記：「殊勝的大寶伏藏全集，是蔣貢工珠羅卓泰耶在其一生中所編撰的五大寶藏中最為豐富的。這個非凡的文集，囊括了當時藏傳佛教寧瑪派的主要伏藏以及給予相關灌頂和實修時所必需的解釋。」（據《大寶伏藏》相關史料記述）
> **白話對照**：五寶藏中卷帙最浩瀚的是《大寶伏藏》：它把那個時代還存在的寧瑪派主要伏藏法門，連同灌頂儀軌與實修必需的講解，全部系統地收錄起來——沒有這部集成，許多伏藏傳承早已斷絕。

## 三、重要名句

> **名句一**：「諸法平等，不應執一斥餘」——利美精神之要義：各派教法皆是佛說，執自謗他即是法之毒。

> **名句二**：「五寶藏」之名——以「藏」（Dzö）喻其如寶庫：一代大師把整個西藏佛教的顯密教法與學問收為五庫。

> **名句三**：「利美不是混淆傳承，而是保全每一傳承之完整」——蔣貢康楚運動遺留給後世的方法論原則。

> **名句四**：四加行為「入道之門，成就之基」——《了義炬》所確立的實修次第觀。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 利美（Rimé） | 「不分教派」運動，十九世紀由蔣貢康楚、蔣揚欽哲旺波等發起 |
| 五寶藏 | 蔣貢康楚五大巨著總稱：大寶伏藏、教授藏、所知藏、噶舉密咒藏、根本教法藏 |
| 伏藏（Terma） | 蓮花生大師等埋藏、後世伏藏師取出之教法 |
| 《所知藏》 | 十明學問總彙，藏傳百科式巨著 |
| 四不共加行 | 皈依大禮拜、金剛薩埵、獻曼達、上師相應四種密乘前行 |
| 《了義炬》 | 蔣貢康楚所著四加行指導經典 |
| 八大實修傳承 | 利美運動所蒐集之八種西藏佛教傳承法脈 |
| 蔣貢（Jamgon） | 噶瑪噶舉重要轉世傳承尊號，第一世即羅卓泰耶 |
