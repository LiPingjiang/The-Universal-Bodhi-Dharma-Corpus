# 瑜伽师地论释 — 学术解读

[原文](原文.md) | [白话解读](解讀_白話.md)

## 一、文献背景与成书

《瑜伽师地论》（Yogācārabhūmi-śāstra）是瑜伽行派（唯识学派）的根本大典，汉传题为弥勒菩萨说、无著菩萨记录（藏传则径题无著造），约成书于公元4世纪。汉译以玄奘于贞观二十年至二十二年（646-648）在长安弘福寺译出的一百卷本为定本，收于《大正藏》第三十册，编号T1579。此前汉地已有部分异译：北凉昙无谶译《菩萨地持经》、刘宋求那跋陀罗译《菩萨善戒经》、陈真谛译《十七地论》（已佚）等，均为其中部分内容的古译。

本文献所题"瑜伽师地论释"，特指印度释论家最胜子（Jinaputra）等菩萨造、玄奘译出的《瑜伽师地论释》，一卷，收于《大正藏》第三十册（T1580），为《瑜伽师地论》最古的注疏。最胜子是北印度钵伐多国人，护法弟子，唯识十大论师之一。梵文方面，20世纪荻原云来校订刊行"菩萨地"部分，1936年罗睺罗·香克利亚衍那于西藏萨迦寺发现全论梵本写本并录写归印，1950年代由加尔各答大学部分刊行，使本论成为梵汉藏三本并传的大论。

## 二、文本结构与核心思想

玄奘译百卷本分五分：

1. **本地分**（卷一至五十）：全论主体，明"十七地"——从五识身相应地、意地，经有寻有伺等三地、三摩呬多地、非三摩呬多地、有心地、无心地，至闻思修三所成地、声闻地、独觉地、菩萨地，终以有余依、无余依地收束。十七地即瑜伽师（禅修者）修行所历的一切境界与阶位。
2. **摄决择分**（卷六十六至七十一卷区间，实际为卷六十六至八十五前后）：对本地分深义再作决择，阿赖耶识的深入阐发多在此分。
3. **摄释分、摄异门分**：解释经的体裁与名相差别。
4. **摄事分》：抉择契经事义。

核心思想可概括为三点：

- **万法唯识**：如本档案原文所录唯识家名偈"由假说我法，有种种相转，彼依识所变"（此偈实出《唯识三十颂》，为瑜伽行派共同纲领），一切现象皆是识的变现，心外无实境。
- **阿赖耶识缘起**：本论系统建立第八识学说——种子与现行互熏，构成生死流转与还灭的机制，本档案原文术语表所列"阿赖耶识""熏习""转依"即此体系的枢纽概念。
- **止观与转依**：本论名"瑜伽师地"，本身即以禅观次第为纲，转识成智、转染成净的"转依"（āśraya-parāvṛtti）是终极目标。

**释论方面**，最胜子《瑜伽师地论释》以六门科简全论大纲：所为、所因、名义、宗要、藏摄、释文，是把握百卷巨论的最早导读，历来为法相学者必习。

## 三、学术研究价值与争议

**研究价值**：（1）《瑜伽师地论》是研究公元4世纪前后印度佛教"禅修学百科"的总库，声闻地、菩萨地的修道论是南传与北传禅法比较研究的枢纽材料；（2）本论组织庞大，保存了大量说一切有部、经量部等部派学说，是部派佛教研究的富矿；（3）最胜子释论提供7世纪唯识家对本论的判读框架，可借以考察印度瑜伽行派的诠释史。

**代表学者与争议**：（1）作者问题是第一争议：弥勒说、无著造两说背后是"弥勒为历史人物抑或未来佛"的宗教与文献分歧，学界至今聚讼；（2）本论各部分成立年代不一，"菩萨地"先行成书的分层说影响深远；（3）近代唯识学复兴中，韩清净以毕生之力撰《瑜伽师地论科句·披寻记》，欧阳竟无内学院诸师对此论的研究，构成20世纪中国唯识学的重镇；（4）宇井伯寿、横山纮一等日本学者对论书成立史的细密考订为学界奠基。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 瑜伽师地 | 瑜伽师（禅修者）所依所行的十七种境界 |
| 十七地 | 全论总纲，从五识身地至无余依地 |
| 阿赖耶识 | 含藏一切种子的第八识，轮回与解脱的枢纽 |
| 转依（āśraya-parāvṛtti） | 认知基础的彻底转变，解脱的唯识式定义 |
| 最胜子 | 护法弟子，十大论师之一，《论释》作者 |
| 五分 | 本地、摄决择、摄释、摄异门、摄事五大部分 |
