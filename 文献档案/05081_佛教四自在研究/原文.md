# 佛教四自在研究 · 原文

## 一、概念概述

「四自在」指菩薩於八地以上所證得之四種無礙無礙作用力（自在，梵 vaśitā），出自《辯中邊論》（T1600，玄奘譯）卷上〈辨相品〉釋「不增不減義」處，為法相宗十地配位學說之綱目：一、無分別自在——於諸法離一切分別戲論而運作無礙；二、剎土（淨土）自在——隨願示現身相國土無礙；三、智自在——於四無礙解得自在，善說法要無礙；四、業自在——於一切神通、陀羅尼、三摩地作業皆得自在。此四自在以法界（真如）為所依：《成唯識論》（T1585）卷九配十真如，謂第八地證「相土自在所依真如」（初二自在）、第九地證「智自在所依真如」、第十地證「業自在等所依真如」——故四自在是菩薩三清淨地（八、九、十地）功德的總綱。八地菩薩得無生法忍、住無相無功用行，華嚴《十地品》更於八地開為「十自在」（命、心、財、業、生、願、解、如意、智、法自在），瑜伽唯識系則攝略為四。別系經典亦說四自在：《自在王菩薩經》（T1531）說戒自在、神通自在、智自在、慧自在；《大集經》卷十五說壽命自在、身得自在、得法自在、願得自在，皆顯「於法得自由轉用」之菩薩行果義。四自在與十八不共法、十力、四無所畏同屬佛菩薩果德系統，是「從般若入薩婆若」之路徑刻度。

## 二、核心經文選錄

> **原文**（《辯中邊論》卷上，T1600）：
> 「第八地中所證法界，名不增不減義。由通達此，圓滿證得無生法忍，於諸清淨雜染法中，不見一法有增有減。有四自在：一、無分別自在，二、剎土自在，三、智自在，四、業自在。法界為此四種所依，名四自在所依止義。第八地中，唯能通達初二自在所依止義。」

> **白話對照**：
    八地所證法界名「不增不減」——染法減時無實減，淨法增時無實增。通達此理即圓滿證得無生法忍，由此出生四種自在：一、無分別自在——於無相無功用中任運度生；二、剎土自在——隨願淨化國土、示現身相；三、智自在——說法無礙；四、業自在——神通作業無礙。四者皆以法界為所依；八地唯通達前二種，智自在屬九地，業自在屬十地。

> **原文**（《大方廣佛華嚴經·十地品》，T279）：
> 「菩薩成就如是身智已，得命自在、心自在、財自在、業自在、生自在、願自在、解自在、如意自在、智自在、法自在。得此十自在故，則為不思議智者、無量智者、廣大智者、無能壞智者。」

> **白話對照**：
    八地菩薩成就種種身智之後，得十種自在：壽命隨意、定心隨意、資財隨意、身業隨意、受生隨意、願求隨意、信解隨意、神變隨意、智慧隨意、說法隨意——即於生死世間與佛法事業俱得自由轉用之權。此十自在是四自在在華嚴系統中的廣開，攝略則仍歸無分別、剎土、智、業四種。

## 三、重要名句

> 「有四自在：無分別自在，剎土自在，智自在，業自在。」（《辯中邊論》卷上）

> 「法界為此四種所依，名四自在所依止義。」（《辯中邊論》卷上——四自在以真如為體，非神我主宰之自由）

> 「得此十自在故，則為不思議智者、無量智者、廣大智者、無能壞智者。」（《華嚴經·十地品》）

> 「自在非由他，證真如故得。」（唯識家論十自在依於真如通達之通義概括）

| 自在 | 於法得自由轉用無礙之力（梵 vaśitā） |
| 無分別自在 | 八地無相無功用行，離戲論而任運度生 |
| 剎土自在 | 隨願示現淨土身相之自在 |
| 智自在 | 九地得四無礙解，說法自在 |
| 業自在 | 十地於神通陀羅尼三昧作業自在 |
| 四自在所依止義 | 法界真如為四自在所依之位名 |
| 十自在 | 華嚴八地所開之命心財業生願解如意智法自在 |
| 無生法忍 | 八地所證、四自在之根本智依 |
