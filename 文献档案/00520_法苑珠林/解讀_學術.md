# 法苑珠林 — 学术解读

## 一、文献背景与成书

《法苑珠林》，一百卷，唐代西明寺沙门道世（俗姓韩，字玄恽，京兆长安人）撰，成书于唐总章元年（668年）前后，收于《大正藏》第五十三册（T2122）。道世为律宗祖师道宣的同门师弟，长期在西明寺从事佛教典籍的编纂工作。

本书为佛教类书之巨著，全书分一百篇（自《劫量篇》始，至《传记篇》终），篇下分部，总计六百余部。道世"以为古今绵代，制作多人，虽雅趣佳辞，无足于记传。由是搴文囿之菁华，嗅大义之瞻卜，以类编录，号《法苑珠林》"。全书博引佛典及世俗典籍四百余种，其中佛教以外典籍一百四十余种，每一条目皆标明出处，许多已佚古籍赖此保存片段，史料价值极高。书前有朝议大夫兰台侍郎陇西李俨所撰之序。

"法苑"意为佛法之园林，"珠林"意为珍宝之林——书名意即"佛法园林中的珍宝之林"，将佛教的种种教义、故事、名相、仪轨分门别类，如珍珠般串联起来。

## 二、文本结构与核心思想

全书按主题分为一百篇，每篇下分若干部。各篇依次涵盖：劫量（时间宇宙观）、三界（世界构成）、诸佛（佛菩萨）、地狱、饿鬼、畜生、修罗、人道、天道、往生、持戒、忏悔、布施、智慧、神异、感通等。其分类体系体现了佛教对世界与人生的完整认知框架。

**核心特色**：

其一，**以类相从**。道世将佛教浩如烟海的知识，按主题分为一百个类别，每个类别下再细分。这种分类法本身就是一部"佛教知识图谱"，反映了唐代佛教对自身知识体系的系统认知。

其二，**经证为本**。每一条目都标明出处（某经、某论、某律），不凭空立说。这种严谨的引用方式，使本书成为一部可靠的佛教文献索引。

其三，**兼收世俗典籍**。本书引用佛教以外典籍一百四十余种，包括儒家经典、道家著作、史书、志怪小说等。这些引用不仅便于佛教学者，也为研究唐代世俗文献的流传提供了线索。

其四，**注重感应故事**。书中大量收录佛教感应故事（如念佛感应、持戒感应、造像感应等），反映了唐代佛教"信仰与实践"紧密结合的特点。

## 三、学术研究价值与争议

**研究价值**：本书是中国佛教类书的巅峰之作，其文献价值居佛书之首。所引四百余种典籍中，许多已佚失，如《冥祥记》《旌异记》《观世音应验记》等，赖本书保存了大量片段。对于研究唐代佛教的教义体系、信仰实践、仪轨制度、佛教文学等，本书都是不可或缺的资料来源。

**代表学者**：道世为作者；道宣《集古今佛道论衡》为同门之作；李俨为本书序作者；陈垣《中国佛教史籍概论》对本书有专章论述；日本学者牧田谛亮对本书所引感应故事有专门研究。

**争议问题**：其一，本书与道世早年所编《诸经要集》的关系——《诸经要集》二十卷为本书的前身，两书之间的内容取舍与编排变化，反映了道世佛教思想的发展；其二，本书的类目编排是否合理——部分篇目的分类标准不够统一，存在交叉重叠；其三，本书所引世俗典籍中，部分引文与现存文本有出入，需要校勘。

## 四、术语对照表

| 术语 | 释义 |
|------|------|
| 法苑 | 佛法之园林，喻佛法之丰富多样 |
| 珠林 | 珍宝之林，喻书中内容如珍珠般珍贵 |
| 类书 | 按主题分类编纂的工具书，中国传统的百科全书式著作 |
| 感应故事 | 佛教信徒因修行而感得佛菩萨灵验应现的故事 |
| 劫量 | 佛教时间单位，一劫为世界从生成到毁灭的周期 |



### 拓展视域

从更广阔的思想史视野来看，此文献的意义不仅限于佛教内部。它与中国本土的儒道思想之间存在着复杂的互动关系——既有竞争、辩论，也有吸收与转化。同时，此文献的解读也需放在汉传佛教与藏传佛教、南传佛教相互参照的框架中，方能获得更全面的理解。现代学者在诠解此文时，逐渐从传统的宗派立场转向客观的学术研究，注重文献学、思想史与社会史的多维视角，为这一佛教经典注入了新的学术生命力。
