# 辨法法性论 — 学术解读

## 一、文献背景与成书

《辨法法性论》（Dharmadharmatāvibhāga）是"弥勒五论"之一，传统上归于弥勒（Maitreya）所说，约成书于公元4世纪，与《辨中边论》《现观庄严论》同属弥勒学系；学界通说多认为其出自无著（Asaṅga）或无著学圈之手。原文为梵语，短篇颂体，附世亲释（一说安慧释，注释者归属有不同传本）。

本论在古代未译为汉文，完整的传承依赖藏译本（收入丹珠尔，德格版 Toh.4021/4022 颂与释）。梵文原典迟至20世纪才由罗睺罗·桑克里提亚延在西藏发现写本，经校勘刊行后，成为国际弥勒学/唯识学研究的热点。现代汉译由法尊法师等据藏译译出；20世纪后期藏传各派（如宁玛派、格鲁派）上师曾为此论撰写多部注释，使其在汉语佛学界广为流传。

## 二、文本结构与核心思想

全论以"法"与"法性"之辨为轴心，分三段展开：

其一，**明法之虚妄**：法（dharma）者，虚妄分别所现，具有能取（认识主体）与所取（认识对象）二相，属有为、生灭、轮回之边。其二，**明法性之真实**：法性（dharmatā）者，离能所二取的真如平等性，属无为、不生灭、涅槃之边。其三，**明转依之道**：由法转入法性的修道次第——从听闻、思惟空性，到加行位的有相与无相修习，最终成就"转依"（āśraya-parāvṛtti）。

核心思想可提炼为两句：**"生死与涅槃之分际，不在别有一物，只在能所二取之有无"**——二取未息即名法，二取既息即名法性；**"转依"为全论枢要**——非于法外别得法性，乃即此虚妄分别之所依，转舍杂染、转得清净而已。本论由此以极简的篇幅，完成了从唯识见（虚妄分别的安立）到修道论（转依的实践）的贯通，被视为弥勒五论中最简洁深刻的一部。

## 三、学术研究价值与争议

研究价值方面，本论在唯识学谱系中位置独特：它既以"虚妄分别"立论（与《辨中边论》一致），又将"法性"与"无分别智"置于修道论的核心，故藏传传统视其为沟通唯识与大乘修道次第的桥梁，宁玛派更以"大圆满加行"的视角阐释之。梵本的重新发现使学界得以对勘汉译《辨中边论》系统中未见的文本传统，深化了对"弥勒五论"文本群构成的理解。藏译注释传统（如跋尊噶惹蜜多罗、智作慧等印度注释家）的研究，是近年国际藏学与唯识学的交叉热点。

争议问题包括：（1）作者与注释者归属——弥勒造颂、世亲或安慧作释的不同传承记载，牵涉弥勒学文献群的成层问题；（2）本论的宗派定位——究竟属唯识（瑜伽行派）还是已被中观化解读（尤其藏传苯教/宁玛派的传统），学界有不同评价；（3）"转依"概念的演变——本论的转依说与《成唯识论》系统中转依八识成四智之说详略不同，比较研究仍在深入。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 法（dharma） | 虚妄分别所现的轮回诸法 |
| 法性（dharmatā） | 离二取的真如，诸法实性 |
| 虚妄分别（abhūtaparikalpa） | 错误的认知构造，轮回之根 |
| 能取/所取（grāhaka/grāhya） | 认识主体与被执取的对象 |
| 转依（āśraya-parāvṛtti） | 认知依止的根本转变，解脱之果 |
| 无分别智（nirvikalpajñāna） | 离概念分别的直观智慧 |
