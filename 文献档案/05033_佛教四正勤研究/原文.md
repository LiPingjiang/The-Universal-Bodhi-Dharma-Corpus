# 佛教四正勤研究 · 原文

## 一、概念概述

四正勤（梵 catvāraḥ samyak-prahāṇāḥ，又譯四正斷、四意斷、四正勤）是三十七道品之第二科，位於四念處之後、四神足之前，屬精進波羅蜜之具體化。其名目為：一、已生惡不善法為斷故，生欲、發起、策勵、攝受、精勤；二、未生惡不善法為不生故，生欲……精勤；三、未生善法為令生故，生欲……精勤；四、已生善法為住不失、倍增廣大故，生欲……精勤。簡言之即「已生惡令斷、未生惡令不生、未生善令生、已生善令增長」。經證見《雜阿含經》（T99）卷三十、《中阿含·念處經》及《長阿含·眾集經》（T1）；論釋見《俱舍論》卷二十五（名「四正斷」）、《大智度論》卷十九、《瑜伽師地論》卷二十九。「正勤」（samyak-prahāṇa）之「正」揀別於外道苦行邪精進，「勤」顯精進無間。四正斷之結構是「防恶」與「修善」雙軌各分「已生／未生」二際，構成完整的道德修養動力學：對治面（斷惡）與長養面（修善）並重。部派異說：《俱舍論》謂「以勤為體」，《成唯識論》卷九則以四正斷即四神足之精進支所攝。四正勤與四念處之關係：念處為「觀」（慧之觀照），正勤為「行」（勤之策發），念處如目、正勤如足，二者合為解脫道之見行基礎。

## 二、核心經文選錄

> **原文**（《雜阿含經》卷三十，T99）：
> 「何等為正勤？若比丘已生惡不善法，方便斷滅，生欲、方便、精勤、攝受；未生惡不善法，方便令不生；未生善法，方便令生起；已生善法，方便修習令不失、令增長。是名四正勤。」

> **白話對照**：
> 四正勤即四種正確的精進：對已經生起的惡法，勤於斷除；對尚未生起的惡法，勤於預防；對尚未生起的善法，勤於引發；對已經生起的善法，勤於保持並令增長。前二種是離過的精進，後二種是修善的精進。

> **原文**（《阿毘達磨俱舍論》卷二十五，T1558）：
> 「四正斷：一於已生惡不善法，為令斷故，起策發勤；二於未生惡不善法，為不生故；三於未生善法，為令生故；四於已生善法，為令安住、不忘、倍修、增廣故。如次即是欲、勤、策勵、正念之差别。」

> **白話對照**：
> 《俱舍論》以「正斷」為名——「斷」不僅指斷惡，也含「斷懈怠」之義。每一正斷皆以「欲（希求）、勤（精進）、策勵（策發其心）、正念（攝持不忘）」為發動條件：精進不是盲目的勤苦，而是由善法欲推動、正念護持的有方向之努力。

## 三、重要名句

> 「已生惡令斷，未生惡令不生；未生善令生，已生善令增長。」（四正勤之通行偈頌概括）

> 「譬如救頭燃，精進不放逸。」（《佛遺教經》精進之譬，正勤之精神）

> 「懈怠為一切惡法之本，精進為一切善法之本。」（《大智度論》卷十五釋精進度之義）

> 「四正斷者，即是戒清淨之勤行。」（《瑜伽師地論》卷二十九以正勤攝律儀之義）

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 四正勤／四正斷 | 斷惡修善四種正精進 |
| 已生惡 | 現前已起之貪瞋等不善法，勤令斷滅 |
| 未生惡 | 尚未現行而種子猶在之惡法，防令不起 |
| 未生善 | 尚未生起之信、戒、聞、施等善法，引令生起 |
| 已生善 | 現行善法，令安住不失、倍復增廣 |
| 策勵 | 於心掉舉時策發其心，屬正勤之因 |
| 善法欲 | 由正見生起之希求善法之欲，精進之動力 |
| 不放逸（apramāda） | 正念與正知攝持善法，四正勤之總果 |
