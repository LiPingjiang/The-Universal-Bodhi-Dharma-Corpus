# 佛教四禪定研究_3 — 学术解读

## 一、文献背景与成书

本条目是语料库「研究」系列的主题类条目，编号 06605，原文档为名目与节引式体例，仅存概述与两段引文、术语对照表等，并非传世典籍，故不涉成书考订，而就「四禅」主题作综述解读。同库另立同名条目 `06608_佛教四禪定研究_3`，底本与本条相同；本条侧重禅支结构与文本用语分析，彼条侧重四禅在整个禅法体系中的定位与跨传统比较，两相分工互注。

四禅是佛教禅法体系的骨架，其原型公式见于四部阿含：初禅以「离欲离诸恶不善法，有寻有伺，离生喜乐」定义，历代部派文献均以此为基准。原文档的特别之处在于其文本层次是叠压的：概述部分作「初禅离生喜乐地、二禅定生喜乐地、三禅离喜妙乐地、四禅舍念清净地」，这一套「某地」式的命名是汉传毗昙与天台系统整理禅法时形成的表述层；而两段核心引文，一段保留阿含式的初禅公式，另一段「寻伺息故，内等净故，心一趣故，无寻无伺，定生喜乐」则明显出自后期阿毗达磨乃至唯识译籍的用语习惯（「内等净」「心一趣」皆玄奘系译语）。原文档内部即并存三个时代的语言层次，如实著录，正可供分析。

## 二、文本结构与核心思想

四禅的经典叙述采取「阶梯式脱落」的结构：每一层禅定都是对上一层心理成分的剥离与提纯。

初禅具五支：寻、伺、喜、乐、心一境性。寻与伺是粗细两级的内心引导活动——把心带向所缘（寻）并在所缘上持续盘桓（伺）。进入初禅的条件是「离欲离诸恶不善法」，即先与欲界的感官刺激脱钩，此时生起的「离生喜乐」是因离欲而涌现的身心欢愉。

二禅略去寻、伺二支，代之以「内等净」——内心不再需要言语性引导而达到的澄净信任，原文引文「寻伺息故，内等净故，心一趣故」正是对这一转折的精确描述：内心的自动评论停止了，只剩定心本身带来的喜乐，故曰「定生喜乐」。

三禅再脱落「喜」这支。喜在禅修术语中特指兴奋性的、带动身心的踊跃感；三禅将其平息，剩下更绵密安静的「乐」，故概括为「离喜妙乐」。

四禅则连乐受也超越，达到「舍念清净」——舍是于一切对象不偏不倚的平衡心，念是清明的忆持力，此时定心纯粹而稳定，成为可以承载观慧的最佳平台。

从概览句的四地名目可见，汉传传统以「离生喜乐地」等四名概括四禅，其要点在于把每一禅的标志性心理成分提取为地名的定语，这一命名策略使四禅结构一目了然，也反映汉地祖师对毗昙材料的消化。

## 三、学术研究价值与争议

第一，禅支系统的部派差异是禅法研究的重要课题。说一切有部《俱舍论》立初禅五支、二禅四支、三禅五支、四禅四支；南传上座部对禅支的列举大体相近而对「内等净」的处理不同；关于「无寻唯伺」的中间定是否存在、何心可入初禅等，《大毗婆沙论》保留了激烈的多方辩难。原文档引文以「内等净故」释二禅，明确属于北传系统的解释框架。

第二，四禅定义句的语言史价值。同一条「离欲离诸恶不善法……」公式在汉译四阿含、巴利尼柯耶中反复出现，用词高度稳定，被学界视为佛教禅法最古老层的遗存之一；而「心一趣」等玄奘译语的时代明确，两段引文放在一起，恰好构成一条从契经到论书的语言演变线索。

第三，现代禅修研究与现象学界对禅支描述有持续兴趣：将寻、伺对应为注意力的引导与维持，将喜乐对应于禅定中的身体与情绪体验，四禅成为「细粒度的意识状态分层描述」的古代范例。但学界也提醒，禅支是规范性名相而非测量指标，直接映射到现代心理构念须谨慎。

## 四、术语对照表

| 梵/巴语 | 汉语 | 英译 |
|---|---|---|
| Jhāna | 禅那 | meditative absorption |
| Vitakka | 寻 | applied thought |
| Vicāra | 伺 | sustained thought |
| Pīti | 喜 | joy |
| Sukha | 乐 | happiness |
| Upekkhā | 舍 | equanimity |
| Ekaggatā | 心一境性 | one-pointedness |

表中 Jhāna 为巴利语形式，梵语作 Dhyāna，即汉译「禅」之语源；Upekkhā 对应梵语 Upekṣā。原文档即用「心一境性」对译 Ekaggatā，与玄奘译籍一致。
