# 大乘義章 — 学术解读

## 一、文献背景与成书

《大乘義章》为隋代净影寺慧远（523—592）所撰的佛教义学类书，是南北朝至隋唐之际中国佛教义学编纂的巅峰之作。慧远俗姓李，敦煌人，先学于慧光的弟子法上门下，后隐居长安净影寺讲经著述，其学兼通地论、摄论与涅槃学，被视为隋代北方义学的代表人物。

本书并非注疏一经，而是将大乘佛教的重要名相与义理分门别类，逐条解释。通行传本为二十卷（一说十四卷本），全书按「五聚」组织：教法聚、义法聚、染法聚、净法聚、杂法聚，共二百余科（旧说二百四十九科，今本有阙），今收于《大正藏》第四十四册。其成书年代难以确指，一般认为汇集慧远在长安讲学时期的义稿，晚年定形。

慧远身处地论学派与摄论学派交汇、判教学说竞起的年代。《大乘義章》正是在这样的思想土壤中，试图以一家义学统摄全体佛法的产物，其五时判教（华严、阿含、方等、般若、法华涅槃）之说，是研究南北方判教思想互动的重要标本。

## 二、文本结构与核心思想

《大乘義章》的结构以「聚」（类）统「科」（条目），每一科先立名义、次辨体性、再判浅深，形成一套层层推演的义学体例。其判摄框架中最具代表性的两点是：

其一，**五时判教**。慧远判如来一代时教为五时：佛初成道为诸菩萨说《华严》，为小乘说《阿含》，为中乘说方等，为大乘说般若，为上根说《法华》《涅槃》。这一判教「从浅至深，从权至实」，既继承了刘虬以来南方判教的传统，又以慧远自己的顿渐五味说加以整理，成为天台「五时八教」判教之前的重要中间环节。

其二，**二谛义**。本档案所录核心段落云：「一代时教，不出二谛——真谛明空，俗谛明有。二谛圆融，中道自显。」慧远的二谛义以「立名依情」「约诠辨」著称，主张二谛一体、以中道收摄空有，对后来三论宗吉藏的二谛论辩有直接的刺激作用——吉藏在《大乘玄论》中多次援引并破斥净影二谛说，可见其影响与争议并存。

此外，书中对佛性、涅槃、八识、六染等条目的疏解，保存了大量南北朝义学的原始论题，堪称当时佛教哲学的一部「问题史」。

## 三、学术研究价值与争议

研究价值方面：（1）《大乘义章》是研究南北朝晚期佛教义学最系统的文献，日本学者常称之为「南北朝佛教教理史之根本资料」；（2）慧远的地论学传承使本书成为探讨《十地经论》派思想向隋唐宗派佛教过渡的枢纽；（3）书中对净影独特的心识说（八识说中的顿悟渐修问题）的整理，为如来藏思想在汉地的展开提供了关键环节。

争议问题方面：（1）五时判教的归属：学界对慧远判教学说与《起信论》思想关联的讨论，与《大乘起信论》真伪之争交织在一起；（2）文本阙佚：今本杂法聚仅存数科，原书面貌需借敦煌写本与日本古抄本对勘复原；（3）慧远二谛义与吉藏二谛义孰为代表中国中观学正统，仍是中古佛教哲学研究的持续论题。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 五时（Pañca-kāla） | 依说法次第判分一代时教为华严、阿含、方等、般若、法华涅槃五期 |
| 二谛（Dve-satye） | 真谛明空、俗谛明有，二谛圆融显中道 |
| 判教 | 中国佛教对佛陀全部教说按深浅权实加以体系化分类的方法 |
| 净影慧远 | 隋代义学僧，居长安净影寺，本书作者，后世多称「净影」以别于庐山慧远 |
| 五聚 | 全书教法、义法、染法、净法、杂法五大类目的结构 |
| 中道（Madhyamā-pratipad） | 超越空有二边的究竟正理 |

- `00263_大乘起信論義記` — 法藏疏解《起信论》，其判教与心性论可上溯至净影一系的讨论框架
