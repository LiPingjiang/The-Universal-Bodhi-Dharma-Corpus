# 大乘起信論續疏 — 学术解读

## 一、文献背景与成书

《起信論續疏》二卷，明·通润（一雨通润，1565—1624）述，收于《卍續藏》第四十五册，经号 X0764（CBETA：X45n0764）。丁福保《佛學大辭典》著录作「起信論續疏二卷（明通潤述疏）」。所依底本为梁·真谛译《大乘起信論》一卷（T1666）。本档旧目录原为「待整理」占位状态，未载作者与版本信息，今据《卍續藏》与丁氏辞典补正。

通润字一雨，为明代吴中沙门，与雪浪洪恩同学于无极（巢松）门下，以贤首教义擅名，著《楞嚴經合轍》《維摩詰所說經直疏》等，是晚明华严教学复兴的中坚人物之一。「續疏」之名，通润自序末尾自作交代：「言續疏者，是續賢首之疏，以顯不外賢首，亦不盡賢首也」——所续者为贤首法藏之疏，既不越出法藏的规模，也不以法藏为限。其取材则主要来自永明延寿《宗鏡錄》中与本论互相发明的部分。书前另附〈大乘起信論主馬鳴菩薩略傳〉一篇，记马鸣受法于十一祖富那夜奢的问答公案（「汝欲識佛，不識者是」）。

## 二、文本结构与核心思想

此书在《起信論》注疏史上的特殊价值，在书前自序提出的「三宗」判释。其总纲曰：「大雄氏！現相人中，雖說無量法門，若統其歸趣，唯是一心。若滙其流派，則有三宗：曰法相，曰破相，曰法性而已。」——世尊一代说法，统摄归趣唯是一心，汇其流派则为三宗。

三宗大旨，自序逐一立论。法相宗：「謂依生滅八識，建五位，開百法，立三性，分二我。行必資於漸滿，惑必期乎漸斷，果必立乎三祇。……其于教也為漸。」——依生灭八识建立五位百法的体系，修行必渐、断惑必渐、成佛必历三祇，教相属「渐」。破相宗：「謂依寂滅一心，直顯真性，不說法相。……生心即妄，不生即佛。無六度可修，無無明可克，無菩提可證，其于教也無頓。」——依寂灭一心直显真性，遣尽法相，「起心即妄，不起即佛」，教相属「顿」。法性宗：「統依寂滅一心，而有六粗三細。故開真如門，以顯空諸所有；立生滅門，以明實諸所無。……即性即相，即空即有，即妄即真。其于教也，為頓悟漸修。」——统依一心而开二门，空有迭彰，教相属「顿悟渐修」。

继而对三宗各判其弊：「宗法相者，謂真如不變不許隨緣，但說萬法皆從識變，而事事俱有其獘也。流而為常，為執著宗。破相者，謂緣生之法不入法性，故說三界唯是一心，而法法皆空。其獘也，流而為斷，為莽蕩宗。」——法相偏于常见成「执著宗」，破相偏于断见成「莽蕩宗」；唯法性宗「真如不變隨緣，而能成一切法……隨緣不變，而能泯一切法」，故「空有迭彰，執蕩雙遣」。最终归宗于《起信論》：「馬鳴總以一心九識統之。若鼎之三足，伊之三點，不縱不橫，不離不即。」其成书取材之径亦在此段交代：「永明主此論而作宗鏡，故集宗鏡中互相發明者作續疏。」——延寿《宗鏡錄》既以本论为宗，遂採其中与本论互发之文，续法藏之疏。

## 三、学术研究价值与争议

就研究价值言，其一，判教史价值：「法相—破相—法性」三宗说是明代教家处理性相关系的成熟框架（其雏形可上溯宗密禅教判），通润此序结构严整、辨析清晰，是该框架最完整的文献表述之一，研究明代判教必及之。其二，方法史价值：以《宗鏡錄》注《起信論》的取材路径，是「以宋证梁、以宗镜证起信」的交叉注释典型，反映了晚明佛教学者对宋代宗门文献的再利用。其三，文献谱系价值：通润与憨山、智旭、真界诸家并世作疏，构成明代《起信論》注疏的高峰群像，本条为其中「教门正统派」的一翼。争议与限制：其一，「三宗」判释带有明显的判教本位——破相宗被判为有「莽蕩」之弊，中观学者未必服气，其评骘应作宗派立场语读；其二，「一心九識」之说源出《釋摩訶衍論》系统，而《釋摩訶衍論》的疑伪问题是学界公案，通润据此立论，其根据的可靠性连带存疑；其三，本疏正文既多取材《宗鏡錄》，其自撰与转引的边界，研读时须逐段与《宗鏡錄》核对；其四，通润生平资料有限，其师承与著述目录尚有若干不可考实之处。

## 四、术语对照表

| 术语 | 出处与释义 |
|---|---|
| 續疏 | 本书题名；续贤首法藏之疏而作 |
| 三宗 | 通润判释：法相宗、破相宗、法性宗 |
| 执著宗 | 通润指法相宗流弊所成，偏于常见 |
| 莽蕩宗 | 通润指破相宗流弊所成，偏于断见 |
| 頓悟漸修 | 通润判法性宗教相特征 |
| 一心九識 | 通润所述马鸣统摄三宗架构；九识说源出《釋摩訶衍論》系统 |
| 伊字三點 | 梵文「∴」形三点，喻不纵不横、不离不即 |
| 三細六麤 | 无明所起三种细相与六种粗相 |
| 五位百法 | 唯识法相分类体系 |
| 真如不變隨緣 | 法性宗教义核心：真如不变而随缘、随缘而不变 |
