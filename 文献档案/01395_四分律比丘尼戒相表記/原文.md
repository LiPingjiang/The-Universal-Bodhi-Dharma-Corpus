# 四分律比丘尼戒相表記 · 原文

## 一、文獻概述

《四分律比丘尼戒相表記》，近現代比丘尼律學著作，係仿弘一律師《四分律比丘戒相表記》之體例，專為比丘尼戒編修之表解類律典。其淵源與當代尼眾教育關係密切：弘一所表記者為比丘二百五十戒，而尼戒三百四十八條更為繁複，故後世律師循其「撮要列表」之法，為尼眾別編此記。此書以五台山尼眾教育一系為編修重鎮（中國佛學院五台山尼眾佛學院以之為戒學根本教材），當代比丘尼大德通願法師（1913–1991）畢生弘傳南山律儀、培養尼眾律學人才，與隆蓮法師同為恢復二部僧傳戒之發起者，此書之流通與此一系尼眾律學教育淵源甚深；因編修過程歷經眾手、印本多有內部流通本，編者題署諸本不一。今之通行整理本，為如瑞法師（中國佛學院五台山尼眾佛學院院長）主持編寫之《四分律比丘尼戒相表記教程》（社會科學文獻出版社2021年，全三冊），於原表記詳加注釋，多有創見（如對戒名之修正），每一戒均以多種資料相互印證，並附警策語。本書為民國以降之著述，未入歷代大藏經。

本書之義理根據，上承道宣《行事鈔》與靈芝元照《資持記》之南山正脈，是比丘尼學戒之總綱性教材。

## 二、核心段落選錄

> **原文**：據學習講記所述：「《四分律比丘尼戒相表記》是對比丘尼三百四十八條戒中的每一條戒，按照其戒名、制戒緣起、釋戒文、制意、具緣成犯、罪相、並制（附制）、境想、開緣等，都依據《四分律》摘錄戒相，使之清晰化。」（《學習〈四分律比丘尼戒相表記〉之感悟》，微信公眾號所刊學戒講記）
> **白話對照**：這部書做的工作是：把比丘尼三百四十八條戒，每一條都拆解成固定的分析項目——這條戒叫什麼名字、佛陀當初因為什麼因緣制定它、戒文的字面意思、制這條戒的用意、要具足哪些條件才構成犯戒、犯了之後罪相輕重如何、附帶制了哪些同類戒、對境認知正誤的「境想」判析、哪些情形開緣不犯——全部依《四分律》原文摘錄，列成表格，使每一戒的持犯軌則一目了然。

> **原文**：據同種講記所述：「許多警策文也引用了道宣律師的《行事鈔》與靈芝律師的《資持記》，對後學施以教誡。」
> **白話對照**：本書除了表格之外，還在各戒之間附有「警策語」——提醒學戒者持戒意義的短文。這些警策文大量引用唐代道宣律師《行事鈔》和宋代元照（灵芝）律師《資持記》的原文，可見本書的義理立場完全是南山律宗一脈：以道宣開宗、元照繼興的注疏體系為最高權威。

> **原文**：據《四分律比丘尼戒相表記教程》內容簡介：「本書為佛學原典類教材，旨在注釋《四分律比丘尼戒相表記》，在具體演繹過程中，並未囿於原作，多有鮮明觀點，如對戒名的修正就是一種創見。每一戒均有多種資料相互印證，且附有警策語。」（社會科學文獻出版社2021年版）
> **白話對照**：如瑞法師主編的《教程》不只是簡單地給原書作注：它在講解中並不盲從原表記，提出不少自己的見解——比如對某些戒條的名稱提出修正意見，這是一種學術創見。每一條戒都拿《四分律》廣律、各家注疏等多種資料來互相印證核對，避免孤證立說，並附警策語以策勵學者。

## 三、重要名句

> **名句一**：「戒為無上菩提本，應當一心持淨戒」——南山律學之根本依據（《華嚴經》語，為《行事鈔》所引），本書全部工作之立足點。

> **名句二**：「具緣成犯」——本書解戒之核心方法：一戒之成立，須條件具足；缺緣則罪相轉輕乃至不犯。

> **名句三**：「制戒緣起」——每戒皆有佛陀因事制戒之因緣；讀緣起即知佛制戒之本懷在護眾生、護僧團、護道業。

> **名句四**：「以戒為師」——佛陀臨終遺教，亦是通願、如瑞等當代尼眾大德弘律編書之總綱。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 戒相表記 | 以表格條列戒之綱要、持犯條件之編纂體裁 |
| 制戒緣起 | 佛因某一事件而制定某戒之因緣本事 |
| 制意 | 制定某戒之用意與深旨 |
| 具緣成犯 | 具足諸緣方構成犯戒之判析法 |
| 罪相 | 犯戒後罪名輕重之相狀 |
| 並制 | 附帶同制之同類戒條 |
| 境想 | 對所犯之境認知正誤之四句分別 |
| 開緣 | 依律不犯之例外情形 |
| 二部僧 | 比丘僧與比丘尼僧；尼眾受戒、治罪須二部僧中作法 |
