# 佛教四照用研究 — 学术解读

## 一、文献背景与成书

本条目为语料库「佛教专题研究」系列的主题类综述条目。据原文档，四照用是临济义玄禅师所立的接机设施之一，与四料简、四宾主并列，出《临济录》（T1985）。本条与 `05066_佛教四料簡研究`、`05067_佛教四賓主研究` 互见分工：料简重在所破之执（破什么），照用重在能破之方（怎么破），宾主重在师资之验（谁明谁暗），三套设施合观方见临济门庭之全貌；「料拣」之异写专条另见 `05069_佛教四料揀研究`。

「照」与「用」是本条目的核心范畴：「照」是寂照之照，谓师家先照破学人之境界、鉴其来势根器（就其所执之客观一面下手）；「用」是作用之用，谓师家继之以言句棒喝夺其人（就其主观我执一面下手）。照与用即「鉴机」与「施为」，四照用则是二者时序组合的四种格局，后世临济儿孙奉为棒喝体系之理论纲要，慈明楚圆、圆悟克勤之颂古皆涉及之。

## 二、文本结构与核心思想

四照用四句为：先照后用（「有人在」——我执犹存者，先照破其境，再以作用夺其我）；先用后照（「有法在」——法执犹存者，先夺其人，再照破其境）；照用同时（二执俱重者，照用一齐俱下，人境俱夺，《临济录》喻为「驱耕夫之牛，夺饥人之食，敲骨取髓，痛下针锥」）；照用不同时（二执俱轻、只须寻常接引者，照用有隔、应机分施，「有问有答，立宾立主，合水和泥，应机接物」）。

原文档特别指出四照用与四料简之结构相应：先照后用配夺境不夺人，先用后照配夺人不夺境，照用同时配人境俱夺，照用不同时配人境俱不夺。但二者视角不同：料简以学人二执为坐标，照用以师家手段之时序为坐标——一表一里，一静一动。又，三玄三要所谓「有权有实，有照有用」，权实照用四字将四套设施收摄为一总体结构：一切门庭设施皆是「权」边事，而设施所指向处是不涉安排之「实」；原文档引《临济录》「若是透脱得底人，一切境界不能拘系」，正是照用之极致——照用至此全成多事，设施本身亦须设施尽弃。

## 三、学术研究价值与争议

四照用的研究价值，首先是教学论层面的：它把「教学动作」分解为「诊断」与「干预」两个要素，并以时序组合穷尽其四种可能（先诊后治、先治后诊、同步、按部就班），在分析结构上与现代教学设计的诊断—干预模型相通，是晚唐禅门方法自觉的突出表达。其次，「驱耕夫之牛，夺饥人之食」之喻以其峻烈著称，为研究临济宗风（「临济将军」）之作风特质提供了最鲜明的语言标本。

争议方面有三。其一，文献学问题：四照用见《临济录》示众段，与四料简等设施同样存在语录编订层累之疑，其是否皆义玄当机之原说，学界未有定谳。其二，义理之争：照用与料简之「相应配对」系后世纲宗书之整理，诸家配释不全一致，有以「照」配人、「用」配境之异说，训释系统内部并不完全整齐，研究时宜以《临济录》原文语脉为主、纲宗整理为辅。其三，实践评价之争：「痛下针锥」式的峻烈手段在禅门内部即有分寸之辨——勘辨本为活人，若手段盖过目的，照用反成新的窠臼，故《临济录》同时保留「照用不同时」之平实一格，正见峻烈与平实互为节度。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 照 | 师家照破学人境界、鉴其根机之「寂照」 |
| 用 | 师家以言句棒喝作用学人之「机用」 |
| 先照后用 | 先破法执后夺我执，用于我执重者 |
| 先用后照 | 先夺我执后破法执，用于法执重者 |
| 照用同时 | 照用齐下、人境俱夺，二执俱重者用之 |
| 照用不同时 | 照用应机分施、宾主宛然，二执轻者用之 |
| 驱耕夫之牛／夺饥人之食 | 俱夺之譬：剥夺学人赖以立足之最后依恃 |
| 棒喝 | 临济宗接机之手段，「德山棒、临济喝」 |
