# 佛教四照用研究 · 原文

## 一、概念概述

四照用是臨濟義玄禪師所立的接機施設之一，與四料簡、四賓主並列（另二題互見：`05066_佛教四料簡研究`、`05067_佛教四賓主研究`），出於《臨濟錄》（T1985）。「照」是寂照之照，指師家先照破學人之境界（客觀、法執一面），即先「照」見其來勢根器；「用」是作用之用，指師家繼之以言句棒喝奪其人（主觀、我執一面）。四句為：一、先照後用——先照破其境、後以作用奪其我執（「有人在」，我執猶存者）；二、先用後照——先以作用奪其人、後照破其境（「有法在」，法執猶存者）；三、照用同時——照與用一齊俱下，人境俱奪，「驅耕夫之牛，奪饑人之食，敲骨取髓，痛下針錐」，用於我法二執俱重者；四、照用不同時——照用有隔、應機分施，「有問有答，立賓立主，合水和泥，應機接物」，用於二執俱輕、只須尋常接引者。四照用與四料簡結構相應（先照後用配奪境不奪人、先用後照配奪人不奪境、照用同時配人境俱奪、照用不同時配人境俱不奪），但料簡重「所破之執」，照用重「能破之方」——即師家接機時「照根器」與「用手段」的時序組合。此法後世為臨濟兒孫奉為「臨濟四喝」「棒喝」體系之理論綱要，慈明楚圓、圓悟克勤之頌古皆涉及之。

## 二、核心經文選錄

> **原文**（《鎮州臨濟慧照禪師語錄》，T1985）：
> 「示眾云：我有時先照後用，有時先用後照，有時照用同時，有時照用不同時。先照後用有人在；先用後照有法在；照用同時，驅耕夫之牛，奪饑人之食，敲骨取髓，痛下針錐；照用不同時，有問有答，立賓立主，合水和泥，應機接物。」

> **白話對照**：
    先照後用：先照破外境（法），再用作用奪人（我）——因為「有人在」，我執還在，故以用繼之。先用後照：先用作用奪人（我），再照破外境（法）——因為「有法在」，法執還在，故以照終之。照用同時：照用一齊施為，如奪走耕夫賴以為生的牛、奪走饑者口中之食、敲骨取髓——二執俱奪，令學人一無所有、徹底死卻偷心。照用不同時：照用次第應機，問答宛然、賓主歷然——接引執障俱輕者之尋常作略。

> **原文**（《臨濟錄》，T1985）：
> 「若是透脫得底人，一切境界不能拘繫。……你欲得識佛住處麼？只這言語是佛住處。」

> **白話對照**：
    四照用的終極目的非「破」而是「透」：透脫之人於一切境界自在無繫，師家之照用至此全成多事，故臨濟處處掃除學人對「照用」本身的執著——施設本身亦須施設盡棄。

## 三、重要名句

> 「先照後用，有人在；先用後照，有法在。」（四照用總綱）

> 「照用同時：驅耕夫之牛，奪饑人之食，敲骨取髓，痛下針錐。」（俱奪之烈）

> 「照用不同時：有問有答，立賓立主，合水和泥，應機接物。」（俱不奪之平實）

> 「照用同時，撥開向上竅；照用不同時，看取當時節。」（後世禪林對四照用時節因緣之頌）

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 照 | 師家照破學人境界、鑒其根機之「寂照」 |
| 用 | 師家以言句棒喝作用學人之「機用」 |
| 先照後用 | 先破法執（照）後奪我執（用），用於我執重者 |
| 先用後照 | 先奪我執（用）後破法執（照），用於法執重者 |
| 照用同時 | 照用齊下、人境俱奪，二執俱重者用之 |
| 照用不同時 | 照用應機分施、賓主宛然，二執輕者用之 |
| 驅耕夫之牛／奪饑人之食 | 俱奪之譬：剝奪學人賴以立足之最後依恃 |
| 棒喝 | 臨濟宗接機之手段，「德山棒、臨濟喝」 |
