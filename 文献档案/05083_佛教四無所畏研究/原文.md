# 佛教四無所畏研究 · 原文

## 一、概念概述

「四無所畏」（梵 catasraḥ vaiśāradyāḥ）指佛於大眾中說法，於四處自稱證得而坦然無懼、無人能難之四種功德。其名目為：一、一切智無所畏（正等覺無畏）——佛自稱「我是一切正智人」，於諸法盡知盡見；二、漏盡無所畏——佛自稱「我一切漏盡」，煩惱永斷；三、說障道無所畏（說障法無畏）——佛宣說染污之法能障聖道，無有怖畏；四、說盡苦道無所畏（說出道無畏）——佛宣說聖道能出世間、盡諸苦邊，無有怖畏。前三明佛自德圓極（智德、斷德），後二明佛說法決定（知障、知道）。經證出於《增一阿含經》（T125）卷十九〈四意斷品〉及巴利《增支部》之「四無畏經」；《大智度論》（T1509）卷廿五釋之最詳，《俱舍論》卷廿九以「四無畏即十力所攝」會通（正等覺無畏攝處非處等力）。「無所畏」與「師子吼」相應——佛於天人魔梵大眾中作決定說，如師子在群獸中無所怖畏，故名安住聖主處。依大乘經（《大品般若》《大智度論》卷五），菩薩亦有其四無所畏：能持無所畏、知根無所畏、決疑無所畏、答報無所畏，與佛四無畏相對，顯因行與果德之別。四無所畏與十力、大悲、三念處，為小乘十八不共法之異說；與大乘十八不共法同屬佛果功德系統，本檔案另有《四無畏研究》（05005、05082）專篇可互見，本篇側重「於大眾中自稱證得而無畏」之結構義。

## 二、核心經文選錄

> **原文**（《大智度論》卷廿五，T1509）：
> 「四無所畏者，佛作誠言：『我是一切正智人。』若有沙門、婆羅門，若天、若魔、若梵，若復餘眾，如實言『是法不知』，乃至不見是微畏相。以是故，我得安隱，得無所畏，安住聖主處，如牛王在大眾中師子吼，能轉梵輪。諸沙門、婆羅門若天、若魔、若梵若復餘眾，實不能轉——一無畏也。佛作誠言：『我一切漏盡。』……二無畏也。佛作誠言：『我說障法。』……三無畏也。佛作誠言：『我所說聖道，能出世間，隨是道能盡諸苦。』……四無畏也。」

> **白話對照**：
    佛於一切大眾前鄭重宣稱四事而心中無有絲毫怖畏：一、「我是一切智人」——若有人能指出我有任何所不知之法，則此言即倒；然而無人能如是指出。二、「我煩惱永盡」——無人能指佛仍有煩惱殘餘。三、「我說此法能障聖道」——無人能證明佛所斥之障法其實不障。四、「我說此道能出世間、盡生死苦」——無人能證此道不能盡苦。故佛安穩無畏，如牛王師子，於大眾中轉正法輪，一切外道天魔不能阻撓。

> **原文**（《妙法蓮華經·方便品》，T262）：
> 「如來知見，廣大深遠，無量無礙，力無所畏，禪定解脫三昧，深入無際，成就一切未曾有法。」

> **白話對照**：
    「力」指十力，「無所畏」即四無所畏——如來知見之廣大深遠，即以力與無畏為其表徵：於自證（一切智、漏盡）與說法（知障、知道）兩面俱決定無疑，故能於三界一切眾會中作師子吼而無所怖畏。

## 三、重要名句

> 「安住聖主處，如牛王在大眾中師子吼，能轉梵輪。」（《大智度論》卷廿五）

> 「四無所畏，即十力所攝：正等覺無畏攝處非處等力，漏盡無畏攝漏盡智力。」（《俱舍論》卷廿九會通之義）

> 「力無所畏，禪定解脫三昧，深入無際，成就一切未曾有法。」（《法華經·方便品》）

> 「由佛十力之智，內充明了決定故，於大眾中凡有所說，則無恐懼之相。」（《三藏法數》釋名）

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 四無所畏 | 佛於大眾中自稱四種證德而無怖畏 |
| 一切智無所畏 | 自稱正遍知一切法而無畏 |
| 漏盡無所畏 | 自稱煩惱永盡而無畏 |
| 說障道無所畏 | 決定宣說諸障法能障聖道 |
| 說盡苦道無所畏 | 決定宣說聖道能盡生死苦 |
| 師子吼 | 佛於眾中作決定說之喻 |
| 微畏相 | 可怖畏之因緣相；佛乃至不見其微相 |
| 菩薩四無畏 | 能持、知根、決疑、答報四種說法無畏 |
