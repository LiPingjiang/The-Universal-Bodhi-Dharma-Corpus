# 薩婆多毗尼毗婆沙疏·原文

## 一、概述

萨婆多毗尼毗婆沙疏，指对《萨婆多毗尼毗婆沙》之疏释。萨婆多毗尼毗婆沙收录于大正藏第1440号，凡九卷，失译人名，附秦录。萨婆多部即说一切有部（Sarvāstivāda），"毗尼"意为律，"毗婆沙"意为广解、胜说。此论为说一切有部对律藏之详细注释，属汉传律学"四律五论"中"五论"之一。论中开篇以"总序戒法异名等"为题，系统阐释佛陀说法之方式、律藏之编纂因缘、戒法之异名等基础概念，进而对十诵律之戒条与犍度品进行注释。该论以问答体为主，层层辨析，为研究说一切有部律学之重要文献。

## 二、核心段落

### 段落一：佛陀说法与三藏编纂

**原文：**

> 佛陀者，秦言觉。觉了一切法相故。复次一切众生长眠三界，佛道眼既开自觉觉彼，故名为觉。佛于一切法，能一切知能得一切说。问曰：佛云何一切说？为应时适会随宜说耶？为部党相从而说法耶？答曰：佛随物适时说一切法，后诸集法藏弟子以类撰之。佛或时为诸弟子制戒轻重有残无残，撰为律藏。或时说因果相生诸结诸使及以业相，集为阿毗昙藏。为诸天世人随时说法，集为增一。

**白话翻译：**

"佛陀"，秦言（汉语）译为"觉"。因为觉了一切法相之故。其次，一切众生在长眠于三界之中，佛之道眼既开，自己觉悟又能觉悟他人，所以名为"觉"。佛对于一切法，能一切知、能得一切说。问：佛是怎样说法的呢？是应时适会随宜而说的呢，还是按部类相从而说的呢？答：佛随众生之时机适当地宣说一切法，后来结集法藏的弟子们按类别编纂。佛有时为诸弟子制定戒律，有轻有重，有残（僧残）无残（波罗夷），编纂为律藏。有时说因果相生、诸结诸使以及业相，集为阿毗昙藏（论藏）。为诸天世人随时说法，集为增一阿含。

### 段落二：佛智与说法之辩

**原文：**

> 问曰：佛若一切说者，有经云：佛坐一树下捉一枝叶，问弟子曰：此枝叶多树上叶多？白佛言：树上叶多。佛言：我所知法如树上叶，我所说法如手中叶。云何言佛一切说耶？答曰：有别相一切总相一切。今言别相一切。有言：佛能一切说，但众生不能一切尽受。佛非不能说。有言：应云一切知，直云说也。不得言一切说。

**白话翻译：**

问：如果佛是一切都说的话，有的经中说：佛坐在一棵树下，手里拿着一片枝叶，问弟子说：这手中的枝叶多，还是树上的叶子多？弟子答佛说：树上的叶子多。佛说：我所知道的法如同树上的叶子，我所说的法如同手中的叶子。既然如此，怎么能说佛一切都说呢？答：有"别相一切"和"总相一切"之不同。现在说的是"别相一切"。有人说：佛能说一切法，只是众生不能完全承受接受，并非佛不能说。有人说：应该说"佛一切知"，不能直接说"佛一切说"。

## 三、名句

1. "佛随物适时说一切法，后诸集法藏弟子以类撰之。"——概括佛陀说法之随机性与三藏编纂之分类性，为律藏成立之理论基础。

2. "我所知法如树上叶，我所说法如手中叶。"——佛所知之法无量无边，所说之法仅如手中之叶，说明佛法浩瀚而众生所闻有限。

## 四、术语表

| 术语 | 释义 |
|------|------|
| 萨婆多 | 梵文Sarvāstivāda，意译说一切有部，主张三世实有 |
| 毗尼毗婆沙 | 对律藏之广解注释，毗尼为律，毗婆沙为广解 |
| 有残无残 | 戒罪之轻重分类，有残为僧残，无残为波罗夷 |
| 阿毗昙藏 | 即论藏，梵文Abhidharma-piṭaka，三藏之一 |
| 增一 | 即增一阿含经，按数字递增编排之佛经 |
| 别相一切 | 就各别事相而言之"一切"，非总体之"一切" |
| 四律五论 | 汉传律学之基本文献体系 |
| 毗婆沙师 | 说一切有部之论师，以毗婆沙论为根本者 |
