# 佛教四禅定研究_18 — 学术解读

## 一、文献背景与成书

本条目是语料库中的综述性研究条目，不是一部古籍。原文档由一句概述（「初禪離生喜樂地、二禪定生喜樂地、三禪離喜妙樂地、四禪捨念清淨地」）、两则引文与一张术语表构成，属名目式编目。同库另有一条同名「佛教四禪定研究_18」（编号 18473），两条名目相同而各自独立；依分工原则，本条以禅支分析与四禅的标准公式为纲，彼条以禅定思想史的南北比较为纲，两相对读。以下以原文档名目为准撰述。

四禅（catvāra-dhyānāni）是佛教定学的核心结构，其经典公式即本条核心引文：「離欲離諸惡不善法，有尋有伺，離生喜樂，入初禪具足住。」此公式与巴利经藏逐句对应（vivicceva kāmehi…savitakkaṃ savicāraṃ vivekajaṃ pītisukhaṃ paṭhamaṃ jhānaṃ upasampajja viharati），是南北传承完全一致的少数核心教法之一。原文概述所用「離生喜樂地、定生喜樂地、離喜妙樂地、捨念清淨地」四地之名，则出自《俱舍論》等阿毗达磨系统的安立——前引经文公式、后列论书地名，本条目兼存经论两个层位。四禅在修行地图上居枢纽位置：八解脱以四禅为基、四无量心于四禅中修、沙门果证依四禅发慧，故《清净道论》称之为「纯熟的心地」。

## 二、文本结构与核心思想

原文档所示义理可综述为三重。

其一，禅支的增减结构。四禅由五禅支的增减定义：初禅具寻（vitakka，觉知引导）、伺（vicāra，持续觉知）、喜（pīti）、乐（sukha）、心一境性（ekaggatā）五支；二禅舍寻伺，加内等净，余定生喜乐；三禅舍喜支，余妙乐与念、慧、舍；四禅并喜乐俱舍，唯念清净与舍（upekkhā）——「捨念清淨」之名即由此出。四禅不是四种不同的定，而是同一颗心层层提纯的四个纯度等级。

其二，引文两句的对照义。核心引文举初禅（「有尋有伺」），白话对照举二禅（「尋伺息故……無尋無伺，定生喜樂」）——两句合观，恰显示禅支的增减轴：初禅之有寻有伺，正是二禅之所舍。这一对照保留了四禅「以舍为进路」的纲要：每一禅的升进，都以舍离前一禅的支分为标志。

其三，「具足住」的安住义。引文每句以「具足住」收束——入定不是一闪而过的体验，而是能够随意安住、出入自在的稳定能力；定学的目标不是瞥见境界，而是心的可使用性。

## 三、学术研究价值与争议

本条目的价值在于兼存经文公式与论书地名两个层位，可作四禅研究的一手纲要。学术争议有三：一是四禅的外道渊源——佛陀成道前从阿罗逻迦蓝学无所有处定、从郁陀迦罗摩子学非想非非想处定，四禅八定的后四层袭自当时禅定传统，佛教的独特贡献是重估四禅为发慧之基（「依四禅发无漏慧」），学界于此有「佛教改造婆罗门禅定学」的定说而细节持续讨论；二是禅支的心理学解释——喜与乐的区分（喜为身心的激动踊跃，乐为沉浸的受用）、寻伺的性质（概念性引导还是注意力的粗细），现代禅修研究与南传注释传统的对读近年活跃；三是「四禅是否经验可证」——当代神经科学对禅定脑电、专注状态的研究，与经典四禅描述的对应关系仍是开放课题，既有谨慎的对应也有彻底的存疑。
