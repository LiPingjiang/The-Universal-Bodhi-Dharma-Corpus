# 往生論 — 学术解读

## 一、文献背景与成书

《往生论》全称《无量寿经优婆提舍愿生偈》，又称《净土论》《愿生偈》，传统归于印度瑜伽行派论师世亲（婆薮盘豆，约四至五世纪）造，北魏菩提流支于永平年间译出，一卷，收录于《大正藏》第二十六册，编号 T1524。现存汉译本由二十四颂及长行释文构成，是印度撰述中唯一被东亚净土宗奉为根本论典的著作；藏译大藏经未保存完全对应的文本，其原梵本亦已佚失。

本论在中国的传播主要通过昙鸾（476–542）《无量寿经优婆提舍愿生偈注》（《往生论注》，T1819）。昙鸾以龙树“难行道、易行道”解释本论，提出“他力增上缘”“往相回向、还相回向”，奠定中国净土宗教理基础。此后道绰、善导承其流，传入日本后更为法然、亲鸾所重。与《无量寿经》《观无量寿佛经》《阿弥陀经》合称“净土三经一论”，成为弥陀净土信仰的核心典籍群。

## 二、文本结构与核心思想

全论分偈颂与长行两部分。偈颂以“世尊我一心，归命尽十方，无碍光如来，愿生安乐国”开篇，依次赞叹极乐国土、阿弥陀佛与诸菩萨三类共二十九种庄严：国土十七种庄严、佛八种庄严、菩萨四种庄严。结尾“普共诸众生，往生安乐国”，显示愿心并非个人求生，而是普遍回向。

长行释文则以“五念门”统摄修行：一礼拜门，身业礼拜阿弥陀佛；二赞叹门，口业称佛名号、如实修行；三作愿门，心常作愿，一心专念；四观察门，以智慧正念观察二十九种庄严；五回向门，不舍一切苦恼众生，将功德回向愿生。五门成就后相应五种功德门：近门、大会众门、宅门、屋门、园林游戏地门。前四是“入功德”，令行者入净土自利；最后是“出功德”，行者从净土回入生死园林，以神通教化众生，显示往生的终点仍是菩萨利他行。

本论更以“一法句”收摄所有庄严：“一法句者，谓清净句；清净句者，谓真实智慧无为法身。”二十九种可见庄严皆是法身清净的显现。这使净土不只是具象乐园，而成为佛智与无为法身的境界，也让本论与瑜伽行派净土观、如来藏思想之间建立了诠释空间。

## 三、学术研究价值与争议

研究价值方面，本论是连接印度大乘论学与东亚净土信仰的枢纽。它将经典中较散的往生叙述整理为五门行法，将净土景观系统化为二十九种庄严，再以一法句会归实相，体现印度论师的高度组织能力。昙鸾对本论的阐释又把中国式“他力本愿”理论发展成熟，其后日本净土真宗的往相、还相二回向均由此而来。

争议问题主要有三。第一，作者归属：传统认定为世亲，但因梵藏本阙如、汉译传承单一，现代学者曾从术语与思想风格质疑其是否为瑜伽行派世亲亲撰；现有证据不足以推翻传统归属，通常仍称“世亲造”。第二，文本是否分为“偈颂本论”与“长行后释”两个层次，有学者从文体差异提出编纂说，但无定论。第三，“一法句”到底应依唯识清净识、法身实相还是如来藏理解，昙鸾、善导与现代佛教学者各有侧重。第四，五念门中的“赞叹门”究竟指广赞佛德还是专称名号，也影响后世对称名念佛地位的不同判释。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 优婆提舍 | 梵语 upadeśa，指依经论义、解释佛说的论书 |
| 五念门 | 礼拜、赞叹、作愿、观察、回向五种净土行法 |
| 二十九种庄严 | 国土十七、佛八、菩萨四种功德庄严 |
| 一法句 | 清净句，即真实智慧无为法身，统摄一切庄严 |
| 入出功德 | 前四门入净土自利，园林游戏地门出而度生 |
| 往相、还相 | 往生净土与由净土回入生死度众生的二种回向 |
