# 辯經邏輯與西方邏輯比較——學術解讀

## 一、東西方邏輯比較的方法論問題

### 1.1 比較研究的前提反思

將藏傳因明與西方邏輯進行比較研究時，首先面臨的是方法論問題：兩者是否具有可比性？比較的框架本身是否帶有某種文化偏見？

Matilal（1998:1-15）在其《印度邏輯的特質》中指出，早期西方學者傾向以西方形式邏輯為標準來「評判」印度和藏傳邏輯——這種做法隱含了「西方邏輯是邏輯學的標準形態」的預設。Matilal 主張採取「多元邏輯觀」（pluralistic view of logic），將不同文化傳統中的邏輯實踐視為對「合理推理」這一普遍人類活動的不同回應，而非某個傳統的不完整版本。

Ganeri（2001:1-25）進一步提出了「哲學互動」（philosophical engagement）的方法論：不是簡單地列舉兩個傳統之間的異同，而是讓兩個傳統在特定哲學問題上展開真正的對話——比如，藏傳因明的「不遍」概念能否為當代非形式邏輯提供新的理論資源？

### 1.2 「不可比性」論題

一些學者（如 Siderits 2003, *Personal Identity and Buddhist Philosophy*）提出了更為根本的質疑：藏傳因明的概念框架與西方邏輯的概念框架之間可能存在「不可通約性」（incommensurability）。例如：

- 西方邏輯的核心概念是「命題」（proposition）——一個有確定真值的語句。藏傳因明的核心概念是「量」（tshad ma）——一個可靠的認知事件。兩者的分析對象根本不同：一個分析的是語句的真假，一個分析的是認知的可靠性。
- 西方邏輯追求語境無關的形式有效性（formal validity），藏傳因明的有效性繫於特定的承許體系（'dod pa'i lugs）。

Garfield（2002:30-45）對此回應：承認差異的存在不意味著比較是不可能的。關鍵在於找到雙方共同關心的問題——如「什麼是好的推理？」「如何檢測論證中的錯誤？」——然後比較兩個傳統對這些問題的不同回答。

## 二、藏傳因明是否為「邏輯學」？

### 2.1 爭議的核心

「藏傳因明是否算邏輯學（logic）」是比較研究中長期爭論的問題。

**狹義觀**：如果將「邏輯學」定義為「研究形式有效推理的學科」（如弗雷格-羅素傳統），那麼藏傳因明**不是**邏輯學。因為：
- 藏傳因明的有效性不僅取決於推理的形式結構，還取決於認知語境
- 藏傳因明沒有發展出抽象的形式符號系統
- 藏傳因明的核心概念（量、現量、比量）是認識論概念，而非純邏輯概念

**廣義觀**：如果將「邏輯學」定義為「研究合理推理的規範性學科」（如圖爾敏、沃爾頓 Walton 等非形式邏輯傳統），那麼藏傳因明**是**邏輯學——而且是一種高度發達的邏輯學。因為：
- 藏傳因明發展出了嚴密的推理有效性判定標準（因三相）
- 藏傳因明對推理謬誤（似因 hetvābhāsa）有系統的分類
- 辯經實踐本身構成了一種精密的「論證評估」活動

### 2.2 Tillemans 的立場

Tillemans（1999:1-10）採取了務實的中間立場：藏傳因明既是認識論，也是邏輯學，但它所理解的「邏輯」與弗雷格-羅素傳統不同。他提出了「認識論邏輯」（epistemological logic）的概念來描述藏傳因明的學科性質——它是一種將認識論關切（什麼認知是可靠的？）與邏輯關切（什麼推理是有效的？）融為一體的理論體系。

### 2.3 Dreyfus 的實踐主義視角

Dreyfus（2003:211-230）從實踐的角度重新界定了這個問題。他認為，問「藏傳因明是不是邏輯學」是一個錯誤的問題（a wrong question）。更有意義的問題是：「辯經作為一種知識實踐（epistemic practice），它實現了什麼？」Dreyfus 的回答是：辯經實現了**批判性思維的系統訓練**——這正是西方邏輯教育所追求但往往未能充分實現的目標。

## 三、形式化重建的嘗試與局限

### 3.1 命題邏輯重建

多位學者嘗試用現代命題邏輯（propositional logic）重建藏傳因明的推理結構。

應成論式的命題邏輯重建：

```
令 p = 對方的主張
令 q = 從 p 推出的結論（對方不接受）

應成論式：p → q, ¬q ⊢ ¬p  （modus tollens）
```

自續論式的命題邏輯重建：

```
令 p = 因（理由）成立
令 q = 宗（結論）成立
令 p → q = 遍（因果涵蓋關係）

自續論式：p, p → q ⊢ q  （modus ponens）
```

### 3.2 謂詞邏輯重建

因三相的謂詞邏輯重建（以 Tillemans 1999:28-35 為基礎）：

```
宗法性：Ha（因 H 在有法 a 上成立）
同品遍有：∀x(Hx → Sx)（凡具因者皆具所立法 S）
異品遍無：∀x(¬Sx → ¬Hx)（凡不具所立法者皆不具因）

有效推理：Ha, ∀x(Hx → Sx) ⊢ Sa
```

### 3.3 形式化的局限

Tillemans（1999:35-40）和 Garfield（2002:50-55）都指出了完全形式化的根本性困難：

**語境依賴問題**：應成論式的有效性取決於「對方的承許體系」，而承許體系不是一個可以形式化指定的固定集合——它是動態的、隱含的、有時甚至是模糊的。現代形式邏輯沒有處理這種語境依賴的標準工具。

**開放紋理問題（open texture）**：藏傳因明中許多概念的定義具有魏斯曼（Waismann）所說的「開放紋理」——它們不能被完全精確地形式化，因為總存在邊界情況需要判斷。辯經的價值恰恰在於探索這些邊界情況。

**語用維度**：辯經中的「同意」、「因不成」、「不遍」不僅是邏輯操作，也是語用行為（speech acts）——它們在特定的社會語境中具有承諾和責任的含義。純形式化無法捕捉這些語用維度。

**多模態推理**：辯經中同時涉及演繹推理（由遍推出結論）、歸納推理（由實例判斷遍關係）和語用推理（判斷對方的策略意圖），這種多模態推理難以用單一的形式系統來刻畫。

## 四、與印度 Nyāya 邏輯的比較

### 4.1 Nyāya 邏輯的特點

印度正理學派（Nyāya）的邏輯體系是藏傳因明的重要歷史源頭之一（通過陳那和法稱對正理學派的批判性吸收）。Nyāya 邏輯的核心特徵包括：

- **五支論式**（pañcāvayava）：宗、因、喻、合、結——比藏傳三支論式更為冗長
- **喻的重要性**：Nyāya 邏輯要求通過具體實例（喻）來支持遍的關係，如「凡有煙處有火，如灶」
- **實在論立場**：Nyāya 承認外境實有，與佛教唯識和中觀立場不同

### 4.2 佛教因明對 Nyāya 的改造

陳那和法稱對 Nyāya 五支論式進行了根本性改造（Matilal 1998:30-50）：

- **刪除「喻」**：佛教因明認為喻是冗餘的——如果遍已經被確立，就不需要另舉實例
- **重新定義「因」**：從 Nyāya 的「原因」概念轉變為「認知標記」（liṅga）概念
- **引入「似因」分析**：系統地分類和排除無效的推理，這在 Nyāya 中不夠精密

藏傳辯經繼承了法稱的改造，但又加入了自己的創新——特別是應成論式的系統化和四句回答的程式化。

### 4.3 三者比較

| 特徵 | Nyāya 邏輯 | 佛教因明（法稱） | 藏傳辯經實踐 |
|------|-----------|---------------|------------|
| 論式結構 | 五支 | 三支 | 應成（歸謬）為主 |
| 喻的角色 | 必要 | 不要 | 不要 |
| 形而上學 | 實在論 | 唯識/中觀 | 中觀應成派為主 |
| 對話性 | 有辯論傳統 | 主要是書面論述 | 高度口頭化、對話化 |
| 教學功能 | 學術工具 | 認識論建構 | 教學方法 + 考核制度 |

## 五、辯經邏輯對當代哲學的啟示

### 5.1 對論證理論的貢獻

藏傳辯經實踐為當代論證理論（argumentation theory）提供了豐富的案例和概念資源：

**「不遍」概念**：辯經中「不遍」的精確操作為非形式邏輯中的「相關性」（relevance）問題提供了新視角。在西方非形式邏輯中，「前提與結論相關嗎？」是一個難以操作化的問題。辯經的「不遍」回答提供了一種具體的操作方式——通過指出前提外延中不屬於結論外延的情況來否認相關性。

**承許體系的概念**：辯經中「對方承許」的概念預示了當代「非單調推理」（non-monotonic reasoning）和「信念修正」（belief revision）理論中的類似觀念——推理的有效性取決於背景假設的集合，而這個集合是可以修改的。

### 5.2 對認識論的貢獻

Dreyfus（1997, *Recognizing Reality*）和 Garfield（2002）都強調了法稱-藏傳因明傳統在認識論上的獨特貢獻：

- **認知作為事件**：法稱將「量」定義為一種認知事件（rig pa），而非命題的屬性。這與當代「德性認識論」（virtue epistemology）中將知識視為認知者的成就（而非命題的屬性）有驚人的相似性。
- **可靠性取向**：法稱的「不欺誑」（mi slu ba / avisamvādin）標準與當代可靠論（reliabilism）——以認知過程的可靠性來定義知識——有結構性的對應。

### 5.3 對教育學的啟示

Cabezón（1994:60-68）特別強調了辯經作為教育方法對當代批判性思維教育的啟示：

- **即時性反饋**：辯經提供了書面考試無法比擬的即時反饋——錯誤在被犯下的瞬間就被暴露
- **主動學習**：辯經要求學生主動運用知識，而非被動記憶
- **元認知訓練**：辯經迫使學僧不僅思考問題的答案，還思考「我為什麼這樣回答」「對方可能怎麼攻擊我的回答」——這是元認知（metacognition）的訓練

## 六、批判性視角

### 6.1 比較的限度

任何跨文化邏輯比較都需要警惕的陷阱包括：

- **選擇性比較**：只挑選兩個傳統中相似的部分進行比較，忽略不相似的部分，從而製造虛假的「普遍性」（Siderits 2003）
- **術語對等假設**：將「tshad ma」翻譯為「valid cognition」並與西方認識論中的「knowledge」等同，可能遮蔽兩個概念之間的深層差異（Dreyfus 1997:30-35）
- **進步敘事**：暗示藏傳因明是「走向形式邏輯的未完成旅程」——這種敘事預設了形式邏輯是邏輯學的終極形態（Matilal 1998:5-10）

### 6.2 開放的問題

當前藏傳因明與西方邏輯的比較研究仍有許多開放問題：

- 辯經中的策略性選擇能否用博弈論形式化？
- 「遍」的概念是否等同於物質條件句（material conditional）？還是更接近嚴格條件句（strict conditional）或相關蘊涵（relevant implication）？
- 藏傳辯經的「四句回答」是否構成了一個完備的對話邏輯系統？
- 應成論式與次協調邏輯（paraconsistent logic）之間是否存在有意義的聯繫？

這些問題的探索將繼續推動東西方邏輯傳統之間的深入對話。
