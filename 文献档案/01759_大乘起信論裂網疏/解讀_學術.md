# 大乘起信论裂网疏 — 学术解读

## 一、文献背景与成书

《大乘起信論裂網疏》，六卷，明代蕅益智旭（1599–1655）述，收于《大正藏》第四十四册，经号 T1850。据原文档案所录自序，此疏的文献特点极为突出：它注解的是唐代实叉难陀的新译二卷本《大乘起信論》（T1667），而非通行的梁代真谛旧译一卷本（T1666）。智旭将两译对阅后认为唐本「文顯義順」，但因旧来流通的是梁本，不敢自专，遂于佛前拈阄决定，「拈得宜解唐本」，遂依唐本作疏。下笔时间在自序末自记为「癸巳十月十有八日」，即清顺治十年（1653），已是智旭晚年。

「裂网」之名，取撕裂知见之网之义。所裂者，是当时教界把法相宗（唯识）与法性宗（般若、起信）判为高下差别的成见之网。智旭以天台藏、通、别、圆四教中的圆教配《起信论》的「一心」——即众生现前介尔之心，主张性相二宗体用不二。这一动机在他的其他著述（如《閱藏知津》的判教）中一以贯之。

## 二、文本结构与核心思想

此疏依《起信论》新译本文随文作解，其诠释特色可从原文档案所录四个核心段落看出。

第一，破判教之网。自序中智旭指出：马鸣、龙树、世亲「並屬金口授記，傳佛心宗，其所著述，決定不當互相乖異」，批评后世讲师妄判世亲唯识为「立相始教」、龙树中观为「破相始教」、马鸣起信为「終教兼頓，並未是圓」。这一段是全疏的宗旨所在：三位论师同传佛心，立说角度不同，不应当作高下之分。

第二，真如与一切法不一不异。智旭以双向破执解读《起信》与《唯识》的差异：若执定一，则真如不生灭应令一切法也不生灭，讲不通；若执定异，则真如应在一切法外别有方隅，不常不遍，更讲不通。由此他提出著名的调和：起信说「真如受熏」，如触波之时即触于水，是破定异之执，「初未嘗言真如隨熏轉變也」；唯识说「真如不受熏」，如波动之时湿性不动，是破定一之执，「初未嘗言別有凝然真如也」。两家各破一边，并非对立。

第三，一心二门的定义。卷二释「显示实义」时，智旭以天台「介尔一念」诠释「一心」：「一心，即指眾生現前介爾心也」。二种门不是前后左右分开的两样东西，「隨緣不變，即此生滅心名真如門；不變隨緣，即此真如心名生滅門」，约迷悟而明二门。这是把如来藏本体论拉回当下一念的观心实践，是天台立场对《起信论》的重构。

第四，一心三宝。卷六释「信根本」，智旭以真如体大配法宝（心性离虚妄相，平等平等）、相大配佛宝（觅之了不可得而性自神解，灵明不昧）、用大配僧宝（一切色心依正、十方虚空并是介尔心中所现之影），将三大的教理结构转成三宝的信仰结构，收束全疏。

## 三、学术研究价值与争议

此疏的价值有三。其一，它是《起信论》注释史上少数依实叉难陀新译本作疏的著作，为研究新旧两译的差异接受史提供了关键样本。其二，它是明末佛教整合运动的代表文献：智旭身兼天台与唯识之学，力图消解延宕数百年的性相宗派之争，「裂网」的命名本身就是一份思想史宣言。其三，水波之喻的双向解读，是《起信论》真如无明关系问题在汉传传统内部最精巧的调和方案之一，至今仍是比较哲学讨论的常用材料。

争议方面：其一，学界对实叉难陀新译本的真实性本身存疑，有学者认为唐本或是对真谛本的改订重治，则依之作疏的文献基础需要重估；其二，智旭的调和是否成立，唯识学者多有保留——「真如受熏」与「凝然真如」之辨，在近现代唯识与如来藏论诤（内学院系对《起信论》的真伪判罚）中屡被重提，智旭此疏常被引为性宗一方的辩护资源；其三，以天台教相配释《起信》的做法，在诠释上究竟是会通还是格义，研究者评价不一。原文档案还著录观国《大乘起信論裂網疏講錄》六卷，可见此疏在后世有讲习传承。

## 四、术语对照表

| 术语 | 出典与释义 |
|------|-----------|
| 裂网 | 本疏题名，撕裂法相／法性二宗高下之见的知见网 |
| 介尔心 | 天台语，指当下一念微细心；智旭用以诠释「一心」 |
| 随缘不变／不变随缘 | 真如二义，智旭以此对配真如门与生灭门 |
| 不变随缘 | 真如体虽不变而随缘现起，即真如门说 |
| 定一／定异 | 决定同一与决定相异两种边执，起信破后、唯识破前 |
| 凝然真如 | 被归于唯识家的不动真如；智旭指出《成唯识論》原无此说 |
| 一心三宝 | 智旭以体大配法宝、相大配佛宝、用大配僧宝 |
| 六即 | 天台位次（理即至究竟即），智旭以之配判起信觉位 |
| 新译本／旧译本 | 实叉难陀二卷本（T1667）与真谛一卷本（T1666） |
