# 大乘起信論裂網疏 · 原文

## 一、概述

《大乘起信論裂網疏》，六卷，明·蕅益智旭（1599–1655）述，收於《大正藏》第四十四冊，經號 **T1850**（CBETA：T44n1850）。

此疏最大的文獻特點是：**它註解的是唐·實叉難陀的新譯本（二卷本），而非通行的梁·真諦舊譯本**。智旭在自序中說明，兩譯對閱後他認為唐本「文顯義順」，但因舊來流通梁本，不敢自專，遂於佛前拈鬮決之，「拈得宜解唐本」。撰作起始時間，序末自記為「癸巳十月十有八日下筆」（清順治十年，1653）。

「裂網」之名，取撕裂知見之網之義——所裂者，即當時教界把法相宗（唯識）與法性宗（般若、起信）判為高下差別的成見之網。智旭以天台藏、通、別、圓四教中的圓教配「一心」即眾生現前介爾之心，主張性相二宗體用不二。

## 二、核心段落（原文與白話對照）

### 段落一：破判教之網——馬鳴、龍樹、天親不當互異

**原文**（卷第一，自序）：

> 至於馬鳴龍樹。並屬金口授記。傳佛心宗。其所著述。決定不當互相乖異。乃後世講師。輒妄判曰。天親識論。是立相始教。龍樹中論。是破相始教。馬鳴起信。是終教兼頓。並未是圓。嗚呼。其亦不思甚矣。

**白話對照**：至於馬鳴與龍樹，都屬佛親口授記、傳承佛之心宗的人物，他們所寫的著作，決定不應當彼此矛盾違背。可是後世的講經法師，動輒隨意判定說：世親的唯識論是「立相始教」，龍樹的中論是「破相始教」，馬鳴的起信論是「終教兼頓教」，三者都還不算圓教。唉！這也太不加思索了。

### 段落二：真如與一切法「不一不異」——水波之喻的雙向破執

**原文**（卷第一，自序）：

> 蓋若言定一。則真如不生滅。應一切法亦不生滅。或一切法生滅。應真如亦生滅。固為不可。若言定異。則真如非即一切法之實性。應在一切法外。別有方隅。不常不遍。尤為不可。故起信謂真如受熏者。譬如觸波之時。即觸於水。所以破定異之執。初未嘗言真如隨熏轉變也。唯識謂真如不受熏者。譬如波動之時。濕性不動。所以破定一之執。初未嘗言別有凝然真如也。

**白話對照**：如果說真如與一切法決定是同一個，那麼真如既然不生不滅，一切法也應該不生不滅；或者反過來，一切法既然生滅，真如也應該生滅——這當然講不通。如果說二者決定是相異的，那麼真如就不是一切法的真實體性，應該在一切法之外另有一塊地盤，那它就既不恆常也不周遍——這更講不通。所以《起信論》說真如受熏，好比手觸到波浪時也就同時觸到了水，這是用來破「決定相異」的執著，並不是說真如會隨著熏習而轉變。而唯識學說真如不受熏，好比波浪在動的時候，水的濕性並不動，這是用來破「決定同一」的執著，並不是說另外存在一個凝然不動的真如。

### 段落三：一心二門的定義——現前介爾一念

**原文**（卷第二，釋「顯示實義」）：

> 一心。即指眾生現前介爾心也。言二種門者。非是前後左右名為二也。秖是隨緣不變。即此生滅心名真如門。不變隨緣。即此真如心名生滅門。……但迷之則生死始。則真如舉體而為生滅。悟之則輪迴息。則生滅當體便是真如。故約迷悟而明二種門也。

**白話對照**：所謂「一心」，指的就是眾生當下這極其微細的一念心。所謂「二種門」，並不是前後左右分開的兩樣東西。只是說：隨緣而其性不變，就在這生滅心上稱它為真如門；性雖不變而能隨緣，就在這真如心上稱它為生滅門。……只是迷了就開始生死輪迴，此時真如整體地現為生滅；悟了則輪迴止息，此時生滅當體就是真如。所以是依「迷」與「悟」來說明這兩種門的。

### 段落四：一心三寶——體相用配法佛僧

**原文**（卷第六，釋「信根本」）：

> 信根本者。真如即是一切三寶根本。謂我現前介爾心性。離虛妄相。平等平等。即真如體大。名為法寶。雖復覓之了不可得。而性自神解。靈明不昧。即真如相大。名為佛寶。一切色心依正。十方虛空。千如百法。並此介爾心中所現之影。與能現心無是非是。不可分離剖析。即真如用大。名為僧寶。

**白話對照**：所謂「信根本」，是說真如就是佛法僧三寶的根本。也就是：我當下這一念微細的心性，離開一切虛妄之相，平等而又平等，這就是真如的「體大」，稱為法寶。雖然去尋覓它了不可得，但它的體性本自有靈知之解，靈明而不昏昧，這就是真如的「相大」，稱為佛寶。一切色法心法、依報正報、十方虛空、千如百法，都不過是這一念心中所顯現的影像，與那能顯現的心說不上是同也說不上不是同，無法分離剖析，這就是真如的「用大」，稱為僧寶。

## 三、名句

1. **「一心。即指眾生現前介爾心也。」**（卷二）
   ——智旭以天台「介爾一念」定義《起信論》的「一心」，這是全疏的樞紐，把如來藏的本體論拉回當下一念的觀心實踐。

2. **「隨緣不變。即此生滅心名真如門。不變隨緣。即此真如心名生滅門。」**（卷二）
   ——以「不變／隨緣」的雙向表述解消真如門與生滅門的對立，是裂「性相二宗之網」的核心命題。

## 四、術語表

| 術語 | 出處與釋義 |
|------|-----------|
| 裂網 | 本疏題名。撕裂「法相／法性二宗有高下差別」之知見網羅 |
| 介爾心 | 天台語，指當下極微細的一念心。智旭用以詮釋《起信論》之「一心」 |
| 隨緣不變／不變隨緣 | 華嚴、天台通用的真如二義。智旭用它對配真如門與生滅門 |
| 一心三寶 | 智旭以真如體大配法寶、相大配佛寶、用大配僧寶 |
| 定一／定異 | 「決定同一」與「決定相異」兩種邊執，智旭指《起信》破後者、《唯識》破前者 |
| 凝然真如 | 唯識家被誤解所立之不動真如。智旭指出《成唯識論》原無此說，是後人誣謗 |
| 藏通別圓 | 天台化法四教。智旭以圓教配《起信論》之一心 |
| 六即起信 | 智旭以天台六即（理即、名字即、觀行即、相似即、分證即、究竟即）配判起信位次 |
