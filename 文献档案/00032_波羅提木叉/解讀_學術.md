# 波罗提木叉 — 学术解读

## 一、文献背景与成书

波罗提木叉（Pātimokkha / Prātimokṣa），意译「别解脱」「处处解脱」，是佛教比丘、比丘尼所受持之戒律条目集成，被公认为佛教文献中最古老的定型文本之一。学界普遍认为其核心条目在部派分裂之前即已基本定型，理由是各部派所传戒本（巴利、说一切有部、法藏部、大众部、化地部等）在条目数量与顺序上高度一致，差异仅在细目分合与用语。Frauwallner 曾据此论证诸部律藏出于共同的古老源头。

汉译戒本流传多种：姚秦佛陀耶舍译《四分僧戒本》、鸠摩罗什译《十诵比丘波罗提木叉戒本》、东晋佛陀跋陀罗译《摩诃僧祇律大比丘戒本》、刘宋佛陀什等译《弥沙塞五分戒本》等，恰与汉传诸部广律一一对应。20世纪发现的犍陀罗语写本中亦有戒本残卷，为戒本在中亚的早期流布提供了实物证据。

## 二、文本结构与核心思想

比丘戒本列举二二七条学处，分八品（八聚）：四波罗夷、十三僧伽婆尸沙（僧残）、二不定、三十尼萨耆波逸提（舍堕）、九十二波逸提（单堕）、四波罗提提舍尼、七十五众学、七灭诤。比丘尼戒本则为三一一条。戒本的实际使用场景是「布萨」：每半月新月与满月日，僧团集会，由上座比丘诵出戒条，犯戒者当众发露忏悔，诵毕三次询问「清净与否」，无人异议则僧团恢复清净共同体状态。

思想上有三点值得注意：其一，「别解脱」意味着持一条戒即得一分解脱，戒不是束缚而是逐条的防护；其二，戒条按罪之轻重排列，从断头的波罗夷到礼仪性的众学，构成一个精密的伦理分级系统；其三，布萨仪式将律制转化为共同体的周期性自我清澄机制，戒因此不只是个人行为规范，更是僧团存续的制度基础。

## 三、学术研究价值与争议

**研究价值**：戒本是部派判定的重要依据——比较诸本异同，可重建部派分化史；戒条内容反映了早期僧团面对的真实社会处境（金钱、衣物、饮食、男女往来），是研究印度佛教社会史的第一手材料。Schopen 即利用戒律材料论证印度寺院经济的实态，纠正了仅凭经典研究佛教的偏颇。

**争议问题**：其一，戒本的原初形态是什么？有学者认为早期仅有「略说教诫」（如「诸恶莫作」偈），条文是随僧团问题逐步增订的，波罗提木叉的定型晚于佛陀在世时期；其二，各部戒本出入的细节（如波逸提条数九十二与九十之别）究竟是部派改订还是传承歧异，至今无定论；其三，布萨与戒本是否受耆那教等同时代沙门团体类似制度影响，亦是老问题。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 波罗提木叉 | 戒律条目总集，意译「别解脱」，律藏核心 |
| 波罗夷 | 最重罪，犯者如断头，逐出僧团、不共住 |
| 僧伽婆尸沙 | 僧残罪，须经僧团羯磨程序方能恢复 |
| 尼萨耆波逸提 | 舍堕，须舍弃财物并忏悔之罪 |
| 布萨（Uposatha） | 半月一次的诵戒忏悔集会 |
| 七灭诤 | 平息僧团争议的七种程序 |
