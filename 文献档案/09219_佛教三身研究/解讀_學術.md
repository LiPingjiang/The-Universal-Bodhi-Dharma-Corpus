# 佛教三身研究 — 学术解读

## 一、文献背景与成书

本条目为语料库「寰宇覺海·菩提法藏」之独立文献补充条目，编号 X7705，名目作「佛教三身研究」。据实而言，其《原文》并非一经一论之传本，而是围绕「法身、報身、化身」三身名数组织起来的主题辑录：概述一节仅列三名，选录与名句两节各存两条引文，术语表七条，末附相关文献指引。条目 README 自署「待後續填充內容」，可知编纂意图在于保存三身名数与纲要式定义，留待扩充，属于名目型简编。

三身说的可考义理史线索相当清晰。早期佛教经典中已有「二身」之说：《长阿含·游行经》及巴利《长部》所说之「生身」（父母所生之肉身）与「法身」（以戒定慧等功德为身），此为法身概念的雏形，且《金刚般若经》「若見諸相非相，即見如來」从遮诠一侧限制了以身相见佛的可能。大乘经逐步扩充为二身、三身：说一切有部旧义唯立生身与法身；《大智度论》已有「法身」与「变化身」对举的用法。完备的三身结构定型于瑜伽行派典籍：《佛地经论》立「自性身、受用身、变化身」三名，世亲一系的《摄大乘论》释之以「自性身、受用身、变化身」为果位三身，即本条目所说的法、报、化三身之滥觞。真谛译《金光明经·三身分别品》别立「化身、应身、法身」之次第，故汉地对第三身的称呼历来有「化身」「应身」二系之别，本条目取「化身」系。

本条目选录引文「如來三身者：一者法身，真如理體，離相絕言；二者報身，萬行所感，智慧圓滿；三者化身，隨類現身，度脫眾生」是典型的纲要式科判语，非某一经本的原句，当为辑录者据通行的三身义理撰成的撮要；「法身為體，報身為相，化身為用」则是汉地注家惯用的体相用框架之移植。

## 二、文本结构与核心思想

《原文》五节悉依本语料库补充条目通例：名目罗列、双引文、名句复出、术语对照、相关文献。其核心义理可以循引文作三层分析。

其一，法身义。「真如理體，離相絕言」明法身即宇宙人生的真实本性（真如，Tathatā），非色非心，离言绝相，是佛之所以为佛的理体依据，也是一切众生平等的成佛根据。

其二，报身义。「萬行所感，智慧圓滿」明报身为因地所修万行感得的果报身，具足相好庄严与圆满智慧，唯地上菩萨得以亲见——报身概念把「修行必有果报」的业感逻辑延伸到佛身论上，回应了「成佛之后功德安在」的追问。

其三，化身义。「隨類現身，度脫眾生」明化身是佛为度化众生而随其种类、根机变现之身，释迦于人间示现八相成道即其显例。三身合观，「體相用三，不一不異」一语最能见其结构：法身为本体，报身为本体所显的庄严相状，化身为本体所起的教化作用；三者非一（各有分际）亦非异（同依一法身），此即汉传注疏以体相用判三身的通义。

## 三、学术研究价值与争议

第一，三身说的谱系学问题。现代研究（如日本学者横超慧日《涅槃經》系研究、山口益与平川彰对瑜伽行派佛身论的梳理）指出：佛身论经历了从生身＋法身的二身说，经般若系「应身」概念的引入，到瑜伽行派《摄大乘论》《佛地经论》确立自性、受用、变化三身体系的演化。本条目的术语表以 Trikāya 领衔，已是成熟期概念，不能反映早期二身阶段的形态，研究者据此当辨。

第二，名相与条目内部的小疵。术语表以 Prajñā 对「智慧」、Upāya 对「方便」，而正文选录无此二词的直接语境，当是辑录者按三身义理的配套概念补入；又 Trikāya 系近代学术整理梵文佛教术语时确立的合成词，古译佛典中并无此现成梵语原词，表列其义可通，视之为对概念体系的现代重构更妥。

第三，三身说的跨宗派形态差异。汉传天台、华严以法身摄一切，禅宗则倾向「即心即佛」而对三身作心性化的消解（如《六祖坛经》以自性三身佛说转化之）；藏传各派对三身另有配合密续四佛身的扩展（自性身、报身、化身加等流身等），相关论典如依《现观庄严论》系统之疏释，多传自梵藏传承，不在大正藏编号体系之内，当转检藏文大藏经编目。又，三身之名与儒家「立德立功立言」三不朽、道教「一气化三清」的比较，是近现代比较宗教学的常见论题，可参而不可牵合。

| Saṃbhogakāya | 報身 | enjoyment body |
| Nirmāṇakāya | 化身 | emanation body |
| Tathatā | 真如 | suchness |
