# 量决定论 — 学术解读

## 一、文献背景与成书

《量决定论》（Pramāṇaviniścaya）为法称（Dharmakīrti，约600-660年）所造，约成书于7世纪，是法称量论三部主要著作（《释量论》《量决定论》《正理一滴论》）中的中期作品，通称"法称七论"之二。学界一般认为本论是《释量论》的简明改写（"略本"性质），但在若干论点上已有发展——尤其在现量的"不错乱"条件上表述更为明确。梵本大部分存世（经藏地发现的贝叶写本整理），完整藏译收入丹珠尔；汉地无古代译本，现代有法尊法师等据藏译的转译与研究。本论在藏传佛教中是因明学习的核心文献，历代注疏众多，萨迦派、格鲁派皆将其列入重要课程体系。

书名梵语 Pramāṇaviniścaya：pramāṇa（量，正确认知）+ viniścaya（决断、决定），直译"对量的决断"——即对"何为可靠认知"给出终局性的判定。

## 二、文本结构与核心思想

全论三品：

**〈现量品〉**立现量之定义为"离分别而不错乱"——"离分别"者，不杂名言、种类等一切概念构造；"不错乱"者，不为翳目（眼病）、动舟（舟行而见岸动）等因素所惑。由此简别：比量与概念认知被"离分别"排除，错觉与似现量被"不错乱"排除——二支具足，方名真现量。复立现量有四：根现量（五感官）、意现量、自证现量、瑜伽现量（禅定直观）。

**〈为自比量品〉**论述为自己获得确定知识的推理，阐明因三相及三种因（自性因、果性因、不可得因）。

**〈为他比量品〉**论述为说服他人而构建的论式与谬误。

核心思想承陈那而更趋严格：**量唯有二——现量与比量**，因为所量唯有自相与共相二种：现量缘自相，比量缘共相，更无第三量。此"二量二所量"的对应结构是整个佛教量论的骨架。较之《释量论》，本论删繁就简，略去了成量品的大部宗教论证，将篇幅集中于认识论与逻辑的技术核心，故成为教学首选。

## 三、学术研究价值与争议

研究价值方面，本论是研究法称思想演变的中继站：其现量定义加入"不错乱"的明确限定，被学界（如户崎宏正）视为法称对陈那现量论的重要修正——感知不仅要无概念，还须无错觉，这使得"真现量"的标准从现象学条件转向了成功性条件。藏传注疏传统（如法上、释迦慧等印度后期论师的释本，及藏族学者的释著）以本论为中心形成了庞大的文献群，是国际藏学的重要研究领地。日本学界对梵藏对勘有长期积累；近年西方学者（如 Birgit Kellner、Eli Franco 等）围绕本论现量品的研究持续产出。

争议问题包括：（1）本论与《释量论》的关系——"略本改写"与"独立新作"之争，涉及法称思想的分期；（2）"不错乱"标准带来的疑难——若无错觉的判准本身依赖因果效力（能成功作用于对象），则现量的定义是否与比量发生了循环，学界有专门讨论；（3）瑜伽现量（禅定直观缘共相）与"现量缘自相"总纲的表面矛盾，历来是注释家聚讼之处。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 量决定（pramāṇaviniścaya） | 对可靠认知的终局判定 |
| 离分別（kalpanāpoḍha） | 现量的第一条件：无概念构造 |
| 不錯亂（abhrānta） | 现量的第二条件：无错觉 |
| 四现量 | 根现量、意现量、自证现量、瑜伽现量 |
| 自相/共相 | 现量对象（个别真实）/比量对象（概念一般） |
| 三种因 | 自性因、果性因、不可得因 |
