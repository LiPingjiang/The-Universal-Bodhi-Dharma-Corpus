# 量决定论 — 学术解读

## 一、文献背景与成书

《量决定论》，梵名 Pramāṇaviniścaya，意为「对量的决定性考察」，印度因明学大师法称（Dharmakīrti，约七世纪）造，是「法称七论」之一。据本库原文档，全书分三品：现量品、为自比量品、为他比量品——分别处理知觉、自我推理与论证表达三个层次。此论与《释量论》《正理滴论》同属法称量论的三大骨干，而以组织精严、便于教学著称。

其流传谱系须特加说明：法称的量论著作没有古代汉译，现存全靠藏译（收于藏文大藏经丹珠尔）与梵文残本，故不在汉文大正藏的编号体系之内；「量决定论」这一汉名是近现代学界的译题。藏传佛教对法称量论的传承与发扬极为深厚：桑浦寺以来的量论讲学传统以法称诸论为教材，格鲁派寺院的因明教育更是以法称为宗——可以说，法称在藏传世界的地位，相当于因明学的一座主峰。

## 二、文本结构与核心思想

据本库原文，其义理骨架有三：

1. **现量的定义**。〈现量品〉立现量的定义为「离分别而不錯乱」——「离分别」指不夹杂名言、种类等一切概念构造（即所谓 kalpanāpoḍha）；「不錯乱」指不为翳目、动舟等错觉因所惑（即 abhrānta）。两支缺一不可：缺前者，混入了概念，就成了比量；缺后者，虽无概念而认知失真，成了似现量。

2. **现量的分类**。立现量有四：根现量（感官知觉）、意现量（随之而起的心理认知）、自证现量（对自身认知活动的觉知）、瑜伽现量（禅定中生起的直观）——从感官到禅观，四种「直接经验」被排成一个连续的谱系。

3. **二量说**。原文名句云：「量唯有二——现量与比量。以所量唯有自相与共相二种故：现量缘自相，比量缘共相，更无第三量。」这是陈那开创、法称定型的量论根本判教：认识对象只有「个别」（自相）与「一般」（共相）两种，故有效的认识渠道也只有直接与推理两种。阿含、圣言等传统权威，都被收摄进二量之内检验——一切知识必须能还原为现比二量，否则不具知识资格。

## 三、学术研究价值与争议

**研究价值**：其一，「离分别而不錯乱」的双重定义是佛教知识论最精密的定义之一，为国际哲学界研究知觉理论提供了古典范本；其二，四种现量的谱系打通感官经验与禅观经验，是研究佛教修行论与认识论关系的枢纽文本；其三，二量说把「知识来源」彻底系统化，是比较哲学与分析哲学讨论「何种信念有资格成为知识」时的经典参照。

**代表学者**：奥地利学者斯坦凯勒纳主持过本论梵文的文献学研究（自藏译重构），国际藏学与因明学界对三品均有专门译注；日本学者（如御牧克己等）对法称量论有系列研究；汉译方面，法称量论的移译与讲习是二十世纪以来藏传因明汉译工程的重要部分。

**争议问题**：其一，「意现量」的地位——意现量是否为独立现量、与根现量如何衔接，法称学派内部（及其后释论传统）有长期讨论；其二，「不錯乱」的判定标准——何种错觉算「錯乱」因、常态认知（如见阳焰为水）如何归类，涉及外在世界实在性的争论（法称的「三相外境」说与后来的释论有出入）；其三，自证现量作为循环论证嫌疑的辩护，至今仍是研究热点。

## 四、术语对照表

| 术语 | 释义 |
|------|------|
| 量（pramāṇa） | 有效的认识、可靠的知识来源 |
| 现量 | 离分别而不錯乱的直接认知 |
| 离分别（kalpanāpoḍha） | 不夹杂名言种类等概念构造 |
| 不錯乱（abhrānta） | 不为翳目、动舟等错觉因所惑 |
| 自相／共相 | 个别事物／一般概念，现量与比量各自的对象 |
| 为自比量／为他比量 | 为自己求知的推理／为说服他人的论证 |
| 似现量 | 有现量之貌而无现量之实的认知 |
