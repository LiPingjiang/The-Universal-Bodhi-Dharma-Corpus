# 佛教十遍處研究_5 — 学术解读

## 一、文献背景与成书

本条目（语料库编号 X10331）属于「独立文献补充条目」系列，并非一部古代成书的经律论，也没有传世写本或刻本可考。原文档由三部分构成：一句概述，列举「地、水、火、风、青、黄、赤、白、空、识」十种遍处；两段选录，一段给出十遍处的定义句，一段给出地遍作意的修法句；一张术语表，收 Kasiṇa 等梵巴名相。目录 README 标注「待后续填充内容」，说明编纂者设立此目，意在为这一禅法名目建立检索入口，其性质是名目汇编型的研究档案，而非完整文献的抄录。

尽管原文档本身没有出处标注，其所录文句均可与传世文献对勘：十遍处的名目见于汉译阿含与毗昙论书，《大毗婆沙论》与《俱舍论》卷二十八〈分别定品〉对此有系统的配属分析；巴利传统则在《清淨道論》的遍处章以数章篇幅展开修法细节。就此而言，本条目虽为后出汇编，其名目与文句却植根于南北共传的禅定学传统。本条目所涉为汉巴通行的禅法体系，非藏传文献，故不存在大正藏编号体系之外的对应问题。

## 二、文本结构与核心思想

原文档的结构极简，却暗含一条「定义—修法—名相」的解读次序。定义句以同构句式十举其目：

「十遍处者：地遍一切处，水遍一切处，火遍一切处，风遍一切处。青遍一切处，黄遍一切处，赤遍一切处，白遍一切处。空遍一切处，识遍一切处。」

前八为色遍，即四大种与青、黄、赤、白四种显色；后二为无色遍，即空、识。这一分类正是毗昙学的标准分判：前八遍处以色法为所缘，空、识二遍处则摄无色行相，论书对其所缘与依地的配属各有精细说法，构成部派阿毗达磨分判禅定的代表性议题。

修法句「若人于地遍作意，增长广大，周遍一切，无有间隙，是名地遍处」点出「遍」字的技术含义：所缘必须被扩展到没有任何间隙的程度，方称「遍处」。这与巴利语 kasiṇa（义为「整体」「周遍」）的语源一致。在《俱舍论》的体系里，十遍处与八解脱、八胜处组成一个由浅入深的序列：八解脱为总门，八胜处于色得自在，十遍处则将所缘推至无边，三组禅法层层相摄。核心思想可概括为：以「周遍无间隙」的所缘扩展，成满心一境性，为神通与观慧的所依。

## 三、学术研究价值与争议

其一，名目汇编的文献学价值。本条目作为大藏经体系之外的近代编纂品，反映了文献整理者对禅法名目系统化的意图；将其与毗昙论书、《清淨道論》对勘，可以观察同一概念在汉译论书与巴利注释传统中的表述差异。

其二，思想史的争议焦点在于十遍处的成立年代。学界一般认为，遍处名单已见于尼柯耶与阿含的后期经段，而其系统化的配属与修法细则则是阿毗达磨时代论师的整理成果；汉译毗昙与巴利《清淨道論》所传的具体修法（如遍作相、取相、似相的三阶次第）更属于注释传统的发展。

其三，现代禅修史研究中，十遍处的传承出现明显的分化：缅甸帕奥系统重视遍处禅，而以观受为核心的系统则不传此法，其取舍背后的定学判教差异，是当代南传禅法研究的一个议题。另外，心理学者尝试将遍处所缘扩展与注意广度、意象控制能力对照研究，属于尚在起步的跨学科探索。
