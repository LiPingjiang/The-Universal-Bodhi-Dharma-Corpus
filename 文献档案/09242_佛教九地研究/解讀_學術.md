# 佛教九地研究 — 学术解读

## 一、文献背景与成书

本条目为语料库「寰宇覺海·菩提法藏」之独立文献补充条目，编号 X7728，名目作「佛教九地研究」。据实而言：其《原文》非经论传本，而是把三界展开为九地的名目辑录。概述一节所列为「欲界五趣地、離生喜樂地、定生喜樂地、離喜妙樂地、捨念清淨地、空無邊處地、識無邊處地、無所有處地、非想非非想處地」九名，而选录引文首句作「五趣雜居地」——概述与引文在欲界一地的名目上微异（「欲界五趣地」与「五趣雜居地」），当以引文之「五趣雜居地」为通行定名，概述一节盖转录时省改；此为本条目内部可指认的一处文字出入，今照原样说明，不改字。条目 README 自署「待後續填充內容」，性质为保存九地名数与断语的名目型简编。

九地又称九有、九有情居，是把三界的存在领域按「识住」标准切成的九段：欲界一地（五趣杂居地），色界四地（即四禅：离生喜乐地、定生喜乐地、离喜妙乐地、舍念清净地），无色界四地（即四无色处地）。这一体系的经典依据以《阿含经》「七识住与二处」之说为前身，定型于阿毗达磨：说一切有部《大毗婆沙论》卷一百三十七及《俱舍论·分别世品》立九地为「九有情居」，天台智者《法华玄义》《摩诃止观》引「三界九地」以判众生的散心与定心层次，则把阿毗达磨名数转为止观教学的框架。本条目术语表列 Jhāna-bhūmi（禪地）一条，显示辑录所重在禅定地相一面。

## 二、文本结构与核心思想

《原文》五节为补充条目通例，其内容要点可析为三。

其一，九地的切分逻辑是「定心」。九地不是三界的机械等分：欲界全境合为一地，因为其中众生散心粗动、五趣杂居；色界无色界则各按定境浅深细分。故九地名为地（bhūmi），实指心的九种住处状态——「地」在这里既是生处也是心所处。

其二，色界四地之名直接取自四禅的功德支分：初禅「離生喜樂」谓离欲恶不善法、由离而生喜乐；二禅「定生喜樂」谓由定心内净所生喜乐；三禅「離喜妙樂」谓舍喜而受妙乐；四禪「捨念清淨」谓喜乐俱舍、舍念清净。名目本身就是四禅修法与功德的自性描述。

其三，断制之语「三界九地，眾生流轉。若了九地皆苦，即求出離」。九地是所遍知，苦谛是能观智：把整个存在领域——从五趣杂居到非想非非想——全部判为苦所摄，修观者于此九地次第遍知其无常苦空，即得厌离。此与三界说的解脱论判摄同一机杼，而更细化为可修可观的次第。

## 三、学术研究价值与争议

第一，九地与七识住、二处的名义关系是阿毗达磨文献学的细目。《俱舍论》以四识住、七识住、九有情居层层相摄，其间出入（如无想天与非想非非想天的归属）在《大毗婆沙论》内部已有诸家异说。本条目唯列九地之名而不及其相摄关系，用作教学名数则可，用作义理考据则须复核原论。

第二，「地」的双关性是现代诠释的争点。九地的 bhūmi 一词兼指生存领域与心的基础状态（所谓「地前心」对「地上心」的用法另见于菩萨阶位），故九地体系既是宇宙论也是禅定心理学。日本学者及欧美佛教研究界对「世界的分层源于定境的对象化」这一命题讨论已久，与三界说共同构成佛教宇宙论心理学化诠释的核心案例。

第三，汉传教学传统的接受。天台家以「三界九地」判散心、定心，并在《六妙法门》等止观文献中把九地配入世间禅定的进阶；藏传与南传各有对应的定学体系（南传清净道论系则依八定加灭尽定立九次第定，与九有情居的名数相近而体系不同，不可混同）。依藏文传承的九地相关论释不在大正藏编号体系之内，应检藏文大藏经；南传《清净道论》虽有大正藏收录的圆晖系《俱舍颂疏》等对应汉文文献，其本身则有巴利原典可据。

| Kāmadhātu | 欲界 | desire realm |
| Rūpadhātu | 色界 | form realm |
| Arūpadhātu | 無色界 | formless realm |
| Pañca-gati | 五趣 | five destinations |

| Bhāvacakra | 有輪 | wheel of existence |
