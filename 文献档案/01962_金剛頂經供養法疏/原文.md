# 金剛頂經供養法疏 · 原文

## 一、概述

現有網路檢索未發現一部題為《金剛頂經供養法疏》、且可核實作者、卷數與全文的漢文續藏注疏。故本檔不虛構其T號、作者或原文，而以可核實的金剛頂系供養儀軌材料作為旁證：唐代不空譯傳的金剛頂瑜伽念誦儀軌，明言行者應先發普賢心、受金剛戒與三昧耶，擇地建立壇場，置本尊並作供養。這些是「金剛頂系供養」可確證的原始材料，但不是一部可確認名為《金剛頂經供養法疏》的注疏正文。

## 二、核心段落

> **原文**（唐代金剛頂瑜伽念誦儀軌）：
>
> 「歸命童真妙吉祥，我依瑜伽說念誦。身口意業金剛念，如來甚深三密門。行者應發普賢心，從師應受金剛戒，不顧身命起慈悲，方可堪入解脫輪。應從師受三麼耶，契印密語如經說，敬阿闍梨如佛想，於同學所殷重心。或於山間阿蘭若、流泉浴池悅意樹、山峰石窟迥樹邊，建立壇場如本法。莊嚴精室置本尊，隨力供養一心住，遍觀十方諸佛海，供養禮諸如來足。」

> **白話翻譯**：
>
> 我頂禮童真妙吉祥，依瑜伽法門說明念誦。應以金剛之念修持身、口、意三業，進入如來甚深的三密法門。行者應發普賢心，從師受金剛戒，以慈悲心不惜身命，才堪能進入解脫之道。又應從師受三昧耶，依經所說受持契印與密語，敬重阿闍梨如同佛，對同學也須誠敬。可在山間阿蘭若等清淨處，依本法建立壇場；莊嚴精室、安置本尊，依自己的能力作供養，專心安住，觀想十方諸佛海，供養並頂禮諸如來。

## 三、名句

1. 「行者應發普賢心，從師應受金剛戒，不顧身命起慈悲，方可堪入解脫輪。」
2. 「莊嚴精室置本尊，隨力供養一心住，遍觀十方諸佛海，供養禮諸如來足。」

## 四、術語表

| 術語 | 說明 |
|---|---|
| 供養 | 以香、花、飲食等事相或以修行、觀想等行持，敬奉三寶與本尊。 |
| 普賢心 | 以普賢菩薩之大願、利他為取向的菩提心。 |
| 金剛戒 | 金剛乘行者所受的戒誓，本文明言須從師受。 |
| 三麼耶 | 三昧耶；密教的誓約與相應關係。 |
| 阿闍梨 | 指導修學與儀軌的師長。 |
| 壇場 | 修法、供養與觀想所依的道場。 |
| 三密 | 身、語、意與佛之身語意相應的法門。 |

## 五、相關文獻

- 《金剛頂瑜伽念誦儀軌》：上引供養與建壇段落之來源。
- 《金剛頂瑜伽金剛薩埵五秘密修行念誦儀軌》：不空譯，述金剛頂瑜伽修行與灌頂、三昧耶。
- 《金剛頂經大瑜伽秘密心地法門義訣》：現存卷上，解說金剛頂系教義。
- 《大毗盧遮那經供養次第法疏》：唐不可思議撰，係《大日經》供養法疏，**不可誤作本條《金剛頂經供養法疏》**。
