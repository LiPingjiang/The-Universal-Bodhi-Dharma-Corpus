# 佛教十八不共法研究 — 学术解读

## 一、文献背景与成书

十八不共法（梵 aṣṭādaśa āveṇika-dharmāḥ）是佛果功德论的核心名相之一，指唯佛独有、不与声闻缘觉及菩萨共有的十八种功德；「不共」（āveṇika）意为其余圣者「於中無分」——阿罗汉虽具四无碍辩之一分，舍利弗虽通达法义，皆不能圆满此十八法。本条目属义理研究类专题条目，其「原文.md」给出的经典依据是《大智度論》（T1509）卷二十六，即鸠摩罗什译《摩訶般若波羅蜜經》的释论部分；亦见于《大乘義章》卷二十末与《法界次第》卷下之下，可见此说经由般若经群的释论而成为汉传佛果论的通说。

名目依「原文.md」所录为：一者身无失，二者口无失，三者念无失，四者无异想，五者无不定心，六者无不知已舍，七者欲无减，八者精进无减，九者念无减，十者慧无减，十一者解脱无减，十二者解脱知见无减，十三者一切身业随智慧行，十四者一切口业随智慧行，十五者一切意业随智慧行，十六者智慧知过去世无碍，十七者智慧知未来世无碍，十八者智慧知现在世无碍。值得注意的是「原文.md」同时记录了部派异说：《大智度論》引说一切有部迦旃延尼子之说，以「十力、四无所畏、大悲、三不共意止（三念处）」为十八不共法，《大毗婆沙論》（T1545）卷十七亦持此小乘旧说；大乘唯识系则另有「一百四十不共法」的广列，见《瑜伽師地論》〈菩萨地〉建立品。同一「十八」之数，部派与大乘各填入不同内容，是佛教功德论内部竞争的绝佳标本。

## 二、文本结构与核心思想

「原文.md」所选两段经文揭示此说的论证结构。第一段罗列十八法之目，其排列自有章法：前三（身口念无失）明断德圆满，永离过失；四至六（无异想、无不定心、无不知已舍）明佛心之行相——于众生无亲疏分别、行住坐卧不离定、于已舍之法照知而后舍；七至十二（欲、精进、念、慧、解脱、解脱知见六无减）明智德无减损；十三至十五明三业皆为智慧所摄导；十六至十八明三世智无碍。「原文.md」的白话对照将其归纳为「断德圆满、智德无减、业用自在、三世智无碍」四层，摄佛果功德之全体。第二段是《大智度論》自设的问答：三十六法（十力、四无所畏、十八不共法等）皆是佛法，为何独以此十八为不共？答曰声闻于十力、四无畏尚能得分——舍利弗能分别诸法、畅演一句通达无碍，宾头卢师子吼第一——唯后十八法二乘无分，故名不共。「不共」的判定标准因此不是「大」而是「专属」：佛之所以为佛，端在此十八种功德的不可分享性。此外《大智度論》以「佛於無量阿僧祇劫來，持戒清淨故，身口業無失」释初二法，显示此说背后的因果时间尺度——十八不共法是三大阿僧祇劫修行的果报，而非佛的特权。

## 三、学术研究价值与争议

研究价值可分三层。义理层面，十八不共法是大乘佛果论的试金石：它以「唯佛专属」的功德清单回答「佛与阿罗汉有何不同」这一部派时代即已尖锐的问题——早期经律中佛陀自称「我是阿罗汉」，而大乘以十八不共法将佛果从解脱的量变推为功德的质变，如来藏与佛性思想皆可置于此延长线上理解。文献层面，「原文.md」保存的大小二说对照（有部「十力四无畏大悲三念处」对《大智度論》十八法）为研究功德名录的层累演化提供了样本：不共法的「清单」随学派立场而重组，正如百四十不共法所示，功德可以无限增殖，其枚举性质大于其教理必然性。争议方面，学界长期讨论十八不共法的经证源头：其完整的十八数列表在早期阿含中不见系统宣说，主要成立于般若经群与释论传统，故有学者视之为大乘「佛身观」发展的产物；《大智度論》文本本身的作者与成立问题（龙树自撰抑或编译）也直接影响对此段资料的断代。又，「念无失」「无不定心」等目的界定在诸疏之间颇有出入，汉译「无不知已舍」一句的读解（已舍之法无不了知）历来是训诂难点。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 不共（āveṇika） | 唯佛独有、余圣无分之义 |
| 身无失 | 历劫持戒，烦恼习气永尽，身业永无过失 |
| 无异想 | 于一切众生无亲疏分别之心 |
| 无不定心 | 行住坐卧皆在定中，心不散乱 |
| 无不知已舍 | 于所舍之法照知而后舍，非如凡夫之忘舍 |
| 解脱知见无减 | 于解脱之自知证智圆满无缺 |
| 三念处 | 有部说不共法之一：佛于顺违俱离三位安住正念 |
| 三世无碍智 | 通达过现未三世一切法之智慧 |
| 百四十不共法 | 唯识系广列之佛功德系统 |
