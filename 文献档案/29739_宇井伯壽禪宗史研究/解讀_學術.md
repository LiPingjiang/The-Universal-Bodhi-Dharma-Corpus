# 宇井伯寿禅宗史研究 — 学术解读

## 一、文献背景与成书

宇井伯寿（1882—1963），日本爱知县人，曹洞宗僧侣出身的印度学与佛教学者，毕业于东京帝国大学，长期执教于曹洞宗系统的佛教专门教育机构。本档所收为其学术代表作《禪宗史研究》三册（第一册1939年、第二册1941年、第三册1943年，岩波书店出版），辅以《印度哲學研究》全六册、《中國佛教史》、《禪の本質》等著作。宇井属于20世纪日本佛教文献学的黄金一代，与常盘大定、关口真大等人同以严格的文献批判方法处理禅宗史，一改此前禅宗史写作依附灯录、语录的传统。需要说明：本档为近现代研究文献档，收录的是研究著作的篇目结构与代表性论述摘录，而非古代文献本身，故依现代学术文献的体例撰写；本档亦不属于大正藏编号体系。

《禪宗史研究》三册的篇章布局是：第一册处理达摩之研究（来华年代、壁观、二入四行论之真伪）、楞伽师传承、法融与牛头宗、神秀与北宗；第二册处理慧能生平与顿悟说、荷泽神会、洪州宗（马祖道一）与石头宗（石头希迁）、临济义玄与洞山良价；第三册处理宋代禅宗（灯录编纂、公案成立）、日本禅宗传入（荣西、道元）、禅思想的展开（悟与修、平常心是道）及禅与华严、天台的关系。三册合观，构成自达摩至宋元日本禅的完整叙事框架。

## 二、文本结构与核心思想

宇井禅宗史研究的方法论核心，是"以文献批判解构传灯叙事，再以思想史重构禅史脉络"。其代表性论点可从本档摘录的三段论述观察。

关于达摩，宇井提出：「達摩之禪，非如後世禪宗所傳之頓悟禪，乃以『壁觀』為特色之漸修禪。所謂『壁觀』，非面壁而坐之謂，乃心如牆壁、內外隔絕之譬喻。」他据《二入四行论》分析达摩禅以"理入"（藉教悟宗）与"行入"（报怨行、随缘行、无所求行、称法行）为纲，判定其与后世慧能顿悟禅有显著区别——这一"达摩渐修说"是全书立论的第一块基石。

关于神会，宇井将开元二十年（732年）滑台大会视为中国禅宗史上最具决定性的事件，认为神会的贡献在于"以慧能為達摩正傳，以神秀為旁出"，并把南北宗对立定性为修行方法论的根本对立——北宗渐修重打坐，南宗顿悟重见性。此论显然承自胡适对神会研究的大方向，但宇井的日本文献学训练使论证更为绵密。

关于禅思想本质，宇井有一段极具思辨性的论述：「『不立文字』之本身，亦需文字表達；『教外別傳』之傳承，亦需記錄維持。此為禪思想之根本矛盾，亦為其豐富發展之動力。」他称禅"以語言超越語言，以修行超越修行，以宗派超越宗派"——这已从史学转入哲学诠释，为其后《禪の本質》的专题研究埋下伏笔。

## 三、学术研究价值与争议

研究价值方面：第一，宇井是第一位以现代文献学系统梳理达摩至宋代禅宗史脉络的学者，《禪宗史研究》三册奠定日本禅宗史研究的基本框架，此后柳田圣山《初期禪宗史書研究》、关口真大的达摩研究，皆在此框架内推进。第二，达摩考订的突破——通过《二入四行论》《续高僧传》与灯录系统的比勘，剥离后世附会，其考订至今仍是讨论达摩历史形象的起点。第三，将《印度哲學研究》六册与禅宗史并列，把禅置于印度佛教思想整体演化（原始佛教—部派—大乘）的长时段脉络中，这种方法论的自觉领先于同时代多数研究。

争议问题有三。其一，达摩评价的争议：宇井将达摩判为渐修禅，与后世禅宗自我理解（顿悟传统）之间的张力，引发其后关口真大等人的再检讨；达摩是否曾传《楞伽》，亦在争讼中。其二，神会"革命说"的限度：宇井与胡适一样高度评价神会的决定性作用，但敦煌文献的后续研究显示，滑台大会之后北宗并未迅速衰落，南宗主导地位的建立过程比"神会革命"叙事更为缓慢复杂。其三，与铃木大拙的对立：宇井重文献考订、铃木重体验诠释，两人分别代表日本禅学的"史学派"与"哲学派"，其分歧折射出禅研究"历史真实"与"宗教意义"之间的永恒张力——宇井本档所收《禪の本質》论述，正是他对这一挑战的回应。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 壁观 | 达摩禅法特征，宇井释为"心如墙壁、内外隔绝"之喻 |
| 二入四行 | 理入与行入（报怨、随缘、无所求、称法四行），达摩禅纲要 |
| 不立文字、教外别传 | 禅宗自我定位，宇井指其为禅思想"根本矛盾"之所在 |
| 滑台大会（732年） | 神会确立南宗正统的关键事件 |
| 渐修／顿悟 | 宇井用以界定南北宗方法论对立的核心概念 |
| 灯录 | 禅宗传法系谱文献（《景德传灯录》等），宇井批判性史料的来源 |
| 公案 | 宋代禅门教学单元，第三册的专题对象 |
