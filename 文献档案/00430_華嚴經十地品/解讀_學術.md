# 華嚴經十地品 — 学术解读

## 一、文献背景与成书

《十地品》是《华严经》中系统说明菩萨十地的核心部分。在唐实叉难陀译八十卷《大方广佛华严经》T279中为第二十六品，主要分布于卷三十四至卷三十九；东晋佛陀跋陀罗译六十华严T278亦有相应品。西晋竺法护另译《渐备一切智德经》T285，后秦鸠摩罗什译《十住经》T286，均属独立《十地经》传统。

这说明《十地品》在编入大型《华严经》之前或同时，已可作为独立经典流通。其梵本《十地经》与藏译尚存，印度世亲《十地经论》经菩提流支等译成汉文T1522，对地论学派及后来的华严、唯识思想影响深远。作为全经一品，它由金刚藏菩萨在他化自在天宫宣说，解脱月菩萨代表大众反复请法。

独立十地经与华严品本的关系，是版本史的核心问题。T285、T286和六十、八十华严并非仅有译语差异，部分偈颂、譬喻与科段也见增减；梵藏资料又保留不同读法。因此，研究十地思想形成时，应先辨明所据传本，再讨论世亲论释及汉地宗派发挥。后世常将“十地”与十波罗蜜整齐配对，但这种体系化也经过论书和注疏的持续整理。

## 二、文本结构与核心思想

十地依次为欢喜地、离垢地、发光地、焰慧地、难胜地、现前地、远行地、不动地、善慧地、法云地。每地通常说明入地条件、主要行相、所见诸佛、修习波罗蜜、譬喻及果德。十波罗蜜亦依次突出：布施、持戒、忍辱、精进、禅定、般若、方便、愿、力、智。

十地不是简单的等级荣誉，而是菩提心逐步成熟的地图。初地以欢喜和大愿超越凡夫位；二地落实十善；三至六地深化禅定、道品与缘起智慧；七地以方便进入广大利他；八地不动而任运；九地善说法；十地如云降法雨。每一地都以慈悲为前导、智慧为主导，并非先自我完善、最后才照顾别人。文本又反复以炼金比喻善根日益明净，说明前阶没有被抛弃，而是在更大能力中重整。

每地还叙述见佛、供养、摄受众生及所任王位，把内在证悟与社会责任相连。末尾以大海十相、山王十相等譬喻总摄阶位，说明次第既有差别，又共享趋向一切智的方向；这为后世“行布与圆融”并说提供了文本基础。

## 三、学术研究价值与争议

《十地品》连接早期大乘菩萨阶位、瑜伽行派修道论和华严法界思想。世亲《十地经论》以唯识和阿赖耶识相关框架解释十地，汉地慧光、法上据此发展地论学；法藏、澄观则把十地纳入华严圆教，强调行布次第与圆融互摄并存。现代学者高崎直道、木村清孝等关注《十地经》在印度大乘与华严形成中的位置。

争议之一，是十地为严格线性阶段，还是每地互摄。经文确有次第，华严注释又强调“一位一切位”，二者不宜互相取消。之二，十波罗蜜与十地一一配属在不同论书中细节不尽相同。之三，《十地经论》的作者、翻译和南北道解释曾引发中国佛教史上的“相州南道、北道”分歧。版本研究还需比较独立十地经与华严品本，避免将后世唯识或华严术语直接当作原经明文。十地名称虽稳定，其所配禅定、王位和果德在传本与注释中仍有差异。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 十地 | 菩萨从初见道至接近佛果的十个成熟阶段 |
| 欢喜地 | 证入初地、决定趣向菩提而生大欢喜 |
| 不动地 | 第八地，无分别智稳固而不被烦恼动摇 |
| 法云地 | 第十地，以广大智慧如云降法雨利益众生 |
| 十波罗蜜 | 六度加方便、愿、力、智，配合十地深化 |
| 行布圆融 | 修行既有阶段次第，又相互包含而不隔绝 |
