# 巴利律藏註疏 — 学术解读

## 一、文献背景与成书

本档案收录巴利律藏的注释书系统，核心是五世纪上座部论师觉音（Buddhaghosa）所造的《善見律毗婆沙》（巴利名 Samantapāsādikā）。需要先厘清文献的名实关系：巴利原典 Samantapāsādikā 意为「普遍令人生起喜悦者」或「全然令人满足者」，本无「善見」之意；「善見律毗婆沙」这一汉译题名系承自汉译传统——南朝萧齐时僧伽跋陀罗译出同名律注十八卷，收入《大正新修大藏经》第二十四册（T24, no.1462）。汉译本与巴利本之间的关系是本领域的经典问题（详见第三节）。此书是上座部律学研究的权威基础文献。

成书因缘依原档案所述：觉音在斯里兰卡大寺（Mahāvihāra）僧团的资助下，将古僧伽罗语的律藏注释整理、翻译并改写为巴利语，编成此注。也就是说，此书与觉音的其他注释书一样，是「旧注的巴利化改写」而非凭空新造——五世纪时锡兰大寺派所藏圣典注释以僧伽罗语传承，觉音据以重撰，遂成今天所见巴利注释传统的主体。PTS（巴利圣典学会）于 1924 至 1947 年间出版此注的校勘本，是现代研究的标准文本。此外，本档案目录名为「巴利律藏註疏」的复数概念，按语料库的完整序列，其后尚有《巴利律藏復注》与再注（ṭīkā）等更后出的注释层次，共同构成律藏注疏的纵深体系。

## 二、文本结构与核心思想

此注覆盖整部《律藏》：从经分别（波罗提木叉条文）到犍度（僧团制度诸章）皆有系统注释，注释体例与觉音经注一致——先释名相，再解缘起（制戒因缘），后辨开遮持犯。原档案所录序偈是其精神纲领：「彼能除惡者，是名為律；正覺者以此律，照亮了長劫輪迴。為解釋此律之義，今造《善見律毗婆沙》，增長智者與心寂靜者之戒行。」此颂以词源训释开篇：律（vinaya）之得名，正由「调伏」（vinaya 为动词「除灭恶法」义），律的功能被定义为照亮轮回长夜的灯。

注释思想中最具理论意义的，是觉音对教义权威层级的区分。按原档案所引：阿闍梨说（Ācariyavāda）即注释传统，由参与第一次结集的五百阿罗汉所保持与裁定，凌驾于经文表面之上；而上座说（Theravāda）在此语境下等同于 attanomati（个人独立见解），权威性不及阿闍梨说。这一区分表面上出乎意料——今日「上座部」自命正统的 Theravāda 一词，在觉音笔下竟指「长老个意见」——它揭示了上座部权威体系的真实结构：以结集裁定、代代相承的注释传统为最高准据，个人的义理推论居其次。注释书之所以必须存在、必须被研习，正在于此：三藏若无注释传承，便无法保证理解的正确性。

## 三、学术研究价值与争议

研究价值方面：第一，此注是理解巴利律藏的钥匙——律条文句极简，无数制戒缘起、开遮细节全赖注释传承，南传僧团今日的实际运作（从受戒程序到雨安居制度）仍以此注及后续注疏为依；第二，注释中保存了大量古代印度与锡兰的僧团制度、地理、风俗信息，是佛教制度史与社会史的重要材料；第三，觉音的权威层级论为研究早期佛教「经典与注释」关系提供了理论标本；第四，此注与汉译《善見律毗婆沙》的对勘，是跨语言文献学的经典课题。

争议问题方面：其一，汉巴关系问题——汉译《善見律毗婆沙》（T1462）是否即巴利 Samantapāsādikā 的对应译本，学界长期讨论：两者结构内容既有大面积对应，又有明显出入，一般认为汉译所据为巴利本之外另一部派的律注或其异传本，此点至今无定论；其二，觉音改写的性质——僧伽罗语旧注已佚，觉音是忠实翻译还是大量增删改写，直接决定此注作为「早期注释传统证据」的可信度；其三，序偈与「五百结集裁定」的叙事属于注释传统的自我论证，其历史性需要批判性对待；其四，权威层级论在后世的上座部文献学中并非无争议，不同时期的注家对「注释与经文何者优先」实际上存在摇摆。需要说明：此书属巴利藏外注疏系统，汉译本虽入大正藏，但巴利原典的引用仍应以 PTS 校勘本为基准。

## 四、术语对照表

| 术语 | 释义 |
|------|------|
| 善見律毗婆沙（Samantapāsādikā） | 觉音所造巴利律藏全注，汉译本 T1462 与之关系复杂 |
| 律（Vinaya） | 音译毗奈耶，僧团纪律与生活规范的总集，词源义为「调伏」 |
| 觉音（Buddhaghosa） | 五世纪上座部注释传统集大成者，据僧伽罗语旧注重撰巴利注疏 |
| 大寺（Mahāvihāra） | 锡兰阿努拉达普拉的上座部正统僧团，觉音注释的资助者 |
| 阿闍梨说（Ācariyavāda） | 注释传统、师承之说，觉音视为由结集五百罗汉确立的最高权威 |
| 上座说（Theravāda） | 觉音语境中指长老个人见解（attanomati），权威低于注释传统 |
| 波罗提木叉（Pātimokkha） | 比丘、比丘尼戒条目总集，每半月诵念 |
| 犍度（khandhaka） | 律藏中关于受戒、安居、衣物等僧团制度的分章 |
| 复注（ṭīkā） | 对注释书再作注释的后出文献层次 |
| 戒（sīla） | 修行三学之首，此注自言其功能在于「增长智者之戒行」 |
