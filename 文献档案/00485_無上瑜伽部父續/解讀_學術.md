# 無上瑜伽部父續 — 学术解读

## 一、文献背景与成书

无上瑜伽部（Anuttarayoga Tantra）父续，以《密集金刚续》（Guhyasamāja Tantra，意译「秘密集会」）为根本经典，密集金刚因此被称为「无上瑜伽部父续之王」。相传释尊于印度西方乌仗那（Uḍḍiyāna）为恩扎菩提王说密集本续，现起金刚持身而为灌顶，复由金刚手善为讲释。梵本今存，藏译本为藏传各派共同尊奉的根本续典；汉译相当本为北宋施护于1002年译出的《佛说一切如来金刚三业最上秘密大教王经》七卷（T833，略称《七卷教王经》），全经十八分，与梵、藏本的十八分结构相当，是汉译文献中少见的无上瑜伽根本续。密集亦位列「藏密五大金刚」，且为格鲁派三大本尊之一、宗喀巴大师之守护本尊。其解释传统以龙树一系为最：龙树《释菩提心论》即解释密集续之重要论典，月称《明炬释》（Pradīpoddyotana）为根本注释；宗喀巴从布顿大师高足法胜受学密集法类，著有《密集金刚生起次第广论》《圆满次第广论》等。

## 二、文本结构与核心思想

父续之「父」，指其以方便（upāya）为主导，与以智慧为主导的母续相对，这是藏传佛教对无上瑜伽内部的经典分判：密集（父续代表）特重生起次第与圆满次第中「幻身」（māyādeha）与「光明」（prabhāsvara）之修持，胜乐、喜金刚（母续代表）则特重俱生大乐与气脉明点之圆满次第；时轮被判为「无二续」，兼摄二者。本档案所选龙树《释菩提心论》颂「远离诸实物；蕴界及入处；灭所持能持；法无我同性。自心本不生，是空之体性」，揭示了密集体系的心髓：远离五蕴、十八界、十二处的实执，能缘之心与所缘之境双双寂灭，胜义菩提心即俱生原始光明心性。而恩扎菩提王的因缘故事——「我愿不舍俗装，亦能成佛」，佛遂于王宫布设曼陀罗授以灌顶——则表达了父续「不舍世间而证解脱」的在家成佛教义，与「现生证得双运身佛果」的即身成佛理想。

## 三、学术研究价值与争议

其一，文献学价值：密集续是少数梵、藏、汉三系文本俱全的无上瑜伽根本续，T833 与梵藏本的对勘为续典成立史研究提供了不可替代的样本；学界一般认为密集续成立较早（约7至8世纪），堪称无上瑜伽续的先驱。其二，思想史价值：龙树中观学派与密集续的「嫁接」（龙树被奉为密集传承祖师），是研究中观义理如何被仪式化、瑜伽化的关键案例，牵涉「释菩提心论」是否龙树真作的长期争论。其三，争议问题：父续母续的分判标准，藏传各派依于不同注释传统而有「以主尊分」「以教义侧重分」「依所化根器分」诸说；宗喀巴在《密宗道次第广论》中的判释（父续重幻身、母续重光明）成为格鲁派标准学说，但宁玛、萨迦的判教立场与之不尽相同。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 父续 | 无上瑜伽中以方便（慈悲行动）为主导的一类续典，代表为密集 |
| 密集金刚（Guhyasamāja） | 意译「秘密集会」，父续之王、藏密五大金刚之一 |
| 幻身（māyādeha） | 由最细气所成、如幻之佛身，父续圆满次第的核心证量 |
| 光明（prabhāsvara） | 心之本性本自光明，死亡与禅定中自然显现 |
| 双运身 | 幻身与光明双运之果位，即身成佛的最终形态 |
| 金刚持（Vajradhara） | 密法法统之源的报身佛，灌顶现起之本尊相 |
