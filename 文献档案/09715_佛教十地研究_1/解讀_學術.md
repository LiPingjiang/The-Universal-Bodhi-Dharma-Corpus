# 佛教十地研究 — 学术解读

## 一、文献背景与成书

本条目为语料库「寰宇覺海·菩提法藏」之独立文献补充条目，编号 X8201，目录名作「佛教十地研究_1」。据实说明：其《原文》非经论传本，而是十地名数的主题辑录，概述列「歡喜地、離垢地、發光地、焰慧地、極難勝地、現前地、遠行地、不動地、善慧地、法雲地」十名，选录与名句各存两条引文，术语表八条（止于远行地），末附相关文献指引。与姊妹条目 `09216_佛教十地研究` 所录文字全同，可知为同一底稿在语料库不同编号位的分置；条目 README 自署「待後續填充內容」，性质均为名目型简编。本条目拟专就十地阶位的断惑证真结构与诸宗诠释差异作分析，与前条之经典源流考述分工互补。

十地体系见《华严经·十地品》（单品别行称《十地经》），其阶位结构的义理定型则赖天亲《十地经论》：以十地为菩萨见道之后修道位的十个阶位，配大乘五位（资粮、加行、见、修、究竟）中之修道位。汉传通义以初地入见道、证遍行真如，二地以上属修道，至十地满心入究竟位；每一地各有「入、住、出」三分，各有当地所断之障、所证之真如、所修之行。

## 二、文本结构与核心思想

《原文》五节为补充条目通例，兹按阶位结构逐地析其断证。

**初欢喜地**：初入见道、亲证二空所显真如，断异生性障，证遍行真如，成就檀那（布施）波罗蜜增上，故「出生大願」，引文「以十盡句不可盡故，發大悲心」正当地愿藏之义——初地十大愿皆依众生界、世界、法界等十种无尽而立，愿与所缘俱无尽。

**二离垢地**：断邪行障，证最胜真如，戒度增上，任运不犯微细戒。

**三发光地**：断暗钝障，证胜流真如，忍度增上，成就闻持陀罗尼，法光发出。

**四焰慧地**：断微细烦恼现行障，证无摄受真如，精进度增上，修道觉分烧烦恼薪。

**五极难胜地**：断于下乘般涅槃障，证类无别真如，禅度增上，真俗二智合观，极难胜过。

**六现前地**：断粗相现行障，证无染净真如，般若度增上，缘起还灭智现前。

**七远行地**：断细相现行障，证法无别真如，方便度增上，纯无相观相续，超过二乘行。

**八不动地**：断于无相中作加行障，证不增减真如，愿度增上，无功用行任运而转，一切烦恼不复现行。

**九善慧地**：断于一切说法妙智愚痴障，证智自在所依真如，力度增上，得四无碍辩。

**十法云地**：断大法智不得自在障，证业自在所依真如，智度增上，大法智云充法界，受灌顶职。

统而观之，十地配十度、断十障、证十真如（此「十真如」依唯识系《成唯识论》卷九之判）——阶位（地）、功课（度）、病（障）、药（真如）四线并进，构成严整的修道矩阵。引文「於一一地中，修行萬行，漸次增進」即此结构之总相。

## 三、学术研究价值与争议

第一，初地证空的阶位判分是唯识与中观诠释分歧的焦点之一：唯识系以初地始证二空真如（见道），中观应成系依《入中论》亦判初地证空性，而于二谛之安立与所断障之细目各有不同施设；汉传华严家则以圆教义释十地（行布门与圆融门不二），「初发心时便成正觉」之说更把阶位的渐次性收摄于当下圆顿。同一张十地图，三系读出三种修道论，是研究大乘修行观比较的绝佳标本。

第二，「十盡句」的文本考证。《十地经》欢喜地十大愿所依十无尽句（众生界尽、世界尽、虚空界尽、法界尽、涅槃界尽、佛出界尽、如来智界尽、心所缘界尽、佛智所入境界尽、世间转法转智转界尽），其数目与名目在各汉译本（《渐备经》《十住经》《十地经》）及梵本之间小有出入，本条目引文唯存「十盡句不可盡故」一语而不列名目，为辑录之简。

第三，十地说与菩萨戒、佛身论的系统关联：《菩萨地持经》与《瑜伽师地论·菩萨地》把十地纳入菩萨戒的位次与受用；佛果三身又以十地圆满为因。故十地实为大乘修道论的中枢节点。又藏传依《入中论》系之十地说（初地得百法明门、一刹那化百身等增上百百之义）另有发挥，其根本论典不在大正藏编号体系之内，应转检德格版《丹珠尔》编目。
