# 佛教四梵住研究_3 — 学术解读

## 一、文献背景与成书

本条目是语料库「研究」系列的主题类条目，编号 06604。原文档为名目与节引式体例，仅存文献概述、两段引文、术语对照表与相关文献链接，并非一部传世典籍，因此不设成书年代的考订，而围绕「四梵住」这一主题在佛教文献史中的可考源流作综述。

四梵住指慈、悲、喜、舍四种心的修习，在早期契经中原型已具。《杂阿含经》与巴利《增支部》中均见佛以「慈俱之心」教导比丘，并将慈、悲、喜、舍四者与「无量」相连接——四者皆以一切众生为所缘，量不可测，故通称四无量心。条目引文「犹如精进牛师子之子，于空处、树下、露地，以慈心遍满一方而住」，保留了阿含部类禅修教导中独处树下、逐方扩展慈心的古老风格。

至于「梵住」这一名义，原文档第二段引文给出的解释极为直白：「修此四者，得生梵天，故名梵住。」即以修行果报立名——成就此四心者感生梵天界。这一得名逻辑与后世论书的整理相符：《清净道论》在辨析「梵住」一名时，同样列出生梵天、如梵天而住、与梵天相应诸义。需要注明的是，原文档术语表中「Appamāṇa-cetta（无量心）」的拼写与通行巴利形式略有出入，此处依原文档著录。

同库中另立有同名条目 `06628_佛教四梵住研究_3`，其原文与本条目所据底本相同，属同系列重复设目。本条目侧重名义考辨与经典源流，彼条目侧重修行次第与实践角度，两相分工并互注，读者宜对照阅读。

## 二、文本结构与核心思想

原文档以一句概述总起——「以慈心、悲心、喜心、舍心遍满一切世间」，点明四梵住的两个要素：四种心的品质，与「遍满一切」的扩展方式。

四者的分工是理解四梵住的关键：慈，愿众生得乐；悲，愿众生离苦；喜，见众生安乐而随喜；舍，于亲怨损益之间保持平等不动。四者并非四种互不相干的善心，而是一组相互支撑、层层校准的心理功能——慈近于主动的给予，悲近于面对苦难的承担，喜对治见他人得意时的嫉妒，舍对治因亲疏而生的偏心。引文「遍满一方」的修法则显示其操作特征：从东方起，逐方扩展，以十方一切众生为所缘，无有界限。

「得生梵天」一句提示了四梵住在早期经典中的定位：它首先被叙述为导向色界梵天果报的殊胜善心，与禅定力相应；在阿毗达磨系统中，四无量则被安排为与色界定相应的「无量心所」，并辨析其行相差别——慈与悲以众生离苦得乐为所缘，喜以众生有乐为所缘，舍以业自理为所缘。原文所录经、论两段引文，恰好呈现了四梵住从经证教导到论书定义两个层面的资料。

## 三、学术研究价值与争议

第一，「梵住」与「无量心」两个名称的关系，是概念史研究的一个焦点。以果报立名称「梵住」，以所缘立名称「无量」，同一组修法在经、论中呈现不同的命名视角，为观察早期佛教名相的层累提供了一个干净的样本。

第二，四梵住究竟导向禅定还是导向解脱，历来存在诠释张力。原文档明言其果报在梵天，即传统上视为有漏的人天善法；而《清净道论》以来的南传传统将四梵住纳入定的修习次第，近现代缅甸禅修传统更以慈心禅为主要入定门径之一，其摄受现代在家信众的功能远超「生梵天」的古义。大乘佛教则对之作空性化的改造，以「无缘大慈、同体大悲」转化四无量与「无量」之所缘，成为菩萨行的核心内容。

第三，就伦理思想而言，四梵住被视为佛教对「何为完善的情感」的系统回答，近代以来常与基督教的爱、休谟的同情学说等进行比较研究，也是当代慈心禅科学化研究（如慈心禅与积极情绪、人际关系测量的对照实验）的经典文本基础。

## 四、术语对照表

| 梵/巴语 | 汉语 | 英译 |
|---|---|---|
| Brahmavihāra | 梵住 | Brahma abode |
| Metta | 慈 | loving-kindness |
| Karuṇā | 悲 | compassion |
| Muditā | 喜 | sympathetic joy |
| Upekkhā | 舍 | equanimity |
| Brahmaloka | 梵天 | Brahma realm |
| Appamāṇa-cetta | 无量心 | immeasurable mind |

其中 Metta 为巴利语，对应梵语 Maitrī；「Appamāṇa-cetta」依原文档著录，通行巴利形式作 appamāṇa（无量），与「cetasā（以心）」连用时作词格变化。
