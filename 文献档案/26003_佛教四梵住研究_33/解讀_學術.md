# 佛教四梵住研究_33 — 学术解读

## 一、文献背景与成书

本目录为语料库中「四梵住」主题的编纂条目，所属 README 标注编号 X24489、性质为「補充文獻」且「待後續填充內容」，可知立项之初仅为名目；现存的原文档以「概述—选段—名句—术语表—相关文献」的辑录体例，围绕慈、悲、喜、舍四种心汇编而成，并非某一特定藏经文本的照录。此类条目的价值在于取样：所录「猶如精進牛師子之子，於空處、樹下、露地，以慈心遍滿一方而住」一句，句式与巴利经藏中勉励独处比丘修慈的定型句相应，「遍滿一方而住」正是南传经典反复使用的修慈套语，冠以「精進牛師子之子」的譬喻则近于《相應部》《增支部》激励禅者的语调；另一段「四梵住者，謂慈、悲、喜、捨。修此四者，得生梵天，故名梵住」为释名式定义，近于觉音《清淨道論》对梵住一语的训释。北传论典中此法多立名为四无量或四等心，如《俱舍論》卷二十九、《大智度論》卷二十均以「四無量」立名；本条目既以「梵住」为名、以南传定型句为主体，解读即依此南传色彩展开。同名条目另有 `26027_佛教四梵住研究_33`，彼篇侧重四无量心在北传论典与大乘菩萨道中的开展，本篇侧重南传巴利传统中的修习次第与禅定配属，两篇互注分工、互参可窥两大传承的全貌。

## 二、文本结构与核心思想

原文档分概述、选录、名句、术语、相关文献五部分。概述「以慈心、悲心、喜心、捨心遍滿一切世間」点出四梵住的两个要素：心的品质与遍满的操作。选录第一段给出修习的场景与动作——于空处、树下、露地，以慈心遍满一方而住；第二段给出定义与果报——修此四者得生梵天。核心思想可从三个层面把握。其一，四心的对象与对治各有分工：慈是与乐之愿，对治瞋恚；悲是拔苦之愿，对治伤害；喜是随喜他荣，对治嫉妒；舍是平等不动，对治贪爱与偏袒。其二，修习以「遍满」为方法：先向一方，再遍四方上下，使心广大无量、无有怨亲之隔，此即术语表中「無量心」一名的由来。其三，在南传体系中四梵住与禅定层次相配：《清淨道論》说慈、悲、喜三住可达三禅，舍住与四禅相应，因为舍心本身即四禅的主导禅支。故梵住虽以生梵天为果报，其修习机制却深嵌于色界禅体系之中，属「世间的」功德，须与出世间慧观衔接方得解脱。

## 三、学术研究价值与争议

学术讨论的焦点有三。其一，源流问题：有学者认为慈悲喜舍的编组吸收了婆罗门教梵天信仰的元素，「梵住」之名本身即暗示与梵天世界的衔接，佛教将其伦理化、心理化为心的训练；亦有学者主张这是佛教自身禅修体系的内生发展，生梵天只是通俗化的果报许诺。其二，名目与传承的差异：南传称梵住、北传多称无量，前者重居所与果报，后者重心的度量；大乘进一步将其与菩提心、空性见结合，使「无量」从禅定功德转为悲智双运的菩萨行。其三，舍住的定位：舍在四梵住、七觉支、五禅支中反复出现，其于此处究竟是旁观式的平静还是主动的中正，注疏间理解不同，《清淨道論》以对众生业果负责性保持中立释之，影响深远。本条目以南传定型句与定义式偈语并列，为比对两大传统的表述提供了简明样本。
