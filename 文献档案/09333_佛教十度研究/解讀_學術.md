# 佛教十度研究 — 学术解读

## 一、文献背景与成书

本条目为语料库「寰宇覺海·菩提法藏」之独立文献补充条目，编号 X7819，名目作「佛教十度研究」。据实说明：其《原文》非经论传本，而是十度名数的主题辑录，概述列「布施、持戒、忍辱、精進、禪定、般若、方便、願、力、智」十名，选录与名句各存两条引文，术语表八条。与姊妹条目 `09277_佛教十度研究` 所录文字全同，可知为同一底稿在语料库不同编号位的分置；条目 README 自署「待後續填充內容」，性质均为名目型简编。本条目拟专就十度中后四度——方便、愿、力、智——的义涵与经典依据作逐目疏解，与前条之总纲考述分工互补。

后四度的成立见《解深密经·地波罗蜜多品》：佛告观自在菩萨，于六度外更立四波罗蜜多为助伴；此后《摄大乘论》卷中、《成唯识论》卷九皆有定释。其名相的梵语原词，汉译诸家略有出入：方便作 Upāya 或 Upāya-kauśalya（善巧方便），愿作 Praṇidhāna，力作 Bala，智作 Jñāna（此「智」与般若 Prajñā 在唯识系统中判然两名：般若为根本智之总称，此智为后得智之别目）。

## 二、文本结构与核心思想

《原文》五节为补充条目通例，兹逐目疏解后四度。

**方便波罗蜜（Upāya）**：《解深密经》释为「如所通达，为诸众生宣说法要」，谓依自己所证之理而善巧为他说法；唯识家又分回向方便（以善根回向菩提）与拔济方便（济度众生）二相。其与「般若」的分工：般若自证空性，方便善知机宜——一切「应机施教」的实践皆摄于此度，包括《法华经》开权显实、会三归一的种种施设。

**愿波罗蜜（Praṇidhāna）**：谓发弘誓愿摄受当来果报。经典细分为二：求菩提愿（愿证无上觉）与利乐他愿（愿度有情）。愿在修行结构中的功能是「定向与续航」：由愿力故，所修诸善不散不失，如 GPS 之于航行；弥陀四十八愿、药师十二大愿皆是此度的典型产物，净土法门的成立即以此度为枢纽。

**力波罗蜜（Bala）**：《解深密经》说二种力：思择力（以慧思择简择诸法之观察力）与修习力（由数数修习所成之堪能力）。其义在「由解入行」的转化：思择力属见地层面，修习力属定慧固化层面；一切「道理懂了却做不到」的落差，正是此度所要填平的沟。

**智波罗蜜（Jñāna）**：谓于一切所知、一切品类、一切时处无碍而转之后得智；唯识家又配「受用法乐、成熟有情」二用。其与前智之分：般若为如所有性智（照真），此智为尽所有性智（照俗）——于世间学问、众生根性、工巧技艺之善知，皆此度所摄，故《华严》《维摩》说菩萨当学五明，正归此度。

统而观之，后四度皆为般若之起用而立：方便是般若对「机」的善巧，愿是般若对「向」的锁定，力是般若对「行」的落实，智是般若对「境」的了达——引文「六度為體，四度為用」的判释在此得其条贯。

## 三、学术研究价值与争议

第一，十度的名数成立是判别唯识与中观文献立场的一个便利指标：中观系月称《入中论》以六度配十地而于后四度不别立目（后四功能摄入般若与方便二目），唯识系则十目并立。两系的差异不是数量之争，而是「后得智的行相是否须分类」的方法论分歧，对研究中观瑜伽行派的论争史有标本意义。

第二，「方便」一度的诠释张力。方便在经中最著名的表述即《法华经·方便品》「諸佛所得法，無量方便力，為眾生演說」；但「方便」一词在佛教史上的滥用（如密教的善巧方便、后世对戒律的便宜开许）也引发「方便出下流」的内部批评。学界对 upāya 概念从般若经到密教文献的语义漂移已有专书研究，本条目唯存名目，读者宜于此延长线上理解其重量。

第三，「愿」度的宗教社会学意义。愿力概念把「誓愿—成就」的因果模式引入佛教（本愿思想），是大乘净土教团得以成立的义理发动机；其与印度教中誓愿（vrata）观念的比较、与基督教恩典观的比较，均是比较神学的成熟论域。又藏传《现观庄严论》系以十度配三智而入广大行，相关藏文根本论典不在大正藏编号体系之内，应转检德格版编目。
