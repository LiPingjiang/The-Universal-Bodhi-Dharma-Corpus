# 大乘起信論義記

## 一、概述

**大正藏編號**：T1846（《大正新脩大藏經》第 44 冊）

**撰者**：唐·法藏（643—712），賢首大師，華嚴宗三祖

**卷數**：三卷（後世會本或作五卷、七卷）

**別稱**：《起信論義記》《大乘起信論疏》《藏疏》《賢首疏》

**所釋論本**：《大乘起信論》一卷，馬鳴造，梁·真諦譯

《大乘起信論義記》是法藏以華嚴宗立場註釋《大乘起信論》的代表作，與隋·慧遠《義疏》、新羅·元曉《海東疏》並稱「起信論三大疏」，而以此疏流行最廣、影響最深。

本書與《大乘起信論疏》（T1844）實為同一部著作的兩個題名（詳見 01341 篇的版本說明）。為避免重複，**01341 篇側重其序文與十門懸談的架構、四宗判教立場**；**本篇則側重其對《起信論》正文核心義理的逐段疏釋**——即一心二門、三大、覺與不覺、三細六粗、四種熏習等。

本疏在義學上有幾項為前人所未及的創見：

1. 明指《起信論》的「阿梨耶識」即唯識家所說的「阿賴耶識」，會通如來藏與唯識二系。
2. 將三細中的業相、能見相、境界相，依次配屬唯識的自體分（自證分）、見分、相分。
3. 指出智相以下六粗通於第六意識，並明白指出《起信論》只舉第六識與第八識，而未論及第七末那識。

版本流傳上，此疏原為三卷，論文另有單行本。唐代宗密將疏與論文會合刊行，但刪削頗多。宋以降世人多知宗密疏而不知法藏原疏。後日僧鳳潭重新考訂會合本為五卷，盛行於世。清·楊文會感於原書遭割裂，別求古本讎校，刊為七卷會本，頗受學界重視。

## 二、核心段落

### （一）立義分：法與義

**《起信論》原文：**

> 摩訶衍者，總說有二種。云何為二？一者法，二者義。所言法者，謂眾生心。是心則攝一切世間法、出世間法，依於此心顯示摩訶衍義。

**白話對照：**

所謂「摩訶衍」（大乘），總的來說有兩種。哪兩種呢？一是「法」，二是「義」。

所說的「法」，指的是眾生心。這個心就統攝了一切世間法與出世間法；依託於這個心，便能顯示出大乘的義理。

**法藏疏釋要義：**

法藏指出，此處立「眾生心」為大乘之法體，正是《起信論》異於他宗之處。不說「佛心」而說「眾生心」，正因此心在凡不減、在聖不增；一切世間出世間法皆不出此心之外，故稱為「大」。

### （二）一心開二門

**《起信論》原文：**

> 顯示正義者，依一心法有二種門。云何為二？一者心真如門，二者心生滅門。是二種門皆各總攝一切法。此義云何？以是二門不相離故。

**白話對照：**

所謂顯示正義：依於這一心之法，開出兩種門。哪兩種呢？一是「心真如門」，二是「心生滅門」。這兩種門各自都能總攝一切法。

為什麼這樣說呢？因為這兩門並不是彼此分離的緣故。

**法藏疏釋要義：**

法藏強調「皆各總攝一切法」與「二門不相離」兩句是全論樞紐。真如門是就一心的不生不滅之體而說，生滅門是就一心的隨緣起動之相而說；但並非有兩個心，也不是把一個心切成兩半。真如門攝一切法者，以一切法即真如故；生滅門攝一切法者，以一切法皆生滅相故。二門互攝，正是「不變隨緣、隨緣不變」在論典結構上的落實。

### （三）心真如門

**《起信論》原文：**

> 心真如者，即是一法界大總相法門體。所謂心性不生不滅，一切諸法唯依妄念而有差別；若離妄念，則無一切境界之相。是故一切法從本已來，離言說相，離名字相，離心緣相，畢竟平等，無有變異，不可破壞，唯是一心，故名真如。

**白話對照：**

所謂心真如，就是那唯一法界的、統攝一切總相的法門本體。也就是說：心的體性本自不生不滅，一切諸法只是依託妄念才顯現出種種差別；如果離開妄念，那就沒有任何境界之相可得。

因此一切法從本以來，就遠離言說之相，遠離名字之相，遠離心所攀緣之相，畢竟平等一如，沒有變異，不可破壞，唯是這一心而已——所以名為「真如」。

### （四）覺與不覺

**《起信論》原文：**

> 所言覺義者，謂心體離念。離念相者，等虛空界，無所不遍，法界一相，即是如來平等法身。依此法身說名本覺。何以故？本覺義者，對始覺義說，以始覺者即同本覺。

**白話對照：**

所說的「覺」的意義，是指心體遠離妄念。那離念之相，等同於虛空界，無處不遍；整個法界唯是一相，這就是如來平等的法身。依於這法身，便稱之為「本覺」。

為什麼呢？因為「本覺」這一概念，是相對於「始覺」而安立的；而所謂「始覺」，其實就等同於本覺。

**法藏疏釋要義：**

法藏於此處分析極為精細。他指出：本覺是眾生本有的清淨覺性，並非修行新得；始覺是依本覺之熏習力而發起的覺悟，是修行所顯。始覺究竟圓滿之時，便與本覺完全冥合，故云「始覺即同本覺」——這說明修行不是製造一個新的佛，而是回復本有的覺性。「不覺」則是不如實知真如法一故而妄念忽起，並無獨立自體，依本覺而有。

### （五）三細

**《起信論》原文：**

> 復次，依不覺故生三種相，與彼不覺相應不離。云何為三？
> 一者無明業相。以依不覺故心動，說名為業；覺則不動，動則有苦，果不離因故。
> 二者能見相。以依動故能見，不動則無見。
> 三者境界相。以依能見故境界妄現，離見則無境界。

**白話對照：**

其次，依於不覺而生起三種相，這三相與那不覺相應而不相分離。哪三種呢？

第一，**無明業相**。因為依於不覺而使心動，這就叫做「業」；若覺悟了則心不動，一動就有苦，因為果不離因的緣故。

第二，**能見相**。因為依於心動所以有能見，若心不動則沒有能見。

第三，**境界相**。因為依於能見所以妄現出境界，若離開能見則沒有境界。

**法藏疏釋要義：**

法藏在此作出本疏最具創見的判斷：以三細配屬唯識三分——業相配自體分（自證分），能見相配見分，境界相配相分。此舉正式打通了如來藏系與唯識系的識論術語，是中國佛教會通兩系最重要的一步。

### （六）四種熏習

**《起信論》原文：**

> 熏習義者，如世間衣服實無於香，若人以香而熏習故，則有香氣。此亦如是。真如淨法實無於染，但以無明而熏習故則有染相；無明染法實無淨業，但以真如而熏習故則有淨用。

**白話對照：**

所謂「熏習」的意思，好比世間的衣服本身實在沒有香氣，如果有人用香去熏它，它就帶上了香氣。這裡的道理也是這樣。

真如這清淨之法本來實在沒有染污，只因無明的熏習，所以才顯現出染污之相；無明這染污之法本來實在沒有清淨的作用，只因真如的熏習，所以才生起清淨的功用。

**法藏疏釋要義：**

《起信論》立四種熏習：無明熏習、妄心熏習、妄境界熏習（此三為染法熏習），以及真如熏習（淨法熏習）。法藏於此詳加疏解，特別闡明「真如熏習」之義——這是《起信論》與唯識學最大的分歧點：唯識家主張真如凝然不作諸法、不受熏亦不能熏，而《起信論》主張真如能熏無明，這正是眾生得以發心修行、終能成佛的內在根據。法藏站在如來藏緣起宗立場，堅決維護真如受熏能熏之說。

### （七）三大

**《起信論》原文：**

> 所言義者，則有三種。云何為三？一者體大，謂一切法真如平等不增減故；二者相大，謂如來藏具足無量性功德故；三者用大，能生一切世間出世間善因果故。

**白話對照：**

所說的「義」，則有三種。哪三種呢？

第一，**體大**——指一切法的真如平等一如，不增也不減。

第二，**相大**——指如來藏具足無量的性德功能。

第三，**用大**——指它能生起一切世間與出世間的善因善果。

### （八）止觀雙運

**《起信論》原文：**

> 云何修行止觀門？所言止者，謂止一切境界相，隨順奢摩他觀義故；所言觀者，謂分別因緣生滅相，隨順毗缽舍那觀義故。云何隨順？以此二義漸漸修習，不相捨離，雙現前故。

**白話對照：**

怎樣修行止觀門呢？所說的「止」，是指止息一切境界之相，這是隨順奢摩他（寂止）的觀行意義；所說的「觀」，是指分別觀察因緣生滅之相，這是隨順毗缽舍那（勝觀）的觀行意義。

怎樣叫做隨順呢？就是把這兩種意義漸漸修習，使它們互不捨離，雙雙現前。

## 三、名句

**其一**

> 一切諸法唯依妄念而有差別；若離妄念，則無一切境界之相。

一切法只是依託妄念才顯現出種種差別；若能離開妄念，就沒有任何境界之相可得。

此為《起信論》「心真如門」的核心命題，法藏於此著墨最深。它一方面否定了外境的實有性——差別相唯依妄念而立；另一方面又不落斷滅——所離者是「妄念」而非「心體」。這一句是後世禪宗「無念為宗」、華嚴「一真法界即一心」乃至宋明理學心性論的共同思想資源，在中國思想史上的輻射範圍遠超佛教之外。

**其二**

> 本覺義者，對始覺義說，以始覺者即同本覺。

「本覺」這一概念是相對於「始覺」而安立的，而所謂「始覺」，究竟處便等同於本覺。

這是解決「本來是佛，何須修行」這一根本詰難的關鍵。法藏藉此說明：修行並非在本覺之外新造一個覺，始覺的全部內容就是本覺的自我顯現；然而若無始覺之功，本覺終不能顯。既保住了「眾生本來是佛」的頓悟義，又保住了「必須修行」的漸修義。宗密日後倡「頓悟漸修」，其理論根據正在於此。

## 四、術語表

| 術語 | 說明 |
|-----|------|
| **摩訶衍** | 梵語 Mahāyāna 的音譯，即「大乘」。《起信論》開篇立摩訶衍之法與義。 |
| **眾生心** | 《起信論》所立的大乘法體，即如來藏心、一心。攝一切世間出世間法。 |
| **一心二門** | 依一心開心真如門與心生滅門。二門各總攝一切法而不相離，是《起信論》的根本架構。 |
| **心真如門** | 就一心不生不滅的體性而立。離言說相、離名字相、離心緣相，畢竟平等。 |
| **心生滅門** | 就一心依無明而有生滅流轉之相而立，即阿梨耶識所攝。 |
| **三大** | 體大、相大、用大。分別指真如平等不增減、如來藏具足性功德、能生世出世間善因果。 |
| **本覺** | 眾生本自具足的清淨覺性，即心體離念、等虛空界的如來平等法身。 |
| **始覺** | 依本覺熏習之力而發起的覺悟，屬修行所顯。究竟時即同本覺。 |
| **不覺** | 不如實知真如法一而妄念忽起的迷惑狀態。無獨立自體，依本覺而有。 |
| **三細** | 無明業相、能見相、境界相。依不覺而起的三種微細心相。法藏配以唯識自體分、見分、相分。 |
| **六粗** | 智相、相續相、執取相、計名字相、起業相、業繫苦相。依境界緣而起的六種粗顯心相。法藏判其通於第六意識。 |
| **四種熏習** | 無明熏習、妄心熏習、妄境界熏習（染法三種）與真如熏習（淨法一種）。 |
| **真如熏習** | 《起信論》特有之說：真如能熏無明而起淨用。與唯識家「真如凝然不作諸法」之說根本相異，是眾生能夠發心成佛的內在根據。 |
| **阿梨耶識** | 《起信論》生滅門中依如來藏而有的心識。法藏明指其即唯識家的阿賴耶識，並指出本論唯舉第六、第八識而不論第七識。 |
| **奢摩他／毗缽舍那** | 梵語 śamatha（止、寂止）與 vipaśyanā（觀、勝觀）的音譯。五行中止觀門的兩面，須雙運現前。 |
