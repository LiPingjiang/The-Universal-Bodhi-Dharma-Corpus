# 佛教三论宗谱_1 — 学术解读

## 一、文献背景与成书

该条目是「寰宇覺海·菩提法藏」档案体系中的独立补充条目，档案编号 X7940，所属 README 中明确标注「待後續填充內容」。本目录的 原文.md 目前只是一种「名目加概述」式的提要模板，并非一部传世古籍的完整录文：全文除标题外，仅有一行概述——「依《中論》《十二門論》《百論》立宗，吉藏大師大成」——以及两段编者自拟的宗旨概括、一张术语对照表和两条库内链接。因此，这是一条以三论宗为主题的综述性条目，整理时只能就可考的背景撰文，不得将其当作古籍本体征引。

需要说明的是，「佛教三論宗譜」并非汉文大藏经中实际存在的书名。传世文献中与三论宗直接相关的核心撰述，是隋代吉藏（549—623）的《三論玄義》《大乘玄論》《二諦義》《中觀論疏》等；「三论宗」则是后世对依三部论典立宗这一学派的习惯称谓。本解读以原文档定名为准，同时注明它与通行定名之间的出入。

档案语料库中「佛教三論宗譜」是一个同名多目录系列：本批十八个条目（`09454_佛教三論宗譜_1` 至 `18056_佛教三論宗譜_18`）各自独立成篇、互为参照；更早的两批同名系列自 `02889_佛教三論宗譜_1` 与 `05235_佛教三論宗譜_1` 起，另有总览条目 `02710_佛教三論宗譜`。以「谱」字连缀成系的编法，本身即模仿了中国佛教以谱牒记宗派源流的传统。

就史实而言，三论宗的轮廓大致如下：思想渊源于印度龙树、提婆的中观学；经鸠摩罗什于后秦弘始年间（五世纪初）在长安译出三部论典，门下僧肇等弘扬「关河旧义」；再经南朝摄山一系（僧朗、僧诠、法朗）相承，至隋代吉藏判教立宗、著述宏富而告大成。唐初此宗与唯识、天台并立，其后渐衰，法脉东传日本。

## 二、文本结构与核心思想

原文.md 现有结构分五节：文献概述、核心段落选录、重要名句、术语对照表、相关文献。「核心段落选录」所引两段文字——「三論宗者，依中論、十二門論、百論三論立宗。以無所得正觀為宗旨，破一切有所得見」与「三論以二諦為教門——俗諦明有，真諦明空。空有不二，名中道觀」——从行文风格看是档案编者对三论宗旨的概述性改写，查无传世古籍逐字对应的出处，应当作编者提要而非原典引文对待。所幸这两段概括相当准确地抓住了三论宗的三个理论支点，可以据以展开。

其一是三论立宗。宗名来自三部论书：《中論》（鸠摩罗什译，通行本四卷，大正藏编号 T1564）明一切法空，《十二門論》（一卷，T1568）被视为入空之阶梯，《百論》（二卷，T1569）以百破之数广破外道。其二是无所得正观。三论宗主张诸法毕竟空、无自性，任何「有所得」的见解——执有执无、执常执断——皆在破斥之列，唯离诸戏论的「无所得」方称正观，吉藏所谓「破邪显正」「唯破不立」即由此出。其三是二谛为教门。吉藏主张二谛是教而非理：俗谛真谛皆是佛说法的方便言教，意在令学者因教悟理、了达不二之中道，此即概述引文所谓「空有不二，名中道观」。

术语对照表列有中观、空、二谛、俗谛、真谛、吉藏、无所得七项，梵目与英译均与中观学通行学术规范一致，可视作该条目预留的学术接口。

## 三、学术研究价值与争议

此条目的价值首先在目录学层面：档案为汉传诸宗（天台、三论、成实各立其「譜」）成批建档，本批编号自 X7940 起以 506 为间距连号排布至 X16542，是考察这一档案体系编纂逻辑的标本。其次在内容层面，「依三论立宗、吉藏大成」的一行概述恰好浓缩了现代宗派史研究的基本结论，可与汤用彤《汉魏两晋南北朝佛教史》、吕澂《中国佛学源流略讲》等论著互证。

争议亦有可述者。第一，名义问题：既无传世的《佛教三論宗譜》其书，条目只能按主题综述撰写，任何将其当作古籍征引的做法都会造成虚构，本解读对此作了明确限定。第二，宗派史学本身的老问题：罗什—僧肇—僧朗—僧诠—法朗—吉藏的传承谱系中，摄山相承一段主要依据吉藏再传弟子硕法师《三論遊意義》等晚期追记，僧朗的事迹与谱系的连续性在学界均有保留意见；此外，「三论宗是否由吉藏正式创宗」也有讨论，有学者认为它更近于一个义理学派而非制度化的宗派。整理同名条目时宜将诸说并存，勿下断语。
