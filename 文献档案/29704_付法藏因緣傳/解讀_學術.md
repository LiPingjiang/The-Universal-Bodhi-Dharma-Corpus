# 付法藏因缘传 — 学术解读

## 一、文献背景与成书

《付法藏因缘传》（依原档案题名，通行或作《付法藏因缘传》六卷），北魏吉迦夜与昙曜共译，收入《大正新修大藏经》第五十册（T50, no.2058）。需要先说明名实问题：原档案于经名处标注的拉丁转写「Dharmagupta-nidāna / Upadeśa-dharmaguptaka」并非学界通用的对应名，所指当与此书叙述「法藏」（法藏部传承）或「付法」（以法相付）之因缘相关，其词源关联宜存疑待考，姑仍其旧。译经因缘颇可注意：昙曜即主持云冈石窟开凿的北魏沙门统，此书译出于平城，正是北魏皇家佛教的鼎盛期——一部讲「佛法代代相传」的书出现在新兴王朝急于建立自身法统合法性的时刻，时代动机不言自明。

此书内容为佛教付法传承的谱系叙事：从释迦牟尼涅槃、摩诃迦叶受佛付嘱结集三藏起，经阿难、商那和修、优婆毱多，一路传至师子比丘被杀为止，凡二十三（或二十四）代祖师。所谓「付法」，即前代祖师「以法付嘱」下一代继承者，使「正法眼」不灭不坏、相续不绝。

## 二、文本结构与核心思想

全书六卷的叙事骨架清晰：卷一摩诃迦叶受佛付嘱、结集三藏、入鸡足山待弥勒；卷二阿难受迦叶付嘱、传法商那和修；卷三优婆毱多化导众生；卷四提多迦至胁尊者；卷五富那奢至鸠摩罗驮；卷六阇夜多至师子比丘被杀、附佛法灭尽之预记。叙事单元高度程式化：每位祖师皆叙其得法因缘、化导功德、临终付嘱，一一衔接如珠串。

全书的思想核心在卷一与卷六首尾呼应的两段。卷一记佛付嘱迦叶：「吾以正法，付囑於汝。汝當守護，令正法眼，不滅不壞，相續不絕。」——正法不是无人格的教义集合，而是需要人格化载体（祖师）代代护持的「眼」；传承中断，即正法眼灭。卷六记师子比丘遇害时「欣然含笑」而告大众：「法之常性，無有常住。吾今付法，竟無可付。」——付法链条在他手中断绝，这一「无可付」本身被解释为法性无常的如实示现，并以佛陀预言（「師子之後，百年之中，吾法漸滅」）收束全书，为末法思想提供了经典叙事基础。

这部书由此完成了双重论证：向前，它把各部派所宗的印度祖师串成一条单线，为汉地佛教提供一个可追认的完整法统；向后，它以「法灭」预记警示当世，赋予护法、传法以紧迫感。

## 三、学术研究价值与争议

研究价值方面：第一，此书是禅宗祖师传承说的直接文献来源——菩提达摩前诸祖的世系、后来禅宗「拈花微笑—教外别传」的法统观，皆与此书系统（及其承自的《达摩多罗禅经》序等材料）相关，是研究禅宗史前史绕不开的文本；第二，它保存了师子比丘以下诸师名号与罽宾一带佛教传承的信息，对重建西北印度佛教史有价值；第三，其「末法」叙事为研究北魏至隋唐三阶教、净土教等末法思想的兴起提供了文本链条。

争议问题方面：其一，史实性问题——二十三代单线付法之说与部派分裂的史实明显不合：佛教在阿育王前后已分派多元，「一人一师」的直线传承只能是一种建构性叙事，学界公认其谱系价值属「传统叙事」而非「信史」；其二，此书与《达摩多罗禅经》慧观序所载传承的出入、与后来《景德傳燈錄》等禅宗灯史的层累演变，构成一个需要逐层剥离的文献地层；其三，师子比丘被害与「法灭」的对应，是否即暗合罽宾地区的灭法事件，所指年代与背景尚有异说；其四，北魏译场的编译性质——此书在多大程度上依据印度原典、多大程度出于昙曜一系的整合，也有讨论余地。使用时宜与《景德傳燈錄》等后世灯史对照，区分叙事层累的先后。

## 四、术语对照表

| 术语 | 释义 |
|------|------|
| 付法 | 前代祖师将正法付嘱下一代继承者的传承制度 |
| 正法眼 | 正法之「眼」，喻佛法传承的枢纽与观照之明 |
| 摩诃迦叶（Mahākāśyapa） | 佛灭后结集三藏、首承付嘱的第一代祖师 |
| 阿难（Ānanda） | 多闻第一，继迦叶之后第二代，经藏的诵出者 |
| 商那和修（Śāṇavāsa） | 第三代付法祖师 |
| 优婆毱多（Upagupta） | 第四代祖师，化导无量，称「无相好佛」 |
| 师子比丘（Siṃha） | 末代付法祖师，罽宾遇害，付法链至此而绝 |
| 罽宾 | 西北印度古地名，后数代祖师弘化之地 |
| 鸡足山 | 运尊者迦叶持佛袈裟入定待弥勒之处所 |
| 末法 | 正法灭尽之说，师子之后「百年之中吾法渐灭」的预记 |
