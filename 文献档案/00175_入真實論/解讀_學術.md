# 入真实论 — 学术解读

## 一、文献背景与成书

《入真實論》这一条目需要首先作文献学的交代。其原文档自署梵名 Tattvāvatāra，而索引卡所记梵名为 Tattvasiddhi，还原为诃梨跋摩（Harivarman）所造、五世纪鸠摩罗什汉译的十六卷《成实论》，即成实宗根本论典，阐述三世无实、二谛等思想。两说并存，本解读以原文档所述「离四句、绝百非以入真实」的论旨为据，同时如实注明索引卡与原文档在梵名还原与归属上的出入，供读者比勘。

就原文档所呈现的内容而言，本论的主旨是阐明趣入「真实」（tattva）之道：所谓真实，非由名言分别所安立，乃离四句、绝百非之法性；论中次第遣除执有、执无、执亦有亦无、执非有非无四种执著，四句既遣、戏论乃息，是名入真实；同时声明入真实非断灭，以世俗缘起不坏故。这一论旨与中观「破邪显正」的传统一脉相承，本档案原文亦将其相关文献指向《中论》《俱舍论》。

## 二、文本结构与核心思想

依原文档所录，本论的论证结构是一个「先破后立而不坏俗」的三段式。

第一段是所入的界定：真实（tattva）不是名言分别所能安立的对象——凡可用概念捕捉者皆非真实本身，真实是「离四句、绝百非」的法性。这一界定预先排除了任何以定义方式把握真实的进路。

第二段是遣破的次第：依次遣除四句——执有（实有论）、执无（虚无论）、执亦有亦无（双执）、执非有非无（双遣执）。值得注意的是第四句：连「非有非无」这个看似已经最高明的立场也要被遣除，因为对「双非」的执取仍然是执取。四门皆闭，戏论止息，真实方「可入」。此即名句一「離四句、絕百非——有、無、亦有亦無、非有非無，四門皆閉，然後真實可入」的完整含义。

第三段是俗谛的保留：入真实不等于取消世俗——名句二明言「若因入真實而撥無因果，是名惡取空，非真實也」。「恶取空」（durgṛhītaśūnyatā）是龙树以来空义教学的关键警戒：把空理解为否定因果业报的虚无主义，是对空最坏的误读。本论以「世俗缘起不坏」来确保所入之真实不坠断灭。

## 三、学术研究价值与争议

研究价值方面：（1）「离四句」的论证结构是印度哲学特有的否定方法论（tetralemma）的佛学运用，本论给出了四句依次遣除的清晰演示，是研究佛教逻辑与否定法的适宜文本；（2）「入真实而不坏世俗」的双轨表述，是二谛义的经典概括，可与大乘中观系的诸多文本互证；（3）「恶取空」的警戒线对理解佛教空义的边界极有教理价值——空不是价值虚无；（4）本条目索引卡与原文档在梵名、归属上的差异（Tattvasiddhi 与成实论系统，对 Tattvāvatāra 的中观式概述），本身构成一个值得注意的档案内部问题，提示条目数据的两个来源层次。

争议与问题方面：（1）梵名与归属之辨：若本论确指诃梨跋摩《成实论》，则其「成实」意为「成就实谛」，属经量部倾向的论书，与原文档所述中观色彩的「离四句入真实」论旨不尽相同——此出入如何解释，是本条目最大的文献学问题；（2）「离四句绝百非」的进路是否可能滑向不可知论，或反过来说是否仅是方便施设，教理史上素有争论；（3）真实「可入」与真实「离言」之间的张力：若真实离名言，则「入」之为言是否自相矛盾，历来注家有层层辩解。

| 真实（Tattva） | 离名言分别、不可安立的法性，本论所入之境 |
| 四句（Catuṣkoṭi） | 有、无、亦有亦无、非有非无四种边见 |
| 离四句绝百非 | 遣尽一切概念性立场的方法论总纲 |
| 戏论（Prapañca） | 概念的增殖扩散，一切执取的语言根源 |
| 无自性（Niḥsvabhāva） | 诸法无独立不变实体，空之正理 |
| 世俗（Saṃvṛti） | 缘起宛然的常识层面，入真实而不坏者 |
| 恶取空（Durgṛhītaśūnyatā） | 错误领会空义而拨无因果，入真实之最大陷阱 |

| 成实论（索引卡说） | 诃梨跋摩造、鸠摩罗什译十六卷论书，成实宗所依 |
