# 入真实论 — 学术解读

## 一、文献背景与成书

《入真实论》梵名 Tattvāvatāra——tattva（真实、如性）+ āvatāra（进入、趣入），直译"入于真实之道"。本论以中观"遮诠"方法阐明趣入真实（法性）的路径，属中观系统的修道论文献。本档案库的索引卡将此一目与诃梨跋摩（Harivarman，约4-5世纪）所造、鸠摩罗什汉译的《成实论》（Tattvasiddhi，十六卷）系统相关联——成实一系在中国曾形成独立的成实宗，阐述三世无实、二谛等义。两处记载的对应关系（入真实/Tattvāvatāra 与成实/Tattvasiddhi 之名近而体系有异：前者纯用中观遣荡法门，后者近于经部系统的分别说），反映了古代经录中以"真实"（tattva）为核心词的论书在流传与编目中的交错，是文本考据上值得留意的问题。

就本目录原文所载，本论的义理立场为标准的中观遮诠：以离四句、绝百非为入真实之门。

## 二、文本结构与核心思想

本论的论证采取经典的"四句遣除"结构：

**其一，立真实义**：所谓真实（tattva），非由名言分别所安立——语言与概念所构造的一切，皆非法的实相；真实是离四句、绝百非的法性（dharmatā）。

**其二，次第遣四句**：论中依次遣除四种执著——**执有**（肯定式实体论）、**执无**（否定式虚无论）、**执亦有亦无**（混合论）、**执非有非无**（双重否定式的超越论）。四句既遣，戏论乃息——连"既非有也非无"这种看似高深的立场，也是概念心所构造，同样要放下。是名入真实。

**其三，遮断灭（防恶取空）**：入真实并非断灭——世俗缘起不坏故。论中特别警示：若因入真实而拨无因果，是名**恶取空**（durgṛhītaśūnyatā，被错误把握的空），非真实也。空义的实践底线由此划出：胜义上无自性，世俗上因果宛然。

这一"四句遣除→戏论息→不坏世俗"的三段结构，是印度中观文献处理"如何言说不可言说者"这一根本难题的标准方案，与龙树《中论》"大圣说空法，为离诸见故；若复见有空，诸佛所不化"的立场一脉相承。

## 三、学术研究价值与争议

研究价值方面：（1）"四句"（catuṣkoṭi）是印度逻辑与佛教哲学的标志性结构，本论以其为修行次第的"阶梯"，是研究四句法从逻辑工具转化为修道论框架的样本；（2）"恶取空"的警示在大乘经论（如《中论》《大智度论》及瑜伽行系文献）中反复出现，本论的表述为中观空义诠释史提供了一个简明的坐标；（3）本目与成实论系统的编目关联，为研究中国古代经录中"成实/真实"类论书的归类传统提供了线索。

争议问题包括：（1）文本身份——如前所述，"入真实"之名的独立论书与《成实论》之间的名实关系需要审慎考辨，学界对梵名相近的中观、成实两类文献的编目交错尚无定论；（2）"四句遣除"的哲学解释——四句是否穷尽一切可能立场（有印度学者视之为古印度版的"穷举否定"，也有学者认为其本质是治疗性的而非逻辑性的），与西方逻辑对悖论的处理可作比较研究；（3）"绝百非"之后的言说地位——遣除一切之后，"法性"是否还可被指称，涉及佛教否定神学与肯定神学之争的老问题。

|---|---|
| 真实（tattva） | 离言说的法之实性 |
| 四句（catuṣkoṭi） | 有、无、亦有亦无、非有非无四种立场 |
| 戏论（prapañca） | 概念心的虚妄构画 |
| 恶取空 | 错误把握空义而否定因果的危险立场 |
| 法性（dharmatā） | 诸法的真实本性 |
| 世俗缘起 | 日常层面因果不坏的运作 |
