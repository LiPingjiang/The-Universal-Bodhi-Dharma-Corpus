# 往生论注注·原文

## 一、概述

《无量寿经优婆提舍愿生偈注》二卷（T1819），通称《往生论注》，北魏·昙鸾（476-542）撰，收于《大正藏》第四十册。本注是对世亲菩萨所造《无量寿经优婆提舍》（即《往生论》，T1524）的注释。《往生论》为印度世亲菩萨依《无量寿经》所作之《愿生偈》二十四偈及长行解释，北魏普泰元年（531年）菩提流支译成汉文。昙鸾于洛阳见菩提流支，得授《观无量寿经》，遂专宗净土而注释此论。

昙鸾依龙树《十住毗婆沙论》阐明难行、易行二道，自力、他力之别，主张依靠阿弥陀佛本愿力为五浊恶世中方便易行之道，始阐净土立教之本义。其核心思想包括：二道二力判教（难行道与易行道、自力与他力）、五念门修行（礼拜、赞叹、作愿、观察、回向）、三类二十九种庄严功德观察、一法句清净义、巧方便回向、他力本愿等。本注为净土宗教理奠基之作，道绰《安乐集》、善导《观经四帖疏》均承此绪。本注注系后人对此注的进一步疏释。

## 二、核心段落

### 原文

> 谨案龙树菩萨《十住毗婆沙》云：菩萨求阿毗跋致，有二种道：一者难行道，二者易行道。难行道者，谓于五浊之世，于无佛时，求阿毗跋致为难。此难乃有多途，粗言五三，以示义意：一者外道相善，乱菩萨法；二者声闻自利，障大慈悲；三者无赖恶人，破他胜德；四者颠倒善果，能坏梵行；五者唯是自力，无他力持。如斯等事，触目皆是。譬如陆路，步行则苦。易行道者，谓但以信佛因缘，愿生净土，乘佛愿力，便得往生彼清净土。佛力住持，即入大乘正定之聚。正定，即是阿毗跋致。譬如水路，乘船则乐。

> 略说入一法句故。一法句者，谓清净句。清净句者，谓真实智慧，无为法身故。此清净有二种，应知。何等二种？一者器世间清净，二者众生世间清净。器世间清净者，如向说十七种庄严佛土功德成就，是名器世间清净。众生世间清净者，如向说八种庄严佛功德成就、四种庄严菩萨功德成就，是名众生世间清净。

> 此无上菩提心，即是愿作佛心；愿作佛心，即是度众生心；度众生心，即摄取众生生净佛国土心。是故愿生彼安乐净土者，要发无上菩提心也。若人不发无上菩提心，但闻彼国土受乐无间，为乐故愿生，亦当不得往生也。

### 白话翻译

> 谨依龙树菩萨《十住毗婆沙论》所说：菩萨求证不退转位（阿毗跋致），有两条道路：一是难行道，二是易行道。难行道，是指在五浊恶世中、没有佛出世时，求证不退转位非常困难。这种困难有多种途径，大略举出五种来说明其义：第一，外道表现善良，扰乱菩萨的正法；第二，声闻只求自利，障碍大慈悲心；第三，无赖恶人，破坏他人的殊胜功德；第四，颠倒的善果，能毁坏清净梵行；第五，唯独依靠自力，没有他力的护持。这样的事，触目皆是。好比走陆路，步行则很辛苦。易行道，是指仅以信佛的因缘，发愿往生净土，乘着阿弥陀佛的愿力，便能往生彼清净国土。由佛力住持，即入大乘正定聚。正定，就是不退转。好比走水路，乘船则很安乐。

> 将广说归纳为一法句。所谓一法句，就是清净句。所谓清净句，就是真实智慧、无为法身。这清净有两种，应当知道。哪两种呢？一是器世间清净，二是众生世间清净。器世间清净，就是前面所说的十七种庄严佛土功德成就，称为器世间清净。众生世间清净，就是前面所说的八种庄严佛功德成就、四种庄严菩萨功德成就，称为众生世间清净。

> 这无上菩提心，就是愿作佛的心；愿作佛的心，就是度脱众生的心；度脱众生的心，就是摄取众生往生清净佛国土的心。所以愿生彼安乐净土的人，必须发无上菩提心。如果不发无上菩提心，只是听说那个国土快乐不断，为了享乐而愿往生，也是不能往生的。

## 三、名句

1. **"唯是自力，无他力持。……譬如陆路，步行则苦。……易行道者，谓但以信佛因缘，愿生净土，乘佛愿力，便得往生。……譬如水路，乘船则乐。"** ——昙鸾依龙树《十住毗婆沙》立难行易行二道、自力他力二力之判，以"陆路步行则苦、水路乘船则乐"为喻，奠定净土宗他力本愿教理之基础。

2. **"一法句者，谓清净句。清净句者，谓真实智慧，无为法身故。"** ——将二十九种庄严功德归纳为一法句、清净句，即真实智慧无为法身，显示净土庄严当体即是法身实相。

## 四、术语表

| 术语 | 释义 |
|------|------|
| 难行道 | 昙鸾所立二道之一，谓五浊之世无佛时，唯依自力求不退转，如陆路步行则苦 |
| 易行道 | 二道之一，谓以信佛因缘乘佛愿力往生净土，如水路乘船则乐 |
| 自力他力 | 自力指菩萨仗自力修行；他力指阿弥陀佛本愿力 |
| 阿毗跋致 | 梵语Avaivartika，不退转位，即菩萨不退转于无上菩提 |
| 五念门 | 礼拜门、赞叹门、作愿门、观察门、回向门，前四为入净土门，后一为出慈悲教化门 |
| 一法句 | 将二十九种庄严归纳为一句，即清净句——真实智慧无为法身 |
| 巧方便回向 | 不求自身住持之乐，欲拔一切众生苦，摄众生共生净土 |
| 器世间清净 | 极乐国土十七种庄严功德成就 |
| 众生世间清净 | 佛八种功德、菩萨四种功德庄严成就 |
| 三类二十九种庄严 | 国土十七种、佛八种、菩萨四种，共二十九种庄严功德 |
