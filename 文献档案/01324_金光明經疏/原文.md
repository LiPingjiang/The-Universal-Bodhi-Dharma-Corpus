# 金光明經文句

## 一、概述

**大正藏編號**：T1760（《大正新脩大藏經》第 39 冊）

**全稱**：《金光明經文句》

**別稱**：《金光明文句》《光明文句》

**撰者**：隋·智顗（538—597）說，門人灌頂（561—632）錄

**卷數**：六卷

**所釋經本**：《金光明經》四卷，北涼·曇無讖（Dharmakṣema）譯（T1766）

**關於編號的說明**：原檔案標示「T1779/T1785」，然經 CBETA 核查，T1760 為智顗《金光明經文句》，T1783 為智顗《金光明經玄義》，而吉藏亦有《金光明經疏》一卷。本篇以智顗《金光明經文句》（T1760）為主要內容，因其為天台宗「五小部」之一，是金光明經注疏中最重要者。

《金光明經文句》是天台宗「五小部」之一，與《金光明經玄義》（T1783）同為智者大師對《金光明經》的系統注釋。二書分工不同：《玄義》在入文之前以「五重玄義」闡發經題深旨，《文句》則逐品逐句解釋經文。

《金光明經》在中國佛教中地位崇高，與《法華經》《仁王經》並稱「護國三部經」。此經敘說金光明的微妙法義，涵蓋懺悔業障、四天王鎮護國土、流水長者子救魚放生等內容。智者大師在《文句》中以天台圓教思想貫穿全經，特別在釋〈懺悔品〉時，將「懺悔」提升為「理事雙懺」的圓頓法門，對後世天台懺法體系影響極為深遠。

宋代知禮大師為此書撰《金光明經文句記》（T1764，十二卷），是研究本書的重要注疏。

## 二、核心段落

### （一）論三障：報障、煩惱障、業障

**原文（《金光明經文句》卷第二，據實修驛站校錄本）：**

> 報障如上可解。煩惱與業云何？數人云：數起而輕名煩惱，數起而重名為業。天台師云：任運常有是煩惱，卒起決定心發動身口，必牽來報者是業。若爾，惡星災異都不關心，云何是業障？此乃外相表業將起，是業責報之相，即得是業障也。若煩惱業轉，報未必轉；若報轉，業煩惱必轉。

**白話對照：**

報障如上所述可以理解。那麼煩惱與業的區別何在？數論師說：頻繁生起而輕微的叫做煩煩惱，頻繁生起而重大的叫做業。天台智者大師說：任運自然常有的就是煩惱，突然生起決定心、發動身口行為、必定牽引未來果報的才是業。若如此說，惡星災異與人心毫不相干，怎麼會是業障呢？其實這是外在的相狀在表示業即將生起——是業來責求果報的前相，因此也就是業障。如果煩惱和業轉變了，果報未必轉變；但如果果報轉變了，煩惱和業必定已經轉變。

### （二）論業障之相：惡星災異與五罪報應

**原文（卷第二續）：**

> 三破業障者，從惡星災異下是也。業將感報故其相前現，相名表發，意在此也。惡星者，別有客星也，亦是五星二十八宿。一方有七，四七二十八也。違其度數，失其分野。若熒惑亂行、麻彗暴出，是客星也。災異者，風雨雪霜乖候等是也。眾邪者有三：人邪、鬼邪、法邪是也。蟲道者，毒鬼也，又言三毒是蟲也。變怪者，詭怪也，謂禽獸醜惡形聲等是也。惡夢者，心靈潛密業現其中，夢見不適意事是也。夫諸業表報不出五罪：若惡星表亡身失命者，殺生業相也；惡星表神棄困窮者，竊盜業相也；惡星表親離幽厄者，淫罪業相也；惡星表誣枉讒謗者，妄語業相也；惡星表喪失財產者，飲酒業相也。其餘災異怪禽惡夢等，隨其時節各有所表，細心推詳不出五罪之報。

**白話對照：**

第三「破業障」，從經文「惡星災異」以下便是。業將要感得果報時，其相狀會預先顯現——「相」就是表露引發，用意即在於此。所謂惡星，有的是客星（不常見的星），也有的是五星二十八宿。一方有七宿，四七二十八宿。如果違背了度數、失去了分野，或者熒惑星亂行、彗星暴出，那就是客星。所謂災異，就是風雨雪霜等氣候反常。所謂眾邪有三種：人邪、鬼邪、法邪。蟲道，指毒鬼，也可以說貪瞋癡三毒就是蟲。變怪，就是詭異怪事，比如禽獸形貌醜惡、聲音怪異等。惡夢，是心靈在幽密之中業相顯現其中，夢見不適意的事。

一切業相表報不外乎五種罪業：如果惡星預示亡身失命，那是殺生業相；如果惡星預示精神棄舍、困苦窮乏，那是偷盜業相；如果惡星預示親人離散、幽禁厄難，那是邪淫業相；如果惡星預示誣枉讒謗，那是妄語業相；如果惡星預示喪失財產，那是飲酒業相。其餘的災異、怪禽、惡夢等，隨其時節各有表徵，細心推究不出這五種罪業的果報。

### （三）所釋經文：金光明經序品

**《金光明經》原文（T1766，曇無讖譯）：**

> 如是我聞，一時佛在王舍大城耆闍崛山。與大比丘眾九萬八千人俱，皆阿羅漢……復有無量百千菩薩摩訶薩……其名曰：金光藏菩薩、金光精進菩薩、金光威德菩薩……如是等菩薩摩訶薩無量無邊。

**白話對照：**

我這樣聽聞：那時，佛陀在王舍大城的耆闍崛山（靈鷲山），與大比丘眾九萬八千人在一起，他們都是阿羅漢……又有無量百千菩薩大士……他們的名字是：金光藏菩薩、金光精進菩薩、金光威德菩薩……這樣的菩薩大士無量無邊。

（智者大師在《文句》中釋此品時，以天台「觀心」之釋貫穿——「金光」即表法身之德，光明表般若之照，菩薩名號皆為表法。）

### （四）所釋經文：四天王品——護國思想

**《金光明經》四天王品原文（T1766）：**

> 爾時毗沙門天王、提頭賴吒天王、毗留勒叉天王、毗留博叉天王，俱從座起，偏袒右肩，右膝著地，合掌向佛，白佛言：世尊！是金光明微妙經典，眾經之王，諸佛世尊之所護念……我等四王亦當來至其所，為聽法故……若有國王欲得擁護自身國土，亦應受持是金光明微妙經典。

**白話對照：**

那時，毗沙門天王（北方）、提頭賴吒天王（東方）、毗留勒叉天王（南方）、毗留博叉天王（西方）——四大天王，都從座上起身，偏袒右肩，右膝跪地，合掌向佛說道：世尊！這部金光明微妙經典，是眾經之王，為諸佛世尊所護念……我們四大天王也會來到講經之處，為了聽法的緣故……如果有國王想要擁護自身和國土，也應當受持這部金光明微妙經典。

### （五）金光明經玄義：五重玄義與十種三法

**《金光明經玄義》（T1783）原文要旨：**

> 將釋此經，大科為五：一釋名、二出體、三明宗、四論用、五教相。

> 釋名為二：一教義釋、二觀行釋。教義釋者……金光明三字，遍譬一切法門：以金譬法身，以光譬般若，以明譬解脫……十種三法者：一三德、二三寶、三三大乘、四三菩提、五三佛性、六三識、七三涅槃、八三身、九三般若、十三道。

**白話對照：**

將要解釋此經，大分五科：第一釋名，第二出體，第三明宗，第四論用，第五教相。

釋名分為兩部分：一是教義釋，二是觀行釋。教義釋中，「金光明」三字普徧譬喻一切法門——以「金」譬喻法身，以「光」譬喻般若，以「明」譬喻解脫……以十種三法來詮釋：三德、三寶、三大乘、三菩提、三佛性、三識、三涅槃、三身、三般若、三道。

（按：《金光明經玄義》的「十種三法」是智者大師以圓教思想系統詮釋經題的核心方法。每一種三法都以「金光明」三字貫通，如「三德」即法身（金）、般若（光）、解脫（明），體現了天台宗「一法攝一切法」的圓融精神。此書有廣略二本，廣本含「觀行釋」，略本則無。五代末年山家山外二派關於廣本真偽的論諍，即由此而起。）

## 三、名句

1. **「任運常有是煩惱，卒起決定心發動身口，必牽來報者是業。」**——智者大師對煩惱與業的精要區分：任運而起、未發動身口者為煩惱；決定心起、發動身口、必感果報者為業。此釋成為天台宗業障論的標準定義。

2. **「以金譬法身，以光譬般若，以明譬解脫。」**——《金光明經玄義》中以「金光明」三字配釋三德的經典表述，將經題提升為圓教法身、般若、解脫三德圓融的象徵，是天台宗「以題攝經」詮釋方法的典範。

## 四、術語表

| 術語 | 釋義 |
|------|------|
| 三障 | 報障（果報之障）、煩惱障（任運常有之惑）、業障（決定心發動身口必感報者），金光明經懺悔品的核心概念 |
| 五重玄義 | 天台宗解經框架：釋名、出體、明宗、論用、教相 |
| 十種三法 | 《金光明經玄義》釋名的方法，以三德、三寶、三大乘等十組三法貫穿「金光明」經題 |
| 文句 | 天台宗注疏體裁之一，逐品逐句解釋經文，與「玄義」（入文前的玄旨闡發）相對 |
| 懺悔 | 金光明經的核心主題，天台宗分為「事懺」（作法懺）與「理懺」（無生懺）兩層 |
| 四天王 | 持國、增長、廣目、多聞四大天王，金光明經中鎮護國土的護法神 |
| 五小部 | 天台宗智者的五部重要小部著作：《觀音玄義》《觀音義疏》《金光明經玄義》《金光明經文句》《觀無量壽佛經疏》 |
| 山家山外 | 宋代天台宗兩派，因《金光明經玄義》廣略二本之爭而分裂。山家派（知禮）主廣本，山外派（晤恩）主略本 |
| 法身·般若·解脫 | 即「三德」，配釋「金光明」三字：金喻法身、光喻般若、明喻解脫 |
