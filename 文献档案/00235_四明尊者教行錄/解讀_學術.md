# 四明尊者教行录 — 学术解读

## 一、文献背景与成书

《四明尊者教行录》，七卷，是天台宗中兴之祖知礼（960—1028，世称"四明尊者"，以久住四明山延庆寺得名）的著述与行实汇编，南宋天台宗学者宗晓编定，收于《大正藏》第四十六册（No. 1937）。如原文所录："知礼大师之门人，集师之教观行仪，编为此录。其要在于弘扬天台教观，以三大部为本，辅以忏法行仪。教观双修，解行并进，住持正法，利益有情。"

知礼活动于北宋初年，正值天台宗典籍从吴越、高丽回流、山家教团重建的关键期。他一生著《十不二门指要钞》《金光明经玄义拾遗记》等数十部，主持明州延庆寺，建忏场修法华三昧，门下广智、神照、南屏三系绵延，是为"山家"正统。宗晓（1151—1214）为四明系后学，曾编《乐邦文类》，其编定本书意在保存祖师言行、巩固山家法脉。

## 二、文本结构与核心思想

全书按文体与性质分类编次，收录知礼的书信、问答、序跋、忏仪、开示及门人记述的行实，末附年谱性质的资料，性质近于"全集＋行状"的合编。核心思想有三：

1. **教观双美**。"天台教观，一念三千，三谛圆融。教理观心，如车二轮，如鸟双翼，不可偏废。"知礼终生强调天台教学的根本立场：教理（一念三千、三谛圆融的性具思想）与观心实践（止观忏悔）必须一体，反对徒讲文字或盲修暗证。

2. **性具立场与别理随缘**。知礼主张"性具三千"，认为贪嗔痴之妄心当体即具三千法，观此一念阴识即是观不思议境；对华严系统"但中"之理与"性起"说持批判态度。其"理毒性恶""妄心观"等主张，构成宋代山家教义的独特性格。

3. **以忏法为行仪核心**。知礼多次主持修忏（法华三昧、大悲忏等），本录所收忏仪文字，反映了宋代天台"教在义理、行在礼忏"的宗教实践形态，也是研究中国佛教忏法史的核心材料。

## 三、学术研究价值与争议

**研究价值**：本书是研究"山家山外之争"的文献总汇。知礼与悟恩门下庆昭、智圆（原属于钱塘系，被贬称"山外"）围绕《金光明玄义》广本真伪、观心之有无、"别理随缘"等展开数十年的论战，其往返文书多赖本录及《十义书》等保存。这场论争是宋代天台宗史的分水岭，胜出的山家派塑造了此后天台宗的基本面貌，也深刻影响了高丽天台（知礼与义天的交往是东亚佛教交流史的重要章节）。

**代表学者**：日本学者安藤俊雄《天台学——根本思想及其开展》对山家山外之争有系统研究；慧岳法师《天台教学史》梳理知礼一系传承；潘桂明、吴忠伟《中国天台宗通史》从中国宗派史角度重新评估知礼；美国学者包如廉（Brook Ziporyn）的著作对知礼的哲学性格有独到分析。

**争议问题**：其一，"山家山外"命名本身出自知礼一系的判教修辞，钱塘一系是否应当如其所述被视为"背离祖道"，现代学者多主张超越胜负叙事重估双方；其二，宗晓编录的取舍标准——哪些文献收入、哪些未收，影响了对论战全貌的复原；其三，知礼"理毒性恶""妄心观"等说的思想史定位——是对智顗的忠实继承还是宋代新开展，学界至今讨论不衰。

| 教观 | 教相门（义理判释）与观心门（止观实践），天台家学之两轮 |
| 山家／山外 | 北宋天台正统（知礼系，居四明）与被视为杂有华严真心系思想的钱塘系 |
| 性具三千 | 一念心当体本具三千诸法，善恶性德皆具，天台性具思想核心 |
| 一念三千 | 一念心即具三千法，天台观法之根本 |
| 三谛圆融 | 空、假、中三谛互即一体，一谛即三谛 |
| 忏法 | 依仪轨礼佛忏悔、净化三业的修行制度 |
