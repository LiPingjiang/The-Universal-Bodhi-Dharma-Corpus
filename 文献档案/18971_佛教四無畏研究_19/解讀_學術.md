# 佛教四無畏研究_19 — 学术解读

## 一、文献背景与成书

本目录原文档为综述性条目，以「四無畏」（梵 catvāri vaiśāradyāni，巴利 cattāri vesārajjāni）为纲，录佛四无畏与菩萨四无畏之名目及文句二段，附术语对照，属专题式汇编而非一经之完整录文。

佛四无畏的文献源头甚早：巴利《中部·师子吼经》等已载如来于大众中作师子吼、成就四无畏之说，汉译《增一阿含經》等亦有平行文句；《大智度論》卷二十五对四无畏有详尽界说——正等觉无畏（佛自言「我是一切智人」，无人能难）、漏尽无畏（自言「我诸漏已尽」，无人能难）、说障法无畏（说染法能障道，无人能难）、说出道无畏（说道能尽苦，无人能难）。原文档所列「正等覺無畏、漏永盡無畏、說障法無畏、說出道無畏」与此全合。菩萨四无畏则各经所列名目不一，原文档作「能持無畏、不忘失無畏、無過患無畏、不失念無畏」，与通行论书所列（多作总持不忘、知根说法、决疑答难之类）名目相近而措辞有异，今以原文档为准并注明此异。四无畏与十力、十八不共法常并称，构成佛功德法数的三足。

## 二、文本结构与核心思想

原文档五节式编排：概述列佛四无畏四名，选录与名句二段，末附术语表。核心段落「如來四無所畏者——正等覺無畏、漏永盡無畏、說障法無畏、說出道無畏。如來在大眾中作師子吼，無所畏懼」以师子吼为喻收束四无畏——师子为兽中之王，吼则百兽慑伏，喻佛说一切法自在无畏；另一段「菩薩亦修四無畏——能持無畏、不忘失無畏、無過患無畏、不失念無畏。如是四法圓滿，即近佛果」则给出菩萨位的四无畏，并以「近佛果」标明两重的阶位关系。

思想要点可析为三层：一是无畏的根据在实证——佛之无畏非勇气而是事实：正觉已成、诸漏已尽、障道与出道之说皆经亲证，故能于任何质问下安然不动；二是无畏的对象是「大众」——四无畏皆是面对他者诘难时的自在，属说法度众的功德而非自受用境界；三是佛与菩萨的双重结构——菩萨四无畏（总持不忘、正念不失之类）是佛四无畏的因地形态，由持法不忘进而说法无碍，因果一线贯通。

## 三、学术研究价值与争议

研究价值方面：其一，四无畏是研究佛教「果德论证」方式的关键材料——佛的权威不诉诸天启而诉诸可被挑战的实证宣称（「无人能难」），这一论证结构在比较宗教学中极为独特。其二，师子吼意象上承印度王权与兽王象征传统，下贯汉译佛典的修辞系统，是佛教图像学与文学研究的交汇点。其三，佛四无畏与菩萨四无畏的名目流变，各经所列互有出入，正适合作法数比较研究，考察大乘如何把佛功德转化为菩萨可修的科目。

争议问题主要有二：一是四无畏中「说障法无畏」的判教功能——判定何法障道即隐含对异见的裁决，此与佛教的宽容形象之间是否存在张力，现代诠释者立场不一；二是菩萨四无畏名目在各经中的差异，究竟反映不同的部派传承，还是同一法数的随机开显，文献上尚无定谳。

## 四、术语对照表

沿用原文档所附对照，酌加注记：

| 梵/巴语 | 汉语 | 英译 |
|---|---|---|
| Vaiśāradya | 无畏 | fearlessness |
| Abhisambodhi | 正等觉 | perfect enlightenment |
| Āsravakṣaya | 漏尽 | destruction of defilements |
| Sāvaramārga | 障道 | hindrance to the path |
| Niyyānika-mārga | 尽苦道 | path leading out |
| Siṃhanāda | 师子吼 | lion's roar |

按：「障道」之梵语构词原文档作 Sāvaramārga，疑为 sa-āvaraṇa-mārga 或 āvaraṇa 一类词之省写，今照录原貌并识于此；「师子吼」（siṃhanāda）为佛经中最著名的比喻之一，佛说法之无畏无所不摧，如师子一吼百兽皆伏。
