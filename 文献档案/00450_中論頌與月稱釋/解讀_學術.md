# 中論頌與月稱釋 — 学术解读

## 一、文献背景与成书

月称（Candrakīrti）是约七世纪的印度中观论师，生平可靠资料不多，传统称其曾住持那烂陀寺。他所作《根本中论般若释·明句》（Prasannapadā，简称《明句论》或《净明句论》）逐品注解龙树《中论颂》，是现存唯一保存较完整梵本的古代《中论》注；另有藏译全本，却无古代汉译，因此没有《大正藏》T号。近现代学者据尼泊尔梵文写本校刊，对理解《中论》原颂、校正汉藏异读贡献极大。

《明句论》写作时，佛护与清辨关于论证方法的分歧已经形成。清辨认为佛护只以归谬破他而不自立规范比量，论证有缺陷；月称则在《明句论》第一品长篇为佛护辩护，指出胜义中若以双方共同承认、具有自性的对象建立独立论证，就已经违背中观立场。他不是简单重复佛护，而是借助陈那以来的因明术语、二谛分析与语言哲学，重新说明归谬法何以有效。

《明句论》梵本的近代发现、抄写和校刊，是其现代学术地位的重要基础；所据尼泊尔写本并非作者手稿，仍须与藏译及引文互校。汉语世界目前主要依现代译注接触此书，故不能给它虚构古代汉译名号或T号。月称另有《入中论》等著作，但二者体例和论题不同，也不应互相代替。

## 二、文本结构与核心思想

全书依《中论》二十七品展开，既释词、释句，又重构论敌和答辩，旁征早期佛经及印度各派观点。月称强调诸法在胜义观察下无自性，但世俗中可依共同经验、语言习惯和因果效用安立。"世俗谛"并非自性较弱的实体层，"胜义谛"也不是藏在现象背后的最高物质；二者是同一缘起事实的两种观察方式。胜义智慧见无自性，世俗言说则维持因果、伦理与修道。

方法上，月称推崇prasaṅga：沿用对方所许前提推出不合理后果。现代逻辑研究又指出，他并非全然拒绝推理，而是将某些归谬翻转理解为针对对方自许前提的"他比量"。这使《明句论》超出"只破不立"的简化标签。语言虽不能把胜义变成对象，却能像路标一样消除错误增益；中观论证的功能是止息戏论，而非建立另一套自性形而上学。

## 三、学术研究价值与争议

《明句论》的文献价值首在梵本保存：校勘龙树颂文时，它与罗什青目释T1564、藏译颂本共同构成三大证据链。其思想价值在于系统呈现月称对佛护、清辨、瑜伽行派和因明传统的回应，为研究印度中观后期发展不可替代。西藏后弘期以后，月称地位不断上升，宗喀巴及格鲁派尤其奉其为应成中观权威，使《明句论》成为藏传佛学核心诠释资源。

争议包括：第一，"应成派—自续派"二分主要由后世西藏学者定型，月称本人是否具有同样清晰的宗派自觉，不能直接假定。第二，月称批评清辨究竟是拒绝一切自主论证，还是只拒绝胜义语境中的共许自性对象，现代逻辑研究看法不一。第三，他与佛护是否属于同一理论系统，也有不同评价：月称显然继承佛护归谬路线，却加入了更成熟的因明批判、二谛论与世俗安立。故青目、佛护、月称三释应分别按汉译合编本、藏译归谬释、梵藏系统注来研究。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 明句论 | 月称所作《中论》逐品注，存较完整梵本及藏译本 |
| 二谛 | 世俗谛与胜义谛，两种观察和表达缘起事实的层次 |
| 应成 | 依对方前提推出其不能接受的过失，月称重视的论法 |
| 自续 | 以论者自立的规范比量主动证明命题的方法 |
| 戏论 | 将概念分别增益为固定实体的思维与言说活动 |
| 他比量 | 依论敌承认的命题而构成、主要约束论敌的推论 |

## 五、延伸阅读

文本比较先读 `00448_中論頌與青目釋` 与 `00449_中論頌與佛護釋`；中观的自反性论辩见 `00451_回諍論頌與注`，汉传三论纲要见 `00452_十二門論註疏`，般若背景可参 `大般若经`。
