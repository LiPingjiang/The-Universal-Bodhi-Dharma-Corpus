# 熱堆攝類——學術解讀

## 一、扎什倫布寺與三大寺的教育傳統差異

### 1.1 歷史背景

扎什倫布寺（bKra shis lhun po）與拉薩三大寺（Se ra, 'Bras spungs, dGa' ldan）雖然同屬格魯派，但在教育傳統上存在「衛藏—後藏」的地域分化。這一分化有深刻的歷史根源：

三大寺位於拉薩，直接處於達賴喇嘛和甘丹赤巴（dGa' ldan khri pa，甘丹寺座主，格魯派法座持有人）的影響之下，其教學傳統更直接地繼承了宗喀巴及其親傳弟子的學術路線。扎什倫布寺則位於後藏日喀則，自第四世班禪羅桑確吉堅贊（Blo bzang chos kyi rgyal mtshan，1570—1662）起成為班禪額爾德尼的駐錫地，在學術上逐漸形成了以班禪系統為核心的獨立傳規。

這種地域和政治上的區隔，導致兩個系統在教材、教法和辯經風格上逐漸分化。攝類學教材的差異就是這一分化在基礎教育層面的體現。

### 1.2 教育理念的差異

三大寺的攝類學教學總體上偏向「理論先行」：先系統建立概念框架，再在此基礎上引入論式和辯論技術。這一路線的邏輯是——只有在概念清晰的前提下，辯論才是有意義的。

扎什倫布寺的傳統則偏向「實操先行」：從一開始就讓學僧接觸應成辯式的基本操作，在辯論實踐中逐步深化概念理解。這一路線的邏輯是——概念的真正理解只能在辯論實踐中獲得，脫離實操的概念學習容易流於記憶和背誦。

這兩種教育理念的差異，與現代教育學中「先理論後實踐」和「理論實踐一體化」兩種教學哲學的爭論有著有趣的對應。

### 1.3 學術氛圍的差異

Melvyn Goldstein 在其對藏傳寺院社會的經典研究中指出，扎什倫布寺的學術氛圍相較於三大寺更為「實用主義」。三大寺的格西學位考試以難度極高的公開辯經著稱，學僧之間的學術競爭非常激烈；扎什倫布寺的考核雖然同樣嚴格，但更注重學僧的整體能力和實際運用水平，而非在個別辯題上的極致精確度。《熱堆攝類》大量收錄現成問答例題的做法，與這種「實用主義」學術取向是一致的。

## 二、熱堆攝類在應成辯式上的獨特貢獻

### 2.1 應成辯式的核心地位

應成辯式（ཐལ་འགྱུར，thal 'gyur）是藏傳辯經中最核心、使用最頻繁的論式形式。其基本結構為：

> 有法（chos can）+ 所立謂語（bsgrub bya'i chos）+ 應（thal）+ 因（rtags）

例如：「有法——聲音，應是無常，因為是所作性故。」

在藏傳辯經的實際操作中，幾乎所有的攻守問答都是通過應成辯式進行的——攻方用應成式提問，守方以四句（承許、因不成、不遍、何以故）之一回應。因此，能否熟練地構造和應對應成辯式，是衡量一個學僧辯經能力的基本標準。

### 2.2 《熱堆攝類》的早期引入策略

《熱堆攝類》的獨特貢獻在於它打破了「先概念後論式」的傳統教學順序，在小理路階段就開始系統性地引入應成辯式訓練。具體做法是：

- **在每個概念點後立即配備應成辯式例題**：學僧學完「成事」的定義之後，立刻就有5到10道以應成辯式呈現的辯題，要求學僧用標準的攻守格式進行練習。
- **例題按難度遞進排列**：從最簡單的單步應成式（一問一答即結束）到多步連鎖應成式（需要三四輪追問），難度逐步提升。
- **提供完整的攻守雙方對話**：不僅給出攻方的問題，還給出守方的各種可能回答以及攻方的後續追問，形成完整的辯論腳本。

這種教學策略的效果是：學僧在完成小理路階段時，已經對應成辯式的基本操作相當熟悉，進入中理路和大理路後可以將更多精力放在概念深化上，而不必從頭學習論式操作。

### 2.3 與應成派中觀的學術關聯

值得注意的是，「應成」（thal 'gyur）一詞在藏傳佛教哲學中還有另一層含義：它是中觀應成派（Prāsaṅgika Mādhyamika）的核心方法論——月稱（Candrakīrti）和佛護（Buddhapālita）主張，中觀哲學的正確方法不是建立自己的理論（自續），而是指出對方理論的內在矛盾（應成）。

宗喀巴繼承了應成派中觀的立場，格魯派因此以應成派自居。從這個角度看，《熱堆攝類》對應成辯式的高度重視，不僅是一個教學方法的選擇，更與格魯派整體的哲學立場具有深層的一致性——在攝類學階段就開始訓練應成辯式，可以為日後學習中觀哲學時運用應成法打下方法論基礎。

### 2.4 形式化分析

從現代邏輯學的角度看，應成辯式具有可形式化的結構。設：

- S = 有法（主語/subject）
- P = 所立謂語（predicate）
- R = 因（reason）

則應成辯式的基本結構可以表示為：

> S 應是 P，因為 S 是 R。（若 R → P 為真，且 S 是 R，則 S 應是 P。）

守方的四種回應分別對應：
- **承許**（འདོད）：接受「S 是 P」。
- **因不成**（རྟགས་མ་གྲུབ）：否認「S 是 R」。
- **不遍**（མ་ཁྱབ）：否認「R → P」的周遍關係。
- **何以故**（ཅི་ཕྱིར）：要求證明「R → P」。

Onoda（1992）和 Tillemans（1999）都指出，藏傳辯經的這一形式結構與西方邏輯學中的推理模式（modus ponens、reductio ad absurdum）存在結構性的對應關係，但也有重要差異——藏傳辯經的「應成」不是純粹的形式邏輯操作，而是嵌入在特定的認識論和本體論框架之中的。

## 三、扎什倫布寺傳統的現代傳承

### 3.1 1959年前後的變遷

1959年後，扎什倫布寺的教學活動一度中斷。與三大寺在印度南部重建的情況不同，扎什倫布寺作為班禪系統的寺院，其傳承在1960年代至1980年代面臨了更為複雜的政治環境。部分學僧流亡至印度，在南印度建立了扎什倫布寺的流亡分寺；留在國內的寺院則在1980年代逐步恢復了教學活動。

### 3.2 教學傳統的延續與挑戰

在恢復教學的過程中，《熱堆攝類》作為扎什倫布寺攝類學教學的核心教材，被重新啟用。但由於歷史斷層，一些傳統的教學技藝（如特定辯題的攻守策略、連鎖追問的技巧等）可能面臨傳承困難。目前，扎什倫布寺正在通過邀請老一輩格西回寺指導、錄製辯經視頻等方式，努力恢復和保存傳統教學的完整性。

### 3.3 學術研究的不足

相較於三大寺和拉卜楞寺的攝類學傳統，學術界對扎什倫布寺教育傳統的研究明顯不足。大部分西方學者（如 van der Kuijp、Onoda、Dreyfus、Perdue）的研究都以三大寺傳統為主要對象，對扎什倫布寺傳統的專門研究極為有限。這一研究空白本身就構成了一個值得關注的學術課題——扎什倫布寺傳規中的獨特要素（如《熱堆攝類》的早期應成辯式引入策略）是否會為我們理解藏傳辯經的多樣性提供新的視角？

中國藏學研究中心及西藏大學的部分學者近年來開始關注扎什倫布寺的教育傳統，但相關的專題研究成果尚不多見。隨著國內藏學研究條件的改善，扎什倫布寺教育傳統的系統性研究有望在未來取得突破。

## 四、結語

《熱堆攝類》代表了藏傳辯經教育中「實操導向」的另一極。如果說洛色林攝類學的實操特色體現在課堂筆記的記錄上，那麼熱堆攝類的實操特色則體現在教材本身的設計上——通過在最早期就引入應成辯式訓練、提供大量現成問答例題，它將辯經實操能力的培養前置到了攝類學學習的起點。這一教學策略的理論基礎和實際效果，值得教育學和因明學的跨學科研究。
