# 雙論 — 学术解读

## 一、文献背景与成书

《雙論》（Yamaka）为巴利论藏七论之一，「Yamaka」意为「成双、对偶」。属巴利语论藏文献，不在大正藏编号体系之内。本目录原文档所收为本论体例与核心义理的提要（双问程序、善不善无记三性的俱生分析），未收全论译文，兹据实撰文。

七论之中，《雙論》以方法论见长：以成对正反问答的方式穷尽诸法定义的边界，防止概念的混淆与漏洞。学界一般推断其成书晚于《法集論》《分別論》而早于或接近《發趣論》，是阿毗达磨从「分类学」走向「辩证检核」阶段的产物。全论共十品，对根、蕴、处、界、谛、行、随眠、心、法等每组法相范畴施以统一的双问程序。

## 二、文本结构与核心思想

原文档所录内容展示了本论的体例与核心分析。

其一，**双问程序**。原文档载：「雙問者，謂先順問、後逆問，先雜問、後純問。如是展轉，以雙分別一切法相。」顺问（甲是乙吗）、逆问（乙是甲吗）、纯问（只就一类问）、杂问（混合类别问）——四种问法交错，把一个定义从四面拷问。当顺逆答案不同时，概念的边界就暴露出来——这在功能上相当于检验「必要条件」与「充分条件」，虽无此术语，实为此操作。

其二，**相应不相应分析**。原文档载：「善法與不善法，此二法互不俱生。善法與無記法，或俱或不俱。以雙問分別，故名雙論。」善心与不善心不能同刹那生起（一刹那一心），而善法与无记法的俱起关系则须分情形判定。这种相容性矩阵的分析，实为佛教心理学的「并发规则」。

其三，**因果不杂**。原文档载：「善法以善心為因，不善法以不善心為因。雙對分別，令知因果不相雜亂。」善因感善果、不善因感不善果，双论的分对辨析正是为确保这一伦理秩序在概念层面不被搅浑。

思想史意义上，《雙論》是佛教逻辑方法的自觉演习，可视为印度因明学前夜的重要预备。

## 三、学术研究价值与争议

研究价值：双问的顺逆问答是最早的系统性概念边界检验法，与后世因明结构有方法论亲缘，是印度逻辑史的重要环节；其「俱生不俱生」的相容性分析为心—心所理论的精细判定提供工具；对阿毗达磨经院教育而言，双论辩论是训练法分别智的标准课程，南传佛教国家的论议传统至今沿用。

争议问题：其一，双论机械重复的问答体使其在七论中最难读，部分学者怀疑其大规模穷举是后期经院化的产物，而非早期佛教思想的有机部分；其二，双论与发趣论（同样有问答体）的先后关系尚无定论；其三，其分析常预设「一刹那一心」等未经论证的阿毗达磨公理，作为「证明」还是「展示」，学界有不同评估。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 双论（Yamaka） | 以成对正反问答分别法相之论 |
| 双问 | 顺问、逆问、杂问、纯问的问答程序 |
| 俱生 | 两法同一刹那共同生起 |
| 无记 | 非善非不善的中性法 |
| 相应／不相应 | 心所与心俱起协同／不协同 |
| 因果不杂 | 善因感善果的类型纯净原则 |
