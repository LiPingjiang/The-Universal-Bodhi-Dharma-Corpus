# 大乘百法明门论解 — 学术解读

## 一、文献背景与成书

《大乘百法明门论解》，又称《百法明门论解》，唐窥基（632—682）解，收入《大正新修大藏经》第四十四册，经号 T1836。本档案原文档对此书的书志界定十分明确：此书为对世亲菩萨所造、玄奘法师所译《大乘百法明门论》（T1614）之详细注解。原论以一百种法为纲，系统阐述瑜伽行派的五位百法体系；窥基之解以详尽方式阐发此论深义。窥基为玄奘译场的上首弟子、慈恩宗（唯识宗）的实际创立者，其解《百法》为历代唯识入门教学的标准读本。

需要指出一条版本与史实的辨析：通行的大藏经著录中，《大乘百法明门论解》题为明普泰所撰（T1836《百法明门论解》），而窥基所撰为《大乘百法明门论本地分中略录名数解》（收入 T44，亦有异说）；本档案原文档明确定性为「唐窺基解」，本条目依档案原文档为准，同时如实注明这一著录差异，供读者在使用时核对。

《大乘百法明门论》本身的来历也值得交代：世亲（约四五世纪）从《瑜伽师地论·本地分》中略录名数而成此短论，玄奘于贞观年间译出，全论以「如世尊言：一切法無我」立宗，以五位百法开展论式，是瑜伽行派义学的袖珍总图。

## 二、文本结构与核心思想

本条目原文档所选「论—解」对照的段落，完整呈现了原论与窥基解的文本结构：

1. **立宗**：「如世尊言：一切法無我。」窥基解指出「如世尊言原為佛說，乃論主推尊法有所自」——以佛语为量，非世亲臆说；「一切法」是所观境，「无我」是所证理，二者「總標百法及二無我，以為宗旨，乃一論之綱領」。
2. **五位分类**：一切法略分五种——心法（八种）、心所有法（五十一种）、色法（十一种）、心不相应行法（二十四种）、无为法（六种），合计百法。窥基解依次释义：心法即心王（八识）；心所法为「心王所有之法」；色法为「質礙之法」；不相应行法「不與心相應，行蘊所攝」；无为法「無造作之法」。
3. **八识系统**：眼、耳、鼻、舌、身、意、末那、阿赖耶八识。窥基解的要点：前五识各依五根各缘五尘；第六意识「遍緣一切法，有分別計度等作用」；第七末那识「恆審思量，執阿賴耶識為自我」；第八阿赖耶识为根本识，「含藏一切有漏無漏種子，為諸法生起之根本」。
4. **五十一心所的六位分科**：遍行五（作意、触、受、想、思——「遍於一切心、一切時、一切處」）、别境五（欲、胜解、念、定、慧——「別別緣境而得生」）、善十一（信、精进、惭、愧、无贪、无瞋、无痴、轻安、不放逸、行捨、不害）、烦恼六（贪、瞋、痴、慢、疑、恶见）、随烦恼二十（忿、恨、覆、恼等）、不定四（悔、眠、寻、伺）。
5. **六无为与二无我**：虚空无为、择灭无为、非择灭无为、不动灭无为、想受灭无为、真如无为；百法的归趣即「人无我」与「法无我」——「此六無為，皆顯示諸法之真實性」。

其核心思想一言以蔽之：以百法为「一切法」的名数总集，逐层分析至无为真如，最终收摄于「无我」之理——瑜伽行派「分析而后见空」的方法论，在此论此解中表露无遗。与中观「直破」的进路不同，唯识先立后破：先把经验世界分解为百法（心王心所色法不相应行皆是依他缘起的有为法），再于百法之上证成人法二空（无为真如），故窥基说百法「攝之盡矣」。

## 三、学术研究价值与争议

1. **唯识教学的入门枢纽**：《百法》以名数提纲的方式浓缩瑜伽行派全部范畴，窥基解更以「定义＋科判」的方式使其成为可教学的读本；慈恩宗（法相宗）千余年的入门传统即以此书为阶梯，本档案原文档称之为「唯識宗入門之必讀文獻」允为定评。
2. **心理学史的价值**：八识五十一心所的分类体系，相当于一部古代的「心理功能与心理现象分类学」——遍行、别境、烦恼、随烦恼的分位思想严密，为比较心理学与佛教心理学研究提供了高密度的古代理论材料。
3. **著录与真伪的文献学问题**：如「文献背景」节所述，T1836 的作者著录（明普泰 vs 窥基）存在档案原文档与通行目录的出入，涉及明代唯学复兴时对唐人注书的重刊与托名问题，是使用此书前必须辨明的文献学关口。
4. **「无我」与「有法」的义理张力**：百法体系把「法相」铺陈得井井有条，而论旨归于「无我」，二者间「安立假法」与「遮遣实执」的关系，是唯识与中观诤论（依他起为有抑为无）的缩影，历来为义理研究重点。
5. **与同库条目的关系**：原论 T1614 见 `00182_大乘百法明門論`；近世注释系统另见 `00473_大乘百法明門論釋`；本条目（01446）依档案原文档专解窥基（或题为窥基）之《论解》，读者宜与上述条目并参。
