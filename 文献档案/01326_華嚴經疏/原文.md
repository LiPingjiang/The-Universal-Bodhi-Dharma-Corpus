# 華嚴經疏

## 一、概述

**大正藏編號**：T1735（《大正新脩大藏經》第 35 冊）

**全稱**：《大方廣佛華嚴經疏》

**撰者**：唐·澄觀（738—839），清涼國師，華嚴宗四祖，署名「唐清涼山大華嚴寺沙門澄觀撰」

**卷數**：六十卷（原撰二十卷，後擴充整理為六十卷）

**所釋經本**：唐·實叉難陀所譯《八十華嚴》（新譯華嚴，三十九品，七處九會）

**撰述年代**：唐德宗興元元年（784）正月始撰，貞元三年（787）十二月完成，歷時四年

《大方廣佛華嚴經疏》是華嚴宗四祖澄觀註釋《八十華嚴》的根本著作，通稱《華嚴大疏》或《清涼疏》。澄觀因感於舊有註疏「文繁義約」，遂發心重新為《華嚴經》作疏。書成之後，貞元四年（788）應賢林之請在五臺山大華嚴寺開講，貞元七年（791）又應河東節度使李自良之邀在太原崇福寺宣講，影響極大。

全書體例總啟十門：一、教起因緣；二、藏教所攝；三、義理分齊；四、教所被機；五、教體淺深；六、宗趣通局；七、部類品會；八、傳譯感通；九、總釋經題；十、別解文義。此「十門釋經」的格局，與法藏《探玄記》十門一脈相承而略有調整，後成為漢傳佛教註疏的典範體例。

澄觀在思想上繼承法藏的五教判與新十玄，同時作出重要推進：他把「法界」直接詮釋為「一心」「心體」，並系統確立了**四法界**（事法界、理法界、理事無礙法界、事事無礙法界）的理論架構，這一架構成為後世理解華嚴哲學最通行的綱領。

此疏後與澄觀自撰的《大方廣佛華嚴經隨疏演義鈔》（T1736）合刊，合稱《華嚴經疏鈔》，是華嚴學最龐大的註疏體系。

需要說明的是：「華嚴經疏」一名並非澄觀專有。智儼所撰《大方廣佛華嚴經搜玄分齊通智方軌》（《搜玄記》）亦曾稱《華嚴經疏》，法藏《探玄記》亦有《華嚴經疏》之別稱。本篇所述為澄觀 T1735 本。

## 二、核心段落

### （一）疏序開篇：法界為佛法大宗

**原文：**

> 往復無際，動靜一源，含眾妙而有餘，超言思而迥出者，其唯法界歟。剖裂玄微，昭廓心境，窮理盡性，徹果該因，汪洋沖融，廣大悉備者，其唯大方廣佛華嚴經焉。

**白話對照：**

往來反覆而沒有邊際，動與靜同出於一個本源，涵容一切玄妙之理而仍有餘蘊，超越言語思慮而迥然拔出——能當得起這樣描述的，大概只有「法界」了吧。

剖開玄奧幽微之處，昭明開廓心與境的實相，窮盡義理、徹了本性，貫徹佛果而又賅攝修因，汪洋浩瀚、沖和圓融，廣大而無所不備——能當得起這樣描述的，大概只有《大方廣佛華嚴經》了吧。

這是全篇疏序的總起。澄觀不像其他疏家那樣先敘佛陀應化、隨宜說法，而是開門見山直標「法界」，正因法界既是此經所宗，又是諸經之通體、諸法之通依，是一切眾生迷悟的根本、一切諸佛所證的究竟。

### （二）疏序：佛成正覺與七處九會

**原文：**

> 故我世尊，十身初滿，正覺始成，乘願行以彌綸，混虛空為體性。富有萬德，蕩無纖塵。湛智海之澄波，虛含萬象；皎性空之滿月，頓落百川。不起樹王，羅七處於法界；無違後際，暢九會於初成。

**白話對照：**

所以我們的世尊，在十身剛剛圓滿、正覺剛剛成就之時，乘著大願大行來周遍統攝一切，融混虛空作為自己的體性。他富足地具有萬般功德，又蕩然清淨得沒有一絲微塵。

如同湛然智慧之海的澄澈波面，空虛之中含映著萬象；如同皎潔法性空寂的滿月，一時之間頓然映落於百千江河。

他不曾離開菩提樹下的座位，卻把七個說法處所羅列遍布於整個法界；不違背未來的時際，卻在初成正覺的當下暢演了九次法會。

### （三）疏序：真妄交徹、事理雙修

**原文：**

> 其為旨也，冥真體於萬化之域，顯德相於重玄之門。用繁興以恒如，智周鑒而常靜。真妄交徹，即凡心而見佛心；事理雙修，依本智而求佛智。理隨事變，則一多緣起之無邊；事得理融，則千差涉入而無礙。

**白話對照：**

這部經的宗旨在於：把真如本體冥合於萬般變化的領域之中，把功德相狀顯現於重重玄妙的法門之內。妙用繁複興起而恆常如如不動，智慧周遍鑒照而恆常寂靜。

真與妄交相徹通，所以就在凡夫這一念心中便可見到佛心；事與理雙運同修，所以依憑本有的智慧去求證佛的智慧。

真理隨順事相而顯現變化，於是有一與多互為緣起的無邊法門；事相得到真理的融通，於是千差萬別的事物互相涉入而毫無障礙。

### （四）疏序：華嚴境界的十重譬喻

**原文：**

> 故得十身歷然而相作，六位不亂以更收。廣大即入於無間，塵毛包納而無外。炳然齊現，猶彼芥缾；具足同時，方之海滴。一多無礙，等虛室之千燈；隱顯俱成，似秋空之片月。重重交映，若帝網之垂珠；念念圓融，類夕夢之經世。法門重疊，若雲起長空；萬行芬披，比華開錦上。

**白話對照：**

因此，佛的十身歷歷分明而又互相作成；菩薩的六種階位不相雜亂而又互相收攝。廣大之物即入於無有間隙之中，一微塵一毫毛卻能包納一切而沒有外余。

一切法炳然齊現，如同芥子瓶中盡納萬物；一切法具足同時，好比大海中的每一滴水都同具海味。一與多互不妨礙，如同空室之中點燃千盞燈，光光相涉而不相礙；隱與顯同時成就，好似秋日晴空中的一彎片月，明處暗處俱在。

重重交相輝映，如同帝釋天寶網上垂懸的明珠，珠珠互現；念念圓融無礙，好比一夜之夢卻經歷了一生一世。法門層層重疊，如同雲氣騰起於萬里長空；萬般修行紛披開展，好比繁花盛開在錦繡之上。

### （五）疏序：稱性極談

**原文：**

> 剖微塵之經卷，則念念果成；盡眾生之願門，則塵塵行滿。真可謂常恆之妙說，通方之洪規，稱性之極談，一乘之要軌也。尋斯玄旨，卻覽餘經，其猶杲日麗天，奪眾景之耀；須彌橫海，落群峯之高。

**白話對照：**

剖開一微塵中所含的大千經卷，那麼念念之間佛果便已成就；窮盡眾生無邊的願行法門，那麼塵塵之處菩薩行便已圓滿。

這真可以稱得上是恆常不變的微妙之說，是通達十方的宏大規範，是稱合法性的究極之談，是一乘教法的根本軌則啊。

探尋了《華嚴》這樣的玄妙宗旨之後，再回頭去看其他經典，那情形就好比明亮的太陽高懸中天，奪去了眾多星辰景物的光耀；又好比須彌山橫亙大海，襯得群峰的高度都低落了下去。

### （六）總啟十門

**原文：**

> 將釋經義，總啟十門：一、教起因緣；二、藏教所攝；三、義理分齊；四、教所被機；五、教體淺深；六、宗趣通局；七、部類品會；八、傳譯感通；九、總釋經題；十、別解文義。

**白話對照：**

將要解釋這部經的義理，總共開立十個門類：第一，闡明教法興起的因緣；第二，判定此經在三藏十二分教中的歸屬；第三，辨析此經義理的層次分限；第四，簡別此教所攝受的根機；第五，論述教法體性的深淺；第六，說明宗旨趣向的通與局；第七，梳理此經的部類與品會；第八，記述傳譯的源流與感應；第九，總釋經題名目；第十，逐段別解經文。

### （七）四法界

**原文：**

> 統唯一真法界，即總該萬有，便是一心。然心融萬有，便成四種法界：一、事法界，界是分義，一一差別，有分齊故；二、理法界，界是性義，無盡事法，同一性故；三、理事無礙法界，具性分義，性分無礙故；四、事事無礙法界，一切分齊事法，一一如性融通，重重無盡故。

**白話對照：**

總攝起來只是一個真實的法界，它總括涵蓋一切存在，也就是這一念心。然而這一心融攝萬有，便開展成四種法界：

第一，**事法界**——「界」在此取「分」的意思，指一切事物各各差別、各有其分限界域。

第二，**理法界**——「界」在此取「性」的意思，指無窮無盡的事法同歸於一個真如體性。

第三，**理事無礙法界**——兼具「性」與「分」兩重意義，指理體與事相彼此融通、互不妨礙。

第四，**事事無礙法界**——一切有分限的事法，每一法都如同真性那樣融通無礙，彼此相即相入、重重無盡。

（此段見澄觀立宗之文，宗密《注華嚴法界觀門》引作「法界統唯一真法界，總該萬有即是一心」，是四法界說最權威的表述。）

## 三、名句

**其一**

> 往復無際，動靜一源，含眾妙而有餘，超言思而迥出者，其唯法界歟。

往來反覆沒有邊際，動與靜同出一源，涵容一切玄妙而仍有餘蘊，超越言語思慮而迥然特出——能當此稱者，唯有法界。

此為《華嚴經疏》全序的第一句，也是漢傳佛教註疏文學中最著名的開篇之一。澄觀不從佛陀說法因緣講起，而徑直標舉「法界」為佛法大宗，奠定了整部疏的思想基調。「往復」為用大，「動靜一源」為體大，「含眾妙」為相大，「超言思」則融拂前三，短短四句已含攝體相用三大之義。

**其二**

> 真妄交徹，即凡心而見佛心；事理雙修，依本智而求佛智。

真與妄交相徹通，就在凡夫的當下一念心中便能見到佛心；事與理雙運兼修，依憑本自具足的智慧去求證佛的智慧。

這兩句是澄觀「一心法界」思想最凝練的表達，也是華嚴宗與禪宗會通的關鍵所在。它既否定了真妄截然二分的立場，又保住了修證的必要性——凡心即佛心，故頓悟有據；依本智求佛智，故漸修不廢。宗密日後倡「頓悟漸修」，思想淵源即在此。

## 四、術語表

| 術語 | 說明 |
|-----|------|
| **法界** | 澄觀疏中的核心概念。統唯一真法界，即一心。既是此經所宗，又是諸經通體、諸法通依、眾生迷悟之本、諸佛所證之極。 |
| **四法界** | 澄觀確立的華嚴根本架構：事法界（差別分齊）、理法界（同一體性）、理事無礙法界（性分無礙）、事事無礙法界（重重無盡）。 |
| **事事無礙** | 四法界中的最高層次，也是華嚴宗區別於其他各宗的標誌。指一切差別事法各各如真性般融通，相即相入，重重無盡。 |
| **十門釋經** | 澄觀疏的體例：教起因緣、藏教所攝、義理分齊、教所被機、教體淺深、宗趣通局、部類品會、傳譯感通、總釋經題、別解文義。前九門為懸談，第十門為正釋。 |
| **十身** | 佛所具的十種身。《華嚴》以毘盧遮那十身圓滿為教主形象，序文「十身初滿」即指此。 |
| **七處九會** | 《八十華嚴》的說法結構：在七個處所（菩提場、普光明殿、忉利天、夜摩天、兜率天、他化自在天、逝多林）舉行九次法會。序文「羅七處於法界，暢九會於初成」即指佛不起樹王之座而遍演一切。 |
| **六位** | 菩薩修行的六種階位（十信、十住、十行、十迴向、十地、等妙覺）。「六位不亂以更收」指階位分明而又互攝互收。 |
| **芥缾** | 芥子瓶。譬喻極小之器能盡納萬物，喻一微塵含容一切法而炳然齊現。 |
| **帝網垂珠** | 即因陀羅網。帝釋天宮寶網結珠，珠珠互映、影中現影，喻法界重重無盡。 |
| **稱性之極談** | 稱合真如法性而說的究極言教。澄觀以此四字定位《華嚴經》在一代時教中的地位。 |
| **懸談** | 在逐句解經之前，先總論一經大意綱宗的部分，相當於總論。與「隨文解釋」（正釋）相對。 |
| **八十華嚴** | 唐·實叉難陀於證聖元年（695）在洛陽譯出的《大方廣佛華嚴經》八十卷本，三十九品、七處九會，較《六十華嚴》完備，澄觀此疏所依即此本。 |

## 五、相關文獻

**澄觀本人的相關著作**

- 《大方廣佛華嚴經隨疏演義鈔》（T1736，九十卷）：澄觀自釋此疏之作，與本疏合刊為《華嚴經疏鈔》。
- 《華嚴法界玄鏡》（T1883）：澄觀註釋杜順《華嚴法界觀門》之作，是理解華嚴三觀與四法界關係的關鍵文獻。
- 《華嚴經行願品疏》：疏釋《四十華嚴》普賢行願品。
- 《三聖圓融觀門》《華嚴心要法門》：澄觀闡發華嚴觀行的短篇。

**所依經本與前行註疏**

- 《大方廣佛華嚴經》八十卷（T279）：實叉難陀譯，本疏所釋經本。
- 《大方廣佛華嚴經》六十卷（T278）：佛陀跋陀羅譯，晉譯本。
- 智儼《華嚴經搜玄記》（T1732）：華嚴二祖之作，亦稱《華嚴經疏》。
- 法藏《華嚴經探玄記》（T1733，二十卷）：華嚴三祖疏釋《六十華嚴》之作，本疏在十門體例與新十玄上直承此書。
- 法藏《華嚴一乘教義分齊章》（T1866）：五教判的根本文獻。
- 杜順《華嚴法界觀門》：華嚴三觀的源頭。

**後續與旁及**

- 宗密《注華嚴法界觀門》（T1884）：華嚴五祖註釋，其中引錄澄觀四法界之文。
- 宗密《原人論》（T1886）、《禪源諸詮集都序》（T2015）：華嚴禪的建立。
- 李通玄《新華嚴經論》（T1739）：與澄觀同時而別立一系的華嚴解釋傳統，可資對照。
