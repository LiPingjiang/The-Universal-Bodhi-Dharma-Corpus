# 四分律刪補隨機羯磨 · 原文

## 一、文獻概述

《四分律刪補隨機羯磨》（全稱《曇無德部四分律刪補隨機羯磨》），一卷（或作二卷、四卷），唐代道宣律師於貞觀年間依《四分律》刪定而成，收於《大正新修大藏經》第四十冊，編號T1807。據明蕅益智旭《閱藏知津》所著錄：「曇無德部四分律刪補隨機羯磨（二卷或作四卷），唐沙門釋道宣撰。」「羯磨」為梵語 karman 之音譯，意譯為「業」或「辦事」，指僧團依律處理受戒、說戒、懺悔、安居、分衣等法事之表決與作業程序，是僧團「立法」與「司法」的具體作法。道宣鑒於當時律學「文繁、事闕」之弊，將《四分律》二十犍度中散見之羯磨文，依實際行事之需刪繁補闕、分類編次，輯成此簡明實用的羯磨範本，使僧團日常一切法事皆有軌則可循。

本書為南山律學「作持」（修善之作法）門之根本典據：道宣復自為此書作疏，即《四分律刪補隨機羯磨疏》四卷（分作八卷），簡稱《羯磨疏》，又稱《業疏》（大正藏T1808），與《行事鈔》《戒疏》合稱南山三大部。其注釋有宋允堪《四分律隨機羯磨疏正源記》、宋元照《四分律羯磨疏濟緣記》等；明末讀體（見月）律師復依之撰《毗尼作持續釋》十五卷。據律宗史載，南宋以後律學衰微，唐宋律疏散佚，明末清初僅存《隨機羯磨》一部，蕅益、見月諸師欲中興律宗即以此書為據，可見其於律學存續之關鍵地位。

## 二、核心段落選錄

> **原文**：羯磨之通例文體，凡白四羯磨皆先「白」後「羯磨」，其受具足戒羯磨云：「大德僧聽！此某甲從和尚某甲求受具足戒。此某甲今從眾僧乞受具足戒，某甲為和尚。某甲自說清淨，無諸難事，具足三衣缽。若僧時到僧忍聽，僧今授某甲具足戒，某甲為和尚，白如是。」「大德僧聽！此某甲從和尚某甲求受具足戒……誰諸長老忍，僧與某甲受具足戒、某甲為和尚者默然，誰不忍者說。是初羯磨、第二羯磨、第三羯磨（說亦如是）。僧已忍，與某甲受具足戒竟，某甲為和尚。僧忍默然故，是事如是持。」（依《四分律》及《刪補隨機羯磨》所傳受戒白四羯磨之通行文體）
> **白話對照**：僧團授具足戒時的法定程序是：先向大眾僧「告白」一次（白），徵詢「若僧時到、僧忍聽」；再作三次正式表決（三番羯磨），每次詢問「誰同意者默然，不同意者發言」；三次皆無異議，主持人即宣布「僧團已一致通過，為某甲授戒、以某甲為和尚，此事如此辦理」。此即「白四羯磨」，一秉僧團民主程序而成立戒法。

> **原文**：據《閱藏知津》解題：此書為「唐沙門釋道宣撰」，依曇無德部《四分律》刪補而成，以應「隨機」之用——「機」謂時機、根機，羯磨之作法須隨時代因緣而損益取捨，故云「隨機」。
> **白話對照**：蕅益大師在《閱藏知津》中指出：道宣此書是把《四分律》中的羯磨文重新整理，「隨機」即隨順時代因緣與實際需要而刪補調整，使古老律制在中國僧團中切實可行。

> **原文**：據律宗史載：明末清初，「唐宋諸家律學撰述皆散佚不存，至明末清初只餘一部《隨機羯磨》。那時有蕅益、見月兩位老人欲重興律宗，可是對唐宋古典已遍索不得了。」（據律學史通行論述）
> **白話對照**：唐宋律學高度發達，但經過數百年戰亂與律學中衰，到明末時各家律疏幾乎全部失傳，唯一完整保存下來的就是這部《隨機羯磨》。蕅益大師與見月律師中興律宗，所能依據的根本典籍就是它。

## 三、重要名句

> **名句一**：「僧今和合，何所作為？」——羯磨作法之起問語：僧團和合聚會，要做什麼法事？一切僧事由此而立。

> **名句二**：「白四羯磨」——一白三羯磨，僧團重大法事（如受具足戒）之法定程序，體現佛教僧團最早之民主表決制度。

> **名句三**：「若僧時到，僧忍聽」——羯磨有效之前提：時間因緣具足、與會者皆忍可默然。

> **名句四**：「是事如是持」——羯磨終結之宣告語：此事即如此辦定，法事由是成立。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 羯磨（karman） | 梵語音譯，意為「業」「辦事」；僧團處理法事之作法程序 |
| 白 | 羯磨前向大眾僧之告白宣示 |
| 白四羯磨 | 一白三羯磨，重大僧事之完整表決程序 |
| 單白／白二 | 只白不表決／一白一羯磨，較輕僧事之程序 |
| 作持 | 「止持」之對稱，指應當積極履行之善行作法 |
| 犍度 | 律藏中制度儀軌篇章，羯磨文之來源 |
| 隨機 | 隨順時機因緣而刪補損益，道宣律學之方法 |
| 業疏 | 《刪補隨機羯磨疏》之別稱，道宣自疏其羯磨 |
