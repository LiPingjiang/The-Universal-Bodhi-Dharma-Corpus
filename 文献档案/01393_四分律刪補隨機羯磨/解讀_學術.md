# 四分律删补随机羯磨 — 学术解读

## 一、文献背景与成书

《四分律删补随机羯磨》全称《昙无德部四分律删补随机羯磨》，一卷（或作二卷、四卷），唐代道宣律师（596–667）于贞观年间依《四分律》删定而成，收于《大正新修大藏经》第四十册，编号 T1807。"羯磨"为梵语 karman 音译，意译"业"或"办事"，指僧团处理受戒、说戒、忏悔、安居、分衣等法事的表决与作业程序。道宣鉴于当时所传诸本羯磨"文繁、事阙"、诸部混杂，遂一依昙无德部之文，删繁补阙、依实际行事分类编次，辑成此简明实用的羯磨范本。本库另设 `01392_四分律隨機羯磨` 同书条目，本条侧重其作为制度文本的编纂方法与法事程序，彼条侧重其流传史，二篇互注，宜并读。

道宣复自为此书作疏，即《四分律删补随机羯磨疏》（《羯磨疏》，又称《业疏》），与《行事钞》《戒疏》合称南山三大部。本书属于南山律学"作持"门——即"应当积极履行之善行作法"——的根本典据。

## 二、文本结构与核心思想

全书内容大别为二：一是"集法缘成"等通叙羯磨的法体、缘成、失坏之理，相当于羯磨的"法理学"总纲；二是别列诸羯磨法文，依受戒、说戒、安居、自恣、受衣钵药、忏悔、治罚、谏喻、杂行、住处（结界）等门，备载单白、白二、白四诸羯磨定文。凡僧团三业之作法——上至传授具足戒、呵责摈除，下至分衣与房——皆有文可依。

核心在羯磨的程序设计。以受具足戒的"白四羯磨"为例：先向大众僧"告白"一次（白），征询"若僧时到僧忍听"；再作三番正式表决，每次问"谁诸长老忍……者默然，谁不忍者说"；三次皆无异议，主持人宣布"僧已忍……是事如是持"，法事即告成立。程序分三级：单白（只白不表决，最轻僧事）、白二（一白一羯磨）、白四（一白三羯磨，最重法事），依事之轻重递增。羯磨成立还须"人、法、事、界"四种如法——到场人数够、文句合法、所办事真实、在结界范围内——这是唐代之前即已成熟的一套程序法。

## 三、学术研究价值与争议

价值有三。第一，它是研究佛教僧团"程序正义"的第一手文本：白四羯磨以公开告白加三轮默然表决成立决议，被认为是人类制度史上相当早的民主表决程序，与希腊罗马传统之外另成一系。第二，"随机"二字是道宣律学方法论的自白——删补之准则不在墨守旧文，而在应机适时，为律制如何跨越文化时空提供范本；这一方法论也使本书在中国、朝鲜半岛、日本戒律史上持续有效。第三，其流传史极富戏剧性：南宋以后律学衰微、唐宋律疏散佚，明末清初仅存此《随机羯磨》一部，蕅益智旭、见月读体中兴律宗皆以此为根本所依，见月更依之撰《毗尼作持续释》十五卷，民国弘一律师弘传南山亦以此书与《行事钞》并重。

争议方面：一、本书与《四分律》原文的关系——道宣的删补在多大程度上改动了律文，历代律家即有辨析；二、"随机"的界限——删补之后文句与广律不一致处，如何在"忠实传译"与"切实行事"之间取舍，至今仍是律学研究的方法论问题；三、白四羯磨中"默然即认可"的表决原则，与现代表决观念的比较研究仍待深入。

|---|---|
| 羯磨（karman） | 梵语音译，意"业""办事"，僧团法事之作法程序 |
| 白 | 羯磨前向大众僧之告白宣示 |
| 单白／白二／白四 | 依事轻重分级之三等羯磨程序 |
| 僧忍听 | 羯磨有效前提：与会者皆忍可默然 |
| 是事如是持 | 羯磨终结宣告语：此事如此办定 |
| 作持 | 应当积极履行之善行作法，与"止持"相对 |
| 犍度 | 广律中制度仪轨篇章，羯磨文之所出 |
| 结界 | 划定作法有效范围之羯磨 |

| 业疏 | 道宣自疏其羯磨之书，南山三大部之一 |
