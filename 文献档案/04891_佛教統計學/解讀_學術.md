# 佛教统计学 — 学术解读

## 一、文献背景与成书

本条目是档案库中的现代学科综述类专题，主题为佛教统计学，即研究以统计方法描述与分析佛教现象的领域，包括佛典文本的定量统计、佛教人口的调查统计与佛教史的计量分析三个层面。需要定位：统计学方法的系统应用是二十世纪的产物，但其雏形在佛典内部早有痕迹——条目指出经典本身即含计数统计意识，如《杂阿含经》记载「于此五百比丘得法眼净」这类证果人数的记录。

三个层面的成熟度并不一致。文本统计是最成熟的面向：CBETA的全文检索系统使词频统计、用字分布、概念演变的量化研究成为可能，如统计「佛性」「空」「如来藏」等核心概念在历代译经与注疏中的出现密度，以印证或修正思想史结论；日本学界对《大正藏》的用字用语统计有多年的「计量文献学」传统。人口统计方面，美国皮尤研究中心的全球宗教格局报告（2012年《全球宗教景况》、2015年《世界宗教的未来》）提供了系统估计：2010年全球佛教徒约近五亿，主要分布于亚太地区，并预测2050年全球佛教人口比例将因人口结构因素而略降——这一「佛教人口稳定甚至下降」的统计事实已成为国际佛教研究界的公共议题。社会科学方面，佛教信仰的代际变迁问卷统计、正念练习人群的心理量表测量（如五因素正念量表FFMQ）皆为活跃领域。

## 二、文本结构与核心思想

条目原文分五节。核心议题一节列出四个层面。其一，词频与思想史：概念出现频率的变化能否作为义理兴衰的证据？「远读」方法补充而非取代传统义学判断。其二，佛教人口统计的困境：「佛教徒」的定义在东亚「多重宗教认同」背景下难以操作化——中国民众烧香拜佛而不自认佛教徒，统计口径直接影响结论。其三，禅修效果的统计研究：正念随机对照试验的元分析（条目引2025年《Frontiers in Public Health》系统综述报告VR正念对焦虑抑郁的效应量约0.975）把佛教修行转化为可检验的变量。其四，统计方法论的反省：诸行无常提示一切统计皆是时点截面；无我提示「总体」只是名言设施，个体差异（方差）与总体均值同等重要。

佛教对统计的态度，条目概括为「不昧因果、不迷数字」：数量是缘起的描述而非实相本身。经典依据引《杂阿含经》证果人数之记载与《金刚经》「三千大千世界其中众生若干种心，如来悉知」而「实无所知」——统计总摄与个体观照之不二。代表学者一节收录了皮尤研究中心的两份人口统计报告、CBETA支撑的词频与文本统计、中国人民大学「数字人文与佛教研究」讲座对TF-IDF、向量空间模型、主题模型的介绍，以及理查德·戴维森团队对长期禅修者的脑成像研究（与高曼合著《改变的特质》指出1970-2016年间正念研究论文达6838篇，本身就是一项文献统计成果）。

## 三、学术研究价值与争议

研究价值有三。其一，文本统计为思想史提供了新的证据类型：核心概念的分布密度可以检验「某思想兴起于某时代」之类的断言，使义学判断获得量化旁证，CBETA使这类研究在汉传佛教领域的成本空前降低。其二，人口统计揭示了「宗教归属」在东亚的操作化难题——多重宗教认同现象迫使国际统计机构反思其分类框架，这一方法论反思的受益者不限于佛教研究。其三，禅修科学的统计研究将修行效果转化为可检验变量，尽管争议众多，其严格的对照设计与元分析规范为「经验性宗教研究」树立了方法标杆。

争议与限度方面：第一，词频作为义理兴衰证据的效度问题——概念出现少可能是思想式微，也可能是表述方式改变、文本存佚偏差所致，因果推断的空间有限，条目以「补充而非取代」为界。第二，统计口径的敏感性——东亚语境下「佛教徒」的定义差异可以造成数以亿计的人口估计出入，皮尤报告自身也标注了不确定性；将此类数字径直引用为实相，恰是条目所反对的「迷数字」。第三，正念RCT研究的局限——样本（多为西方、自我选择人群）、指标（量表而非解脱）、效应量的解读争议都存在；效应量0.975之类的数字需要在研究语境中理解，跨情境引用容易误导。佛教式的回答（无常、无我）反而是对这些限度的准确概括。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 词频统计 | 统计词语在文本中出现次数的方法。 |
| 远读 | 对大规模文本整体模式的量化阅读。 |
| 随机对照试验 | 随机分组检验干预效果的实验设计。 |
| 元分析 | 对多项研究结果作统计合成的方法。 |
| 效应量 | 干预效果大小的标准化统计指标。 |
| 多重宗教认同 | 同时参与多个宗教实践的认同状态。 |
