# 中观心论 — 学术解读

## 一、文献背景与成书

《中观心论》（Madhyamakahṛdaya，全称《中观心论颂》）为清辨（Bhāvaviveka，约490-570年，或作 Bhāviveka）所造，约成书于6世纪，是清辨阐述自续中观（Svātantrika）立场的核心著作。本论为颂体，清辨自作长行注释，名《思择焰》（Tarkajvālā）——颂与自注合观，构成印度中观史上规模最大的综合性论书之一。梵本大半不存（仅存部分残片与引文），主要依赖藏译流传；汉地无古代译本，现代研究以藏译本为基础。

清辨生平记载散见于藏传文献（《布顿佛教史》等）：出身南印度（一说摩腊婆）刹帝利种姓，曾在那烂陀寺学习，后赴南方修行弘法，其著作多部，是中观学史上"以因明量式重构中观论证"的转折人物。本论及其自注的写作，正值瑜伽行派势力鼎盛、中观亟需方法论更新的时代。

## 二、文本结构与核心思想

全论十一品，结构为"先立自宗、次破诸宗"：首立中观自宗（二谛义、缘起无自性义），继而逐品破斥声闻（毗婆沙等部派）、瑜伽行（唯识）、以及数论、胜论、吠檀多等内外诸宗——是印度论书中对六派哲学学说概述与批驳最系统的文献之一，故具有"印度哲学史资料库"的价值。

核心思想可概括为两点：

**其一，中观非无所立**：清辨明确主张——于胜义中一切法无自性，于世俗中因果缘起宛然；二谛各有所司，破而不堕断见。反对将中观理解为纯然的"只是破他、自无所立"。

**其二，自续量式的确立**：破他宗须以自立能破之比量——即以具有（世俗层面）自性的因、喻来成立三支论式。这一方法论主张与月称（Candrakīrti）唯以"应成"（prasaṅga，归谬）破他的方法异趣，是中观学史上**自续派与应成派分途之始**。

## 三、学术研究价值与争议

研究价值方面，本论（及其自注《思择焰》）是印度中观思想史的分水岭文献：（1）它确立了"自续/应成"的方法论分歧框架，后世月称《明句论》对清辨的批评、藏传"宗义书"对两派的系统分判，皆以此为源头；（2）其破瑜伽行诸品保存了唯识学派（尤其"识有境无"论）的精细表述，是研究6世纪唯识与中观论战的双方一手材料；（3）其破外道诸品系统转述数论、胜论的教义，成为后世复原早期数论思想的重要文献来源。西方与日本学界对《思择焰》的研究（如 Yoshihito Muroji、William Ames、叶少勇等的相关工作）持续深入。

争议问题包括：（1）清辨"世俗有自性"的表述是否与其"胜义无自性"的中观立场自相矛盾——月称一系的经典批评（若世俗有自性则胜义亦应有）及其辩护，绵延至今；（2）"svabhāva"在清辨文本中认识论用法与形而上学用法的分层问题；（3）清辨与《般若灯论》作者是否同一人（"两个清辨"说），涉及中观文献群的作者身份研究。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 自续（svātantrika） | 主张以自立三支论式论证的中观路线 |
| 应成（prāsaṅgika） | 主张唯以归谬破他、不立自比量的路线 |
| 思择焰（Tarkajvālā） | 清辨为本论自作的长行注释 |
| 二谛（satyadvaya） | 胜义谛与世俗谛 |
| 无自性（niḥsvabhāva） | 一切法无独立不变的自体 |
| 戏论（prapañca） | 概念心的虚妄构画 |
