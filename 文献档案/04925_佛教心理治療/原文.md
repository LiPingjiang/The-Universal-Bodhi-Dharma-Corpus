# 佛教心理治療 · 原文

## 一、學科概述

佛教心理治療是當代心理治療中影響最深遠的佛教滲入領域。其歷史轉折點明確可考：1979年，分子生物學博士喬·卡巴金（Jon Kabat-Zinn）在麻塞諸塞大學醫學中心創立「正念減壓門診」，將佛教內觀禪修剝離宗教外衣、標準化為八周課程（MBSR），首次使禪修成為可計費、可研究的臨床干預。此後三十餘年，以MBSR為母體衍生出一系列「正念為本干預」（MBIs）：正念認知療法（MBCT，齊德爾·西格爾、馬克·威廉斯、約翰·蒂斯代爾三位認知心理學家於1990年代開發、2002年出版專著，用於預防抑鬱復發）；辯證行為療法（DBT，華盛頓大學瑪莎·萊恩漢Marsha Linehan於1980-90年代創立，1993年出版治療手冊，明言其「智慧心」與「徹底接納」取自禪宗）；以及接納承諾療法（ACT，史蒂文·海耶斯創立）中的接納技術。英國國家衛生與臨床優化研究院（NICE）已將MBCT納入抑鬱復發預防指南。

## 二、核心議題與佛教觀點

核心議題包括：（一）機制——正念療法被認為通過「去中心化」（decentering，將念頭視為心理事件而非事實）打破抑鬱的反芻循環，與佛教「於念離念」的教法一致；（二）證據——2014年約翰斯·霍普金斯大學的戈亞爾（Madhav Goyal）等人在《JAMA內科學》發表的薈萃分析確認冥想程序對焦慮、抑鬱有中等效應量；（三）世俗化爭議——佛教學者批評「拔除佛法的正念」是否仍是正念，以及宗教療法的倫理邊界。佛教對治療的根本立場由《雜阿含經》二十億耳聞弦聲而悟的公案給出：修行如調琴弦，鬆緊得中方出妙音——治療的藝術正在於對精進力度的把握，這一喻已成為正念教學的通用隱喻。

> **經典依據**：
> 「精進太急，增其掉悔；精進太緩，令人懈怠。」——《雜阿含經》（T99）

佛陀以調弦之喻教誡彈琴出家後過度苦行的二十億耳：太緊則斷（焦慮激越），太鬆則不成調（懈怠消沉），治療與修行皆當「平等修攝，莫著莫放」——這是佛教對「劑量—反應關係」的最早表述。

## 三、代表學者與實踐

卡巴金1979年在麻省大學醫學中心地下室接待第一批慢性疼痛病人，1990年出版《多災多難的人生》後MBSR風行全球，至今已有上千項臨床研究。MBCT三位創始人的軼事廣為流傳：1990年代初他們受瑪莎·萊恩漢指點前往麻省訪問卡巴金，回國後將認知療法嫁接於八周正念課程；2000年發表於《諮詢與臨床心理學雜誌》的關鍵隨機對照試驗證明MBCT將三次以上抑鬱發作者的復發率約減半。萊恩漢的DBT起初為治療邊緣型人格障礙而設，其本人公開談論自己的邊緣型特質病史，使「以患者之身立說」成為佛教式治療的動人註腳。此外，克里斯托弗·格默與羅納德·西格爾發展「基於同情的療法」，將慈心禪引入臨床，構成正念療法之後的「第二代」佛教干預。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| MBSR（正念減壓） | 卡巴金創立的八周正念課程，現代正念療法之母 |
| MBCT（正念認知療法） | 融合認知療法與正念的抑鬱復發預防方案 |
| DBT（辯證行為療法） | 萊恩漢融合禪宗接納觀與行為技術的療法 |
| 去中心化 | 將思想感受視為暫時心理事件的能力 |
| 徹底接納 | DBT核心技能，源自禪宗的如實接納 |
| 精進（vīrya） | 佛教六度之一，恰當而不過度的努力 |
