# 大乘起信論纂注 — 学术解读

## 一、文献背景与成书

《大乘起信論纂註》二卷，明·真界纂注，收于《卍續藏》第四十五册，经号 X0762（CBETA：X45n0762）。真界自署「明擕李沙門真界纂註」，擕李即今浙江嘉兴。所依底本为梁·真谛译《大乘起信論》一卷（T1666）。丁福保《佛學大辭典》「大乘起信論」条列历代注疏，明确记作「起信論纂注二卷（明真界纂注）」。

须订正一处旧误：本档旧有目录题此书为「明代云栖祩宏（莲池大师）所撰」，与文献不符。CBETA 原书题署为「明擕李沙門真界纂註」，丁氏辞典亦作明真界纂注，莲池祩宏并无《起信論纂註》之作。真界为明中期嘉兴僧，生平资料不多，其名见于《续藏》所收此书及同系撰述。

「纂註」之名，真界释题时自作交代：「言纂註者，謂纂集疏記要義，以釋此論也。」——所纂者为前代疏记的要点，属「汇编再释」型注疏，非独出机杼的新解。其成书动机是对前人体例的不满，详见下节。

## 二、文本结构与核心思想

本疏释题部分保存了一段注疏体例批评的珍贵史料：「然疏記流布，其來久矣。今復纂之者，蓋以賢首疏釋，論疏各分。而圭峯以為覧者不便，即碎析疏文，列於論下，使論疏錯雜，而章段不分。雖則便於披覧，又復困於支離，而弗克見本論渾全之旨，不無尋枝之厭。故今聯合論文，而分章段，收束科目，以為斷章。復纂集要義，隨文銷釋。」——这段话把《起信論》注疏的版本史一语道尽：法藏《義記》（T1846）的体例是论、疏各自分卷，读者须两书对翻；宗密（圭峰）为方便读者，把疏文切碎逐条置于论文之下（T1847），从此论疏错杂、章段不明——便于披览而困于支离，见不到本论的浑全脉络。真界的方案是第三条路：重新联合论文、划分章段、收束科目为「断章」，再于每章内纂集诸家要义随文销释。这一「合—分—再合」的体例辩证，正是十六世纪中国佛教注疏出版史的一个切面。

其思想立场承贤首一系而以释题为最精。释「大乘」：「言大乘者，大謂所乘之法，乘謂能乘之人。法具一心三大，人通因人、果人。」并推至能所互摄：「故知所乘即是能運，能乘即是所運。……無有餘乘，唯一佛乘，故云大乘。」释「起信」则直接把「信」安放在自心之上：「夫大乘信者，謂信自心本來清淨，本自具足，本不生滅，本來平等；亦信自心具足性德，能生萬法。」——大乘之信不是信外在对象，而是四个「本」字打底的自我确信。真界又判《起信論》为「宗論」——宗百余部大乘经而造、非释一经的论书，此判为其全书定位之所系。

## 三、学术研究价值与争议

就研究价值言，其一，版本史价值：真界对法藏「论疏各分」与宗密「碎析疏文」两种体例的批评，及自创「断章」再纂的方案，是研究佛教注疏由写本入刻本时代、由专家读物转向普及读物这一进程的直接证词。其二，注疏学价值：本书是「纂注」体的标准样本——以汇编要义为主、附以己意（「間有不符論旨者，竊附己意」），据此可以界定明代「纂注」「捷要」类注疏与唐人「义记」「疏」的功能差别。其三，考据价值：本书曾长期被误题莲池祩宏所撰，这一误题的形成与流传，本身是近代佛教书目学的典型案例，考镜其源流有助于澄清明代嘉兴一系僧人著作的著录混乱。争议与限制：其一，真界生平可考者太少，其学问渊源（是否直承华严一系）只能由内证推测；其二，本书既为纂集体，其中见解多为转引，研究明代《起信論》诠释的原创性贡献时，须将真界自附己意之处与其转引诸家处分别处理；其三，明清之际同类注疏（正远《捷要》、通润《續疏》等）彼此影响的关系，尚无确证可考。

## 四、术语对照表

| 术语 | 出处与释义 |
|---|---|
| 纂注 | 本书题名；纂集诸家疏记要义以注释本论 |
| 断章 | 真界体例语，指重新划定的完整章段 |
| 销释 | 随论文次第逐句解说的注疏方式 |
| 宗论 | 真界判《起信論》为宗百余部大乘经而造之论 |
| 能乘／所乘 | 真界释题：所乘为法（一心三大），能乘为人（因人果人） |
| 一心三大 | 众生心及其体大、相大、用大 |
| 论疏错杂 | 真界对宗密「碎析疏文列于论下」体例的批评语 |
| 浑全之旨 | 真界所追求的本论贯通全貌 |
