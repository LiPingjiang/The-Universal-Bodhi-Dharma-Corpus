# 佛教心理生理學 · 原文

## 一、學科概述

心理生理學（psychophysiology）以軀體生理指標——腦電（EEG）、皮膚電（GSR）、心率變異（HRV）、皮質醇、呼吸模式等——測量心理活動的生理基礎。佛教心理生理學即以這些指標研究禪修狀態，是冥想研究中歷史最久的實證傳統：早在1966年，日本的笠松明（Akira Kasamatsu）與平井富雄（Tomio Hirai）便發表了對禪僧坐禪的腦電研究，發現資深禪修者入定時α波振幅增高且對聲刺激的反應模式獨特，成為禪修腦電研究的開山之作。1970年代，哈佛心臟病學家赫伯特·本森（Herbert Benson）研究超覺靜坐者，提出著名的「放鬆反應」（relaxation response）概念，1975年出版同名暢銷書，將冥想帶入主流醫學視野。此後，從腦電到神經內分泌，禪修的生理效應研究蔚為大觀。

## 二、核心議題與佛教觀點

核心議題包括：（一）自主神經調節——禪修狀態下心率變異提高、呼吸減緩、交感張力下降，與佛教「身輕安、心輕安」的禪悅描述相合；（二）應激激素——多項隨機對照研究顯示正念訓練降低皮質醇水平或削弱其應激反應；（三）高級禪修狀態的生理標記——對「滅盡定」等極深禪定被試的研究（如戴維森團隊2008年發表的個案腦電報告）顯示出與常規清醒態截然不同的生理模式。加州大學戴維斯分校的「沙瑪莎計劃」甚至測得長期閉關者端粒酶活性提高（雅各布斯等，2011年發表於《心理神經內分泌學》），將禪修生理學延伸至細胞老化層面。佛教以安般念（出入息念）為調身攝心的基本法門，其「繫念於息」的操作正是可被生理測量的心理生理程序。

> **經典依據**：
> 「念於內息，繫念善學；念於外息，繫念善學。」——《雜阿含經》（T99）

佛陀於《安那般那念經》中教導如實覺知入息出息——呼吸既是可被內觀察的心理對象，又是可被儀器記錄的生理信號，天然構成心理生理研究的理想窗口：如今實驗室中的呼吸記錄與禪堂中的數息，正是同一對象的兩種「測量」。

## 三、代表學者與實踐

笠松與平井1966年發表於《Psychologia》的《禪定腦電圖研究》比較了僧侶與新手坐禪時的腦電演變，確立了「禪修腦電」的研究範式。本森在哈佛醫學院對超覺靜修者血壓、代謝率的研究催生「放鬆反應」理論，其後續研究將類似技術應用於高血壓與心血管疾病。卡內基梅隆大學的謝爾頓·科恩（Sheldon Cohen）與之合作的著名研究（2016年）顯示正念訓練降低老年人促炎基因表達。在中國大陸，學者們自1990年代起對氣功與禪修狀態開展腦電與心生理研究；台灣、香港亦有團隊以心率變異指標研究佛教念誦與禪修，形成漢語圈的區域研究傳統。這些工作共同確立了一個基本結論：禪修是有明確生理指紋的心身訓練。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 腦電圖（EEG） | 記錄腦皮層電位變化的技術，禪修研究的經典工具 |
| 放鬆反應 | 本森提出的、與應激反應相對的生理狀態 |
| 心率變異（HRV） | 心跳間期的波動，反映自主神經平衡 |
| 皮質醇 | 主要應激激素，長期升高損害免疫與記憶 |
| 安般念（ānāpānasati） | 覺知出入息的禪修法，佛教調心調身之要門 |
| 輕安（passaddhi） | 七覺支之一，身心調暢安適的禪修效應 |
