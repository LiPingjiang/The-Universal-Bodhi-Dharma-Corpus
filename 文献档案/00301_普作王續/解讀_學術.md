# 普作王续（Kun byed rgyal po）— 学术解读

## 一、文献背景与成书

《普作王续》（藏语 Kun byed rgyal po，梵名还原为 Kulayarāja，"普作之王/一切作者之王"），全名《菩提心普作王续》（Byang chub kyi sems kun byed rgyal po），是宁玛派大圆满**心部**（sems sde）最重要的续典，也是"十七续"之首要者。本档案编号 V34，语言为藏语，学界一般断代约9–10世纪。

"普作"之名直指本续主旨：一切轮回涅槃诸法皆是心之所"作"，心即普作之王。本续主尊为普贤王如来（Samantabhadra），即大圆满体系所立的法身本初佛——以蓝色裸身、定印双运之形，表心性本然无饰之相。

成书与传译史上，本续是"大圆满文献中最有特殊性的一部"：其一，卷帙庞大（藏译约七十余品），在心部十一续（一说十八续）中居于首位；其二，其文风与早期密续及"口诀"体文献不同，多用直陈式的心性开示，与大圆满"直指"传统吻合；其三，本续的存在为"大圆满心部有一套自成体系的续典文献"提供了核心证据，是讨论大圆满文献谱系绕不开的坐标。英译本方面，John Reynolds 曾译出重要章节并附长篇学术导论；梵文原典未见完整传世，学界通说视其为藏地集成（或藏译定型）的续典。

## 二、文本结构与核心思想

本续虽卷帙浩繁，其教义骨架却极为单纯，可概括为"一心普作"：

**其一，一切法自圆满。** 原文开篇即云："一切法自圆满，不假修证，本来清净。"（藏语 lhun grub，自圆满/任运成就）——大圆满的"果"不是新造的，而是本具的；修行的意义在"认出"而非"制造"。

**其二，心即法界，心即普作王。** 名句二："普作者，心也。心造一切法，心即普作王。离心无法，离法无心。心法不二，即大圆满。"这一命题使本续成为大圆满"唯心"表述最直接的经典：轮回涅槃、凡夫佛陀，皆是此心之显现，故"轮迴涅槃本来平等，众生与佛本来不二"。

**其三，虚空与云雾之喻。** 原文以"虚空中云雾自生自灭，虚空本不动摇"说明烦恼与心性的关系：烦恼有生有灭，心性不生不灭；修行不必与烦恼缠斗，只须认得不动摇的虚空本身。这是大圆满"不取不舍"修法（对念头不迎不拒）的经典依据。

**其四，众生本来是佛，不假外求。** "众生本来是佛，不假外求"一句，把如来藏思想推到果乘表述的极致：佛果不是目的地，而是出发点——问题从来不是"如何成佛"，而是"为何不识"。

## 三、学术研究价值与争议

**研究价值**：其一，本续是研究大圆满心部文献层累与定型过程的核心文本，其术语体系（ka dag 本净、lhun grub 自圆满、rig pa 觉性）成为全部大圆满文献的共享语汇；其二，"心造一切法"的表述与唯识、与如来藏系经典的互文关系，为印度-西藏心性论谱系研究提供接口；其三，本续与禅宗文献（如敦煌本《坛经》"自性本自清净"）的比较研究，是国际学界"禅与大圆满关系"论域的重要材料。

**代表学者**：Samten Karmay 关于大圆满起源与本续性质的研究具有奠基意义；John Reynolds 英译本及导论系统介绍了本续在大圆满文献中的位置；Herbert Guenther（根特）早年关于大圆满心部的译介亦多以本续为据；国内学者关于宁玛文献的研究（如沈卫荣等）对本续的史学语境亦有讨论。

**争议问题**：其一，本续是印度原本的忠实藏译，还是藏地（或于阗-藏通道）集成定型，学界至今聚讼；其二，"众生本来是佛"的表述与印度中观学派"佛果是修道所生"的立场存在张力，萨迦班智达以来的格鲁-萨迦学者对"本净成佛说"多有辨破，宁玛派则有龙钦巴、米庞等人的系统辩护；其三，本续与后期伏藏文献中"普作王"名相的混用，需要文献学清理。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 普作王（Kulayarāja / Kun byed rgyal po） | "一切作者之王"，指心为万法总源头 |
| 自圆满（lhun grub） | 诸法本具成就，不假修造 |
| 本来清净（ka dag） | 心性从未被烦恼染污 |
| 觉性（rig pa） | 心之本明，认取心性之所依 |
| 法界（Dharmadhātu） | 一切法之真实体性，与心无二 |
| 普贤王如来（Samantabhadra） | 大圆满之法身本初佛，本续主尊 |
