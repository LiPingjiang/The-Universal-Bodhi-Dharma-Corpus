# 大乘起信论究竟义精 — 学术解读

## 一、文献背景与成书

「精」谓精义、精要、精华，指从繁富的文本与注疏传统中提炼思想内核的工作。这一传统可以追溯到《系辞》「精义入神」之训，汉地学问素以「由博返约」为最高标准：读书万卷，最后要能以数语尽其要；注疏积累如山，最终要能标出几处真正的义理枢纽。在注疏诸体中，钞博而精约，科繁而简：精，是把已成的解读再压缩一次，直抵「非此不可」的那几个命题。

据本目录原文档说明，「大乘起信论究竟义精」题为《大乘起信论》注疏变体之一，其变体名属机器生成的文献变体名称，不对应独立的历史文献。但「提炼《起信论》思想精华」的工作，却是历代注家与现代学者共同的实际操作——原文档所列诸家注疏，各自都有其对「最要处」的判断；现代哲学研究更以概念分析为工具，试图从这卷短论中提炼出严格意义上的哲学命题。本条目即以「精」为纲，从全论与千年注疏史中抽绎其思想的最小内核，并检视现代学术对这一内核的哲学化重述。

## 二、文本结构与核心思想

《起信论》的思想内核，可以提炼为四个不可再省的命题。

命题一：心是一切法的基体。「所言法者，謂眾生心，是心則攝一切世間出世間法。」——全论的第一句话就已经是全部：不是先有世界再有心，而是心总摄世出世间一切法。此一「一心」之为基体的断言，是全部后续义理的地基。

命题二：此心开二门。心从本际看是真如（不生不灭、离言平等），从起用看是生灭（依如来藏而有生灭心）。二门「非一非異」——这一逻辑形式比其内容更重要：论主拒绝在一元与二元之间做简单选择，以「不二」的辩证方式安顿清净与杂染的关系。

命题三：觉性本来具足，迷是客尘。本觉义是全论最具哲学强度的概念：觉性不从因生、不假修成，无明只是「忽然念起」的客尘，故迷非觉之缺失，而是觉之覆蔽。由此，「成佛」在结构上被改写为「显了本有」而非「新得」。这一命题是禅宗「直指」与华严「性起」的共同义理根据。

命题四：真如能熏无明。在还灭的机制上，论立「内熏」义：真如作为净因，内在地熏习无明，令众生厌生死、乐涅槃；外缘（佛菩萨善友）与内因相资，遂有解行发心、证道入位的阶次。此一「自我转化可能」的机制论，是本论实践哲学的核心。

四命题合观：基体—二门—本觉—内熏，构成一个自足的形而上与实践系统。其惊人的经济性——千余字容纳一个完整体系——正是「精」体注家历来瞩目此论的原因。

## 三、学术研究价值与争议

第一，作为哲学文本的提炼。现代研究者以概念分析重述上述四命题：本论可被刻画为一种「绝对的一元论 + 功能的二元论」结构，或以「本体与现象的不二」模型处理。此类重述虽为现代产物，却印证了本论思想的可提炼性：它经得起不同哲学框架的反复压缩与重构。

第二，围绕「基体说」的批判。松本史朗指本论「一心为一切法之体」的结构为 dhatu-vāda（基体说），判其为非佛所说之缘起，而是一种一元论本体论；袴谷宪昭更进一步指本觉思想与日本社会伦理问题相关。批判者等于在说：这卷书的「精华」恰是其「病灶」。辩护者（如如来藏研究者）则回应：真如缘起不违缘起性空，基体之判出于对「不二」逻辑的误解。这一场围绕「精华还是糟粕」的争论，是当代佛学研究最重要的议题之一。

第三，「精」与「偏」的历史教训。历代「精义」式的读法各有偏至：华严精其性起，禅精其本觉，净土精其信心，唯识家则往往精其违处。提炼总是带立场的提炼——本论的解释史证明，所谓精华，从来是「为谁所用」的精华。

第四，本条目名属机器生成之虚目；然「精」之为体提醒我们：一切注疏最终都要回答「此书的一句话版本是什么」——这既是理解的完成，也是误解的开始。

| 精义 | 汉地学术语，无对应梵语 | 从博杂文本中提炼的思想内核 |
| 一心 | 约定构拟作 eka-citta | 总摄世出世法的心体 |
| 真如 | bhūta-tathatā | 心性不生不灭、离言平等之体 |
| 如来藏 | tathāgata-garbha | 众生心中本具的如来性德 |
| 本觉 | 论内自铸语，无定梵 | 本来具足、不假修成的觉性 |
| 客尘 | āgantuka-kleśa | 后起非本有的杂染覆障 |
| 内熏 | 注家依论义提炼语 | 真如自内发起净用之力 |
| 二门 | 论内自铸语 | 真如门与心生灭门 |
