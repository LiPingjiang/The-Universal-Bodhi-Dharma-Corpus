# 肇論 — 学术解读

## 一、文献背景与成书

《肇論》是东晋僧肇（384—414）的论文集。僧肇俗姓张，京兆长安人，早年家贫，以佣书为业，遍读经史，因读旧译《维摩经》而披剃出家，后师事鸠摩罗什，参与译场，被视为罗什门下「解空第一」的弟子。他年仅三十一岁早逝，却被后世誉为「中国玄宗佛教向般若学转化的完成者」。

《肇论》的结集并非僧肇手订，通行本包括《宗本义》与《物不迁论》《不真空论》《般若无知论》《涅槃无名论》四篇论文，以及僧肇与刘遗民、姚兴的往来书信，今收于《大正藏》第四十五册。四论的具体撰作年代不一：《般若无知论》作于罗什译出《大品般若》之后（约404—405年）；《物不迁论》《不真空论》约作于同一时期；《涅槃无名论》的真伪则是学术公案，汤用彤、横超慧日等学者均指出其文体、思想与前三论有异，或为后世附益。

## 二、文本结构与核心思想

《肇论》四论构成一个层层递进的般若学体系，可以视为对鸠摩罗什所传龙树中观学的中国化重述：

其一，**《物不迁论》——动静之辩**。开篇即以四组悖论式意象立论：「旋风偃嶽而常靜，江河競注而不流。野馬飄鼓而不動，日月歷天而不周。」僧肇并非否认现象界的运动，而是论证：万物各住其位、刹那不住，「动」只是俗谛上的相续假相；就每一刹那而言，法法各住一世、不从他方来，故「不迁」。这是以中观「不来不去」之八不中道观照时间与运动问题。

其二，**《不真空论》——有无之辩**。针对六家七宗中「心无」「即色」「本无」各派对空的误解，僧肇提出「不真空」——万物非实有（不真），但宛然显现（不无），「不真故空」方是正解空义。

其三，**《般若无知论》——能所之辩**。本档案所录名句「般若無知，無所不知」，点明圣智「无分别而无所不知」：般若之知不是概念性的对象认知，而是与实相冥合的寂照，「不知之知」才是真知。

其四，**《涅槃无名论》**——论证涅槃「无余」超越名言称谓，总结归于无名之道。

## 三、学术研究价值与争议

研究价值方面：（1）《肇论》是早期中国般若学摆脱「格义」玄学框架的标志，代表罗什译经后中国学僧对龙树中观的第一流消化；（2）《物不迁论》对时间、运动的讨论使其进入现代哲学比较研究的视野，有学者将其与芝诺悖论、柏格森时间观对勘；（3）《肇论》深刻影响了后世三论宗、华严宗乃至禅宗的语言风格，「江河竞注而不流」成为禅门反复参究的话头。

争议问题方面：（1）《涅槃无名论》真伪之争是《肇论》研究最大悬案，日本学界（汤用彤亦持保留态度）从文体、用典、思想线索多方位质疑；（2）僧肇对「物不迁」的论证是否成立，当代学者意见分歧：或视为华严「事事无碍」的先声，或认为存在逻辑跳跃；（3）《肇论》与庄子、玄学的亲缘关系如何评价——是「以庄解佛」还是「以佛夺庄」，关系到对整个东晋佛教思想史的重估。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 般若（Prajñā） | 般若无知之知：无分别而与实相冥合的圣智 |
| 不真空 | 万物非实有而不无，宛然而有即是「不真」，不真故空 |
| 物不迁 | 刹那各住其位、不来不去，运动是俗谛假相 |
| 八不中道 | 不生不灭、不常不断、不一不异、不来不去，中观核心方法 |
| 野马 | 春日野外浮动的阳焰，喻虚幻不实的显现象 |
| 解空第一 | 后世对僧肇的推许，谓其于罗什门下最善解空义 |
