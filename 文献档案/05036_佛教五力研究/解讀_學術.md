# 佛教五力研究 — 学术解读

## 一、文献背景与成书

五力，梵语 pañca-balāni，即信力、精进力、念力、定力、慧力，为三十七道品之第五科。五力与五根名数全同而阶位有别：根约「能生」（出生善法）、力约「能破」（摧破恶法、不为烦恼所屈伏），根增长而力成，故五力是五根的成熟形态。

经典来源：《杂阿含经》（T99）「五根五力相应」诸经，《中阿含·度经》等；《阿弥陀经》（T366）云极乐国土众鸟「演畅五根、五力、七菩提分、八圣道分」，显示五力通于大乘净土教法。论典方面，《大毗婆沙论》卷一四一（T1545）有「何缘此五名根名力」的著名问答，《俱舍论》卷二十五〈分别贤圣品〉、觉音《清净道论》「说力品」、《大智度论》卷十九至二十及《瑜伽师地论》皆有诠释。位次配属上，说一切有部以五根配暖、顶位，五力配忍、世第一法位；天台智顗《法界次第》以「根成恶破，复名为力」释二科之别。藏传菩提道次第传统则以「五力」为临终迁识（颇瓦）修法之要，此属藏地教授体系，不在汉传论典及大正藏所收论书的科判之内。

## 二、文本结构与核心思想

五力的名目与五根一一对应，其「力」义在摧破：信力破诸邪信、不为疑惑所动；精进力破身心懈怠、成办出世之法；念力破诸邪念、成就出世正念；定力破诸乱想、发起事理禅定；慧力破三界见思诸惑、能断一切邪执。《法界次第》所引问答最明二者之辨：「名同于根，何须更立？答：善根虽生，恶犹未破，更须修习，令根增长。根成恶破，复名为力。」——根是善法的出生，力是烦恼的摧破，一科二名，因果相承。

核心思想有三：其一，五力标示修行从「防」到「破」的质变——根位防善法之退失，力位则主动出击、与烦恼正面对垒；其二，《瑜伽师地论》卷九十八以「诸有学者成就五力，唯有如来成就十力」对辨五力与佛十力，显示五力是有学圣者的极限、十力是果地的圆满，力之概念由此贯通因果二位；其三，五力在道品序列中居七觉支、八正道之前，是由世间善根转向无漏现观的临门一脚——四善根位（忍、世第一法）恰是有漏慧的顶点。

## 三、学术研究价值与争议

五力研究的学术价值：第一，根力二科的名同位别是研究三十七道品编纂逻辑的典型样本——道品诸科为何重复立名，有部以位次、天台以功能分疏，两条解释路线的比较可见阿毗达磨学与中国判教的方法差异；第二，五力配忍、世第一法位的安排，牵涉「顺抉择分」理论的整体结构，是理解有部修道次第的钥匙；第三，五力概念在净土经典（《阿弥陀经》）与藏传道次第中的不同用法，是佛教概念跨传统流变的个案。

争议点：五力与五根是「体同名异」还是「体有别」——《大毗婆沙论》以生灭破立答之，然论师间仍有静诤；有学位五力与无学位十力之「力」是否同性；以及四善根位配根力的文献先后问题。

| 念力 | 念根增长，能破邪念、成就正念 |
| 定力 | 定根增长，能破乱想、发起禅定 |
| 慧力 | 慧根增长，能破三界见思诸惑 |

| 如来十力 | 果地十力，与有学五力对辨 |
