# 佛教六度研究 — 学术解读

## 一、文献背景与成书

本条目为语料库「寰宇覺海·菩提法藏」之独立文献补充条目，编号 X7762，名目作「佛教六度研究」。据实说明：其《原文》非一经一论之传本，而是以六度名数为纲的主题辑录——概述列「布施、持戒、忍辱、精進、禪定、般若」六名，选录与名句各存两条引文，术语表七条，末附相关文献指引；条目 README 自署「待後續填充內容」，性质为保存六度名数与纲要断语的名目型简编。

六度（六波罗蜜多）是大乘菩萨道的总纲，其文献谱系可考者甚明。般若经系最先确立六度为菩萨行门的总框架：《小品般若》《大品般若》广说六波罗蜜相，至玄奘译《大般若经》六百卷处处以六度收摄菩萨行；《大智度论》以释《大品般若》之体例，于般若波罗蜜一品中备论六度相。选录引文「菩薩摩訶薩應行六波羅蜜——所謂檀那波羅蜜、尸羅波羅蜜、羼提波羅蜜、毗梨耶波羅蜜、禪那波羅蜜、般若波羅蜜」正用般若经系的列举体式，六度皆存旧译对音（檀那、尸罗、羼提、毗梨耶、禅那），与鸠摩罗什译般若类典籍的用语习惯一致，可视为辑录者对般若经系六度说的撮述。

第二条引文「六度如船筏，能度眾生從生死苦海至涅槃彼岸。前五度為足，般若為目，目足並運，方能到岸」糅合了两层旧义：「到彼岸」为波罗蜜一词的语义训释；「目足並運」则本于天台家《摩诃止观》「智目行足」之喻而移用于六度，是汉地注疏传统的产物。又按：藏传寂天《入菩萨行论》以「六度统摄一切菩萨行」总纲展开全论，龙树《宝鬘论》则说「施戒忍精进、禅慧为六度」，与本条目名数全同。

## 二、文本结构与核心思想

《原文》五节悉依补充条目通例，其义理要点有三。

其一，六度作为完整的实践系统。布施（Dāna）对治悭贪、成就福德资粮；持戒（Śīla）防护身口意、为一切善法之基；忍辱（Kṣānti）安受苦辱、对治瞋恚；精进（Vīrya）勇悍策进、对治懈怠；禅定（Dhyāna）摄心一境、成就奢摩他；般若（Prajñā）照见实相、成就毗钵舍那。六者两两相资：前五为福德行，后一为智慧行。

其二，「度」的语义即解脱指向。波罗蜜（Pāramitā）旧训「到彼岸」——生死为此岸、涅槃为彼岸、六度为渡河之筏。引文的船筏喻同时暗含《金刚经》「法尚应舍，何况非法」筏喻之意：筏是工具，度河则应舍。

其三，般若的主导地位。「前五度為足，般若為目」概括了般若经系「五度如盲，般若为导」的通义：无般若则前五度同人天有漏善法，不得名为波罗蜜；必以空慧摄持，布施方成「三轮体空」之施。此即六度体系的枢纽——不在行目之多，而在般若之深。

## 三、学术研究价值与争议

第一，六度名数的成立史。学者（平川彰《大乘起の研究》、印顺《初期大乘佛教之起源与开展》等）指出：六波罗蜜的集合最早明确出现于般若经系，此前《大智度论》所引旧传及本生谭中已有施、戒、忍、精进、禅定诸分别说；巴利上座部《佛种姓经》则别立十波罗蜜（以布施、持戒、出离、智慧、精进、忍辱、真实、决意、慈、舍为序），与大乘六度、十度系统名数不同源。故六度并非佛教诸传共用的唯一纲领，而是大乘般若经系的特有构造。

第二，「目足」之喻的诠释史问题。以般若配「目」、前五度配「足」，是天台止观架构的移植；瑜伽行派《解深密经·地波罗蜜多品》则另有判释——以六度配三学（施戒忍进属增上戒学所摄的福德行、定属增上心学、慧属增上慧学），并以五事（增上生、摄受善士、饶益有情、三学、证菩提）说明六度安立的理由。两系取径不同，本条目引文采天台式的表述，读者当知其为汉地诠释传统的选择。

第三，六度与十度之辨。唯识经论于六度外别立方便、愿、力、智四度，成十波罗蜜以配菩萨十地；本条目止于六度，未涉十度，两系统的关系详见同库十度条目。又藏传依《入菩萨行论》系的传统对六度各有大量注疏，相关根本论典不在大正藏编号体系之内，应转检德格版《丹珠尔》等藏文大藏经编目。
