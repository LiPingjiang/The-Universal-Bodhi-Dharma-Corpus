# 佛教十度研究 — 学术解读

## 一、文献背景与成书

本条目为语料库「寰宇覺海·菩提法藏」之独立文献补充条目，编号 X7763，名目作「佛教十度研究」。据实说明：其《原文》非经论传本，而是以十度名数为纲的主题辑录——概述列「布施、持戒、忍辱、精進、禪定、般若、方便、願、力、智」十名，选录与名句各存两条引文，术语表八条，末附相关文献指引；条目 README 自署「待後續填充內容」，性质为保存十度名数与断语的名目型简编。

十波罗蜜的系统成立史可考。六度确立于般若经系之后，瑜伽行派经论为进一步配合菩萨十地的修行阶位，将六度扩充为十度：《解深密经·地波罗蜜多品》是最早完整立十度的经典，于六度外别立方便善巧波罗蜜多、愿波罗蜜多、力波罗蜜多、智波罗蜜多；《摄大乘论》及《成唯识论》卷九承之，以十度配十地——欢喜地修施、离垢地修戒、乃至法云地修智，一地一度，各有正修。本条目概述十名的次第（布施……般若、方便、願、力、智）与《解深密经》系统全合，选录引文「菩薩摩訶薩行十波羅蜜，所謂布施、持戒、忍辱、精進、禪定、般若、方便、願、力、智。如是十度圓滿，得無上菩提」即此系统的纲要式撮述。

第二条引文「六度為體，四度為用。以方便願力智，助般若波羅蜜，令速圓滿」是汉地注家式的体用判释，非经论原句：谓六度为十度之基本结构，后加的四度是般若在外用上的四种分化——此说于义理有据（后四度皆从后得智开出），但表述形式显系后人撮要所加。

另须说明与巴利系统的区别：上座部《佛种姓经》与《清净道论》系的十波罗蜜为布施、持戒、出离、智慧、精进、忍辱、真实、决意、慈、舍，与大乘十度仅前三名目字面相近而次第、内容均异。本条目属大乘唯识系十度，与巴利十波罗蜜不可混同。

## 二、文本结构与核心思想

《原文》五节悉依补充条目通例，其义理要点可析为三层。

其一，后四度的义涵。方便波罗蜜（Upāya）谓大悲与般若相摄，能于度生善巧运转；愿波罗蜜（Praṇidhāna）谓发弘誓愿、摄受当来果；力波罗蜜（Bala）谓思择力与修习力，能破诸障；智波罗蜜（Jñāna）谓如实了知一切法相、一切有情心行的后得智。四者共同的特点是「从般若起用」：般若自证空性为根本智，起而照见万法为后得智，后四度即后得智在利他行上的四种展开。

其二，十度与十地的配属。依《解深密经》与《成唯识论》：初欢喜地由施度增上而入，二地戒度增上，三地忍度，四地精进度，五地定度，六地般若度，七地方便度，八地愿度，九地力度，十地智度。一地一度各显其增上，恰如十道关口各有专属的通关科目；引文「如是十度圓滿，得無上菩提」正点出十度圆满与佛果的对应。

其三，「体用」判释的枢纽。第二条引文以六度为体、四度为用，显示十度系统并非推翻六度，而是把六度中笼统含摄的「般若利他」一翼析出为四目：知行结构由「五足一目」细化为「五足一目四翼」。

## 三、学术研究价值与争议

第一，十度成立的宗派归属。十度说为瑜伽行派所立，中观系论典则多以六度为量（月称《入中论》仍以六度配十地，于第六地广赞般若）。故「十度对六度」实为唯识与中观在菩萨行结构上的分歧之一。本条目采十度说而未标宗派立场，当由读者自辨。

第二，配属次第的诠释差异。《解深密经》《摄大乘论》《成唯识论》于十度配十地大同小异，而《华严经·十地品》于各地所举诸行并不严格一地一度（如初地广说布施而兼及十愿），显示「一地一度」是论典化的整理而非经文原貌。本条目引文只举总纲、不及配属，回避了这一层的复杂性。

第三，与十地说的内在关联使十度成为研究菩萨道阶次论的重要标本：六度答「修什么」，十地答「修到哪一步」，十度配十地则把两者焊成一张「课程—年级」对照表。又藏传依《现观庄严论》系的传统以十度配合三智四加行，另有庞大注疏体系，其根本论典不在大正藏编号体系之内，应转检德格版《甘珠尔》《丹珠尔》编目。
