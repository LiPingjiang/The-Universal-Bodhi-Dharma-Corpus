# 中論頌與青目釋 — 学术解读

## 一、文献背景与成书

《中论颂》的梵名为 Mūlamadhyamakakārikā，传统归于印度中观学派创始人龙树（约二至三世纪）。现行汉文本《中论》四卷二十七品，收《大正藏》第三十册，编号T1564，题为龙树造、梵志青目释，后秦鸠摩罗什译。一般据僧叡《中论序》及罗什译经活动，将译出年代置于弘始年间，约409年前后。T1564并非只有龙树偈颂，而是以颂为骨架、把青目释文编入其间的"颂释合编本"。这正是它与仅存藏译的佛护释、保存梵本和藏译的月称《明句论》最显著的文献差别。

青目，梵名常还原为Piṅgala（宾伽罗），生平与年代均缺乏可靠材料。僧叡序称其注释有"乖阙烦重"处，鸠摩罗什曾加以裁补，因此现存汉文究竟在多大程度上保留青目原貌，须审慎判断。该本梵本已佚，却因文字简洁、义路清楚，成为中国三论宗研习《中论》的基础，与《百论》《十二门论》合称"三论"，又深刻影响天台、华严、禅宗的空义表达。

版本上，T1564的二十七品次序与现存梵藏颂本大体相应，却在颂数、分品和个别句义上存在差异。历代刻藏又有字形、断句异文，吉藏《中观论疏》等注释则保存早期读法。故校勘龙树偈颂时，不能先删去释文再把所得汉句视作唯一原颂，而应结合释文引句、梵本和藏译逐处判断。

## 二、文本结构与核心思想

全论从观因缘、去来、六情、五阴等日常范畴起，逐层考察作业、苦、行、合、缚解、时间、自性、四谛与涅槃，最后以观邪见品收束。方法不是先提出一种宇宙实体，而是检查人们认为事物"自有、自成、自立"时会产生何种矛盾。开篇八不——"不生亦不灭，不常亦不断，不一亦不异，不来亦不出"——总摄对生灭、常断、一异、来出的破斥。

青目释的特色，是用宾主问答和生活事例解释颂义。例如论证诸法非自生、他生、共生、无因生，并不等于说经验世界全无，而是指出任何法都依因待缘，故无固定自性。《观四谛品》的"众因缘生法，我说即是空，亦为是假名，亦是中道义"，把缘起、空、假名、中道联为一体：正因为事物没有不变自性，才可能依条件成立、变化并发挥作用。因此"空"不是虚无，反而是因果与修行能够成立的条件。

## 三、学术研究价值与争议

T1564的首要价值是保存了一套早期《中论》解释传统。它比佛护、清辨、月称等六世纪以后的注本更接近罗什时代，是研究印度中观早期分化与汉传三论思想不可替代的资料。第二，它显示翻译不是机械换字：僧叡序留下罗什裁补释文的记录，使学者能够讨论译场协作、文本编辑与思想诠释的关系。第三，汉、梵、藏对勘可揭示偈颂品名、颂数、句义的异同。

争议主要有三层。一是青目的身份至今不明，不能把后代传说当作确定传记。二是T1564释文的作者层次复杂，某句话究竟出自青目、罗什还是译场润饰，往往难以判定。三是著名"三是偈"的汉译用语与梵、藏本在语法层次上不完全重合，学界对"假名"与"中道"的解释仍有分歧。与佛护相比，青目释并未以"应成"方法自我标榜；与月称相比，也没有后来系统化的二谛和语言哲学论证。把三者直接等同，会抹去数百年的注释史演变。

## 四、术语对照表

| 术语 | 释义 |
|---|---|
| 中观 | 不落有、无等两边，以缘起无自性观察诸法的立场 |
| 自性 | 被设想为独立、恒定、不待条件而有的本质 |
| 八不 | 不生灭、不断常、不一异、不来出的八重否定 |
| 假名 | 依条件和语言约定而成立的名称与事物 |
| 四句 | 有、无、亦有亦无、非有非无四种概念选项 |
| 青目释 | T1564所收早期《中论》释文，现存形态经过罗什译场裁整 |
