# 智力階梯：藏傳攝類學新論

## 本書結構

《智力階梯：藏傳攝類學新論》為國內正式出版的藏傳因明學入門讀物，全書以「階梯」為比喻，意指攝類學的學習如同攀梯，須循序漸進、拾級而上。全書分為六篇：

**第一篇　基礎範疇**：介紹攝類學（bsdus grva）的歷史源流與學科定位，說明其在藏傳佛教教育體系中的基礎地位。涉及色法（gzugs）、心法（sems）、心所法（sems byung）、不相應行法（ldan min 'du byed）、無為法（'dus ma byas）等五類法的基本定義與分類。

**第二篇　邏輯基礎**：系統講解「有（yod）與無（med）」「一（gcig）與異（gzhan）」「相違（'gal ba）與相屬（'brel ba）」「周遍（khyab）」等邏輯範疇，並以圖表方式呈現各範疇之間的邏輯關係。

**第三篇　因明論式**：詳細剖析自續論式（rang rgyud kyi sbyor ba）與應成論式（thal 'gyur kyi sbyor ba）的結構與運作方式，以流程圖展示論式中宗（phyogs）、因（gtan tshigs）、喻（dpe）的邏輯鏈條。

**第四篇　認識論**：講解現量（mngon sum）、比量（rjes dpag）、再決識（bcad shes）、伺察識（yid dpyod）、現而不決（mngon du byung yang ma nges pa）等認識類型的定義與區分。

**第五篇　辯經實戰**：以圖表梳理辯經邏輯結構，總結應成論式套路，並提供大量練習題與高頻易錯點分析。

**第六篇　附錄**：藏漢術語對照表、辯經常用語式速查表、推薦閱讀書目。

## 辯經邏輯結構圖表說明

本書的核心特色之一，是以圖表方式呈現辯經的邏輯結構，使抽象的邏輯推理過程視覺化。以下為主要圖表的說明：

### 圖表一：辯經基本流程圖

```
攻方立宗 → 守方回應 → 攻方追問 → 守方再回應 → …… → 守方自相矛盾或攻方因不成
```

辯經的基本流程是一個「推進—回應」的循環。攻方每次提出一個推論，守方有三種可能的回應：

- **承認（khas blangs）**：同意攻方的推論。攻方繼續追問，直到守方的承認與其原有立場產生矛盾。
- **不周遍（ma khyab）**：否認攻方推論中的周遍關係——即「即使你的前提成立，結論也不一定成立」。攻方需要證明周遍關係。
- **因不成（rtags ma grub）**：否認攻方推論中的前提——即「你的前提本身不成立」。攻方需要先證明前提。

### 圖表二：應成論式結構圖

```
【應成論式基本結構】
若 A，應 B，以 C 故。

     ┌─── A = 所立（phyogs，宗）
     ├─── B = 所遮（dgag bya，所破）
     └─── C = 能立因（gtan tshigs，因）

【邏輯鏈條】
C（因）→ 周遍 → B（所遮）
     ↑
  A（所立）中 C 成立嗎？
     ├── 成立 → 守方必須承認 B
     └── 不成立 → 攻方需另尋因
```

應成論式的特點在於：攻方不直接主張「凡是 A 皆是 B」，而是以對方所承認的前提為出發點，推出對方不願接受的結論。這是一種歸謬法（reductio ad absurdum）的邏輯結構。

### 圖表三：周遍關係判定圖

```
            ┌── 正周遍（yang dag khyab）：若因成立，則所立法必成立
因與所立法 ─┤
            └── 反周遍（ldog pa khyab）：若所立法不成立，則因必不成立

            ┌── 同品周遍（mthun phyogs khyab）：同品中因必遍
同品與異品 ─┤
            └── 異品周遍（mi mthun phyogs khyab）：異品中因必不遍
```

### 圖表四：三相判定圖

```
因三相（rtags gsum）：
1. 宗法（phyogs chos）：因在所立上成立
2. 同品遍（mthun pa'i phyogs khyab）：凡是同品皆有此因
3. 異品遍（mi mthun pa'i phyogs khyab）：凡有此因者皆非異品

判定流程：
因 → 是否在所立上成立？ ──是──→ 是否同品遍？ ──是──→ 是否異品遍？ ──是──→ 正因
  └──否──→ 因不成                └──否──→ 不定因        └──否──→ 相違因
```

## 應成論式套路詳解

應成論式（thal 'gyur kyi sbyor ba）是藏傳辯經的核心工具。以下為本書總結的五大套路：

### 套路一：同體破斥法

**適用場景**：守方承認兩法「同體」（bdag gcig），但又否認二者在邏輯上應有相同的屬性。

**論式模板**：
若 A 與 B 同體，且 A 具有屬性 C，則 B 亦應具有屬性 C，以同體之法不可分離故。

**實例**：
攻方：色與色之無常，同體否？
守方：同體。
攻方：若同體，則色無常時，色之無常亦應無常，以同體之法不可分離故。
守方：不周遍。
攻方：同體之法不可分離，汝已承認。若不可分離，則一法轉變時，同體之法亦應轉變。
守方：（若承認）——則色之無常亦無常，此為不合理。守方自宗相違。

### 套路二：周遍逆推法

**適用場景**：守方承認一個周遍關係，攻方利用逆否命題推出守方不願接受的結論。

**論式模板**：
守方承認「若 A 則 B」（A khyab byed, B khyab bya）。
攻方：若非 B，應非 A，以汝承認「若 A 則 B」故。

**實例**：
守方：凡是色皆是無常。
攻方：若非無常，應非色，以汝承認「凡是色皆是無常」故。
守方：承認。
攻方：虛空（nam mkha'）非無常，以是無為法故。
守方：承認。
攻方：然則虛空非色？
守方：承認。（正確。虛空確實非色。此處攻方未能破斥，需另尋角度。）

### 套路三：定義排除法

**適用場景**：利用定義中的排除功能，找出守方所承認之法不符合定義的情況。

**論式模板**：
D 之定義包含要件 E。守方承認 F 是 D。但 F 不具備要件 E，故 F 非 D。

**實例**：
攻方：現量之定義為何？
守方：離分別、無錯亂、新起、不欺誑之了知。
攻方：見雪山為青色之眼識，是否為現量？
守方：是現量。（常見錯誤。）
攻方：此識是否離錯亂？
守方：離錯亂。（若如此答，則與事實不符——雪山在遠處看為青色是錯亂的。）
攻方：若此識離錯亂，則雪山應為青色，以離錯亂之識如實反映對象故。
守方：不周遍。
攻方：離錯亂之識的定義即「如實反映對象之識」，汝已承認。若如實反映，則對象應如所現。
守方：根本宗已壞。

### 套路四：兩難破斥法

**適用場景**：迫使守方在兩個都不利的选择中做抉择。

**論式模板**：
F 是否具備 G？
若具備——推出矛盾 A。
若不具備——推出矛盾 B。
故 F 之存在方式有問題。

### 套路五：返推歸謬法

**適用場景**：從守方的立場出發，推出一個明顯荒謬的結論。

**論式模板**：
若守方承認 P，則應承認 Q（以 P 為前提推出 Q）。而 Q 為守方所不許（或明顯荒謬），故 P 不能成立。

## 高頻易錯點匯總

本書總結了初學者在攝類學學習與辯經練習中的三十餘個高頻易錯點，以下列舉最重要者：

### 易錯點一：混淆「現量」與「現而不決」

現量（mngon sum）必須是「新起」的認識——即首次生起的正確認識。而已經生起過的認識再次生起時，稱為「再決識」（bcad shes），不是現量。此外，「現而不決」（mngon du byung yang ma nges pa）——即對象已經呈現在認識面前，但尚未形成確定的判斷——也不是現量。初學者常將「看到但不確定」誤認為現量。

### 易錯點二：「不周遍」與「因不成」的誤用

守方在辯經中只有三種回答，但初學者常在不該說「不周遍」時說了「不周遍」，或在該說「因不成」時說了「不周遍」。判斷標準：

- 如果攻方的前提你同意，但認為推不出結論——說「不周遍」。
- 如果攻方的前提你不同意——說「因不成」。
- 如果兩者都同意——說「承認」。

例如：攻方說「聲音應是無常，以是所作故」。如果你認為「聲音是所作」這個前提不成立（比如你認為聲音是永恆的），應說「因不成」。如果你同意聲音是所作，但不認為「所作」必然推出「無常」，應說「不周遍」。

### 易錯點三：將「自相」與「自性」混淆

「自相」（rang mtshan）是攝類學中的認識論概念，指個別的、具體的、可以被現量所緣的對象。「自性」（rang bzhin）則是本體論概念，指事物固有的本性。中觀派（dbu ma pa）否定「自性」（rang bzhin gyis grub pa），但不否定「自相」——否則將墮入虛無主義。初學者常將二者混為一談，在辯經中犯嚴重錯誤。

### 易錯點四：「相違」範圍的過度擴大

「相違」（'gal ba）在攝類學中有嚴格定義——兩法不能同時存在於同一處。初學者常將「不同」「相反」「不相關」都理解為「相違」。實際上，「冷」與「熱」是相違（不並存相違），但「紅」與「藍」並非相違——它們可以同時存在於同一處（如彩虹）。紅與藍是「異」而非「相違」。

### 易錯點五：應成式中「應」字的理解

應成論式中的「應」（thal/應成）表示「按照你的邏輯，應該推出這個結論」。初學者常將其理解為「我認為這個結論是對的」，從而在辯經中搞混攻守雙方的立場。應成式是歸謬工具——攻方並不主張結論為真，而是說「如果接受你的前提，就必須接受這個荒謬結論」。

### 易錯點六：忽略定義中的「新起」要件

現量定義中的「新起」（gsar du）要件常被忽略。初學者認為「只要是直接感知就是現量」，但攝類學要求現量必須是「首次生起」的認識。第二次看到同一個對象時生起的認識是「再決識」，不是現量。這一區分在辯經中極為重要——如果守方忽略了「新起」要件，攻方可以輕易找到破綻。

### 易錯點七：混淆「同品」與「同體」

「同品」（mthun phyogs）是邏輯概念，指「具有所立法屬性的法」——如在「聲音無常，所作性故」這個論式中，凡是無常的法都是同品。「同體」（bdag gcig）是本體論概念，指兩法在存在上不可分割。初學者常將二者混淆，導致在判定三相時出錯。

## 結語

《智力階梯：藏傳攝類學新論》以圖表化、套路化的方式重構了攝類學的學習路徑，使其成為零基礎讀者進入藏傳因明學的理想門徑。書中的邏輯結構圖表將抽象的因明推理視覺化，應成論式套路將繁複的辯經策略模塊化，高頻易錯點分析則為初學者提供了實用的「避坑指南」。對標國內中小學教育中的「教材全解」系列，本書在藏傳因明學領域扮演了類似的角色——它不追求學術原創，而是追求教學效率，讓盡可能多的人在盡可能短的時間內掌握攝類學的基本邏輯框架。
