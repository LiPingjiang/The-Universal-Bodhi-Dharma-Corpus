# 佛教心理統計 · 原文

## 一、學科概述

佛教心理統計並非一門獨立學科，而是對冥想科學研究之統計方法學的總括：禪修干預的效應如何估計、樣本量如何計算、效應量如何解讀、薈萃分析得出什麼結論、研究可否重複——這些統計學問題直接決定「佛教心理學」的科學成色。該領域的標誌性事件有二：其一，2014年約翰斯·霍普金斯大學的馬達夫·戈亞爾等人在《JAMA內科學》發表對47項臨床試驗、3515名被試的薈萃分析，結論是冥想程序對焦慮與抑鬱呈中等效應量（效應量約0.3），但證據品質有限；其二，2018年，范達姆（Nicholas Van Dam）等八位學者在《心理科學視角》發表「注意炒作」（Mind the Hype）一文，系統檢討正念研究中缺乏活性對照、樣本量不足、定義含混等統計與方法學缺陷，成為領域自我糾偏的里程碑。佛教「緣起」的因果思維與統計學對條件依賴的建模，構成東西方方法的深層呼應。

## 二、核心議題與佛教觀點

核心議題包括：（一）對照組設計——正念試驗的理想對照是「活性對照」（如健康教育的等接觸干預），以分離安慰劑與期待效應；（二）效應量語境——正念對一般人群「幸福感」的效應量普遍小於對臨床人群症狀的效應量，統計顯著不等於臨床意義；（三）重複性危機——預註冊、多實驗室聯合重複（如2023年發表於《心理科學》的跨實驗室正念重複研究）正成為新標準；（四）中介分析——正念研究大量使用結構方程建模檢驗「去中心化」「自我慈悲」等中介變量，與佛教「因緣次第生」的緣生觀在方法上同構：一切效應皆依條件網絡而生，統計即緣起的現代數學語言。《雜阿含經》迦旃延對「有無二邊」的破斥，恰是統計思維「避免全有全無、估計連續量化」的古典表達。

> **經典依據**：
> 「世人顛倒依於二邊，若有、若無……如實正觀世間集者，則不生世間無見；如實正觀世間滅者，則不生世間有見。」——《雜阿含經》（T99）

佛說世人墮於「全有」「全無」二邊之見，正觀者依緣起而離二邊——這與統計學拒斥二值化思維、以連續概率與置信區間估計真相的精神如出一轍：研究結論永遠是「估計」，而非「有無」的斷言。

## 三、代表學者與實踐

戈亞爾團隊2014年的薈萃分析以嚴格的納入標準（僅取隨機對照試驗）重新校準了正念的療效定位，論文成為引用最高的正念方法學文獻之一。范達姆、蓋爾蓋伊·德利貝爾特（Gaelle Desbordes）等合著的「Mind the Hype」匯集了神經科學與臨床的多方視角，明確提出「正念研究的未來取決於方法嚴謹性」。哈佛大學的德利貝爾特堅持以活性對照與「一假設一影像」的腦成像標準研究禪修，其「佛教學者與神經科學家」雙重背景使批評尤有分量。近年，「沉思研究協會」與《正念》（Mindfulness）期刊推動的預註冊報告、多臂參數化試驗設計，正把這一領域的統計實踐推向臨床試驗的黃金標準；而針對長期禪修者小樣本研究的貝葉斯方法應用，也為「高價值個案」提供了合適的統計工具。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 效應量 | 干預效果大小的標準化量數，如Cohen's d |
| 薈萃分析 | 對多項研究結果的統計合成 |
| 活性對照 | 與干預組接觸量相當的對照處理 |
| 中介分析 | 檢驗「干預→中介變量→結果」路徑的統計方法 |
| 預註冊 | 研究前公開假設與分析計劃以防偏倚 |
| 緣起 | 佛教因果論：此有故彼有，條件網絡中生滅 |
