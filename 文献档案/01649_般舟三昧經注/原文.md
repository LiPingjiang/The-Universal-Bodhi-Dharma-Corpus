# 般舟三昧经注·原文

## 一、概述

《般舟三昧经》三卷（T417），又称《佛立三昧》《十方现在佛悉在前立定经》，东汉·支娄迦谶于光和二年（179年）在洛阳译出，收于《大正藏》第十三册。另有同经异译一卷本（T418），同为支娄迦谶译，或题为失译。隋代阇那崛多、笈多另译为《大方等大集贤护经》五卷（T416）。

本经是大乘佛教早期融通般若空观与念佛禅定的根本经典，也是天台常行三昧、净土念佛心法共同依止的源头圣典。"般舟"为梵语Pratyutpanna音译，意为"现前""佛立""常行"；"三昧"即一心专注不散不乱的正定。经中提出"有三昧，名十方诸佛悉在前立"，以专一念佛为入手，以九十日（或七日）为一期，昼夜恒行不坐不卧，摄心归一，复以般若正观照破诸相，了达万法唯心，于现世正定中感通十方诸佛、阿弥陀佛当下现前。见佛之力依三力：佛威力、三昧力、行者本功德力。本经最早将阿弥陀佛净土信仰传入中国，东晋慧远庐山白莲社即以般舟三昧为根本行持。

## 二、核心段落

### 原文

> 佛告颰陀和：菩萨欲疾得是定者，常立大信，如法行之则可得也。勿有疑想如毛发许，是定意法，名为菩萨超众行。立一念，信是法，随所闻，念其方。宜一念，断诸想，立定信，勿狐疑。精进行，勿懈怠。勿起想，有与无。勿念进，勿念退。勿念前，勿念后。勿念左，勿念右。勿念无，勿念有。勿念远，勿念近。勿念痛，勿念痒。勿念饥，勿念渴。勿念寒，勿念热。勿念苦，勿念乐。勿念生，勿念老。勿念病，勿念死。勿念身，勿念命。勿念寿，勿念贫。勿念富，勿念贵。

> 菩萨有四事法，疾逮得三昧。何等为四？一者所信无有能坏者，二者精进无有能逮者，三者所入智慧无有能及者，四者常与善师从事。菩萨复有四事，疾得是三昧。何等为四？一者不得有世间思想，如指相弹顷三月。二者不得卧出三月，如指相弹顷。三者经行不得休息，不得坐三月，除其饭食左右。四者为人说经，不得望人衣服饮食。

> 佛告颰陀和：是菩萨三昧当云何譬？如佛今于若前说经。菩萨当作是念：诸佛悉在前立。当具足念诸佛端正，悉欲逮见一一想。……佛亦不用心得，亦不用身得，亦不用心得佛，亦不用色得佛。何以故？心者佛无心，色者佛无色。不用是心色，得阿耨多罗三藐三菩提。

### 白话翻译

> 佛告诉颰陀和：菩萨想要迅速证得这个三昧，要常立坚固的信心，如法修行就能获得。不能有毛发般的疑惑，这个定意法门，名为菩萨超越一切修行的方法。确立一念，信受此法，随所听闻的，忆念那个方向。保持一个清净的念头，断除所有妄想，建立坚定的信心，不要犹豫。精进修持，不要懈怠。不要起有与无的分别想。不要念进退、前后、左右、有无、远近、痛痒、饥渴、寒热、苦乐、生老病死、身命寿、贫富贵贱——一切皆不执著。

> 菩萨有四种法能迅速证得三昧。哪四种？一是信心坚固无有能破坏，二是精进修行无有能超过，三是所入智慧无有能企及，四是常与善知识共事。菩萨又有四种法能迅速证得此三昧。哪四种？一是在三月中没有世间杂念，连弹指顷都不可以。二是在三月中不卧睡，连弹指顷都不可以。三是经行不休息，三月中不坐下，除吃饭和大小便之外。四是为人讲说佛经，不求人供养衣服饮食。

> 佛告诉颰陀和：这个菩萨三昧应当如何比喻呢？如同佛现在在你面前说经。菩萨应当这样观想：十方诸佛都站在面前。应当具足忆念诸佛的端正相好，一一想见。……佛也不是从心而得，也不是从身而得，不是从心得佛，也不是从色得佛。为什么呢？说到心，佛没有心；说到色，佛没有色。不是用这心色，能证得无上正等正觉。

## 三、名句

1. **"常立大信，如法行之则可得也。勿有疑想如毛发许。"** ——经中开宗明义，以"大信"为般舟三昧成就之根本前提，强调信心须坚固不疑如毛发，方堪修此超众行之法门。

2. **"心者佛无心，色者佛无色。不用是心色，得阿耨多罗三藐三菩提。"** ——此句揭示般舟三昧的般若空观核心：念佛见佛而不著佛相，了达心色本空，方契实相，体现本经融通般若与念佛的根本特色。

## 四、术语表

| 术语 | 释义 |
|------|------|
| 般舟三昧 | 梵语Pratyutpanna-samādhi，意为现前、佛立，即定中见十方现在诸佛现前立于面前 |
| 佛立三昧 | 般舟三昧之异名，以定中见佛立前而得名 |
| 常行三昧 | 天台四种三昧之一，依《般舟三昧经》修，九十日常行不坐不卧 |
| 三力 | 见佛之三种力量：佛威力、三昧力、行者本功德力 |
| 颰陀和 | 梵语Bhadrapāla，即贤护菩萨，本经之当机众 |
| 经行 | 旋绕行道，身常行不休息，为般舟三昧的身业行法 |
| 九十日 | 般舟三昧修行的标准期限，在此期间不坐不卧不眠不息 |
| 无著 | 本经第五品名，谓于所见佛相不生执著，以般若空观消融相执 |
