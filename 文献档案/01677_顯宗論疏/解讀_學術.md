# 顯宗論疏 — 学术解读

## 一、文献背景与成书

本档名目为《顯宗論疏》，须先如实说明文献实情：本档原文档是一篇以文言概述体写成的总叙文字，行文以「夫显宗论疏者，阿毗达磨之疏释」发端，通篇系统复述有部阿毗达磨的教理框架，而非一部流传有绪的古代疏本——其语句组织、叙述方式与现代拟古撰述的特征相符，且本档目录的 README 亦标注为「占位目录，内容待整理」。故本档的撰写立场是：以原文档之所述为据，对勘通行文献学记载，如实注明出入，不作虚构。

通行文献学的记载如下：题为「显宗论」之书，即《阿毘達磨顯宗論》，众贤（Saṃghabhadra）造，唐玄奘译，四十卷（通行分卷或作四十八卷），大正藏编号 T1563。众贤是有部迦湿弥罗系论师，先造《阿毘達磨順正理論》（T1562，八十卷）驳世亲《俱舍论》，后为便利学人，将《顺正理论》义理删节别裁为《显宗论》，故古称《显宗论》为《顺正理论》之「略本」或「别疏」。原文档称「玄奘三藏为作疏释」，与通行记载有出入：玄奘是《显宗论》之译者而非疏释之作者，译与疏不可混为一谈；此点依规则注明，读者采用本档时宜以通行记载为参照。

## 二、文本结构与核心思想

原文档所述的教理框架，恰是有部阿毗达磨的标准体系，可分五层看。

其一，阿毗达磨之名义与源流：「阿毗达磨者，此云对法，谓以智对观四谛之理，而得涅槃之法。」并历数佛世自说、结集论议、有部造论（《发智》《六足》《大毗婆沙》）的教学史脉络。其二，五位法之分类：一切法摄为色法（五根、五境及无表色，共十一）、心法（六识心王）、心所法（遍行、别境、善、烦恼、随烦恼、不定）、心不相应行法（得、非得、众同分、命根等）、无为法（虚空、择灭、非择灭）——此即有部七十五法的组织法。其三，三世实有之宗义与四相：「法体恒有，三世实有」，三世约作用而立名；有为四相（生住异灭）令法从生至灭。其四，六因四缘五果之因果论：能作、俱有、同类、相应、遍行、异熟六因，因缘等无间缘所缘缘增上缘四缘，异熟、等流、离系、士用、增上五果——原文档对此一节的铺陈最为完整，是其核心所在。其五，行位论：六根本烦恼（贪嗔痴慢疑恶见）之相，五停心、四念处、暖顶忍世第一法之加行，以及七贤四圣之位次。

就思想归趣而言，原文档末段自道：「此疏使阿毗达磨之法相明白如画，有部之宗义昭然可见。学者当依之修学，洞明法相，然后入大乘之圆理，自浅至深，渐次通达。」

## 三、学术研究价值与争议

本档的研究价值须分两层评估。就原文档本身而言，其价值在于提供了一份系统而有条理的有部教理提要——五位法、六因四缘五果、七贤四圣诸节的组织完整清晰，作为俱舍、阿毗达磨之学的入门导读，自有其便用；但其性质是后人概述而非古疏，不能作为唐代文献引用，此一判断应向使用者明确交代。就「显宗论」这一名目所联系的通行典籍而言，《显宗论》（T1563）的研究价值有三：其一，作为《顺正理论》的纲要本，二书对读可观察有部论书「广论—略本」的写作传统；其二，其与《俱舍论》的对峙立场，是部派晚期有部正统与经部化倾向论争的主要史料；其三，玄奘连译《顺正理论》《显宗论》二部，其译语对勘为汉传阿毗达磨词库研究提供同源样本。争议与限制：其一，如上所述，本档原文档与通行文献学记载存在作者归属的出入（玄奘译抑或玄奘疏），且原文档非古本，采信须注明；其二，众贤生平与《顺正理论》《显宗论》先后关系的细节，依《婆藪槃豆法師傳》等所载而年代先后仍有讨论；其三，《显宗论》删节《顺正理论》时取舍的标准与造成的义理偏移，是二书比较研究中的持续课题。

## 五、延伸阅读

- `01676_順正理論疏`：T1562 众贤《顺正理论》，《显宗论》之广本，两档对读最见「广略」传统。
- `01667_俱舍論頌疏`：世亲《俱舍论》系统——众贤著述所回应的对象，背景必读。
- `01670_阿毗達磨大毗婆沙論釋`、`00046_大毗婆沙論`：有部根本论典，《显宗论》所承之正统。
- `01671_發智論疏`、`01673_六足論疏`：有部「一身六足」论书群。
- `01679_入阿毗達磨論疏`：同为有部入门论书条目，与本档俱作俱舍学阶梯，可比较两类入门书之取径。
