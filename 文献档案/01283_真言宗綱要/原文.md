# 真言宗綱要

## 一、概述（大正藏編號）

《真言宗綱要》為黃繩曾居士編著的近現代真言宗概論，非佛典，**無大正藏編號**。全書設「宗名」「教相與事相」「十住心」「六大體大」「三密用大」「即身成佛」「護摩」等二十五節，旨在提綱介紹真言宗義理與行法。

## 二、核心段落（真實原文＋白話翻譯）

> **原文（〈羅序〉）：**
>
> 「古學簡而質，今學繁而縟；行持或異，義解微殊，要皆以從『本不生』義流出，速疾圓滿福智資糧為宗趣也。」

> **白話翻譯：**
>
> 古代傳承簡要而質樸，後起傳承繁富而細密；修行方法或許不同，義理詮釋也略有差別，但都以「本不生」的義理為根源，並以迅速圓滿福德與智慧二種資糧為宗旨。

## 三、名句

> 「要皆以從『本不生』義流出，速疾圓滿福智資糧為宗趣也。」

## 四、術語表

| 術語 | 說明 |
|---|---|
| 真言宗 | 以真言、印契、觀想等三密法門為核心的日本密教宗派。 |
| 教相 | 對教義體系的理論闡釋。 |
| 事相 | 儀軌、修法等實踐面向。 |
| 本不生 | 一切法本來不生的義理。 |
| 福智資糧 | 福德資糧與智慧資糧。 |
