# 藏传佛教艺术典籍 — 学术解读

## 一、文献背景与成书

本档案为藏传佛教艺术文献的综述性条目，核心典籍是《佛說造像量度經》。按原档案所记，此经收于《大正新修大藏经》第十九册，编号 T1419；经首因缘谓佛将升忉利天为母说法时，舍利弗问「若有善人思覩世尊，願造容像者，則其法如何為之」，佛遂宣说造像量度之法，故传统上题为舍利弗所记。需要说明：本经虽以汉译本形态编入大正藏编号体系，但它所代表的造像量度学传统属于藏传佛教的知识体系，其藏文原典与后世的量度论疏、唐卡画诀等大量文献均以藏文传存，不在大正藏编号之列——这是研究藏传艺术文献时必须先厘清的版本学事实。

汉译本题《佛說造像量度經》，由清代工布查布（又称衮布扎布，1690–1750）于乾隆七年（1742年）译成。工布查布出身蒙古贵族，通晓满、蒙、藏、汉诸语，他的译文并非单纯的翻译，而是一个完整的编译工程：全书分〈序〉〈引〉〈本经〉〈经解〉〈续补〉五部分，译者以「经解」与「续补」承担原典在藏传传统中的义理说明与补充仪则，使汉地读者得以按藏传规范造像。乾隆时代正是清宫藏传佛教艺术的鼎盛期，此书的译出与宫廷造办处的实际需求直接相关。

## 二、文本结构与核心思想

本经的核心是一套以「指」（tāla，中指宽度）为基本单位的比例系统。佛身全长合一百二十指，经文以偈颂逐项规定：「以自手指量，百有二十指。肉髻崇四指，發際亦如此。面輪豎縱度，帶半十二指……」肉髻、发际、面轮、额鼻、口唇、手足，每一部位都有精确的指数，构成一个可以复制、可以校验的造像技术标准。

「如來身量，縱廣相稱，如尼拘囉陀樹，滿自一尋」——如来的身量纵广相称，本身即是对佛陀三十二相中「身纵广等」之相的经典呼应。也就是说，量度并非任意的审美约定，而是佛身的如实呈现：比例正确，即是以像法身；比例失度，则失其本。工布查布在经解中说得更透彻：「蓋具幾分之准量，則凝注幾分之神氣；有神氣之力，以能引彼眾生之愛敬心；因以其愛敬心之輕重之分，而因獲其攝受利益之大小。」量度—神气—爱敬—摄受，这四环构成的链条，把技术标准最终归结为宗教功能：像的准确性决定了它能否成为有效的信仰媒介。

由此可以概括藏传艺术典籍系统的整体特征：它是「可操作的义理」。藏传佛教不把艺术当作装饰，而当作修行与观想的对象（本经即言造像为「為自他利益作福田」），因此曼荼罗的方位、唐卡的构图、像的量度都必须成典成法，由师徒传承。量度经正是这一「以经典规范技艺、以技艺承载教法」传统的代表文本。

## 三、学术研究价值与争议

研究价值方面：第一，此经是汉藏艺术交流史的关键文献——它是少数由藏文系统进入汉文大藏经序列的技术经典，为考订清宫藏传造像的规格提供了同时代的标准文本；第二，以「指」为相对单位的量度系统体现了一种比例化的身体观念，可与西方的维特鲁威人体比例、汉地传统画论（如「立七坐五」之说）作跨文化比较，是艺术史与身体史研究的好材料；第三，工布查布的〈经解〉〈续补〉保存了大量藏传造像仪轨细节，本身即是一份十八世纪藏传佛教知识东传的记录。

争议与问题方面：其一，经首「舍利弗请问」的叙事属经典的典型序分安排，其所据藏文原典的实际形成年代与文献层级，学界仍在研究之中，引用时宜区分信仰叙事与文献史结论；其二，汉译本中的经解部分掺入译者自家理解，译文与藏文原典之间的出入需要通过藏汉对勘逐段核实；其三，量度规范与实际造物之间的差距——传世造像并不总是严格遵守经文指数，规范文本如何转化为工匠实践，涉及口传诀窍、粉本传承等不见于文字的层面，单靠经文无法完整重建。此外，本档案作为主题类条目，实际收录以量度经为核心，唐卡画史、曼荼罗仪轨文献的系统整理尚有赖于藏文文献目录学的进展。

## 四、术语对照表

| 术语 | 释义 |
|------|------|
| 造像量度（pratimā-lakṣaṇa） | 规定佛像各部位比例与尺寸的学问，藏传佛教艺术的理论基石 |
| 指（tāla） | 以造像自身中指宽度为准的基本量度单位，佛身全长一百二十指 |
| 肉髻（uṣṇīṣa） | 佛头顶隆起之相，三十二相之一，量度经定为崇四指 |
| 唐卡（thang-ka） | 藏传佛教卷轴画像，依量度与仪轨绘制的可移动观想对境 |
| 曼荼罗（maṇḍala） | 佛菩萨依仪轨配置的圆形或方形图式，观想与灌顶的空间模型 |
| 尼拘啰陀树（nyagrodha） | 榕树类，经典中喻如来身量「纵广相称」、周圆一寻之相 |
| 神气 | 工布查布经解术语，指依准量而凝聚于像中的摄受力量 |
| 福田 | 造像作为功德之「田」，众生依之种福获益的功能定位 |
| 工布查布 | 清代译经家，满蒙贵族出身，此经之汉译者与经解撰者 |
