# 信心銘註解 · 原文

## 一、文獻概述

《信心銘》相傳為禪宗三祖鑒智禪師僧璨（?—606，隋大業二年圓寂）所作，收於《大正新修大藏經》第四十八冊（編號T2010）。全文為四言詩體，凡一百四十六句、五百八十四字，自「至道無難，唯嫌揀擇」起，至「言語道斷，非去來今」止。僧璨生平史料極簡，《楞伽師資記》以「罔知姓位，不測所生」八字概括，唐道宣、宋贊寧皆未為其立傳，故《信心銘》之著作權學界亦有異說，然千餘年來禪門皆以此銘為三祖心要。其思想強調遠離一切對立、差別、是非得失之妄念，而住於平等自在之境地，提倡「一即一切、相互融通」之圓融思想，與傅大士《心王銘》、牛頭法融《心銘》同出一思想脈絡，對初期禪宗思想之形成影響極大。

歷代注解方面，據《佛學大辭典》所載，著名者有宋·真歇清了之《信心銘拈古》、元·中峰明本之《信心銘義解》；此外宋圓悟克勤、永明延壽《宗鏡錄》等於著述、拈提中亦多處徵引發揮此銘。近代以降，鈴木大拙曾英譯此銘流傳西方；現代注解、講錄（如各家《信心銘》講記）更多。本檔「信心銘註解」即彙集歷代注解之總目。本銘與《六祖壇經》並稱最中國化之佛門典籍，禪門常於課誦中諷誦之。

## 二、核心段落選錄

> **原文**：「至道無難，唯嫌揀擇。但莫憎愛，洞然明白。毫釐有差，天地懸隔。欲得現前，莫存順逆。」（《大正藏》T2010）
> **白話對照**：最高的道本來不難體悟，唯一的障礙是分別挑揀。只要放下憎惡與貪愛，真理便豁然明朗。然而只要有絲毫的偏差，便與道相隔天壤。想讓大道現前，心中就不能存著順與逆的對立。

> **原文**：「一心不生，萬法無咎。」「不用求真，唯須息見。」（《大正藏》T2010）
> **白話對照**：只要一念妄心不生起，萬法本來就沒有過失；不必另外去追求一個「真」，只需要止息種種妄見就夠了。此二句為全銘樞要，歷代注家如中峰明本《信心銘義解》皆於此發揮「歇即菩提」之旨。

> **原文**：「信心不二，不二信心。言語道斷，非去來今。」（全銘結句，《大正藏》T2010）
> **白話對照**：對真如的信心與真如自身不二，真如也不外於這份不二的信心。這一境界超越言語表詮，也超越了過去、未來、現在的時間分別——是全銘的總結。

## 三、重要名句

> **名句一**：「至道無難，唯嫌揀擇」——大道本自現成，分別揀擇是人為造成的障礙；此為禪門「平常心是道」思想之先聲。

> **名句二**：「止動歸止，止更彌動」——用強力壓制妄念以求靜止，反而使心更加躁動；不通向「一」，則動靜兩邊皆失其功。

> **名句三**：「執之失度，必入邪路；放之自然，體無去住」——執著過度必入歧途，放任自然則本體無所來去。

> **名句四**：「智者無為，愚人自縛」——智者隨順無為，愚人以造作之心自縛自纏。

> **名句五**：「眼若不睡，諸夢自除；心若不異，萬法一如」——清明覺照若常在不昧，如夢之妄境自然消散；心若不起分別，萬法本自一如。

## 四、術語對照表

| 術語 | 釋義 |
|---|---|
| 揀擇 | 分別挑選、取捨好惡；全銘視之為悟道唯一之「嫌」 |
| 至道 | 究竟之大道、最高真理，即真如法界 |
| 不二 | 超越能所、有無、順逆等一切二元對立 |
| 拈古 | 禪門注釋體裁之一，就古人公案語句拈提評唱，如清了《信心銘拈古》 |
| 義解 | 就文逐句解釋義理之體裁，如中峰明本《信心銘義解》 |
| 六塵 | 色、聲、香、味、觸、法；銘云「欲取一乘，勿惡六塵」 |
| 一如 | 萬法平等不異之本體 |
| 言語道斷 | 真理超越言語思慮之表詮 |
